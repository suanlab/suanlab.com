## 실수 미분보다 강한 극한

복소 도함수는 복소 증분 h가 모든 방향에서 0으로 접근할 때 같은 몫 극한을 요구합니다. f=u+iv로 쓰고 실수 방향과 허수 방향을 비교하면 필요한 Cauchy–Riemann 조건을 얻습니다.

$$
f'(z)=\lim_{h\to0}\frac{f(z+h)-f(z)}h,\qquad
u_x=v_y,\quad u_y=-v_x.
$$

위 수식의 u를 실수부로 읽습니다. 편미분이 있다는 사실만으로 충분하지는 않습니다. 실수 미분 가능성 또는 편미분의 근방 연속성과 함께 CR 조건을 사용해야 충분성을 얻습니다. 이 단원의 세 예제는 실수 C¹ 함수라 해당 조건을 충족합니다.

## 두 방향의 몫을 직접 비교하기

실수 방향의 극한은 uₓ+ivₓ이고 허수 증분 방향의 극한은 vᵧ−iuᵧ입니다. 두 값이 다르면 복소 도함수는 없습니다.

$$
\lim_{t\to0}\frac{f(z+t)-f(z)}t=u_x+iv_x,\qquad
\lim_{t\to0}\frac{f(z+it)-f(z)}{it}=v_y-iu_y.
$$

z²에서는 u=x²−y²,v=2xy라 두 방향 모두 2z입니다. 켤레 함수에서는 u=x,v=−y이므로 1과 −1로 달라 어느 점에서도 복소 미분 가능하지 않습니다. 실수 선형사상으로는 완전히 미분 가능한 함수라는 점과 대조하세요.

## 한 점의 미분과 정칙 근방

|z|²은 u=x²+y²,v=0입니다. CR은 x=y=0에서만 성립합니다. 원점에서는 |h|²/h=conj(h)→0이므로 실제 복소 도함수가 0입니다. 그러나 어떤 열린 근방도 원점 외 점을 포함하고 거기서 복소 미분이 실패합니다. 따라서 원점 주변에서 정칙이지 않습니다.

정칙은 열린 집합의 모든 점에서 복소 미분 가능한 성질입니다. “도함수가 한 점에서 존재한다”를 “그 주변에서 해석적이다”로 바꾸면 안 됩니다. 복소 해석의 강한 결론들은 열린 영역의 가정을 사용합니다.

## 실수 Jacobian의 제한된 모양

CR이 성립하는 점의 실수 Jacobian은 복소수 곱셈의 형태입니다.

$$
J_f=\begin{pmatrix}a&-b\\b&a\end{pmatrix},\qquad f'=a+ib.
$$

f′≠0이면 국소적으로 회전과 균일 확대의 일차 근사를 줍니다. f′=0인 임계점에서 같은 각도 보존 설명을 그대로 적용하지 마세요. 일반 실수 2×2 선형층은 이 구조를 만족하지 않을 수 있습니다.

## 그림과 AI 해석

그림은 기준점을 지나는 수평·수직 입력선의 **출력상**입니다. 출력 복소평면의 Re/Im 축이며 입력 격자 자체가 아닙니다. 유한 선분의 모양만으로 정칙성을 증명하지 않고 정확한 편미분·CR 잔차·근방 판정을 제공합니다.

복소 신경망의 활성화나 손실이 모두 정칙일 필요는 없습니다. 특히 실수값 비상수 손실은 열린 영역에서 정칙일 수 없으므로 Wirtinger 미분이나 R² 미분으로 최적화합니다.

## CR이 충분한 조건을 증명하기

f가 p에서 실수 사상으로 미분 가능하다고 가정하겠습니다. 실수 미분을 복소 선형 부분과 켤레 선형 부분으로 유일하게 나누면

$$
f(p+h)-f(p)=a h+b\bar h+o(|h|),\qquad
a=\tfrac12(f_x-if_y),\quad b=\tfrac12(f_x+if_y).
$$

입니다. fₓdx+fᵧdy에 dx=(h+conj h)/2, dy=(h−conj h)/(2i)를 대입하면 얻습니다. h로 나누면 a+b·conj(h)/h+o(1)입니다. 실수·허수 방향의 극한은 a+b와 a−b이므로 b=0이 필요합니다. b=0이면 모든 접근에서 나머지를 h로 나눈 값이 0으로 가므로 충분하기도 합니다.

f=u+iv로 쓰면 b=0은 정확히 uₓ=vᵧ, uᵧ=−vₓ입니다. a가 복소 도함수입니다. 이 증명은 좌표 편미분의 존재만이 아니라 실수 미분 가능성을 사용합니다. a와 b는 뒤에서 배우는 두 Wirtinger 미분이기도 합니다.

## 연속이고 한 점에서 CR이 성립하는 반례

원점의 값을 0으로 정한 실수값 복소 함수를 생각하세요.

$$
f(x+iy)=\begin{cases}\dfrac{x^3y}{x^4+y^2}&(x,y)\ne(0,0),\\0&(x,y)=(0,0).\end{cases}
$$

|f(x+iy)|≤|x|/2이므로 원점에서 연속입니다. 실수부의 두 좌표 편미분은 원점에서 0이고 허수부는 항상 0입니다. 따라서 원점에서 CR이 성립합니다. 하지만 다음 세 접근을 비교하면 다릅니다.

| 접근 h | 차분 몫 f(h)/h | 극한 |
|---|---|---|
| 실수 t→0의 t | 0 | 0 |
| 실수 t→0의 it | 0 | 0 |
| 실수 t→0의 t+it² | 1/[2(1+it)] | 1/2 |

두 좌표 검산은 일치하지만 곡선 접근에서 복소 극한이 실패합니다. 충분조건과 모순되지 않습니다. 이 함수는 원점에서 실수 미분 가능하지 않으며 [전미분 반례](/book/online/physics-math-for-ai/jacobians/)에서 그 이유를 증명했습니다. x≠0인 (x,0)에서 y 편미분은 1/x이므로 근방의 연속 편미분 조건도 실패합니다.

## Python으로 반례 검산하기

다음 표준 라이브러리 코드는 정확한 유리수로 차분 몫의 실수·허수 성분을 계산하며 음수 t도 포함합니다. 유한 계산은 식을 보여주고 서로 다른 극한은 복소 미분 실패를 증명합니다. 기존 대화형 실습의 세 C¹ 모형은 유지하며 이 함수를 별도 모형으로 표시하지는 않습니다.

```python
from fractions import Fraction as Q

def f(x, y):
    return Q(0) if x == 0 and y == 0 else x**3 * y / (x**4 + y**2)

def quotient(x, y):
    value = f(x, y)
    denominator = x*x + y*y
    assert denominator > 0
    return (value*x/denominator, -value*y/denominator)

for t in [Q(1, 2), Q(1, 8), Q(1, 32), Q(-1, 16)]:
    assert quotient(t, Q(0)) == (0, 0)
    assert quotient(Q(0), t) == (0, 0)
    curved = quotient(t, t*t)
    assert curved == (1/(2*(1+t*t)), -t/(2*(1+t*t)))
    assert abs(f(t, t*t)) <= abs(t)/2
    print(t, curved)
```

연구 과제: 정칙 층에 대한 논증을 적용하기 전에 어떤 정칙성 가정으로 실수 일차 전개를 정당화하는지 적어보세요. 실수·허수 두 방향의 섭동은 많은 잘못된 미분을 찾아낼 수 있지만 모든 함수의 복소 미분 가능성을 증명하지는 못합니다.
