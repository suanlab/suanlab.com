## 1. 국소 궤도에서 에너지 띠까지

반복 사슬의 각 셀에 국소 궤도 A와 B를 둡니다. 전자가 두 궤도 사이에서 이동할 가능성은 해밀토니안의 호핑 항으로 표현합니다. 유한한 고리에서는 주기 경계 조건을 만족하는 블로흐 파수가 이산적입니다. 고리가 길어질수록 파수가 연속 구간을 촘촘하게 채우고, 허용 에너지가 이어져 밴드를 이룹니다. 각 자리에 궤도 하나가 있고, 스핀이 없는 독립 전자가 최근접 자리 사이에서 이동한다고 가정합니다. [MIT OpenCourseWare, 전자 밴드 구조와 밀접결합 근사](https://ocw.mit.edu/courses/6-730-physics-for-solid-state-applications-spring-2003/resources/lecture_12c/)

## 2. 반복 사슬을 블로흐 해밀토니안으로 표현하기

두 자리를 포함한 셀의 길이는 $a$, 무차원 파수는 $q=ka$입니다. 셀 내부 호핑을 $t_1\ge0$, 셀 사이 호핑을 $t_2\ge0$으로 둡니다. 자리 에너지의 평균을 빼 A에는 $+\Delta$, B에는 $-\Delta$를 부여합니다. $n$번째 셀에서 공통 블로흐 위상 $e^{iqn}$을 분리하면 다음 행렬을 얻습니다.

$$
H(q)=\begin{pmatrix}
\Delta & t_1+t_2 e^{-iq}\\
t_1+t_2 e^{iq} & -\Delta
\end{pmatrix}.
$$

셀 사이 호핑은 이웃 셀을 연결하므로 위상 인자가 붙습니다. 비대각 성분이 서로 켤레이므로 에르미트 행렬입니다. $\Delta=0$이면 이 셀 규약에서 Su–Schrieffer–Heeger 모형의 벌크 해밀토니안이 됩니다. [Asbóth, Oroszlány, Pályi 강의록 1장](https://arxiv.org/abs/1509.02295)

## 3. 밴드의 끝과 간격 계산하기

대각합은 0이고 행렬식은 $-\Delta^2-|t_1+t_2e^{-iq}|^2$입니다. 두 고윳값은 다음과 같습니다.

$$
E_\pm(q)=\pm\sqrt{\Delta^2+(t_1-t_2)^2+4t_1t_2\cos^2(q/2)}.
$$

$q=0$에서는 두 호핑 항이 더해지고 $q=\pi$에서는 두 항의 차이가 남습니다. 두 호핑이 양수이면 위쪽 밴드의 최솟값과 아래쪽 밴드의 최댓값이 모두 영역 경계에 있습니다. 벌크 에너지 간격은 $E_g=2\sqrt{\Delta^2+(t_1-t_2)^2}$입니다. 호핑 하나가 0이면 두 밴드는 평평하고 어느 $q$에서나 같은 간격을 얻습니다.

$t_1=1$, $t_2=0.6$, $\Delta=0$이면 영역 중심 에너지는 $\pm1.6$, 경계 에너지는 $\pm0.4$입니다. 간격은 $0.8$입니다. $t_1=t_2=1$, $\Delta=0.4$로 바꾸면 간격은 같고 영역 중심 에너지는 달라집니다. 간격을 한 번 측정하면 호핑 차이와 자리 에너지 차이에 함께 제약을 줄 수 있습니다.

## 4. 밴드 접힘과 간격 열림 구분하기

$t_1=t_2=t$이고 $\Delta=0$이면 사슬을 $a/2$만큼 평행 이동해도 해밀토니안이 같습니다. 한 자리 셀의 분산은 $2t\cos(ka/2)$입니다. 두 자리 셀의 작은 브릴루앙 영역에 이 곡선을 옮겨 담으면 옮겨진 구간이 두 번째 가지를 이룹니다. 두 가지는 영역 경계에서 만납니다. 번갈아 달라지는 호핑이나 자리 에너지 차이는 반 셀 평행 이동 대칭을 깨고 간격을 엽니다.

축퇴점에서 떨어진 곳의 파동 묶음 군속도는 $v_\pm=(a/\hbar)dE_\pm/dq=\mp at_1t_2\sin(q)/(\hbar|E_\pm|)$입니다. 교차점에서 에너지 순서로 정렬한 가지는 주기 영역에서 꺾입니다. 그 지점에서는 부드럽게 이어지는 가지를 정한 뒤 기울기를 구합니다. 이 모형에서 아래쪽 띠가 차 있고 위쪽 띠가 비어 있으면 에너지 간격이 점유 상태와 비점유 상태를 가릅니다. 전자 수가 바뀌면 점유 여부도 다시 따져야 합니다.

## 5. 에르미트 고윳값 계산으로 검산하기

Python에서 NumPy로 브릴루앙 영역을 훑고 수치적으로 구한 간격을 닫힌 형태의 식과 비교합니다.

```python
import numpy as np

q = np.linspace(-np.pi, np.pi, 1001)

def bands(t1, t2, delta):
    coupling = t1 + t2 * np.exp(-1j * q)
    h = np.zeros((q.size, 2, 2), dtype=complex)
    h[:, 0, 0], h[:, 1, 1] = delta, -delta
    h[:, 0, 1], h[:, 1, 0] = coupling, coupling.conj()
    return np.linalg.eigvalsh(h)

for t1, t2, delta in [(1, .6, 0), (1, 1, .4), (1, 1, 0), (1, 0, .4)]:
    e = bands(t1, t2, delta)
    gap = e[:, 1].min() - e[:, 0].max()
    expected = 2 * np.hypot(delta, t1 - t2)
    assert np.isclose(gap, expected, atol=1e-12)
    assert np.allclose(e[:, 0], -e[:, 1])
    print(f"gap={gap:.3f}, center={e[q.size // 2, 1]:.3f}")

assert np.allclose(bands(1, .6, 0), bands(.6, 1, 0))
```

## 6. 역문제를 위한 관측 설계하기

어떤 매개변수 조합이 같은 분산을 줄 수 있는지 예측해 봅니다. 이 주기 모형에서 $t_1$과 $t_2$를 바꾸어도 모든 에너지가 같습니다. 고유상태가 A와 B 중 어느 자리에 분포하는지는 추가 정보를 줍니다. 예를 들어 영역 경계에서 위쪽 고윳값이 단순하면 A 성분의 가중치는 $(1+\Delta/\sqrt{\Delta^2+(t_1-t_2)^2})/2$입니다. 따라서 간격과 함께 자리별 가중치를 관측하면 제약을 늘릴 수 있습니다. 데이터로 모형을 추정할 때는 셀 규약, 관측 파수, 후보 해밀토니안을 구별할 관측량을 기록합니다.
