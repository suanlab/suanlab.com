## A computation is an ordered chain of maps

Function composition means applying the inner function first. A type-compatible chain can still be noninvertible, and reversing the notation does not reverse lost information. This unit connects the earlier set-based function definitions with concrete algebraic maps.

Let g(x)=ax+b, f(u)=u² and h=f∘g. The input and output spaces must be specified. Initially both maps use real inputs, and h outputs nonnegative values.

## Work both operation orders

At a=2,b=1,x=1, g(1)=3 and f(3)=9. Reversing the maps gives g(f(1))=g(1)=3. Therefore f∘g and g∘f are generally different.

Associativity is another statement: when domains match, (f∘g)∘k=f∘(g∘k). It permits regrouping, not reordering. An identity map changes no value, and a genuine inverse cancels a map only on its declared domain and codomain.

## Invert the affine stage first

If a≠0, the affine function is bijective from ℝ to ℝ and g⁻¹(u)=(u−b)/a. If a=0, it is constant and has no inverse on ℝ. Dividing by a without this condition would manufacture an invalid formula.

The numerical reconstruction g⁻¹(g(x)) is checked separately in the lab. It does not establish invertibility of the squared composition, which can lose sign information afterward.

## A preimage can contain two points

For a≠0 and y≥0, solving (ax+b)²=y gives

$$
x=\frac{\sqrt y-b}{a}\quad\text{or}\quad x=\frac{-\sqrt y-b}{a}.
$$

At the reference output y=9, the preimage is {−2,1}. This set exists even though h has no inverse function on all real inputs. At y=0 the two formulas coincide and there is one preimage. At y<0 there are no real preimages.

The lab’s y is generated by its probe, so it is always nonnegative. It reports the whole preimage, not a claim about arbitrary negative targets. If a=0, the displayed target is the constant b² and every real input produces it.

## Restrict a branch explicitly

Restrict the input domain so g(x)≥0. For a>0 this is x≥−b/a, while for a<0 the inequality reverses. On that branch the composition is one-to-one onto nonnegative outputs, with

$$
h_{\rm branch}^{-1}(y)=\frac{\sqrt y-b}{a}.
$$

The restriction is part of the inverse definition, not an implementation detail. For a=2,b=0 and probe x=−1, h(x)=4. The positive-branch inverse returns 1, not −1, because the original probe lies outside the chosen branch. No contradiction occurs.

An inverse statement must say which side is restricted. A rule returning one plausible input is a selection from preimages; it is not automatically a two-sided inverse of the original map.

## Inverses of a longer chain

For bijections f and g with compatible spaces, (f∘g)⁻¹=g⁻¹∘f⁻¹. One undoes the last operation first. If a stage is noninjective, a later deterministic operation cannot generally restore the missing input distinction without additional assumptions or information.

This is why reversible architectures, normalization maps and data encodings need explicit domain analysis. A low reconstruction error on a finite sample is weaker than a mathematical bijection over a full input space.

## Read the experiment

The plot shows h only; all operation-order comparisons and inverse candidates are numerical. A branch indicator is one when the current probe satisfies g(x)≥0 and zero otherwise. The preimage count is distinct from the number of outputs: a function still has exactly one output per input.

Change a to a negative number and solve the branch inequality by hand. Then use a=0 and compare the valid constant forward value with undefined inverse expressions. Floating-point roundoff can affect tiny reconstruction residuals near zero; it does not justify changing domains.
