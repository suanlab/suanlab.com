## 델타의 높이를 묻는 대신 작용을 묻기

분포 T는 시험 함수 공간 C_c^∞의 원소를 숫자로 보내는 연속 선형 범함수입니다. 이 공간의 수렴은 단순한 점별 수렴이 아닙니다. 지지집합이 공통 compact 집합 안에 있고 모든 차수 도함수가 균등 수렴하는 시험 함수열을 사용합니다. Dirac 델타는 δₐ[φ]=φ(a)로 정의됩니다.

$$
\delta_a[\varphi]=\varphi(a),\qquad T_f[\varphi]=\int f\varphi.
$$

국소 적분 가능한 f는 오른쪽 식으로 분포를 만들지만 모든 분포가 보통 함수로 표현되는 것은 아닙니다. 델타를 “원점에서 무한대인 함수”로 정의하면 적분과 도함수의 의미를 잃기 쉽습니다.

## 단위 면적 삼각형으로 근사하기

실습은 중심 a, 폭 ε의 삼각형 ηε(x)=ε⁻¹ max(1−|x−a|/ε,0)을 씁니다. 지지 길이는 2ε, 높이는 1/ε, 면적은 1입니다. φ가 연속이면 ∫ηεφ→φ(a)입니다. ε=.5에서 높이 2, ε=.1에서 10이지만 면적은 같습니다.

$$
\int\eta_\varepsilon(x)\varphi(x)\,dx\longrightarrow\delta_a[\varphi].
$$

화면의 시험 함수는 [−2,2]에서 xᵈ와 같고 바깥에서 매끄럽게 0이 되는 compact 지지 연장입니다. 삼각형의 지지가 이 구간 안이라 그림 밖의 연장 부분은 적분에 영향을 주지 않습니다. 다항식 자체를 compact 지지 시험 함수라고 부르지는 않습니다.

## 작용의 정확한 수치

삼각 분포의 중심 분산은 ε²/6입니다. 따라서 이차 시험 함수의 근사 작용은 a²+ε²/6입니다. a=.5, ε=.5이면 델타 작용 .25, 근사 7/24≈.29167, 오차 1/24입니다. ε=.1에서는 오차가 1/600으로 줄어듭니다. 파랑은 밀도, 주황은 시험 함수의 국소 부분이며 같은 종류의 함수값을 비교하는 오차 곡선은 아닙니다.

## 분포 도함수의 부호

도함수는 시험 함수로 미분을 옮기고 음의 부호를 붙여 정의합니다. 이로써 델타처럼 보통 함수가 아닌 대상도 미분할 수 있습니다.

$$
T'[\varphi]=-T[\varphi'],\qquad \delta'_a[\varphi]=-\varphi'(a).
$$

φ=x이면 작용은 −1입니다. φ=x²이면 −2a이고 삼각 근사 도함수도 같은 값을 줍니다. φ=x³이면 델타 도함수는 −3a², 삼각 근사는 −3a²−ε²/2입니다. 약한 PDE, 점 하중, Green 함수에서 부호를 실수하면 물리적 보존이나 잔차 해석도 바뀝니다.

## 점프와 모서리는 같은 미분이 아니다

Heaviside H(x)=1{x>0}는 원점 밖에서 고전 도함수가 0이지만, 시험 함수로 부분적분하면 H′[φ]=−∫₀∞φ′=φ(0)입니다. 따라서 H′=δ₀입니다. 반면 |x|는 원점에서 연속이어서 양쪽 경계항이 상쇄되고 일차 도함수는 sign(x)입니다. Sign의 jump가 2이므로

$$
H'=\delta_0,\qquad (|x|)'=\operatorname{sign}(x),
\qquad (|x|)''=2\delta_0.
$$

이 사실로 |x|는 원점을 내부에 포함하는 유계 구간에서 H¹이지만 H²는 아닙니다. 계단은 점 밖의 도함수 0만 사용하면 jump를 잃습니다. 물리의 점 하중과 약한 PDE에서 바로 이 항이 중요합니다. −|x|/2는 실수 직선에서 −d²/dx²에 대한 분포 Green 함수이지만, 경계조건을 갖춘 다른 영역의 Green 함수와 자동으로 같지는 않습니다.

## 델타가 L¹_loc 함수가 아닌 이유

0에서 1이고 지지가 [−h,h]에 든 매끄러운 φ_h, 0≤φ_h≤1을 택합니다. 만약 δ₀=T_f이고 f가 국소 적분 가능하다면 |T_f[φ_h]|≤∫₋ₕʰ|f|→0입니다. 그런데 δ₀[φ_h]=1이라 모순입니다. 단지 높이를 아주 크게 정한 보통 함수로 정확한 델타를 대신할 수 없습니다.

연속성의 위상도 확인할 수 있습니다. 고정 compact 지지 위에서 |δ₀[φ]|≤sup|φ|, |δ₀′[φ]|≤sup|φ′|입니다. 시험 함수 공간의 도함수 seminorm이 이러한 분포의 연속성을 제어합니다.

## 실제 매끄러운 bump로 부호와 근사를 검산하기

φ(x)=exp(−1/(1−x²))를 |x|<1에서, 바깥에서는 0으로 두면 C_c^∞ 시험 함수입니다. 코드가 −∫Hφ′=φ(0), ∫|x|φ″=2φ(0)를 수치 부분적분으로 대조합니다. 삼각 근사도 이 bump에 작용시켜 실제 델타 작용 e⁻¹과 비교합니다.

| ε | 삼각 작용 | 델타와의 절대 차이 |
|---|---|---|
| .5 | .351752949 | .016126492 |
| .25 | .363998934 | .003880507 |
| .125 | .366918420 | .000961022 |

대칭 삼각형의 첫 중심 모멘트는 0이고 두 번째는 ε²/6입니다. Taylor의 적분 나머지 또는 이차 나머지 경계로 |∫ηεφ−φ(0)|≤(sup|φ″|)ε²/12를 얻습니다. 수치 적분 표는 검산이며 모든 시험 함수의 수렴 증명은 이 모멘트 경계로 따로 제공합니다.

**직접 풀기:** |x|의 두 번째 a.e. 고전 도함수 0을 그대로 약도함수라고 해도 되나요? **해설:** 아닙니다. Sign의 jump가 2δ₀를 만들며 이 항은 점 밖 값만으로는 보이지 않습니다.

```python
from math import exp

def bump(x):
    if abs(x)>=1:return 0
    return exp(-1/(1-x*x))
def prime(x):
    if abs(x)>=1:return 0
    return -2*x/(1-x*x)**2*bump(x)
def second(x):
    if abs(x)>=1:return 0
    d=1-x*x
    return bump(x)*(4*x*x/d**4-2/d**2-8*x*x/d**3)
def simpson(f,lo,hi,n=2000):
    step=(hi-lo)/n
    return step/3*sum((1 if i in [0,n] else 4 if i%2 else 2)*f(lo+i*step)
                      for i in range(n+1))

assert abs(-simpson(prime,0,1)-bump(0))<1e-10
assert abs(2*simpson(lambda x:x*second(x),0,1)-2*bump(0))<1e-10
for width in [.5,.25,.125]:
    action=2*simpson(lambda x:(1-x/width)/width*bump(x),0,width)
    print('width, triangle action, error vs delta:',width,
          round(action,9),round(abs(action-bump(0)),9))
```


## 확인 문제와 해설

1. ε를 반으로 줄이면 이차 작용 오차는? **1/4이 됩니다.** 분산이 ε²에 비례합니다.
2. 높이가 커진다고 질량도 커지나요? **아니요.** 폭이 함께 줄어 면적 1을 유지합니다.
3. 한 시험 함수에서 작용이 같으면 분포도 같나요? **아니요.** 모든 시험 함수에서 같아야 합니다. 유한 실험은 일반 분포 수렴의 증명이 아닙니다.
