# [논문 리뷰] LLM 기반 다중 에이전트 시스템의 마음 이론과 내부 믿음 평가

## TL;DR
대규모 언어 모델(LLM) 기반 다중 에이전트 시스템(MAS)의 협력적 문제 해결 능력을 향상시키기 위해, 본 연구는 **마음 이론(Theory of Mind, ToM)**과 **내부 믿음(Internal Beliefs)**을 통합한 새로운 아키텍처를 제안합니다. LLM의 유연한 추론 능력과 상징적 논리의 엄격함을 결합한 이 하이브리드 접근법은 에이전트 간의 의도 파악과 논리적 일관성을 높여, 자원 할당 문제에서 기존 방식보다 뛰어난 성능을 보였습니다. 이 연구는 더 신뢰성 있고 예측 가능한 협력 AI를 개발하는 데 중요한 방향을 제시합니다.

## 연구 배경 및 동기
다중 에이전트 시스템(Multi-Agent System, MAS)은 여러 에이전트가 상호작용하며 공동의 목표를 달성하는 시스템입니다. 최근 LLM의 비약적인 발전으로, LLM을 각 에이전트의 '두뇌'로 사용하는 연구가 활발히 진행되고 있습니다. 기존의 규칙 기반 MAS는 정적인 환경에서는 효과적이었지만, 예측 불가능한 상황에 대한 유연성과 적응력이 부족했습니다.

LLM은 이러한 한계를 극복할 잠재력을 지니고 있지만, 새로운 문제를 야기합니다. LLM은 '환각(Hallucination)' 현상으로 인해 논리적으로 일관되지 않은 결정을 내리거나, 다른 에이전트의 의도나 상태를 정확히 파악하지 못해 비효율적인 협력을 초래할 수 있습니다. 단순히 여러 LLM 에이전트를 한 공간에 모아놓는 것만으로는 진정한 의미의 협력 지능을 구현하기 어렵습니다.

본 연구는 이러한 문제에 대한 해결책으로, 인간의 사회적 상호작용 능력을 모방하는 **마음 이론(ToM)**과, 에이전트의 지식을 체계적으로 관리하는 **내부 믿음(Internal Beliefs)** 체계를 LLM 기반 MAS에 도입하고자 합니다.

## 관련 연구
MAS와 LLM의 융합은 AI 연구의 최전선에 있습니다. 초기 연구들은 LLM의 강력한 자연어 처리 및 추론 능력을 활용하여 개별 에이전트의 성능을 높이는 데 집중했습니다.

| 연구 | 주요 내용 | 본 논문과의 차별점 |
| :--- | :--- | :--- |
| [1] Generative Agents (Park et al., 2023) | LLM 에이전트가 인간 행동을 모방하는 가상 사회 시뮬레이션 | 개별 에이전트의 행동 생성에 집중 |
| [2] CAMEL (Li et al., 2023) | 역할극을 통해 LLM 에이전트 간의 협력적 작업 수행 유도 | 명시적인 ToM이나 내부 믿음 모델 없이 프롬프팅에 의존 |
| [3] ChatDev (Qian et al., 2023) | 여러 LLM 에이전트가 특정 역할을 맡아 소프트웨어를 개발하는 프레임워크 | 협력적 지능 자체보다는 역할 기반의 작업 분배에 초점 |

위 연구들이 LLM 기반 MAS의 가능성을 열었다면, 본 논문은 한 걸음 더 나아가 에이전트가 서로를 더 깊이 이해하고, 논리적으로 일관된 행동을 하도록 만드는 **내부 인지 아키텍처**에 집중하여 기존 연구들과 차별화됩니다.

## 핵심 기여
1.  **ToM과 내부 믿음의 통합**: 에이전트가 다른 에이전트의 상태를 추론(ToM)하고, 자신의 지식을 논리적으로 관리(내부 믿음)하도록 하여 협력의 질을 높였습니다.
2.  **하이브리드 아키텍처 제안**: LLM의 유연한 생성 능력과 상징적 논리 솔버의 검증 능력을 결합한 새로운 MAS 아키텍처를 제안합니다.
3.  **다양한 LLM에서의 성능 검증**: GPT-3.5-Turbo, GPT-4, GPT-4o 등 여러 LLM을 대상으로 제안 아키텍처의 효과를 실증적으로 분석했습니다.
4.  **신뢰성 있는 협력 AI 방향 제시**: AI 에이전트가 더 예측 가능하고 신뢰성 있게 상호작용하는 시스템을 구축하기 위한 구체적인 방법론을 제시합니다.

## 제안 방법론
본 연구는 LLM 기반 에이전트에 ToM, 내부 믿음, 논리 검증 모듈을 통합한 인지 아키텍처를 제안합니다. 이 아키텍처는 에이전트의 의사결정 과정을 다음과 같이 구조화합니다.


*(설명을 위한 가상 다이어그램)*

### 모델 아키텍처
1.  **마음 이론 (Theory of Mind, ToM)**: 다른 에이전트의 정신적 상태(믿음, 목표, 의도)를 추론하는 능력입니다. LLM은 관찰된 다른 에이전트의 행동과 발언을 바탕으로 "에이전트 B는 현재 '물' 자원이 부족하여 어려움을 겪고 있을 것이다"와 같은 가설을 생성합니다. 이는 보다 인간과 유사한, 이타적이거나 전략적인 협력 행동의 기반이 됩니다.

2.  **내부 믿음 (Internal Beliefs)**: 에이전트가 관찰한 사실과 ToM을 통해 추론한 내용을 명제 논리 형식으로 저장하고 관리하는 지식 베이스입니다. 이는 고전적인 BDI(Belief-Desire-Intention) 모델에서 영감을 받았습니다. 예를 들어, `has(agent_A, food, 10)`나 `believes(agent_A, needs(agent_B, water))`와 같은 형식으로 지식을 저장합니다. 이를 통해 LLM의 context window에만 의존할 때 발생하는 정보의 소실이나 불일치 문제를 방지합니다.

3.  **논리 검증 (Logical Verification)**: LLM이 생성한 행동 계획이 내부 믿음과 충돌하지 않는지 검증하는 단계입니다. 본 연구에서는 **답 집합 프로그래밍(Answer Set Programming, ASP)**이라는 상징적 논리 솔버를 사용합니다. 예를 들어, LLM이 "모든 식량을 에이전트 B에게 준다"는 계획을 세웠을 때, ASP는 "자신이 생존에 필요한 최소한의 식량은 보유해야 한다"는 내부 믿음(규칙)과 이 계획이 충돌함을 감지하고 계획을 수정하도록 요구합니다. 이는 LLM의 창의성을 존중하되, 치명적인 논리적 오류를 방지하는 '안전장치' 역할을 합니다.

### 아키텍처 작동 예시
> 두 에이전트 A, B가 있고, 유일한 '에너지' 자원을 공유해야 하는 상황을 가정해 봅시다.
> 1.  **관찰**: 에이전트 A는 "에이전트 B의 이동 속도가 현저히 느려졌다"는 사실을 관찰합니다.
> 2.  **ToM 추론**: A의 LLM은 이 관찰을 바탕으로 "B의 에너지가 고갈되고 있을 가능성이 높다"고 추론합니다.
> 3.  **내부 믿음 업데이트**: A는 자신의 내부 믿음에 `believes(A, low_energy(B))`라는 사실을 추가합니다.
> 4.  **계획 생성**: A의 LLM은 "에너지를 B에게 양보하자"는 협력적 계획을 생성합니다.
> 5.  **논리 검증**: A는 이 계획이 자신의 핵심 목표(예: `mission_critical(self, task_X)`)와 충돌하지 않는지 ASP로 검증합니다. 만약 자신의 에너지 잔량이 임무 수행에 필수적이라면, 계획은 "에너지의 50%만 B에게 공유한다"로 수정될 수 있습니다.

### 핵심 수식
실험 환경에서 에이전트의 상태를 모델링하는 데 사용된 수식은 다음과 같습니다.

1.  **자원 업데이트**: 시간 $t$에 구역 $d$의 자원 $r$의 양($R(d, r, t)$)은 시간 단위당 소비량 $C$만큼 감소합니다.
    $$ R(d, r, t + 1) = \max(0, R(d, r, t) - C) $$

2.  **건강 상태 업데이트**: 시간 $t$에 구역 $d$의 에이전트 건강 상태($H(d, t)$)는 해당 구역의 자원 수준이 임계치 $R_{min}$ 이하로 떨어지면 감소합니다.
    $$ H(d, t + 1) = H(d, t) - \delta \quad \text{if} \ R(d, r, t) < R_{min} $$
    여기서 $\delta$는 건강 감소량입니다.

3.  **계획 검증**: 에이전트의 계획($P$)이 내부 믿음($B$)과 논리적으로 일관되는지 확인합니다. ASP 솔버는 $P$와 $B$를 결합한 논리 프로그램의 '답 집합(Answer Set)'이 존재하는지 확인하여 일관성을 검증합니다.
    $$ \text{IsValid}(P, B) \iff \text{AnswerSet}(P \cup B) \neq \emptyset $$

## 실험 설정
제안된 아키텍처의 유효성을 검증하기 위해, 여러 에이전트가 제한된 자원을 수집하고 분배하여 생존해야 하는 시뮬레이션 환경을 구축했습니다.

-   **작업**: 다중 에이전트 자원 할당 및 생존 문제
-   **평가 지표**: 시스템 정확도 (전체 에이전트가 생존하고 임무를 완수하는 시뮬레이션의 비율)
-   **베이스라인**: ToM과 내부 믿음(IB) 없이, 순수 LLM 프롬프팅에만 의존하는 에이전트
-   **실험 구성**:
    1.  **기본(Vanilla LLM)**: 베이스라인
    2.  **ToM만**: ToM 모듈만 추가
    3.  **IB만**: 내부 믿음과 논리 검증 모듈만 추가
    4.  **ToM + IB**: 제안된 전체 아키텍처

## 실험 결과 분석
실험은 네 가지 아키텍처 구성과 세 가지 LLM(GPT-3.5-Turbo, GPT-4, GPT-4o)을 사용하여 진행되었습니다.

### 주요 결과 (시스템 정확도)

| 구성 | ChatGPT-3.5-Turbo | ChatGPT-4 | ChatGPT-4o | 평균 |
| :--- | :---: | :---: | :---: | :---: |
| 기본 (Vanilla) | 65% | 70% | 75% | 70.0% |
| ToM만 | 68% (+3) | 72% (+2) | 74% (-1) | 71.3% |
| IB만 | 67% (+2) | 73% (+3) | 76% (+1) | 72.0% |
| **ToM + IB (제안)** | **70% (+5)** | **75% (+5)** | **74% (-1)** | **73.0%** |

### 결과 해석
-   **LLM 모델 성능**: 예상대로 최신 모델인 GPT-4o가 기본 구성에서 가장 높은 성능을 보였습니다. 이는 모델 자체의 추론 및 계획 능력이 향상되었음을 시사합니다.
-   **ToM과 IB의 효과**: GPT-3.5-Turbo와 GPT-4에서는 ToM과 IB를 함께 사용했을 때 **가장 큰 성능 향상(+5%p)**을 보였습니다. 이는 제안된 아키텍처가 LLM의 부족한 논리적 일관성과 사회적 추론 능력을 효과적으로 보완했음을 의미합니다.
-   **GPT-4o의 예외적 결과**: 흥미롭게도, 가장 뛰어난 모델인 GPT-4o에서는 ToM+IB 구성이 오히려 미미한 성능 하락을 보였습니다. 이에 대한 가설은 다음과 같습니다.
    1.  **과도한 제약**: GPT-4o는 이미 내재적으로 상당 수준의 ToM과 논리적 추론 능력을 갖추고 있어, 외부에서 명시적으로 추가된 모듈이 오히려 유연한 사고를 방해하는 '과도한 제약'으로 작용했을 수 있습니다.
    2.  **통합 방식의 한계**: 현재의 통합 방식이 GPT-4o의 정교한 내부 작동 방식과 최적으로 맞물리지 않았을 가능성이 있습니다.

## 비판적 평가
### 강점
1.  **혁신적인 하이브리드 접근**: LLM의 창의성과 상징적 AI의 신뢰성을 결합하여, 두 접근 방식의 장점을 모두 취했습니다.
2.  **명확한 문제 해결**: LLM 기반 에이전트의 '환각'과 '비협조적 행동'이라는 구체적인 문제를 해결하기 위한 실용적인 아키텍처를 제시했습니다.
3.  **심층적인 모델 분석**: 여러 세대의 LLM을 비교하며 제안 방법론의 효과가 모델의 발전에 따라 어떻게 변하는지 분석하여 중요한 통찰을 제공했습니다.

### 한계점 및 개선 방향
1.  **계산 복잡성**: 내부 믿음을 관리하고 매번 논리 검증을 수행하는 것은 상당한 계산 비용을 유발하며, 실시간 시스템에 적용하기에는 확장성 문제가 있을 수 있습니다.
2.  **GPT-4o 성능 저하**: 가장 진보된 모델에서 성능이 저하된 원인에 대한 추가적인 분석이 필요합니다. 이는 향후 LLM과 외부 모듈의 통합 방식에 대한 중요한 연구 주제가 될 것입니다.
3.  **정적인 논리 규칙**: 현재 논리 검증 규칙이 사전에 정의되어 있어, 에이전트가 경험을 통해 새로운 규칙을 학습하거나 수정하는 동적인 능력은 부족합니다.

## 향후 연구 방향
1.  **적응형 아키텍처**: LLM의 능력에 따라 ToM이나 IB 모듈의 개입 강도를 동적으로 조절하는 아키텍처를 연구하여, GPT-4o와 같은 고성능 모델과의 시너지를 극대화할 수 있습니다.
2.  **LLM과 상징적 추론의 심층 통합**: LLM이 ASP와 같은 논리 언어를 직접 생성하거나, 논리 검증 실패 시 그 원인을 이해하고 스스로 계획을 수정하도록 학습시키는 연구가 필요합니다.
3.  **복잡한 문제 영역으로의 확장**: 자원 할당을 넘어, 과학적 발견, 외교 협상, 소프트웨어 개발과 같이 더 개방적이고 복잡한 사회적 상호작용이 필요한 문제에 제안 아키텍처를 적용하고 검증할 필요가 있습니다.

## 실무 적용 가이드
-   **구현 시 고려사항**: 시스템의 요구사항에 따라 LLM과 논리 검증 모듈 간의 균형을 맞추는 것이 중요합니다. 모든 결정에 논리 검증을 적용하기보다는, 치명적인 오류가 발생할 수 있는 중요한 결정에만 선택적으로 적용하여 효율성을 높일 수 있습니다.
-   **팁**: 상징적 논리 솔버로는 Clingo와 같은 고성능 ASP 솔버 사용을 권장합니다. 또한, 내부 믿음의 구조를 문제 도메인에 맞게 잘 설계하는 것이 전체 시스템 성능에 큰 영향을 미칩니다.

## 결론
본 연구는 LLM 기반 다중 에이전트 시스템에 마음 이론(ToM)과 논리적으로 검증된 내부 믿음(IB)을 통합하는 것이 협력적 지능을 한 단계 발전시킬 수 있는 강력한 접근법임을 입증했습니다. 특히, LLM의 창의적 추론과 상징적 솔버의 논리적 견고함을 결합한 하이브리드 방식은 환각을 줄이고 예측 가능성을 높여, 더욱 신뢰할 수 있는 AI 에이전트를 만드는 데 핵심적인 역할을 할 것입니다. GPT-4o에서 나타난 예외적인 결과는 미래 LLM의 발전 방향과 외부 모듈 통합 방식에 대한 중요한 화두를 던져주며, 이 분야의 지속적인 연구 필요성을 강조합니다.
