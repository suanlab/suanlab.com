# Duffing 세속항·장시간 위상: 독립 응답 검증과 Worker

2026-11-10. `duffing-secular-frequency-long-time`에 독립 전체 응답 검증·계산/검증 Worker·React hook을 연결했다. 아직 실제 교재에 미등록이며 교수 화면·reader·생산 Next.js 자산 검증은 후속이다.

## 검증 경로와 범위

같은 AGM/nome 해석식을 별도 산술로 재구성한다. 생산 모델·공유 양자 유리수 코어·생산 지수/삼각함수/π 코드를 검증기에서 가져오지 않는다. 별도 유리수와 복원형 이진 제곱근, 다른 arctan 원주율 항등식, 음수 교대 Taylor 지수와 추가 guard 비트의 삼각함수를 사용한다. 조화파는 생산 모델의 Chebyshev 재귀 대신 복소 회전으로 전진하고, 잔차는 (1−z²)P″−zP′ 연산자로 구한다.

이 단계는 다른 물리 방정식으로 검증하는 것이 아니다. 같은 해석해의 독립 산술 재구성이며, 이전 단계의 직접200자리 cn/sn/dn 참조33입력과 함께 평가한다. 모든 응답 필드·표본·오차·정규화/물리 잔차·주파수 유효성·위상/aliasing 설명·원시 입력 표기를 비교한다.

산술 피연산자는 소유한 원래 입력에서만 읽는다. 외부 응답의 분수 문자열을 수학적으로 해석하지 않고 기대 문자열과 비교한다. 제한된16입력 캐시는 신뢰한 입력으로 독립 재구성한 값만 저장한다. 기본 응답의 개별1570항목을 변조해 모두 거부했다.

## 전송과 React 연결

각 실행은 계산 Worker와 검증 Worker를 소유한다. 요청번호·원시 입력·전체 검산이 일치한 응답만 ready로 공개한다. 큰 응답 복사는 작은 작업으로 나눠 취소 가능하게 하고, 입력 변경·비활성화·숨김·해제에서 이전 결과를 숨기고 작업을 종료한다. 계산/검증 양쪽의 오류·메시지/복사 제한·시간 제한과 재시도를 처리한다.
