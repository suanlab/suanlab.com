# 유한 장의 측도와 열 자유에너지: 시각화·실험·해설

2026-11-11. [생산 계산·독립 Worker 검산](thermal-field-producer-verification.md) 다음 단계다. `finite-field-measure-and-thermal-free-energy`의 한영 실험 화면을 작성했다. 등록 전의 격리 React 화면을 확인한 결과이며, 실제 교재 reader와 Next 생산 자산 검증은 아직 남는다.

## 학습 내용과 시각화

한영 개념 6단계는 최솟값/적분 부피, 평균 영 평면의 유도 거리, 유효 에너지/U, 두 엔트로피, 기준 측도/좌표 변환, 실수 Fourier 모드 수를 설명한다. SVG는 **고정된 설명 기준**으로 명시한다. 현재 적용한 입력의 검산 결과와 혼동하지 않도록 제목·본문·그림 설명에 구분을 넣었다.

실제 계산 화면에는 14예제, 공간·경계·제약·온도·기준 척도, r·κ·배경·위치별 원천의 값/1차/2차 미분 입력이 있다. 적용하지 않은 편집과 현재 결과를 구별하고, 결과에서 적용한 계수·미분도 다시 확인할 수 있다. 오류 입력은 이전 결과를 유지하며 실패 이유를 알린다. 정규화 불가능 분기는 유한한 Z·공분산을 만들어 표시하지 않는다.

평균의 물리 격자, 공분산·응답·정밀도의 행렬 탐색, 선택 성분의 정확한 값, Three.js 이산 행렬 막대를 연결한다. 두 행렬 첨자는 실제 공간의 x/y축과 다르다. 색·높이의 상대 척도와 부호 보존 로그 변환도 설명한다. 매우 큰 분수는 큰 분자/분모를 각각 Number로 바꾸지 않고 표시를 투영한다. 표현 불가능한 비영 값을 영으로 숨기지 않고 정확한 값을 남긴다. 포함 구간의 소수 요약과 정확한 양끝점은 별개로 제공한다.

안내 실험 6개는 먼저 예측한 뒤 예제를 비교하고 해설을 여는 방식이다. 배경만 바꾼 확률 법칙, 일관된 단위 변환, 영모드/음의 방향, 고정 snapshot에서 미분만 바꾸기, 작은 determinant를 포함한다. 해설 문제 8개는 오답과 정답 모두 피드백을 제공한다.

## 확인한 동작

실제 계산·독립 검산 module Worker를 연결한 React 미리보기를 한영×명암×320/1440px **8상태**에서 확인했다. 각 상태의 6개념·6안내·14예제와 8문제의 정오답을 조작했다. 행렬의 화살표 이동·행렬과 척도 변경·성분 재생·Three.js 회전/초기화도 확인했다. 선택·재생·보기 변경은 계산 Worker를 새로 만들지 않는다.

잘못된 지수 표기 온도를 거부하고, 올바른 온도 수정과 r의 1차 미분 수정을 적용했다. 미분만 바꾸면 같은 snapshot의 평균은 그대로이고 U는 바뀌는 것을 화면에서 비교했다. 각 상태가 끝날 때 생성한 Worker가 모두 한 번씩 종료되어야 통과한다.

8상태에서 영어 한글 혼입·문서 가로 넘침·pageerror가 없고 axe 위반이0이다. 처음 발견한 선택 행렬 셀의 글자 대비를 수정한 뒤 다시 검사했다. 별도 모션 감소 상태에서는 자동 재생이 비활성이고 개념 전환 animation이 꺼진다. WebGL을 사용할 수 없는 경우에는 열지도·정확한 값과 재시도 안내가 유지된다. 대표 영어 3D와 한영 모바일 개념 screenshot도 직접 확인했다.

새 projection/draft/교육 비교 4검사는 Node20/24에서 통과했다. TypeScript와 ESLint도 통과했다. 기존 Gaussian 3D renderer의 props type만 필요한 필드로 넓혔으며, `b9b54ee` 대비 두 공유 파일의 **방출 JavaScript가 동일**함을 대조했다. 기존 등록 콘텐츠와 수치 엔진은 수정하지 않았다.
