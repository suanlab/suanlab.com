# 확산 연구 보강: 엔트로피 생성과 지속적인 공간 오차

2026-11-13 설계. 기존 열·물질 확산 두 단원의 한영 전체 원고와 통합 기록을 읽었다. 주기 열 모드·현열/노름·Gaussian 질량/모멘트·유한 창·꼬리·산술 가용성의 기존 내용을 보존한다. 이미 존재한 입문 내용을 미집필로 다시 세지 않는다.

## 열: 같은 에너지에서 달라지는 엔트로피

`fourier-heat-diffusion-mode-budget`: 같은 양의 온도·유효 상수 열용량 모델에 국소 평형과 ds = C dT/T 상태 관계를 명시적으로 추가한다. 열방정식 하나로 전체 열역학이 주어진다고 주장하지 않는다. 엔트로피 플럭스 q/T와 생성률 kappa T_x²/T²를 유도하고 주기 전체와 작은 관측 창을 구분한다.

로그의 오목성으로 고정 평균의 균일 상태가 엔트로피를 최대화함을 설명한다. 코사인 인수분해와 수렴 Fourier 급수로 정확한 주기 로그 적분을 구한다. 현열 보존·엔트로피 증가·평형 상대 가용성 감소를 단위와 함께 비교한다. 가용성은 정의한 함수이며 실제 기관의 추출 일을 계산하지 않는다. 기존 이차 노름과의 관계는 작은 대비의 선도 근사다. 실습 범위 |a(0)| <= 0.2와 기존 제어를 유지한다.

## Gaussian: 형상 비교와 물리적 오차의 차이

`gaussian-fick-diffusion-spreading`: 같은 일정 이류·확산을 따르는 양의 질량 구름 두 개를 각자 정규화한다. 움직이는 기준의 KL 소산을 두 PDE의 부분 적분으로 유도하고 Gaussian 상대 Fisher 정보를 모멘트로 검산한다. 다른 계수나 고정 목표에 같은 식을 적용하지 않는다.

최적 제곱 수송 비용은 공분산 하한과 같은 표준정규 변수 결합으로 증명한다. 같은 분산의 두 구름은 KL이 영으로 가도 중심 차이와 제곱 수송 비용이 남는다. 같은 형상·다른 질량의 KL 영 대조와 질량 영의 정의 불가를 구분한다. 정규화 정보 발산을 열역학적 엔트로피로 바꾸어 부르거나 기존 실습에 둘째 구름 제어를 추가한 것으로 소개하지 않는다.

## 검증과 후속 범위

한영 4원고·4그림, 40표시 수식·4실행 표·12연구 해설을 대조한다. 연구 절 제거로 원래 4본문과 24해설을 복원한다. 독립 표준 라이브러리의 실제 온도 적분/차분·Gaussian 로그/score 구적·정확 유리수 모멘트/수송 비용/질량 대조를 확인한다. 소스·출력을 고정하고 새 빌드와 한영 16화면·안내·퀴즈·저장/완료를 확인한 뒤 순차 집계에 반영한다.

설계 당시 연구 완료는 8/22단원이었으며, 위 설계의 원고·그림과 최종 검증을 마쳐 현재는 10/22단원이다. [검증 진행](continuum-diffusion-research-status.md)을 별도로 기록하며 영역 전체 감사 이전에는 전체 42영역·415주제 대조/9영역·94주제 후속을 유지한다.
