# Boltzmann·Gibbs 분포 주제의 다음 작성 계약

2026-11-07. 이 문서는 제작에 적용한 계약이다. 세 가족의 모델·한영 원고·교수 컴포넌트를 구현하고 [실제 읽기 통합 검증](boltzmann-gibbs-integration-verification.md)을 마쳤다. 로컬521단원·1563안내이며 다음은 상전이·질서변수다. 아래의 제작·검증 순서는 당시의 계약이며, 전체 교육과정과 연구 심화는 계속 진행 중이다.

## 범위와 참고

분포의 에너지·기준 측도·지지집합을 명시하고, 정적 평형 법칙과 그 법칙을 표본추출하는 알고리즘을 구별한다. 정준 가중치의 출발점은 [Tong의 canonical ensemble](https://www.damtp.cam.ac.uk/user/tong/statphys/statmechhtml/S1.html#S1.S3)이다. Gibbs의 조건부 갱신·random/systematic/block 구분은 [Stanford의 Gibbs sampling 설명](https://ermongroup.github.io/cs323-notes/probabilistic/gibbs/)을 참고한다. Gaussian의 precision은 역공분산이라는 정의를 [Taboga의 설명](https://www.statlect.com/glossary/precision-matrix)과 대조한다. 아래 예제·수치 경계·검증 계약은 이 교재를 위한 별도 유도다.

## 1. 기준 측도·Boltzmann 가중치·softmax 식별 가능성

예정 ID: `reference-measure-boltzmann-softmax-identifiability`.

기준 가중치 m_i를 명시한 `p_i=m_i exp(−βE_i)/Z_m`에서 출발한다. m_i=0은 지지집합에서 제외하고, 양의 실수 기준 가중치와 정수 미시상태 다중도를 구별한다. 여러 상태를 한 준위로 묶은 확률과 미시상태 하나의 확률을 같은 값으로 해석하지 않는다.

- 이상적 `βε=ln2`, 준위 `(0,ε,2ε)`, 다중도 `(1,2,1)`이면 `Z=9/4`, 준위 확률 `(4,4,1)/9`다. 같은 에너지에 다중도 `(1,1,1)`인 이전 세 준위 준비와는 다른 법칙이다. 명시적 네 미시상태 `(0,ε,ε,2ε)`의 주변화와 비교한다.
- 같은 기준 가중치를 모두 λ배 하면 p는 같고 Z는 λ배다. 정규화 사전 `(1/4,1/2,1/4)`이면 같은 p에도 `Zprior=9/16`이다. 물리적 상태 계수와 사전 상대 엔트로피를 혼동하지 않는다. 다중도 기준의 엔트로피는 `H(level)+E[ln g]`이며, 정규화 사전 기준의 상대 엔트로피는 `−KL(p||prior)`다.
- 고정 m에서 공통 에너지 이동과 `(E,T)→(λE,λT)`의 확률 불변성을 확인한다. 관측된 p만으로 절대 에너지 기준과 온도·에너지 척도를 모두 식별할 수 있다고 주장하지 않는다.
- AI logit s와 무차원 softmax 온도 α는 `p∝m exp(s/α)`다. 물리적 kelvin 온도와 연결하려면 별도 에너지 척도를 지정해야 한다. `Eeff=E−kBT ln m`에 기준 가중치를 흡수한 뒤 온도 의존성을 무시하고 고정 Hamiltonian 공식을 적용하지 않는다.

유한 양수의 범위 초과·m=0의 실제 금지·퇴화·공통 기준·극저온 로그를 포함한다. 실제 이진 입력 oracle과 이상적 로그2 항등식을 분리한다.

## 2. 조건부 Gibbs 갱신과 지원 제약

예정 ID: `finite-gibbs-conditionals-scan-support`.

이름 붙은 두 스핀의 전체 곱 공간에서 `E=−Jσ1σ2−h1σ1−h2σ2`를 직접 열거한다. 양의 유한 온도에서 `P(σ1=+1|σ2=s)=logistic(2β(Js+h1))`이며 둘째 자리도 같다. 실제 조건화 확률이0인 사건에는 임의 조건부분포를 만들지 않는다.

- 4×4 단일 자리 kernel K1,K2를 정확한 조건화에서 구성한다. row-stochastic 관례로 한 번의 systematic sweep는 K1K2다. `πKi=π`이므로 곱도 π를 보존한다. random scan `(K1+K2)/2`는 각 kernel의 상세평형을 보존하지만 systematic scan은 일반적으로 가역적이지 않다.
- 이상적 βJ=ln2,h1=h2=0에서 π=(2/5,1/10,1/10,2/5)다. systematic의 `--→-+`와 역방향 흐름은8/125와2/125로 다르다. 정지분포 보존과 상세평형을 같은 검사로 취급하지 않는다.
- M=0인 두 배치만 허용하면 단일 자리 Gibbs 갱신은 항등 kernel이다. π가 정지분포여도 한 초기 상태에서 다른 상태로 이동하지 못한다. 두 자리 block 갱신은 매번 두 배치에1/2를 주어 한 단계에 목표 분포가 된다. 상호작용 크기와 상태공간 연결성의 원인을 분리한다.
- random 한 단계와 두 자리 systematic sweep를 같은 계산 비용으로 비교하지 않는다. 행렬 거듭제곱의 분포와 고정 seed 경로의 경험적 빈도를 구별하며, 표본 수·상관·초기화·비혼합을 설명한다. 업데이트 번호는 물리 시간이나 스핀 반전율이 아니다.

유한 비영 온도의 양의 가중치·제약 지원을 먼저 구현한다. T=0 조건화의 퇴화·정의되지 않는 사건·연결성은 별도 경계로 판정하고 무한 β를 직접 대입하지 않는다. 상세평형 일반 이론과 실제 물리 동역학은 뒤 주제에서 더 확장한다.

## 3. 연속 Gaussian Gibbs 법칙과 정규화 가능성

예정 ID: `quadratic-gaussian-gibbs-normalizability`.

무차원 상태 x∈R²와 Lebesgue 기준 dx, 양의 T를 고정하고 `E(x)=xᵀAx/2−hᵀx+c`를 지정한다. A는 대칭 에너지 행렬, h는 에너지 source다. 전체 R² 위의 정규화는 A가 양의 정부호일 때만 가능하다. 이진 입력의 `A11>0`과 정확한 `det A>0`으로 판정하며 작은 고윳값을 임의 epsilon으로0 처리하지 않는다.

- `τ=kBT`, `μ=A⁻¹h`, `Σ=τA⁻¹`, `Emin=c−hᵀA⁻¹h/2`, `Z=(2πτ)/sqrt(det A) · exp(−Emin/τ)`를 유도한다. 두 차원에서 `U=Emin+τ`, 고정 A,h,c의 `C/kB=1`이다. 밀도 높이가1보다 커도 유효하며, 밀도와 셀 확률은 다르다.
- 이상적 한 준비의 `A/τ=[[2,1],[1,2]]`,h=0,c=0에서 `Σ=[[2,-1],[-1,2]]/3`, 상관−1/2, `Z=2π/sqrt3`다. `h/τ=(1,0)`이면 `μ=(2/3,-1/3)`, `Emin/τ=−1/3`, `U/τ=2/3`이다. 이 비는 기준 준비에서 지정하며,온도를 바꿀 때는 A,h,c를 고정하여 A/τ도 함께 변하도록 한다.
- 반정부호의 평평한 방향이나 음의 고유 방향은 R² 정규화를 막는다. singular Gaussian을 낮은 차원 지원 위에 정의할 수 있다는 사실은 전체 R² 밀도의 정규화와 다른 문제다. pinv로 바꿔 같은 밀도를 얻었다고 하지 않는다.
- 가역 좌표 변환의 Jacobian과 differential entropy 변화를 함께 추적한다. 같은 확률 측도, 다른 밀도 값·기준 측도를 구별한다. source 응답 `∂h μ=A⁻¹`와 무차원 source 응답 `∂(βh) μ=Σ`의 단위를 분리한다.

평균/분산이 표시 범위 밖이어도 표현 가능한 에너지·응답을 보존한다. 정규화 불가·정확한0·미해결·표시 범위 밖 비영을 서로 다른 상태로 제공한다. 모든 적분을 유한 격자에서 다시 정규화하여 정상처럼 보이게 만들지 않는다.

## 구현·검증 순서

기존 binary product·방향성 구간·조건화·작은 Markov kernel·worker를 검토한다. 이상적 유리 손계산 → 실제 binary64 독립 고정밀 기준 → 모델 → 상세 한영 원고 → 고정 개념·실험·해설 퀴즈 순서로 작성한다. Gaussian 정상화·정지분포·상세평형은 각각 별도 판정한다.

작은 상태의 정확한 유리 검산은 `scripts/learning/generate-boltzmann-gibbs-ideal-cases.py`와 `scripts/fixtures/boltzmann-gibbs-ideal-hand-cases.json`에 둔다. 이것은 정확한 로그2 관계를 가정한 사전 검토이며 실제 이진 입력 참조가 아니다. 모델·원고와 실제 읽기 화면 검증 전까지 해당 주제를 완료 수에 넣지 않는다. 상전이·상관·상세평형·열역학 극한과 다른 영역·연구 심화는 계속 남는다.
