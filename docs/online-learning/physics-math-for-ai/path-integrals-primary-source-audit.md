# 경로적분의 정의·근사: 범위와 일차 자료 검토

2026-11-10. 상관함수 다음의 입문 원주제를 준비한다. 기존 유한 가우스 적분과 사차 적분은 선수 내용이며, 경로 측도·시간 분할·진동 위상·연산자 극한을 이미 구현한 것으로 계산하지 않는다. 신규 단원 등록이나 완료 판정은 아직 없다.

## 직접 확인한 자료

- [David Tong, Statistical Field Theory §2·§2.1](https://davidtong.org/teaching/statistical-field-theory/sfthtml/S2): 이차 변동, 모드 절단과 측도의 교육적 배경을 확인했다. 정적 장 적분을 양자 시간 진화와 동일시하지 않는다.
- [Christian Grosche, An Introduction into the Feynman Path Integral, §II.1](https://arxiv.org/pdf/hep-th/9302097): 원래 인쇄5–6쪽/PDF6–7쪽의 시간 분할·연산자 합성·Trotter 출발점과 도입의 진동 적분/측도 문제를 확인했다. 굽은 공간과 연산자 순서의 전 범위를 읽거나 검증했다고 주장하지 않는다.

Tong의 이전 aqm PDF 주소는 시간 초과/접근 실패였고, 이전 강의 페이지는 이동 안내뿐이었다. 읽지 못한 PDF를 근거로 세지 않는다. 이하 유한 Brownian bridge의 정확분수 식과 정련 항등식은 새 모형에서 직접 유도하며 위 자료의 공식을 전사하지 않는다.

## 필요한 네 처리

1. **유한 시간 분할과 Brownian bridge** — 고정 양끝, Gaussian 증분의 정규화, 조건부 평균·공분산·소거/합성, 사다리꼴 면적의 편향과 정련, 전형적인 경로의 거칠기를 먼저 다룬다. 예정 ID `brownian-bridge-time-slicing-measure`. 양의 확률 측도와 경로합의 의미를 명확히 한다.
2. **Euclidean 양자 커널과 시간 분할 오차** — 자유입자·조화진동자의 커널 정규화, 열핵과 닫힌 경로의 trace, potential 분할 규약, 유한 격자 오차를 독립 기준해와 대조한다. τ와 βℏ의 관계를 선언하고 양끝 고정 커널을 partition function과 구별한다.
3. **안장점·요동·비가우스 근사** — 최소 작용 경로와 주변 요동, determinant 인자와 작은 매개변수, 여러 안장점의 기여를 구별한다. 기존 유한 사차 적분의 나머지 보증은 그 모형 범위에서만 재사용한다. 일반 경로적분 수렴 정리로 확대하지 않는다.
4. **실시간 위상과 고전 극한** — 자유입자 진동 커널의 조절과 제곱근 가지, 합성과 간섭·정지 위상, 위상 가중치와 확률의 차이를 다룬다. 실시간 경로 전체에 균일한 양의 확률을 부여하거나 Wick 회전을 임의의 potential에 무조건 적용하지 않는다.

각 처리에 한영 상세 이론·손계산·설명 그림·예측 안내·해설 퀴즈·독립 수학 검산·Worker·실제 reader 검증이 필요하다. 네 처리 이후 최초 범위를 감사한다. 상호작용 연속체, fermion·gauge 측도, 굽은 공간의 순서 문제와 재규격화는 추가 연구 범위다.

## 첫 모형의 명시적 계약

N은 시간 구간 수2…32, 내부 자유도는N−1개다. 전체 시간τ>0, 확산D>0, 양끝a,b를 유리수로 받는다. τ,D≤16, |a|,|b|≤16이며 분자·분모는 각각12자리 이내다. δ=τ/N, x₀=a,x_N=b, 유한 가중치는 exp[−Σ(Δx)²/(4Dδ)]다. 각 Gaussian 증분의 밀도 인자(4πDδ)^−1/2를 유지한다.

내부 행렬L은 대각2·이웃−1인 고정끝 사슬이다. Q=L/(2Dδ), μᵢ=a+(b−a)i/N, Cᵢⱼ=2Dδ[min(i,j)−ij/N], detL=N이다. 양끝 변위에 따른 자유 커널은 (4πDτ)^−1/2 exp[−(b−a)²/(4Dτ)]다. 소스 j의 보조 생성함수 로그 비는 jᵀμ+jᵀCj/2다. 이 j는 기존 물리적 에너지 원천과 동일한 기호 규약이 아니다.

N→2N에서 짝수 시각의 평균·공분산은 원래 분할과 정확히 일치한다. 하지만 사다리꼴 면적 A_N=δ[(a+b)/2+Σ내부xᵢ]는 관측 자체가 달라져 Var(A_N)=Dτ³(1−1/N²)/6이다. 정련 불변인 유한 시각 주변분포와 정련에 따라 달라지는 적분 근사를 구별한다.

예상 이차 변동 합은 (b−a)²/N+2Dτ(1−1/N), 예상 Gaussian 작용은 (b−a)²/(4Dτ)+(N−1)/2다. 평균 경로의 매끈함을 전형적인 경로의 미분 가능성으로 오해하지 않도록 비교한다. 이 식들은 유한 분할에서 직접 검산하며 연속 확률 과정의 존재 정리와 별도로 설명한다.

## 구현·검증 순서

유도식의 정확분수/기호 검산→한영 원고와 수치 기반→별도 행렬 구성·소거 방식의 전체 응답 검산→실제 Worker와 취소/복구→기존 홈페이지 스타일의 그림·2D/Three.js·입력/저장·학습 안내→reader 등록·생산 자산 검증 순서다. 계산에 쓰는 전체 분할 수와 표시 경로·표본 수의 한도를 독립적으로 선언한다. 그림의 유사성이나 난수 표본 평균만으로 수학 검산을 대체하지 않는다.
