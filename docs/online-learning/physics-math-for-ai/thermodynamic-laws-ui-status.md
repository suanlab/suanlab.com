# 열역학 법칙: 독립 실습 화면 구현과 검증

2026-11-06. [계산 어댑터](thermodynamic-laws-adapters.md)에 실제 입력·그림·관측 표를 연결했다. **검증 범위는 아직 교재에 등록하지 않은 실습 컴포넌트다. 홈페이지 통합·주제 전체 완료를 뜻하지 않는다.**

## 구현

- `src/components/learning/thermodynamic-laws-lab.tsx`: 세 가족의 실습 화면과 독립적으로 검사할 수 있는 계산 결과 뷰.
- `src/data/interactive-book.ts`의 `thermodynamicLawLabs`: 입력 16개, 한영 비교 예제 40개. 기존 단원·안내에는 등록하지 않았다.
- `scripts/learning-thermodynamic-laws-ui.test.ts`: 예제별 한영 렌더링, 실제 계산 관측과 표시값, 숫자 표현 범위, 의미 구별 검사.

카르노 순환은 실제 p–V·T–S 경로, 현재 위치, 누적 제1법칙 수지, 세 엔트로피 변화와 네 구간의 열·일·상태 변화를 보여준다. 전체 운전 분류·온도 상한·형식 비율·기관 효율·두 성능계수를 구별한다. 경로 재생은 물리 시간이 아니며, 감소 모션·사이트 일시정지를 따르고 수동 단계를 유지한다.

저장고 화면은 열·일 포트의 실제 부호로 화살표를 정하고, 생성 계수에 따른 완결 순환의 일과 생성량을 그린다. 내부 피스톤 경로를 가정하지 않는다. 음의 생성은 실현 불가한 비교로 명시하고, 일 입력 소산을 냉동기로 분류하지 않는다. 잘못된 저장고 순서는 입력 수정 안내로 처리한다.

스펙트럼은 축퇴 미시상태와 상태군 확률, 복제당 S·C·U, 작은 확률의 로그를 그린다. 극소 값과 큰 로그의 축은 명시적인 배율을 사용한다. 실제 0·미정·비영 표현 범위 밖을 구별하고, 첫 로그·추가 로그의 상태도 별도로 표시한다. 정확한 정수 상태 수, 잔류 엔트로피, 들뜸 보정, 서로 다른 두 극한과 `dS/dT`의 단위를 유지한다. 양의 온도 곡선과 T=0 평형 극한을 연결하지 않는다.

## 확인한 근거

관련 **314개 검사**, 타입 검사, 변경 파일 lint를 통과했다. 여기에는 기존 등록 단원 순서·메타데이터·안내 보존 검사가 포함된다. 새 화면의 렌더링·의미 검사는 86개다.

`.runtime/learning/thermodynamic-laws-ui-preview/`의 독립 브라우저 환경에서 실제 컴포넌트와 기존 정적 출력의 스타일을 사용했다. 한영 예제 80상태·입력 변경 32회에서 전체 입력과 관측 표 2,788행을 계산 뷰와 비교했다. 축 388개, 새로고침 6회, 비정수 입력 거부 6회, 접근성 검사 9상태를 확인했다. 경로의 실제 진행, 감소 모션 정지·수동 단계·사이트 일시정지, 320px 문서 폭을 확인했고 페이지·콘솔 오류는 없었다. 명암 스크린샷도 저장했다. 전체 키보드 조작과 배경 탭·화면 이탈 동작은 최종 통합 검사에서 추가로 확인해야 한다.

실행 근거는 `.runtime/learning/thermodynamic-laws-ui-verification.json`, 브라우저 결과는 `.runtime/learning/thermodynamic-laws-ui-preview/browser-result.json`이다. 이 미리보기는 실제 등록 경로나 최종 정적 출력 검사가 아니다.
