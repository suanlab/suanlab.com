# 분배함수 세 가족의 교육 화면 구현 계약

현재 갱신: [실제 교재 입문 통합 검증](partition-function-authoring-status.md)을 마쳤다. 아래는 해당 준비·모델·분리 화면 단계의 계약과 당시 검증 기록이다.

2026-11-07. 세 가족의 모델·독립 참조·한영 원고가 준비되었다. 아래는 다음 구현 계약이며 화면·worker·등록 완료의 증거가 아니다. 기존 홈페이지 색상·컴포넌트·접근성 규칙을 유지한다.

## 공통 실행과 수치 표시

- 계산은 전용 module worker에서 실행한다. 데이터·설정과 무거운 계산 import를 분리하고 SSR이나 worker 실패 시 메인 스레드 계산으로 대체하지 않는다.
- 기존 numerical worker controller의 요청 식별·최신 요청만 반영·취소/cleanup·재시도 패턴을 재사용한다. 현재 입력과 다른 이전 결과를 현재 결과처럼 표시하지 않는다.
- 유한0, 비영 표시 범위 초과, 미해결, 수학적 무한대, 정규화 불가, T=0의 미분 부재를 한영으로 구별한다. 확률 막대의 최소 높이는 시각 보조임을 알리고 실제 확률을 변경하지 않는다.
- 최대64개 상태 샘플은 원래 확률로 표시하고 합을1로 보정하지 않는다. 큰 표는32행씩 탐색하며 모든 수식·표·상태 설명은 키보드로 접근할 수 있어야 한다.
- 모션은 준비 조건의 비교를 돕는 전환이다. 열평형에 도달하는 실제 시간이나 전이율로 표현하지 않는다. reduced motion·전역 끄기·수동 정지·화면 밖 정지를 준수한다.

## 유한 스펙트럼: 정규화와 cumulant

입력은 최대32개 상대 준위·별도 공통 기준·온도다. 네 고정 개념은 다음 순서다.

1. `(0,ε,2ε)`, βε=ln2의 가중치와 `(4,2,1)/7` 확률. 에너지·확률 축의 단위를 분리한다.
2. 같은 확률에서 U·분산·세 번째 cumulant가 서로 다른 가중합이라는 비교. 양의 온도에서도 음의 세 번째 cumulant가 가능한 퇴화 예를 붙인다.
3. 큰 공통 기준과 작은 간격을 별도 입력한 경우, 입력 전에 이미 반올림된 평평한 목록의 차이. 회복 가능한 정보의 범위를 명시한다.
4. T=0 퇴화·음의 온도·범위 밖 Z와 유한 lnZ. 작은 양수를 금지 상태로 잘못 표시하지 않는다.

안내3개는 손계산 재현, 기준 이동, 온도 부호/경계 비교다. 해설 퀴즈2개는 고정 Hamiltonian 조건과 에너지 기준이 바꾸는 양을 묻는다. 고정 개념도는 독립 입력을 쓰고 저장된 실험 결과에 따라 바뀌지 않는다.

## 결합 이진계: 상호작용과 상태공간

입력은 J·h·T와 전체 곱/합0 지원이다. 네 고정 개념은 다음과 같다.

1. 네 배치표와 `E=−JA−hM`. 이름 붙은 두 반정렬 상태를 하나로 합쳐 세지 않는다.
2. J=0 전체 공간과 같은 J=0 합0 제약의 결합확률 격자. 같은 주변확률이 다른 의존성과 양립함을 보인다.
3. βJ=ln2,h=0에서 Δ≈0.22314355와 I≈0.19274476의 다른 비교 대상. 두 수치를 같은 축의 오차 점수로 순위 매기지 않는다.
4. source Hessian과 고정 온도 응답. J=h=0,T=0의 교차 공분산0/미분 부재 반례를 포함한다.

안내3개는 결합 부호, 외부장 편향, 지원 제약 비교다. 해설 퀴즈2개는 곱 분해의 두 조건과 공분산/source/물리적 미분의 구별을 묻는다. 지원 변경 시 금지 배치를 확률0으로 명시하고 상태 수를 함께 갱신한다.

## 무한 사다리: 절단과 오차

입력은 ε·T·L(0..4096)이다. 유한·무한 준비를 나란히 보여주되 무한이 비정규화이면 임의 분포 곡선을 그리지 않는다.

1. q=1/2,L=2의 무한 첫 상태와 절단 조건부 확률. 누락 질량1/8을 별도 영역으로 표시한다.
2. δ·총변동·순방향 KL과 역방향 KL. 질량 오차와 평균/분산 편향을 다른 단위로 구별한다.
3. 고정 절단의 높은 온도와 절단 제거의 순서. C/kB의0과1 극한, 상태 수 절단과 열역학 극한의 차이를 설명한다.
4. ε=0·음의 온도·온도0·q의1 반올림. 무한 분포 부재, 계산 미해결, 비영 표시 범위 초과, 실제 바닥 점질량을 구별한다.

안내3개는 손계산, 허용 누락 질량으로 절단 선택, 높은 온도에서 절단 확장이다. 해설 퀴즈2개는 정규화의 존재 조건과 두 KL 방향을 묻는다. 샘플 막대와 생략 질량을 구별하고 원래 확률을 재정규화하지 않는다.
