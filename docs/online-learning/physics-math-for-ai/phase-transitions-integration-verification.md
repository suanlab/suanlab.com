# 상전이·질서변수: 실제 교재 연결 검증

2026-11-07. 유한 Curie–Weiss, 변분 안정성과 극한, 6차 Landau 공존의 세 단원을 실제 Interactive Book 읽기 화면에 등록했다. 상세 한영 본문, 개념 단계, 계산 실습, 안내 실험과 해설 퀴즈를 연결했다. 기존 521개 단원의 값·순서를 보존했고 현재 등록은 **524개 단원·1,572개 안내 실험**이다.

## 읽기 화면과 수치 계약

한영·명암·320/1440px의 24개 읽기 조합에서 개념 144단계, 고정 선택 432회, 안내 72개, 프리셋 240회, 퀴즈 216선택과 새로고침 복원을 확인했다. 별도 48상태에서 근 확대, 미해결 값 표시, 접힘의 비단일값 미분과 유한 상태 페이지 나눔을 검사했다. 접근성 72회에서 위반과 가로 넘침이 없었다. 그림은 표본 곡선이며 근의 개수·안정성을 인증하지 않는다는 안내를 유지한다.

실제 Next 정적 worker 616개가 생성·종료되었다. 입력 오류·초기화·계산 중 취소·재시도·자산 실패 복구·화면 밖 정지·전역 모션 정지를 확인했다. 실제 클라이언트 단원 이동에서도 진행 중이던 무거운 계산이 종료되었으며, 해당 검사에서 worker 5개가 모두 정리되고 이전 결과가 남지 않았다. 수치 구현은 전용 worker 번들에만 존재한다.

도서 → Interactive Book에서 교재에 진입한다. 한영 모바일·데스크톱 메뉴·breadcrumb·검색을 검사했고 Online Book의 본문에는 이 교재 링크가 없다. 기존 읽기 URL은 보존한다.

- 전체 테스트 **7,824개 통과**, 실패 0.
- lint·typecheck·정적 빌드·콘텐츠 검증·정적 출력 링크/자산/fragment/sitemap 검사 통과.
- 이전 소스 4,141개에서 삭제 0; 의도한 등록·dispatch·기존 단계 검증 수정 8개를 기록했다.

현재 공개 배포가 아닌 로컬 작업본 반영이다. 원래 범위의 입문 주제는 **287/362**, 미완료 입문 주제는 **75개**다. 이는 전체 51영역·509주제와 연구 심화 완료를 뜻하지 않는다. 다음 `상관·fluctuation`은 [집필 계약](correlations-fluctuations-authoring-plan.md)에 따라 연결 공분산, 유한 Ising 고리, 상관된 평균 오차를 차례로 구현한다.
