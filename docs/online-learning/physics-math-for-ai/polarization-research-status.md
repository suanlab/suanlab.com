# 편광 연구 보강 검증

2026-11-12. 두 단원의 한영 네 편에 연구 확장을 추가했다. 기존 본문·여섯 해설 문제·실습 제어를 보존했으며 새 주파수·잡음 제어를 구현했다고 표현하지 않는다. 파동 순차 연구 대조는 **12/18단원**이며 전체 영역 완료가 아니다. 전체 대조 **40영역·396주제**, 후속 **11영역·113주제**를 유지한다.

## 보강 내용

- `jones-polarization-waveplates-analyzers`: 주파수별 순수한 Jones 상태와 주파수를 구분하지 않은 검출기의 평균 결맞음 행렬을 구분했다. 가우스 특성함수·편광도·분석기 읽음, 이차 모멘트 하계, 같은 분산의 두 선 스펙트럼에서 나타나는 되살아남과 부호 역전을 유도했다. 주파수 의존 보상 전후의 정보 소실과 고정 유니터리의 한계를 설명한다. 가우스는 편차 포락선 모델이며 유한 시간 게이트·전체 물질 응답을 인증하지 않는다.
- `stokes-coherency-polarization-tomography`: 약한 원형 감도를 갖는 여섯 읽음 계열의 장치 행렬·특잇값·유사역행렬 상계·독립 동일 분산의 공분산을 유도했다. 지연량 보정 오차의 정확한 혼합식과 고정 설정에서의 일차 근사, 모두 양수인 읽음이 원뿔 밖 추정값을 주는 반례를 추가했다. 무편광 입력에서 물리적으로 허용되는 거짓 편광 추정도 구분한다. 조건수만으로 모든 잡음·광자 예산에서 최적이라고 주장하지 않는다.

한영 원고마다 Python 셀·표·연구 질문 세 개를 추가했다. 수식은 단원별 7개·8개, 코드는 언어 간 동일하다. 기존 홈페이지의 파랑·주황·회색을 사용한 SVG 네 개의 원본과 최종 모바일 화면 네 개를 확인했다.

## 계산과 화면 검증

선택 4파일 **50검사**, 집중 보강·보존 **12검사**, lint·콘텐츠·빌드·타입·**1,888 HTML** 정적 검증을 통과했다. 전체 등록 **650단원·1,969안내**, URL 1,885개를 유지한다.

독립 표준 라이브러리 계산으로 가우스 스펙트럼 24상태·정련 4개·주파수별 순수 상태/역보상 각 45개·고정 지연판 54개·유한 스펙트럼 하계 18개를 대조했다. 장치 스펙트럼 7개·복원 오차 336개·독립 잡음 모서리 조합 448개·공분산 7개·보정 오차 32개·미분 16개·양의 읽음 반례 3개·원형 비식별 쌍 2개도 확인했다. 가우스 적분은 [−9,9]에서 16,000/32,000 분할로 대조하고 빠진 확률 꼬리를 별도로 명시한다.

기존 계산기로 유한 스펙트럼 모집단 45개·주파수별 Jones/역보상 각 105개·평균 후 고정 지연판 45개를 재현했다. 약한 분석기 준비 28개/읽음 56개와 잘못된 Stokes 거부 두 개·물리적으로 허용되는 편향 상태 한 개를 확인했다. 실제 연속 가우스 주파수 제어가 구현되었다는 의미가 아니다.

최종 빌드의 변경 두 단원에서 한영 **16화면**(밝은 테마 320/768/1440px·어두운 테마 1440px), 영어 320px의 **6안내·4해설 퀴즈·8개념 선택·2저장/완료 그룹**을 점검했다. 페이지 오류·Axe 위반은 없다. 이 검사는 전체 영역의 같은 최종 빌드 화면 검사로 합산하지 않는다.

초기 검사는 마지막 영문 다크 화면의 이미지 decode 오류로 중단되었다. 후속 시도에서 미리보기 연결 거부와 리스너 부재를 확인해 서버를 다시 실행했다. 초기 decode 오류의 정확한 원인은 확정하지 않았다. 검사기도 선택 언어의 그림과 로드 완료를 먼저 기다리도록 보완한 뒤, 같은 고정 원고/그림·최종 빌드의 전체 16화면을 처음부터 다시 검증했다. 처음 15화면을 재검사 수에 더하지 않는다.

## 보존과 다음 순서

추가 절을 제거하면 이전 네 본문이 바이트 단위로 복원된다. 다른 파동 원고 32편·기존 검토 701항목·이전 다섯 배치 원고/그림 40해시를 보존했다. 검토 기록은 705항목이다. 고정한 원고/그림 여덟 입력, 원본·내보내기·서빙 SVG 네 쌍과 HTML 두 쌍을 대조했다. 목차는 원래 16절+추가 1절=17절이며 추가 절을 제거하면 원래 16절이어야 한다.

다음은 **기하·파동 광학** 두 단원이며 이후 Fourier optics, 관측·샘플링·센서 순서다. 전체 근거와 해시는 [검증 기록](polarization-research-evidence.json)에 보관한다. 로컬 검증과 원격 공개 배포 성공은 별도로 확인한다.
