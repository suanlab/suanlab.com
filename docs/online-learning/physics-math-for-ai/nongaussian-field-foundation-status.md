## 교육 내용과 모형

평균·공분산이 같아도 사차 연결량이 다른 순수 사체 반례, 독립 비가우스 변수의 반복 첨자, 비영 평균의 잘못된 사차 빼기, 이웃 상호작용과 유한계 대칭, 열린/주기 경계와 홀수 고리 좌절을 설명한다. 물리 원천과 보조 원천·Boltzmann 인자·온도 경로·비선형 응답을 구분한다. AI 연결에서는 이차 특징의 정보 한계를 모집단 반례로 보여 주며 표본 검증과 인과 추론을 대신하지 않는다.

4–8개 고전 스핀, 열린/주기 간선과 첫 네 위치에 한 번 작용하는 사체 항이다. q,r,pᵢ는 물리 에너지가 아닌 유리수 Boltzmann 인자다. 모든 배치가 양의 확률을 가지며 counting measure로 합산한다. 모든 상태 확률·부분집합 모멘트·평균/공분산·선택 삼차/사차량·원천 미분·충분통계 분산과 공분산·자화 분포를 반환한다.

생산 모델은 공통분모 정수 가중치와 Walsh 변환을 사용한다. 확률 합·양의 가중치·변환 역복원·스핀 대각 항등식을 검사한다. 입력을 descriptor로 읽고 중첩 벡터를 소유·동결하며 getter·잘못된 원형/추가 속성/희소 배열을 거부한다.

## 독립 참조와 확인한 범위

- 별도 Python Fraction은 각 배치의 유리수 가중치와 스핀 곱을 직접 합산한다. 누적량은 삽입 자리의 집합 분할로 구하고 중심화한 곱도 직접 합산한다. 생산 Walsh 변환이나 중심화 전개를 복사하지 않는다.
- 17예제+고정 난수16+극한3, 총36입력·2688배치를 대조했다. 상태 확률과 모든 부분집합 모멘트부터 응답·정규화까지 전체 수학 출력을 비교했다. 같은 정의의 다른 알고리즘이며 모든 입력의 형식 증명은 아니다.
- 참조36+추가17, 총53검사를 통과했다. 평균/공분산 동일 반례·반복 첨자·원천 반전·온도 재척도/고정 에너지 가열·경계/좌절·정확 Cauchy–Schwarz·입력 소유권·한영 strict 수식 렌더링을 확인했다. 타입과 변경 파일 lint도 통과했다.
- 최대 서로소 입력은256상태·256부분집합 모멘트, 직렬화810635bytes다. 후속 전송/복사/취소 한도를 정할 때 유지할 사례다. 아직 Worker·학습 화면·reader·생산 자산은 검증하지 않았다.
