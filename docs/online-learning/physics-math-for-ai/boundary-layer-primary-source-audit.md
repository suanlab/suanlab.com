# 특이 섭동·경계층: 범위와 일차 자료 검토

2026-11-10. 섭동 원주제의 세 번째 처리다. 정칙 섭동과 발산 점근급수 두 단원은 실제 reader에 등록됐다. 경계층 단원은 한영 원고·계산 기반을 먼저 준비하며, 이 단계에서 기존592단원·1808안내·입문313/362검증·49미완료 수치를 늘리지 않는다.

## 읽은 자료와 구분

- [John K. Hunter, Asymptotic Analysis and Singular Perturbation Theory, §4.3, 인쇄54–57쪽](https://math.ucdavis.edu/~hunter/notes/asy.pdf): 최고차 항을 지울 때 차수가 줄어드는 현상, 안쪽/바깥 변수, 정합과 합성의 교육적 전개를 확인했다. 해당 예시는 εy″+2y′+y=0으로 아래 구현 방정식과 다르다. 동일 모형의 외부 검산이나 그대로 옮긴 증명으로 기록하지 않는다.
- [NIST DLMF §2.1(iv)](https://dlmf.nist.gov/2.1#iv): 매개변수를 포함한 균일 점근성의 정의를 확인했다. 본문에서는 끝점을 포함한 상한 노름과 고정 내부점의 극한을 직접 비교한다.

두 자료는 개념·정의의 근거다. 아래 정확해·오차·미분·잔차 식은 이 저장소에서 독립적으로 유도하고 검산한다. 연구 논문 검색 결과나 읽지 않은 자료를 검증된 근거로 추가하지 않는다.

## 선언한 모형

εu″+au′=f, 0<x<1, u(0)=A, u(1)=B, ε>0. a·f는 상수다. a의 양/음/0, 부호 있는 경계 자료와 강제항, 얇지 않은 층과 층 진폭0인 경우를 구별한다. a<0이면 y=1−x로 반사하며 물리적 일차 미분 부호를 유지한다. a=0은 정확한 이차식으로 처리한다. ε=0은 입력으로 계산하지 않는다.

b=|a|, δ=ε/b, k=f/b, D=F−N−k로 두면 정확해는 N+ky+D(1−e^(−y/δ))/(1−e^(−1/δ))다. 바깥해와 합성해의 전체 구간 최대 오차는 각각 |D|, |D|e^(−1/δ)다. 합성해 미분 오차는 |D|e^(−1/δ)/[δ(1−e^(−1/δ))]다. 모든 식의 가정은 상수 계수 유한 구간 모형이며 일반 경계층 이론의 오차 정리가 아니다.

## 구현·검산 약속

- 입력 유리수 분자/분모 각12자리, 0<ε≤16, |a|·|f|·|A|·|B|≤16, 관측 위치[0,1], 패널4..256. 기호와 접근자·추가 속성은 거부하며 입력 복사를 소유한다.
- 정확한 유리수 산술과192비트 방향 보존 지수 구간을 사용한다. 연산 정밀도와 최종 포함 구간 폭을 구분한다. 아주 작은 양의 지수를 정확한0으로 분류하지 않는다.
- 물리65점과 안쪽65점은 그림 표본이며 전체 오차 보증의 근거가 아니다. mδ≥4와 δ≤0.1은 명시적 화면 기준이며 격자 수렴 증명이 아니다.
- 독립 Python은 원래 부호 좌표의 적분인자 해와200자리 mpmath/expm1을 사용한다. SymPy로 정확해의 방정식·경계와 합성해의 내부 잔차를 확인한다. 고정밀 수치는 형식적인 포함 구간 증명으로 표시하지 않는다.
- 전체 응답의 독립 검증과 Worker, 한영 개념 그림·실험·퀴즈·저장, 실제 reader와 생산 자산은 후속 단계다. 해당 단계가 끝나기 전 등록/완료 수치에 포함하지 않는다.

가변 계수, 내부층·전환점, 비선형 정합, WKB와 일반 PDE 안정성은 이 단원 완료 주장에 포함하지 않는다. 이후 장시간 세속항 단원과 섭동 원주제 감사도 남아 있다.
