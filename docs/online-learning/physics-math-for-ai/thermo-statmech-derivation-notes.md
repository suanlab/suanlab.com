# 열역학 첫 두 가족의 유도 메모

2026-11-06. [집필 준비](thermo-statmech-authoring-plan.md)의 수학 명세다. 제품 모델·실습을 구현하거나 검증한 기록은 아니다. 양의 절대온도·일정 물성과 선언한 제어조건 안에서만 사용한다.

## 유한 열용량 두 물체

Cᵢ의 단위는 J/K, 연결 K는 W/K, 시간은 s다. 외부는 단열이고 두 물체의 체적은 고정한다. 열 흐름의 방향은1→2이며 Φ=K(T₁−T₂)다. 각 물체를 내부적으로 균일한 온도로 근사한다.

\[
C_1\dot T_1=-\Phi,\quad C_2\dot T_2=\Phi,\quad
C_e=\frac{C_1C_2}{C_1+C_2},\quad \lambda=K/C_e.
\]

초기 차를 d=T₁₀−T₂₀, 평형 온도를 Tₑ=(C₁T₁₀+C₂T₂₀)/(C₁+C₂)라 하면

\[
T_1=T_e+\frac{C_2d}{C_1+C_2}e^{-\lambda t},\qquad
T_2=T_e-\frac{C_1d}{C_1+C_2}e^{-\lambda t},\quad
Q_{1\to2}=C_ed(1-e^{-\lambda t}).
\]

Q는 전달 과정의 양이며 내부에 저장된 별도 '열 함량'이 아니다. ΔU₁=−Q, ΔU₂=Q다. 내부 에너지의 기준값은 임의로 정할 수 있고, 그 기준 선택과 무관하게 총변화는0이다. 두 온도가 같은 숫자로 반올림되어도 별도로 계산한 d·exp(−λt)와 순간 흐름이 비영일 수 있다.

\[
\Delta S=C_1\ln(T_1/T_{10})+C_2\ln(T_2/T_{20}),\qquad
\dot S=\frac{K(T_1-T_2)^2}{T_1T_2}\ge0.
\]

작은 차의 두 로그를 직접 상쇄시키는 대조와 양의 적분을 구분한다. h=1−exp(−λt), T₁(u)=T₁₀−C₂du/(C₁+C₂), T₂(u)=T₂₀+C₁du/(C₁+C₂)라 하면

\[
\Delta S=C_ed^2h\int_0^1\frac{1-hv}{T_1(hv)T_2(hv)}\,dv.
\]

양의 구조를 유지하는 계산 후보이며, 최종 수치 적분의 정확도는 독립 검증해야 한다. K=0·d=0·t=0이면 전달과 엔트로피 생성은 정확히0이다. K=0에서 평형 도달 시간1/λ를 임의의 유한 값으로 채우지 않는다. '두 초기 온도가 같음'과 '접촉이 끊겨 변화 없음'은 다른 물리 상황이다.

손계산 기준은 C₁=2,C₂=3J/K,T₁₀=330,T₂₀=270K,K=0.4W/K,t=3s다. Tₑ=294K, λ≈1/3s⁻¹이며 실제 행렬 지수·열 흐름 적분·엔트로피 생성 적분으로 아래 준비 기록에서 대조한다.

## 이상기체의 두 복합 경로

n은 mol, R은 J/(mol K), V는 m³, p는 Pa다. 일정한 단원자 이상기체의 몰 정적 열용량을 Cᵥ=3R/2로 선언한다. 입자 이동이나 다른 형태의 일이 없고, 마찰 없는 준정적 체적 제어와 가역 열 교환을 명시한다. 진행률 s는 물리적 시간이 아니다.

경로A는 (T₀,V₀)→(T₁,V₀)→(T₁,V₁), B는 (T₀,V₀)→(T₀,V₁)→(T₁,V₁)이다. 같은 두 끝점에서

\[
p=nRT/V,\quad \Delta U=nC_v(T_1-T_0),\quad
W_A=nRT_1\ln(V_1/V_0),\quad W_B=nRT_0\ln(V_1/V_0),
\quad Q_A=\Delta U+W_A,\quad Q_B=\Delta U+W_B.
\]

W는 기체가 외부에 한 일이 양수다. 따라서 압축에서는 음수가 되고 ΔU=Q−W다. 온도 변경 구간의 가역성을 위해서는 매 순간 기체와 무한소 온도차를 갖는 연속적인 저장고가 필요하다. 온도T₁인 저장고 하나에 처음부터 접촉시킨 과정을 같은 가역 경로라고 부르지 않는다.

\[
\Delta S=nC_v\ln(T_1/T_0)+nR\ln(V_1/V_0)
=\int_{\rm path}\frac{\delta Q_{\rm rev}}T.
\]

A와B의 ΔU·ΔS는 같지만 Q·W는 대체로 다르다. T₀=T₁이면 두 일이 같아지고, V₀=V₁이면 일은0이다. 임의의 한 경로에서 Q/T를 계산해 엔트로피 변화로 대체하지 않는다. 체적 변화 구간은 로그 보간으로 매개변수화할 수 있으며, 압력과 일은 실제 상태식·경로 적분으로 계산한다.

`.runtime/learning/thermo-statmech-preparation/check-derivations.py`는 제품을 호출하지 않는다. 두 물체는 물리 변수의2×2 행렬 지수와 실제 시간의 열·엔트로피 생성 적분을 닫힌 식과 비교한다. 기체는 실제 p(V)·열용량·가역 엔트로피 적분을 대조한다.100자리10사례의 실행 근거를 `derivation-sanity.json`에 남긴다. 이것은 수학 준비의 근거이며 미래 제품 구현의 독립 검증을 대신하지 않는다.

## 실제 기반 구현에서 선택한 경로

[이상기체 기반 구현](ideal-gas-paths-foundation.md)은 각 단계의 온도·부피를 선형으로 보간한다. 위의 로그 보간은 가능한 다른 매개변수화이며 이번 구현의 선택은 아니다. 경로 위치는 시간으로 해석하지 않는다.

엔트로피는 ΔS=(nR/2)log[(T/T₀)³(V/V₀)²]로 결합하여 공급된 이진 경로 좌표의 정확한 영 차이와 작은 부호를 보존한다. 반대 부호의 열 항에는 Q/(nR)=(3/2)ΔT+T_iso log(V/V₀)의 로그 상하한을 사용한다. 실제 식·관례·정확도 범위와 독립 적분은 기반 보고서에 연결했다. 홈페이지 통합 검증의 근거는 아직 아니다.
