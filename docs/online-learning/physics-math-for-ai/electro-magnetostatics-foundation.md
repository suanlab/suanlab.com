# 정전·정자기의 계산 모델과 상세 한영 원고

2026-11-05 모델·원고 집필 단계의 기록이다. 이후 [홈페이지 통합 검증](electro-magnetostatics-authoring-status.md)을 마쳤으며 아래 미등록 수치는 당시 기준이다.

균일한 비도체 대전 구와 무한 정상 전류 원통의 계산 모델·상세 원고를 작성했다. 두 단원은 아직 홈페이지에 등록하지 않았다. 현재 등록462개 한영 단원·1,386개 안내 실험, 원래36영역·362주제 중259개 입문 검증·103개 미완료 수를 유지한다. 전체51영역·509주제와 연구 심화는 미완료다.

## 모델의 가정과 반환 계약

구는 균일한 **지정 부피 전하**다. 도체 평형의 표면 전하나 완화한 점전하가 아니다. 원통은 무한히 길고 단면에 균일한 **지정 정상 전류**다. 유한한 열린 도선이나 재료의 구성 법칙·힘의 평형을 함께 푼 결과가 아니다. 관측 벡터는 삼차원이며 원통 해만 축 방향 평행이동에 불변이다.

교육용 k=9×10⁹과 μ=4π×10⁻⁷은 반올림한 정적 계수다. 후자를 정확한 현대 SI 상수로 주장하지 않는다. 이후 전자기파 계산에는 ε·μ·광속의 일관된 준비가 별도로 필요하다. [자료 대조](electro-magnetostatics-source-audit.md)에 MIT 유도와 NIST 상수표를 연결했다.

구의 장은 내부에서 위치에 선형, 외부에서 거리 제곱에 반비례한다. 원통의 방위각 장은 내부에서 축까지 거리에 선형, 외부에서 거리에 반비례한다. 중심·축에서는 실제 전류원/전하원 벡터가0이지만 좌표 방향은 미정이다. 이를 특이점이나 epsilon 반지름으로 바꾸지 않는다. 퇴화한 닫힌 면·경로의 적분은0이어도 면적·길이로 정규화한 추론은 계산 불가다.

영이 아닌 전하·전류에서 경계의 장은 연속이고 한쪽 미분은 다르다. 경계의 고전적 미분·발산/회전은 양쪽 평균으로 만들지 않는다. 한쪽 극한은 따로 반환한다. 영전하·영전류이면 불연속 자체가 사라지는 예외를 검사한다. 경계 판정에 임의의 epsilon 띠를 만들지 않는다.

균일한 배경장은 전체 장의 점별 값을 바꾸되 닫힌 선속·순환에는 기여하지 않는다. 따라서 적분 법칙은 유지되어도 전체 장을 대칭 상수로 꺼내는 계산은 실패할 수 있다. 원천·배경·전체 벡터를 분리한다. 구의 원천 전위는 무한대 기준, 배경 전위는 원점 기준이며 배경이 있는 전체 전위에 무한대0을 주장하지 않는다.

지원 범위는 원천 반지름0.25–4 m, 전하·전류 −4–4 C/A, 관측 좌표 각 −16–16 m다. k는10⁻¹²–10¹², μ는10⁻¹²–2, 배경 E는 성분별±10⁶ N/C, B는±1 T다. 범위 밖 입력은 조용히 보정하지 않고 거부한다. 표현 가능한 장을 포함 전하/전류의 언더플로 때문에 잃지 않도록 내부 벡터를 직접 계산한다. 수치 범위 한계와 실제0, 좌표 방향 미정, 경계 한쪽 미분은 서로 다른 상태다. 극단 입력 검사는 연속체 모형의 물리적 유효 길이를 확장하는 주장이 아니다.

## 독립 기준과 관측 차이

`scripts/learning/generate-electro-magnetostatics-references.py`는 제품 코드를 가져오지 않는다. 구63조건에서는 Coulomb 구껍질의 각 평균 커널을 SciPy로 적분한 전위를 독립5점 미분한다. 원통63조건은 무한 필라멘트의 Biot–Savart 기여를 관측점 중심 광선·단면 교차 길이로 적분한다. 삼차원 배경장 관측24조건과 경계 차분 수렴4단계도 포함한다. 고정 seed 기준 파일을 재생성하고 동결한 바이트와 일치함을 확인한다.

제품과 기준의 최대 차이는 k·μ를 분리한 값으로 구 전위8.88×10⁻¹⁶, 비경계 전위 기울기5.28×10⁻¹¹, 경계 기울기4.00×10⁻⁵, Biot–Savart 장8.88×10⁻¹⁶이다. 삼차원 전체 전위 차이는2.22×10⁻¹⁶, 독립 기울기 차이는2.13×10⁻¹¹이다. 지정한 조건에서 관측한 차이이며 보편적인 오차 인증이 아니다.

경계에서 전위는 C¹이지만 C²는 아니다. 중심5점 미분의 경계 오차는 간격0.01→0.005→0.0025→0.00125에서 약0.005→0.0025→0.00125→0.000625로 줄었다. 매끄러운 영역의 고차 수렴을 그대로 주장하지 않는다. 해석 적분 항등식의 잔차와 별도로 실제 전체 벡터의 닫힌 면·선 수치 적분, 삼차원 미분, 대칭·부호·스케일·수치 범위를 검사했다.

## 검증과 보존

전용36개·전체3,895개 테스트, 타입·lint·콘텐츠 검사(1,696 URL)가 모두 통과했다. 최종 실제 종료와 결과는 `.runtime/learning/electro-magnetostatics-foundation-verification.json`, 수치 비교와 원고 렌더링은 같은 디렉터리의 `electro-magnetostatics-reference-comparison.json`과 `electro-magnetostatics-manuscript-review.json`에 기록한다.

등록 전 고정한 `scripts/fixtures/pre-electro-magnetostatics-registry-hashes.json`으로 기존462개 단원·안내,42개 실험 그룹의453항목과 상대 순서를 대조한다. 이전 홈페이지 소스2,908개와 출력4,139개를 보존하고 신규10개를 더한 소스2,918개를 동결한다. 미등록 원고의 렌더링 검증을 새 홈페이지 화면 검증으로 부르지 않으며 기존 출력을 다시 빌드하거나 배포하지 않는다.
