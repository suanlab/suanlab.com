## 픽셀 관측에서 유지한 구분

픽셀 간격과 감광 폭은 다른 조작이다. 전자는 Nyquist 조건을 바꾸고 후자는 공간 평균과 수광 면적을 바꾼다. 노출은0부터T까지이며 중심 시각은T/2다. 이동하는 장면의 시간 적분을 공간 평균과 분리한다. 주파수·원점·이동 중심에 따른 부호 있는 alias 위상을 유지한다.

0면적·0노출에는 실제 평균을 미정으로 표시하고 에너지·광자 평균은0이다. 유한한 점·순간 극한을 실제 광량으로 부르지 않는다. 단색550nm의 교정된 W/m²·영역·시간·SI 상수로 광자 평균을 계산한다. 이전 광학 모델의 상대 강도를 교정 없이 물리 광량으로 바꾸지 않는다.

유한 sinc 복원은 유지한 격자점을 통과해도 원래 장면과 다를 수 있다. 점 사이 보간의 음수·overshoot를 실제 음의 에너지로 해석하지 않는다. 원래 연속 장면과 전달 곡선의 가장 빠른 진동을 고려해 표시 표본을 배치한다. 이 표시 격자는 실제 센서 표본을 추가한 것이 아니다.

## 센서 분포에서 유지한 구분

노출·복사조도를 바꾸면 고정 면적25µm²·파장550nm에서 입사 광자 평균도 다시 계산한다. 유효 QE는 전체 면적 기준으로 정의하여 fill factor를 이중 적용하지 않는다. 독립 Poisson 광전자·암전자와 Gaussian 읽기 잡음이라는 가정을 밝힌다.

저장 상한 뒤에 읽기 잡음, 이득·offset, 반올림·ADC clipping을 적용한다. 저장 넘침은 N>F, 위쪽 ADC clipping은 Y≥M+.5이며 최대 코드 점유 Y≥M−.5와 다르다. 막대는 각 정수의 실제 확률 질량이며 연속 Gaussian 그림으로 대신하지 않는다. 원래 무한 분포의 생략된 꼬리와 확률 질량 잔차를 보존하고 강제로 재정규화하지 않는다.

포화 전 해석적 SNR과 실제 저장·디지털 모멘트를 나눈다. 결정론적8.2DN 준비는 실제 디지털 분산0이며1/12DN² 근사의 반례다. 포화로 줄어든 분산을 정보가 좋아졌다는 증거로 쓰지 않는다. 계산 지원 비트·광자 범위는 실제 카메라의 보편 한계나 표준 인증이 아니다.
