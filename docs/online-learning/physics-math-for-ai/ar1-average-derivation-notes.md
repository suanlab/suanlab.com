# 정상 AR(1) 유한 평균: 유도와 계산 계약

## 명시적 초기 법칙과 끝점

중심화된 Y1∼N(0,1), 독립 εi∼N(0,1), `Y_(i+1)=ρYi+sqrt(1−ρ²)εi`다. 관측은 Xi=μ+Yi로 해석할 수 있다. 모델 입력은 n=1..512와 실제 binary64 ρ∈[−1,1]이며 μ와 무관한 중심화 평균 오차를 계산한다. 혁신 분산을 1로 고정하거나 Y1=0으로 시작하는 모델과 다르다.

|ρ|<1이면 초기 정상 Gaussian 법칙이 보존된다. ρ=1은 Y1이 반복되는 상수 준비, ρ=−1은 ±Y1이 교대하는 퇴화 정상 준비다. 끝점은 혼합하지 않으므로 보통의 무한 자기공분산 합 IAT를 보고하지 않는다. 음의 끝점에 유리식의 형식적 연장 0을 대신 쓰지 않는다.

## 두 개의 분산 유도

재귀를 k번 전개하면 `Cov(Yi,Y_(i+k))=ρ^k`다. 초기값과 이후 혁신항이 독립이라는 점을 사용한다. 평균의 공분산 이중 합에서 대각은 n개, 지연 k는 2(n−k)개다. 따라서

`V_n=[n+2Σ(k=1..n−1)(n−k)ρ^k]/n²`.

별도로 독립 입력들을 모으자. `a_m=Σ(k=0..m−1)ρ^k`라 하면

`Σ(i=1..n)Yi=a_n*Y1+sqrt(1−ρ²)*Σ(j=1..n−1)a_(n−j)*εj`.

독립 입력의 분산을 더하면

`V_n=[a_n²+(1−ρ²)*Σ(m=1..n−1)a_m²]/n²`.

이것이 구현의 양의 기여 분해다. a는 `a_(m+1)=1+ρa_m`으로 순회하며, [−1,1]의 ρ에서 `0≤a_m≤m`이라는 해석적 경계로 구간을 좁힌다. 혁신 분산은 전달된 ρ의 정확한 이진 제곱을 1에서 뺀 값이다. 표시 값의 반올림 뺄셈으로 구하지 않는다.

## 유한 값·점근값·관측량

고정 |ρ|<1에서 `τ=1+2Σ(k≥1)ρ^k=(1+ρ)/(1−ρ)`이며 `nV_n→τ`다. 정확한 내부 보정은

`V_n=τ/n−2ρ(1−ρ^n)/[n²(1−ρ)²]`.

양의 ρ에서 τ/n은 유한 답보다 크고 음의 ρ에서는 작다. 고정 모수에서의 O(n⁻²) 보정과 끝점에 접근하는 공동 극한을 구별한다. τ<1은 상쇄를 포함하는 이 관측량의 분산 팽창이지 모든 의존성이 빨리 사라진다는 뜻이 아니다.

`n_eq=1/V_n`은 단위 주변 분산의 선형 평균에 대한 분산 등가 수다. ρ=−1에서 짝수 n이면 V=0·n_eq=+∞이고, 홀수이면 V=1/n²·n_eq=n²다. 같은 경로의 Yi² 평균은 Y1²로 계속 랜덤이므로 이 등가 수를 임의 관측량의 독립 정보 수로 해석하지 않는다. ρ=1에서는 모든 n에서 V=1이다.

## 방향성 계산과 제곱근

자기공분산 거듭제곱은 정확한 이진 계수·지수를 보존한다. 최소 양수 모수의 먼 지연처럼 선형 범위 밖인 비영 관측량도 부호·경계를 잃지 않는다. a와 혁신 분해에는 128,…,8192비트의 방향성 구간을 사용한다. 보고할 비영 관측량은 부호 확정 및 상대 폭 ≤2⁻⁴⁸를 요구한다.

혁신 분해의 분자 경계가 고정소수점 정수 L,U와 척도 S=2^P로 주어지면 평균 분산 경계는 `L/(S*n²),U/(S*n²)`다. 표준오차는 `floor(sqrt(L*S))/(S*n)`와 `ceil(sqrt(U*S))/(S*n)`로 감싼다. 정수 제곱근은 Newton 반복으로 바닥을 구한 뒤 정확한 제곱 비교로 위 경계를 정한다. 이 경계들을 제곱하면 원래 분산 구간을 바깥에서 감싼다는 검사를 포함한다. 일반 크기 로그 투영은 근사다.

## 독립 참조와 실제 원고 경로

Python Fraction은 `Fraction.from_float`로 실제 입력을 읽고 공분산 지연 합을 정확히 계산한다. 작은 10사례는 실제 공분산 이중 합으로 추가 검산한다. 구현의 혁신 분해를 참조에 재사용하지 않는다. 21사례·404개 선택 관측은 유한 분산·표준오차·팽창·등가 수·점근 비교와 선택된 지연·접두 길이를 포함한다. 이는 모든 실수 모수나 모든 가능한 길이를 열거했다는 뜻이 아니다.
