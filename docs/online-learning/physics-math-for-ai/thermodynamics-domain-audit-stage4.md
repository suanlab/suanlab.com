# 미시·거시 상태 세 단원 점검

2026-11-07. 상태: **완료**. 한영 본문 6파일·풀이 36개, 개념 12단계·안내 9개·퀴즈 6개를 대조했다. 열역학 종합 점검의 완전 확인은 **10/32단원**, 나머지는 22단원이다. 아래 전체 읽기 행렬을 통과해 세 단원을 추가했다.

## 본문과 그림 보완

- 이진 껍질 한영 수식에서 전체 공간 확률의 full 첨자가 줄바꿈과 잘못된 문자로 손상된 네 곳씩을 수정했다. KaTeX가 렌더된다는 사실과 두 번역의 수식이 같다는 사실만으로 같은 오기를 찾을 수 없어 기존 콘텐츠 검사에 의미 있는 첨자 검사를 보강했다. 실제 화면의 다섯 Pfull 표기도 확인했다.
- 첫 실습의 ε=10⁻²¹ J와 독립 모델의 기본값을 혼동하던 설명을 바로잡았다. 세 단원 모두 이미 있는 그림·입력·등록을 미완료로 설명하던 문구를 고치고 실제 예제 선택 표와 조작 절차를 넣었다.
- 배치·껍질·조건부의 다른 분모, 선택 군과 전체 가중 평균, 균등 재구성의 추가 가정, 행 조건부·결합·사후의 다른 정규화를 연결했다. 군 수 감소가 레이블을 합치는 조작과 JSON의 명시적 사상 검증을 구별했다.
- 전용 Bars 그림에 최소 560px 내부 폭과 10단위 SVG 글씨를 적용해 실제 글씨가 최소 16px로 보이게 했다. 설명과 캡션은 스크롤 밖에 두고, 방향키 안내를 aria-describedby로 연결했다. 색상·테마·메뉴·단원 URL과 수치 모델은 유지했다. 다른 공통 WavePlot 사용처의 가독성은 별도 후속 항목이다.

## 확장 JSON의 비영 값 보호

실제 잡음 관측 화면에서 준비 가중치 1e-999가 0으로 저장되어 지지집합을 바꾸는 문제를 재현했다. JSON의 숫자 원문과 파싱 결과를 함께 검사하는 순수 도우미를 만들고 미시·거시 상태·앙상블·분배함수의 기존 세 편집기에 적용했다. 비영 underflow·비유한 수를 거부하고, 개수·사상·절단 항목은 소수 부분이 Number 변환에서 사라지기 전에 검사한다. 일반적인 소수의 binary64 근사와 표현 가능한 작은 수, 정확한 0은 유지한다. 기존 저장된 숫자에서 잃어버린 원문을 복원한다고 주장하지 않는다.

아홉 단원의 한영 18화면에서 비영 underflow 36회, overflow 18회, 소수 개수 12회를 거부하면서 저장값·Worker 생성 수가 바뀌지 않는 것을 확인했다. 표현 가능한 최소 양수의 실제 적용 16회와 저장고의 유효 개수 변경 2회도 통과했다. 전체 페이지 접근성 18상태에서 위반이 없었으며 Worker 54개가 모두 종료됐다. 이 범위는 알려진 세 학습 JSON 편집기이며 모든 웹사이트 입력 계층의 증명은 아니다.

## 수학·교수 내용과 실제 화면

정확한 정수 조합, Fraction 정규화와 독립 고정밀 상태 합으로 27준비·612비교·정수 계수 7,291검사를 통과했다. 일반 사례는 800자리, 거의 같은 가중 분포와 극소의 세제곱 군 KL은 4,096자리를 사용했다. 빈 계·한 자리·조건부 모멘트·N=4096, 희귀 확률과 엔트로피 기여, 빈 군·질량0·지지집합 무한대, 한 ULP와 극소 군 KL, 사후·지워짐·반전·정확한 독립성을 포함한다. 수치 검사는 모든 유효 입력에 대한 증명이 아니다.

실제 조작에서 N을 줄이면 K와 블록 크기가 줄어드는 것, 군 수 감소가 가중치를 유지하면서 레이블을 합치는 것, 질량0인 군과 빈 군의 차이, 사전3:1에서 Y=1 사후 .75, 지워짐 Y=2의 균등 사후를 확인했다. 선수 여섯 링크의 등록 순서도 대조했다. 물리적 엔트로피와 정보량, 상태 비교와 시간·소산을 혼동하지 않도록 설명을 검토했다.

큰 16×16 혼합 가중치 계산에서는 debounce 중 중단·시작된 Worker·언어/테마 응답성·클라이언트 이동 시 정리·저장 복원·다른 예제로 교체 후 현재성 유지를 확인했다. 별도 상호작용 프로브의 Worker 11개가 모두 종료됐다. 예제 자동 비교·사이트 일시정지·수동 이동·모션 감소·실제 화면 밖 정지도 통과했다.

전체 읽기 행렬은 3단원 × 한영 × 명암 × 320/1440px의 24화면이다. 전체 통과 결과는 24/24화면, 개념 96회·안내 72회·프리셋 160회·입력 152회·퀴즈 144회·새로고침 24회다. 전체 페이지 접근성 280상태와 SVG 내부 글씨 최소 16.00px를 확인했다. 모든 조합을 마쳤다.
