# 구조 보존 연구 보강: 장기 위상·관측 시계

2026-11-12. 마지막 두 단원의 한영 원고 네 편에 정확 이차 불변량·장기 위상과 상태별 관측 시계·위상면적을 보강·검증했다. 기존 실습·본문·각 여섯 해설 문제를 보존한다. [해석역학 10원주제·20단원 종합 대조](analytical-mechanics-research-audit.md)에 연결하며 공개 배포 여부는 별도로 확인한다.

## 추가 내용과 적용 조건

- 사차 이산 작용 단원은 별도의 조화 극한 `a=0`에서 Verlet의 정확 이차 불변량, 실제 수정 생성자와 진동수를 유도한다. `0<hω<2`의 양정치성과 `hω=2`의 퇴화·일반 운동량의 선형 성장을 구분한다. 보폭이 줄어도 관측 기간을 `h⁻²`에 비례해 늘리면 에너지 오차 상계는 줄면서 위상 오차는 약 1rad로 남는다. 고정 기간 정련이나 비선형 사차 퍼텐셜의 정확 불변량으로 바꾸어 설명하지 않는다.
- 원의 RATTLE 단원은 정확한 자유 원 궤적을 상태별 양의 시간 간격으로 관측하는 별도 예제를 제공한다. 에너지·각운동량·두 구속을 모두 만족해도 시계를 버린 같은 관측 순서의 사상은 접힐 수 있다. 세 초기점의 같은 최종 각도와 서로 다른 경과 시간을 계산한다. 이는 공통 고정 시간의 Liouville 정리나 초기값 유일성의 실패가 아니다.
- 정칙 RATTLE 계열에 시간을 삽입한 별도 Jacobian과 `h=h(L)`의 정준 예외도 유도한다. 정확 흐름의 접힘 예제와 RATTLE의 근 경계를 혼동하지 않는다. 확장 위상 공간을 사용하는 적응형 방법은 별도 구성이 필요하다.
- 한영 그림 네 개·비교표·실행 Python·각 세 연구 질문을 추가했다. 새 시간 조절기는 기존 고정 보폭 실습의 조작 기능이 아니다.

## 계산·원고 검증

`python3 scripts/learning/verify-structure-research.py --json`은 제품 모듈을 불러오지 않는다. 정확분수 행렬 54경우·불변량 1,944상태, 닫힌 해 1,620상태·수정 생성자 36경우·안정 경계 405상태를 확인했다. 네 장기 위상은 70자리 Decimal 급수로 대조했으며 수백만 번의 실습 적분을 실행했다고 집계하지 않는다.

관측 시계 1,458상태·정칙 RATTLE 제어 108상태·세 초기점의 충돌·누적 시계 12궤적도 확인했다. 이 유한 검산과 본문의 행렬·상계·시계 미분 증명을 구분한다. 실제 실습 함수의 조화 Verlet 불변량과 고정 RATTLE의 단위 행렬식·알려진 위상 오차를 별도 테스트로 연결했다.

한영 표시 수식은 단원별 8개·7개로 같고 Python 네 셀의 출력은 본문 표와 일치했다. 영역 선택 **23파일·390검사**, lint·콘텐츠·빌드·타입·정적 출력 검사를 통과했다. 이전 검토 항목 677개를 그대로 두고 네 편의 검토 해시를 추가하여 681개다.

변경 두 단원을 포함한 **전체 20단원·160화면**을 검사했다. 한영 320·768·1440px 라이트와 1440px 다크, 영어 모바일의 펼친 안내 60개·해설 퀴즈 40개·개념 80선택·저장/완료 20그룹을 확인했다. 페이지 오류·Axe 위반은 0개다. 새 두 단원은 이 중 16화면에 해당하며 독립적인 추가 16검사로 중복 집계하지 않는다.

원고·그림 80개의 고정 해시와 SVG 40개의 원본/출력/실제 제공 바이트, HTML 20개의 출력/실제 제공 바이트를 대조했다. 새 그림 네 개와 한영 모바일 화면 네 개를 직접 검토했다. 빌드 1,893경로·출력 1,888 HTML의 내부 링크·자산·앵커·canonical을 확인했다. [검증 해시와 명령](structure-research-evidence.json)을 따른다. 선택 검사를 전체 저장소 CI 성공으로 표현하지 않는다.
