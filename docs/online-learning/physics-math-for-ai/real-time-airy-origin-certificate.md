# Airy 원점 상수의 적분 경계

2026-11-10. `Ai(0)=1/[3^(2/3)Γ(2/3)]`, `Ai′(0)=−1/[3^(1/3)Γ(1/3)]`에 필요한 상수를 소수 literal 없이 감쌌다. **전체 Airy 함수나 생산 calculator의 완료 증거는 아니다.**

## 양의 Gamma 적분

y=t³를 대입하면 r=1,2에서 `Γ(r/3)=3∫₀∞t^(r−1)e^(−t³)dt`다. 적분 구간을 R=11에서 나눈다. [0,R]에서 exp의 M=5000항 Taylor 다항식을 항별 적분하면

`P_r=3R^r Σ_(k=0)^(M−1) (−R³)^k/[k!(3k+r)]`.

M이 짝수이므로 적분형 Taylor 나머지는 양수이며 `0≤finite remainder≤3R^r (R³)^M/[M!(3M+r)]`다. 이 부등식은 초기 항이 감소해야 한다는 조건을 요구하지 않는다. 정확 정수 비교로 이 상계가2⁻²²⁰⁰보다 작음을 확인한다.

무한 꼬리는 `∫_(R³)^∞ y^(r/3−1)e^(−y)dy≤e^(−R³)`다. R³≥1에서 power factor가1이하이기 때문이다. `Σ₀⁷5^k/k!>128`이므로 e⁵>2⁷, 따라서 `e^(−1331)<2⁻¹⁸⁶²`다. 양의 무한 꼬리도 Gamma 구간의 위 끝점에 더한다.

## 정수 반올림과 근호

작업 척도는2⁴⁰⁹⁶이다. `(R³)^k/k!`의 양의 구간을 recurrence로 운반하고, 각 항 나눗셈과 교대 합에서 바깥 반올림한다. 유한 생략항과 무한 꼬리의 경계를 추가한 뒤 Gamma 양성과 구간 폭을 검사한다. 큰 항들의 상쇄를 정확한 실수 연산이라고 가정하지 않는다.

3의 세제곱근은 정수 Newton과 `a³≤3·2^(3·4096)<(a+1)³`로 감싼다. 양의 구간 곱/역수를 사용해 Ai 원점값을 구하며, 도함수는 역수를 구한 뒤 부호를 뒤집는다. 내부 구간 폭은2⁻¹⁸⁰⁰보다 작다. 체크인 reference는1536bit 격자에 바깥 반올림한 양끝이다.
