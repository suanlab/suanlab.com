# Quantum variational manuscripts: 수학·번역·교육 검토

2026-11-09. `finite-state-rayleigh-energy-variance`와 `nonorthogonal-ritz-subspace-certificates`의 한영 원고4편을 검토했다. 아래 기록은 원고의 범위와 검산이며 실제 reader·Worker·시각화 검증을 뜻하지 않는다.

## 두 원고의 학습 경로

첫 장은 상태 방향과 에너지 지형에서 시작해 정의역·정규화·스펙트럼 가중평균·복소 방향 미분·분산과 잔차·gap 기반 바닥 공간 누출로 이어진다. 영분산의 들뜬 상태와 축퇴 바닥 공간을 구별한다. 두 준위·미소 분산·Gaussian 조화 진동자·제한 ansatz의 영 Jacobian을 설명하고 VQE·Monte Carlo·신경망 연구의 오차를 분리한다.

둘째 장은 물리 평면과 좌표 격자를 구별하고 Gram 양성·일반화 고유값·공간 사영·min–max/interlacing·전체/내부/외부 잔차를 유도한다. 3×2 손계산, 복소 좌표 shear, 정확 rank와 조건수, 연속 문제의 추가 가정, 움직이는 기저의 overlap 미분으로 확장한다.

각 원고는14절·표시 수식12개·비교표2개·풀이6개다. 한영 표시 수식과 문제 번호를 동일하게 유지했다. 영어는각각3039/2893단어, 한국어는각각11352/10560문자다. 영어 원고에 한글이 없으며, 한국어도 단순 개요가 아닌 직접 유도·반례·풀이를 포함한다.

## 수학적으로 확인한 지점

- N=z†z와 켤레 내적을 유지하고, 원시 상태 경로의 이차 미분에 정규화 분모의 미분을 포함했다. z=(1,1), eta=(1,-1)의 정확 경로 몫에서 미분-2/0을 별도 SymPy로 확인했다.
- 분산은 정확 잔차 제곱이고 영분산이 들뜬 상태에서도 성립한다. gap 누출 상한에는 정확 E₀ 또는 인증된 하한과 양의 gap 하한이 필요하다. H=diag(-3,1), z=(2,1)의 누출1/5·분산64/25를 모델과 대조했다. 바닥 상한-2를 잘못 대입하면-1/20을 얻는 반례를 적었다.
- 상수 H의 gap과 영벡터 경로는 정의되지 않음을 설명했다. 연속 스펙트럼 infimum과 실제 바닥 고유상태의 존재를 구별해 유한 사영 공식을 무조건 확장하지 않았다.
- Gaussian의 정규화·운동/퍼텐셜 평균·분산을 독립 적분했다. 가족 내부 최소화만으로 전역 하한을 증명하지 않고 H=ℏω(a†a+1/2)와 최적 Gaussian을 소멸시키는 항등식으로 전체 하한을 설명했다. alpha 두 배의 에너지5/8·분산9/32를 진동자 단위로 검산했다.
- Ritz 평면의 다항식3μ²−8μ+3, 최소(4−√7)/3, 복소 좌표 변경과 물리 상태 보존을 확인했다. H=diag(0,2,4)의 축퇴 Ritz 예제는 내부 분산0·전체/외부 분산8/3으로 Galerkin 정류와 전체 고유상태를 구별한다.
- 포함 관계 없는1차원 바닥 직선과2차원 들뜬 평면은 최소가0에서1로 증가한다. 차원 증가만으로 단조성을 주장하지 않았다. 정확 det B=-1인 거의 평행한 기저는 rank 손실과 조건 문제를 구별한다.
- 움직이는 한 열 B(q)=(1,q)에서 q=1의 올바른 미분1과 overlap 미분을 빼먹은 값2를 독립 미분으로 확인했다. 이 연구 연결을 현재 고정 입력 계산기의 기능이라고 표시하지 않았다.

## 연구 연결과 적용 한계

[Peruzzo 등의 VQE 원 논문](https://arxiv.org/abs/1304.3061)과 [Carleo·Troyer의 신경망 변분 상태](https://arxiv.org/abs/1606.02318)를 연구 진입 자료로 확인했다. 유한 평균의 변분 하한과 유한 표본 추정치를 구별한다. Monte Carlo의 정확 영진폭 집합은 확률0이어서 그 위의 임의 정의가 기대값을 바꾸지 않지만, 노드 근처의 큰 유한 값이나 실패 평가를0으로 대체하면 일반적으로 편향을 만들 수 있음을 명시했다.

부분공간과 양의 metric 관례는 [MIT Ritz/Galerkin 강의](https://ocw.mit.edu/courses/18-335j-introduction-to-numerical-methods-spring-2019/pages/week-7/) 및 [Cornell 일반화 고유값 강의](https://www.cs.cornell.edu/courses/cs6210/2025fa/lec/2025-11-03.html)와 대조했다. 평면 예제와 직접 계산은 원고에서 전개한 것이다. 연속 정의역·경계·quadrature·conforming 공간·비선형 ansatz의 가정을 생략하지 않는다. 신경망·다체·텐서 네트워크·일반 연속 수렴·연구 깊이를 두 유한 실험의 완료 범위로 세지 않는다.

## 실제 검증 범위

`learning-quantum-variational-authoring.test.ts`의21검사가 네 원고를 실제 Markdown/KaTeX로 렌더링하고 표 구조·유일한 절 앵커·한영 수식·해설과 대표 수치 예제를 확인한다. 해석 예제는 `generate-quantum-variational-authoring-references.py`가 별도 SymPy 미분·적분·행렬 항등식으로 확인하며 기준을 재생성해 byte 동일성을 검증한다.

이 검사는 모든 문장의 정리를 자동 증명하는 도구가 아니다. 위 의미·가정 검토와 실행 가능한 대표 예제를 함께 근거로 쓴다. 수치 엔진·입력 계약·기존 원고·사이트 출력은 바꾸지 않았다. 실제 개념 그림·자유 실험·Worker·읽기 화면·접근성 검증은 후속 단계다.
