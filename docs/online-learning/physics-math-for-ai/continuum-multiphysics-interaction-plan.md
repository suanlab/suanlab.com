## 공통 표시와 계산 원칙

`learning-continuum-multiphysics.ts`의 관측은 일반 값·부호·로그를 함께 가진다. 실제0,비영 표현 불가,조건을 만족하지 않는 성능 비를 구분한다. 기존 파랑·주황·초록과 명암 테마를 사용하며 범례·선 형태·표를 함께 제공한다. 물리량의 단위와 실제 체적·면적을 표시한다. 한 방정식으로 만든 잔차를 독립 인증이라고 부르지 않는다.

초기 상태·현재 조회·적분 시간 구간을 구분한다. 실제 미분방정식의 시간 이력과 단순한 설명 애니메이션을 섞지 않는다. 정확한 끝점과 조회점을 표본에 포함하고 작은 변화·꼬리·일반 값 불가를 표와 로그 그림에서 확인할 수 있게 한다.

## 열·탄성 상호 교환

단원 ID는 `thermoelastic-mode-reciprocal-energy-exchange`다. 기본 실습은 밀도1kg/m³,체적 열용량1J/(m³K),기준 온도300K를 고정·명시한다. 일반 계산 모델은 이 물성들도 인자로 받지만 선택한 교재 가족의 고정 조건과 구분한다.

입력12개는 E∈[0.5,4],β∈[0,0.05],κ∈[0,1],k∈[0.25,2],A∈[0.25,4],a0,v0∈[−0.001,0.001],b0∈[−0.02,0.02],조회 시간[0,4],공간 위상[0,2π],적분 시작/끝[0,4]다. 모든 연속 입력은 정밀 입력과 같은 값으로 연결한다. 거꾸로 된 시간 구간은 적분 불가로 표시하되 실제 장은 유지한다.

상호 모델과 역방향 열 항을 생략한 모델을 각각 실제로 푼다. 그림은 다음 순서로 구성한다.

1. 공간 변위·온도 위상과 열팽창·역방향 열 작용의 개념도. 변위m와 온도K를 같은 세로축에 더하지 않는다.
2. 시간에 따른 역학·열 가용 에너지와 합. 전도0에서 두 부분의 교환과 합의 보존을 읽는다.
3. 부호 있는 상호 교환 전력과 비음 전도 소산. 시간창의 실제 교환·소산 적분도 별도 단위J로 제공한다.
4. 두 모델의 다른 궤적과 남는 교환 항. 일방향 근사의 외부 제어·근사 해석을 설명한다.

확장 그림은 온도·변위·속도 진폭 이력,실제 응력·열 플럭스,작은 시간의 생성 온도·2차 속도 변화·3차 누적 소산 로그,빠른 열 감쇠의 비영 꼬리,일반 끝점 뺄셈과 수지 유도 변화 대조다. 실제 셀 길이2π/k와 체적을 표에 표시한다. 가용 에너지와 전체 내부 에너지·누적 열량을 같은 이름으로 표시하지 않는다. 상호 모델의 변형률 상한을 일방향 모델의 보증으로 재사용하지 않는다.

고정 개념4단계는 두 방향의 작용,단열 상호 교환,전도 소산,일방향 누락이다. 안내3개는 β0의 분리,κ0의 교환,초기 온도/속도 부호와 전력 반전이다. 퀴즈2개는 가용 에너지의 의미와 일방향 모델의 수지다.

예제에는 초기 손계산,전도0,결합0,음의 초기 온도,영 초기 상태,작은 시간·최소 시간,작은 진폭·최소 결합,빠른 비영 감쇠 꼬리,영 적분 구간·거꾸로 된 구간,면적 배율,공간 위상0/π/2를 포함한다.

## 열·전기 막대의 포트 수지

단원 ID는 `thermoelectric-bar-seebeck-peltier-joule-balance`다. 입력10개는 L,A∈[0.25,4],r∈[0.01,4],K∈[0.1,4],S∈[−0.05,0.05],TL,TR∈[250,350],지정 전류 밀도j∈[−10,10],기준 전위∈[−4,4],조회 ξ∈[0,1]다. 전위차는 종속 관측이다. 별도의 독립 전압을 동시에 강제하지 않는다.

고정 개념4단계는 손계산 전류·단자 조건,냉각 예제의 Fourier/Peltier 열,국소 jE와 rj²의 차이,발전 상태의 전기 일·경계 열이다. 온도·전위·전기장·세 열 플럭스·국소 전기/Joule 전력·부분 구간 전기 일·끝면 포트를 시각화한다. 온도의 추가 포물선과 전체 온도의 최대를 구분한다. 단일 막대의 결과를 접촉·반환 도선까지 포함한 실제 장치 성능으로 표시하지 않는다.

기준 전위를 바꿀 때 전위 곡선만 평행 이동하며 실제 전력·열 플럭스가 유지되는지 확인한다. 개방회로j0에서는 Fourier 열전도·Seebeck 전압이 남을 수 있음을 보여준다. 양의 왼쪽 열 입력과 양의 전기 입력이 함께 성립할 때만 해당 COP를 제공한다. 발전·영 입력·열 배출·비영 표현 불가의 상태를 구별한다.

안내3개는 개방회로,전류 반전과 냉각/발전 포트,기준 전위의 불변성이다. 퀴즈2개는 경계 법선의 부호와 COP조건이다. 예제에는1V손계산,이상 냉각,발전,전류0,S0,온도차0,전류 반전,작은 전류·최소 전류,최소 S,작은Joule 온도 상승,반올림된 두 열의 상쇄,정확한 양끝·기준 전위 이동·면적 배율을 포함한다.

## 연결 후 확인할 증거

단원2개·고정 개념8단계·안내6개·퀴즈4개·입력22개를 등록하고 입력별 물리 연결과 모든 예제를 검사한다. 기존 단원/안내·실험 데이터의 내용과 순서를 보존한다. 전체 회귀·타입·lint·내용·정적 출력,한영·명암·모바일/데스크톱·키보드·정밀 입력·저장/복원·퀴즈를 확인한다. 원본 그림·주요 수치 표를 수동 검토하고 전체 영어 순회를 통과한 뒤에만 등록 수·입문 검증 수를 올린다. 현재496개 등록·276개 입문 검증을 미리 갱신하지 않는다.
