# 미시·거시 상태 세 실험 패널 기반

2026-11-06. 세 모델의 Worker 계산을 실제 실험 패널·도표·저장·안내에 연결했다. 기존 홈페이지의 색 변수와 학습 컴포넌트 스타일을 사용한다. 격리된 실제 패널 검증 단계이며 단원 등록·개념 단계·퀴즈와 실제 Next 읽기 경로는 아직 남아 있다.

## 세 패널의 내용

이진 패널은 N,K,블록 크기,양의 에너지 간격을 조작한다. 작은 계의 이름 붙은 배치를 열거하고 전체 준비·선택 껍질·껍질 내부의 확률을 나눈다. 큰 모형은 선택 레이블의 확률을 재정규화하지 않고 그리며,전체 껍질과 고정 K 블록의 정확한 계수는 각각32행 페이지 표로 모두 접근할 수 있다. 선택 조건과 단위를 결과에 함께 쓴다.

가중 분할 패널은 준비/목표 가중치와 상태군 사상을 조작한다. 실제 미시분포와 균등 재구성,군 확률·크기·조건부,엔트로피 연쇄와 미시/거시/숨은 KL을 비교한다. 선택 군의 재구성·가중 KL 기여를 따로 보여주며 빈 군·질량0·미정·무한대를 구별한다.

잡음 패널은 준비와 채널 행을 따로 조작하고 K,J,R,선택 출력의 사후를 연결한다. 각 채널 행의 자체 엔트로피와 준비로 가중한 기여도 분리한다. 준비 확률0인 행의 양수 엔트로피를 평균 기여0과 혼동하지 않는다. 모든 정보량은 원래 Worker 결과를 사용한다.

20개 비교 예제와9개 한영 안내를 갖췄다. 확장 JSON 설정은 기존 모델의 전체 계산 범위까지 지원하며 잘못된 정규화·범위·정수를 임의로 보정하지 않는다. 계산 중에는 이전 결과를 새 조건의 결과로 보여주지 않는다.

## 저장·중단·비교

검증한 입력만 브라우저에 저장하고,저장값 오류나 저장 차단에서도 유효 기본 설정으로 읽기·조작을 계속한다. 입력 변경은120ms 동안 모은 뒤 Worker로 보낸다. 대기 중 중단도 예약 실행을 취소하며 재시도로 다시 계산할 수 있다.

자동 순회는 현재 예제의 계산 완료 뒤 다음 예제를 선택한다. 물리 시간·완화·적분이 아니다. 전역 일시정지·모션 감소·실제 화면 밖 이동에서 자동 순회를 멈추며 수동 단계는 유지한다. 변경/중단/단원 전환은 긴 계산을 끝까지 기다리는 대기열을 만들지 않는다.

세 가족의 코드 기반 장식 표지도 추가했다. 이진 여섯 배치,가중 관측과 균등 재구성,균등 입력·지워짐1/4의 모티프다. 공통 색 변수를 사용하고 정량 실험이나 필수 설명을 장식 이미지로 대체하지 않는다. 표지는 아직 도서 목록 dispatch에 연결하지 않았다.

## 검증과 화면 확인

20개 예제를 두 언어로 렌더링하는40개 검사와 설정/표시 성질4개,표지3개를 작성했다. 기존 모델·본문·Worker와 합친298개 검사가 통과했고 타입·대상 lint도 통과했다. 도표의 NaN/Infinity,접근성 속성,영어 한글 혼입,범위 밖 양수와 실제0·미정·무한대,일반N의 전수 열거 방지를 확인한다.

`check-micro-macro-panels.mjs`는 실제 webpack 자산과 기존 정적 출력의 CSS로 세 패널을 실행한다.20예제×한영×명암×320/1440px의160조합에서 패널 전체 axe 위반,페이지 가로 넘침,영어 한글 혼입,비정상 SVG 값이0이었다. 이는 실제 홈페이지 경로가 아니라 격리된 패널 검사다.

`check-micro-macro-panel-interactions.mjs`는9개 안내의 실제 예제 로딩,가족별 저장/재로드·잘못된 저장값 복구,문법/수치가 잘못된 JSON의 적용 거부와 이전 설정 보존,큰 계수 두 표의 다음 페이지,빈 군·질량0 군·확률0 출력의 선택을 확인한다. 입력 대기 중 중단으로 새 Worker가 생성되지 않음도 확인했다.

16×16 극한 입력의 실제 계산 시작 뒤 언어·화면 전환과 작업 교체,재시도와 전체 계산 완료,전역 일시정지·모션 감소·수동 단계·실제 offscreen 정지,저장 차단을 검증했다. 최종 페이지 구간의 Worker 시작/종료 수가 같고 남은 Worker와 런타임 예외는0이다. 모바일 한글 밝은 화면과 데스크톱 영어 어두운 화면도 캡처해 직접 확인했다. 격리 서버는 UTF-8로 제공하며 기존 홈페이지4175 서버는 변경하지 않았다.
