# Fourier optics 연구 보강 검증

2026-11-13. 두 단원 한영 네 편에 제어 기준광·광동공 모호성·보정 위상 다양성을 보강했다. 기존 본문·여섯 해설 문제·실습 제어를 보존하며 새 위상 복원·잡음 제어를 구현했다고 표현하지 않는다. 파동 순차 연구 대조는 **16/18단원**이고 전체 영역 완료가 아니다. 전체 대조 **40영역·396주제**, 후속 **11영역·113주제**를 유지한다.

## 보강 내용

- `coherent-fourier-pupil-spatial-filtering`: 네 기준 위상 읽음에서 복소 교차항을 복원하고 기준 파워의 두 근·기준광 단독 보정의 필요성을 설명했다. 알려진 비영 기준에 대한 전달 비율, 읽음 오차 연산자 상계·분산, 상대 기준 위상 오프셋과 차단 기준의 한계를 유도했다. 실제 영상 밀도와 축소 좌표 강도의 비율은 일관된 보정에서 같은 결과를 준다. 공통 위상·상대 위상·입력 계수·스펙트럼 표본을 구분한다.
- `incoherent-psf-otf-image-formation`: 광동공의 켤레 반사가 전체 PSF·복소 OTF·투과율·모든 해당 비결맞은 영상을 보존함을 증명했다. 기존 위상 정의 q*(nu/fc)^2+b*nu/fc에서 q와 −q가 모호하다. 제어 결맞은 준비는 다른 정보를 측정한다. 열린 광동공의 알려진 추가 이차 위상으로 제한된 두 후보를 구분하는 전달식과 sinc 나머지 상계를 유도했다. 임의 광동공의 전체 유일성이나 잡음 안정성 정리로 확대하지 않는다.

한영 수식은 단원별 8개씩, 실행 Python 셀·수치 표는 언어 간 동일하다. 원고마다 연구 질문 세 개를 추가했다. 기존 홈페이지의 파랑·주황·회색 SVG 네 개의 원본과 최종 모바일 화면 네 개를 확인했다.

## 독립 계산과 기존 계산기 대조

선택 4파일 **54검사**, 집중 보강·보존 **12검사**, lint·콘텐츠·빌드·타입·**1,888 HTML** 정적 검증을 통과했다. 전체 등록 **650단원·1,969안내**, URL 1,885개를 유지한다.

표준 라이브러리 독립 계산으로 위상 변경 72계열/288읽음·읽음 오차 상계 576개·비율 오차 상계 432개·위상 보정 216개·독립 잡음 16조합·기준 파워 모호성 세 개를 확인했다. 광동공 켤레 대응 60개·PSF/OTF 모호성 각 60개·열린 광동공 적분 72개·다양성 나머지 상계 및 비영 차이 인증 각 36개를 대조했다.

기존 계산기에서 기준광 취득 64계열/384계산을 확인했다. 각 계열은 네 위상 읽음에 대조용 기준광·신호 단독 계산을 더한 범위이며, 실제 설명 절차는 네 읽음과 독립 기준 보정이다. 차단 기준 네 읽음·단독 보정 하나도 확인했다. 광동공 16계열의 PSF 64쌍·OTF 80쌍, 전체 비결맞은 영상 네 쌍, 다양성 전달 24쌍과 제어 결맞은 구분 두 노출도 확인했다. 새 취득 절차가 기존 UI 제어로 구현되었다는 뜻은 아니다.

초기에는 기존 검사 네 건이 모든 H3를 연습문제로 세어 추가 설명 절에서 실패했다. 기존 수치 검사와 통합 검사는 그대로 유지했고, 독자 검사에서 원래 H3 여섯 개+연구 H3 다섯 개=열한 개, 원래 H2 열여섯 개+연구 H2 한 개=열일곱 개를 각각 정확히 확인하도록 보완했다. 원래 본문 전체 해시 검사는 유지한다.

## 화면과 보존 검증

최종 빌드에서 변경 두 단원의 한영 **16화면**(밝은 테마 320/768/1440px·어두운 테마 1440px), 영어 320px의 **6안내·4해설 퀴즈·8개념 선택·2저장/완료 그룹**을 검증했다. 페이지 오류·Axe 위반은 없다. 선택 언어 그림의 로드·목차·키보드 가로 스크롤·실습 제어를 확인했다. 이 수를 전체 영역의 최종 화면 검사로 합산하지 않는다.

추가 절을 제거하면 기존 네 본문 바이트가 복원된다. 다른 파동 원고 32편·기존 검토 709항목·이전 일곱 배치 원고/그림 56해시를 보존했다. 검토 기록은 713항목이다. 고정한 원고/그림 여덟 입력, 원본·내보내기·서빙 SVG 네 쌍과 HTML 두 쌍을 대조했다. 기존 상세 강의·해설·선수 순서·등록 데이터를 유지한다.
