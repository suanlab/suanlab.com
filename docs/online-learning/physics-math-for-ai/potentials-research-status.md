# 전위·벡터 퍼텐셜 연구 보강 검증

2026-11-13. 전위·일과 벡터 퍼텐셜 두 단원의 한영 네 원고에 불확실성 있는 전위차 복원과 주기 표현의 평균 선속 장애를 추가했다. 기존 본문·각 여섯 해설 문제·실습 입력을 보존한다. 전자기학 순차 보강은 **6/20단원**이며 영역 전체 대조는 후속이다.

## 원고·논증·직관

- `electrostatic-potential-reference-path-work`: A→B→C→A의 세 방향 전위차와 기준을 고정한 두 상대 절점 전위를 정의한다. 알려진 독립 분산의 제약 가중 최소제곱을 Lagrange 승수로 풀고 사영·가중 정규 방정식·잔차 최솟값을 검증한다. 기준 이동과 계측기 오프셋, 역공분산 계량과 Euclidean 계량을 구분한다. 공분산 전파와 두 독립 경로의 역분산 평균으로 같은 복원을 설명하며, 공통 확률 오프셋의 상관 예제도 다룬다. 잡음 순환만으로 유도·비보존 장을 단정하지 않는다.
- `magnetic-vector-potential-curl-gauge`: 매끄러운 전역 주기 A를 갖는 셀의 평균 curl·기본 면 선속이 0임을 적분으로 증명한다. 상수 B의 한 면 선속과 전체 닫힌 선속을 구분해 자기 단극자와 혼동하지 않는다. 비영 Fourier 모드의 Coulomb 역변환, 상수 A와 주기 게이지의 다른 자유도, 코사인 요동+아핀 배경의 정확한 장을 유도한다. 주기 퍼텐셜만 사용하는 모형의 셀 적분 제곱 오차 하한은 평균 B의 제곱이다. 유한 표본 손실에는 그대로 적용하지 않으며 양자 관측이나 MHD 시간 발전을 주장하지 않는다.
- 한영 원고마다 **8표시 수식·1표·1실행 Python 셀·3해설 연구 질문**과 언어별 그림을 추가했다. 삼각형 전압·분산별 보정·추정 표준편차, 주기 장과 누락된 평균·퍼텐셜 점프·최소 RMS/면 선속을 기존 청색·주황·회색으로 비교한다. 퍼텐셜 단면 그림의 미분 하나가 전체 curl을 대신하지 않는 이유도 설명한다.

새 추정기·주기 셀은 보충 모형이다. 기존 이차 전위와 무한 원통의 새 제어 기능으로 표시하지 않는다. 분산은 별도 보정/측정 가정이며 세 잔차로 추론하거나 한 실현의 가중치를 바꿔 정확도가 좋아졌다고 집계하지 않는다.
