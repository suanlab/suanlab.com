## 구현한 모형

[모형 계약](euclidean-kernels-model-contract.md)의8소유 필드·N2…32·12자리 분수·양/비음/부호 경계를 유지한다.20예제에 자유·강한 구속·양끝 반전·같은/반대 끝점·질량/ℏ/시간 변경·분수·최소 양수·최대/서로 다른 분모를 포함한다. 원래 입력 표기를 보존하고 getter를 호출하지 않고 자체 필드를 복사한다.

생산 계산기는 행렬식 점화식과 닫힌 역행렬을 사용한다. 전체 정밀도·양끝 포함 공분산·평균·LDLᵀ·최소 작용·정규화 커널 계수·오른쪽 분할 보정·유한/발산 trace·끝점 적분·기대 작용 분해를 반환한다. N,2N,4N,8N의 같은 물리 시각과 커널/trace를 비교하며 최초 행만 전체 행렬 계산이다.

공분산의 정확분수를 첫 등장 순서로 등록하고128개씩 묶어 인덱스 행렬로 전송한다.33×33 전체 항목을 유지하며 소수 반올림이나 행렬 축소를 하지 않는다. 기존 wire 한도도 바꾸지 않았다. 입력 한도를 낮춰 최대 검사를 통과시키는 방식은 사용하지 않는다.

## 독립 검산과 기준

독립 검산은 다른 유리수 산술,간선 발생 행렬·LDL 소거·삼각 연립방정식을 사용한다. 정련은 Gaussian 커널 적분 합성으로 계산한다. 생산 점화식·닫힌 역행렬·생산 산술을 runtime에서 가져오지 않는 것을 번들 그래프로 확인한다. 후보 분수는 산술 피연산자로 파싱하지 않고, 소유 입력으로 재구성한 전체 예상값과 대조한다. 승인 응답은 깊게 동결한 소유 복사이며 캐시는4입력으로 제한한다.

별도 표준 Python 기준은 발생 행렬·Gauss–Jordan·주기 사슬 행렬식·Gaussian 합성을 사용한다. TypeScript 수치 모듈을 실행하지 않는다.20예제와31개 일반 분수 격자 sweep,총51입력의 전체 결과를 대조한다. 최대256구간의 정확 계수를 문자열로 출력하기 위해 Python 정수 변환 한도를 명시적으로65536자리로 설정하며 제한 자체를 없애지 않는다.

- 관련120검사는 Node.js20/24에서 모두 통과했다. 한영 원고/실습과 전체51생산 결과·51독립 응답 검산을 포함한다. 두 버전의 실행 로그를 따로 보존한다.

- getter·cycle·prototype·symbol·sparse array·과대 문자열/배열을 거부한다. 같은 수의 다른 분수 표기·원래 입력 귀속·필드 누락/추가·그럴듯한 인증값 변경도 거부한다. requestId/version/kind의 Worker 응답 귀속은 다음 단계다.

- 고정끝 자유 법칙은 앞 Brownian bridge와 대조했다. N2 두 끝 forcing,질량/ℏ의 서로 다른 정확한 scaling,원점 구속에 따른 분산 감소,반전 대칭,명시적 정련 행렬 비교와 주변분포의 비불변성을 확인했다. TypeScript·ESLint도 통과했다.
