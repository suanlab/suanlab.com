## 구현 계약

`src/lib/learning-stationary-cycle.ts`는 이름 붙인 세 상태에서 시계·반시계·머무름 정수 가중치를 정규화한다. 각 가중치는0..1,000,000이며 합은 양수다. 초기 가중치도 같은 범위의 길이3 배열이고 영합·희소 배열을 거부한다. 전이 횟수는0..512다. 입력을 변경하지 않고 정규화된 필드와 초기 배열을 별도로 동결한다.

모든 확률·흐름·전류·유한 분포·편차·총변동·수축 상계는 BigInt 유리수다. `learning-finite-markov-exact.ts`는 공약수로 줄인 양의 분모와 동일한 유리수 양 끝을 제공한다. 소수와 크기의 로그는 표시 투영이며 정확한 유리수·부호와 구별한다. 비영 표시 범위 밖의 값은 `value:null`과 비영 부호·정확한 경계를 유지한다. 적응 정밀도 상한을 흉내 낸 상태나 가짜 정밀도 설정은 없다.

균일 정상 참조의 흐름과 현재 준비의 흐름을 따로 반환한다. 현재 순유출은 현재 분포에서 다음 분포를 뺀 값이다. 항등 전이에서는 정상분포 전체의 가족을, 머무름 없는 단방향 전이에서는 주기3을 구별한다. 양방향 이동이 있는 세 고리는 머무름이 없어도 귀환2·3으로 비주기적이다. 시간 반전은 균일 정상 준비에서의 전치이며 물리적 속도 반전으로 확장하지 않는다.

## 본문과 직접 유도

한영 각각16절·18수식·표2개·해설 문제6개다. 수위와 순환의 직관, 출발 행/도착 열, 실제 분포의 반복 계산, 정상해의 최대원리 증명, 흐름·발산·쌍별 상세평형, 정상 경로의 반전, 주기·가약성, 총변동과 행 거리의 수축 상계를 설명한다. 일반 정의와 수렴 정리는 [저자 공개 교재](https://pages.uoregon.edu/dlevin/MARKOV/markovmixing.pdf)의1.5–1.6·4.3절과 대조하며, 구체적인 모형·손계산·증명은 이 프로젝트의 유도다.

f=s=1,000,000,b=999,999의 정확한 편차도 유도했다. 확률들이 모두 반올림된1/3으로 보이고 선형 총변동이 표시 범위 밖이어도, 현재 준비가 정확히 정상이라는 잘못된 결론을 내리지 않는다. 모델과 본문 검사에서 이 경계를 확인했다. 세부 유도는 [별도 노트](stationary-cycle-derivation-notes.md)에 정리했다.
