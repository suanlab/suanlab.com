# 파동·진동·음향·광학 입문 영역 종합 점검

점검일: 2026-11-05. 원래 9개 주제에 대응하는 18개 단원과 한영 원고 36개를 대조한다. 개별 주제의 과거 통과 기록과 이번 전체 영역 점검을 구분한다. 같은 최종 빌드의 수치·화면·상호작용 검증을 마쳐 입문 영역 종합 점검을 통과했다. 연구 심화 완료는 아니다.

## 범위와 연결

[점검 계획의 대응표](waves-optics-domain-audit-plan.md)에 따라 조화진동·공진, 결합 정상모드, 파동 방정식, 간섭·회절, 분산·군속도, 편광, 기하·파동 광학, Fourier optics, 관측·샘플링·센서를 확인했다. 18개 단원에는 개념 단계 72개, 안내 실험 54개, 예제 200개와 퀴즈 36개가 있다. 선수 단원이 실제 등록되어 앞에 위치하는지, 목차와 이전·다음 링크가 등록 순서에 맞는지 검사한다.

## 물리·수학 검토와 수정

- 강제 진동의 유한 초기값 해와 발산하는 주기 특수해를 구분한다. 일·열의 수치 적분 잔차는 엄밀한 오차 보증으로 제시하지 않는다.
- 질량 내적 정상모드, 영모드의 이동, 연결 스프링 에너지와 부호 있는 국소 흐름을 확인했다. 맥놀이 포락선의 교환이 에너지 전량 교환을 뜻하지 않는다.
- 격자에서 연속체로 갈 때 질량·강성의 스케일을 함께 바꾼다. 초기 변위와 속도의 반사, 전체 에너지와 관측 창 에너지를 구분한다.
- 간섭의 장 평균·강도 평균·유한 노출 평균을 구분한다. Fresnel 근사의 물리적 유효성과 구적 해상도 차이를 별도로 표시한다.
- **작은 파수 처리 오류를 수정했다.** 기존 국소 위상 기울기 절댓값 기준은 유한한 속도를 숨겼다. 이제 정확한 0만 따로 처리하며 유한 비율, 영장, 영기울기, 부동소수점 범위 초과를 구분한다. 예를 들어 파수 10⁻¹³ rad/m와 각주파수 8 rad/s의 비율은 8×10¹³ m/s다. 이는 정보·에너지 전달 속도의 주장이 아니다. 순수 모델·실험 연결 회귀 테스트 3개와 한영 설명을 추가했다.
- 편광의 시간 위상 관례와 Stokes 부호, 양의 coherency 행렬과 실제 6개 분석기 관측을 대조했다.
- 실제 센서와 상면, 정확한 초점 특이점과 인접한 유한 상, Gaussian 빔의 2차원 적분을 구분했다.
- coherent 장 합과 incoherent 강도 합, 원래 투과량과 조건부 PSF 정규화, 복소 OTF의 부호를 확인했다.
- 픽셀 간격·감광 폭·노출 시간, 수집량과 정규화 평균을 구분한다. 광자·전자·저장 포화·읽기 잡음·이득·양자화·ADC 순서와 rail 점유/실제 clipping 차이를 확인했다.

독립 기준 생성기의 출처·방법을 읽고 전용 테스트와 대조했다. 한영 표시 수식은 언어별 202개이며, 구두점·동일한 조건의 본문/수식 배치·단위 번역 차이를 직접 확인했다. 안내 실험 해설 54개와 퀴즈 36개도 읽고 수치와 해설을 비교했다.

## 실행 근거

수정 후 파동 전용 343개·전체 3,811개 테스트, 타입 검사, lint, 콘텐츠 검사(1,694 URL), 정적 빌드(1,702 페이지)와 출력 검사(1,697 HTML)가 실제 종료 코드 0으로 통과했다. 소스 2,895개와 정적 출력 4,135개의 해시를 고정해 같은 빌드를 점검한다.

현재 원본 SVG 갤러리 36개·패널 394개, 모바일 키보드 이동 394건의 자동 검사가 통과했다. 갤러리 전체와 한영을 번갈아 선택한 대표 안내 화면 18개를 직접 열어 확인했다. 최종 기본·보완 브라우저 검사는 한영 × 320/1,440px × 명암의 모든 8조합에서 총144개 기본 상태·432개 펼친 안내를 통과했다. 400개 예제 적용, 36개 단원/언어 상호작용 그룹에서 입력 정밀 저장·새로고침·오답/정답·완료 저장·초기화를 확인했다. 목차·선수·이전/다음 링크, WCAG axe 검사, 그림 레이블 범위와 화면 넘침도 통과했다. 기본/보완 검사의 모바일 그림 키보드 이동은 총788건이며 원본 캡처 검사의394건과 구분한다. 영어 전체544경로·602상태에서 잔존 한글이 없었다. 모든 검사의 실제 종료 코드는0이다.

재현 근거는 `.runtime/learning/waves-domain/`의 소스·출력 해시, 수식 비교, 교안 검토, 원본 이미지와 브라우저 보고서 및 `waves-domain-*-exit.json`이다. 수정 전 증거는 별도 `waves-domain-before-crest-gradient-fix/`에 보존하며 현재 통과 근거로 사용하지 않는다.
