# 난류·폐쇄 연구 보강 검증 기록

2026-11-13. [설계](continuum-turbulence-research-plan.md)에 따라 실제 요동 외력 일과 중첩 Gaussian 응력·전달을 기존 두 단원에 추가했다. 한영 원고 4편·그림 4개, 표시 수식 40개·실행 표 4개·연구 해설 12개를 연결했다. 보충 절 제거로 원래 본문 4편과 풀이 24개를 원래 해시로 복원했다. 기존 실습·등록 순서는 보존했다.

## 추가한 설명

- **Reynolds:** 기존 실습이 미검증으로 남긴 요동 외력 일 예산을 보충한다. 실제 속도·외력 두 성분과 구배 적분으로 평균·요동·전체 전력을 대조한다. 전달과 소산, 음의 요동 외력 일, 영 점성과 비대칭의 대조를 구분한다. 정상 제조 앙상블을 시간 발전 난류로 소개하지 않는다.
- **Gaussian:** 표준편차 제곱합과 두 필터 응력 항등식을 유도한다. 양의 분산 분해와 공통 거친 구배에서의 전달 분해를 설명하고, 기존 전달을 필터하면 거친 전달과 달라지는 정확한 평균 반례를 제시한다. 영 폭·속도 오프셋과 기존 유한 모드 역연산 범위를 유지한다.

## 검증 결과

관련 8파일 **220검사**, lint·콘텐츠·생산 빌드·타입·정적 출력 검사를 통과했다. 1,893경로를 생성하고 1,888 HTML을 검사했다. 소스/도구 5,349파일과 이전 연구 입력 224개를 고정했다. 보존 장부는 기존 793항목을 유지하고 새 4항목을 추가해 797개다.

독립 표준 라이브러리 검산은 실제 여덟 위상 외력 예산 36사례, 그중 음의 요동 외력 일 6사례, 정확한 영 점성 소산 12대조, 직접 중첩 Gaussian 적분 60사례·영 폭 6가족과 정확한 유리수 전달 반례를 포함한다. Gaussian 적분은 [-9,9]의 96절점 구적이며 이 유계 sine 가족의 생략 정규 꼬리 확률은 3×10⁻¹⁹ 미만이다. 유한 구적은 해석적 항등식이나 일반 LES 인증을 대신하지 않는다.

같은 새 출력과 실제 제공 파일을 대조했다. 한영·320/768/1440px·명암 **16화면**, 안내 6개·퀴즈 4개·개념 8개·저장/완료 2흐름을 확인했다. 페이지 오류·접근성 위반은 0이다. 최종 모바일 캡처 4개와 원본 크기 그림 4개를 직접 검토했다. [검증 JSON](continuum-turbulence-research-evidence.json)에 근거를 연결했다. 로컬 검증은 공개 배포 성공을 뜻하지 않는다.
