# 유한 분포 상대 엔트로피: Helmholtz–KL 가족의 계산 기반

2026-11-06. `learning-relative-entropy.ts`는 유한한 양의 목표 가중치와 음이 아닌 시도 가중치로 정의한 분포를 비교한다. 교재 단원으로 등록되지 않았고, 고정 Hamiltonian의 정준 분포 생성기나 실제 완화 동역학은 아직 구현하지 않았다. 전체 가족의 완료나 새 주제 검증 수로 세지 않는다.

## 정규화와 양의 차이

입력은 최대32개 미시상태의 binary64 가중치다. W=Σw, V=Σv에 대해 pᵢ=wᵢ/W, qᵢ=vᵢ/V를 정한다. 합이 숫자 범위를 넘어가도 정규화는 정수 계수와 이진 지수의 정확한 유리수 연산으로 유지한다. 목표 가중치는 모두 양수여야 한다. pᵢ=0은 허용하고 0 ln0=0의 연속 확장을 쓴다.

정규화 때문에 Σ(pᵢ−qᵢ)=0이므로

D(p∥q)=Σ[pᵢ ln(pᵢ/qᵢ)−pᵢ+qᵢ].

각 항은 f(x)=x ln x의 볼록 나머지다. p=0에서는 q, p=q에서는 정확히0이다. 그 외에는 양수이며 전체가0인 조건은 모든 정규화 확률의 정확한 일치다. 두 분포의 표시값이 같아졌다고 평형으로 판정하지 않는다.

δ=(p−q)/q가 작을 때 항은 qδ²g(δ)이며 g(δ)=Σₖ≥₀(−δ)ᵏ/[(k+1)(k+2)]이다. |δ|≤1/8을 정확한 유리수 비교로 선택하고 k=32까지 계산한다. 생략한 꼬리는2×10⁻³³보다 작지만, 이는 binary64 평가 오차나 모든 초월함수의 정확한 반올림을 보장하지 않는다. 먼 영역은 정의식으로 계산한다. 음수 결과를0으로 자르는 보정이나 평형 epsilon을 쓰지 않는다.

## 표시와 단위

반환값은 값·부호·로그 크기를 포함한다. 양수가 숫자 범위 밖이면 값은 null이며 부호와 로그 증거를 보존한다. 거의1인 확률의 로그는 정규화 전 차이와 log1p로 계산한다. 극소수의 반올림된 확률에서 로그를 다시 구하지 않는다.

엔트로피 H(p), H(q), 교차 엔트로피와 KL을 반환한다. 이들은 자연로그의 무차원량이다. 물리적인 S=kB H 또는 자유 에너지 차이의 단위와 복제 수는 호출자가 지정해야 한다. 이름 붙인 배율은 최대8개의 음이 아닌 유한 인자로 받고, 원래 유리수 결과에 곱한 후 표시한다. 중간 곱의 overflow/underflow 때문에 표현 가능한 최종값을 잃지 않는다.

## 열역학과 연결할 조건

고정 에너지 Eᵢ와 T>0에 대한 정준 분포 πᵢ=exp(−Eᵢ/kBT)/Z일 때에만 F[p]−Feq=kBT D(p∥π)로 연결한다. 임의의 목표 가중치를 정규화하는 현재 함수 자체는 q=π를 증명하지 않는다.

한 온도 T₀에서 Eᵢ=C−kBT₀ ln vᵢ를 정의하면 q=v/V가 정준 분포다. 같은 에너지를 유지하고 온도를 바꾸면 가중치는 vᵢ^(T₀/T)에 비례한다. v/V를 계속 쓰는 방식으로 온도 제어를 구현해서는 안 된다. 가중치가 정확히 표현 가능한 이 특수 사례로 일반 고정 Hamiltonian 범위를 대체하지 않는다.

## 검증과 남은 순서

독립 Python 참조는 Fraction 정규화, mpmath160/1000자리 계산과 양의 곡률 적분을 사용한다. 생산 다항식을 복사하지 않는다. 일반24개·극한20개를 비교하며,4개는 한 기준 온도의 가중치 정의 스펙트럼에서 열역학 항등식을 검사한다. binary64 투영 분류는80자리 문자열로 줄이기 전에 저장한다. 그렇지 않으면 반올림 경계의 방향이 사라질 수 있다.

`npx tsx --test scripts/learning-relative-entropy.test.ts`로 실행한다. 추가 검사는 순열·상태 분할·비례 정규화·방향성·희소 입력 거부·극소 확률·배율·직렬화를 다룬다. 근거는 `.runtime/learning/relative-entropy-kernel-verification.json`에 기록한다.
