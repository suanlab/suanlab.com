# 오류 정정·주요화와 얽힘 자원 기반

2026-11-09. 양자정보 순서7·8의 한영 원고4개, 반복 코드/Knill–Laflamme·주요화·Bell 희석 계산기를 추가했다. **8/9단원의 본문·수치 기반**을 준비했으며 실제 교재 등록을 완료한 수치가 아니다.

## 상세 본문과 실제 계산

두 단원은 언어별10절·해설 문제6개다. 오류 정정 장은 parity 측정의 논리 coherence 보존, 복소 입력의 복구, 모든 오류 쌍의 Knill–Laflamme 조건, 위상 오류와 이중 반전의 실패, 퇴화 오류 가족, IID 논리 채널과 참조계 기준을 설명한다.

주요화 장은 Schmidt 진폭과 확률, 내림차순 누적합의 방향, 엔트로피로 판정할 수 없는 비교 불가능 쌍, 양방향 Vidal 꼬리합 성공률과 rank 장애를 설명한다. Bell 쌍에서 `(4|00>+3|11>)/5`로 가는 실제 두 결과 국소 측정·고전 통신·조건부 보정을 구성했다.

## 수치 계약

- 반복 코드는8차원에 직접 구성한2차원 등거리 부호화다. 임의8차원 밀도행렬의 PSD 검사 지원을 추가한 것은 아니다. 입력은 기존 정확 복소 벡터 검사를 거친다.
- 세 site의 모든 I/X/Y/Z Pauli 단어와 syndrome별 복구를 계산한다. 확률0의 조건부 상태는 null이다. 특정 Pauli 오류와 IID X-noise의 평균 채널을 분리한다.
- 선택한 최대16오류 연산자 가족의 모든 압축 교차 항 `V†Ea†EbV`를 검사한다. 통과한 임의 가족에 대한 일반 복구기를 합성한다고 주장하지 않는다.
- 여덟 X 오류 마스크에서 논리 채널·정규화 Choi·입력 제곱 충실도·얽힘 충실도를 계산한다. 고정 다수결 복호이므로 모든 잡음 매개변수에서 최적인 복호기는 아니다.
- 주요화는1–16개의 정확 유리수 Schmidt 확률을 검사하고, 정렬 순서·0 채움·모든 누적합과 꼬리합을 반환한다. 반올림 값으로 전환을 판정하지 않는다. 목표 꼬리합0은 비율에서 제외한다.
- Bell 희석은 비음수 유리 진폭 a,b와 a²+b²=1인 명시적 LOCC 가족이다. 일반 Nielsen/Vidal 프로토콜 합성기는 아니다. 엔트로피는 기존256bit 방향 로그로 계산하며 전환 판정에 쓰지 않는다.

## 독립 참조와 검사

독립 SymPy 조밀 행렬은 **104개 Pauli/입력 사례**(복소 입력 하나에서는64개 Pauli 전부), **24개 IID 잡음/입력**, **11개 KL 오류 가족**의 전체 행렬·가지 연산자·교차 항을 제공한다. 입력별 상태 충실도만이 아니라 참조와의 Choi 채널도 대조한다.

주요화 **100쌍**의 결정론적 전환은 제품의 누적합 조건 대신, 목표 벡터 순열들의 볼록 껍질에 출발 벡터가 포함되는지 정확 유리수 선형계로 검사한다. Vidal 확률은 해당 정리의 꼬리비를 별도로 대조하고, 엔트로피 참조는130자리 mpmath 수치값이다. 이를 일반 LOCC 프로토콜의 직접 실행 또는 엄밀한 초월함수 참조 구간 증명으로 과장하지 않는다.

새250검사는 영 꼬리합·길이가 다른/미정렬 입력·작은 정확 누적합 위반·복소 coherence·퇴화 가족·불가능한 조건부 가지와 한영 strict KaTeX/표 렌더링을 포함한다. Bell 희석은 측정 완비성·각 확률1/2·두 보정 상태의 동일성을 검사한다. 이전 정보/프로토콜/회로/채널 회귀·타입·lint·참조 재생성·기존 소스와 출력 보존은 `.runtime/learning/quantum-information-resources/verification.json`에 기록한다.
