# 매질·경계의 계산 모델과 상세 한영 원고

2026-11-05 기초 집필 단계의 기록이다. 이후 [홈페이지 통합 검증](material-interfaces-authoring-status.md)을 마쳤으며 아래 미등록 수치는 당시 기준이다.

자유·분극 전하의 정전 경계와 임피던스에 따른 수직 입사 반사·투과를 집필했다. 계산 모델과 원고 검증 단계이며 화면·조작·안내·퀴즈·등록은 다음 순서다. 등록472개 한영 단원·안내1,416개, 원래264개 입문 검증·98개 미완료를 유지한다. 전자기학은6/10개 입문 주제 검증, 전체51영역509주제·연구 심화는 미완료다.

원고4개는 단원별16/17개 절, 언어별 표시 수식18개·풀이12문제다. 영어 본문은 약1,520/1,610단어다. 직관·가정·단위·방향·유도·손계산·표·실패 반례·AI 경계 잔차를 포함한다. 양의 계수의 등방성·선형·정지한 평면 매질이라는 가정을 밝히며 일반 손실·분산·이방성·코팅·유한 장치까지 해결했다고 주장하지 않는다.

## 순수 계산 모형

`src/lib/learning-material-interfaces.ts`는 데이터·파일·AI 의존성이 없는 모형이다. 기존 Maxwell 계수와 일관된 SI 기준을 사용한다. API는 `dielectricInterfaceState`, `dielectricInterfaceMeasures`, `normalInterfaceCoefficients`, `normalInterfaceState`다.

정전 모형은 매질1의 법선 D, 자유 표면 전하, 공통 접선 E로 양쪽 장을 정한다. D 점프는 자유 전하, ε₀E 점프는 자유·분극 전하의 합이다. 법선은 매질1에서2로 향하는+z다. 전위의 공통 기준과 접선 불일치의 x 의존 점프를 구분한다. 경계점에서는 평균 장을 만들지 않고 양쪽 극한만 제공한다.

법선 E를 같게 강제하면 필요한 자유 전하가 달라질 수 있다. 요청한 전하와 일치할 때는 유효하므로 무조건 물리적으로 불가능하다고 처리하지 않는다. 보상 곱 전개로 원천 조건을 비교하며 표현이 충분하지 않으면 적합성을 사용 불가로 보고한다. 작은 원천·매질 점프는 공통 배경을 먼저 소거하고 반올림한 면 값 차감과 별도로 표시한다. 양쪽이 진공이면 비영 자유 전하가 있어도 분극 전하는 정확히0이다.

고정 상자의 위·아래 법선은 바깥쪽, x-z 루프의 법선은−y다. 높이가 정확히0이면 붕괴한 측정과 양쪽 극한을 구분하고 측정값·꼭짓점을 임의로 만들지 않는다. 면적0의 적분과 면적당 정규화 미정도 구분한다. 유한 범위를 벗어난 입력은 자르지 않고 거부한다.

파동은 일정 양의 ε·μ의 임피던스와 공통 주파수를 사용한다. 반사 H는 진행 방향 때문에 음의 부호를 가진다. μ가 다르면 접선 H가 같아도 접선 B는 다를 수 있다. R=r²와 T=(Z₁/Z₂)τ²를 구분하며 τ>1이 에너지 생성이라는 오해를 막는다. 임피던스 일치와 파동 속도 일치도 다르다.

반사를0·투과 진폭을1로 강제한 대조에서는 E가 맞아도 H가 달라 표면 전류가 필요할 수 있다. 시트가 없다는 요청에 불일치하는 것이며 시트를 명시적으로 공급하면 경계 일률 차이를 설명할 수 있다. 실제 강제 출력·호환 기준과 원천의 흡수·공급 부호를 분리한다.

일곱 고정밀 계수 기준에는 직접 제곱근이나 곱 차감이0으로 만드는 r≈10⁻³² 사례가 있다. 보상 곱 산술과 유리화한 식으로 비영 반사를 유지한다. 강한 반사에서는 직접 구한 양의1+r·1−r 계수와 정상파 기저로 장을 계산한다. 영진폭의 측정 일률 비율은 미정, 영주파수는 주기 평균 없음, 비영 주파수의 표현 손실은 산술 사용 불가다. 위상 한도를 명시하며 조용히 감거나 자르지 않는다.

## 실제 검증

전용26개·전체4,090개 테스트와 타입·lint·콘텐츠1,706 URL 검사가 실제 종료 코드0으로 통과했다. 기존472개 단원·안내,42개 실험 그룹463항목과 상대 순서를 등록 전 canonical 기준으로 보존했다. 네 원고를 실제 콘텐츠 로더로 렌더링하여 strict KaTeX, 한영 수식 일치, 고유 목차·스크롤 접근성·영어 한글 잔존 없음·풀이를 확인했다.

독립 Python 생성기는 제품 코드를 가져오지 않는다. 정전243조건의 실제 벡터 pillbox 면적 구적·네 모서리 적분과 전위를 비교했다. 파동81조건은 E/H 경계의2×2 선형계를 NumPy로 풀고 실제 부호 있는 Poynting 곱을 SciPy로 위상 적분했다. 별도96조건에서 직접 진행파 합과 공간·시간5점 차분을 비교했다.180자리 mpmath로 임피던스7조건·작은 전하/매질 점프2조건을 대조했다. 기준 파일은 재생성해 바이트 단위 재현성을 확인했다. 선택한 수치 근거이며 엄밀한 전역 오차 상한이 아니다.

기존 홈페이지 소스·설정2,971개와 정적 출력4,159개를 유지했다. 새 파일을 포함한 소스·설정2,981개를 동결했다. 미등록 원고 단계이므로 이번에는 새 빌드·화면 점검·공개 배포를 하지 않았다.
