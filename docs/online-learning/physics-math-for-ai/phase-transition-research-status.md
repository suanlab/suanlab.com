# 상전이·질서변수 연구 보강 검증 기록

2026-11-13. 기존 유한 Curie–Weiss 대칭, 변분 안정성, 6차 Landau 공존의 **3단원·한영 6원고·그림 6개**에 연구 절을 추가했다. 기존 본문과 해설 36개를 정확히 보존하고 표시 수식 44개, 실행 Python·표 각 6개, 연구 풀이 18개를 더했다. reader의 기존 조작과 별도 점근·공간 모형의 가정을 명시한다.

## 추가한 연구 설명

- **임계 유한 크기 요동:** 이항 계수·엔트로피의 이차 상쇄에서 M/N^(3/4) 척도와 사차 극한 밀도를 유도한다. 국소 전개에 꼬리 제어를 더하고 Gamma 모멘트·sqrt(N) 응답·Binder 통계량을 연결한다. 영장 평균 0, 유한계의 해석성, 비정규 요동을 구별한다.
- **골짜기 가중치:** 구속된 ψ의 Stirling 계수·격자 간격·Gaussian 폭을 모두 포함한 Laplace 진폭을 유도한다. K>1에서 b=v/N으로 준비하면 최소점은 조금 움직여도 혼합 비율은 유한하게 바뀐다. 조건부 분산과 전체 혼합 분산을 구분하고 임계점·spinodal·끝점에서는 같은 근사를 사용하지 않는다.
- **공간 계면과 방울:** 차원 있는 양의 강성을 추가한 새 범함수에서 0→m₀ 평면 계면·logistic 제곱 프로파일·장력을 유도한다. 공존에서 조금 벗어난 3차원 등방 매질을 명시해 구형 방울의 얇은 계면 장벽을 계산한다. 정확한 평면 해와 근사 구형 장벽을 구분하며 핵생성 속도는 예측하지 않는다.

원문·출처 경계는 [출처 기록](thermo-statmech-source-audit.md), 해시와 실제 검증 결과는 [JSON 근거](phase-transition-research-evidence.json)에 연결한다.

## 독립 계산과 보존

미시 상태 22준비의 직접 열거를 이항 거시 상태 합과 비교했다. 사차 극한 모멘트 5개를 별도 수치 적분했고 임계 유한 크기 5개에서 정확한 영장 대칭과 접근 양상을 확인했다. Laplace 진폭과 축소장 혼합 21준비, 계면 방정식·일차 적분 15개, 근공존 구동·반지름 장벽 9개를 검산했다. 표본 계산은 모든 모형·극한의 수치 인증이 아니다.

관련 **13파일·213검사**를 통과했다. 마지막 수식 기호 표기를 정돈한 뒤 연구 본문·변분 원고·보존 검사 22개도 다시 통과했다. 기존 본문을 새 절 제거로 정확히 복원하고 기존 풀이를 유지하는 검사를 별도로 둔다. 최초 초안에서 Markdown이 별표 기호를 강조로 해석한 곳은 기호를 escape해 수정했다. 브라우저 검사의 첫 실행은 `.ai-question`이 개념도 질문까지 선택해 본문 퀴즈와 어긋났으므로 종료 코드 1이었다. 별도 재현으로 확인하고 `#check .ai-question`으로 범위를 한정한 뒤 같은 정적 출력 전체를 재검사했다. 제품 콘텐츠는 이 선택자 수정으로 바뀌지 않았다.

다른 29단원·58원고와 앞선 연구 자산 126개를 기준 커밋 그대로 유지했다. 기존 보존 장부 841항목을 유지하고 6개를 추가해 847항목이다. 등록은 650단원·1,969안내, 전체 범위는 51영역·509주제다.
