# 열역학 연구 그림의 제목·축 잘림 수정

2026-11-13. 32단원 전체 화면 종합 검토에 앞서 실시한 native SVG 검사에서 **온도 추정·열접촉 척도·열과 일 경로의 한영 그림 6개**에 경계를 벗어나는 제목 또는 축 이름이 발견됐다. 나머지 연구 SVG 58개는 통과했다. 수정 전 실패 글자와 해시는 [JSON 근거](thermo-research-svg-repair-evidence.json)에 보존한다.

## 수정과 재현

두 Matplotlib 생성기의 SVG·미리보기 저장에 `bbox_inches='tight', pad_inches=.25`를 적용했다. constrained layout만 사용하던 출력에 글꼴 경계 여유를 더한다. 계산식·데이터·기존 색상은 유지했다. 생성기를 다시 실행해 공개 SVG 6개를 재생성했다.

`node scripts/check-thermodynamics-research-figures.cjs`는 실제 등록 32단원과 한영 연구 절에서 그림을 찾아 Chromium의 글자 경계를 검사한다. 현재 **64/64 SVG**가 통과한다. 회전한 축 이름과 제목을 포함하며, 원문 수학의 정확도를 대신 검증하는 도구는 아니다. 그림 재생성은 `python3 scripts/learning/generate-thermometry-figures.py`와 `python3 scripts/learning/generate-heat-work-research-figures.py`로 실행한다.

## 새 출력에서 확인한 범위

관련 연구·원고 보존 **16검사**, lint·콘텐츠 1,885 URL·새 빌드 1,893경로·타입·정적 1,888 HTML 검사를 통과했다. 수정된 세 단원의 한영 320/768/1440px 라이트와 한영 1440px 다크 **24화면**, 개념 12개·안내 9개·해설 퀴즈 6개·저장/완료 3그룹을 재검사했다. 최종 두 검사 과정은 종료 코드 0이며 페이지 오류·Axe 위반은 0이다. 첫 병렬 실행의 열·일 검사는 15/16화면에서 프로세스 종료 코드 143으로 중단돼 부분 결과를 제외하고 해당 16화면 전체를 단독 재검사했다.

새 출력에서 영역 전체 원고 64편의 렌더링과 연구 Python 64개를 다시 대조했다. HTML 32개·SVG 64개의 실제 제공 바이트가 출력과 같다. 입력 5472개·출력 400개를 고정했다. 수정 그림의 원본 크기 미리보기 6개와 한영 모바일 일반 읽기 캡처 6개를 직접 검토했다. 캡처는 스크롤 뒤 800ms와 두 프레임을 기다리며 설명 글자 경계도 확인했다.

원고 64편·기존 풀이 384개·장부 865항목은 보존됐다. 앞선 연구 자산 206개 중 이번에 명시한 그림 6개·생성기 2개만 대체하고 나머지 198개는 동일 해시다. 이전 원고 1차 대조는 당시 출력의 기록이며, 변경된 여섯 그림의 현재 근거는 이 기록을 따른다.

## 남은 영역 종합 검토

그림 결함이 확인된 첫 종합 실행은 해당 프로세스와 자식을 확인한 뒤 중단했다. 그 실행의 부분 검사나 대기 중 결과를 전체 통과로 집계하지 않는다. **32단원·256화면의 종합 검토는 수정된 최종 출력에서 다시 진행해야 한다.** 이번 24화면 재검사는 그 전체 검토를 대신하지 않는다. 순차 연구 보강은 32/32지만 전체 **43영역·426주제 대조 / 8영역·83주제 후속**은 유지한다. [진행표](thermo-statmech-research-progress.md)를 따른다.
