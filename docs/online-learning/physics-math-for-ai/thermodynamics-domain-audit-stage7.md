# Boltzmann·Gibbs 세 단원 점검

2026-11-07. 기준 측도·유한 Gibbs 갱신·이차 Gaussian의 한영6본문을 읽고 가정·단위·손계산·풀이를 대조했다. 선택한 독립 계산은 아래 범위에서 마쳤으며 전체 화면 점검은 아직 남아 있어 완전 점검 수에는 더하지 않는다.

## 수학·설명 검토

기준 측도 재조정과 에너지 기준 이동, 준위 엔트로피와 기준 상대 엔트로피를 구별했다. 유한 Gibbs의 행벡터 관례·K1K2 순서·흐름 반례·상관 제곱 수축을 손으로 검토했다. Gaussian의 엄격한 양의 정부호 조건, A/τ인 precision, 밀도 높이와 질량의 차이, 절댓값 Jacobian을 확인했다. 이 검토를 독립 수치 모형 대조나 연구 심화 완료로 세지 않는다.

배경 원문은 [Stanford Gibbs sampling 설명](https://ermongroup.github.io/cs323-notes/probabilistic/gibbs/)과 [StatLect precision matrix 정의](https://www.statlect.com/glossary/precision-matrix)를 확인했다. 조건부 갱신과 역공분산의 정의를 대조했으며 본문의 별도 수치 예제를 외부 자료에서 복사하지 않았다.

## 실제 화면에서 발견한 문제

- 한영 실제 Gibbs 화면에서 소수 원문 `2.00000000000000001` 등을 넣으면 정수2로 반올림되어 seed·격자 비트·경로 길이·관측 단계가 저장된다.8입력을 재현했다. 입력은 정확한 정수를 요구하므로 소수부가 Number 변환에서 사라지기 전에 검사해야 한다.
- 해당 수정은 공통 숫자 원문 검사를 사용하는 선택적 정수 모드로 준비했다. 연속 에너지·온도의 일반적인 binary64 근사는 유지한다. 분배함수6차 작업에 입력 후속 수정으로 함께 적용했다. 관련125·전체8407검사와 빌드·타입·정적 출력을 통과했다. 한영8소수 입력 거부와8유효 정수 적용을 실제 검증했으며 해당 두 화면 접근성도 통과했다.
- 유한 Gibbs 본문의 ‘경로 생성기는 별도 구현 대상’이라는 설명을 현재 화면의 기능 상태와 맞춰 수정했다. 화면에는 이미 seed·비트·단계·규칙을 지정하는 LCG32-high-bits 예시 경로와 양자화 kernel Q가 있다. 이론적 kernel, 독립 균등 격자 추출의 Q, 결정적 시드 경로와 경험적 빈도를 구별해야 한다.
- 320px 결과 그림에서 미시상태 묶음·갱신 그래프 글씨는 약6.46px, Gaussian 타원은 약7.10px, 확률 막대는13px였다. 전용 그림4종의 최소 내부 폭560px·인라인 글씨·키보드 안내를 적용했다. 최종 캡처의 최소 글씨는16px이며 Gaussian은17.6px 이상이다.

## 최종 구현과 검증

한영6본문에 실제 목록 적용·scalar 확정·kernel/관측 조회·시드 경로·좌표 전환을 연결했다. 이론 P·독립 격자 추출의 Q·LCG 결정적 예시를 구별하고, 원래 이론 모형 검증이 렌더러나 난수 구현까지 증명하지 않는다는 제한도 유지했다. Q 표의 분모 지수를 d로 표시하여 격자 비트 b와 구별했다.
