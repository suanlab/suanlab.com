# 매질·경계의 자료 대조와 독립 준비

2026-11-05. 장의 에너지·Poynting 흐름 다음 주제의 준비 기록이다. 이 자료·탐색에 이어 [계산 모델과 상세 한영 원고 검증](material-interfaces-foundation.md)을 마쳤다. 이후 [단원 등록·화면 통합 검증](material-interfaces-authoring-status.md)을 마쳤다. 자료 준비 자체로 완료 수를 올리지는 않는다.

## 확인한 1차 자료

Haus·Melcher의 [제6장 PDF](https://ocw.mit.edu/courses/res-6-001-electromagnetic-fields-and-energy-spring-2008/8f7b5c420309e3802750867b900337ac_06.pdf), MIT 공식 교재의 [§6.2 분극을 포함한 법칙·연속 조건](https://web.mit.edu/6.013_book/www/chapter6/6.2.html)과 [§6.5 선형 유전체](https://web.mit.edu/6.013_book/www/chapter6/6.5.html)를 확인했다. 자유 전하와 분극 전하, D=ε₀E+P, 두 면의 법선 방향을 구분하는 근거다.

[Feynman II 제33장 §§33–3–33–4](https://www.feynmanlectures.caltech.edu/II_33.html)는 파동을 경계에서 맞추는 절차와 비자성 가정을 확인하는 자료다. 해당 장의 B 연속·굴절률 식을 임의의 서로 다른 μ에 그대로 확장하지 않는다. [MIT §9.2 자화를 포함한 법칙](https://web.mit.edu/6.013_book/www/chapter9/9.2.html)에서 B와 H·자화의 구분도 확인했다. 아래 임피던스 식은 명시한 일정 양의 ε·μ와 E/H 경계 조건에서 직접 유도한 것이다.

## 후보와 모형의 범위

| 후보 ID | 중심 질문 |
| --- | --- |
| `dielectric-interface-free-bound-charge` | E·D·P에서 무엇이 연속이고 어떤 점프가 자유·분극 전하에 대응하는가? |
| `normal-incidence-impedance-interface` | E 진폭의 반사·투과와 실제 에너지 반사·투과는 어떻게 다른가? |

두 매질은 정지한 등방성·선형·비분산 매질이며 ε·μ는 양수다. 평면 반공간의 이상화로 시작한다. 손실·이방성·분산·움직이는 매질·유한 장치 전체를 이 두 입문 예제로 해결했다고 주장하지 않는다. 경계에서는 양쪽 극한을 따로 보고 임의의 평균 장을 만들지 않는다.

## 정전 경계의 직접 유도

법선 n=+z는 매질1에서2로 향한다. 공통 접선 E를 지정하고 D₁z=d, D₂z=d+σfree로 둔다. 각 쪽의 Ez는 해당 D를 ε로 나눈 값이다. Pj=(εj−ε₀)Ej이므로 분극 표면 전하는 P₁z−P₂z다. 따라서 D의 법선 점프는 자유 전하, ε₀E의 법선 점프는 자유·분극 전하의 합이다.

각 반공간에서 Vj=−Et x−Ejz z+Vref를 사용하면 z=0의 전위가 연속이다. 얇은 pillbox의 두 면과 옆면을 실제 벡터로 적분하고, 경계를 가로지르는 직사각형의 네 모서리 E·dℓ를 비교한다. 접선 E를 서로 다르게 지정한 반례는 정전 순환과 전위 연속을 실패한다. 법선 E가 같지 않다고 곧바로 오류라고 판단하지 않는다.

## 수직 입사 파동의 직접 유도

Zj=√(μj/εj), cj=1/√(εjμj)로 두고 +z 입사·−z 반사·+z 투과를 사용한다. 접선 E와 H를 맞추면 r=(Z₂−Z₁)/(Z₂+Z₁), t=2Z₂/(Z₁+Z₂)다. 반사 H의 부호는 진행 방향 때문에 반대다. 전력 계수는 R=r², T=(Z₁/Z₂)t²로 구분한다. t>1이어도 에너지 보존 위반은 아니다.

임피던스가 같고 파동 속도가 다른 예제에서는 반사가 없지만 파장은 달라질 수 있다. 반사를 임의로0, 투과 진폭을1로 강제한 대조는 E를 맞추면서 H의 점프를 남길 수 있다. 이는 자유 표면 전류가 없다는 요청에 부합하지 않는 것이다. 필요한 전류 시트를 허용하면 경계 일률 차이가 시트의 J·E와 맞을 수 있으므로 무조건 어떤 Maxwell 해도 불가능하다고 설명하지 않는다.

## 실제 독립 계산

`.runtime/learning/prepare-material-interfaces.py`는 제품 코드를 가져오지 않는다. 정전243조건에서 실제 E·D·P와 방향 있는 pillbox 면적 구적, 직사각형 모서리 적분·전위 점프를 비교했다. 파동81조건에서는 반사식을 바로 대입하는 대신 E/H 연속의2×2 선형계를 NumPy로 풀고 실제 부호 있는 Poynting 흐름을 위상에 대해 SciPy 적분했다. 시트가 필요한 대조의 경계 일도 비교했다.

거의 같은 임피던스의180자리 기준도 확인했다. ε₂를 ε₁의 다음 표현 가능한 수로 정했을 때 직접 제곱근 차감의 r은 약−7.5443×10⁻¹⁷, 고정밀 기준은 약−4.5616×10⁻¹⁷이었다. 계수의 상대 차이에 log1p를 적용한 식은 이 기준을 유지했다. 입력 자체가 이미 같은 수로 반올림된 경우와 구분해야 한다. 선택한 조건의 관측이며 엄밀한 전역 오차 상한은 아니다.

실제 종료 코드0: `material-interfaces-preparation-exit.json`. 결과: `.runtime/learning/material-interfaces-preparation.json`.

## 집필 순서

먼저 자유 전하·분극 전하를 색으로 구분한 pillbox와 접선 루프를 읽고, 식·단위·법선 부호·전위를 계산한다. 다음에는 두 매질의 입사·반사·투과 E/H를 그린 뒤 진폭 계수와 전력 계수를 비교한다. 무반사와 같은 속도를 혼동하지 않고, 경계 원천을 누락한 모형·작은 임피던스 차이·불연속점의 양쪽 극한을 풀이 문제와 AI 경계 잔차의 예제로 연결한다.


## 기초 집필에서 확장한 검증

독립 생성기를 재현 가능한 `scripts/learning/generate-material-interfaces-references.py`로 정리했다. 직접 진행파의 공간·시간5점 차분96조건과180자리 임피던스7조건·작은 정전 점프2조건을 더했다. 고정 μ의 초기 log1p 예제를 넘어, 거의 같은 두 곱 자체가 차이를 잃는 사례는 보상 곱 전개와 유리화한 반사식으로 처리한다. 초기 자료 준비와 새 제품·원고 검증은 [기초 집필 기록](material-interfaces-foundation.md)에서 구분한다.
