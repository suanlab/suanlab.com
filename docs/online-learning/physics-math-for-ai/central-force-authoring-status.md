## 집필 단계 기록

갱신: 2026-11-04. **중심력**의 두 단원을 레지스트리와 홈페이지 화면에 연결했다. 한·영 상세 원고, 시각화 10개, 개념 단계 8개, 안내 실험 6개와 퀴즈 4개를 구현했다. 첫 소스 고정 실행에서 전체 테스트 2,976개·역학 집중185개·정적 빌드·링크·새 화면35회·이전 마찰 화면35회·영어500경로/558상태 검사를 통과했다.

그림 검토에서 유효 퍼텐셜 우물이 압축되어 보이는 문제와 원에 가까운 이심률의 반올림 모호성을 발견했다. 표시 창을 초기·조회·근점 반지름에 맞추고 정확한 이심률 제곱을 표시하도록 개선했다. 개선 소스의 전체 검증을 다시 실행 중이며, 완료 수치 **414개 단원·1,242개 안내 실험**과 남은 **13영역·127주제**는 최종 검토 전까지 유지한다. 레지스트리의 집필 수는416개이며 검증 완료 수와 구분한다.

## 독립 수치 검증

- Python `Fraction`으로 데카르트 초기 불변량과 반지름 조건 700개를 검산했다.
- 70자리 이분법으로 부호·작은 각·반복 회전·거의 포물선인 극한을 포함한 케플러 근 220개를 만들었다.
- SciPy DOP853으로 별도의 데카르트 역제곱 운동방정식과 면적 적분 160개를 계산했다. 높은 이심률과 22바퀴 이상 도는 사례를 포함한다.
- 두 원고의 한·영 수식 렌더링, 해설 문제, 목차 앵커도 검사한다. 초기 모델·원고 집중 검사25개와 회귀검사2,966개를 마쳤으며 화면 연결 후 전체2,976개·역학 집중185개로 검증 범위를 확장했다. 최종 시각 개선의 재검증은 별도 실행 중이다.
- 원래 `interactive-book.ts`와 이전 414개 단원의 레지스트리는 이번 단계에서 변경하지 않았다.

참조값은 `scripts/fixtures/central-force-independent.json`에 저장한다. 재생성하려면 별도 Python 환경에서 `scipy`와 `mpmath`를 설치하고 저장소 루트에서 다음 명령을 실행한다. 프런트엔드 실행에는 Python 패키지가 필요하지 않다.

```bash
python3 scripts/learning/generate-central-force-references.py
npx tsx --test scripts/learning-central-force.test.ts
```

## 완료 및 남은 작업

1. **연결 완료.** 기존 단원의 모든 데이터·안내 실험·상대 순서를 보존하면서 두 단원의 제목·선수 관계·개념 단계·각 3개 안내 실험을 레지스트리에 연결한다.
2. **구현 완료·시각 개선 검증 중.** 기존 색상과 스크롤·키보드 접근성을 사용해 공간 기하, 유효 퍼텐셜, 반지름·속력, 에너지·면적 시각화를 만든다. 기하와 시간 경로, 전체 기준 타원과 실제 방문 경로, 특이점과 화면 잘림을 명확히 구분한다.
3. **첫 실행 통과·개선 소스 재검증 중.** 한국어·영어 및 모바일·데스크톱·다크 모드에서 예제·경계 조건·저장·언어 전환·퀴즈·접근성을 확인한다. 기존 마찰·구속과 에너지 입문의 회귀검사도 수행한다.
4. **첫 실행 통과·개선 소스 재검증 중.** 소스를 고정한 뒤 전체 테스트·정적 빌드·타입·링크·영어 한글 노출 검사를 수행하고 생성 그림을 검토한다.
5. 모든 검증이 끝나면 완료 수치와 전체 남은 순서를 갱신한다. 이 단계는 전체 교육과정의 완성을 뜻하지 않는다.
