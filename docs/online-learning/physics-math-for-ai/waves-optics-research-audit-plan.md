## 내용·계산 대조

공진, 결합 진동, 파동 방정식, 간섭·회절, 분산·군속도, 편광, 기하·파동 광학, Fourier optics, 관측·샘플링·센서의 원주제를 기존 기반 원고와 연구 보강 기록에 연결한다. 각 기록의 가정·단위·유도·예제·질문·모델 한계를 검토한다. 보충 계산을 새로운 네이티브 UI 제어로 기록하지 않는다.

한영 연구 절의 수식·Python 셀·표·해설 대응을 대조하고 실행 가능한 모든 Python 셀을 실제 실행한다. 수치 검사를 일반 증명·물질 유효성 인증으로 확대하지 않는다. 아홉 배치의 `selectedTestFiles`를 중복 제거해 기존 물리·통합 검사, 새 연구 검사, 본문 보존 검사를 함께 실행한다. 검사 개수는 최종 로그에서 집계한다.

## 같은 최종 빌드의 출력·독자 화면

원고·그림을 먼저 고정하고 lint·콘텐츠·빌드·타입·내보내기 검증을 마친다. 36개 SVG의 원본/내보내기/서빙 바이트와 18개 HTML의 내보내기/서빙 바이트를 대조한다. 과거 여러 빌드의 개별 화면 수를 합해 최종 영역 검증으로 대신하지 않는다.
