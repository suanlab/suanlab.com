# 상관·요동 세 단원 사전 검토

2026-11-07. 연결 공분산·장 Hessian, 주기 Ising 고리, 정상 AR(1) 평균의 유한 오차를 다루는 한영 원고6개를 모두 읽었다. 앞선 상전이 단원의 전체 브라우저24조합을 확정한 뒤 이 단원의 본문·그림·정수 입력 수정을 적용했다. 현재 관련75검사를 통과했고 전체 검사와 정적 빌드는 실행 중이다. 이 기록은 작업 중인 범위이며 최종 완료 판정이 아니다.

## 독립 계산

현재 UI 예제32개의 수치 모델 출력을 수집했다. 스핀 쌍11개는900자리 계산에서 네 이름 붙은 배치를 직접 열거하여 중심화한 관측량220개와 방향성 구간220개를 대조했다. K=0의 교차 공분산 및 영장의 평균0은 해석적 대칭으로 유지한다. 부동소수점 합의 잔여값을 구조적0과 혼동한 첫 참조 실행은 별도 로그로 보존하고 수정했다.

고리10개는900자리 두 경로 식으로 관측량1172개와 구간1164개를 대조했다. 작은 계6개는 직접 배치 열거36항,9개 준비는 독립 전달행렬 trace413항으로 추가 검산했다. 최소 결합의 긴 고리는 전달행렬 상쇄 예산에서 제외하며 그 경우까지 trace로 확인했다고 주장하지 않는다. AR(1)11개도 실제 binary64의 정확한 Fraction 지연 합으로 완료했다. 관측량4382개·구간4381개, 인덱스·끝점4290항과 작은 접두 구간 이중 합63항을 대조했다. 전체32예제에서 관측량5774개·구간5765개를 통과했다.

근거는 `.runtime/learning/thermodynamics-domain-audit-stage9/`의 `model-values.json`, `pair-independent-comparison.json`, `ring-independent-comparison.json`, `preliminary-review.json`이다.

## 재현한 수정 사항

- 고리의 정수 N과 AR(1)의 정수 n에 `3.00000000000000001`을 입력하면 오류 없이3으로 저장된다. 소수 부분이 변환 과정에서 사라지기 전에 원래 문자열을 검사해야 한다.
- 320px에서 전용 그림의 최소 글자 크기는 스핀 쌍 약6.95px, 고리·AR(1) 약4.45px다. 그림 내부 폭과 인라인 글씨, 키보드 스크롤 안내를 보완하고 설명문은 그 밖에 둔다.
- 한영 원고는 실제 등록된 읽기·학습 조작부를 향후 단계로 설명한다. 실제 source 벡터와 확률 구름, 공간 경로와 표본 시간, 유한 분산과 점근 참조를 구별하는 조작 예제를 보태야 한다. source 그림은 확률 구름이 아니며 AR(1) 계산은 임의 훈련 스트림의 정상성을 입증하지 않는다.

실제 기본 화면의 측정과 정수 오류 재현은 `baseline.json`에 기록했다. 전체 조합 및 연구 심화 검증을 대신하지 않는다.

배경 자료로 [Geyer의 자기공분산 강의](https://www.stat.umn.edu/geyer/8054/notes/initseq.html)와 [Tong의 상전이 강의](https://davidtong.org/teaching/statistical-physics/statmechhtml/S5)를 확인했다. 이 교재의 입력 범위·유한 준비와 독립 검산은 별도로 지정한 것이다. 앞 행렬이 끝나면 본문·그림·정수 검증을 수정하고 관련 검사, 전체 검사, 재빌드 및 실제 읽기 확인을 이어간다.


## 본문·그림·정수 입력 수정 적용

`learning-correlations.next.ts`, `correlations-lab.next.tsx`는 고리 N과 관측 수 n의 소수 손실을 변환 전 문자열에서 거부하는 초안이다. `correlations-view.next.tsx`는 전용 그림5종에 외부 설명문·키보드 스크롤 안내·14px 인라인 글씨와 그림별 내부 최소 폭을 제공한다. 실제 화면의16px 이상 여부와 새 접근성은 적용·빌드 후 확인해야 한다. `bridges-draft.json`에는 각 한영 원고에 넣을 조작·예측·해석3행 표를 준비했다. 원본 비교 해시는 `draft-baseline-hashes.json`에 기록했다. 이 초안을 기존 소스14파일에 적용했다. 수식은 한영 모두 원본과 같음을 확인했고 수치 모델·예제·가이드·등록·전역 스타일·메뉴는 유지했다. 관련 검사에서 수식 개수의 기대값까지 잘못 늘린2실패를 원래13개로 바로잡은 뒤75개 모두 통과했다. 첫 실패 로그는 `related-tests-first-equation-expectation-failure.log`에 보존했다. 실제 새 화면의 검증은 빌드 후 진행한다.


현재 열역학 완전 점검은22/32단원이며 남은10개에 이 세 단원이 포함된다. 전체 교육과정과 연구 심화는 미완료다. 소스 변경 목록과4306파일 해시는 `source-changes.json`, `source-hashes.json`에 기록했다.


## 모바일 source 벡터의 초기 위치 보완

첫 재빌드의 가독성24조합·그림72개·소수 손실 거부48건 및 오류 복구는 통과했지만, 실제 화면을 보고 별도 확인한 결과320px source 벡터 그림에서 원점과 화살표 끝이 모두 초기 가시 영역 밖이었다.226px 영역에600px 그림이 왼쪽 정렬되어 원점은화면x347, 오른쪽 경계는x273이었다. 수치·글씨 검사가 통과해도 시각적 설명이 처음부터 보인다는 증거는 아니었다.

실제 UX 결함을 고치기 위해 실행 중이던 전체 읽기 검증의 소유 브라우저만 종료했다. 관찰 시간 초과에 따른 재시작이 아니다. 당시 완료4조합은 이전 출력 근거로만 보존하며 새 출력 완료 수에 재사용하지 않는다. 로그·출력 근거는 `pre-centering/`, 이유는 `reader-stop-source-vector-visibility.json`에 남겼다.

source 벡터 그림만 마운트·크기 변경 때 중앙으로 위치시키고 ResizeObserver는 해제하도록 보완했다. 다른 그림의 시간축 시작 위치는 유지한다. 검사기도 초기 원점·선택 예제 끝점의 가시성과 방향키에 따른 실제 이동량을 확인하도록 강화했다. 관련75검사가 다시 통과했으며 전체 검사·빌드·실제 화면은 새 출력으로 다시 확인한다.
