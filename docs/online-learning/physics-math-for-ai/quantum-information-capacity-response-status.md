# 채널 용량과 아홉 가족의 독립 응답 검증

2026-11-09. `validateQuantumCapacityResponse`와 통합 진입점 `validateQuantumInformationResponse`를 추가해 양자정보의 독립 응답 검증 **9/9가족**을 준비했다. 실제 Worker·학습 화면·reader 등록은 아직 남아 있다. 응답 검증 준비와 교재 완료를 구분한다.

## 채널·환경과 선택 입력

입력의 Hermitian 밀도행렬을 정확 대각/행렬식으로 검증한다. 출력은 채널의 matrix-unit 작용으로 구성한다. 대각 성분은 유지되고 비대각 성분에1-2p를 곱한다. 정규화 Choi도 이 작용에서 구성한다.

환경 상태의 행렬식은 `p(1-p)(1-z²)`다. 이 특성방정식과 별도768bit 이분 root로 작은 고유값을 감싸고, 환경 coherence는 별도 `sqrt(p(1-p))*z` 구간으로 확인한다. 두 비대각 원소는 같은 구간이어야 한다. 입력·출력/환경 엔트로피는 별도512bit signed log1p 참조를 쓴다. 생산 판별기·root/log·용량 모델을 호출하지 않는다.

선택 입력의 coherent information은 출력 엔트로피와 환경 엔트로피의 차이다. 순수 입력 또는 완전 탈위상일 때 정확한0을 유지하고 raw 차이의 불확실성은 보존한다. 참조 mutual information은 입력 엔트로피를 더한 값이다. 보고된 entropy/raw/최종값의 구간 연동도 검사한다.

## 가족 정리의 범위

이 알려진 memoryless 탈위상 가족에서 C=1, CE=2-h2(p), Q=1-h2(p)를 별도로 검증한다. CE의 공유 얽힘 자원과 C/Q의 비보조 전송률을 구분한다. 임의 채널·선택 입력의 최적화·유한 블록 부호기를 구현한 것으로 설명하지 않는다.

정확 양자 용량 양성 여부는 p≠1/2로 판정한다. 반올림된 h2(p)가1이어도 작은 양의 Q를0으로 만들지 않는다. Z 기저의1bit, X 기저의 정보량과 재표지 후 추측 성공률을 확인한다.77개 수치 관측과 모든 결과/가정 필드를 검사한다. 유리수·표시 primitive는 공유하지만 수학 참조 경로와 구분한다.

## 통합 검증과 다음 단계

통합 진입점은 원래 입력을 소유한 뒤 해당 가족의 독립 검증기로 전달한다. 성공 응답의 관측·정확 계수 수를 공통 형식으로 반환한다. 생산 계산 진입점이나 fixtures를 import하지 않으며, 실제 비동기 메시지의 순번/취소 관리를 대신하지 않는다.
