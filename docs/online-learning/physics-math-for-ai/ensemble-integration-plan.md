# 세 앙상블 가족의 교육 화면 통합 계약

2026-11-07. 세 모델과 한영 원고 이후의 구현 순서다. worker와 24예제·9한영 안내의 격리 검증은 `ensemble-worker-foundation.md`에 기록했다. 이 문서는 화면·등록 완료의 증거가 아니다. 기존 사이트의 색상·명암·폰트·학습 패널과 **도서 → Interactive Book** 진입 경로를 유지한다.

## 네 개념 단계씩 연결할 대상

| 가족 | 1단계 | 2단계 | 3단계 | 4단계 |
| --- | --- | --- | --- | --- |
| 유한 저장고 | 전체 고정-K 배치와 두 블록 | 부분계의 특정 배치와 여기 수 집계 | 평균이 같은 정확/정준 분포의 분산·TV | 저장고 증가의 오차와 반대 방향 KL의 지지집합 |
| 정준 요동 | 한 자리 가중치와 정규화 | 전체 이항 분포와 평균·분산 | 고정 Hamiltonian의 온도 응답·열용량 | 자리 수·독립 표본 수·상대 요동의 차이 |
| 입자 교환 | 고정 자리 용량과 변하는 입자 수 | 점유 분포와 선택한 수의 조건부 배치 | μ 응답의 단위와 grand potential | 온도 0의 빈/가득 찬/임계점 및 접근 경로 |

개념도는 설명에 대응하는 고정 예제를 사용한다. 저장된 실험 입력이나 비교 프레임이 설명과 그림을 어긋나게 만들지 않도록 별도 입력을 둔다. 표·개념 예제·실험에는 중복되지 않는 접근성 이름을 사용한다.

## 안내 실험 9개

1. 저장고 n=2,b=2,K=2: 두 평균 1, 분산 1/3 대 1/2, TV=1/6을 비교한다.
2. 같은 n과 절반 점유에서 b=2,6,18,98: K를 함께 바꾸는 규칙과 TV 수열을 확인한다.
3. 저장고 b=0,K=1: 점질량 P와 이항 Q, 유한/무한 양방향 KL을 구별한다.
4. 정준 n=2,t=ln 2: 분포 (4,4,1)/9와 응답의 단위를 복원한다.
5. 같은 t=1에서 n=4와16: 총량 네 배·표준편차 두 배·상대 요동 절반을 구별한다.
6. 정준의 드문 여기: 표시되지 않는 양의 확률이 에너지·분산에 남는 사례를 비교한다.
7. 입자 교환 M=2,μ=ε: 무조건부 배치·입자 수·조건부 배치와 μ 응답의 분모를 확인한다.
8. 온도 0에서 μ와 ε의 관계: 빈/가득 찬/임계점, 발산하는 log Ξ와 유한 Ω를 구별한다.
9. 희박한 점유와 화학 응답: 확률은 선형 범위 밖이어도 1/(kBT)로 복원되는 응답을 확인한다.

예제 선택은 이산적인 준비 비교다. 음의 온도, 정확한 간격 0, 빈 부분계/빈 계, 임계점 경로, 매우 작은 비·큰 입력 상쇄도 별도 예제로 제공한다. 주제를 줄이기 위해 이러한 경계를 생략하지 않는다.

## 계산·입력·표시

세 모델을 새로운 타입이 있는 worker 요청/응답에 연결한다. 클라이언트 설정·입력 검증은 무거운 모델을 import하지 않는다. 순수 스칼라 입력을 검증·복제하고 고정 필드 순서의 요청 키를 만든다. 새 입력은 이전 결과를 새 결과처럼 표시하지 않아야 한다. 입력 대기·실제 계산 중단·재시도·다른 단원 이동에서 worker 수명을 검증한다.

전체 분포와 정확한 계수는 보존하되 큰 표는 페이지로 나눈다. 차트가 일부 이산 빈만 그린다면 이를 표시하고 전체 확률로 재정규화하지 않는다. 선형 값이 없는 양수는 로그와 상태를 표시하며 실제 0 막대로 바꾸지 않는다. 정의되지 않은 비·조건부, 무한대 KL, 발산하는 온도 0 log Ξ, 유한 값의 범위 초과를 별도로 처리한다. 중첩 로그는 꼬리 진단에 사용한다.

기본 제어와 확장 입력은 같은 모델 계약을 사용한다. T=0 입력의 접근 방향과 μ 임계점 관례를 표시한다. α 고정·μ 고정의 미분, 에너지 기울기·고정 입자 수 열용량을 혼동시키지 않는다. 이미 입력에서 반올림된 μ−ε 차이를 복구한다고 표현하지 않는다.

## 완료 기준과 순서

worker와 모델 어댑터 → 실제 패널·대표 그림 → 안내·고정 개념도 → 퀴즈 두 개씩 → 등록 순서로 진행한다. 기존 512단원·1536안내의 내용과 순서를 먼저 해시로 보존한다. 미등록 준비 자료를 원래 주제 완료 수에 더하지 않는다.

격리 패널 검증 후 전체 검사·빌드·정적 출력과 실제 읽기 경로를 확인한다. 한영·명암·320px/데스크톱, 키보드·접근성·가로 넘침·수치 표시, 저장/재로드·오류 복구, 모션 정지·감소·수동 이동·화면 밖 정지, 계산 교체·중단·이동 중 정리를 검증한다. 메뉴·목차·breadcrumb·검색·sitemap은 Interactive Book에 연결하고 Online Book 목록에는 교재 진입 링크를 추가하지 않는다.

실제 경로 검증 이후에만 등록·원래 주제의 입문 검증 수를 갱신한다. 연속 공간·상호작용·앙상블 비동등성·연구 깊이와 전체 교육과정은 별도로 계속한다.
