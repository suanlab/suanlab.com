## 관측 준비

평균 0·분산 1인 정상 Gaussian 준비에서 `X_(i+1)=ρX_i+sqrt(1−ρ²)ε_i`, X1과 ε들의 독립 표준정규 준비를 명시한다. |ρ|<1에서 이 구성은 `Cov(Xi,Xj)=ρ^|i−j|`를 준다. ρ=±1은 혁신 분산 0인 별도의 정상 퇴화 준비로 포함한다. ρ=1에서는 경로 전체가 X1, ρ=−1에서는 X1과 −X1이 교대한다. 통상적인 혼합·CLT를 이 끝점에 적용하지 않는다.

실습 범위는 정수 n=1..512, 실제 binary64 ρ∈[−1,1]로 준비한다. 표본으로 추정한 ρ가 아니라 지정된 모델 모수다. 데이터로부터 자기공분산을 추정하는 문제와 이 정확한 모델 계산을 구별한다.

## 유한 값과 점근 값을 구별하기

`Var(mean)=[n+2Σ(k=1..n−1)(n−k)ρ^k]/n²`를 공분산 이중 합에서 유도한다. 점근 IAT `(1+ρ)/(1−ρ)`를 곧바로 n으로 나누지 않는다. 유한 오차는 양의 혁신 분해

`Var(mean)=[a_n²+(1−ρ²)Σ(m=1..n−1)a_m²]/n²`, `a_m=Σ(k=0..m−1)ρ^k`

로 계산한다. ρ≈−1에서 작은 짝수 a_m를 잃지 않도록 부호 있는 방향성 연산 또는 짝·홀 기하급수 형태를 검토한다. 정확한 `1−ρ²`를 반올림된 관측량에서 빼지 않는다. 자기공분산의 거듭제곱은 별도 이진 지수로 보존할 수 있다. 양의 정확한 분산, 표시 범위 부족과 정밀도 미해결을 구별한다.

끝점은 Var(mean)=1(ρ=1), 짝수 n에서 0·홀수 n에서 1/n²(ρ=−1), 독립 ρ=0에서는 1/n이다. 분산 등가 표본 수 `1/Var(mean)`가 n보다 클 수 있고 퇴화 취소에서는 무한대일 수 있다. 이를 독립 표본 수나 일반 추정량의 정보량으로 부르지 않는다. 끝점 IAT는 통상적 혼합 상관시간으로 보고하지 않는다.

## 독립 근거와 교육 요소

Python Fraction으로 실제 `float.as_integer_ratio()` 모수의 공분산 이중 합을 구한다. TypeScript의 혁신 분해를 참조에 재사용하지 않는다. n=1, 짝·홀, ρ=±1/0, ±1의 이웃 binary64 값, 최소 양·음 모수와 최대 n을 포함한다. 평균 분산·표준오차·분산 등가 수·유한/점근 비를 각각 검토하며, 표준오차 제곱근을 인증할 경우 별도의 구간 근거가 필요하다.

그림은 공분산 행렬과 평균의 가중합, n에 따른 유한 오차를 우선한다. 임의로 생성한 짧은 경로가 이론 분산을 인증한다고 주장하지 않는다. 공간 고리의 거리, 시간/관측 인덱스, Monte Carlo 실행 횟수와 독립 복제 수를 따로 표시한다. AI 연결은 의존 미니배치·Monte Carlo 평균의 불확실성이며 임의 비정상 훈련 로그에 정상 공식을 자동 적용하지 않는다.
