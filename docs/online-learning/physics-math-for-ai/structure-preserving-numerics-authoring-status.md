## 비선형 사차 퍼텐셜의 이산 작용과 보정

후보 `quartic-discrete-action-splitting`은 사차 퍼텐셜에서 velocity Verlet·RK4·입력 에너지 보정의 실제 갱신을 실행한다. Verlet의 이산 Lagrangian과 양 끝 운동량을 유도하고 단계·누적 Jacobian, 물리 에너지와 잘린 수정 Hamiltonian, 같은 시간의 세분화 오차와 왕복 오차를 구분한다.

에너지 보정은 입력 에너지의 도함수를 포함해 미분한다. 에너지 값이 맞아도 정준 넓이가 달라지는 사례, 순방향 완료 뒤 역방향에 실수 운동량이 없는 사례, 실수 근의 경계와 표시 한계, 0 보폭의 항등 갱신과 미정 이산 작용을 다룬다. 기존 선형 진동자의 정확한 이차 불변량을 비선형 계에 이름만 바꾸어 적용하지 않는다.

## RATTLE과 정규화 사영의 구속·위상 오차

후보 `circle-rattle-projection-phase`는 자유 원 운동에서 RATTLE의 항등 근처 가지를 직접 유도한다. 입력 정수 비율의 정확한 판별식으로 정칙·유한한 경계·실수 근 부재를 구분하며 실제 Cartesian 갱신의 부동소수점 잔차를 남긴다.

이 특별한 자유 원에서는 RATTLE이 에너지·각운동량을 보존해도 `N(asin(nu)−nu)`의 위상 오차가 쌓인다. 위치 정규화 뒤 접선 운동량 사영은 두 구속을 맞추면서 에너지와 각운동량을 잃고 축약 정준 넓이를 수축시킨다. 초기 운동량0에서 한 점의 행렬식1이 전체 사상의 구조를 증명하지 않는다는 예도 포함한다. 이 특수한 에너지 보존을 모든 구속계의 RATTLE로 확대하지 않는다.
