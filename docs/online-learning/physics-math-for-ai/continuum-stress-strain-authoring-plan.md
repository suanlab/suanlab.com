이후 [홈페이지 통합과 최종 검증](continuum-stress-strain-authoring-status.md)을 마쳤다. 아래 수치와 다음 단계는 기초 작성 당시의 기록이다.

이후 [계산 모델·상세 한영 원고 검증](continuum-stress-strain-foundation.md)을 마쳤다. 아래 준비 단계 설명은 해당 기록 당시 기준이며 홈페이지 통합은 다음 단계다.

2026-11-06. [자료 검토](continuum-stress-strain-source-audit.md)에 따른 다음 주제의 설계다. 모델·원고·홈페이지 완료 증거가 아니며 기존 완료 수에 더하지 않는다.

## 1. Cauchy traction과 응력의 수지

예정 ID: `cauchy-traction-stress-balance`. 선수는 압축 흐름의 운동량 수지, 연속체의 척도 가정과 행렬 사상이다.

먼저 같은 응력에서도 면의 방향에 따라 힘/면적 벡터가 달라지는 예를 보여 준다. t=sigma n, normal=n·t, shear=t−normal n을 구분하고 법선을 뒤집으면 traction이 반전되는지 확인한다. 평면 내 등방 압축 sigma2D=−pI2, 단축 인장과 순수 전단을 비교한다. plane-stress의 평면 밖 응력0과 완전한 삼차원 정수압의 sigma_zz=−p를 구분한다. 전단 traction을 스칼라 크기로만 표시해 방향을 지우지 않는다.

공간적으로 affine인 대칭 응력 가족을 실제 직사각형 영역에서 관측한다. 현재 좌표의 각 면 traction, 면적·깊이, 순힘·모멘트를 직접 적분한다. 상수 체적력으로 평형을 맞춘 경우와 그것을 누락한 대조를 같은 응력장에서 비교한다. 대칭성은 고전적인 couple 없는 Cauchy 연속체의 조건이며 일반화 연속체까지 무조건 확장하지 않는다. 0 면적의 힘과 해당 법선에서 계산한 국소 traction은 다른 관측이다.

그림은 단위 법선·traction 분해·방향 스윕·응력 타원과 실제 경계의 힘을 보여 준다. Pa, N, N·m와 체적력 N/m³를 다른 축과 표에 남긴다. 응력만으로 실제 변위를 결정했다고 표시하지 않는다.

## 2. 유한 변형과 소변형률의 회전 한계

예정 ID: `finite-deformation-small-strain-rotation`. 선수는 입자 평균장, 벡터 길이·내적, 행렬·좌표 회전이다.

양의 lambda_x,lambda_y와 전단 gamma에 회전 R(theta)를 결합한 F=R(theta)[[lambda_x,gamma],[0,lambda_y]]를 사용한다. 실제 격자와 선분의 위치, 방향 신장 ||F n||, 각도 변화와 detF의 면적 비를 계산한다. 변위는 길이 단위, H·F·변형률은 무차원이다. 평행 이동은 상대 거리와 변형률을 바꾸지 않는다.

E=(F^T F−I)/2와 epsilon=(F+F^T)/2−I를 함께 읽는다. 정확한 강체 회전 F=R에서 E=0이지만 유한 각도의 epsilon=(cos(theta)−1)I일 수 있다. 이를 물리적 압축으로 오해하지 않도록 실제 길이 보존과 대조한다. I+omega J는 유한 회전 행렬이 아니며 이차 크기의 실제 신장을 남긴다는 별도 반례도 다룬다.

추가 관측 회전 Q에 대해 QF의 E는 유지되는지, 벡터·응력 성분은 올바른 법칙으로 변환되는지 확인한다. 전단이 있으면 삼각 행렬의 대각값을 모두 주신장으로 부르거나 R을 극분해 회전으로 부르지 않는다. 임의 회전을 소변형 근사의 범위 안으로 표시하거나 E만으로 특정 재료의 Cauchy 응력을 자동 결정하지 않는다. 특이하거나 방향을 뒤집는 변형은 지원 범위 밖으로 명시한다.

## 원고와 완료 조건

각 단원에 직관·선수 지식·가정·단위·유도·손계산·잘못된 추론·실험 순서·풀이6개를 한영으로 작성한다. 독립 면·체적 구적, 변형된 두 점과 면적의 관측, 고정밀 회전·작은 변화 참조를 먼저 확보한다. 그다음 홈페이지 테마의 정밀 입력, 고정 개념4단계, 안내3개와 퀴즈2개를 연결하고 실제 한영 화면·키보드·접근성·그림을 검증한 뒤 원래 주제 완료 수에 포함한다.
