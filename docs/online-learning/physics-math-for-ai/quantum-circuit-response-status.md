# Quantum circuit·channel: circuit observations and independent validation

2026-11-09. 앞 단계의 [채널 수치 기반](quantum-channel-foundation-status.md)에 이어 회로의 단계별 관측값과 독립 검증기를 구현했다. 네 단원의 유한 수치 기반을 준비했으며 **등록0/4·홈페이지/Worker/브라우저 미검증** 상태다.

## 추가한 계산

- 각 회로 단계의 정규화 전 진폭·제곱 노름·노름 잔차, 계산 기저 확률, 결합 밀도행렬·순도.
- 큐비트별 축약 밀도행렬·순도·Bloch XYZ, 모든 큐비트 쌍의9개 Pauli 기댓값과 연결 상관관계.
- 전체 유니터리·유니터리 잔차, 입력과의 중첩·제곱 fidelity, 진폭 동일성과 물리 상태 동일성의 구별, 역회로 복원.

제품 계산은 기존 진폭 갱신 kernel을 사용한다. 독립 검증기는 전체 행렬을 따로 만들어 진화시키고, 환경 좌표 삽입과 Pauli 작용으로 관측값을 다시 계산한다. 공통 스칼라 연산을 별도 모듈로 분리해 두 검증기 번들 모두 제품 회로·채널 계산기를 포함하지 않게 했다. 기존 공개 함수 이름과 형식은 유지했다. 자세한 관례는 [응답 계약](quantum-circuit-response-contract.md)에 기록했다.

## 본문 보강

한영 회로 본문에 Bloch 좌표·순도·연결 상관관계·fidelity를 읽는 절을 추가했다. 확률만 같은 위상 차이, 순수 결합 상태와 혼합된 국소 상태, 곱 상태의 원래 상관관계와 연결 상관관계를 예제로 구별한다. GHZ와 고전 혼합이 같은 두 지점 축약 상태를 가지지만 XXX에서 다르다는 손검산도 추가했다. 전체 교육과정의 분량이나 주차를 제한하지 않는다.

## 검증

독립 SymPy91회로·216단계의 **31286복소 관측값**과 정확히 일치했다. 모든 게이트·선 위치·양방향 제어, 빈 회로, 최대16게이트, 복소 입력·무리수 노름, Bell/GHZ·간섭·전체 위상 예제를 포함한다. 각 회로의 유효 스칼라 한 개를 잘못된 값으로 바꾼91응답을 거부했다. 루트 필드 누락·추가와 확률은 같지만 관측값이 다른 응답도 거부했다.

새 **101검사**, 기존 회로·채널·본문·유니터리 **1098회귀 검사**, 보강 본문의 별도5검사, 타입·lint를 통과했다. Bell 회로의 결합 밀도행렬을 채널에 전달했을 때 Bell 출력·국소 출력·참조계 주변 상태도 일치했다. 두 검증기의 번들 의존성과 준비 코드의 미등록 상태를 확인했다. 참조 데이터 재생성의 바이트 일치와 기존 소스·정적 출력 보존은 `.runtime/learning/quantum-circuit-response/verification.json`에서 확인한다.
