# 정칙 섭동과 잔차 기반 오차 보증: 한영 원고와 계산 기반

2026-11-10. [섭동이론의 범위·일차 자료 검토](perturbation-primary-source-audit.md)를 마치고 첫 단원 `regular-perturbation-residual-certificates`의 한영 원고와 정확 계산 모형을 작성했다. **독립 응답 검증·Worker·학습 화면·실제 reader 등록은 아직 남아 있다.**

## 학습 내용

각 언어판은17절·11표시수식·7해설 문제를 담는다. 비선형 용수철 직관에서 사차 에너지와 유일한 평형,무차원 결합,계수 맞추기와 손계산,잔차의 의미,변위/에너지 오차 보증,수렴 반경과 서로 다른 극한,감수율과 AI 평형 해법 검증으로 이어진다.

모형은 `kx+λx³=h`, `k>0`, `λ≥0`이다. `g=λh²/k³`를 사용해 작은 λ가 충분하지 않은 예제를 설명한다. 고정 차수의 점근성과 고정 입력에서 차수를 늘리는 수렴을 구분한다. 음의 강성·다중 우물·상전이·연속체 장·시간 적분을 구현했다고 주장하지 않는다.

계산기는 정확 유리수 삼중 합 점화식으로0–16차 계수를 구한다. 모든 부분합의 항·직접 잔차·`|F(p)|/k` 오차 보증·`F(p)²/(2k)` 에너지 차이 보증을 계산한다. 기호 잔차의0–N차 소거와 실제 잔차를 확인한다. 최대48회 유리수 이분법의 근 포함 구간과 그 구간에서 얻은 거리·감수율 범위를 제공한다. 수렴 반경 내부/경계/외부와 영 해를 구분하며 수렴 분류를 오차 보증으로 표시하지 않는다.

입력 범위는 `k∈[1/1000,16]`, `λ∈[0,16]`, `|h|≤16`,분자/분모 각12자리다.14예제는 선형/영 원천/부호 반전/공통 재조정,작은 결합의 실패,연한 강성,수렴 경계/외부,정확 유리근과 최대 입력을 포함한다. 입력/예제 번들은 계산 엔진과BigInt산술을 포함하지 않는다.

## 독립 확인

- Python Fraction의 Lagrange 이항계수 공식은 생산 모형의 삼중 합 점화식을 재사용하지 않는다. SymPy가 잔차 다항식을 독립 전개하고 실근을 구간 분리한다.
- **52독립 사례**는14예제·고정seed36입력·최대 분수 표기/작은 결합2입력이다. 모든 계수·항·부분합·잔차·상계와기호 잔차 계수를 대조한다.
- 독립 유리수 검사로 계산 근 구간과 참조 구간의 겹침,끝점 부호,각 근사 오차 보증 구간의 부호를 확인한다.0원천·선형 극한·감수율 상계·동시재조정·입력 소유권/경계값도 검사한다.
- **62검사**와 한영 strict수식 렌더링,타입·대상lint·기존 콘텐츠 검사를 확인한다. 실제브라우저·생산Worker검증 근거로 확대 해석하지 않는다.

명령은 `python3 scripts/learning/regular-perturbation-reference.py`와 `npx tsx --test scripts/learning-regular-perturbation-foundation.test.ts`다. 근거는 `.runtime/learning/regular-perturbation-foundation/`의 `tests.log`, `manuscripts.json`, `verification.json` 등에 보존한다.
