# 보존형 이산화 실습 연결 설계

후속 상태: [두 단원의 홈페이지 통합 검증](continuum-conservative-authoring-status.md)을 마쳤다. 아래 내용은 자료·설계·기반 단계의 기록이며 현재 다음 순서는 연속체 전체 영역 종합 점검이다.

2026-11-06. 기존 홈페이지의 색·타이포그래피·Interactive Book 실습 틀을 사용한다. 이 문서는 화면 구현·브라우저 검증 완료를 뜻하지 않는다. 등록 전에 두 계산 모델과 한영 원고를 각각 검증한다.

## 비균일 체적·공유 플럭스

계산: `src/lib/learning-continuum-volume-discretization.ts`의 실제 Euler 궤적을 사용한다. 표시용 곡선을 별도 물리 해처럼 만들지 않는다.

- 12개 입력: 셀 수 지수3–6, 길이, 면적, 격자 변형, 유속, 확산계수, 평균 농도, 상대 대비, 정수 모드, 위상, 시간 간격, 단계 수. 각 입력이 바꾸는 기하·시간·농도·예산을 연결한다.
- 그림1: 실제 셀 폭을 갖는 농도 막대와 정확한 **셀 평균** 표식. 바닥의 셀 경계를 표시하고 중심 표본과 구분한다. 음수 농도와 과도한 증폭을 잘라 숨기지 않는다.
- 그림2: 공유 면의 방향·플럭스. 주기 연결 면을 명시한다. 전체 이류 플럭스와 평균에서의 편차 플럭스를 구분하고, 작은 변화는 별도 확대 축으로 보여준다.
- 그림3: 단계별 실제 체적 규칙과 평균 체적 대조의 물리 질량·이차 노름. 공유 면 장부와 셀 합산을 따로 표시한다. 상쇄가 나쁜 상태에서는 절댓값 질량 합을 함께 제공한다.
- 수치: 최종 물리 시간, 실제/대조 질량 변화, 노름 변화, 확산·상류 소산, 다음 단계 양의 Euler 보정, 최대 국소 계수, 양성 충분 조건, 체적 적분 오차. 조건 미충족을 실제 결과와 함께 보여주며 dt를 자동 변경하지 않는다.
- 가용성: 부호·로그는 비영인데 일반 수치가 null이면 0으로 표시하지 않는다. 차트에 그리지 못하는 값을 설명하고 예산 수치를 유지한다. 정확한0·언더플로·오버플로를 구분한다.

기본 실험은 N=8,L=2,A=1,g=0.6,a=0.5,D=0.1,c0=1,대비0.8,모드1,위상0.125,dt=0.01,8단계다. 대조 예제는 균일 격자(g=0), 음의 유속(a=−0.5), 순수 확산(a=0), 순수 이류(D=0), 정지(a=D=0), 상수 농도(대비0), 초기 상태(단계0), 과도한 단계(a=D=2,g=0.75,dt=0.25,16단계)를 포함한다.

안내1은 격자 변형을 바꿔 물리 질량과 단순 농도 합을 비교한다. 안내2는 같은 물리 시간에서 격자·dt를 함께 줄여 셀 평균 오차를 본다. 안내3은 큰 dt를 그대로 실행해 보존과 안정성이 다름을 확인한다. 각 안내에는 예상 관찰·실제 수치·설명 질문을 제공한다.

## Godunov·충격파·entropy

계산: `src/lib/learning-continuum-godunov.ts`의 Godunov·미보정Roe 자체 궤적을 사용한다. 전체선 Riemann 해의 정확한 셀 평균을 비교하고, 외부 ghost 셀은 이전 시간의 정확한 외부 셀 평균으로 공급한다. 경계 통과 뒤에도 초기 원방 값을 고정하지 않는다.

- 7개 입력: 셀 수 지수3–6, 구간 길이0.5–4, 좌·우 상태 각각−2–2, 점프 위치1/4·1/2·3/4 선택, 시간 간격0–0.25, 단계 수0–64. 입력한 dt를 그대로 실행한다.
- 그림1: 두 해법의 실제 셀 평균과 전체선 정확한 프로필. 충격파 양쪽 상수 구간은 분리해 그리며, 표본을 대각선으로 이어 매끄러운 전선처럼 보이게 하지 않는다. 희박파는 정확한 선형 fan 구간과 경계 위치를 표시한다.
- 그림2: 면별 보존 플럭스·entropy 결손D. sonic 면에서 Roe의 음의D를 드러낸다. 전체 합이나 셀별 인접 합이0이어도 부적합한 개별 면은 남아야 한다.
- 그림3: 시간별 질량과 실제 수치 경계 장부. 연속체 정확한 질량 변화와 수치 경계 공급을 다른 양으로 표시한다.
- 그림4: 경계entropy·공간결손·양의Euler 보정과 결합된 실제entropy 변화. 별도 반올림 성분 합이 작은 결과를 잃을 수 있으므로 `roundedEntropyComponentSum`을 참값으로 대체하지 않는다. 수치entropy와 정확한 연속체entropy 적분도 구분한다.
- 수치: 셀 평균L1오차, 재구성 프로필L1오차, 계산한CFL·국소충분조건·면별적합성, 정확한충격위치·검출교차수·실제단계시간. 여러 교차를 임의의 하나로 고르지 않는다. 상수상태에 가상의 충격/희박파경계를 만들지 않는다.
- 가용성: null의 일반 수치는 부호·로그와 함께 설명한다. 작은 비선형 나머지/오차를0으로 표시하지 않고, 불안정한 큰 진폭은 축 범위·가용성으로 설명한다. 임의로 클리핑한 다른 궤적을 보여주지 않는다.

기본값은N=8,L=2,qL=1.5,qR=0.5,중간점프,dt=0.01,12단계다. sonic희박파(−1→1), 정지압축(1→−1), 양의희박파(0.5→1.5), 음의충격(−0.5→−1.5), 음의희박파(−1.5→−0.5), 상수(1→1), 초기상태(단계0), 경계통과(1→0.5,dt=0.25,16단계), 과도한단계(2→0,N=64,L=0.5,dt=0.25,64단계)를 준비한다. 경계통과 예제의CFL 엄격판정은 반올림 때문에1경계 부근에서 달라질 수 있으므로 실제 수치도 보여준다.

안내1은sonic희박파에서두해법의공유플럭스와D를비교한다. 안내2는같은물리시간에서격자·dt를함께바꾸며실제충격위치와재구성오차를본다. 평균오차만으로충격의해상도를판정하지않는다. 안내3은경계통과와과도한시간간격에서실제경계수지·entropy보정을확인한다. 주기4셀손계산·2셀Roe상쇄·양의advective질량손실은본문과계산검사에서별도스텐실임을명시한다.

## 통합 완료 조건

두 단원의 한영 본문·고정 개념·퀴즈·각3개 안내와 실제 모델을 연결한다. 모든 입력·예제·정지/영/작은 변화·과도한 시간 간격을 검증하고, 한영·명암·모바일·키보드·원본SVG·정적 출력·영어 순회를 통과한 뒤 등록 단원·검증 주제 수를 갱신한다. 진입은 **도서 → Interactive Book**이며 Online Book 목록에 새 카드를 넣지 않는다.
