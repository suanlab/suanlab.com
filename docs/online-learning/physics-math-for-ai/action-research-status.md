# 작용·정상 작용: 끝점 비용과 전체 변분 공간

2026-11-12. 자유 입자·조화진동자 두 단원의 한영 원고 4편을 보강하고 검증했다. 기존 본문·여섯 연습 문제·실습 입력을 보존한다. 전체 해석역학 연구 대조 완료를 뜻하지 않는다.

## 보강 내용

- 자유 입자의 부드러운 끝점 비용을 작용 단위로 정의한다. 전체 경로의 정확한 분해로 끝점 최적화를 풀고, 전미분과 끝점 비용을 함께 변환해야 목적함수가 점별로 같아짐을 증명한다.
- 양의 끝점 곡률·음의 곡률·영 곡률의 경우를 구분한다. 축약 끝점 함수의 최대가 전체 경로에서는 안장이 될 수 있음을 설명한다.
- 조화진동자의 전체 Fourier 변분에서 Morse 지수와 핵 차원을 구한다. 이차 값의 상쇄와 쌍선형 형식의 핵을 구분한다. 두 시험 모드의 그림과 전체 공간의 지수는 다른 범위다.
- 켤레 구간에서 끝점 자료의 적합성·무한 해 가족·해 부재·역문제 민감도와 완전한 초기값 흐름의 가역성을 연결한다.
- 증명·직관·비교표·실행 Python 셀과 그림 2종의 한영 SVG 4개를 제공한다. 새 끝점 벌점·추가 Fourier 모드를 기존 실습 조작에 구현했다고 표시하지 않는다.

## 검증 결과

독립 표준 라이브러리 `python3 scripts/learning/verify-action-research.py`에서 정확 유리수 경로 1,152개, 정확한 Morse 분류 117설정, 독립 이차 형식 적분 162개, 임계 끝점 36조건과 임계 근처의 끝점 오차 40조건을 검산했다. 한영 표시 수식은 각각 6개·7개이며, 대응 Python 셀 4개의 실행 결과가 일치했다.

- 선택 **16개 파일·356개 검사**, lint·콘텐츠·타입·빌드·출력 검사를 통과했다. 전체 저장소 검사나 전체 CI 성공으로 집계하지 않는다.
- 최종 정적 빌드는 **1,893경로·1,888 HTML**이다. 8개 고정 소스 해시, SVG 4개의 소스/출력/제공 바이트, 두 단원의 출력/제공 HTML 바이트를 대조했다.
- 변경 두 단원을 한영 320·768·1440px 라이트와 한영 1440px 다크의 **16상태**에서 검사했다. 안내 6개·퀴즈 4개·개념 선택 8개·저장/완료 2그룹이 통과했다. 수식/표/코드의 키보드 스크롤, 목차, 이미지 decode도 확인했다. 페이지 오류·Axe 위반은 0개다.
- 한영 SVG 원본 4개와 모바일 화면 4개를 직접 검토했다. 모바일 화면 캡처는 가로 스크롤을 조작한 상태를 포함한다.
- 기존 본문 전체 바이트와 이전 검토 항목 649개를 보존했다. 새 검토 항목 4개만 추가해 총 653개다. 등록은 **650단원·1,969안내** 그대로다.
- 이전 20단원·160화면 검증은 당시의 근거로 보존한다. 이번 화면 검증은 바뀐 두 단원의 범위이며 전체 해석역학의 연구 깊이 최종 검토를 대신하지 않는다.
