# 연속체 가정 두 단원의 집필 설계

이후 [홈페이지 통합과 최종 검증](continuum-assumptions-authoring-status.md)을 마쳤다. 아래 수치와 다음 단계는 기초 작성 당시의 기록이다.

2026-11-06. [자료 검토](continuum-assumptions-source-audit.md)에 따라 일반 대학원생이 미시 입자와 평균장의 연결을 계산할 수 있도록 설계한다. 계산·상세 한영 원고를 먼저 검증하고 홈페이지 실습을 연결한다. 원고만으로 원래 주제나 영역 전체를 완료 처리하지 않는다.

## 1. 입자 커널과 연속장

ID: `particle-kernel-continuum-fields`. 선수는 이동 제어체적의 질량 수송, 미적분과 가중 평균이다.

- 같은 초기 입자의 탄도 궤적, 지지 구간과 실제 관측 위치를 함께 그린다. 서로 통과하는 입자를 충돌로 바꾸지 않는다.
- 정규화한 C1 compact 사차 커널의 폭을 조절해 입자 기여·선밀도·질량 유속·가중 속도·이차 모멘트·분산 수송을 분리한다.
- 반대 방향 두 입자의 평균 속도0과 비영 운동량 수송, 같은 속도에서 분산0을 비교한다.
- 전체 질량과 유한 관측 창의 적분, 시간 변화와 실제 경계 유입을 비교한다. 화면 안의 질량으로 재정규화하지 않는다.
- 빈 지지 구간의 미정 속도, 영길이 창의 미정 평균, 지원하지 않는 작은 폭의 거부를 표시한다.
- 고정 폭의 국소 수지와 폭 변화율에 따른 관측 항을 대조한다. 그림의 평활성을 유체 타당성으로 해석하지 않는다.

계산 범위: 입자1–64개, 질량0.1–4kg, 초기 위치±4m, 속도±2m/s, 시각±1s, 관측 위치±8m, h=0.02–2m, 폭 변화율±0.5m/s. 양의 구간 길이는10⁻⁸m 이상이며 정확한 영길이는 별도로 처리한다. 실제 UI의 조작 수는 읽기 쉬운 고정 입자 배치와 명시된 선택으로 정한다.

## 2. 연속체의 척도 분리와 계수 요동

ID: `continuum-scale-separation-counting`. 선수는 입자 평균장, 분산·표준편차와 무차원 비다.

- 입자 간격, 평균 자유 행로, 평균 창과 거시 길이를 로그 축에서 구분한다.
- 정육면체의 기대 계수·Poisson 상대 요동과 지정한 허용 요동을 비교한다. 실제 관측 정수 개수와 기대 개수를 구분한다.
- 계수 하한·충돌 하한·해상도 상한을 동시에 그린다. 가능한 구간의 존재와 현재 창의 통과를 따로 표시한다.
- 같은 입력에서 L을 줄여 후보 구간이 사라지는 경우와 창만 너무 작거나 큰 경우를 대조한다.
- 고정 N의 이항 분산과 Poisson 기준을 비교한다. p=0의 미정 비와 p=1의 정확한0을 구분한다.
- Fano 계수·상관·시간 척도·벽면·국소 평형·구성 관계의 미검증 범위를 본문과 캡션에 설명한다.

## 원고와 통합의 완료 조건

각 원고에 직관, 선수 개념, 단위, 가정, 유도, 손계산, 잘못된 추론, 실험 순서와 풀이6개를 포함한다. 한영 수식·목차·출력·독립 계산·기존482단원 보존을 확인한다. 이후 기존 사이트 테마로 각 단원의 정밀 입력, 고정 개념 단계4개, 안내3개, 퀴즈2개를 연결하고 최종 빌드·한영 반응형·키보드·접근성·그림 직접 검토를 거쳐 완료 수를 갱신한다.
