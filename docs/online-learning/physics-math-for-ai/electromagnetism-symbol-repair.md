# 전자기학 연구 원고의 기호 표시 수정

2026-11-13. 전자기학 전체 원고 감사에서 Maxwell Gauss 보정 단원의 평문 별표가 Markdown 강조로 처리되는 문제를 확인하고 수정했다. **20/20단원 순차 보강은 유지하며 영역 전체 연구 종합 대조는 미완료**다.

## 발견과 수정

`maxwell-charge-displacement-continuity`의 한영 원고에서 의도하지 않은 강조 노드 **5개**를 확인했다. 새 회귀 검사는 수정 전 **1실패**를 재현했다. 보호한 표시/인라인 수식·코드와 기존 본문을 유지하고 평문·표 머리·해설의 `E_*`, `ρ_*`, `U_*`, `rho_*`를 문자 `∗`로 바꿨다. 한영 각각 **10곳**, 총 **20곳**이다.

연구 AST의 강조 노드가 0개임을 검사하고 실제 reader의 일반 문단에서 `E∗`, `ρ∗`, `U∗`가 KaTeX 밖의 문자로 표시되는지도 확인한다. 보존 원장은 757항목을 유지하며 이전 755항목은 같고 두 개만 정확한 구/신 해시·검토 경로로 갱신했다. 전자기학 보강 전 717항목은 모두 같다. 이전 연구 입력 152개 중 150개는 같고 두 원고의 평문 기호만 명시적으로 바뀌었다. 40개 전자기학 그림은 그대로다.

- 38파일 **487검사**와 lint·콘텐츠·새 빌드·타입·정적 출력 검사가 종료 코드 0이다. 빌드 1,893경로·내보내기 1,888 HTML을 확인했다.
- 새 `node scripts/learning/audit-electromagnetism-research.cjs`로 40원본문·240기존 해설 보존, 40 Python 실행/표, 364연구 표시 수식과 120연구 해설, 159단원 선수 폐포를 대조했다. 한영 연구 수식·코드·출력은 같고 원래 수식도 공백을 제외하면 같다. 현재 40렌더링 원고가 한국어 SSR/디코딩한 영어 Flight에 정확하게 들어간다.
- 교정 범위 두 단원의 한영 320/768/1440px 라이트·1440px 다크 **16화면**, 6안내·4퀴즈·8개념·2저장/완료 그룹을 확인했다. 교정 대상 한 단원의 8언어/폭/명암 상태에서 세 평문 기호를 검사했다. 페이지 오류·Axe 위반은 0이며 모바일 캡처 네 개를 직접 검토했다.
- 40개 SVG의 원본/출력/실제 제공 바이트, 20개 HTML의 출력/실제 제공 바이트가 같다. 이는 로컬 최종 출력 검증이며 공개 배포 완료 선언은 아니다.
