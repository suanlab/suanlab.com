# 반응수송 화면 통합 설계

이후 [홈페이지 통합과 최종 검증](continuum-reaction-transport-authoring-status.md)을 마쳤다. 아래 미완료 설명·수치는 이 문서 작성 당시 기록이다.

2026-11-06. 계산 모델과 상세 한영 원고는 작성했다. 이 문서는 다음 구현의 검증 기준이며 화면을 이미 제공한다는 뜻은 아니다. 진입은 **도서 → Interactive Book**이다.

## 공통 구성

기존 테마의 색상 변수·명암·정밀 숫자 입력·반응형 SVG와 진행 저장을 사용한다. 각 단원에 고정 개념4단계, 안내 실험3개, 퀴즈2개와 상세 원고를 연결한다. 새 전용 순수 계산 모듈을 기존 실습의 어댑터로 호출하고 기존 연속체 실습은 보존한다. 계산하지 못한 비영 관측은 unavailable로 표시하고 수학적 영과 구분한다. 한영 라벨·설명·단위·접근성 이름을 모두 제공한다.

## 가역 반응과 종별 질량 수지

ID: `reversible-reaction-advection-diffusion-budget`.

입력은 전체 질량·관 단면적·초기 폭과 중심·이류 속도·확산계수·정반응률·역반응률·초기 A 비율·시간·관측 위치·관측 창이다. 두 종과 전체 농도 곡선, 종별 플럭스, 양방향 전환량과 순원천, 시간별 조성과 평형선을 보여준다. 창의 저장 변화·순유출·반응 적분을 같은 kg/s 단위로 비교한다. 전 직선 종별 질량과 합은 창 질량과 구분한다.

개념은 ①공통 운반장과 분리 가정 ②정·역반응과 순원천 ③종별 수지와 합의 보존 ④관측 한계와 독립 검증 순서다. 안내는 기본 비평형 완화, 같은 속도의 평형에서 양방향 전환, 이동 구름을 좁은 창에서 관측하는 실험으로 구성한다. 퀴즈는 순원천0과 사건0의 차이, 창 질량 감소와 전 직선 질량 보존의 양립을 묻는다.

필수 상태는 두 반응률0의 비유일 평형, 한쪽 반응만 있는 경우, 양의 속도의 평형, 전체 질량0의 미정 측정 비율, 작은 생성 B와 반올림된 A=1, 빠른 완화의 비영 로그 꼬리, 먼 Gaussian 꼬리다. 같은 실제 장에서 반응을 누락한 잔차와 실제 원천을 비교한다. 수치 재정규화·꼬리 절단·가짜 평형값으로 결과를 맞추지 않는다.

## Fisher–KPP 성장 전선

ID: `fisher-kpp-reaction-diffusion-front`.

입력은 양의 확산계수·성장률·수용 농도·배경 속도·초기 기준 위치·단면적·시간·관측 위치·관측 창·상대 농도 수준이다. 농도와 기준점·절반/선택 수준 위치, 기울기·곡률, 이류/확산 플럭스, 시간 변화와 성장 원천, 유한 창 수지를 보여준다. 상대 속도와 실험실 속도를 별도로 표시한다. K/4 기준점을 절반 위치로 부르지 않는다.

개념은 ①성장과 열린 모델 ②직접 미분과 정확한 특수 프로필 ③수준 위치와 기준계 ④유한 창·포화·로그 꼬리다. 안내는 손계산 D=1/6,r=1,K=4, 배경 속도로 실험실 전선을 정지시키기, 같은 장에서 성장항을 누락하기다. 퀴즈는 전체 질량의 발산과 유한 창의 차이, 특수 속도와 임의 초기조건의 속도 선택을 묻는다.

필수 상태는 전선의 좌우 꼬리, 반올림 c=K와 양의 안정 여량·성장, 선형 농도 언더플로와 유한 로그, 배율에서 회복되는 원천, 작은 이동과 반올림된 기준점, U=-v에서 정지하는 실험실 프로필이다. 전체 질량 카드는 수치 infinity 대신 설명 가능한 발산 상태를 표시한다. D=0/r=0을 같은 프로필로 그리지 않으며 모델 밖의 자원을 숨겨 닫힌 질량 보존처럼 설명하지 않는다.

## 통합 완료 조건

등록 전 기존490단원·1,470안내와43실험 그룹481항목의 canonical 내용·상대 순서를 다시 확인한다. 등록 후 두 단원의 선수·이전/다음·목차·상세 원고와 검색/사이트맵을 검사한다. 전체 테스트·타입·lint·콘텐츠·정적 export 검사를 수행한다. 빌드 출력을 고정한 뒤 한영·명암·좁은/넓은 화면에서 실제 입력, 프리셋, 재설정, 키보드 수식·SVG 탐색, 콘솔·오버플로·접근성 검사를 수행하고 원본 그림을 직접 검토한다. 실제 종료 기록과 해시가 확인된 뒤에만 주제 입문 검증 수를 올린다. 전체 영역 감사와 연구 심화 완료는 별도로 남긴다.
