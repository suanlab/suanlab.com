# Fokker–Planck 두 단원: 교재 연결과 검증

2026-11-08. OU 모멘트와 셀 질량·경계의 두 단원을 도서 → Interactive Book에 연결했다. 입문 주제의 전체 읽기·수명·접근성 검증을 정상 종료했다.

한영4본문·표시 수식44개·해설24문제,12개념 단계·예측,32이름 붙은 준비,6안내와6최종 확인 문제를 연결했다. 기존 색·글꼴과 Interactive Book 메뉴·검색·breadcrumb·표지를 사용한다. Online Book 목록에는 추가하지 않았다. 기존536단원·1608안내의 값·순서와 영역 메타데이터를 보존하고 총538단원·1614안내가 됐다.

시간 기록과 절단 선택은 새 계산을 만들지 않는 표시 조작이다. 입력은 물리 시간과 N/M을 구별한다. 셀 수 변경은 기존 구간별 상수 초기 밀도를 새 셀과의 겹침 길이로 적분해 질량을 재분배한다. 반사·흡수 변경이 결합 계산 조건을 넘으면 이전 준비와 설명을 유지한다. 원자에 얇은 밀도를 만들지 않고, 음수 명시 결과를 자르거나 넓은 반군 구간에 중간값을 부여하지 않는다. 탈출 장부에는 밀도가 없고 생존 조건부 재정규화도 하지 않는다.

## 계산·전달·수명

사전 독립32준비의861시간 기록·960절단 기록을 생산 모델로 옮겼다. 현재 Node 생산 결과는 루트의 계약 설명을 제외한 모든 수치 필드가 사전 결과와 일치한다. 사전240자리 해·분산 핵 구적·정확 유리수 점화, 별도 면 흐름 연산자·SymPy 역행렬·행렬 지수·양의 꼬리 대조는 이전 준비 기록에 보존했다.

규약은 소유 입력·정수 원문·배열 길이·범위·결합 작업량, 요청/준비 식별과 전체 결과 구조·기록 순서·제공 조건을 검사한다. 이는 송신자의 수학적 진실성을 증명하는 검사는 아니다. 실제 계산은 요청별 native worker에서 수행하고 교체·취소·단원 이동은 이전 worker를 종료한다. 동기 대체 계산은 없다. 저장 JSON은 소수 손실과 비영 underflow를 검사한 뒤 읽는다.

곡선 좌표·로그 표시는 근사다. 첫 브라우저 실행에서 Node와 Chromium의 Math.log 마지막 자릿수가 약1e−15 차이 났다. 원본 실패를 보존하고 정확 유리수·구간 끝점·부호·정의 상태·메타데이터는 엄격히, 표시 value만 상대2e−13·근사 logMagnitude만5e−12×max(1,|기준|)로 대조한다. 수치 모델은 바꾸지 않았다. 처음16조합의 worker 집계가 새로고침 이후 요청만 세는 점을 발견해 전후를 각각 합산·균형 검사하도록 보완하고 전체 조합을 다시 실행했다. 첫16조합의 기능·수치·접근성 통과 기록과 후속 검증을 구별해 보존했다.
