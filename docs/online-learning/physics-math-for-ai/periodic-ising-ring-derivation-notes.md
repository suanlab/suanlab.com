# 주기 Ising 고리: 유도와 실제 입력 계산 계약

## 계·거리·정규화

N=3..128인 이름 붙은 고전 스핀의 단순 주기 고리다. N개 최근접 결합을 한 번씩 세고 모든 국소 장은 0이다. 입력 K∈[−8,8]는 전달된 binary64 수를 정확한 실수로 해석한다. 두 위치의 오프셋은 r∈{0,…,N−1}, 최단 거리는 d=min(r,N−r)다. N=2의 두 평행 결합이나 앞의 단일 두 스핀 결합을 이 관례와 혼용하지 않는다.

각 bond에 `exp(K*si*sj)=coshK*(1+t*si*sj)`, t=tanhK를 쓰자. 스핀 합에서 선택 edge의 각 위치 차수가 짝수여야 하므로 빈 집합과 전체 고리만 남는다. 따라서 `Z=(2coshK)^N*(1+t^N)`다. 스핀 둘을 삽입하면 두 끝점의 차수만 홀수여야 하므로 양쪽 경로가 남는다. 그 결과 `C(r)=(t^r+t^(N−r))/(1+t^N)`다. r=0은 자기 상관 1로 따로 처리한다. 유한 영장에서는 전체 스핀 반전으로 위치 평균이 정확히 0이다.

## 독립적인 전달행렬 확인

`T=[[expK,exp(−K)],[exp(−K),expK]]`, `D=diag(−1,1)`로 놓으면 `Z=trace(T^N)`, `C(r)=trace(D*T^r*D*T^(N−r))/Z`다. 직접 2×2 행렬을 곱하는 참조는 고윳값·tanh·기하급수 합을 사용하지 않는다. 양의 T 원소와 음의 둘째 고윳값을 구별한다. 전달행렬을 정규화 없이 시간 확률 전이로 해석하지 않는다.

## 부호와 안정적인 양의 표현

v=|t|∈[0,1), `G_n(v)=Σ(j=0..n−1)v^j`다. K<0이면 최단 거리 기준 부호는 (−1)^d다. 짝수 고리에서는 양쪽 경로 부호가 같고, 홀수 고리에서는 반대다. 홀수일 때 공유 인수 1−v를 먼저 지우면

`|C(d)|=v^d*G_(N−2d)(v)/G_N(v)`.

짝수 또는 양의 K에서는 `|C(d)|=v^d*(1+v^(N−2d))/(1+v^N)`다. 두 식은 음의 항을 더해 작은 상관을 얻는 계산을 피한다.

공통 무차원 장 b를 총스핀 M에 결합하면 영장에서 `χ=∂b E[M/N]=Var(M)/N=Σr C(r)`다. 관측 평균의 분산은 χ/N이다. 기하급수를 합한 χ 식을 다시 정리하면 다음 양의 식을 얻는다.

- K≥0: `χ=(1+v)*G_N(v)/(1+v^N)`.
- K<0, N 짝수: `χ=(1−v)^2*G_N(v)/[(1+v)*(1+v^N)]`.
- K<0, N 홀수: `χ=(1+v^N)/[(1+v)*G_N(v)]`.

u=exp(−2|K|)로 `v=(1−u)/(1+u)`, `1−v=2u/(1+u)`를 계산한다. 홀수 반강자성의 로그 고리 보정은 `log(1−v)+log(G_N)`로 구한다. 이와 함께 `log(2coshK)=|K|+log(1+u)`를 써서 log Z를 복원한다. 모든 유한 입력에서 χ는 양수다.

## 작은 값·로그·상한

지수·로그는 기존 방향성 고정소수점 함수로 계산한다. 양의 기하급수와 보정 인수는 구간 연산으로 전파한다. `v^d`는 작업 격자로 잘라내지 않는다. v 경계 정수의 정확한 거듭제곱에 이진 지수 `−P*d`를 따로 보존한다. 따라서 K가 최소 양수이고 d=64이어도 비영 상관의 부호와 상대 구간 폭을 인증할 수 있다.

직접 계산한 `log|C|=d*log(v)+log(분자 보정)−log(분모 보정)`도 별도 관측량이다. 일반 관측량의 크기 로그 투영은 근사이며 이 방향성 로그와 구별한다. 128,…,8192비트에서 상대 폭 ≤2⁻⁴⁸ 및 비영 부호를 요구한다. 상한에서 미해결을 0으로 바꾸지 않는다. K=0의 비자기 상관은 구조적 0이며 로그는 음의 수학적 무한대다. ξ=0은 독립 영 범위의 연속 극한으로 명시하며 유한 log(0)을 계산하지 않는다.

## 참조의 실제 검증 범위

Python Decimal은 실제 입력을 `Decimal.from_float`로 읽는다. 독립 닫힌 식 20사례·2,580관측을 400/900/1200자리 및 추가 80자리에서 재계산한다. 이 중 18사례를 전달행렬 trace와, 11사례를 672개 이름 붙은 배치의 직접 열거와 대조한다. 최소 결합·긴 고리 두 사례는 전달행렬 상쇄에 필요한 자릿수가 이 예산을 훨씬 넘으므로 **닫힌 식 참조만 사용했다고 명시**한다. 그 두 사례까지 독립 trace 검산이라고 세지 않는다.

## 길이와 극한

고정 거리·고정 유한 K에서 N→∞일 때 `C∞(r)=t^r`, 포락선 길이는 `−1/log|t|`다. 이는 유한 둘레를 무시하는 거리 절단이나 시간 상관시간이 아니다. 음의 K에서 큰 길이와 작은 균일 응답 exp(2K)가 공존하며 교대 source의 반응은 다르다. 고정 홀수 N의 K→−∞에서는 2N개 바닥 배치의 M=±1 때문에 χ→1/N이다. 이 극한, 유한 온도 사슬, 완전 연결 평균장의 임계점을 구별한다.
