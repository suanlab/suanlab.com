## 유한 집단의 수치 계약

`learning-finite-kuramoto-input.ts`는 N=1…32의 소유 정수 배열과 유리수 계수·초기 위상을 검증하고 복사한다. |ωᵢ|≤8,K≤16,T≤4s, 기본 격자1…1024와 표시 기록1…64를 지원한다. 실제 입력 검사와 배열 복사를 통과한 준비만 계산한다.

`learning-finite-kuramoto.ts`는 전체 결합 K/N을 쓴다. 일반 궤적은 n,2n,4n RK4 중 가장 촘촘한 결과다. 시간 간격 비교와 d₂/15는 **형식적 진단이며 증명된 오차 구간이 아니다**. 의도적인 거친 격자에서는 독립 참조에 대한 최대 위상 오차가 약5.34rad인데 형식적 추정은 약0.114rad다. 이 실패를 정상 정확도 검사와 구별해 남긴다. 정상 일반 사례는 참조 대비1e−6rad 예산, 해석적 회전 사례는1e−13rad 예산으로 검사한다.

동일 주파수의 정확한 균형 정다각형과 K=0에서는 해석적 회전을 별도 주 궤적으로 사용한다. 대칭 여부는 정수 관계로 확인하며 가까운 상태를 같은 상태로 보정하지 않는다. 수정하지 않은 RK4 결과도 함께 제공한다. 정지한 반대 위상의 불안정 대칭에서 계산 오차가 증폭되는 사례를 물리적 잡음으로 해석하지 않는다.

R₁=0,R₂=1의 반대 집단과 R₁=R₂=0,R₄=1의 사분점 집단을 구별한다. 정확한0에는 평균 방향이 없고 일반 부동소수점 관측에는 정확한 대칭 판정을 붙이지 않는다. 음의 퍼텐셜 −KN R₁²/2의 감소 항등식은 동일 주파수에 적용하며 물리적 열·엔트로피라고 부르지 않는다. N=2를 앞 가족의 δ̇=Δ−Ksinδ와 대조했다.

표시 기록은 기본 격자에서 floor(in/S)번째 시각을 선택한다. 실제 시각과 정확 유리수 표현을 보관하고, 표시 밀도만 바꾸어도 끝점과 전체 진단이 유지됨을 검사한다. 위상 감기·평균 재조정·수치 질서 변수의 강제 클리핑으로 잔차를 숨기지 않는다. 순간 속도와 유한 창 평균으로 장시간 동조·안정성을 자동 판정하지 않는다.

## 별도 Lorentzian 비교와 원고

Lorentzian 무한 집단의 Ott–Antonsen 비교는 폭 γ를 따로 지정하고 불변 다양체·해석성 조건을 설명한다. 유한 주파수 배열에 맞추어 γ나 임계값을 추정하지 않는다. Kc=2γ, 양의 가지 R*²=1−2γ/K, 그 가지의 회복률 K−2γ를 유도한다. 임계에서 지수 이완시간은 빈값이다. 기계 반올림으로 K와2γ가 같아 보이는 두 사례도 정확 유리수 부호로 구별한다. Lorentzian 중심은 존재하지 않는 Cauchy 산술 평균으로 설명하지 않는다.

- Hopf: [한국어](hopf-amplitude-critical-relaxation-chapter.ko.md) · [영어](hopf-amplitude-critical-relaxation-chapter.en.md)
- 두 진동자: [한국어](two-oscillator-locking-phase-slips-chapter.ko.md) · [영어](two-oscillator-locking-phase-slips-chapter.en.md)
- 유한 집단: [한국어](finite-kuramoto-collective-order-chapter.ko.md) · [영어](finite-kuramoto-collective-order-chapter.en.md)

각 원고는14절·표시 수식10개·표2개·풀이6개다. 실제 Markdown/KaTeX, 한영 수식 일치, 정확한 균형 집단과 회복시간 비교표를 독립 준비와 연결해 검사했다. 관측 통계량의 정보 손실과 AI 표현의 식별 한계, 단일 진동자 진폭과 집단 질서의 차이도 설명한다.
