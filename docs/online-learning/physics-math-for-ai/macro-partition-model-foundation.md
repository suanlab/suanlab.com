# 가중 미시분포의 결정론적 거시 관측 모델

2026-11-06. `finite-macro-partition-conditional-entropy`의 생산 모델을 독립 검증했다. 첫 이진 가족의 한영 원고에 이어 둘째 계산 가족을 완성한 단계다. 둘째 한영 본문·잡음 관측 가족·세 가족의 교육 UI와 홈페이지 등록은 남아 있다.

## 모형과 출력

`macroPartitionModel(w,v,mapping,groupCount)`는1–32개 미시상태와1–32개 선언된 군을 지원한다. 이는 유한 계산기의 자원 한도다. 준비 가중치와 비교 목표 가중치는 유한·비음수이며 각각의 합은 양수여야 한다. 두 벡터의 길이와 사상은 일치해야 한다. 누락된 원소나 범위 밖 라벨을 자동으로 보정하지 않는다.

가중치와 군의 합, 확률·조건부·균등 재구성 확률의 분자/분모는 정확한 이진 유리수로 유지한다. 원래 준비의 미시 엔트로피, 관측 군의 엔트로피, 가중 조건부 엔트로피, 별도로 정한 군 내부 균등 재구성의 엔트로피를 반환한다. 재구성 증가량은 가까운 두 엔트로피의 차이 대신 양의 조건부 KL 합으로 계산한다.

목표 분포와의 미시·거시·조건부 KL도 별도로 제공한다. 작은 상대 차이에는 양의 Bregman 급수를 사용하고, 확률 또는 KL이 underflow해도 원래 분자와 로그 증거를 유지한다. 로그·엔트로피·KL은 근사이며 보편적인 정확 반올림을 주장하지 않는다. 이진 유리수 합·곱·비의 정확성과 초월함수 근사는 다른 계약이다.

## 0·미정·무한대

선언된 빈 군과 상태를 갖지만 준비 확률이0인 군을 구분한다. 양수인 군에서만 조건부를 정의하며, 확률0인 군의 가중 엔트로피 기여는0이다. 수학적 KL 무한대는 `status: infinite`로 표시한다. 유한하지만 표시 범위 밖인 양수는 `status: finite`, `value: null`, 양의 부호와 유한 로그를 유지한다.

P가 양수지만 Q가0인 군의 목표 조건부는 미정이다. 전체·거시 KL이 무한대인 사실과 별도로 해당 조건부 분해 항과 합을null로 둔다. 무한대끼리 빼서 숨은 KL을 만들지 않는다. P=0 군은 조건부를 임의로 채우지 않고 가중 기여만0으로 둔다.

## 독립 검증과 정밀도 교정

Fraction 정규화와 mpmath 직접 로그 합으로 일반24개·극한12개를 비교했다. 생산 모델은 이 참조를 가져오거나 런타임에 사용하지 않는다. 총46개 검사가 전체/군/조건부/재구성 분포와 정보량, 엔트로피·KL 연쇄, 같은 거시분포의 다른 미시분포, 일대일/단일군 관측, 라벨·순서·스케일 불변성, 입력 거부와32상태 경계를 확인한다.

초기1800자리 참조의 한 실패를 조사하니 군 KL이 약10⁻¹⁸⁹⁵인 사례에서 직접 로그 합의 상쇄 잡음이 남았다. 참조 정밀도를4096자리로 올리고 내부 항등식의 절대 허용치를10⁻³⁰⁰⁰으로 설정해 교정했다. δ=MIN_VALUE/MAX_VALUE일 때 이 사례의 거시 KL이 점근적으로δ³/2라는 별도 로그 비교도 추가했다. 수정 참조의 독립 재생성은 바이트까지 일치한다. 과거1800자리 준비 증거를 현재의 모델 검증으로 사용하지 않는다.

추가 성질 검사의 정확한 동등성 주장은 선형 확률과 실제0에 적용한다. 서로 다른 정수 표현에서 계산한 근사 로그의 비트 일치나, 한 ULP 차이를 갖는 준비의 근사 엔트로피끼리 정확히 같다는 가정은 하지 않는다. 작지만 양수인 재구성 증가량을 직접 검증한다. 타입 검사와 대상 lint도 수행한다.
