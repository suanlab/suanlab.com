# 보존 이산화 연구 보강 검증 기록

2026-11-13. [설계](continuum-conservative-research-plan.md)에 따라 확률 평균·볼록 엔트로피와 공간 플럭스·시간 단계 보정을 기존 두 단원에 추가했다. 한영 원고 4편·그림 4개, 표시 수식 40개·실행 표 4개·연구 해설 12개를 연결했다. 보충 절 제거로 기존 본문 4편과 풀이 24개를 원래 해시로 복원했다. 원래 Python/TypeScript 예제·실제 실습·등록 순서를 보존했다.

## 추가한 설명

- **비균일 체적:** 대칭 비음 확산의 체적 가중 생성자와 Poisson uniformization을 유도한다. 농도·셀 질량 확률·상대 엔트로피의 단위를 구별하고 모든 볼록 함수의 수축, 영 농도의 로그 미분 특이성, 영 생성자·영 저장량·분리 성분을 설명한다. 질량과 이차 노름은 맞아도 음의 농도를 만드는 정확한 Euler 반례를 제시한다.
- **Burgers:** 엔트로피 보존 플럭스와 물리 플럭스 산술평균, 비음 소산 구조와 면 결손을 비교한다. 반이산 부등식과 실제 Euler 단계의 양의 보정·범위 위반을 구별한다. 기존 Godunov/Roe 솔버를 교체하지 않으며 구조 하나로 단조성·모든 엔트로피·시간 안정성을 인증하지 않는다.

## 검증 결과

관련 8파일 **381검사**, lint·콘텐츠·생산 빌드·타입·정적 출력 검사를 통과했다. 1,893경로를 생성하고 1,888 HTML을 검사했다. 소스/도구 5,356파일과 이전 연구 입력 232개를 고정했다. 보존 장부는 기존 797항목에 새 4항목을 더해 801개다.

독립 표준 라이브러리 검산은 체적 가중 반군·볼록 진단 15사례(끊긴 성분·영 생성자·영 저장량 포함), 정확 면 엔트로피 75사례·비균일 주기 Euler 예산 36사례와 정확 노름/양성·산술 플럭스 반례를 포함한다. Taylor와 Poisson 전파를 별도로 비교했다. 유한 계산은 해석적 주장이나 일반 솔버 검증을 대신하지 않는다.

동일한 새 출력과 실제 제공 파일을 대조했다. 한영·320/768/1440px·명암 **16화면**, 안내 6개·퀴즈 4개·개념 8개·저장/완료 2흐름을 확인했다. 페이지 오류·접근성 위반은 0이다. 최종 모바일 캡처 4개와 원본 크기 그림 4개를 직접 검토했다. [검증 JSON](continuum-conservative-research-evidence.json)에 근거를 연결했다. 로컬 검증은 공개 배포 성공을 뜻하지 않는다.
