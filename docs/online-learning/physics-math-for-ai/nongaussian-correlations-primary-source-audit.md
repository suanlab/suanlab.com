# 비가우스 연결량: 범위와 일차 자료 검토

2026-11-10. 상관함수의 첫 가우스 단원은595등록 단원·1826안내에 포함되었다. 두 번째 처리 `interacting-nongaussian-connected-correlations`의 상세 모형을 아래처럼 확정한다. 입문314/362검증·48미완료와 전체51영역509주제의 범위를 유지한다.

## 직접 확인한 자료와 사용하는 부분

- [Tong, Statistical Field Theory §1.1·§1.2.1](https://davidtong.org/teaching/statistical-field-theory/sfthtml/S1): 고전 이진 스핀·이웃 에너지·분배함수와 유한계/무한계 극한의 구분을 확인했다. 유한 합산을 상전이 검증으로 소개하지 않는다.
- [Tong, §2.2](https://davidtong.org/teaching/statistical-field-theory/sfthtml/S2): 물리 원천과 log Z 미분의 온도 인자를 확인했다. 가우스 결과를 상호작용 분포의 Wick 규칙으로 일반화하지 않는다.
- [Helias·Dahmen, Statistical field theory for neural networks, §§II.3–II.4·III.2–III.3](https://arxiv.org/html/1901.10416v1): 로그 생성함수, 삽입 자리의 분할, 반복 첨자와 가우스 쌍짓기의 특수성을 본문에서 확인했다. 논문의 동역학·평균장·loop 전개 전체를 구현했다고 주장하지 않는다.

저자 사이트 HTML과 논문 HTML을 직접 열었다. 이 자료들은 기본 정의·규약의 근거다. 유리수 인자 매개화·한도·순수 사체 반례·정수 Walsh 계산과 독립 참조는 이 교재에서 별도로 유도한 교육 구성이다.

## 모형과 정확한 입력 약속

q=exp(J/T),r=exp(g/T),pᵢ=exp(hᵢ/T)를 유리수로 입력한다. 인자 범위는[1/16,16], 온도는(0,16], 분자·분모 각12자리다. 물리 에너지 자체가 유리수라는 뜻이 아니다. 1보다 작은 인자는 음의 계수이며 물리 원천0은 pᵢ=1이다. T만 바꾸면 물리 계수도 재척도한다. 같은 Hamiltonian 가열 예제는4→2,9→3처럼 정확한 제곱근 인자를 사용한다.

양의 유한 가중치이므로 배치를 버리거나 표본을 생성할 필요가 없다. 원래/중심 이차·삼차·사차량과 누적량, 물리 원천의1/T 규약, 충분통계 S,R의 분산/공분산, 자화 분포를 계산한다. 같은 위치를 여러 번 삽입하는 경우도 유지한다.
