# Euler·Navier–Stokes 두 단원의 계산·상세 원고

이후 [홈페이지 통합과 최종 검증](continuum-euler-navier-stokes-authoring-status.md)을 마쳤다. 아래 수치·미완료 설명은 기초/설계 작성 당시 기록이다.

2026-11-06. 연속체의 네 번째 입문 주제에 대해 계산 모델과 상세 한영 원고를 작성했다. **홈페이지 실습 통합과 화면 검증은 미완료**다. 등록486개 단원·1,458개 안내, 원래 주제271개 입문 검증·91개 미완료를 유지한다. 전체51영역509주제와 연구 심화의 완료를 뜻하지 않는다.

## 두 계산 모델

`src/lib/learning-continuum-euler-navier-stokes.ts`에 다음을 구현했다.

- `linearizedEulerAt`: 균일 이상기체 배경의 음향/접촉 모드, 실제 밀도·속도·압력 섭동과 공간/시간 미분, 세 특성 속도·불변량, 선형 잔차와 같은 장의 비선형 원시변수 잔차, 음향 에너지·플럭스·수지·양성 범위. 접촉 변수의 안정적 가족 식과 반올림 뺄셈을 분리했다.
- `taylorGreenAt`: 실제 이차원 속도·압력·속도 기울기·와도, 대류·압력·시간·점성 가속도, 같은 장의 압력 누락 대조와 국소 변형률 소산.
- `taylorGreenCell`/`taylorGreenDecay`: 실제 주기 길이·깊이·질량·에너지J·소산W, 반올림 감쇠와 expm1 안정적 변화·언더플로 상태. 점성 영과 계산 불가한 비영 변화를 구분한다.
- `taylorGreenParticle`: 시간 의존 실제 속도장의 RK4 입자 경로, 정지 시간·미지원 시간 증분·산술 상태·반올림된 좌표 갱신 횟수. 유선을 입자 시간 진행으로 대신하지 않는다.

계산 범위는 명시적으로 제한하고 비유한 입력을 거부한다. 비영 곱의 언더플로는 null로 남기며, 구조적으로 영인 인자는 정확한 영으로 유지한다. 이 모형들은 충격파·벽·일반 경계값 솔버·삼차원 난류 모델이 아니다.

## 상세 한영 원고

| 단원 | 언어별 목차 | 언어별 수식 | 풀이 |
| --- | --- | --- | --- |
| `linearized-euler-acoustic-characteristics` | 14 | 13 | 6개씩 한영 |
| `taylor-green-navier-stokes-viscous-decay` | 16 | 13 | 6개씩 한영 |

각 원고에 직관, 선수 지식·가정·SI 단위, 직접 유도, 손계산, 보존 관측, 반례·산술 한계, 실험 순서와 AI 연구 검증을 넣었다. 접촉 변수는 열역학적 엔트로피 자체가 아니며 음향 에너지는 전체 기체 에너지와 구분한다. Taylor–Green의 압력 gauge·물리적 셀·유선과 입자 시간·국소 회전과 소산을 설명했다. 한영26쌍의 수식과12쌍의 연습 해설을 제공한다.

## 독립 검증과 회귀

- `generate-continuum-euler-navier-stokes-references.py`는 제품을 import하지 않고 mpmath140자리 미분·구적을 수행한다. 음향장24개와 실제 유한 창의 변화율/경계 플럭스, 와류장24개와 실제 주기 체적의 에너지/변형률 소산을 계산했다.
- SciPy DOP853으로 점성0·0.07·0.3에서 입자 끝점6개를 따로 계산했다. 제품 RK4 끝점과 기하 라벨, 시간 간격 세분화의 수렴을 확인했다. DOP853 참조를 임의 문제의 엄밀한 오차 인증으로 부르지 않는다.
- 매우 작은 점성/시간의 expm1 변화3개를 고정밀로 계산했다. 재생성 파일이 fixture와 바이트 단위로 일치한다. 참조 생성기는 기존 파일을 덮어쓰지 않는다.
- 새23개 검사와 전체4,403개 검사가 통과했다. 제품 장의 실제 공간/시간 차분, 고정 창 수지, 점성 영, 압력 기준, 압력 누락, 양성·단위·소산·산술 경계를 포함한다. 유한 창의 중점 구적 해상도가 부족했던 첫 시도는 분할을4,096개로 늘려 원래 허용 오차를 유지했다.
- 한영 원고를 실제 Markdown/KaTeX 로더로 렌더링했다. 목차 ID·키보드 접근 가능 수식/표·동일 수식·영어 한글 부재·각6개 풀이를 검증했다.
- 타입 검사·lint·콘텐츠1,721 URL 검사가 통과했다. 기존486단원·안내와43실험 그룹477항목의 canonical 내용·순서를 보존했다. 앞서 검증한 소스3,063개와 출력4,190개는 해시가 그대로다.

기존 미리보기와 메뉴 분리를 유지했고 commit·push·공개 배포는 하지 않았다. 새 화면을 만들지 않았으므로 새로운 브라우저 검증이나 배포 빌드 완료를 주장하지 않는다. 근거는 `.runtime/learning/continuum-euler-navier-stokes-foundation-verification.json`과 실제 종료 기록이다.
