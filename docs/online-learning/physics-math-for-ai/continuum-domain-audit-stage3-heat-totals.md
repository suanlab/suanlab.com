## 전체량과 섭동을 분리

평균300K, 체적 열용량0.25, 전도율4, 대비를 binary64 최소 양수, 파수4, 시간4초로 설정하면 온도 섭동은 양의 비영이지만 표시 범위 아래다. 수정 전에는 전체 온도까지 미정이었다. 검증된 입력 범위에서 섭동의 크기는 최대80K이므로 미정인 섭동은 언더플로이며,250~400K의 평균을 반올림할 때 영향을 주지 않는다. 이제 전체 온도는300K를 유지하고 섭동은 미정으로 남긴다.

중심0m·반폭1m의 창에서도 기준 현열은 약13.425J인데 작은 모드 기여 때문에 총에너지가 미정이었다. 기준과 모드의 로그 표현을 합친 뒤 총량을 관측하도록 수정했다. 평균이 기준273.15K와 같아 전체량도 표현 범위 아래인 경우는 미정을 유지한다. 정확한 대비0·폭0은 별도 영 대조다. 같은 로그 식을 공유하는 잔차는 여전히 일관성 진단이며 독립 검증이나 일반 솔버 인증이 아니다.

한영 원고의 기존 수식·목차·해설 연습을 유지하면서 위 직관과 예외를 추가했다. 전체 온도와 섭동, 총에너지와 모드 에너지의 표현 가능 여부를 각각 읽도록 설명한다.

## 관측이 없는 그림의 범위

같은 설정의 기울기 그림이 공간−1~1m 대신0~0.01m를 표시하는 문제도 재현했다. 열·물질 확산 그림에서 세로값을 거르기 전에 입력 좌표 범위를 보존하고 `WavePlot`에 전달한다. 미정 구간을 영으로 그리지 않으며 기존 색상·배치는 유지한다.
