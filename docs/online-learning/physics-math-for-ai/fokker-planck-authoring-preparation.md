## 첫 준비 단원

`ornstein-uhlenbeck-density-euler-moments`는 실수축 위의 Itô OU 과정과 독립 Gaussian/점 질량 초기화를 다룬다. 기존 확률과정 영역의 `coupled-ou-sde-discretization`은 공통 잡음을 통한 경로 오차, `fokker-planck-gaussian-flux`는 양의 분산에서의 국소 밀도·흐름을 다룬다. 새 단원은 정확한 모멘트 구간, 이산 불변 법칙의 편향, 점 질량과 score 제공 조건, 서로 같은 주변분포와 다른 시간 결합 법칙을 상세히 설명한다.

한영 본문은 각각12개 절·표시 수식12개·표2개·해설6문제다. 단위·독립 초기화·Itô 유도·경계 흐름·평균/분산 수지부터 Euler–Maruyama의 정확한 이산 모멘트까지 전개했다. gamma=0의 Brownian 극한, 두 계수0의 정상 가족, D=0의 결정론적 원자, 영 시간, 양의 확산에 의한 양의 시간 정칙화를 구분한다.

정상 분산이면서 평균이 움직이는 법칙과 정상 법칙을 구별한다. Euler의 확률 유효성·평균 수축·정상 분산 정확성도 구별한다. gamma h=1의 인위적 평균 초기화,2의 경계,3의 팽창 예제를 유지하며 실패한 결과를 자르거나 정상값으로 바꾸지 않는다. Probability-flow의 정상 정지 흐름과 SDE의 감쇠 시간 공분산을 비교하고, 원자 시작에서 score 속도장의 특이성을 설명한다. 역시간 생성기나 학습 score를 구현했다고 주장하지 않는다.

## 계산과 확인 근거

계산 원형은256bit 방향성 지수 구간과 정확 유리수 Euler–Maruyama 모멘트를 사용한다. 분산은 비음수 항의 합으로 포함시키고 정상 분산 편차는 별도 식으로 계산한다. 입력은9개 소유 정수 필드·범위·결합 조건을 검사하며 복사·동결한다. 전체 결과를 JSON과 structured clone으로 전달할 수 있다. 아직 UI 전달 규약이나 worker 수명 제어는 아니다.

- 16개 준비·623개 시간 기록을 별도의240자리 해와 직접 유리수 점화/기하합으로 비교했다. 정확 유리수 관측5267개·구간 관측2509개·법칙/제공 조건3738개를 확인했다.

- 잘못된 입력19개 거부, 소유·불변 초기값,16개 전체 결과의 전달 가능성, 준비 TypeScript 검사를 통과했다.

참조 계산의 유한 정밀도에는 `1e-215 × max(1,|참조값|)` 허용량을 명시했다. 이 대조는 방향성 산술의 일반 증명, 모든 허용 입력, 밀도 공간 구적이나 브라우저 동작의 증명이 아니다. 첫 내부 Python 실행의 문법 오류를 수정한 뒤 계산했고, 본문 검사에서 실제 절/수식 수와 다른 예상 상수를 바로잡았다. 수치 모형 실패로 기록하지 않는다.

## 화면과 다음 집필 순서

첫 단원은 기존 홈페이지의 색·글꼴과 도서 → Interactive Book 진입을 유지한다. 정확/근사 평균·분산 시간 그래프, 정규화와 부호 오차 표, 정상 편차, 정상 초기화의 두 시간 공분산을 준비한다. 원자는 별도 질량 표식으로 나타내며 밀도 높이·score는 미제공으로 표시한다. 수치 곡선의 표시 근사는 정확값/포함 구간과 구분한다.

개념6단계는 단위·초기화 → 정확 모멘트 → 정상성과 극한 → Euler 법칙 → 안정성/편향 → score와 시간 결합으로 구성한다. 안내는 같은 T의 N 비교, 같은 폭의 이동 평균, 원자와 양의 시간 정칙화의 세 묶음을 계획한다. 모션은 표본 입자의 경로를 암시하지 않는 물리 시간 순회이며 정지·동작 줄이기·보이지 않는 장면·단원 이동을 처리해야 한다. 조작 범위가 교재의 분량 제한은 아니다.

다음으로 유한체적 공간 이산화의 별도 단원을 집필한다. 유한 구간의 반사/흡수 경계, 셀 질량과 밀도, 면 흐름의 상쇄, upwind 드리프트·확산의 양수율 생성자, 명시 Euler의 보존과 양수성 시간 조건을 구별해야 한다. 유한 격자 해법을 전체 실수축 OU 해와 동일시하지 않고 공간 오차·시간 오차·경계 오차를 분리한다. 이 후속 계산·한영 본문은 [별도 준비와 독립 대조](fokker-planck-finite-volume-preparation.md)를 마쳤으며 아직 홈페이지에는 연결하지 않았다. 위상공간 Kramers와 과감쇠 극한은 이후 심화로 연결한다.

그 뒤 확률 흐름·상세평형 위반·요동 소산·선형 응답·엔트로피 생성·확률열역학·동기화와 임계 동역학·축약과 유효 기술, 이어서 나머지6영역을 진행한다. 전체51영역509주제·연구 심화·공용 WavePlot32소비자 가독성의 범위는 유지한다.
