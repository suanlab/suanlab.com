# 특이 섭동·경계층: 독립 응답 검증과 Worker

2026-11-10. `singular-perturbation-boundary-layer-matching`의 별도 전체 응답 검증과 계산/검증 Worker, React hook을 연결했다. 아직 실제 교재에는 미등록이며 교수 화면·reader·생산 자산 검증이 남아 있다.

## 독립 검증의 범위

생산 모형의 유리수/지수 엔진을 가져오지 않고 별도 유리수 산술과 작은 음수의 교대 Taylor 전개·반복 제곱으로 지수 구간을 검산한다. 생산 지수는 양수 Taylor 전개를 역수로 변환하므로 계산 경로도 다르다. 양쪽은 정확히 같은192비트 지수 포함 셀을 선택하고 유리수 구간으로 모든 응답 필드를 재구성한다.

원래 유리수 입력만 산술 피연산자로 읽는다. 외부 응답의 분수 문자열은 계산에 사용하지 않고 소유한 사본과 기대 문자열을 대조한다. 16입력의 제한된 캐시에는 신뢰한 입력으로 독립 재구성한 값만 저장한다. 분류·좌표·미분·오차·격자 기준·계약·현재 입력 표기까지 검사한다. 기본 응답의 개별1355항목을 하나씩 변조하여 모두 거부했다.

## 전송과 수명주기

매 실행은 계산 Worker와 독립 검증 Worker를 소유한다. 입력 표기/요청번호가 일치하고 전체 검증을 통과한 응답만 ready로 공개한다. 큰 응답 복사는 나누어 실행하며 입력 변경·취소·숨김·해제에서 중단한다. 계산/검증 양쪽의 오류·복사 제한·시간 제한과 재시도를 처리한다. React hook과 main-thread controller에는 숫자 계산 엔진이 포함되지 않는다.

## 검증 결과

- 기존 기반50검사와 신규66검사, 합계116검사를 통과했다. 독립 Python41참조 입력의 전체 응답 검증, 개별1355항목 변조, 추가 속성·접근자·기호·순환·크기 제한·귀속·원시 입력 표기를 확인했다.
- 실제 Chromium module Worker에서58요청(Python참조41+명시적17예제, 중복 포함)을 계산/검증했다. 잘못된 분류58개와 요청 귀속 오류58개를 거부하고 직접 생성한 Worker2개를 종료했다. 계산 중 타이핑 반응성도 확인했다.
- 실제 React hook에서 비활성화·시작 중 숨김·검증 중 숨김·복귀·입력 교체·전송 오류 후 재시도·계산 중 unmount를 확인했다. Worker17생성/17종료, 활성0, 페이지 오류0이다. 숨김은 visibility event 모의이며 실제 탭을 물리적으로 숨긴 실험으로 기록하지 않는다.
- 타입·lint와 의존성 검사를 통과했다. 독립 검증 번들에는 생산 모형·양수 Taylor 지수/유리수 엔진이 없고, reader hook 번들에는 생산/검증 산술이 없다. SSR에서도 Worker를 만들지 않는다.

실행 근거는 `.runtime/learning/boundary-layer-worker/`의 `all-tests.log`, `leaf-mutations.json`, `native-workers.json`, `native-hook.json`, 의존성 그래프와 타입/lint 기록이다. 브라우저용 자산은 이 단계의 별도 esbuild module Worker이며 생산 Next.js 자산 검증은 후속이다.
