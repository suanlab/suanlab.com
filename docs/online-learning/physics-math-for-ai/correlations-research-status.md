# 상관·요동 연구 보강 검증 기록

2026-11-13. 기존 두 스핀 연결 상관, 주기 Ising 고리, AR(1) 평균 불확실성의 **3단원·한영 6원고·그림 6개**를 보강했다. 기존 본문과 풀이 36개를 정확히 보존하고 표시 수식 48개·실행 Python과 표 각 6개·연구 풀이 18개를 추가했다. 지정 모수의 기존 reader와 새 추론·Fourier 관측량·가중 추정량의 질문을 구별한다.

## 새로운 연구 설명

- **결합을 모르는 추론:** 장 둘과 상호작용의 세 특징 Fisher 행렬, 양의 네 칸 확률의 행렬식·로그 대비 역산, 방해 점수의 사영을 유도한다. 물리적 장 응답 C와 미지 결합을 제거한 효율적 정보의 Schur 여행렬을 구분한다. 모집단 역산·양의 경험 횟수의 MLE·빈 칸의 경계 문제를 구별하고 극한 정규분포와 유한 표본 공분산을 동일시하지 않는다. 추론 확장은 모든 유한 실수 자연 모수를 허용하며 reader의 입력 범위를 제약 추정으로 해석하지 않는다.
- **공간 Fourier 모드:** 정확한 두 경로 공분산을 이산 주기 파수로 변환한다. 구조인자의 양성·원천 정규화·대각합을 유도하고 홀수 고리에 정확한 π 모드가 없음을 설명한다. 고정 크기 저온 극한과 고정 유한 K의 큰 크기 극한을 비교하며 공간 모드와 시간 주파수를 섞지 않는다.
- **효율적 AR(1) 평균:** 정상 초기 법칙과 알려진 내부 계수에서 혁신 우도·삼중대각 정밀도·끝점 가중치를 유도한다. 보통 평균의 V_n은 유지하고 다른 GLS 추정량의 정확한 분산·정보·분포를 계산한다. 공분산을 모를 때의 plug-in 추정이나 특이 끝점에 역행렬 공식을 그대로 적용하지 않는다.

[출처 기록](thermo-statmech-source-audit.md)과 [JSON 근거](correlations-research-evidence.json)에 수식·검산·보존·화면 범위를 연결한다.

## 독립 계산과 보존

양의 확률표 81개에서 유리수 특징 공분산·행렬식·블록 역행렬·사영 직교성을 검산하고 로그 대비로 복원했다. 유한 고리 32준비는 모든 스핀 배치의 Fourier 이차 관측량으로 대조했다. 별도 바닥 상태 열거로 홀짝 저온 고리 15개를 확인했다. AR(1) 유리수 공분산 선형계 65준비에서 역행렬의 모든 열, GLS 가중치와 분산 차이를 검산했다. 교대 끝점 31길이의 직접 상쇄도 확인했다. 유한 검산은 모든 시계열·모수 추정·공간 모형의 인증이 아니다.

관련 **12파일·203검사**와 마지막 추론 범위 명료화 후 연구·두 스핀 원고·보존 재검사 **22개**가 통과했다. 새 절을 제거하면 기존 원문 해시와 정확히 일치한다. 다른 29단원·58원고, 앞선 연구 자산 146개와 보존 장부 847항목을 유지했다. 장부는 새 검토 6개를 추가해 853항목이다. 등록은 650단원·1,969안내이며 원래 분모는 51영역·509주제다.
