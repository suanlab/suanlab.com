# Boltzmann·Gibbs 교수 자료와 읽기 통합 계약

2026-11-07. 이 문서는 제작에 적용한 계약이다. 세 가족의 모델·한영 원고·교수 컴포넌트를 구현하고 [실제 읽기 통합 검증](boltzmann-gibbs-integration-verification.md)을 마쳤다. 로컬521단원·1563안내이며 다음은 상전이·질서변수다. 아래의 제작·검증 순서는 당시의 계약이며, 전체 교육과정과 연구 심화는 계속 진행 중이다.

## 고정 개념과 실제 실험

| 단원 | 고정 개념4개 | 준비한 실험3개 |
| --- | --- | --- |
| 기준 측도·Boltzmann | 네 미시상태/세 준위; 엔트로피 분해; 영점/척도; 지원과 가중 바닥 | 기준 해석; 영점/척도/기준 재조정; 금지·0 K·음의 온도 |
| 유한 Gibbs | 조건부 행렬; random/순차 흐름; 제약/블록; 법칙/유한 난수 경로 | 정상성/상세평형; 지원 연결; 희귀 전이/수축 |
| 연속 Gaussian | 그릇/타원/source; 정규화 경계; 밀도/면적/Jacobian; 고정 계수 저온 응답 | 중심/곡률; 양·0·음 행렬식; 밀도/좌표/양의 저온 |

각 단계에 개념 설명·가정·수식·직관·예측·조작·해설을 제공한다. 단원당 해설 퀴즈2개, 문항당3선택지를 구현했고 기존 퀴즈 컴포넌트로 검증한다. 안내9개를 교재에 등록했다. 고정 그림도 실제 결과와 대조하고, 계산이나 지원을 바꾼 이전 그림을 재사용하지 않는다.

## 계산 경계와 worker

전용 literal-URL worker에만 세 무거운 모델을 import한다. 타입 전용 import의 경량 구성, 입력/결과 프로토콜, 요청 controller와 hook을 분리하고 기존 partition 구현의 취소·재시도·언마운트 패턴을 따른다. 계산 중 입력/언어/단원을 바꾸면 이전 결과를 숨기고 요청 식별자로 늦은 응답을 차단한다. main-thread 동기 대체 계산을 두지 않는다.

가중치0과 유한 양수, 0 K 가중 극한과 유한 온도, Gibbs의 명시적 T=0 거부, Gaussian의 T>0 및 정규화 불가를 분리한다. 숫자 입력에서 비영 표기가 Number로0이 되는 underflow를 조용히 0 K나 금지 가중치로 바꾸지 않는다. 배열·지원·단계 범위와 저장값을 검증하고 소유한 스냅샷을 사용한다.

출력은 실제0·표시 범위 밖 비영·미해결·수학적 무한대를 구별한다. Gibbs 거리의 dyadic 거듭제곱은 기본8192비트보다 긴 계수/지수를 가질 수 있으므로 결과 프로토콜의 합당한 자원 상한을 별도로 정한다. 수치 잔차의 미해결 구간은 정상성 반증이나 `fullyResolved` 대상 관측값과 같지 않다.

## 시각화와 표본 경로

기존 primary/secondary·파랑/주황 색과 명암 모드, 타이포그래피를 유지한다. 전역 모션 설정·감소 모션·수동 중지·화면 밖 중지를 적용한다. 축·상태·준위·확률 질량·밀도·좌표 갱신 수를 한영으로 명시한다.

작은 양의 전이를 표시상0으로 지워 연결성을 바꾸지 않는다. Gaussian이 비정부호면 정규화된 확률 구름을 그리지 않는다. 그릴 수 없는 평균/공분산은 상태와 수치를 보존하고, 설명 없이 중심을 잘라내거나 격자 질량을 다시 정규화하지 않는다. 긴 수식·표는 키보드 스크롤, 과학 표기는 한 줄을 유지한다.

Gibbs 경로는 이론적 `q0 P^t`와 분리한다. PRNG·seed·비트 격자·초기화·갱신 횟수와 양자화 법칙을 명시하고 표본 경로를 정확한 임의 실수 Gibbs 표본이라고 부르지 않는다. 극소 확률을 경로에서 처리할 수 없으면 그 제한을 보이되 이론적 kernel을0으로 바꾸지 않는다. random 단계와 두 좌표 sweep의 비용을 구분한다.
