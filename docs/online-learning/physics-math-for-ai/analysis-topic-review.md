2026-11-11에 해석학의 9개 원주제를 한영 원고·계산 모형·실습 설명과 대조했다. 전체 51영역·509개 원주제 검토의 일부다. 평균값정리의 a<b, Riemann 합의 x≥0, 중요도 표본의 독립성도 본문에 명시했다. 이번에는 Taylor의 매끄러운 비해석적 반례 증명을 완성하고, 적분·극한 교환의 봉우리를 표본 추출과 기대 경사에 연결했다. 영역별 연구 심화는 계속 진행한다.

## Taylor에서 보강한 증명

기존 원고가 심화 과제로 남겼던 g(0)=0, g(x)=exp(−1/x²)의 미분 귀납을 작성했다. 지수함수의 양의 항으로 다항식×exp(−t²)의 감소를 제어한다. t=1/x와 P₀=1, Pₘ₊₁=−t²P′ₘ+2t³Pₘ의 점화식으로 비영점 도함수를 구성한 뒤, 원점의 차분 몫도 같은 감소 상한으로 0임을 증명했다. 이로써 모든 차수의 원점 도함수가 0이면서 비영점의 함수값은 양수임을 확인했다.

처음 네 도함수 다항식의 표와 정수 계수 Python 계산을 한영으로 추가했다. 두 코드 모두 계수 표를 재현했다. 유한 차수의 계산과 임의 차수에 대한 귀납의 역할을 각각 설명했다.

## 봉우리와 표본 추출의 정확한 계산

기존 연속 삼각형 fₙ(x)=n·max(0,1−|nx−1|), n≥2를 그대로 사용한다. 면적은 1, 제곱 적분은 2n/3이다. 독립 균등 입력 M개의 평균은 불편이고 분산이 (2n/3−1)/M이다. 봉우리를 전부 놓칠 확률은 (1−2/n)ᴹ이다.

| n, M=8 | 전체가 0인 배치 확률 | 원래 표본평균 분산 | 지지 제안 분포의 가중 분산 |
|---|---|---|---|
| 4 | 0.003906 | 5/24 | 1/24 |
| 16 | 0.343609 | 29/24 | 1/24 |
| 64 | 0.775700 | 125/24 | 1/24 |

유한 배치를 재사용하며 n을 늘리면 추정량이 확률 1로 0으로 가는 이유와 기대값이 계속 1인 이유를 증명했다. 고정 n에서 M을 늘리는 절차, Mₙ/n→∞인 평균제곱 수렴도 구분했다. 지지 구간 (0,2/n)의 균등 제안에서는 가중 관측이 2H, H∼Uniform(0,1)이어서 분산이 1/(3M)이다.

가중치를 생략하면 기대값이 n/2가 되고, 지지를 절반만 덮으면 가중 후에도 기대값이 1/2이다. Python은 알려진 구간별 다항식 적분과 이항 개수의 조건부 모멘트를 정확한 유리수로 각각 검산했다. 두 언어의 코드가 표와 같은 결과를 냈다.

손실 θ²/2−θfₙ의 기대 경사는 θ−1이다. 표본 경사의 불편성과 커지는 분산, θ=0에서 배치가 모두 0인 사건을 연결했다. 고정 n에서 미분을 정당화하는 국소 지배 상한과 n에 대한 극한 교환을 별도로 설명했다.

## 실행 검증

`learning-analysis.test.ts`의 32개 검사와 해석학 9개 단원의 원고 공통 검사가 통과했다. 원고 검사는 두 언어의 수식·MathML·본문 분량·목차·영어의 한글 혼입을 확인했다. 해당 이름의 검사 9개를 선택했고 다른 검사 662개는 이 실행에서 선택하지 않았다.

`npm run check:analysis`는 해석학 9개와 행렬 미적분 6개의 학습 화면을 검사한다. 수화·초기화 반영 대기, 해당 가로 넘침 요소의 키보드 스크롤, 정수 초안의 오류 표시·계산 보존·Escape 복원을 현재 규약에 맞췄다. 새 두 코드 예제도 키보드 스크롤 대상에 포함했다. 한영·320/768/1440px·명암·전체 교육과정 펼침을 포함한 118개 상태와 상호작용 17개 묶음, 안내 예제 45개를 통과했다. 51영역·509주제의 목록과 검색, 문제 풀이·입력·진도 저장 복원, 두 코드 예제의 키보드 스크롤을 확인했다. 페이지 실행 오류와 WCAG A/AA 위반은 0건이었다. 실행 근거는 `.runtime/learning/analysis-browser.json`이다. 가정 문구를 명시한 최종 빌드도 성공했고, 1,888개 HTML의 내부 링크·자산·앵커·사이트맵·canonical 검사가 통과했다. 마지막으로 수정한 세 단원은 영어·한국어, 320/1440px, 명암의 12개 상태에서 다시 열어 가정 표시·수식·페이지 폭·접근성을 확인했다. 추가 실행 근거는 `.runtime/learning/analysis-assumptions-browser.json`이다.
