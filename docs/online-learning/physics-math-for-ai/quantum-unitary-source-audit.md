# Unitary evolution·Schrödinger 원문과 수치 근거

2026-11-08. 시간 독립 스펙트럼 가족의 기반을 구현했다. 두 가족 중 pulse 순서 비교, 두 가족의 한영 원고·Worker·교수 화면·실제 읽기는 아직 남아 있다.

## 원문 확인

- [Preskill §2.1, Axiom4](https://www.preskill.caltech.edu/ph219/chap2_15.pdf): 닫힌계의 unitary 전파, Hamiltonian 생성자와 ℏ=1 표기. 앞선 관측·연산자 작업 때 실제 원문을 열어 확인한 내용을 사용한다. 미소 시간의1차 근사를 유한 간격의 정확 unitary로 취급하지 않는다.
- [NIST DLMF §4.19.1–2](https://dlmf.nist.gov/4.19): sin/cos의 Maclaurin 급수를 이번에 열어 확인했다. 아래 축소·잔차·구간 연산 계약은 이 교재 구현에 맞춰 직접 유도했다.

## 방향성 삼각함수

작업 격자는2⁻⁷⁶⁸이고 공개 관측은 바깥 방향으로2⁻⁵¹² 격자에 반올림한다. 유리수 위상 x는 |x|≤2⁶⁴이며, 정수 k를 골라 |x/2ᵏ|≤1/8로 만든다. π의 부동소수 근사로 각도를 빼지 않는다. 최대 k는67이다.

양의 축소 각 y에서 sin은 y부터, cos는1부터 시작해 각134개 후속 항을 더한다. 모든 곱·정수 나눗셈·합·차를 방향성 정수 구간으로 계산한다. 항의 크기는 감소하며 첫 생략 항은 sin에서 y²⁷¹/271!, cos에서 y²⁷⁰/270!이다. 둘 다2⁻⁸⁰⁷보다 작으므로 그 보수적 경계를 위로 반올림해 양쪽에 더한다. 음수 sin은 홀대칭으로 처리한다.

이후 sin(2y)=2sin(y)cos(y), cos(2y)=cos²(y)−sin²(y)를 구간으로 반복한다. 각 결과는 삼각함수의 알려진 범위[−1,1]과 교차한다. 이는 norm을 맞추는 조작이 아니다. 입력 자체가 구간이면 정확한 중점에서 계산하고, |sin′|·|cos′|≤1에 따라 입력 반경만큼 넓힌다. 입력 불확실성을 배각에 반복 투입해 불필요하게 확대하지 않는다.

같은 부호 구간의 제곱과 영을 가로지르는 제곱을 구별하고, 영을 포함하는 분모로 나누지 않는다. 확률 경계는 물리적으로 증명된[0,1]과 교차한다. 영을 포함하는 잔차·작은 미해결 구간은 구조적0이나 임의의 값으로 바꾸지 않는다.

## 시간 독립 가족과 Euler 비교

원시 정수 복소 벡터가 P를 정하고 H=aI+b(2P−I)를 만든다. 에너지 E0·시간 T0·작용 E0T0를 명시하며 ℏ의 수치는 E0T0 단위다. H와 시간 격자, 초기 스펙트럼 무게·에너지 평균/분산은 정확 유리수다. U(t)의 진폭·확률·직접 보존량과 구조 잔차는 구간 관측이다.

관측 격자는1…16구간, Euler는1…64단계이며 단계 수가 관측 구간 수로 나누어떨어져야 한다. 하나의 Δt=T/N을 전 구간에 유지한다. 생산 Euler는 각 고유공간의 (1−iEΔt/ℏ)ᵏ를 정확 복소 유리수로 계산한다. 출력 norm을 나눠주지 않으며 초기 norm만 사용한다. 일반 Number 범위를 넘는 성장도 정확 유리수 경계와 magnitude-log로 남긴다.

## 독립 대조와 해석 범위

독립 Python은 생산 코드를 가져오지 않는다. mpmath250자리 직접 행렬 exponential로 실제 시간 표본을 구하고 SymPy 고유공간으로 에너지 확률을 대조한다. Euler는 Python Fraction의 직접 행렬·벡터 반복을 사용한다. 별도의 복소 DOP853 궤적도 비교한다. 큰 위상·작은 revival 결함·복소 방향·최대 원시 정수·큰 정확 분모·Euler overflow를 포함하고 참조 재생성이 바이트 단위로 일치했다.

점 관측의 폭 예산과 넓은 입력 구간의 포함 검사는 구분한다. 넓은 구간을 좁다고 보고하지 않는다. 고정밀/ODE 대조는 지정한 유한 모형의 검증이며 무한 차원 스펙트럼·정의역·일반 시간 의존 Hamiltonian·열린계나 전체 연구 범위의 완성을 증명하지 않는다.
