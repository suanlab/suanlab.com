# 잡음 거시 관측의 계산 기반

2026-11-06. 셋째 가족 `finite-noisy-macro-observation-channel`의 모델·독립 참조를 검증했다. 이진 껍질과 가중 결정론적 관측에 이어 세 계산 모델을 갖춘 단계다. 이 가족의 상세 한영 원고와 세 가족의 교육 UI·등록·실제 읽기 화면 검증은 남아 있다.

## 준비·장치·사후의 구별

`noisyMacroObservationModel(preparationWeights,channelWeights)`는1–16개 입력 상태와1–16개 출력 레이블을 받는다. 입력 준비와 각 채널 행은 각각 양의 총합을 갖는 유한 비음수 가중치다. 확률0인 입력에도 완전한 행을 요구하며, 빈 행·길이 불일치·누락 원소를 자동 보정하지 않는다. 한도는 자원 제한이며 채널 이론이나 교육과정의 범위를 제한하지 않는다.

준비 확률 p,행 조건부 K,결합 J=pK,출력 R,사후 B=J/R를 서로 다른 필드로 반환한다. 실제0인 출력에는 사후가 정의되지 않으므로null을 반환하고 가중 조건부 엔트로피 기여만0으로 둔다. 표시할 수 없는 작은 양수 출력은 원래 지지집합과 조건부를 유지한다.

H(X),H(Y),H(X,Y),H(Y|X),H(X|Y),I(X;Y)를 nat으로 계산한다. 장치가 만드는 출력 잡음과 상태를 식별하지 못해 남는 정보는 다른 양이다. MI는 D(J||p⊗R)의 양의 Bregman 항 합으로 계산하며 근사 엔트로피의 차이를 빼거나 음수라서0으로 자르지 않는다. 정확한 유리수 비교로 독립 여부와 준비 지지집합 위의 결정론성을 판정한다.

## 정확한 확률과 근사 정보량

입력 binary64 값을 정확한 유리수로 바꾸고,준비·행·결합·출력·사후 확률의 합과 곱은 정확하게 처리한다. 행마다 다른 분모를 Number 확률로 먼저 투영하지 않는다. 정규화 다섯 항목은 정확한 합으로 확인한다. 원시 BigInt는 모델 결과에 노출하지 않는다.

로그·정보량은 초월함수 근사다. 근사 로그가 들어간 비음수 정보량 항은192개 유효 이진 자리로 반올림한 뒤 dyadic 합을 정확히 구한다. 항마다 상대 반올림 오차는2⁻¹⁹² 이하며 지수에 binary64 제한을 적용하지 않아 양수가0으로 되지 않는다. 이는 확률을 먼저 반올림하는 규칙이 아니다. 기존 로그 근사 오차는 별도로 남으며,전체 초월함수의 정확 반올림을 주장하지 않는다.

큰 유리수의 약분에는 상위 limb가 제안한 Euclid 변환을 BigInt에서 적용하는 gcd를 쓴다. 정수 변환과 감소 조건을 확인하고 필요하면 정확한 나머지 연산으로 돌아간다. [HAC14.57](https://cacr.uwaterloo.ca/hac/about/chap14.pdf)의 다중정밀 gcd 틀을 참고했다. 정보량 합에서 불필요한 거대 분모 약분도 피했다.

## 독립 참조와 검사

Python Fraction으로 확률을 정규화하고 직접 로그를 더하는 독립 MI 참조를 일반24개·극한12개 생성했다. 반환하는 모든 분포와 정확한 결합/독립 차이에서 정밀도를 산정한다. 사례별160–2687자리이며 각각80자리 더 높은 계산의 직렬화 결과도 같다. 최종 생성기의 독립 재생성은 바이트까지 일치한다.

초기 산정은 결합 법칙에만 집중하여 준비 확률0인 행의 극소 조건부 엔트로피를 충분히 분해하지 못했다. 그 행은 전체 정보량에는 기여하지 않지만 개별 행 엔트로피로 반환되므로,채널·입력·출력·사후도 정밀도 산정에 포함하도록 고쳤다. 해당 초기 참조와 실패 로그는 진단 기록으로 보존하며 최종 증거로 사용하지 않는다.

모델49개 검사에 gcd4개·정보량 반올림3개를 더한56개가 통과했다. 독립 참조의 분포·엔트로피·MI,오류/지워짐의 닫힌식,결정론적 모델로의 환원,독립 잡음의 정확한0,두 결합 엔트로피 항등식,MI 경계,미사용 행·열,순서·스케일 불변성,한 ULP 차이,underflow 기여 복원과 입력 거부를 포함한다. gcd는 별도 Euclid 구현·큰 공약수·Fibonacci 이웃과 비교한다. 반올림은 부동소수점 허용치 대신 정수 부등식으로 오차 한계와 동률·양수 보존을 확인한다.

관련 회귀 검사는 총231개,타입 검사와 대상 lint도 통과했다. 기존 통합 소스·자산·검사3888개와 정적 출력4236개는 그대로다. 등록509단원·1527안내 및 입문 검증282주제·미완료80주제도 유지한다.

## 최대 혼합 입력과 UI 통합 조건

16×16에서 최소·최대 가중치를 섞은 추가 진단은 정확한 정규화·양의 MI·직렬화를 완료했다. 최종 관측 시간은 약7.95초다. 이전 개선 과정에서 같은 패턴에165초가 관측되었지만,단일 환경의 진단이므로 일반 성능 보장으로 해석하지 않는다. 기본16×16 검사와 달리 이 극단적인 범위의 계산은 여전히 무겁다.

재현 명령은 `npx tsx scripts/learning/check-noisy-macro-observation-boundary.ts`다. 일반 입력 지원을 유지하면서 실제 UI에 노출할 때는 별도 작업 스레드 등으로 메인 화면을 막지 않도록 처리해야 한다. 아직 UI가 없으므로 브라우저의 응답성을 검증한 단계가 아니다.
