# Master equation 연구 보강 검증 기록

2026-11-13. 기존 두 상태 생성자·Euler, Poisson uniformization, 상태 의존 holding/jump/occupation **3단원·한영 6원고**를 보강했다. 원래 본문과 풀이 36개를 정확히 보존했다. 표시 수식 56개·실행 Python과 표 각 6개·연구 해설 18개·그림 6개를 추가했다. 기존 reader의 확률 법칙 계산과 별도 관측·추론·점근 예제를 구분한다.

## 연구 설명과 가정

- **경로의 전이율 정보:** 마지막 미완료 체류를 포함한 노출·실제 이탈 수로 우도와 점수·Fisher 정보를 유도한다. 알려진 전이율 독립 초기화, 보정된 시간, 양의 전이율을 명시한다. 짧은 초기 기록에서 복귀 전이율의 정보는 이차 시간 척도로 작아진다. 0/0·경계 최대점·개별 기록과 기대 정보, 점수 직교와 횟수 독립을 구분한다. 미지 시계의 밀도 환산 인자와 정보의 영방향도 설명한다.
- **관측 간격의 별칭:** 순환 생성자의 Fourier 감쇠·회전 모드에서 같은 간격 전이 kernel을 공유하는 양의 전이율 쌍을 구성한다. 전체 격자 관측 법칙은 같지만 중간 지연과 방향 전류는 다르다. 알려진 시작·전이 쌍과 정상 한 시각 히스토그램, 실제 표집 간격과 잠재 사건 시계를 구분한다. 무리수 참조 전이율을 기존 유리수 입력의 정확한 설정으로 소개하지 않는다.
- **재생 시간 평균:** 완전 회로의 보상·시간 비, 미완료 경계 항과 중심극한 계수, 고정 주기 수와 고정 물리 시간의 정규화를 유도한다. Poisson 방정식으로 분산을 대조하고 횟수 기울임의 고윳값에서 장시간 점프 평균·분산·Fano 비를 구한다. 기울인 행렬은 확률 생성자가 아님을 명시한다. 순간 분산·장시간 계수·유한 표본 보장과 흡수 경계를 구분한다.

일차 자료와 직접 유도의 경계는 [자료 대조](nonequilibrium-research-source-audit.md), 수식·직관·실행 예제는 실제 reader, 해시·검사·화면 범위는 [JSON 근거](master-equation-research-evidence.json)에 연결한다.

## 독립 계산과 보존

잠재 사건 상태 수열을 직접 열거하고 순서 통계량 사이 Dirichlet 간격 모멘트로 경로 점수를 적분한 **108준비**를 대조했다. 생략 점수의 이차 증가를 포함한 Poisson 가중 꼬리 상한과 부동소수점 허용량을 준비별로 확인했다. 이는 방향 반올림 구간 인증이 아니다. **375개 정확 유리수 Poisson/재생 분산 비교**, **125개 횟수 특성다항식 비교**, **9개 양의 전이율 별칭 준비**의 독립 uniformization·Fourier·semigroup 대조도 통과했다.

관련 **4파일·84검사**, 빌드 전후 타입·lint·콘텐츠 1,885 URL/293논문/51프로젝트·새 빌드 1,893경로·정적 1,888 HTML 검사를 통과했다. 다른 14단원·28원고, 앞선 연구 자산 207개와 기존 장부 865항목을 유지했다. 새 검토 6개를 더해 장부는 871항목이다. 등록은 650단원·1,969안내, 전체 범위는 51영역·509주제다.
