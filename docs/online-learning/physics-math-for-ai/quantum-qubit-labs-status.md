# Quantum circuit·channel: bilingual mathematical labs

2026-11-09. [Worker 표시 관측값](quantum-qubit-observations-status.md)에 이어 네 단원의 한영 수치 학습 화면을 작성했다. **아직 전역 등록0/4이며 실제 reader·생산 Next 자산·정적 통합 검증은 남아 있다.**

## 학습 화면

- 회로: 게이트 단계 슬라이더와 이전/다음·재생, 기저 확률 그림, 원시 진폭/정규화 확률, 단일 큐비트 선택·축약 순도/Bloch, 쌍별 Pauli/연결 상관, 전체 밀도행렬·U·역회로 잔차·제곱 fidelity를 비교한다. 원시 진폭의 노름 분모를 fidelity 식에 명시한다. 단계 선택과 재생은 계산된 prefix를 사용하며 새 Worker를 만들지 않는다.
- 채널: CP·TP·TNI·unital·이번 출력의 유효성을 구분한다. 입력/출력/Bell 출력/참조 주변 상태를 선택하고 Choi·Φ†(I)·Φ(I)를 확인한다. 전치의 비물리적 Bell 출력, 영출력, trace가 커진 출력은 자동 정규화하거나 Bloch 상태로 그리지 않는다.
- 환경: 입력·계·환경·결합·참조 상태의 순도를 비교하고 V/U·다른 환경 기저의 Kraus 행렬을 확인한다. 현재 t와 γ=(2t/(1+t²))²를 표시한다. 두 축약 순도가 같아지는 순수 결합 상태 조건을 설명한다.
- Instrument/deferred: 기록 확률·POVM 효과·정규화 전 출력, 조건부 X 보정 전/후 갈래와 고전–양자 상태를 비교한다. 확률0 갈래는 정의되지 않은 조건부 상태로 표시한다. 묶인 결과의 혼합과 결맞는/탈위상 기록의 Y 차이도 관찰한다.

13안내 실험의 예측/조작과33입력 예제를 연결했다. 학습자는 JSON 편집에서 정확 분수·게이트·상태·채널·환경 파라미터·측정을 변경할 수 있다. 적용 전 초안은 결과를 바꾸지 않고 형식 오류는 이전 입력을 유지한다. 수학 조건 오류에서는 결과를 숨기며 예제/초기화/재계산으로 복구한다.

## 그림과 실행

기존 홈페이지의 색·카드·버튼을 사용한다. 정확 값과 표시 구간·정확 부호를 함께 제공하며, 근사 좌표로 물리 조건을 판정하지 않는다. 넓은 표/2D 그림은 내부에서 키보드와 터치로 이동한다.

Bloch 장면은 기존 Three.js 엔진을 동적으로 읽는다. 카메라 버튼/드래그,2D 대체,WebGL 손실 후 재시도를 제공한다. 화면 밖에서는 renderer를 정리한다. 카메라 자동 회전과 연속 물리 시간 진화는 없다. 회로 단계 재생은 별도 조작이며 reduced motion·화면 밖·숨겨진 문서에서는 중지한다. 결합 상태를 하나의 Bloch 벡터로 바꾸지 않는다.

컨트롤러 hook은 새 입력이 렌더링되는 즉시 이전 결과를 숨기고 독립 검산을 통과한 응답만 제공한다. 저장은 단원별이며 복원 전에는 계산/쓰기를 시작하지 않는다. 손상된 입력은 첫 예제로 복구하고 저장소 차단/쓰기 실패는 세션 사용과 구별해 알린다. 취소·재시도·단원 변경·unmount는 기존 컨트롤러의 종료 규칙을 따른다.
