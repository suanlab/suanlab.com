## 전송선: 관측 적합과 에너지의 차이

양의 단위 길이 L/C와 유한 길이, 개방 종단, 지정된 입력 전압의 정현파 경계값 문제다. exp(+iωt), θ=ωℓ/c를 고정한다. 공간 V/I와 순간 전력·에너지, 주기 평균 전기/자기 저장, 단자 어드미턴스를 각각 계산한다. tanθ≈θ는 저주파 단자 근사이며 공간 해·자기 저장의 정확한 일치를 뜻하지 않는다.

Cfit=B/ω는 한 주파수의 응답을 맞추지만 비분산 저장량 Cfit Vin²/4는 실제 선로 저장량과 다르다. 이 무손실 지정 가족에서는 Vin²(dB/dω)/4가 공간 적분과 일치한다. 공진 뒤의 음의 Cfit을 양의 수동 정전 커패시터로 해석하지 않는다. 정확한 DC의 정적 에너지와 양의 주파수 주기 평균의 극한도 구분한다.

명시적인 기호 사분파장 공진에서는 비영 구동은 비호환, 영 구동은 비유일이다. 가까운 유한 이진 입력을 정확한 기호 공진으로 바꾸지 않는다. 작은 보정·자기 저장·맞춤 에너지 차이는 급수로 평가하고 비영 산술 손실을0으로 숨기지 않는다. 실제 주파수·위치·에너지의 가용성은 따로 유지한다. 켜짐 과도·저항·방사·전체 장치장은 이 가족 밖이다.

## 층상 매질: 평균·반복·관측을 구분

양의 실수 상대 유전율·상대 투자율1, 수직 입사·접선 E, 진공 외부 포트에 한정한다. exp(−iωt), 상태(Ey,Zref Hz), 층 순서 M2M1, 실제 주기와 Ω=ωa/c_ref를 명시한다. 한 셀의 trace·행렬식과 유한0~16주기 적층의 산란·내부 E/H·정규화 흐름·에너지를 계산한다. 출력 경계의 에너지 밀도는 오른쪽 진공 측으로 표기한다.

장파장 평균 ε는 해당 편광의 두께 가중 산술 평균이다. Ω⁴ 선도 차이는 점근 항이며 전역 오차 상한이 아니다. Bloch 주값 위상은 접힌 위상이고 누적 위상 전체를 복원하지 않는다. 금지대의 모드 감쇠는 흡수가 아니며 무손실 유한 적층의 R+T와 따로 읽는다. 빈 적층과 셀 자체의 분산도 구분한다.

유한 적층은 전력 정규화 산란행렬을 합성하여 큰 전달행렬의 반복 곱을 피한다. ε의 작은 대비는 계면 반사식에서 유지하고 굴절률 자체의 대비가 표현되지 않는 경우도 표시한다. D−1/D+1의 안정적 식으로 작은 위상을 보존하되, 가장자리 근처의 반올림·위상 민감도는 수치적 여유로만 판단한다. 이는 엄밀한 구간 인증이 아니다. 판정 미정·표현 범위 손실·정확한0주파수 극한을 구분한다. 정확한0주파수의 주기 평균은 제공하지 않고 선택한 정적 경계 상태의 저장과 양의 주파수 극한을 별도로 둔다.

## 독립 기준과 보존 검사

`scripts/learning/generate-electromagnetic-effective-models-references.py`는 제품 코드를 가져오지 않는다. 전송선108조건에서 역방향 SciPy ODE와 공간 전기/자기 에너지 구적·주파수 차분을 사용했다. 층상 매질162조건은 행렬 지수·유한 적층 경계 선형계와 내부장972표본으로 대조했다. 금지대14조건과 손실 없는 전력 수지를 포함한다.240자리 정확 이진 입력 기준은 전송선7조건·층상 매질9조건의 작은 보정·극점 근처·장파장 위상을 확인한다.

기준은 `scripts/fixtures/electromagnetic-effective-models-independent.json`에 저장했고 별도 재실행으로 바이트 재현성을 검사한다. 선택한 수치 근거이며 장치 인증이나 엄밀한 전역 오차 상한이 아니다. 등록 전478단원·안내와42실험 그룹469항목의 canonical 값·상대 순서를 `scripts/fixtures/pre-electromagnetic-effective-models-registry-hashes.json`으로 검사한다.

전용31개·전체4,224개 테스트와 타입·lint·콘텐츠1,712 URL 검사가 실제 종료 코드0으로 통과했다. 결과는 `.runtime/learning/electromagnetic-effective-models-foundation-verification.json`에 기록했다. 실제 콘텐츠 로더로 원고4개를 렌더링하여 strict KaTeX·한영 수식 일치·고유 목차·스크롤 접근성·영어 한글 잔존 없음·풀이를 검사했다. 기준 생성기는 재실행 후 바이트 단위로 동일했다. 기존 홈페이지 소스3,010개·정적 출력4,171개와 기초 집필 소스3,020개의 해시를 대조했다. 이번 단계에서는 빌드·화면 통합 검사를 새로 수행하지 않았으며, 기초 집필을 홈페이지 완료로 세지 않는다.
