## 점전하 모델의 계약

`pointChargeField`는 평면의 원천·관측 좌표에 **삼차원** Coulomb 커널을 적용한다. SI 전하·거리·장·힘·전위를 반환하며 교육용 k=9×10⁹은 명시한 반올림 값이다. 독립 기준은 E/k와 V/k를 사용한다. 평면에 그렸다는 이유로 이차원 무원천 발산 조건을 적용하면 안 되는 이유를 유도하고 실제 평면 성분 미분으로 확인했다.

시험 전하를 바꾸어도 준비한 장·전위는 유지된다. 같은 부호의 중점에서는 벡터 장이 상쇄되어도 전위가 남고, 반대 부호의 중점에서는 그 반대가 가능하다. 공통 평행 이동·회전·거리 확대, 원천 부호와 시험 전하 부호의 서로 다른 효과를 검사한다.

정확한 비영 원천 위치는 특이점이다. 근처의 비영 거리를 epsilon으로 덮지 않는다. 영원천은 표시 위치에서도 기여0이며 원천이 없는 준비도 유한한 영장이다. 원래 선언한 비영 원천이 겹치면 해당 위치의 개별 특이점을 유지한다. 원천을 통합하는 모델 변경과 구분한다.

원천 충돌과 수치 overflow/underflow를 구분한다. 장이 표현 불가능해도 표현 가능한 전위는 유지한다. 필요한 장이 미정인 힘은0으로 꾸미지 않는다. 결과에 NaN·Infinity가 들어가지 않는지 재귀적으로 확인한다. 순수 모델은 표시용 화살표 길이 압축이나 자동 원천 정규화를 하지 않는다.

## 전하 수송 모델의 계약

`transportedChargeObservation`은 일정한 폭·속도·단면적의 Gaussian 전하 구름을 지정하고 밀도·전류·공간/시간 미분을 계산한다. 단일 공통 속도의 J=ρv와 여러 운반자 전류의 합을 구분한다. 속도·폭을 지정한 수송이며 힘·구성 법칙·자기 일관된 Maxwell 해를 푼 것이 아니다.

`directedSurfaceCurrent`는 균일한 평면 조각의 J·n과 면적을 사용한다. 임의로 고른 측정 면의 방향과 고정 제어 구간 양끝의 바깥 법선을 구분한다. `gaussianChargeInterval`은 구간 전하, 왼쪽/오른쪽 바깥 전류와 순유입을 반환한다. 단면적을 바꾸되 총전하를 유지하면 밀도는 달라져도 전체 끝면 전류와 구간 전하는 유지된다.

Gaussian 구간 질량은 원래 물리적 폭을 유지한 직접 밀도 적분으로 계산한다. 표준편차 한 단위 이하의 패널과16점 Gauss-Legendre 구적을 사용하며8점 결과와의 차이는 진단값으로만 반환한다. 꼬리·보기 창을 잘라 다시 정규화하지 않는다. 양의 구간 질량이 수치적으로0이 되면 underflow 상태를 남긴다.

`transportedChargeBalance`는 두 시각의 구간 전하 차와 별도로 적분한 경계 순유입을 비교한다. 역방향 시간 적분과 동일 시각도 지원한다. 국소 잔차는 해석적으로 반대인 항을 합한 항등식이라는 의미를 표시하며 독립 검증으로 과장하지 않는다. 실제 독립 유한 차분과 공간·시간 적분을 따로 대조한다.

## 독립 계산과 실제 차이

휴대 가능한 생성기는 `scripts/learning/generate-charge-current-fields-references.py`, 기준은 `scripts/fixtures/charge-current-fields-reference.json`이다. 제품 코드를 가져오지 않고 NumPy 벡터 합·퍼텐셜5점 미분, SciPy CDF·공간/시간 구적·국소5점 미분을 사용한다. 점전하48조건, 수송60조건, 국소 관측180개와 좁은 꼬리 적분7조건을 계산했다. 고정 seed로 재생성해 동결된 파일과 동일함을 확인한다.

제품과 기준의 관측 최대 차이는 장 성분과 전위 각각 약2.22×10⁻¹⁶(상수 k를 분리한 값), 장과 독립 전위 기울기3.32×10⁻¹², 구간 전하2.22×10⁻¹⁶ C, 경계 흐름8.33×10⁻¹⁷ A, 시간 적분·수지 잔차6.67×10⁻¹⁶ C였다. 국소 미분과 독립 시간 차분 차이는8.72×10⁻¹¹, 꼬리 적분의 최대 상대 차이는6.37×10⁻¹⁵였다. 지정한 조건에서 관측한 차이이며 보편적인 오차 인증은 아니다.

정확한 상쇄·영입력·점원 충돌·작은 비영 거리·수치 범위·대칭·스케일·면 법선·역방향 시간·단면적 변화도 검사한다. 기존460개 단원과 안내,41개 실험 그룹의451항목은 수정 전에 고정한 canonical 데이터와 대조한다. 보존 기준은 `scripts/fixtures/pre-electromagnetism-registry-hashes.json`으로 그대로 옮겼으며 등록 후 기대값을 재생성하지 않는다.

실제 종료와 비교·수식·소스 근거는 `.runtime/learning/charge-current-fields-foundation-verification.json`에 연결한다. 이전 홈페이지 빌드는 그대로 유지한다. 원고 렌더링 검증을 새 단원 홈페이지의 화면 검증이나 공개 배포로 부르지 않는다.
