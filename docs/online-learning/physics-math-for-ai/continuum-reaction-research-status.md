# 반응수송: 공간 조성과 전파 상·하계 연구 보강

2026-11-13. 기존 두 단원에 한영 연구 원고 4편·개념 그림 4개를 통합하고 같은 최종 출력에서 검증했다. 연속체 순차 연구 보강은 **12/22단원**이다. 영역 전체 종합 대조는 미완료이며 전체 **42영역·415주제 대조/9영역·94주제 후속**을 유지한다.

## 전역 조성이 놓치는 국소 전환

`reversible-reaction-advection-diffusion-budget`는 양의 반응률과 서로 다른 초기 종 구름을 공통 수송한 뒤 반응 행렬 지수로 혼합한다. 양의 성분·열 합 1·상수 연산자 교환으로 실제 해를 구성하고 공간 조성 PDE의 운반장 기울기 항을 유도한다. 전체 종 질량이 일정해도 국소 비율과 원천이 다를 수 있다.

현재 운반장으로 가중한 조건부 정보의 Hessian과 반응 내적으로 확산·반응 소산을 분리한다. 단위는 kg이며 열역학적 엔트로피가 아니다. 조건부 정보 영도 운반장 전체의 평형을 보장하지 않는다. 영 반응률에 양의 평형 가중치 로그 식을 적용하지 않으며 기존 시간 전용 실습은 보존한다.

## 선형 상계와 별도의 양의 하계

`fisher-kpp-reaction-diffusion-front`는 봉우리 K 이하인 유한 질량 Gaussian 초기값 문제를 별도로 둔다. 선형 성장 Gaussian 상계의 경로별 지수율로 임계 원뿔 바깥의 감쇠를 설명한다. 상계 증가를 비선형 침입의 증명으로 바꾸지 않는다. 지수 시험 함수의 분산 관계와 원래 정확 이동해의 완만한 꼬리를 대조하며 두 초기 자료를 구분한다.

임계보다 작은 상대 속도에는 기울인 유한 지지 코사인 봉우리를 구성한다. 유한 폭 누출·이류 비용과 초기 최소값·반응 여유로 폭과 양의 진폭을 정한다. 영 연장의 일차 미분 점프를 포함해 약한 하부해 부호를 확인한다. 내부 경로의 비소멸 하한은 수용 농도로의 수렴·큰 관측 문턱·로그 전선 보정까지 증명하지 않는다. 실제 비선형 궤적을 수치적으로 푼 것으로 소개하지 않는다.

## 원고·독립 계산·그림 검토

한영 **40표시 수식·4 Python 표·12연구 해설**의 수식·코드·실제 출력이 같다. 연구 절 제거로 원래 4본문을 바이트 단위로 복원하고 **24기존 해설**과 원래 13/14절을 보존한다. 최종 목차는 14/15절이다. 실험실 경로 속도와 상대 속도는 다른 기호로 표시했다.

독립 표준 라이브러리 계산은 **144정확 반응 반군·81정확 정보 Hessian·81반응 로그 비/부호**를 검증했다. 실제 혼합장 독립 차분 **18사례**, 조건부 정보 적분 **4시각**, 부호 있는 속도의 이동 하부해 **45사례**, 선형 Gaussian 경로/꼬리 **45사례**를 확인했다. 초기 정보 변화율은 실제 장을 직접 미분해 적분한다. 유한 구적·차분 사례는 일반 비교 원리나 모든 꼬리의 인증을 대신하지 않는다.

홈페이지 색·서체 계열의 한영 SVG 4개를 원본 크기로 직접 검토했다. 전역/국소 조성, 조건부 정보의 kg 단위, 지수 시험 관계, 선형 경로 상계와 정규화한 약한 하부해를 구분했다. 유한 그림 구간을 잘라 재정규화하지 않았다. 작은 양의 진폭은 과학 표기로 남긴다.
