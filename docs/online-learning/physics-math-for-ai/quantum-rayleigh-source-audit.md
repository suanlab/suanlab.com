# General Hermitian Rayleigh engine: 수학·입력·정밀도 계약

2026-11-08. [양자 변분 집필 설계](quantum-variational-authoring-plan.md)의 첫 수치 가족이다. 이 문서는 연속 Hamiltonian이나 양자 변분 주제 전체의 검증 완료가 아니다.

## 입력과 정확한 계산

`src/lib/learning-rayleigh-input.ts`는36개 소유 정수 필드를 받는다. `dimension`은1…4, `hDenominator`와 `pathDenominator`는1…10⁶이며 나머지 정수의 절댓값은10⁶ 이하이다. Hamiltonian은4개 실수 대각과6개 복소 상삼각 원소로 지정하고 하삼각은 켤레로 구성한다. 상태와 방향은 각각4개 복소 원소이며 비활성 좌표는0이다. 상태는 비영이어야 하고 방향은 영벡터도 허용한다. 경로는 ψ+tη, t=`pathNumerator/pathDenominator`이다.

추가 키·symbol·누락·상속·accessor·잘못된 차원·비활성 원소·분수·비유한 수·영분모·영상태를 거부한다. getter를 실행하지 않고 data descriptor를 검사하며 입력 복사본을 동결한다. 원래 입력을 정규화된 상태로 덮어쓰지 않는다.

`learning-rayleigh.ts`는 N=ψ†ψ, E=ψ†Hψ/N, 〈H²〉, r=(H−E)ψ, Var(H)=r†r/N을 정확 복소 유리수로 계산한다. E와 분산의 두 계산 방식 및 ψ†r=0을 대조한다. 실수 경로 매개변수에 대한 미분은 E′=2 Re(η†r)/N, E″=2η†(H−E)η/N−2E′N′/N이다. 상태의 크기·전체 위상 방향 미분은0이다. 일반 η에서 방향 미분이0인 경우와 모든 복소 방향에서 정류하는 경우를 구별한다.

경로가 영벡터에 닿으면 입력 전체를 거부하거나 이전 값을 재사용하지 않는다. 해당 경로점의 모멘트만 `null`, `defined=false`로 반환한다.

## 스펙트럼·축퇴·바닥 공간

일반 Hermitian 행렬의 모든 principal minor에서 정확 특성 다항식을 구성한다. 기존 `learning-tensor-roots.ts`의 square-free/Sturm 분리는 **부호가 있는 일반 실근**을 처리하므로 양의 스펙트럼으로 제한하지 않고 재사용한다. 차수1…4,1024비트 분리, 정확 중복도와 유리수 구간을 보존하며 Number 고유값이나 거리 임계값으로 중복을 결정하지 않는다.

서로 다른 고유값 λⱼ에 대해 Pⱼ=∏ₖ≠ⱼ(H−λₖI)/(λⱼ−λₖ)로 전체 고유공간의 사영을 계산한다. 축퇴 공간에서도 특정 기저 벡터를 선택하지 않는다. 768비트 방향성 구간 계산과512비트 바깥 반올림으로 사영·중첩·바닥 초과 에너지·gap을 반환한다. 확률은 증명된[0,1] 범위와 교집합을 취한다. 상태 벡터 재정규화나 고유값/gap의 임계값 병합은 하지 않는다.

확률 합·에너지/이차 모멘트 재구성, 사영 완전성·Hermitian 성질·멱등성·고유공간 방정식·사영 trace와 중복도의 차이는0을 포함하는 구간으로 검산한다. 에너지 분산이 정확히0이면 정확 에너지가 포함된 유일한 고유공간을 찾아 중첩0/1을 결정한다. 들뜬 고유상태를 바닥 상태로 오인하지 않는다.

서로 다른 들뜬 에너지가 존재할 때만 Δ>0을 정의하고 누출≤(E−E₀)/Δ를 계산한다. 인증된 몫 구간의 상단과1 중 작은 값을 누출 상한으로 제공한다. 상수 Hamiltonian은 전체 공간이 바닥 공간이며 gap·해당 몫·gap 기반 상한은 `null`이다. 이는 일반 잔차 오차를 바닥 상태 fidelity라고 부르는 주장이 아니다.

## 독립 검증과 적용 범위

Python 생성기는 생산 TypeScript를 호출하지 않는다. SymPy가 모멘트·특성 다항식·실수 경로 몫의1·2차 미분·정확 Sturm 중복도를 구하고, mpmath250자리 Hermitian 고유분해가 사영과 확률을 독립 계산한다. 중복 공간의 묶음은 부동소수점 거리 대신 정확 다항식의 중복도를 사용한다.215자리 기준을 출력하며 대조 허용 오차는 max(1,|기준|)×10⁻²⁰⁵이다. 극미한 수치 잔차의 기준 표현 정책은 fixture에 명시했다.

56개 서로 다른 준비가 전체 차원·일반 복소 결합·양/음/영 에너지·축퇴·상수 H·복소 위상·크기·Hamiltonian 이동/양음 배율·최대 계수·약10⁻¹² gap·약10⁻²⁴ 분산·영경로를 포함한다. 이 사례들의 출력 구간 폭은 max(1,|기준|)×10⁻¹²⁵ 이하이다. 이것을 모든 허용 입력에서의 일률적인 폭 보장으로 확대하지 않는다.
