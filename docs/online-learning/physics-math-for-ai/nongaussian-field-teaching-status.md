# 비가우스 연결 상관: 한영 학습 화면 검증

2026-11-10. `interacting-nongaussian-connected-correlations`의 독립 학습 화면을 구현했다. 실제 Interactive Book reader 등록과 생산 Next.js 자산 검증은 다음 단계다. 등록595단원·1826안내·입문314/362검증·48미완료·미등록1초안을 유지한다.

## 학습 내용과 시각화

한영8개념·6안내·8해설 퀴즈·17예제를 연결했다. 모든 배치 확률과 총자화 히스토그램, 위치별 스핀과 평균, 연결/원래 이점함수·감수율·logZ Hessian 열지도와 이산 Three.js 막대, 중심 사차·공분산 세 쌍·사차 누적량을 비교한다. 배치 재생은 이진 순서의 전수 탐색이며 시간 궤적이나 확률 표본 추출이 아니다.

표는 정확한 분수를 사용하고 그림은 그 값을 실수로 투영한다. C와 κ₄를 그림에서 모멘트끼리 빼서 재계산하지 않는다. 각 그림은 독립적으로 재척도하며 부호 로그의 정의와 확률 그림에도 적용됨을 밝힌다. 표현 불가 값은 그림을 숨기고 정확한 표를 남긴다. 이 방어 경로는 합성 큰 값으로 검사했으며36참조 입력은 표시 가능했다.

독립/순수 사체/반대 사체를 선택하여 평균0·공분산I·서로 다른 사차 누적량0,3/5,−3/5를 비교한다. 별도의 고정 기준표는 현재 입력 결과와 구분한다. 물리 원천과 Boltzmann 인자, 반복 관측 자리, 평균 응답의 온도 인자와 고정 인자/고정 에너지 온도 경로를 설명한다.

## 입력·저장·조작

위치4–8개, 열린/주기 경계, q,r,T, 원천 인자 벡터와 네 관측 첨자를 입력한다. q,r,p 범위는[1/16,16]이며 물리 원천0은 p=1이다. 위치 수를 바꾸면 벡터 길이와 첨자도 맞춰야 한다. 잘못된 입력은 이전 결과를 유지한다. 저장은 버전/크기를 검사해 복원하며 차단된 환경에서도 실험은 계속할 수 있다.

행렬은 화살표 키로 이동하며 표는 가로/세로 스크롤을 제공한다. 3D는 명시적으로 열고 키보드·터치·시점 초기화·컨텍스트 손실 후 재시도를 제공한다. 배치 선택·재생·행렬·척도는 Worker 재계산 없이 검산된 결과를 탐색한다. 감소 모션과 숨김에서 재생을 중지한다.
