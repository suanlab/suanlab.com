# 정칙 섭동: 한영 학습 화면과 시각화

2026-11-10. [독립 검증과 Worker](regular-perturbation-worker-status.md)에 한영 학습 화면을 연결했다. **실제 Interactive Book reader 등록과 Next 생산 자산 검증은 아직 남아 있다.**

## 학습 화면

8개 개념·6개 안내 실험·7개 해설 퀴즈·14개 예제를 작성했다. 용수철과 평형, 무차원화, 계수와 보정항, 잔차와 실제 오차, 에너지 보증, 수렴 반경, 민감도와 연구 검사를 설명한다. 전체 교재와 같은 HSL 색상·카드·버튼·표·명암 테마를 사용한다.

강성·결합·원천·최대 차수를 정확한 분수로 편집하고 저장·복원한다. 검증을 마친 결과에서 차수 슬라이더와 재생, 표시 범위를 바꾸어도 새 계산을 실행하지 않는다. 모션 감소 설정에서는 자동 재생을 사용하지 않는다. 입력 오류는 이전에 적용한 결과와 구별하고 새 요청·취소·오류에서는 이전 결과를 숨긴다.

## 시각화와 정확한 값

- 힘 그래프는 단조 함수, 근 포함 구간, 부분합과 수직 잔차를 표시한다. 픽셀보다 작은 근 구간은 시각적으로 확장했음을 설명한다.
- 2D 에너지 곡선과 Three.js 곡면은 실제 사차 에너지를 사용한다. 3D 축은 변위·결합·에너지이며 모든 결합 단면에 같은 선형 에너지 척도를 사용한다. 키보드·터치 카메라, 명암 전환, WebGL 손실 시2D와 재시도를 지원한다.
- 차수 그래프는 항·잔차·오차 보증·근 거리 상한의 절댓값을 상용로그로 비교한다. 매우 긴 유리수도 BigInt 계산 없이 그리며, 정확한0은 로그값과 구분한 빈 기호로 표시한다.
- 근 주변/선형 변위 범위를 선택한다. 범위 밖 부분합을 명시적으로 알리고 정확한 값과 전체 차수 그래프에 유지한다. 계수·부분합·잔차·변위/에너지 보증·근/감수율 구간·잔차 다항식은 전체 자릿수를 보존한다. 긴 표와 값은 내부 스크롤을 사용한다.

그림은 근사 투영이며 수학적 판정의 근거는 검증한 정확 결과다. 곡면은 시간 진화가 아니다. 음의 강성·다중 우물·장 전체·시간 적분이나 섭동이론 원주제 전체를 구현했다고 주장하지 않는다.

- 새7개 학습 화면 검사와 기반을 합친 **150개 검사**, 타입·대상lint·기존1825URL 콘텐츠 검사.

- 같은8조합에서 키보드 카메라·WebGL 손실/복구와 접근성16회. 기록의Worker 수는 마지막 새로고침 이후 창별4생성/4종료이며, 그 이전에도 각 계산 완료 시 활성0을 확인했다.

근거는 `.runtime/learning/regular-perturbation-teaching/`의 `tests.log`, `native-verification.json`, `storage-maximum.json`, 스크린샷과 `verification.json`이다. 로컬 검토는 `npx tsx scripts/preview-regular-perturbation.ts`로 실행하고 서버 주소는 `review-server.json`에 기록한다. 이 검토 화면은 정적 홈페이지 출력을 변경하지 않는다.
