2026-11-05. 순수 계산 모델 두 개, 이식 가능한 독립 기준값 생성기와 기준값, 상세 한영 원고 네 개를 작성한 기반 단계의 기록이다. 이후 홈페이지 연결과 검증을 마쳤으며 현재452개 단원·1,356개 안내 실험, 원래 범위254개 입문 검증·108개 미완료다. 최신 근거는 [홈페이지 연결 기록](dispersion-authoring-status.md)에 있다. 아래 기반 단계의28개 전용 검사와 미등록 시점 수치는 당시 이력이다. 전체51영역·509주제와 연구 심화도 계속한다.

## 실제 순수 모델

`src/lib/learning-dispersion.ts`는 교재 등록 데이터·Node API·외부 패키지에 의존하지 않는다.

- `gaussianDispersivePacket`은 초기 진폭 Gaussian의 이차 분산 Fourier 진화를 계산한다. 제곱근 가지를 초기 조건과 연속적으로 고르고 퍼짐에 따른 진폭 계수를 유지한다. 정확한 포락선 미분을 같은 반송 인자와 함께 반환해 방정식을 검사한다.
- 강도 노름은 무차원 장에서 m 단위이며 역학적 에너지가 아니다. 진폭 폭과 강도 표준편차를 구분한다. 영진폭의 관측 중심·위상, 영 반송 파수의 위상속도, 영 국소 위상 기울기의 마루 속도는 미정으로 반환한다.
- 반송파 기준 속도와 전체 위상의 실제 국소 등위상 속도를 분리한다. Gaussian 꼬리로부터 인과 전면을 추론하지 않는다. 이차 다항식의 정확한 해와 실제 매질의 Taylor 근사 타당성도 구분한다.
- `latticeDispersivePacket`은 양의 해상 가능한 모드만으로 실제 변위·속도·힘을 계산한다. 입자는32개 또는64개이며 영모드와 Nyquist 모드는 제외한다. 초기 변위에 맞는 진행 속도를 함께 준비한다.
- 질량ρa·강성T/a, 실제 운동·탄성·배분 에너지와 링크 전력을 계산한다. 노름은 변위 제곱의 공간 적분이므로 m³, 에너지는 J, 전력은 W다. 고정한 최고 진폭 상한에서 대역폭을 바꾸면 준비 에너지가 달라진다.
- 전력에서 직접 계산한 aΣJ/E와 모드 에너지로 가중한 군속도를 별도로 반환한다. 넓은 대역에서는 반송 군속도와 다르다. 영에너지의 전달 속도는 미정이며 중심의 시간 미분으로 대신하지 않는다.
- `periodicPacketCenter`는 비음수 가중치의 원형 모멘트와 그 크기를 반환한다. 영가중치나 크기10⁻¹⁰ 미만의 중심은 미정이다. 균일 분포 외에도 서로 마주 보는 봉우리에서 첫 모멘트가 사라질 수 있다. 작은 모멘트에서는 각도가 불안정함을 설명한다.
- ΣkA 기울기 상한을 제공하되 이를 모든 재료의 작은 기울기 근사에 대한 오차 보증으로 부르지 않는다.

## 독립 기준값과 실제 비교

`scripts/learning/generate-dispersion-references.py`는 제품을 불러오지 않고 `scripts/fixtures/dispersion-independent.json`을 생성한다. Gaussian36개 계·180개 위치에서 초기 Fourier 스펙트럼을 QUADPACK으로 직접 적분하고 포락선의 공간1·2차 및 시간 미분도 독립 적분한다. 실공간 적분으로 노름·강도 분산을 확인하고 SymPy로 포락선 방정식의 유리식 잔차가 정확히0임을 검사한다.

사슬36개 상태는 실제 실수 운동방정식 행렬의 지수함수로 계산한다. 실제 입자 변위에서 별도 FFT로 해석장을 복원하고 에너지·링크 전력·원형 모멘트를 구한다. 제품의 정현 시간 진화식을 다시 호출한 기준값이 아니다.

실제 제품과의 최대 절대 차이는 복소장 성분 약5.45×10⁻¹³, 포락선 미분9.29×10⁻¹², Gaussian 노름6.67×10⁻¹⁶, 격자 변위4.75×10⁻¹⁵, 속도5.08×10⁻¹⁴, 에너지5.73×10⁻¹⁴, 전달 속도2.11×10⁻¹⁵, FFT 해석장5.43×10⁻¹⁵였다. `.runtime/learning/dispersion-reference-comparison.json`에 기록했다. 유한 사례의 관측 차이이며 보편적 오차 상한은 아니다.

초기 검사에서는 거의 평탄한 분포의 중심 각도를 모든 집중도에서 같은 절대 허용오차로 비교하는 가정을 수정했다. 첫 모멘트가 작으면 각도 오차가 증폭되므로 주기적 최단 각도 차이에 모멘트 크기를 곱한 조건화된 비교를 사용한다. 실제 변위·속도·전력 등의 독립 검사는 그대로 유지한다. 원고에서는 순수 진행 모드의 중심 미정과 공간적 균일성을 혼동하지 않도록 설명했다.

## 최종 수학·원고 검사

전용28개 검사가 실제 기준값과 영시각·영분산·음의 chirp·영진폭·위상 기울기·힘·국소 수지·보존·좁은/넓은 대역·진폭 배율·병진·주기 경계·중심 미정·입력 범위를 대조한다. 네 원고를 실제 콘텐츠 로더와 엄격한 KaTeX로 처리하고 한영16개 목차·각 여섯 개 해설 문제를 검사했다.

전용28개·전체3,629개 테스트, TypeScript·lint·기존 등록 콘텐츠1,684개 URL 검사가 실제 종료0으로 통과했다. 네 원고를 포함한2,837개 소스 해시가 최종 검사 동안 유지되었으며, 기존 홈페이지의2,829개 소스도 바뀌지 않았다. 등록 데이터는 `pre-dispersion-data.ts`와 바이트 단위로 같다.

최종 근거는 `.runtime/learning/dispersion-foundation-verification.json`, `dispersion-foundation-*.log`, `dispersion-foundation-source-hashes.json`이다. 기존 홈페이지의 최신 실제 화면 근거는 별도의 `.runtime/learning/interference-integrated-verification.json`이며 이번 미등록 단원에 대한 화면 검증으로 사용하지 않는다. 이번 기반 작업에는 새 UI 빌드·브라우저 검증의 완료 주장이 없다.

## 기반 단계에서 정한 홈페이지 연결 계획

아래 계획은 이후 연결·검증했다. 최신 화면·진행 수치는 [홈페이지 연결 기록](dispersion-authoring-status.md)을 따른다.

1. 기존 HSL 테마로 실제 실수장·복소장·포락선·초기/현재 폭·분산 관계·chirp를 각각 표시한다. 반송 기준선과 실제 마루 추적을 혼동하지 않는다. 빠른 위상과 넓은 표시 구간의 표본 간격을 함께 검토한다.
2. 영분산과 양·음 분산, 같은 강도와 다른 위상, 영진폭·영파수의 미정값을 안내 실험과 해설 퀴즈로 연결한다. 유한 그림의 면적을 전체 노름으로 표시하지 않는다.
3. 실제 입자·모드 가중치·배분 에너지·링크 흐름·국소 수지와 두 종류의 원형 중심·집중도를 연결한다. 넓은 대역과 좁은 대역에서 반송 군속도와 에너지 전달을 비교한다.
4. 기존450개 단원·설정·상대 순서를 보존하고 화면·언어·반응형·테마·접근성·글자 영역·조작·저장·수치 검증을 마친 뒤에만 새 등록과 입문 검증 수를 반영한다.

[자료 대조](dispersion-source-audit.md)와 [전체 남은 순서](remaining-next-steps.md)를 유지한다. 이번 기반 집필은 공개 배포·commit·push를 포함하지 않는다.
