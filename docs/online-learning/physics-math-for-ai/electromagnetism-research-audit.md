## 원고·번역·선수 관계

연구 절 하나를 제거하면 기준 `fda18599013ec054a840e3c472cd278fe83b1463`의 원고 **40편**이 바이트로 복원된다. 기존 해설 **240문제**를 보존했다. 새 연구 **20쌍·364표시 수식**, Python **40셀**의 코드·실제 출력이 한영에서 같다. 새 연구 질문은 언어별 단원당 세 개, 총 **120해설**이다. 원래 표시 수식도 공백을 제외하면 한영이 같다. 기존 Maxwell 원수식의 공백 차이 8개는 의미 변화가 없어 보존했다.

등록은 **650단원·1,969안내**, 전체 분모는 **51영역·509원주제**다. 영역·단원 선수의 존재, 직접 선수의 등록 순서와 **159단원 폐포**의 순환 없음을 확인했다. 기존 보존 원장 717항목을 그대로 유지하고 전자기학 40항목을 더해 757항목이다.

종합 감사 중 Maxwell 평문 별표가 강조 문법으로 처리되는 문제를 발견했다. [기호 수정](electromagnetism-symbol-repair.md)에서 한영 20곳을 교정하고 수정 전 회귀 실패를 재현했다. 이전 연구 입력 152개 중 150개는 같고 두 원고의 평문 기호만 명시적으로 바뀌었다. 수식·코드·기존 원본문은 보존했다. 수정 전 부분 화면 결과는 분리하고 최종 160화면을 새 출력에서 다시 실행했다.
