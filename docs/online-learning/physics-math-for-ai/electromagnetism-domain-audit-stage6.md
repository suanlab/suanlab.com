# 전자기학 종합 점검 6차: 남은 계산 모델과 독립 참조

2026-11-05. [5차 점검](electromagnetism-domain-audit-stage5.md)의 수정 소스와 정적 출력을 유지한 채 남은 다섯 계산 모델군을 검토했다. 전체 영역의 화면 검사는 진행 중이며, 이 보고서만으로 전자기학 종합 점검이나 연구 심화를 완료 처리하지 않는다.

## 계산·입력·그림 대조

- **정전·정자기:** 균일 비도체 구와 무한 정상 전류 원통의 내부·외부 장, 중심·축의 영벡터와 비영 발산·회전, 경계 한쪽 미분을 대조했다. 배경장을 더한 점별 장과 선속·순환의 정규화 값을 구분한다. 그림의 구 단면·측정 구 투영과 원통의 원형 경로는 서로 다른 적분 기하다.
- **매질·경계:** 법선 D의 자유 전하, P의 분극 전하, 접선 E의 순환과 전위 점프 부호를 확인했다. 높이0의 양쪽 극한을 실제 측정값으로 채우지 않는다. 수직 입사의 반사 H 부호, 임피던스가 포함된 전력 투과율, 강제 무반사에 필요한 시트 전류·일을 대조했다.
- **게이지:** A/V 동시 변환과 부분 변경, 실제 장·원천·Lorenz 표현을 따로 확인했다. 조화 전위의 지정 원천과 장이 요구하는 원천, 초기 G와 시간 미분, 일정한 비영 G의 대조를 읽었다. 정규화 좌표와 SI 척도를 구분한다.
- **회로·센서:** RC 회로의 순간·누적 에너지 수지와 준정적 장 복원의 Faraday 결함을 대조했다. 유한 면적·이동 코일의 전기·운동 기여, 정지 교정 코일, 구조적 rank·조건수·측정 오차·비식별한 절대 장을 확인했다.
- **유효 모델:** 개방 전송선의 위상 관례, 정확한 DC와 주기 평균 극한, 유한 이진 위상과 기호 공진을 대조했다. 층상 매질의 전달행렬·산란망·내부 장, 접힌 Bloch 위상, 금지대 감쇠와 흡수, 빈 적층과 셀 분산을 구분한다.

각 모델군의 순수 계산, 실험 연결, 그림 컴포넌트와 독립 참조 생성기를 직접 읽었다. 해당 10개 단원의 한영 개념 단계40개·안내 실험30개·퀴즈20개와 예제 입력도 대조했다. 전체20단원의 본문 검토는 앞선 4차 기록에 이어 유지한다. 이번 검토에서 추가 제품 수정이 필요한 결함은 확인하지 못했다. 임의의 모든 부동소수점 입력이나 일반 장치·재료의 정확성을 증명한 것은 아니다.

## 실행 근거

관련 테스트는 두 실행에서87개와127개, 합계214개가 종료 코드0으로 통과했다. 독립 참조 생성기 다섯 개를 별도 경로에서 재실행했고, 결과는 기존 canonical 참조와 의미 및 파일 해시가 모두 일치했다. 기존 참조 파일은 덮어쓰지 않았다.

검증 방법은 Coulomb 껍질 구적·전위 차분, Biot–Savart 필라멘트 구적, 실제 표면·경로 구적, 경계 선형계, 전위의 시공간 차분, RC 초기값 적분, 이동 코일의 선속 미분, 전송선 ODE·공간 에너지 구적, 층 행렬 지수·산란 경계 계산이다. 고정밀 참조의 정밀도는 모델군에 따라180 또는240자리다. 이 수치 비교는 선택한 예제의 근거이며 엄밀한 전역 오차 상한이 아니다.

근거는 `.runtime/learning/electromagnetism-domain-stage6/`의 재계산 참조, `reference-comparison.json`, `reviewed-teaching-data.json`, 소스·출력 해시와 관련 실행의 실제 종료 기록이다. 제품 소스 변경이 없어 전체4,257개 테스트·빌드의 근거는 같은 해시의5차 기록을 사용하며, 이번에 전체 검사를 재실행했다고 표시하지 않는다.
