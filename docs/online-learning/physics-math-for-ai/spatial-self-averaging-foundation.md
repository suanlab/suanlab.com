# 공간 밀도·상관·자기평균화 계산 기반

2026-11-07. 유한계·열역학 극한의 두 번째 가족 `spatial-density-self-averaging-correlations`의 정확 모델과 독립 기준을 검증했다. 자세한 [유도와 손계산](spatial-self-averaging-derivation-notes.md)을 작성했다. 한영 학습 본문·worker·학습 화면·등록은 아직 미완료다. 첫 가족의 모델·한영 원고는 보존하며 세 번째 가족은 다음 제작 대상이다.

## 구현과 입력 계약

- 모델: `src/lib/learning-spatial-self-averaging.ts`.
- 독립 생성기: `scripts/learning/generate-spatial-self-averaging-oracle.py`.
- 기준: `scripts/fixtures/spatial-self-averaging-oracle.json`.
- 검사: `scripts/learning-spatial-self-averaging.test.ts`.

N=1..512, 정수 점유/비점유 무게0..10^6과 양의 합, 기본 공통모드 비0≤C/D≤1, 양의 유리수 ε를 받는다. 분모와 ε의 분자는1..10^6이다. 공통 가중치 경로는 c,c/N,c/N²다. 지정한8개 키 외 입력은 거절하며 임의 precision 설정은 없다.

계 전체의 모드를 한 번 선택하는 공간 준비다. 동일한 한 자리 평균에도 서로 다른 공분산과 평균 밀도 분산이 생긴다. 정확한 분포·모멘트·순서 있는 공분산 합·포함 꼬리 사건·Chebyshev와 혼합 상한을 제공한다. 분포에서 합한 모멘트를 닫힌 식과 대조한다. 크기 기록은2의 거듭제곱과 요청 끝점이며 시간 궤적이 아니다.

유한 값은 BigInt 유리수의 점 구간으로 보존한다. 직렬화 가능한 문자열 계수와 분모가 인증값이며 Number와 로그 크기는 표시용이다. 비영 확률의 표시 불가를0으로 바꾸지 않고, 유한 꼬리 비의 범위 초과를 수학적 무한대로 바꾸지 않는다. N=1의 다른 자리 쌍 부재, p=0/1의 상관계수·분산 등가 수 미정의를 정확한0과 구별한다.

## 확인한 학습 반례

고정 공통 가중치에서는 밀도 분산이 남는다. c/N은 자기평균화하면서 IID와 다른 선도 계수를, c/N²는 같은 선도 계수를 갖는다. 후자도 매우 드문 사건에서는 IID보다 훨씬 큰 꼬리를 보일 수 있다. 반대로 공통모드가 분산을 키우면서 특정 임계값의 꼬리 확률을 줄이는 준비도 검증했다. 약한 극한 원자와 고정 ε 사건의 극한은 별도로 유도했다.

현재 준비에서 p 변경은 고정 기준 법칙의 지수 기울이기가 아니다. 분산을 입력 p의 열역학적 응답으로 부르지 않는다. 일반 Gibbs 모형·대편차·시간 MCMC·AI 샘플러의 성능을 이 모형에서 추론하지 않는다.
