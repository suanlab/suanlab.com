# 열역학 법칙: 실습 입력과 계산 곡선 연결

2026-11-06. [세 계산 가족의 기반 검증](thermodynamic-laws-foundation.md) 이후 [상호작용 계획](thermodynamic-laws-interaction-plan.md)의 입력·계산 연결을 구현했다. **실제 실습 화면·교재 등록·주제 전체 검증은 아직 완료하지 않았다.**

## 구현한 연결

`src/lib/learning-thermodynamic-laws.ts`는 브라우저에서 사용할 수 있는 독립 어댑터다. 기존 계산 모델과 동일한 입력 범위를 사용하며, 카르노 순환 7개·저장고 수지 4개·유한 스펙트럼 5개의 전체 입력을 각각 검증하고 계산한다. 방향·복제 수·축퇴도에는 정수만 허용한다. 잘못된 배열·비유한 값·빈 배열 슬롯은 거부한다.

저장고 온도 순서가 반대이면 두 온도를 바꾸거나 계산을 강행하지 않는다. 원래 입력과 `invalid-reservoir-order` 상태를 반환하여 화면에서 수정할 수 있도록 한다. 현재 관측값은 그래프의 보간값이 아니라 선택한 입력으로 직접 계산한다.

카르노 순환은 네 꼭짓점·시작·끝·현재 진행률을 포함한다. 역방향도 직접 계산하여 아주 작은 진행률이 `1−s` 연산에서 사라지지 않게 한다. 전체 순환의 냉동기 분류와 부분 순환의 양의 일을 함께 보존한다.

저장고 곡선은 상대 엔트로피 생성 계수를 바꾸는 **완결된 순환들의 비교**다. 내부 피스톤 경로나 시간·출력이 아니다. 반사실적 음의 생성, 전달 없음, 일 입력, 가역 한계와 실제 효율의 정의 범위를 계산 모델에서 그대로 전달한다. 부동소수점으로 계산한 영 일 경계는 정확한 영이라고 강제하지 않는다.

스펙트럼은 양의 온도에 로그 축을 사용하고, 선택한 온도가 전이 구간과 멀어도 간격 주변을 별도로 세분한다. `T=0`은 독립된 평형 극한 관측이다. 정확한 정수 상태 수와 복제당/전체 관측을 유지한다. 표현 범위 밖인 비영 값이나 미정은 그래프에서 선을 끊으며 실제 0으로 그리지 않는다. 로그 크기는 부호와 별도다. 곡선은 유한한 표본의 평형 비교이며 실제 냉각 동역학이 아니다.

## 검증과 다음 단계

`scripts/learning-thermodynamic-laws-adapters.test.ts`의 20개 검사는 모든 입력 연결, 수정 가능한 온도 순서, 정수 제약, 극소 진행률·온도·간격, 영 간격과 유한 간격의 구별, 곡선 분리, 직렬화를 검증한다. 세 계산 모델·한영 본문 검사를 합친 **191개 검사**, 타입 검사, 해당 파일 lint를 통과했다. 실행 근거는 `.runtime/learning/thermodynamic-laws-adapters-verification.json`이다.

다음 작업은 실제 그래프·읽기값·입력 화면과 각 가족의 개념 4단계·안내 3개·이해 확인 2문제다. 이후 교재 등록과 전체 빌드·정적 출력·브라우저·언어·접근성·모션 검증을 진행한다. 메뉴는 **도서 → Interactive Book**을 사용한다. 현재 등록 504단원·1512안내, 원래 범위 검증 280주제·잔여 82주제를 이번 단계에서 늘리지 않는다.
