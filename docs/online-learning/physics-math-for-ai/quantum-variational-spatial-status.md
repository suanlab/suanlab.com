## 3D 표시

`quantum-variational-space-engine.ts`는 이미 계산된 실수 3차원 좌표를 Three.js로 그린다. 시험 공간의 차원에 따라 단위 선분·원판·단위 구의 그물을 표시한다. 구는 노름 기준이며 무한한 선형 공간의 경계가 아니다. 상태와 잔차는 각각 파랑과 주황이다. 잔차는 공통 에너지 척도를 사용하며 단위 길이로 정규화하지 않는다.

공간 방향은 직교 투영 행렬에서 구한다. 복소 성분을 버리거나 높은 차원을 잘라 그림을 만들지 않는다. 복소/다른 차원은 전체 성분 그림과 행렬로 안내한다. 카메라 드래그·정면·위·초기화 버튼이 있으며 자동 회전·물리적 시간 진화·유휴 그리기 루프는 없다.

화면에 접근하면 renderer를 생성한다. 2D 전환, 입력 변경, WebGL 손실과 화면 해제 시 이벤트·관찰자·controls·geometry·material·texture·renderer·GPU context를 정리한다. WebGL 미지원과 생성 도중 실패에는 같은 좌표의 두 2D 투영을 제공하고 다시 시도할 수 있다. 고해상도 모바일에서도 canvas의 CSS 크기와 drawing-buffer 크기를 분리한다.

두 단원에 기존 색상 토큰을 사용하는 장식 표지를 준비했다. 읽기 강조 재생은 모션 감소·전역 일시정지·화면 밖 상태에서 멈춘다. 일시정지 중에도 사용자가 재생 의도를 완전히 해제할 수 있다.

초기 예제의 값을 잘못 편집한 뒤 같은 예제로 초기화할 때 오류 표시가 남는 문제도 수정했다. 유효 입력이 같더라도 초기화는 편집 초안을 새로 만든다. 두 종류의 실제 화면에서 회귀 검사를 통과했다.

## 검증 범위

- 기존 학습 화면 회귀: 한영·320/1440px·명암 8개 조합, 예제 선택 50회, 예측·퀴즈·안내 실험 각 24회, JSON·차원 변경·저장 복원·접근성 검사 각 8회.
- 실제 WebGL: 한영·모바일 DPR 2/데스크톱 4개 조합. 카메라 키보드·마우스·모바일 실제 터치, 세 잔차, 1/2/3차원 시험 공간, 명암 전환, 실제 `WEBGL_lose_context`와 복구, 2D 전환, 복소 사례 제외, 유휴 draw 호출 부재, 해제 후 애플리케이션 관찰자와 Worker 정리.
- 초기화 실패: WebGL context 미지원과 renderer 설정 중 ResizeObserver 오류를 주입해 2D 전환·canvas 제거·재시도를 확인.
- 실제 UI 8개 사례: 올바른 저장값 복원, 손상·다른 종류 데이터의 기본값 복구, 저장 거부, Worker 생성/실행 실패 후 재시도. 계산 시작 후 취소·다시 계산·다른 입력으로 교체·화면 해제/재진입. 키보드와 실제 터치 가로 이동, 수동/자동 강조, 모션 감소·전역/화면 밖 정지.
- 계산·학습 36개와 추가 공간·SSR 3개 테스트. SSR은 브라우저 전역 없이 접근 가능한 2D 그림과 장식 표지를 출력한다.

최종 통과 수와 로그는 `.runtime/learning/quantum-variational-spatial/verification.json`을 기준으로 한다. 초기 정리 검사에서는 Playwright가 페이지 수명 동안 유지하는 자체 MutationObserver를 발견했다. 캡처된 `InjectedScript._setupGlobalListenersRemovalDetection` 스택으로 해당 테스트 도구 관찰자만 구별하고, 애플리케이션 관찰자의 종료를 검사했다. 근거는 `cleanup-failure.json`과 검증 스크립트에 남겼다.
