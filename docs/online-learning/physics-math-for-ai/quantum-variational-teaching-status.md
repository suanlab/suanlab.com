# 양자 변분 원리: 학습 화면 준비

후속 3D·UI 검증은 [양자 변분 원리: 3D와 학습 화면 검증](quantum-variational-spatial-status.md)을 참고한다. 아래는 핵심 학습 화면을 준비한 시점의 기록이다.

2026-11-09. 전체 교육과정의 다음 원주제 `variational principle`을 두 단원으로 준비하고 있다. 기존 등록 **564개 단원 / 1,692개 안내 실험**, 원주제 **307/362**의 완료 수는 올리지 않는다.

## 구현 범위

- Rayleigh 에너지·분산·고유값 잔차·바닥 공간 확률·gap·경로 미분과 영벡터 경로의 정의 불가 상태.
- 비직교 Ritz 공간의 metric, 실제 열 prefix의 최소 에너지, 좌표 변경, 내부/바깥 잔차의 직교 분해.
- 각 단원 16개 예제, 세 단계 개념 비교와 예측 문제, 세 안내 실험, 별도의 해설 퀴즈 세 문항. 고정 비교와 자유 실험 입력은 독립적이다.
- 모든 정수 입력, 원자적 JSON 입력, 전체/시험 차원의 새 공간 생성. 유효하지 않은 편집은 마지막 유효 입력을 유지한다.
- 실제 module Worker를 사용하는 자유 실험, 취소·재시도, 복원 완료 후 저장. 입력이 바뀌면 이전 계산 결과를 숨긴다.
- 에너지/확률의 서로 다른 눈금, 복소 성분 그림, 수치 인증 표. 실제 실수 3차원 사례에는 투영 행렬에서 구한 시험 공간의 단위 노름 절단과 상태/잔차의 두 직교 투영을 제공한다. 복소 성분이나 다른 차원을 생략해 공간 그림을 만들지 않는다.
- 기존 홈페이지의 카드·버튼·색상 토큰을 사용한다. 다크 모드의 기본 select 배경 대비 문제를 수정했다.

## 검증과 근거

`scripts/learning-quantum-variational-teaching.test.ts`는 32개 예제의 실제 계산/결과 인증, 지원 차원 조합, 입력 조건, 공간 축의 정규직교성과 투영 일치, 복소/다른 차원 표시 제한, 선수 단원과 퀴즈를 검사한다. **36개 통과**.

`scripts/check-quantum-variational-teaching.ts`는 기존 로컬 정적 서버에 테스트 경로만 연결한다. 실제 컴포넌트와 Worker를 별도로 묶어 한영·320/1440px·명암 8개 조합에서 예제, 예측 문제, 해설 퀴즈, 안내 실험, 잘못된 입력, 저장/퀴즈 복원, JSON, 차원 변경, 영어 화면, 가로 넘침과 접근성을 검사한다. 최종 실행 결과는 `.runtime/learning/quantum-variational-teaching/browser-verification.json`과 로그를 기준으로 한다.

이는 등록 전 컴포넌트 검사다. 실제 교재 읽기 페이지나 Next 정적 Worker 자산의 검증으로 간주하지 않는다. 이전 소스·근거 6,372개와 정적 출력 4,376개를 비교한 변경 없음 기록도 같은 근거 폴더에 있다.

## 다음 순서

1. 같은 실수 공간 데이터의 Three.js 카메라/3D 표시와 2D 대체 화면, WebGL 실패·복구·자원 정리 검증.
2. 단원 표지, 실제 화면에서의 취소/재시도·저장 거부·키보드/터치 이동·모션 제어 추가 검증.
3. 두 언어 원고·단원·안내 실험을 등록하고 실제 읽기 화면, 정적 빌드와 배포용 Worker 자산을 검증.
4. 검증 완료 후에만 원주제 완료 수를 올리고 다음 양자역학 주제로 진행.

교재 진입은 **도서 → Interactive Book**을 유지한다. Online Book 목록에 새 교재 링크를 추가하지 않는다. 이번 준비 단계에서는 기존 `out/`과 미리보기 서버를 교체하거나 배포하지 않는다.
