## 실제로 구현한 내용

[계산 모델](../../../src/lib/learning-continuum-godunov.ts)은 무차원 Burgers의 Godunov·미보정Roe 궤적을 각각 실행한다. 전체선 Riemann 해의 정확한 셀 평균을 외부 ghost 자료로 매 이전 시간에 공급한다. 파가 경계를 지났다고 초기 원방 값을 고정하지 않는다. 실제 수치 경계 플럭스를 누적한 질량 장부와 셀 직접 합산을 따로 제공한다.

압축·팽창·sonic·정지·상수·음의 상태를 다룬다. 면 보존 플럭스, 수치entropy플럭스·결손D, 셀별 충분 조건, 실제Euler의 양의 보정과 전체 예산을 구분한다. 두 셀Roe의 전역·셀별 상쇄가 잘못된 개별 면을 감추는 반례도 확인했다. 주기4셀 손계산과 양의 비보존advective 갱신의 실제 질량 손실을 별도 API로 제공한다.

[한국어](../../../content/learning/physics-math-for-ai/godunov-burgers-conservative-shock-entropy.ko.md)·[영어](../../../content/learning/physics-math-for-ai/godunov-burgers-conservative-shock-entropy.en.md) 원고는 각각14절, 일치하는 표시 수식11개, 코드 예제와 풀이6개를 포함한다. 보존과 해 선택, 전체선 참조와 수치 경계, entropy밀도 평균과 평균의제곱, 질량·entropy·CFL의 다른 의미를 설명한다. 기존 `weak-entropy-riemann-solutions`의 해석해 설명에서 실제 비선형 갱신·국소/시간 예산으로 확장했다.

## 독립 참조와 수치 수정

[참조 생성기](../../../scripts/learning/generate-continuum-godunov-references.py)는 제품 코드를 가져오지 않는다. Godunov는 볼록 플럭스의최소/최대로, Roe는중심플럭스−점성으로 계산한다. 실제 고정밀Euler 궤적, 구간별 정확한셀모멘트, 경계통과시간을나눈연속체경계플럭스적분을사용한다. 질량뿐아니라연속체entropy의경계공급과충격결손도독립적분으로대조한다.

일반궤적24사례160자리, 작은값12사례1600자리, 두해법면162사례1600자리를계산했다. 출력은70유효숫자로직렬화하며계산정밀도와구별한다. 총198참조를재생성해fixture와바이트일치를확인했다. 궤적의아주작은면결손은중심점성에따른동등한안정식을사용하고, 고정면참조는원래잠재함수차와플럭스정의로직접대조한다.

검사에서드러난다음문제를수정했다.

- 작은시간에큰셀값/주된변화를직접빼면수치오차가사라졌다. 초기선형응답과비선형나머지를분리하고, 파가바로인접셀에머무는범위의정확한선형셀변화와비교한다.
- 큰경계entropy와공간소산을반올림한뒤합하면작은실제증가량을잃었다. 공유면일의결합식을대수적으로재배열해계산하고, 개별성분의반올림합은별도진단으로남겼다.
- 수치entropy플럭스의정확한영점에서작은가짜잔차가생겼다. 좌/우추적선택의인수분해식을사용하고정확한기호식으로동등성을확인했다.
- 거친셀의평균오차만으로는충격해상도의수렴을판정하기어려웠다. 수치상수재구성과정확프로필의L1적분및실제문턱교차위치를추가해고정물리시간의수렴을확인했다.
- 상수상태에는충격/희박파경계를제공하지않도록했다.

극도로작은전달량을0으로클리핑하지않는다. 큰dt도입력그대로실행하며비유한일반값은부호·로그와함께null로제공한다. 로그산술도유한정밀도이고, 나쁜상쇄와CFL경계의엄격판정에는반올림영향이남는다.
