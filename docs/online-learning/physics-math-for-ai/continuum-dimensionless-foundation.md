## 두 계산 가족

[`learning-continuum-dimensionless.ts`](../../../src/lib/learning-continuum-dimensionless.ts)에 정상 상수계수 scalar 경계값 문제 두 개를 구현했다. 범용 유체·반응·열 결합 해석기라는 주장을 하지 않는다.

| 단원 ID | 계산과 비교 |
| --- | --- |
| `advection-diffusion-peclet-boundary-layer` | 부호 있는 Pe,두 경계 가중치·농도·기울기/곡률,이류·확산·전체 플럭스와 실제 면적 수송,두 시간·경계층 척도,작은 Pe 보정·큰 Pe 로그 꼬리 |
| `reaction-diffusion-damkohler-penetration` | 반두께 평판의 Da·Thiele,농도·고갈·기울기/곡률,국소/전체 소모·유입·저장 질량,효과도·부족분·침투 길이,작은 Da와 큰 φ밀폐면 꼬리 |

물리 관측은 일반 값·부호·로그 크기를 함께 가진다. 실제0과 비영 표현 불가를 구분한다. U0의 이류 시간,k0의 반응 시간/침투 길이,농도 대비0·표면 농도0의 측정 정규화,이상 소모0의 측정 효과도에는 임의의 유한값을 만들지 않는다. 해석적 기저와 실제 측정 비도 구분한다.

큰 Pe에서는 양의 경계 가중치와 안정적인 경계 플럭스를 사용한다. 작은 Pe에서는 선형장에 대한 비영 보정을 별도로 유지한다. 큰 φ에서는 log cosh비와 밀폐면의 반사 계수2를 유지하고,작은 Da에서는 sinh곱 항등식으로 고갈을 계산한다. 결합 배율은 반올림된 중간값을 다시 곱하지 않고 로그에서 합성한다. 같은 Pe/Da의 닮음과 실제 시간·질량·전체 수송량 변화도 검사했다.

## 한영 상세 원고

두 ID의 `content/learning/physics-math-for-ai/{id}.{ko,en}.md`를 작성했다. 각 언어에서13개 절과 풀이6개를 제공한다. Peclet 원고는 언어별8개 수식,반응·확산 원고는9개 수식을 갖고 한영 수식은 일치한다.

일반 대학원생을 위한 동기·가정·단위·직접 유도·손계산·대조·작은 변화·산술 범위·닮음·AI 전이의 적용 조건을 포함했다. Reynolds·Mach·Froude·Prandtl·Schmidt·Peclet·Damkohler는 정의와 적용 항을 표로 연결했고,Weissenberg·Deborah의 시간 정의와 주기/각주파수의2π차이도 설명했다.

실제 Markdown/KaTeX 렌더링,목차 ID,접근 가능한 수식·표,한영 수식17쌍,각6개 풀이,영문 한글 부재를 검사했다. 실습 그림을 이미 브라우저에서 확인했다는 뜻은 아니다.

## 독립 참조와 수정 사항

`scripts/learning/generate-continuum-dimensionless-references.py`는 제품 모델을 import하지 않는다. 일반 사례는160자리,작은 입력과 큰 지수 극한은1,200자리 mpmath 계산을 사용한다. 이류·확산20개와 반응·확산20개는 직접 경계값 해의 수치 미분을 대조한다. 실제 좌표에서20개 플럭스 적분·20개 저장량 적분·20개 반응 소모 적분도 수행한다. 두 가족의 극한을 각각12개 추가해 총64개 참조를 제공하며 별도 재생성 결과가 fixture와 바이트 단위로 일치한다.

독립 참조에서도 작은 왼쪽 가중치를1−오른쪽 가중치로 만들면 큰 음의 Pe에서 꼬리가 사라질 수 있음을 확인했다. 직접 지수 차의 경계식을 사용하고,작은 역방향 전체 플럭스는 국소 큰 항을 빼지 않는 끝점에서 미분하여 계산했다. 최초 참조는 채택하지 않았으며 수정 생성기의 결과만 검증에 사용한다.

최소 양수의 절반 부근의 로그를 다시 지수화할 때 반올림으로 최소 양수가 만들어지는 문제를 수정했다. 값을 만들어 채우는 대신 비영 부호·로그와 일반 값 불가를 남긴다. 이는 모든 입력의 엄밀한 반올림 오차 한계나 모든 실수의 정확한 연산을 보증하는 방식은 아니다.
