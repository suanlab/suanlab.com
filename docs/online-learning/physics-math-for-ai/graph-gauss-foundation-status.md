# 정준 그래프·Gauss 제약·물리 위상공간의 한영 원고와 계산 기반

2026-11-10. `graph-gauss-constraints-physical-phase-space`의 한영 상세 원고와 정확 계산 모형을 작성했다. [일차 자료·범위 검토](graph-gauss-primary-source-audit.md)를 바탕으로 연결만의 궤도 차원과 정준 제약 이후의 물리 위상공간을 구분한다. **독립 응답 검증·실제 Worker·학습 화면·reader 등록은 아직 남아 있다.**

## 작성한 내용

각 언어판은18절·16표시수식·7해설 문제를 담는다. 진자의 각도/운동량에서 출발해 접속행렬의 부호,제약 생성자,경계 전하,rank와 안정자,원형 좌표/국소 각도,숲과 경로 행렬,affine 전기 해,정준 쌍과 Hamiltonian미분을 설명한다. 중성 삼각형·전하 쌍·앵커 사슬을 손계산하고 연구에서의 영공간 매개화·벌점·투영 차이와 제약 검사를 연결한다.

입력은3–12노드·0–32간선,정확한 분수 위상/전기 변수/양의 전기 계수,비앵커 전하·앵커의null표시와 명시한 퍼텐셜 경로다. 경로는 최대8개·각32단계이며 닫히거나 두 앵커를 연결해야 한다. 기준 변환도 앵커에서는 항등이어야 한다.17개 예제를 준비했다.

계산기는 부분 숲의 전하 수지로 특수해를 구한다. `BI Pᵀ=0`,비숲 열의 단위행렬,정준 괄호와 `E=E⁽⁰⁾+Pᵀπ`를 확인하고 실제 변환·정확 경로 곱·에너지·순간 Hamiltonian벡터장을 계산한다. 전하 조건 자체가 불가능하면 물리 차원은null이다. 제약을 어긴 입력에 같은 비숲 운동량의 올림값을 보여도 동치 상태·최소거리 투영·현재 물리 상태로 부르지 않는다.

이 모형은 고전적인 유한U(1) 연결과 고정 내부 전하를 다룬다. 외부 앵커에 대한 열린 퍼텐셜은 선언한 경계 모형의 선택이다. 물질 동역학·양자 정수 전기 스펙트럼·비가환 군·연속체 Maxwell극한·시간 적분을 구현했다고 주장하지 않는다.

## 독립 확인

- Python Fraction과 SymPy로 **70사례**를 계산했다: 예제17·고정 seed의 그래프48·최대 입력5다.
- 숲은 부분집합 열거,전기 특수해는 일반 유리수 선형계로 구한다. 생산 계산기의 탐욕 숲 선택과 부분 트리 전하 전파를 복제하지 않는다.
- 접속행렬 rank와 확대행렬의 해 가능성,경로/영공간,전체 정준 Poisson행렬의 괄호,전기 재구성,운동 에너지 계량/선형/상수 항을 대조했다. 퍼텐셜의 힘은 경로의 각 인자를 따로 미분하는 곱 미분으로 확인했다.
- 새79검사와 재사용한 궤도 계산 기반85검사를 합친 **164검사** 통과. 서로 다른 전하 호환성·현재 제약 위반·전체 중성만으로 부족한 분리 성분·경계 선속·모든 앵커·고립 노드·평행 간선·자기 루프를 포함한다.
- 12노드32간선·18자리 분수·0/1/3/12앵커와 숲 역순을 검사했다. 마지막 최대 입력은8개 경로 모두32단계다. 다섯 최대 결과를 기존의 제한된 소유권 복사기로 복사했다. 이는 Node기반 준비 검증이며 실제 Worker전송 검증은 아니다.
- 한영 원고의 strict수식 렌더링,타입·대상 lint·기존 콘텐츠1824URL 검사를 통과했다. 입력/예제 번들은 정준·궤도 수치 엔진과BigInt산술을 포함하지 않는다.

명령은 `python3 scripts/learning/graph-gauss-reference.py`와 `npx tsx --test scripts/learning-{graph-gauss,gauge-orbits}-foundation.test.ts`다. 근거는 `.runtime/learning/graph-gauss-foundation/`에 보존한다.
