# 전위·벡터 퍼텐셜의 자료 대조와 독립 준비

2026-11-05 자료 준비 당시의 기록이다. 이후 [순수 계산 모델·상세 한영 원고](potentials-foundation.md)를 작성·검증했다. 이후 [홈페이지 등록·시각화·상호작용 통합 검증](potentials-authoring-status.md)을 마쳤다. 아래 독립 탐색 자체로 주제 완료 수를 늘리지는 않는다.

## 확인한 1차 자료와 단위

[MIT 8.02X FAQ의 전위와 시험 전하 설명](https://web.mit.edu/course/8/8.02x/www/faq.html)은 장의 선적분과 전위차, 전위와 시험 전하의 퍼텐셜 에너지를 구분한다. 다음 원고에서는 외력이 한 일과 장이 한 일의 부호도 각각 정의한다. 정전기 경로 독립성을 일반적인 시간 의존 전기장에 확대하지 않는다.

[MIT 다변수 미적분 §29.5 Potentials](https://www.ocw.mit.edu/ans7870/18/18.013a/textbook/HTML/chapter29/section05.html)은 스칼라·벡터 퍼텐셜과 게이지 표현을 소개한다. 영회전의 국소 결과와 전역 퍼텐셜 존재를 구분하고, 정의역의 구멍·매끄러움·경계 조건을 별도로 적는다. 무한 전류 원통의 로그 퍼텐셜에는 국소화된 원천에서 쓰는 무한대0 경계를 그대로 적용할 수 없다.

[MIT 8.06 L13.4 강의 기록](https://ocw.mit.edu/courses/8-06-quantum-physics-iii-spring-2018/xVZ-lIuIi7A_transcript.pdf)의 p.1–2는 curl A와 grad χ 추가, 전기장을 보존하는 스칼라 퍼텐셜의 동반 변화를 설명한다. 이 강의의 시간 의존 식에는1/c가 등장한다. 교재는 **SI**로 유도하며 그 계수를 옮겨 적지 않는다. 우선 정적이고 매끄러운 단일값 χ를 사용하고, 시간 의존·양자적 위상·전역 게이지 심화는 후속 주제로 남긴다.

## 두 후보의 집필 방향

| 후보 ID | 중심 질문과 예제 |
| --- | --- |
| `electrostatic-potential-reference-path-work` | V·E·시험 전하 에너지가 어떻게 다른가? 유계 영역의 대칭 이차형 전위에서 기준 상수·직선/곡선 경로·부호 있는 일을 비교한다. ΔV와 −∫E·dl의 독립 대조, 기준 상수 변화, Poisson 밀도와 국소 유효 영역을 명시한다. |
| `magnetic-vector-potential-curl-gauge` | 서로 다른 A가 어떻게 같은 B를 나타내는가? 앞 단원의 균일 전류 원통에 연속인 Az를 구성하고 curl·게이지 변환·관측 장을 비교한다. 기준 반지름·로그 외부 해·한쪽 고차 미분과 정의역 조건을 명시한다. |

원통에서는 Az(a)=0으로 잡고 내부 Az=μI(1−r²/a²)/(4π), 외부 Az=−μI log(r/a)/(2π)를 준비한다. curl의 부호를 직접 확인하여 앞 단원의 +z 전류가 +x에서 +y 자기장을 만드는 관례를 유지한다. 무한대0 조건을 주장하지 않는다. χ의 기울기를 더하는 것과 물리적인 균일 배경장을 더하는 것은 다른 실험이다.

## 실제 독립 탐색

`.runtime/learning/prepare-potentials.py`는 제품 코드를 가져오지 않는다. 대칭 행렬 이차형 전위36조건에 대해 SciPy로 직선과 이차 Bezier 경로의 장 선적분을 각각 계산하고 끝점 전위차와 비교했다. 관측 최대 차이는8.88×10⁻¹⁶이다. 유계 국소 전위 준비이며 고립된 유한 원천의 전 공간 경계값 해로 주장하지 않는다.

또한 원통 벡터 퍼텐셜에 매끄러운 χ=α(x²+y²+z²)/2+gxyz의 기울기를 더한36조건을 독립5점 미분했다. 내부·외부와 음·영·양 전류, 삼차원 관측을 포함한다. curl과 앞 단원 Ampere 예측의 최대 차이는1.48×10⁻¹¹이었다. 투자율 계수는 μ=1로 분리한 정규화 계산이다. 경계에서0.1 m 이상 떨어진 표본이며 경계 미분 검증을 대신하지 않는다. 이는 관측 차이이며 엄밀한 오차 상한이 아니다.

결과는 `.runtime/learning/potentials-exploration.json`, 실제 종료는 `potentials-preparation-exit.json`이다. 후속 제품 검증에서는 원점·경계·기준 변경·폐곡선·수치 범위·국소/전역 조건을 추가하고 상세 원고와 화면 검증을 따로 수행한다.
