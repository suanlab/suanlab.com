# 세 앙상블 실험 패널과 대표 그림

2026-11-07. 유한 저장고·정준 에너지 요동·입자 교환의 실제 실험 패널과 대표 SVG를 작성했다. 이 단계는 단원 등록이나 홈페이지 읽기 경로의 완료가 아니다. 세 모델과 한영 원고, worker 검증은 이전 foundation 보고서에 기록되어 있다.

## 구현 범위

- `ensemble-lab.tsx`: 기존 교재의 스타일과 모션 설정을 사용하는 패널. 24개 준비 예제와 9개 한영 안내 실험, 매개변수 입력과 확장 JSON, 저장/초기화/재로드, 계산 중단/재시도, 수동 비교와 예제 순회를 제공한다. 순회는 서로 다른 준비의 비교이며 물리 시간의 진행으로 설명하지 않는다.
- `ensemble-view.tsx`: 분포의 확률 막대, 단위가 붙은 관측값과 로그 상태, 정확한 계수와 페이지 표. 큰 분포는 최대68개 레이블을 선택하며 재정규화하지 않는다. 전체 분포는 보존하고 화면의 32행만 형식화한다.
- 유한 저장고에서는 같은 평균의 P·Q, 분산·TV·방향별 KL을 비교한다. 정준 모형에서는 에너지 요동·열용량·상대 요동을 구분한다. 입자 교환에서는 점유·빈 자리·화학 응답·grand potential과 선택한 입자 수의 조건부 배치를 검사한다. 배치 열거는 여섯 자리까지 제공한다.
- 실제0, 선형 범위 밖의 비영, 미정 조건부/응답, 무한대 KL과 발산하는 log Ξ를 구분한다. T=0의 양의 쪽 접근 방향과 고정 μ 관례를 설명한다.
- `ensemble-cover.tsx`: 기존 색상 변수와 책 표지 스타일의 장식용 대표 그림 세 개. 별도 이미지 생성 서비스나 자산을 사용하지 않는다.

## 검증

검증 결과의 최종 집계는 `.runtime/learning/ensemble-panel-verification.json`에 기록한다. 재현 명령은 다음과 같다.

```bash
npx tsx --test scripts/learning-ensemble-panels.test.ts
node scripts/check-ensemble-panels.mjs
node scripts/check-ensemble-panel-interactions.mjs
npm run typecheck
```

격리 브라우저는 실제 패널·기존 정적 출력의 CSS·별도 webpack worker를 사용한다. 전체 Next 정적 빌드와 실제 읽기 화면 검증은 별도 단계다. 단순히 모델 함수나 테스트용 대체 화면을 렌더링한 결과로 홈페이지 완료를 주장하지 않는다.
