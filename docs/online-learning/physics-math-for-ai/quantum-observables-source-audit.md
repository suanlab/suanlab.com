# 관측·연산자 원문과 독립 검산

2026-11-08. 다음 공식 강의 자료를 열어 유한 차원에서의 정의와 가정을 확인했다. 원문 문장이나 그림은 복제하지 않는다.

- [Preskill §2.1, pp.4–6](https://www.preskill.caltech.edu/ph219/chap2_15.pdf): 서로 다른 고유값의 사영, Born 확률, 조건부 사영, 기대값과 무한 차원의 주의. 이 원고는 유한 차원의 이상적인 Lüders 도구를 명시적으로 선택한다.
- [TU Delft §8.7–8.8](https://interactivetextbooks.tudelft.nl/mqp/hilbert-spaces-and-operators.html): 복소 내적과 켤레 전치, 유한 Hermitian 행렬의 실수 고유값. 일반 비유계 연산자의 정의역까지 같은 설명으로 처리하지 않는다.

## 이번 교재에서 직접 구성한 부분

C²의 유리수 중심·간격과 rank1 방향 가족, 수동 기저 변환, nilpotent 반례를 구성했다. 고유값이 같으면 사영을 합치며 음수 간격에서는 고유값과 사영을 함께 정렬한다. 정규화 진폭만 방향성 제곱근 구간이고 행렬·확률·모멘트는 정확 복소 유리수다.

C³에서 rank1/rank2 스펙트럼 사영과 rank1 세분화 도구를 비교했다. 같은 수치 분포라도 뒤 상태·purity·후속 관측이 다를 수 있는 예제와, 한 준비에서 순서별 법칙이 같아도 commutator는 영이 아닌 반례를 직접 계산했다. 세분화는 별도의 도구다. 일반 측정 장치의 상태 갱신이 관측량 하나로 정해진다고 설명하지 않는다.

## 독립성

생산 코드는 원시 정수·복소 유리수 행렬과 사영 벡터 norm을 사용한다. Python 참조는 생산 모듈을 읽거나 호출하지 않으며 SymPy의 고유벡터·고유공간 직교화로 사영을 다시 얻는다. 순차 결합 법칙은 출력 밀도행렬의 trace로 계산하고, Q의 세분화는 Gram–Schmidt로 구성한다.

24개 C² 준비와26개 C³ 준비에는 복소 위상·배율, 큰 좌표, 작은 비영 확률·간격, 음수·동일 유리수 고유값, 영 확률 분기, 완전 축퇴, 가환·비가환 사례를 포함한다. 별도 경로로 재생성한 참조가 바이트 단위로 일치했다. 독립 참조의 일치는 지정한 유한 실험의 검증이며 일반 스펙트럼 정리나 무한 차원 자기수반성의 증명이 아니다.
