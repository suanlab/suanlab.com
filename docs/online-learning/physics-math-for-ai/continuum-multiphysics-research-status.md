# 복합물리 연구 보강 검증 기록

2026-11-13. [설계](continuum-multiphysics-research-plan.md)에 따라 열탄성 이완과 열전 발전 부하를 기존 두 단원에 추가했다. 한영 원고 4편·그림 4개, 표시 수식 40개·실행 표 4개·연구 해설 12개를 연결했다. 연구 절을 제거하면 기존 본문 4편과 풀이 24개가 원래 해시로 복원된다. 기존 실습 제어와 등록 순서는 유지했다.

## 추가한 설명

- **열탄성:** 특성 삼차식·Hurwitz 조건과 영 손실 집합을 통해 양의 전도·비영 결합이 필요한 이유를 설명한다. 단열 정지 사영과 지속 진동, 작은/큰 전도의 고유근 점근식, 비단조 이완률을 비교한다. 비증가 에너지와 완전 이완, 점근 지표와 유한 시간 좌표를 구분한다.
- **열전:** 원래 포트 부호에서 수동 부하의 전류·전력·고온 열·효율을 유도한다. 최대 출력과 최대 효율의 서로 다른 부하, 저장소 엔트로피·국소 생성 적분, 개방·단락·영 온도차를 비교한다. 상수 물성·고정 저장소·이상적 막대의 결과를 실제 제품으로 확대하지 않는다.
