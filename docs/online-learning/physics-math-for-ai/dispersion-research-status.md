# 분산·군속도 연구 보강 검증

2026-11-12. 기존 두 단원 한영 네 편의 본문·여섯 해설 문제·실습 제어를 보존하고 연구 확장 절을 추가했다. 이번 범위는 파동 영역 **10/18단원**까지의 순차 연구 보강이며 전체 영역 완료가 아니다. 전체 대조 **40영역·396주제**, 후속 **11영역·113주제**를 유지한다.

## 보강 내용

- `dispersive-wave-packets-phase-group-velocity`: 동일 가우스 초기 스펙트럼의 이차·삼차 분산을 비교한다. Plancherel 오차 적분, 육차 모멘트에 따른 L2 상계, 고정 시간과 증가 시간 극한, 강도 중심·분산, 대역 밖 가우스 꼬리와 절대 점별 상계를 유도했다. 삼차 계수는 보충 모델이며 기존 제어를 확장했다고 표현하지 않는다.
- `lattice-wave-packet-transport-dispersion`: 스프링 에너지 배분에 맞는 국소 전류, 순간 전체 플럭스의 보정 및 시간 평균 상계를 유도했다. 기존 양의 진행 모드에서 유지되는 군속도 항등식과 다른 준비 상태인 정지파의 반례를 구분한다. 원형 모멘트 변화·각도 미분과 영 모멘트 근처 조건성을 설명한다. 다른 초기 상태 계열을 시간 궤적으로 해석하지 않는다.

각 원고에 Python 실행 셀·수치 표·연구 질문 세 개를 추가했다. 한영 수식은 단원별 7개·8개, 실행 코드는 언어 간 동일하다. 기존 홈페이지의 파랑·주황·회색으로 제작한 SVG 네 개의 원본 미리보기와 최종 모바일 화면 네 개를 확인했다.

## 검증 결과

선택 4파일 **53검사**, 보강·보존 집중 **12검사**, lint·콘텐츠 검증·빌드·타입·**1,888 HTML** 정적 검증을 통과했다. 전체 등록 **650단원·1,969안내**, URL 1,885개를 유지했다.

독립 표준 라이브러리 계산으로 스펙트럼 오차 8상태·실공간 모멘트 적분 4개·점별 상계 2,564개·대역 꼬리 상계 9개, 에너지 배분 512상태·국소 수지 6,144격자점·원형 모멘트 512상태·진행 수송 128상태·시간 평균 12개·중심 조건성 4개를 확인했다. 표의 네 스펙트럼 적분은 16,000/40,000/80,000 분할로 정련 비교했다. 기존 계산기의 이차 모멘트 27설정·진행 배분 12상태·정지 배분 12상태·원형 중심 7상태도 대조했다. 수치 검사는 해석 증명이나 물질 모델의 유효성 인증을 대신하지 않는다.

최종 빌드에서 변경 두 단원의 한영 **16화면**(밝은 테마 320/768/1440px, 어두운 테마 1440px)을 점검했다. 영어 320px에서 **6안내·4해설 퀴즈·8개념 선택·2저장/완료 그룹**을 조작했다. 페이지 오류와 Axe 위반은 없었다. 이 수를 영역 전체의 최종 화면 검증으로 합산하지 않는다.

## 보존과 다음 순서

새 절을 제거하면 네 편의 이전 본문 바이트가 복원된다. 다른 파동 원고 32편·기존 검토 697항목·이전 네 배치 원고/그림 32해시를 재검증했다. 검토 기록은 701항목이다. 고정한 원고/그림 여덟 입력, 원본·내보내기·서빙 SVG 네 쌍, HTML 두 쌍을 대조했다. 기존 목차 검사는 16절에 새 1절을 더한 17절을 요구하며 새 절을 제거하면 원래 16절이어야 한다.
