## 보완한 설명과 그림

Helmholtz–KL 본문에 실제 그림·입력·등록이 미완료라는 문장이 남아 있어 고쳤다. 두 상태 유도와 실제 실습의 세 미시상태를 구별하고, 두 바닥 상태를 포함한 정준 들뜬 확률과 균등 조건부 비교 분포를 한영 수식으로 추가했다. 가중치 정규화, Δ/kB·C/kB 입력의 K 단위와 관측의 J 단위, 불균등 준비의 표식이 비교 곡선 위에 놓이지 않는 이유를 설명했다. 실제 예제 네 가지를 선택해 비교할 항목도 표로 제시했다.

이상기체 본문에는 n=1, T=256, P=68112.07776791134, Vr=0.03125, Fr=1000과 세 부피 입력으로 기존 수치 표를 재현하는 절차를 추가했다. 기본 예제와 다른 등온선임을 밝히고, 로그 부피 축·에너지 배율·수동 비교와 33상태 순회를 설명했다. 실제 압력 평형은 반올림 좌표와 구별한다.

그림의 일부 눈금은 기존 최소 폭에서 약 9px로 표시됐다. 두 자유에너지 읽기 화면에 한해 내부 SVG 폭을 최소 560px로 유지하고 SVG 내부 글씨를 최소 16px로 보완했다. 좁은 그림은 가로로 이동하며 캡션은 밖에 남는다. 스크롤·방향키 안내를 개념과 실습에 추가했다. 기존 색상·테마·메뉴·단원 URL은 유지했다.

## 독립 계산과 교수 내용 검토

800자리 계산으로 스펙트럼 13준비·기체 11준비의 **396비교**를 통과했다. 직접 정규화한 상태 합과 상대 엔트로피, 기체의 압력·힘 적분을 사용했다. 거의 정준인 이진 입력의 양의 차이, 에너지 기준 이동, 경계 분포·축퇴·복제 수 0, 복제당 표시 범위 밖이지만 총량으로 복원되는 차이, 정확한 압력 평형과 인접 부동소수점 부피를 포함한다. 극저온의 엄청나게 작은 지수는 직접 계산한 척하지 않고, log1p 꼬리의 명시적 부등식으로 로그 구간을 대조했다.

고정 Hamiltonian·양의 T·KL 방향·지지집합·축퇴도의 단일 계수, 독립 복제의 조건을 검토했다. 기체에서는 고정 n,T,P와 Fr의 한 등온선 기준, Ggas와 Φ의 구별, 조건부 열·일·엔트로피 수지, 부피 안정성과 압력 곡률의 다른 변수를 확인했다. 선수 단원 네 링크가 등록 순서상 먼저 오는 것도 대조했다. 이 검토는 선택한 입문 사례의 근거이며 모든 입력과 연구 깊이에 대한 증명이 아니다.
