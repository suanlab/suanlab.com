# 중첩·간섭·회절: 다음 집필의 자료와 계산 기준

2026-11-05. 아래 자료 대조·독립 탐색 이후 계산 모델 두 개와 상세 한영 원고 네 개를 작성하고 홈페이지 검증까지 마쳤다. [기반 집필 기록](interference-diffraction-foundation.md)은 당시 모델·기준값·27개 전용 검사와 가정을, [최신 홈페이지 연결 기록](interference-diffraction-authoring-status.md)은450개 단원·253개 입문 검증의 실제 근거를 담는다. 아래 후보·다음 실행 순서는 자료 준비 당시 이력이다.

## 실제 읽은 일차 자료와 한계

- [TU Delft Interactive Optics의 간섭·결맞음](https://interactivetextbooks.tudelft.nl/tn2421/content/Chap5_Interference/InterferenceCoherence_2022_01Clean.html): 같은 진동수의 복소장 중첩·검출 강도·가시도 부분을 읽고, 시간·공간 결맞음의 정의와 서로 다른 위치의 상관 정의를 대조했다. 학습 목표·검색 결과만으로 장 전체를 읽었다고 기록하지 않는다. 정규화에서 생략한1/2와 매질 계수를 실제 SI 강도와 구분해야 한다.
- [TU Delft의 스칼라 회절](https://interactivetextbooks.tudelft.nl/tn2421/content/Chap6_Diffraction/DiffractiveOptics_2022_01Clean.html): Fresnel/Fraunhofer 근사 부분의 거리·개구 크기·파장 조건, 관측면 위상과 두 점광원 예제를 대조했다. 작은 Fresnel 수 하나가 모든 관측 각도·벡터장 경계의 정확성을 보장하는 것으로 확대하지 않는다.
- [MIT2.71 강의14 노트,1–2쪽](https://ocw.mit.edu/courses/2-71-optics-spring-2014/da64653098bef719b4537bb2d149c95d_MIT2_71S14_lec14_notes.pdf): 조명·개구·전파 커널의 분리와 거리 전개의 위상 항을 읽었다. 뒤의 렌즈·격자 전체를 이번 단계의 읽은 범위로 세지 않는다. 스칼라 구면파 커널을 모든 Maxwell 경계의 정확한 해로 부르지 않는다.

## 기존 내용과 새 질문

앞의 결합 맥놀이는 용수철로 연결된 실제 물체의 에너지 교환이다. 앞의 파동 방정식은 정해진 초기 장의 전파·반사·국소 수지다. 새 내용에서는 서로 독립적으로 준비한 장의 합과 검출기의 이차 관측량, 개구 여러 위치의 위상 합으로 생기는 공간 분포를 설명한다. 기존 단원의 곡선을 다시 이름 붙여 완료로 세지 않는다.

당시 후보였던 `coherent-superposition-detector-averages`와 `finite-aperture-fresnel-fraunhofer`는 이후 실제 등록·화면 검증을 마쳤다. 편광, 분산·군속도, Fourier optics 전체는 뒤의 원래 주제로 남긴다.

## 직접 유도할 관측량

같은 편광의 스칼라 복소장을 가정한다. 정규화 강도에서 I=|U1+U2|², Ij=|Uj|²라 두고 교차항을 실제 복소 합과 별도로 대조한다. 물리적 실수장의 제곱 시간 평균에는1/2가 있고, 실제 전자기 SI 강도에는 고정한 매질 임피던스 계수도 필요하다. 파동 변위를 제곱하는 것만으로 앞 단원의 실제 에너지 흐름을 대신하지 않는다.

여러 유한 위상 표본과 비음수 합1 가중치에서 상호 결맞음을 직접 계산하고 Cauchy–Schwarz 경계를 확인한다. 두 강도가 모두0일 때 가시도는 미정이다. 진폭 불균형과 결맞음 저하가 모두 가시도를 낮출 수 있으므로 가시도만으로 원인을 유일하게 추론하지 않는다.

유한 검출 창의 두 진동수 간섭은 별도 계산한다. 준단색 해석 신호를 평균하는지, 빠른 실제 반송파까지 제곱해 적분하는지 명시한다. 해석 신호의 중심시간 t0·폭T 평균 교차항에는 sinc(ΔωT/2)와 위상이 생기지만, 이것을 무작위 위상 앙상블의 결맞음과 같은 가정으로 섞지 않는다. T=0 극한과 Δω=0을 분모 특이점 없이 계산한다.

## 개구와 전파의 검증 기준

1차원 선형 개구의 전체 폭w와 반폭a=w/2를 명확히 구분한다. Fraunhofer 진폭은 개구의 복소 Fourier 적분이며, 균일 단일 슬릿에서는 정현비의 제곱 강도가 나온다. 두 슬릿은 각 슬릿의 폭과 중심 간격을 분리하고, 위상차·비대칭 조명·차단된 슬릿의 극한을 검사한다. 슬릿 간격만 바꿨는데 전체 개구 투과량까지 임의로 바꾸지 않는다.

Fresnel 적분은 개구 내부의 이차 위상을 유지한다. 먼거리 근사와 비교할 때 상수 위상·관측면 위상을 생략한 이유를 표시한다. 위상을 포함한 장 오차와 강도 오차를 구분한다. 개구를 바꿀 때마다 최대값을1로 맞추면 총 투과량과 실제 중심 강도 변화가 숨겨지므로 원래 정규화와 상대 분포를 따로 제공한다.

독립 검증은 실제 복소 사분 적분, 단일/이중 직사각 개구의 해석적 먼거리 식, Fresnel 적분의 별도 특수함수 계산, 직접 이중 합으로 확인하는 교차항과 가시도를 사용할 수 있다. Fourier 부호·2π·단위와 Parseval 정규화를 명시한다. 격자 크기를 늘린 결과만으로 독립 검증이라고 부르지 않는다.

## 다음 실행 순서

명시한 가정의 순수 계산 모델과 독립 기준값·유의미한 경계 검사를 먼저 만든다. 한영 상세 원고에 유도·직관·계산 예제·해설 문제를 작성한 뒤 기존 테마의 장·위상·검출 평균·개구·관측 분포 시각화와 실험·퀴즈를 연결한다. 이 순서에 따라 모델·원고·독립 기준값과 수학 검증, 홈페이지 연결과 화면 검증까지 마쳤다.

## 실행한 독립 탐색

`.runtime/learning/explore-interference-diffraction.py`를 실행했고 결과는 `interference-diffraction-exploration.json`에 있다. 제품 코드는 불러오지 않았다. 유한 시간 창48개 사례에서 해석 신호 강도의 sinc 교차항과 실제 실수장 제곱의 합·차 진동수 항을 각각 직접 적분으로 대조했다. 최대 차이는 각각 약3.11×10⁻¹⁵와1.33×10⁻¹⁵였다. 빠른 반송파 항을 생략한 모델과 정확한 실수장 평균은 다른 관측 모델임을 유지한다.

1차원 단위 폭 개구의 Fresnel 커널을68개 관측점에서 실제 복소 사분 적분과 별도 Fresnel 특수함수로 대조했다. 최대 차이는 약4.21×10⁻¹⁵였다. 같은 무차원 관측 좌표에서 λz/w²를10에서100으로 늘렸을 때 정규화한 복소장 먼거리 근사 오차는 약0.02618에서0.002618로 줄었다. 이것은 선택한 사각 개구와 표본의 탐색이며 모든 개구·각도에 대한 오차 상한이 아니다. 복소장 위상과 강도의 차이를 따로 계산했으며 각 곡선의 최댓값을 별도로1로 맞추지 않았다.

비식별 예제도 직접 확인했다. 균형 강도 I1=I2=1와 결맞음 크기1/2는 I(φ)=2+cosφ를 준다. 완전 결맞음이어도 I1=(2+√3)/2, I2=(2−√3)/2이면 같은 곡선이다. 가시도뿐 아니라 이 강도 곡선만으로도 원인을 유일하게 결정할 수 없다. 새 교재의 추론 한계 예제로 발전시킨다.

이 탐색은 제품 계산 모델·이식 가능한 기준값 생성기·한영 원고·홈페이지 검증을 대신하지 않는다. 탐색만으로 당시 등록·입문 검증 수에는 반영하지 않았으며 이후 별도의 통합 검증을 마쳤다.
