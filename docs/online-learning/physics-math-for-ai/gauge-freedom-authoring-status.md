# Gauge freedom 두 단원의 홈페이지 통합 검증

2026-11-05. 시간 의존 게이지 변환과 Lorenz·원천·초기 제약 두 단원을 홈페이지 교재에 연결했다. 로컬476개 한영 단원·안내1,428개, 원래36영역362주제 중266개 입문 검증·96개 미완료다. 전자기학은8/10개 입문 주제 검증이며 전체 영역 점검·전체51영역509주제·연구 심화는 미완료다. 공개 배포는 하지 않았다.

총 그림28개·표8개·입력25개(연속23개·선택2개)·예제32개다. 개념8단계·안내6개·풀이 퀴즈4개와 고유 표지를 연결했다. 한영 상세 원고4개에는 언어별 표시 수식25개·풀이12문제가 있다. 기존 HSL 색상과 명암·공통 스크롤·범례를 유지한다. 개념 단계의 그림·수치는 설명에 맞는 같은 고정 예제를 사용한다.

## 물리와 수치의 구분

좌표와 시간은 ξ=x/L,τ=ct/L로 정규화하며 실제 전위·장·원천·잔차는 각각의 SI 척도로 변환한다. τ를 초·ns와 같은 숫자로 취급하지 않는다. 동시 A/V 변경은 실제 장을 유지하지만 Lorenz 조건은 바뀔 수 있다. 부분 변경은 B가 같아도 E를 바꿀 수 있고, 시간에 일차인 대조는 원천도 같을 수 있어 초기·경계 조건을 함께 확인한다. 점별 대칭0은 가족 전체 판정이 아니다.

전위 파동식이 지정한 원천과 실제 E/B가 요구하는 원천을 분리한다. 전위 파동식·원천 보존·초기 G만으로 Maxwell 전체를 인증하지 않는다. 초기 시간 미분과 호환되는 경계 조건도 필요하다. 일정 비영 G의 유효한 진공 표현은 비Lorenz와 물리 실패를 혼동하지 않게 한다. 모드별 비활성 계수도 표에 명시한다.

고정 xy 루프의 법선은+z이며 순회는 아래+x,오른쪽+y,위−x,왼쪽−y다. 같은 축척의 기하와 실제 모서리 적분을 보여준다. 정확한 영면적·작은 반폭의 표현 손실·SI 변환 손실을 구분한다. 작은 비영 계수·산술 판정 미정·U=0의 물리적0을 분리한다. 높은 파수·주파수에서는16표본/주기 이상의 공간·시간 분해능을 유지한다. 해석 가족의 잔차는 독립 인증이나 엄밀한 전역 오차 상한이 아니다.

## 실제 검증

전자기학 관련322개·전체4,149개 테스트와 타입·lint·콘텐츠1,710 URL·빌드1,718페이지·출력1,713 HTML 검사가 실제 종료 코드0으로 통과했다. 기존474개 단원·안내,42개 실험 그룹465항목 및 상대 순서를 등록 전 canonical 기준으로 보존했다. 독립 차분·구적·180자리 기준과 원고 검사는 [기초 집필 기록](gauge-freedom-foundation.md)에 있다.

2단원×2언어×2폭(320/1440)×2명암의16기본 상태와24특수 입력, 안내 펼침48개·예제64개·전체 조작4그룹을 확인했다. 정밀 입력·저장·퀴즈 오답/정답·완료 저장·초기화·선수 링크·이전/다음 이동·목차·개념 단계·접근성·키보드·넘침·라벨 잘림·영어 한글 잔존·페이지 오류를 검사했다.

모바일 원본 SVG112개의 키보드 스크롤과8개 갤러리, 펼친 안내4개·영어 개념8단계의 캡처를 직접 검토했다. 영어 UI560경로618상태에서 표시 한글 잔존·페이지 오류가 없었다. 소스·설정2,997개와 출력4,167개를 동결하고 검사 전후 해시를 비교했다. 커리큘럼 재생성 후에도 동일했다. 실행·화면·해시 증거는 `.runtime/learning/gauge-freedom-homepage/`와 `gauge-freedom-integrated-verification.json`에 있다.
