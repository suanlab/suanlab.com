# 결합 진동 연구 보강: 모드 간격·이웃 모델

2026-11-12. 두 단원의 한영 원고 네 편에 고유값 간격과 모드 사영자의 민감성, 약결합 근사의 이웃 스프링 모델과 장시간 상태 오차를 보강·검증했다. 기존 본문·각 여섯 해설 문제·실습 입력을 보존한다. [파동 9주제의 순차 연구 검토](waves-optics-topic-review.md)는 **4/18단원**이며 영역 전체 완료로 집계하지 않는다.

## 보강한 이론과 직관

- 정상모드 단원은 같은 질량·같은 두 고유값을 갖는 양의 스프링 계열을 구성한다. 비음 결합과 양의 고정 강성을 실제 식으로 확인한다. 부호 불변 사영자의 차와 스프링 행렬 차의 비율이 고유값 간격의 역수임을 직접 증명한다. 작은 간격의 서로 다른 계와 정확히 중복된 한 계의 기저 자유도를 구분한다.
- 같은 초기값에서 고정 시간의 물리 궤적은 수렴하면서 개별 모드 사영자와 에너지 이름표는 다를 수 있음을 계산한다. 질량 기하·단위·관측 기간을 고정하고, 작은 비축퇴 간격에서 임의로 기저를 회전해도 된다고 설명하지 않는다.
- 맥놀이 단원은 일차 근사 진동수가 정확히 대응하는 이웃 결합 강성을 찾는다. 원래 방정식 잔차, 이웃 모델의 정확 에너지, 원래 물리 에너지의 작은 결함을 각각 유도한다. 첫 맥놀이 척도와 결합 비율 제곱의 역수인 장기 척도에서 위치·속도 결합 오차를 상계한다. 임의 반송 위상의 수렴을 가정하지 않는다.
- 한영 SVG 네 개·비교표·실행 Python·각 세 해설 연구 질문을 추가했다. 표의 2,048초는 보충 닫힌 해 계산이다. 기존 reader의 관측창은 128초이며, 별도 순수 함수 `coupledBeatingState`의 점 조회는 512초까지다. 연속 섭동 매개변수나 이웃 강성을 기존 제어 격자의 새 기능으로 표시하지 않는다.

## 독립 계산·원고 보존

`python3 scripts/learning/verify-coupled-research.py --json`은 표준 라이브러리만 사용하며 제품 코드·등록 데이터를 가져오지 않는다. 양의 스프링 계열 135개·사영자/간격 135쌍, 운동방정식과 고정 시간 상계 540상태, RK4 600/1,200보 정련 15사례와 축퇴 기저 81상태를 확인했다. 이웃 모델 잔차·에너지·상태 상계 360상태와 장기 척도 54상태도 대조했다. 같은 상태의 서로 다른 검사를 더해 새로운 궤적 수로 집계하지 않는다. 유한 수치 검산과 본문의 노름·에너지·극한 증명은 구분한다.

한영 표시 수식은 단원별 7개·8개로 같고 Python 네 셀의 출력이 본문 표와 일치했다. 기존 계산 함수의 격자에 맞는 두 계의 스펙트럼·사영자와 8개 상태, 실제 약결합 근사의 6개 점 조회도 대조했다. 선택 **4파일·51테스트**, 원고/보존 집중 **12테스트**가 통과했다. 전체 저장소 CI 성공을 뜻하지 않는다.

연구 절만 제거하면 기존 본문 네 편은 기준 `c1e70d5`와 바이트가 같다. 원래 해설 24개·다른 파동 원고 32편·이전 검토 항목 685개를 보존했다. 새 검토 해시 네 개를 더해 689개다. 앞선 공진 보강의 네 원고·네 그림도 기존 증거 해시와 일치한다. 등록은 650단원·1,969안내 그대로다.
