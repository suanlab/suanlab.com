# Gauge freedom의 계산 모델과 상세 한영 원고

2026-11-05 기초 집필 단계의 기록이다. 이후 [홈페이지 통합 검증](gauge-freedom-authoring-status.md)을 마쳤으며 아래 미등록 수치는 당시 기준이다.

시간 의존 게이지 변환과 Lorenz 조건·원천·초기 제약을 다루는 두 단원의 계산 모델과 원고를 작성했다. 이 문서는 기초 집필 기록이며 홈페이지 등록·조작·안내·퀴즈·화면 통합은 다음 순서다. 등록474개 한영 단원·안내1,422개, 원래265개 입문 검증·97개 미완료를 유지한다. 전자기학은7/10개 입문 주제 검증, 전체51영역509주제·연구 심화는 미완료다.

## 작성한 두 단원

| ID | 내용 |

| `time-dependent-gauge-field-invariance` | 시간 의존 A/V 동시 변환, E의 두 항 상쇄, 실제 E/B와 원천, Lorenz 표현의 변화, 부분 변경과 초기·경계 조건, 고정 폐경로 |
| `lorenz-gauge-source-initial-compatibility` | 전위 파동식과 Maxwell 잔차, 원천 연속성·초기 G와 시간 미분, 조화 전위의 두 원천 집합, 공명·정상파·일정 비영 G 대조 |

원고4개는 각각17개 절이며, 언어별 표시 수식25개·풀이12문제다. 영어 원문은 약1,865/1,902단어다. 일반 대학원생이 식을 따라갈 수 있도록 선수 개념·국소 가정·단위·직관·유도·손계산·실패 예제·AI/PINN 검증 질문을 포함한다. 전역 위상·양자 게이지 이론·일반 초기 경계 문제의 존재와 유일성 전체는 이 두 입문 예제와 구분한다.

## 계산 모델과 SI 정규화

`src/lib/learning-gauge-freedom.ts`는 파일·데이터·AI 의존성이 없는 계산 모델이다. `gaugeScales`, `timeGaugeState`, `timeGaugeLoop`, `lorenzHarmonicState`, `lorenzInitialConstraintState`, `constantLorenzOffsetState`가 중심 API다. 입력은 유한 범위를 검사하고 알 수 없는 모드·희소 좌표를 거부한다.

길이 L·전위 U와 기존 Maxwell 매질의 c를 사용한다. ξ=x/L,τ=ct/L이며 실제 A=(U/c)a,V=Uv,χ=(UL/c)χ̃다. E·B·G·ρ·J와 Gauss/Ampere 잔차에 각각의 SI 척도를 적용한다. 정규화 τ와 초·ns를 같은 숫자로 취급하지 않는다. U=0에서는 정규화 진단이 남더라도 실제 장과 원천은0이며 물리 판정도 이에 맞춘다.

## 시간 의존 변환의 구분

기준 a=(−bη/2,bξ/2,0),v=0에 χ̃=αξηζg(τ)를 적용한다. A와 V를 함께 바꾸면 실제 E/B·원천은 유지되지만 g″가 비영일 때 Lorenz 조건은 달라질 수 있다. Lorenz 조건 실패를 물리적 Maxwell 실패로 잘못 분류하지 않는다.

A만·V만 바꾸는 대조는 E를 바꿀 수 있다. g가 시간에 일차인 경우에는 추가 장이 시간에 일정하고 발산도0이어서 **같은 ρ/J라도 다른 E**가 가능하다. 초기·경계 조건을 포함해야 장을 비교할 수 있다. g가 이차면 부분 변경에 필요한 전류도 달라진다. 한 점의 대칭 영점과 가족 전체의 장·원천·Lorenz 판정을 구분한다.

고정 xy 직사각형의 법선은+z이고 순회는 위에서 본 반시계다. 각 A 선적분·전체 순환·자기 선속·E 순환을 분리한다. 폭·높이0의 정확한 영면적과 양의 반폭이 사라지는 기하 표현 손실을 구분한다. 해석적 보존값과 반올림한 모서리 합은 독립 인증이 아니다.

## Lorenz·원천·초기 조건

전위 파동식이 지정한 ρ/J와 실제 E/B가 요구하는 ρ/J를 별도로 제공한다. 분리된 파동식이 맞아도 Gauss 잔차 −∂tG와 Ampere 잔차 ∇G가 남을 수 있다. 원천 보존이면 G의 파동식은 동차지만 초기 G·∂tG와 적절한 경계 조건이 있어야 Lorenz의0을 유지한다.

종방향 조화 모형에는 비공명 호환 강제 모드, 공명 순수 게이지, 영원천 파동식은 맞지만 Maxwell이 틀리는 공명 대조가 있다. 정상파 벡터 전위는 초기 G가 모든 위치에서0이어도 초기 시간 미분이 비영인 대조다. v=γτ,a=0의 일정 비영 G는 E=B=0인 유효한 진공 표현이다. G≠0을 무조건 물리 불가능으로 판정하지 않는다.

## 작은 값과 수치 근거

k²−ω²는 (k−ω)(k+ω)로 계산한다. 전기장·Lorenz 계수의 두 곱 차이는 보상 곱을 사용하고 반올림한 직접 차감과 별도로 반환한다. 곱의 저차 오차항까지 지탱하지 못하는 작은 범위는 보수적으로 미정 처리한다. 동일 곱의 구조적 상쇄와 단순 표현 손실을 구분한다. 작은 비영 계수를 허용 오차로0이라고 선언하지 않는다.

독립 생성기 `scripts/learning/generate-gauge-freedom-references.py`는 제품 코드를 가져오지 않는다. 다항식576조건에서 실제 전위의5점 공간·시간 차분과 혼합·이차 미분으로 E/B/G/J를 구하고, SciPy로 방향 있는 네 모서리 선적분을 구했다. 조화36조건의 전위 파동식 원천과 장 원천·잔차, 초기 제약36조건도 대조한다.180자리 정확 입력 기준은 곱 차이5조건·근접 공명3조건이다. 생성 기준 파일은 재생성 후 바이트 단위 일치를 확인했다. 선택한 수치 관측이며 엄밀한 전역 오차 상한은 아니다.

## 검증 상태

전용26개·전체4,133개 테스트와 타입·lint·콘텐츠1,708 URL 검사가 실제 종료 코드0으로 통과했다. 기초 검증 증거는 `.runtime/learning/gauge-freedom-foundation-verification.json`이다. 네 원고를 실제 콘텐츠 로더로 렌더링하여 strict KaTeX·한영 수식 일치·고유 목차·스크롤 접근성·영어 한글 잔존 없음·풀이를 확인했다. 기초 집필 자체로 홈페이지 완료 수를 올리지는 않는다. 기존474개 단원·안내와42개 실험 그룹465항목은 등록 전 canonical 기준으로 보존한다. 기존 홈페이지 소스·설정2,984개와 정적 출력4,163개를 유지하며, 새 파일 포함 기초 소스·설정2,994개를 동결한다. 미등록 원고 단계라 새 빌드·화면 점검·공개 배포는 아직 하지 않았다.
