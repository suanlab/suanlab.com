# 다체계 첫 가족: 국소 spin Hamiltonian 수치 기반

2026-11-09. 다음 원주제 `many-body·tensor network`의 다섯 예정 단원 중 **첫 수치 가족**을 구현·검산했다. 아직 새 단원을 등록하지 않았으며 **566개 한영 단원·1,698개 안내, 원래 입문 308/362개 검증·54개 미완료**를 유지한다. 전체 51영역·509주제와 연구 깊이도 미완료다.

## 구현한 모형

`src/lib/learning-spin-chain.ts`는 1…4개 spin-1/2, 차원 2…16의 일반 복소 원시 상태를 받는다. 국소 XYZ와 모든 아홉 두-site Pauli 축 조합을 지원한다. 열린 사슬·중복 없는 고리·사용자 지정 쌍으로 정확 복소 유리수 Hamiltonian을 만든다. 기저 순서와 Pauli/ℏ-spin 계수 convention을 명시한다.

- H·Hz·평균 에너지·이차 모멘트·분산·잔차와 항별 에너지 계정.
- 각 site의 실제 reduced density·Bloch 성분·purity, 변이 없는 쌍까지 포함하는 모든 쌍의 연결 상관.
- 전체 Z·Z parity의 행렬 교환자와 현재 상태의 기대·분산을 구별.
- 대각 H에서 모든 기저 에너지·축퇴 공간·바닥 확률·gap·누출 경계. 비대각 H에는 계산하지 않은 스펙트럼·바닥 판정을 반환하지 않는다.
- 정확 유리수 관측과 √N으로 나눈 좌표의 바깥 512비트 구간. 작은 양의 분산을 0으로 바꾸거나 입력 상태를 다른 상태로 보정하지 않는다.

`learning-spin-chain-input.ts`는 수치 엔진을 가져오지 않는 별도 입력 모듈이다. 소유 정수 102개, 크기 10⁶ 이하, 양의 공통 분모, 비영 상태와 비활성 항 0을 검사한다. 검증한 descriptor로 한 번의 canonical snapshot을 만들고 caller 프로퍼티를 다시 읽지 않는다. 자세한 가정·식·nullable 상태는 [수학·입출력 계약](quantum-spin-chain-contract.md)에 있다.

## 독립 기준과 검증

`scripts/learning/generate-spin-chain-references.py`는 제품 코드를 가져오지 않는다. SymPy의 Kronecker 행렬·H² 모멘트·바깥 밀도 행렬의 직접 partial trace·실제 행렬 교환자와, mpmath 250자리 정규화 성분을 사용했다.

**42개 독립 준비 / 61개 검사**를 통과했다. 검사 전체에서 정확 유리수 관측 16,381개와 방향성 정규화 좌표 775개를 대조했다. 정확 관측 수에는 항등식 인증의 영 잔차 검사도 포함한다. 기준값 x에 대한 구간 대조 여유는 10⁻²⁰⁵·max(1,|x|), 폭 관문은 10⁻¹²⁵·max(1,|x|)다. 기준 JSON을 다시 생성해 SHA-256 바이트 일치를 확인했다. 타입 검사와 lint도 통과했다.

대표 검사는 다음과 같다.

1. 일반 복소 상태와 모든 축을 1…4 site·세 graph에서 비교한다. 복소 Y 방향은 실제 partial trace의 부호까지 대조한다.
2. GHZ₄와 횡장에서 E=−3·Var=1, 대각 강자성 바닥 공간과 영분산 들뜬 상태를 구별한다.
3. 반강자성 삼각형의 여섯 바닥 기저 상태, 2-site 고리의 중복 없는 결합, 상수 H의 전체 바닥 공간과 없는 gap을 검사한다.
4. XX+YY의 합에서 Z 보존이 회복되는 경우와, 현재 상태가 sharp여도 H가 보존하지 않는 경우를 구별한다.
5. 상태의 복소 배율, 에너지 원점, Hamiltonian 부호·배율, site 재배열과 홀수-Y 항의 복소 켤레 변환을 대조한다.
6. 작은 양의 분산, 최대 크기 정수, 확률 범위를 넘는 energy/gap 비율과 인증 경계의 차이를 확인한다.
7. 상호작용이 있어도 주어진 곱 상태의 연결 상관은 0일 수 있음을 확인한다. 수치 상태를 자동 진화시키지 않는다.

근거는 `.runtime/learning/spin-chain-foundation/verification.json`, 검사 로그, 독립 JSON·재생성 SHA, 소스/근거 hash manifest에 있다. 이전 소스/근거와 정적 출력은 별도 비교하여 보존한다. 이번 단계는 Node 수치 기반 검증이며 브라우저·Worker·실제 교재 검증으로 세지 않는다.
