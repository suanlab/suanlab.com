# 상세평형 연구 보강 검증 기록

2026-11-13. 기존 정상 3상태 순환, Metropolis–Hastings 제안 균형, 가역 2상태 주기성·혼합의 **3단원·한영 6원고·그림 6개**를 보강했다. 기존 본문과 풀이 36개를 정확히 보존하고 표시 수식 46개·실행 Python과 표 각 6개·연구 풀이 18개를 추가했다. 기존 분포 reader와 경로 법칙·수락 규칙 비교·확률적 시간 평균을 구분한다.

## 새로운 연구 설명

- **경로 비가역성:** 균일 정상 초기화와 양의 양방향 전이를 명시하고 경로와 역순 수열의 로그 확률 비를 유도한다. 방향 증가량의 독립성에서 유한 누적량·요동 관계·지수 항등식·전류와 순환 친화도의 곱을 얻는다. 단방향 지지 경계에서는 항등식의 가정이 깨짐을 보이며 통계적 KL과 물리적 엔트로피를 동일시하지 않는다.
- **수락과 분산 순서:** 같은 목표·제안에서 Barker와 Metropolis의 올바른 수락을 비교한다. Dirichlet 형식·평균 0 부분공간의 역연산자 순서·Poisson 방정식으로 점근 분산 순서를 증명한다. 비보정 목표 비 전용 규칙과 구별하고 같은 시도 수 비교를 모든 혼합 시간·유한 MSE·실행 시간의 순위로 확대하지 않는다. 없는 제안의 흐름은 0으로 처리하며 분모가 양수인 쌍 흐름 공식을 명시한다.
- **초기화와 머무름:** 두 시각 공분산에서 초기화별 정확한 표본 평균 분산·편향·MSE를 계산한다. 정상 이진 관측량의 AR(1) 공분산 연결과 비정규 주변 법칙을 구분한다. 추가 머무름이 분포 수축을 개선해도 음의 상관 상쇄를 없애 점근 분산을 키울 수 있는 정확한 재설정 반례를 제시한다.

원문·출처 경계는 [출처 기록](thermo-statmech-source-audit.md), 해시·재현·화면 범위는 [JSON 근거](detailed-balance-research-evidence.json)에 연결한다.

## 독립 계산과 보존

상태 경로를 직접 열거한 25준비에서 정·역 경로 비, 계수 법칙, 모멘트와 생성함수를 확인했다. 단방향 지지 경계 15준비에서 지수 기댓값을 별도로 계산했다. 유리수 Poisson 관측량 비교 96개는 상세평형·역문제 잔차·분산 순서와 독립 공분산 행렬 거듭제곱 급수로 대조했다. 이진 경로의 점유율을 직접 열거한 144준비에서 초기화별 편향·분산·MSE를 비교했다. 머무름 커널 12준비의 고윳값·분산 단조성과 정확한 재설정 2개도 확인했다. 유한 계산은 일반 비정상 체인·모수 추정·물리적 엔트로피의 인증이 아니다.

관련 **14파일·222검사**, 마지막 쌍 흐름의 양의 분모 조건 보완 후 연구 원고·Hastings 본문·보존 재검사 **21개**가 통과했다. 원문 복원·기존 여섯 풀이·한영 수식/예제/표/그림 경로를 별도로 확인했다. 다른 29단원·58원고, 앞선 연구 자산 166개와 보존 장부 853항목을 유지했다. 새 검토 6개를 더해 장부는 859항목이다. 등록은 650단원·1,969안내, 원래 범위는 51영역·509주제다.
