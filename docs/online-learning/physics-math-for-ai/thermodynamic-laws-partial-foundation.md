# 열역학 법칙: 첫 두 가족 기반 구현

최신: [저온 가족을 포함한 세 가족 기반 검증을 마쳤다](thermodynamic-laws-foundation.md). 아래는 먼저 마친 두 가족의 단계 기록이며 홈페이지 통합은 여전히 남아 있다.

2026-11-06. 계획한 세 가족 중 카르노 순환과 두 저장고 포트의 계산·한영 본문 기반 검증을 마쳤다. 저온 유한 스펙트럼은 아직 초안이다. 새 가족의 그림·실습·교재 등록·홈페이지 통합 검증은 하지 않았으며,504단원·1512안내·원래280입문 검증·82미완료를 유지한다. 전체 법칙 주제·열역학 영역·연구 심화는 미완료다.

## 가역 카르노 순환

`src/lib/learning-carnot-cycle.ts`는 두 일정 온도 저장고와 단원자 이상기체의 네 가역 구간을 구성한다. 물질량0.25–2 mol, 두 온도250–800 K(Th≥Tc), 초기 부피0.005–0.04 m³, 등온 팽창비1–4, 진행률0–1을 지원한다. 각 단열 구간은 온도, 등온 구간은 log(V)를 진행률에 선형으로 매개변수화한다. 진행률은 시간이 아니며 열·일은J/순환이다.

현재 온도·부피·압력, 두 열 포트·순열·일·내부 에너지, 계와 두 저장고의 엔트로피를 계산한다. 전체 순환·네 꼭짓점·구간별 수지·효율·역방향 냉동/난방COP와 퇴화 조건도 제공한다. 역순환 초기에는 기체가 양의 일을 할 수 있지만 전체 순환은 일을 받는다는 차이를 본문에 추가했다. 온도가 같아 Qh≠0·W=0인 경우 수학적 W/Qh=0을 따로 제공하며, 실제 기관 운전 분류 및 영 분모의 미정 비율과 구별한다.

작은 진행률을1에서 빼서 지우지 않도록 역방향 경로를 직접 구성한다. 온도 차이는 공급된 이진 입력의 정확한 차로 유지해, 한 바퀴 뒤 가짜 에너지 잔차가 남지 않게 했다. 공통 log(r) 앞의 온도 괄호도 투영 전에 구성하여 작은 순일과 역방향의 정확한 영 교차를 보존한다. 지수·로그는 부동소수점 근사이며 전체 계산이 임의 정밀도라는 주장은 하지 않는다.

독립 생성기 `scripts/learning/generate-carnot-cycle-references.py`는 물리 부피의 p(V)를 적분한다.30일반 사례는160자리의 직접 적분,16극한 사례는1000자리의 물리 좌표 원시함수를 사용한다. 구조적으로 입증되는0만 따로 인식하고 수치 잔차의 임의 문턱값으로0을 만들지 않는다. 네 구간·양 방향·작은 간격/팽창/진행률·퇴화·영 일 교차·비대칭 이진 온도 복귀가 포함된다.

## 두 저장고의 에너지·엔트로피 포트

`src/lib/learning-reservoir-cycle.ts`는 내부 궤적을 만들지 않고 닫힌 순환의 경계 수지만 계산한다. 두 온도250–800 K(Th≥Tc), 고온 입력0–4000 J, 상대 엔트로피 생성 계수σ∈[−1,4]를 지원한다. 음의 생성은 명시적인 반사실적 대조이며 실제 가능한 기관으로 분류하지 않는다.

고온 열·저온 열·일·저장고 엔트로피·생성량·가역 한계와의 일 차이를 계산한다. 양의 일·양의 생성 조건을 만족하는 기관, 일 입력 소산, 일 없는 열전달, 전달0, 반사실적 포트를 구별한다. 일 입력이라는 이유만으로 냉동기라고 부르지 않는다. 에너지·엔트로피 조건의 일치는 이 예산의 필요 조건이며 내부 장치의 동역학을 구성했다는 증거가 아니다.

1+σ가 표시상1이 되어도 실제 생성량을 따로 유지하고, 일의 전체 유리식에서 부호를 정한다. 범위 밖 비영 관측은 값의null과 비영 부호·로그로 유지한다. Qh=0일 때는 상대 계수가 음수여도 실제 생성이0이므로 전달 없음으로 분류한다.0/0 비율은 정의하지 않는다.

독립 생성기 `scripts/learning/generate-reservoir-cycle-references.py`는 `fractions.Fraction`으로 저장고 엔트로피에서 저온 열을 구성한 뒤 에너지 수지로 일을 구한다.24일반·12극한 사례를 대조했다. 이는 정확한 수치 예산의 참조이며 실제 비가역 궤적의 독립 시뮬레이션이라고 부르지 않는다.

## 원고와 검증 범위

두 가족의 한영 본문4개를 `content/learning/physics-math-for-ai/`에 작성했다. 각 언어에 가정·직관·부호·단위·유도·손계산·6개 풀이·AI 연구 연결을 담았다. 카르노 본문에는 영법칙의 추이 관계·온도계·절대온도 척도를 명시하고, 접촉이 끊겨 변화가 없는 상황과 열평형을 구별했다. 두 언어의 수식 일치·본문 앵커·수식/표 스크롤 표기와 영어의 한글 부재를 렌더링 검사로 확인했다. 새 화면의 브라우저 접근성 검증을 대신하지 않는다.

카르노 모델59검사·본문1검사, 저장고 모델48검사·본문1검사로 합계109검사를 통과했다. 타입과 대상 파일lint도 통과했다. 두 독립 생성기를 다시 실행한 결과는 각 고정 참조와 바이트 단위로 일치한다. 상세 근거는 `.runtime/learning/thermodynamic-laws-partial-foundation-verification.json`에 연결한다.
