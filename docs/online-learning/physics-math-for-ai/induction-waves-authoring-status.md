## 물리와 수치의 계약

유도 모형은 유계 영역의 Bz=b₀+b₁t+b₂t²/2, E=(b′y/2,−b′x/2,0)와 필요한 J=−ε∂tE를 지정한다. 전도·변위 전류가 상쇄하며 외부 경계와 원천이 필요하다. 유한 고립 솔레노이드나 도선·회로·힘·되먹임을 푼 해로 주장하지 않는다. µT 기반 입력은 SI로 변환하고 E의 µV/m, 기전력의 µV, 선속의 µWb를 구분한다.

기본 xy 경로의 법선은+z다. E 순환−b′LH와 운동 항−buH를 따로 비교한다. 고정 경로 식만으로 움직이는 면의 전체 선속 변화를 설명하지 않는다. 순간 기전력에 시간 길이를 곱하는 것과 실제 시간 적분도 구분한다. L₀∈[1,2], u∈[−0.25,0.25], |t|≤2의 전체 지원 구간에서 폭은 양수다. 높이0에서는 평균이 미정이며 폭 증가분의 산술 손실에서는 폭·꼭짓점을 사용 불가로 보고한다. 화면에서 구별할 수 없는 라벨은 묶되 실제 작은 높이를 계산에서 버리지 않는다.

펄스는 일정한 SI 계수의 c=1/√(εμ)를 유지한다. 시간 입력은 ns, 내부는 s다. 같은 초기 E와 다른 초기 B의 단방향·대칭 분리를 비교한다. B=0 음성 대조는 두 파동 식과 발산을 통과해도 일반 위치에서 일차 Maxwell 관계가 실패한다. 실제 지정 B와 호환 기준 B를 곡선·표·안내에서 명확히 분리한다.

가까운 Gaussian 차이의 expm1 계산, 작은 자속 변화의 다항식 상수 선소거와 직접 끝값 차감을 함께 보여준다. 실제 자기장 배경 b₀는 운동 항에 기여하며 게이지 상수가 아니다. 수치 손실·정확한 대칭 영점·영진폭을 구분하고 SI 변환이 비영 값을 잃으면 실험 관측을 사용 불가로 표시한다. 가로로 무한한 평면 Gaussian은 유한3차원 안테나나 날카로운 파면이 아니다. 장 에너지·Poynting 흐름·물질 경계는 후속 원래 주제로 남긴다.

## 실제 통합 검증

전자기학 관련205개·전체4,026개 테스트와 타입·lint·콘텐츠1,704 URL·빌드1,712페이지·출력1,707 HTML 검사가 통과했다. 기존468개 단원·안내,42개 실험 그룹459항목과 상대 순서를 등록 전 canonical 기준으로 보존했다. 이전 Maxwell 가족이 전체의 마지막이어야 한다는 테스트는 그 가족 내부 상대 순서 검사로 바꾸었다.

화면은2단원×2언어×2폭(320/1440)×2명암의16기본 상태와12특수 입력을 확인했다. 안내 펼침48개·예제58개·전체 조작4그룹에서 정밀 입력 저장, 퀴즈 오답·정답, 완료 상태 저장과 초기화를 검사했다. 개념 단계별 두 그림 교체, 접근성·키보드·넘침·SVG 라벨 잘림·영어 한글 잔존·페이지 오류도 검사했다.

모바일 원본 그림84개의 키보드 가로 이동을 확인했다. 한영·명암 갤러리8개(84그림), 펼친 안내4개와 영어 개념8단계 캡처를 직접 검토했다. 영어 UI 전체554경로·612상태 검사가 통과했다. 소스2,958개·출력4,155개를 동결하고 진행 원장·교육과정 동기화 뒤에도 일치함을 확인했다.

첫 특수 입력 검사에서 최소 양의 폭 변화율에 시간0.7123을 곱하면0이 아니라 최소 양의 수로 반올림되는 것을 확인했다. 실제 곱의 소실을 만드는0.4123으로 검사 입력을 수정해 전체 화면 검사를 다시 통과했다. 제품 소스·빌드는 바뀌지 않았으며 첫 실패·부분 기록은 `.runtime/learning/induction-waves-width-audit-input-initial/`에 구분해 보관했다. 해당 부분 결과를 최종 화면 증거로 대신 사용하지 않는다.
