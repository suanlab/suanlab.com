# 분배함수의 도출과 계산 계약 사전 검토

최신 구현 상태: 첫 유한 스펙트럼 가족의 [모델·원고 검증](partition-cumulant-foundation.md). 아래 내용은 그 이전 수학 계약이며 다른 두 가족과 실제 교육 화면은 계속 작성한다.

2026-11-07. 다음 주제의 모델 작성 전 수학 검토다. 아직 새 계산 모델이나 한영 교재의 완료 근거는 아니다. 정의와 에너지 미분의 출발점은 [Tong, §§1.3.1–1.3.2](https://davidtong.org/pdfs/teaching/statistical-physics/statphys1.pdf#page=24)다. 아래의 구현 경계·반례·검증 구성은 별도로 명시한다.

## 고정 유한 상태공간과 기준 측도

서로 구별되는 유한 상태 i의 온도 독립 에너지 E_i와 비영 유한 온도를 가정한다. β=1/(kBT), Z=Σ_i exp(−βE_i), p_i=exp(−βE_i)/Z다. 퇴화 준위의 총 확률은 g_i배를 포함하지만, 상태를 g_i번 열거한 뒤 다시 g_i를 곱하지 않는다. 유한 상태공간의 모든 허용 상태는 유한 β에서 양의 확률을 갖는다. 제외된 상태와 표시되지 않는 양의 꼬리는 다르다.

합의 기준은 개별 상태에 가중치1을 주는 계수 측도다. 합을 상태 수 m으로 나눈 Z/m은 같은 p를 주어도 ln Z를 ln m만큼 바꾼다. 물리적 상태 계수와 ML의 정규화한 기준 측도를 몰래 바꾸지 않는다. 이는 에너지 기준의 상수 이동과도 다른 연산이다.

## 무엇을 생성하는가

고정 상태·고정 준위에서 다음 식을 직접 미분해 얻는다.

- ∂β ln Z=−U, ∂β² ln Z=Var(E), C=Var(E)/(kBT²).
- 에너지의 cumulant 생성함수는 K_E(t)=ln Z(β−t)−ln Z(β), t의 단위는1/J다. κ_r=(−1)^r ∂β^r ln Z이며 단위는J^r이다.
- source가 있는 Z(θ)=Σ_i exp(θ·A_i)의 gradient는 평균 A, Hessian은 feature covariance다. θ·A_i는 무차원이어야 하며, 같은 기준 측도와 θ 독립 feature를 유지해야 한다.

Hessian은 양의 준정부호이지만 항상 양의 정부호는 아니다. 어떤 v에 대해 v·A_i가 모든 허용 상태에서 상수이면 해당 방향의 분산은0이다. 이것을 샘플 수 부족이나 계산 오류로 오해하지 않는다. 이 계산은 명시적 고전 상태 또는 함께 대각화한 관측을 위한 것이다. 비가환 양자 관측의 응답을 동일한 스칼라 공분산 식으로 확장하지 않는다.

Z(β)만으로 모든 관측을 복구할 수 있다는 설명도 피한다. 두 상태의 에너지 다중집합이 (0,ε)인 두 모형에서 A의 배치를 각각(0,1)과(1,0)으로 잡으면 Z는 같지만 평균 A는 r과1−r다. 관측의 상태별 값이나 그 source가 추가로 필요하다.

## 미분에서 고정하는 것

E_i(T)가 변한다면 단순한 열용량 식은 일반적으로 성립하지 않는다. 직접 미분하면

`d⟨E⟩/dT = ⟨∂T E⟩ + Cov(E, E−T∂T E)/(kBT²)`

다. β 의존 준위에서도 `−∂β ln Z=⟨E+β∂βE⟩`다. 외부 매개변수 λ에 대해서는 고정 T에서

`∂λ F=⟨∂λ E⟩`,

`∂λ∂η F=⟨∂λ∂η E⟩−β Cov(∂λE,∂ηE)`

가 된다. 에너지에 비선형으로 들어가는 매개변수를 선형 source처럼 미분하지 않는다.

온도 독립 상수 c를 모든 준위에 더하면 ln Z는−βc만큼, U와 F는 c만큼 변하지만 p·S·분산·C는 유지된다. c(T)를 바꾸는 실험은 이 고정 기준 이동과 다르다. 큰 기준값과 작은 간격은 입력 표현부터 분리해 보존할 수 있지만, 이미 반올림된 준위 목록에서 소실된 차이를 복구할 수는 없다.

## 분배함수의 곱과 제한된 지지집합

전체 상태공간이 X×Y이고 E(x,y)=E_X(x)+E_Y(y)이면 이중합이 분리되어 Z=Z_X Z_Y다. 상태공간을 고정 총합 제약으로 제한하면 가법적인 에너지라도 이 결론이 자동으로 따르지 않는다. 두 스핀의 J=0,h=0에서 전체 네 배치는 Z=4지만 반정렬 두 배치만 허용하면 Z=2다.

상호작용 예제 J/(kBT)=ln2,h=0에서는 정렬 두 배치의 가중치가 각각2, 반정렬 두 배치가 각각1/2여서 Z=5다. 정렬 상관은3/5다. 곱 분해의 log 차이 ln(5/4)와 상호정보량 `(4/5)ln(8/5)+(1/5)ln(2/5)`는 서로 다른 값이며, 비교 기준을 명시해야 한다. 이 값들은 이상적 로그2 입력의 손계산이고, 실제 이진 입력의 독립 수치 기준과 구분한다.

## 절단과 빠진 질량

전체 정규화된 p에서 사건 A를 남기고 빠진 질량을 δ라 쓰자. q=p(.|A)이면

- Z_A/Z=1−δ, ln Z−ln Z_A=−ln(1−δ).
- TV(p,q)=δ, D(q||p)=−ln(1−δ).
- 빠진 상태에 양의 p가 있으면 D(p||q)=∞다.

절단 분포 자체의 합이1이라는 사실은 δ의 상한을 제공하지 않는다. 사다리 준위의 등비 꼬리처럼 별도의 구조를 써서 빠진 질량을 구해야 한다. 유한 절단의 정규화 가능성과 무한 상태공간의 정규화 가능성도 별도로 판정한다.

## 기존 코드에서 재사용할 계약과 빈틈

`src/lib/learning-canonical-spectrum.ts`의 `canonicalFiniteSpectrum`은1..32개 유한 미시 에너지와 양의 유한 온도를 받는다. 최소 준위를 빼고 정확한 이진 곱·차·비를 보존하며, 상태별 에너지·scaled gap·확률 관측을 돌려준다. 음의 온도, 일반 source의 covariance, 모든 에너지 cumulant를 이미 지원한다고 가정하지 않는다.

특히 그 반환값의 표시 확률만 곱해 모멘트를 만들면 드문 양수가0이 되거나 물리적 에너지 척도로 복원될 항을 놓칠 수 있다. `learning-binary-products.ts`, `learning-information-arithmetic.ts`, `learning-binomial-logit.ts`의 비제한 지수·양수 보존 계약과 기존 interval 모듈을 함께 검토한다. 기존 binary kernel은 독립 동일 자리의 특별한 구조이며 임의 준위/상호작용의 일반 커널로 취급하지 않는다.

분산은 가능한 경우 쌍 차이의 양수 합 `1/2 Σ_ij p_i p_j(E_i−E_j)²`로 검토하여 큰 두 모멘트의 뺄셈을 피한다. signed covariance는 부호와 상쇄의 근거를 보존한다. 임의의 작은 잔차를 epsilon으로0 처리하지 않는다. 원래 ln Z는 기준 이동과 작은 centered ln Z의 차이가 될 수 있으므로, 불확실한 상쇄를 구조적 영으로 선언하지 않는다. 수치 계약은 지원 범위와 근사·미해결 상태를 구현 전에 명시한다.

작은 상태의 직접 열거·이상적 유리 손계산과 실제 binary64 입력의 고정밀 기준을 분리한다. 미분 관계는 해석식과 여러 차분 간격의 관찰 오차를 함께 비교하되 유한 차분만으로 참값을 인증하지 않는다. 이 검토를 통과한 모델 이후에 한영 원고와 실제 실험을 작성한다.

## 독립적인 이상적 손계산 사전 확인
