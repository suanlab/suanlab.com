# 정칙 섭동: 독립 응답 검증과 실제 Worker

2026-11-10. [한영 원고와 계산 기반](regular-perturbation-foundation-status.md)에 독립 응답 검증기,계산/검증Worker,취소 가능한 controller와React hook을 연결했다. **학습 화면·실제 Interactive Book reader·Next생산 자산 검증은 아직 남아 있다.**

## 독립 검증과 입력 귀속

생산 모형은 삼중 합 점화식으로 계수를 구하고 유리수 이분법으로 근을 포함시킨다. 검증기는 별도 유리수 연산과Lagrange 이항계수 공식,정수 격자의 영점 위치 탐색으로 결과를 재구성한다. 잔차 다항식은 순서 없는 세 인자의 조합과 중복도를 합산한다. 같은 총차수의 공통 인자를 먼저 묶어 최대 분수 입력에서 불필요한 큰 정수 최대공약수 연산을 줄였다.

모든 계수·부분합·잔차·오차/에너지 보증·근 구간/부호·거리·감수율·수렴 분류와배열 길이/추가 항목을 대조한다. 응답의 분수 문자열은 산술 피연산자로 읽지 않는다. 계산은 검증한 입력에서만 시작하며,원래 분수 표기·차수·원천·요청ID의 귀속도 확인한다. 검증기는 생산 계산기와 그 유리수/다항식 도구를 가져오지 않는다.

## 화면에서 사용할 연결

각 실행은 계산Worker와독립 검증Worker를 순서대로 소유하고 종료한다. 큰 응답 복사는 작업을 나누며 새 입력·취소·시간 초과·이탈 시 중단한다. 오래된 콜백이 최신 상태를 덮어쓰지 못하고 검증 전 결과를ready로 표시하지 않는다.

React hook은 비활성화·문서 숨김·입력 변경 시 이전 결과를 숨기고 작업을 취소한다. 다시 표시·재시도 시 새 요청으로 시작한다. 서버 렌더링에서는Worker를 생성하지 않는다. 계산/검증 수치 엔진은 hook번들에서 제외한다.

## 확인한 근거

- **새81검사·기반 포함143검사**를 통과했다.52기존 독립Python/SymPy입력의 전체 응답,4최대 서로소 분수 입력의 독립Python해시,77개 개별 응답 항목 변조,입력/귀속/자원 제한,controller의 취소·복사 중 교체·오류·기한·폐기를 포함한다.
- 최대 차수16과각12자리 분자/분모의 서로소 분수4입력을 추가했다. 약분되는 큰 숫자만 검사하지 않고 실제로 긴 계수·잔차·보증값을 전송한다. 최대 관측 응답은463699바이트이며 기존 소유권 복사의 제한을 바꾸지 않았다.
- 실제브라우저 moduleWorker에서 **70입력**(독립참조52·명시 예제14·추가최대4,예제 중복 포함)을 계산/검증했다. 전체 결과 해시를Node계산과 대조하고,수렴 분류 변조70건·다른 요청ID70건을 거부했다. 입력 타이핑이 계산 묶음이 끝나기 전에 반영됐고 두Worker를 종료했다.
- 실제React hook에서 큰 서로소 입력,비활성화·숨김 이벤트·복귀·입력 교체·재시도·계산 중 이탈을 확인했다. **14생성/14종료·활성0**이며브라우저 오류가 없다. 숨김 검사는visibility이벤트를 모의한 것으로 실제 운영체제 탭 전환 검증과 구분한다.
- 타입·대상lint·기존1825URL콘텐츠 검사를 통과했다. 실제Next생산 자산이나 교재 화면을 검증한 것으로 확대 해석하지 않는다.

명령은 `python3 scripts/learning/regular-perturbation-budget-reference.py`, `npx tsx --test scripts/learning-regular-perturbation-{foundation,workers,controller}.test.ts`, `npx tsx scripts/check-regular-perturbation-{workers,hook}-native.ts`다. 근거는 `.runtime/learning/regular-perturbation-worker/`의 `tests.log`, `native-workers.json`, `native-hook.json`, `budget.json`, `verification.json`에 보존한다.
