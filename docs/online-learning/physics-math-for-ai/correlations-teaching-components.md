## 학습 구성

각 가족6개념 단계·3안내·3최종 문항이다. 전체 **18단계·고정 예측18문항·단계별 고정 준비42회·안내9개·프리셋32개·최종9문항**을 작성했다. 고정 예제는 저장된 자유 입력과 분리하며 단계·예제 전환에서 오래된 결과를 노출하지 않는다.

- 두 스핀: 네 배치의 확률, 관측/source 벡터, 연결 공분산 행렬과 합·차·척도 비교.
- 고리: 선택 오프셋과 두 경로, 유한/무한 사슬 참조, 선택 상관·방향성 로그·균일 반응·길이와 전체 오프셋 표.
- AR(1): 최대512관측 계산의8×8 공분산 창, 모든 접두 길이의 유한 분산, 점근 참조·로그 축·정확한0 표시, 표준오차·등가 수와 전체 지연·접두 표의 페이지 나눔.

기존 palette·명암·모션 설정을 사용한다. 자동 순회는 준비 비교이며 물리적 시간 진화가 아니다. 화면 밖·전역 모션 정지에서 순회를 멈추고 수동 단계는 유지한다. 입력 오류는 기존 준비를 유지하고 reset은 초안도 지운다. 저장 복원·자유 입력·정밀도에 대응하는 프리셋 강조는 현재 입력에서 직접 결정한다.

## 수치 표현의 구별

정확한0은 중립색, 양·음 상관은 파랑·주황으로 구별한다. 미해결/표시 범위 밖의 값은0으로 그리지 않는다. 무한대 등가 수와 비혼합 끝점의 IAT 미제공도 구별한다. AR의 음의 의존성 곡선을 단조 평활화하지 않으며 확대 축의 반올림 눈금이 겹치면 실제 투영 범위를 별도로 적는다.

Node와 Chromium의 `Math.log(3)/2`가1 ULP 달라 고정 예제 key가 달라지는 것을 확인했다. 실제 참조 입력 `0.5493061443340549`를 고정하여 재현성을 확보했다. 이상적인 기호 로그와의 구별은 유지한다.

일반 크기 로그는 인증된 방향성 로그와 다르다. 1 근처에서 큰 정수 로그를 빼는 근사 오차가 가짜 부호를 만들지 않도록 정상 표시값의 로그를 우선하고, 비정규/표시 범위 밖 값은 모델의 별도 근사 크기를 유지한다. 이는 표시 투영이며 수치 모델의 경계를 바꾸지 않는다.
