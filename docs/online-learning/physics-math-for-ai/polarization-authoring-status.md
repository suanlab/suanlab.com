# 편광의 홈페이지 연결

2026-11-05. 기존 HSL 색상·명암 테마·독자 화면에 계산 모델 두 개와 상세 한영 원고 네 개를 연결했다. 전체 교육과정과 연구 심화의 완료 여부는 별도로 관리한다.

## 연결한 구성

| 단원 | 계산과 시각화 |
| --- | --- |
| `jones-polarization-waveplates-analyzers` | 입력·중간·출력의 실제 전기 벡터, 타원과 주축, 시간 위상의 실수 성분·제곱·주기 평균, 단계별 강도·분석기 스캔·Stokes·지연량별 변환 |
| `stokes-coherency-polarization-tomography` | 정규화 Stokes의 두 직교 투영, 집단·결맞음·실현별 기여, 여섯 분석기·재구성 잔차·Mueller, 단계별 편광도·출력 강도·명시한 대표 성분 |

기본 SVG23개·표8개, 개념 단계8개·안내 실험6개·해설 퀴즈4개를 한영으로 제공한다. 각 상세 원고의16개 절·여섯 개 해설 문제와 독립 기준값은 [기반 집필 기록](polarization-foundation.md)에 있다.

Jones의12개 예제는 사분파장판의 선형→원형 변환, 영지연, 소자 순서의 비가환 차단/투과, 전체 위상과 시계 벡터, 반대 원형, 영입력·직교 분석기·타원 수치 예제·반파장판 두 배 회전·끝값을 비교한다. 상대 위상π/3과 √3/2 같은 비정수 값을 임의로 반올림하지 않는다.

Stokes의14개 예제는3:1 혼합의 회전, 무편광·반대 원편광, 완전 탈편광·필터 선택, 평균 장이0인 순수 편광 집단, 서로 다른 무편광 준비, 영강도·비가환 순서·순수 타원·큰 강도를 비교한다. 확률과 제곱 관측의 평균을 따로 보존한다.

## 물리와 그림에서 지킨 조건

실제 장의 타원은 x/y의 화면 단위 길이를 같게 하는 전용 SVG를 사용한다. 입력·중간·출력에 공통 표시 범위를 적용하여 투과 손실이 숨겨지지 않게 했다. 선택한 시간 위상의 점과 반지름은 실제 실수 벡터다. 원형에는 특정 주축을 만들지 않으며 영장에는 정규화 편광을 만들지 않는다.

Stokes의 Q·U 및 Q·V 그림은3차원 정규화 공의 직교 투영이다. 투영된 반경이 전체 편광도인 것으로 해석하지 않도록 설명한다. 영강도는 정규화 점이 없고, 무편광은 양의 강도와 공 중심의 점을 갖는다. 별도의 원편광 관측으로 같은 선형 스캔의 다른 원인을 구별한다.

부분 편광 화면의 타원은 양의 확률·영이 아닌 장을 가진 출력 성분 하나다. 실제 성분 번호와 확률을 명시하고 전체 집단의 유일한 타원으로 제시하지 않는다. 단계별 원래 강도·조건부 편광도·소자 순서를 함께 표시한다. 채널별 읽음값은 이산 점으로 표시하며 가짜 연속 관측으로 잇지 않는다.

지연량·탈편광 비율 스캔은 검증한 관측 모델을 공유한다. `jonesPolarizationObservation`, `stokesPolarizationObservation`을 분리하여 각 스캔 점에서 전체 시간 궤적과 분석기 스캔까지 다시 만들지 않도록 했다. 기존 전체 모델과 같은 상태·관측량을 반환하는지 검사했다.

전치의 Choi 고유값 반례는 고정한 연구 설명이며 현재 장치로 적용하지 않는다. 모든 현재 채널은 비음수 준비·Jones 소자·Pauli 혼합으로 구성한다. 매질 교정 없는 정규화 강도를 SI 복사조도라고 부르지 않는다.
