# 열역학 입문 종합 점검: 첫 다섯 단원

2026-11-07. 열접촉·이상기체 경로·카르노 순환·두 저장고 수지·저온 스펙트럼의 한영 본문10개,가정·단위·예제·교수 자료·선수 연결과 실제 실습을 대조했다. **5/32단원**의 입문 점검을 기록하며 나머지27단원과 연구 심화는 미완료다. 등록533단원·1,599안내,원래290/362주제 입문 검증·72미완료는 바꾸지 않았다.

## 발견한 입력 오류와 수정

실제 열접촉 실습의 전도 계수에 `1e-999`를 입력하면 원래 필드의 `valueAsNumber`가0이 되어,비영 연결을 끊긴 연결로 저장했다. 오류 표시도 없었다. `underflow-before.json`과 `underflow-after.json`은 수정 전 저장값0과 수정 후 오류 표시·이전 값0.4 유지의 실제 브라우저 근거다.

`ThermodynamicNumberField`는 범위 안의 유한한 십진/지수 입력을 Enter 또는 초점 이탈 때 적용한다. 비영 문자가 있는 수가0으로 변환되면 거부한다. 빈 입력·범위 밖·정수 제약 위반도 설명하고 이전 설정을 유지한다. 표현 가능한 `5e-324`와 작은 정상 값은 허용하며 정확한0은 별도로 허용한다. 프리셋/초기화는 같은 값이어도 초안을 지우고 숫자 입력에 초점을 두면 자동 진행을 멈춘다. 저장 스키마와 수치 모형은 바꾸지 않았다.

다섯 실습이 새 필드를 사용하지만 기존 공통 `lab-controls.tsx`의 다른10사용처는 남는다. 실제 목록은 `shared-number-field-followup.json`과 진행 JSON에 기록했다. 이들을 다음에 수정하며 공통 입력 계층 전체가 완료됐다고 주장하지 않는다. 저장고 영어 본문의 ‘예정 그림’ 제목도 실제 포트 그림에 맞게 고쳤다.

## 물리·수학·교수 자료 검토

열접촉은 바깥 단열·내부 에너지 교환,가중 평형과 엔트로피 생성,연결 없음과 같은 온도의 차이를 검토했다. 이상기체는 Q−W=ΔU,같은 끝점의 경로량 차이,가역 열교환과 준정적 체적 제어,경로 진행률과 시간의 차이를 대조했다. 앞 단계의 독립100자리116비교와 현재 제어/예제 실행을 함께 사용했다.

카르노는 네 구간의 체적 연결·개별 단열 일·상쇄,완결/부분 순환과 역방향 COP,퇴화 비율의 미정을 확인했다. 저장고는 에너지 보존과 엔트로피 허용성의 독립성,σ<0의 반사실적 비교,일 입력 소산과 냉동기의 차이,주어진 조건에서의 잃은 일을 대조했다. 스펙트럼은 상태군 확률과 개별 상태,복제 수와 상태 수,고정 스펙트럼 요동식,양의/0간격 극한 순서와 냉각 동역학의 경계를 확인했다. 출처의 work-on 관례와 이 교재의 work-by 관례도 혼동하지 않는다.

세 법칙 가족의 모델 출력을 독립 Python Decimal800자리 계산과231회 대조했다. 카르노6사례의 개별 구간/완결 열·일·에너지·엔트로피,저장고7사례의 포트·생성·분류·잃은 일,스펙트럼7사례의 상태 합과 Shannon 엔트로피·열용량을 확인했다. 역순환·같은 온도·r=1·가까운 두 온도·음의 생성·0열·표현 범위 밖 생성·T=0·Δ=0·희귀 꼬리를 포함한다. 정상 값은 상대 오차와 비교하고 subnormal 투영에는 반ULP를 허용했다. 실제0으로 잘못 바뀌는 것을 허용하지 않도록 부호를 별도로 검사하며 범위 밖 값은 부호·로그로 대조했다. 이 표본들은 모든 입력의 정리를 증명하지 않는다.

한영20개 개념 단계·10문제와15안내의 예측·행동·해설을 읽고 고정 예제·자유 실습의 차이를 대조했다. 선수 단원은 기존 열역학,적분,계 경계·수지,지수/로그,확률 분포에서 이어지며 순서와 실제 정적 링크를 확인했다.
