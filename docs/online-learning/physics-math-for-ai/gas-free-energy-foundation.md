# 등온 이상기체의 자유 에너지와 체적 가용 함수: 기반 검증

2026-11-06. [엔트로피·자유 에너지 설계](entropy-free-energy-authoring-plan.md)의 두 가족 중 **체적 가용 함수 가족의 모델·한영 본문 기반 검증**이다. 유한 스펙트럼의 Helmholtz–KL 가족, 실습 화면, 교재 등록과 주제 전체 검증은 남아 있다.

## 물리적 계약

예정 단원 ID는 `ideal-gas-helmholtz-gibbs-volume-availability`다. 고정 n,T의 고전적 이상기체에서 입력한 기준값 Fr로 등온선 F(V)=Fr−nRT ln(V/Vr)를 정한다. 내부 압력으로 계산한 Ggas=F+nRT, 외부 압력 제약 함수 Φ=F+P외부V, 평형 Gibbs 값 Geq를 구별한다. Φ의 기울기는 P외부−pgas이고, 양의 곡률과 Φ−Φ*=nRT(x−1−ln x)가 평형 부피를 판정한다.

Fr(T,n)의 함수 형태는 제공하지 않았으므로 절대 U·S·열용량이나 온도에 따른 완전한 자유 에너지 함수는 출력하지 않는다. 엔트로피·내부 에너지는 등온 차이만 계산한다. 일정 압력 일과 열 저장고, 처음·끝 기계적 에너지 차이 0, 다른 일 없음의 조건부 끝점 수지를 제공한다. 가역 최대 일 비교는 변하는 준정적 하중의 별도 절차다. 피스톤 경로·완화 시간·생성률은 지정하지 않는다.

## 수치적 계약

`src/lib/learning-gas-free-energy.ts`는 nRT와 P외부V의 차이를 입력 이진 수의 곱·합으로 보존한다. 반올림한 평형 좌표를 정확한 평형으로 붙이지 않는다. 가까운 부피의 로그는 투영 전 차이를 유지하며, 양의 차이는 작은 변위의 이차 나머지로 직접 계산한다. 전개 절단 오차와 이진 부동소수점 반올림은 별개다.

기준을 가진 네 절대 에너지는 근사 로그의 상쇄가 일어날 수 있다. `AnchoredFreeEnergy.zeroStatus`를 반드시 해석해야 한다. `unresolved-transcendental-cancellation`은 표시값·계산 부호가 0이어도 구조적 영이 증명되지 않았다는 뜻이다. 이후 화면은 이를 기존 관측 표의 ‘실제 0’으로 표시하면 안 된다. 구조적 압력 수지·양의 가용 차이와 절대 에너지의 근사 부호도 구별한다. 물리 상수와 매개변수의 불확실성을 넘어서는 실험 정확도는 주장하지 않는다.

## 독립 참조와 검사

`scripts/learning/generate-gas-free-energy-references.py`는 Fraction으로 입력을 보존하고 mpmath 압력 일 적분·양의 기계적 힘 적분으로 참조를 계산한다. 생산 코드의 로그/나머지 다항식을 복제하지 않는다. 일반 24사례는 160자리, 한계 20사례는 1000자리에서 계산하며 JSON에는 80유효숫자를 저장한다. 네 일반 사례는 독립 미분으로 기울기와 곡률도 확인한다. 참조 재생성 파일은 고정 참조와 바이트 단위로 일치한다.

모델 58검사·본문 1검사, 타입 검사와 해당 파일 lint를 통과했다. 정확한 평형·인접 부피·표시 비율 1·반올림된 동일 함수값·상쇄된 개별 엔트로피·가역 일 감소·기준 이동·계의 크기 확대·로그 상쇄·입력 범위·직렬화를 확인했다. 절대 기준 에너지의 일반 상쇄는 절대 오차로 검사하며 초소형 양의 가용 차이는 상대 오차와 부호로 검사한다.

상세 한영 본문 2개에는 같은 수식 12개, 본문 절 15개와 언어별 풀이 6개를 작성했다. 고정 T,V와 T,P의 차이, Gibbs 자연 변수의 곡률, 조건부 엔트로피 수지와 최적화 해석을 설명한다. 표준 정의는 [Tong 4.4절](https://davidtong.org/pdfs/teaching/statistical-physics/statphys4.pdf), SI 기준은 [NIST 상수 표](https://physics.nist.gov/cuu/pdf/all.pdf)에 연결한다.
