## 내용과 설명의 연결

감쇠·회전·확산의2차원 선형 SDE를 정상 등방 Gaussian에서 시작한다. 드리프트 흐름의 방사 부분과 확산 흐름을 상쇄하고 남는 접선 흐름을 구한다. 밀도가 고정이어도 흐름이 순환하는 이유, 발산0과 벡터0의 차이, 원점 탐침과 장 전체의 차이를 설명한다. 원의 법선 확률 흐름과 접선 선적분·속도 순환은 방향·단위·의미를 구별한다.

같은 주변분포를 갖는 SDE와 probability-flow ODE의2×2시간 공분산을 비교한다. 공분산 순서를 `E[Xt X0ᵀ]`로 고정하고 음수 비대각 항을 확률처럼 자르지 않는다. 선형 관측량과 방사 관측량의 시간 평균 점근 분산, 회전으로 엄격해지는 Euler 안정성·불변 분산 편향을 연결한다. 연속시간 관측량의 이득을 모든 혼합률·수치 성능의 개선으로 일반화하지 않는다.

한영 각각13개 절·표시 수식12개·표1개·해설6문제다. 정상 히스토그램 안의 순환을 보행로 비유로 시작하고 단위·가정·계수·미분·예제로 전개한다. 일반 대학원생이 경로·밀도·흐름·측정을 구별할 수 있도록 관측 해석을 덧붙였다.

## 계산 원형

gamma,D>0, 부호 있는 유리수 radian 각속도, 탐침 위치, 물리 시간과 Euler 단계 수의11개 소유 정수 필드를 사용한다. 기존 방향성 pi·지수·로그를 재사용하고 유리수 각도의 방향성 삼각함수를 추가했다. 범위 반분·고정소수점 Taylor 다항식·명시적 잔여항·각도 두 배 공식으로 sin/cos를 포함시킨다. 원형은256bit를 사용하며 삼각함수 검사는64/128/256/512bit를 포함한다.

Euler 공분산과 증폭 제곱은 정확 유리수다. 정확한 방사 상쇄·발산·법선 흐름의 영 값을 별도로 보존한다. 매우 작은 양의 밀도가 선형 구간에서 미해결이면0으로 바꾸지 않고 로그 밀도와 성분 절대값 로그를 따로 제공한다. 음수 각속도·부호 공분산·안정성 경계·영 시간·영 승수·원점·아주 작은 양의 장을 구분한다.

준비18개에는 경계 바로 아래/위, 유리수 Pythagorean 경계, 빠른 회전, 시계 재척도, 극소 밀도와 `355/113`의 비정확 pi 근사도 포함했다. 표본 간격2초의 해석적 pi alias와 유리수 근사의 수치 오차를 구별한다. 정확한 pi를 유리수 radian 조작으로 입력할 수 있다고 주장하지 않는다. gamma,D가0인 경우·일반 비등방·물리적 열역학은 이 첫 원형의 범위에 포함하지 않으며 후속 학습 범위에는 남긴다.
