## 홈페이지와 공통 스타일

기존 홈페이지의 `PageHeader`, `Button`과 공통 컨테이너를 사용한다. 배경·본문·카드·
테두리·입력창·선택 항목은 전역 HSL 테마 토큰을 공유한다. 별도 종이색·녹색 배경과
기울어진 표지는 제거했다. 실험용 파랑·주황·초록은 물리량 구분용이며, 한 팔레트로
범례·표지 그림·손실 그래프·2D·3D에 적용한다. 테마 전환은 모델과 카메라를 유지하면서
WebGL 재질·격자·축 라벨까지 갱신한다.

## 계산·렌더링 규약

- 모델은 `src/lib/learning-simulations.ts`의 순수 함수다. 화면·수치 표·2D 대체 그림이 같은
  계산을 사용한다. 실험 입력은 `lab-model.ts`에서 검증한다.
- 힘은 N, 입자 위치는 m로 별도 그림을 사용한다. 일정 가속도의 해석해를 쓰고 중력·마찰·
  충돌을 추가하지 않는다. 힘·질량·초기 속도를 바꾸면 시간은 0으로 돌아간다.
- 행렬은 행 단위 저장과 열벡터 `y=Ax` 규약이다. 그림에 적용하기 전에 모델에서 좌표를
  계산하므로 Three.js의 행렬 저장 순서가 정답에 영향을 주지 않는다.
- 경사하강법은 `L=(ax²+by²)/2`에만 적용한다. 높이는 손실, 바닥은 파라미터다. 표시 축척은
  수치 계산과 독립적이다. 최대 50회, 좌표 절댓값 1,000 초과, 손실 10⁻¹² 미만에서 자동
  실행을 멈추며 마지막 계산값을 자르지 않는다. 학습 과정 전체의 분량 제한과는 무관하다.
- Three.js는 뷰포트 진입 시 로드하고 데이터·카메라·크기 변경에만 렌더링한다. 기본은 정지다.
  자동 진행은 모션 설정·시스템 모션 감소·탭 및 실험 가시성을 따른다. 수동 단계 이동은 유지한다.
- 회전은 드래그, 정면·위·초기 시점은 버튼으로 조작한다. 휠 확대는 페이지 읽기를 방해하지
  않도록 사용하지 않는다. 카메라 변경은 모델 좌표를 바꾸지 않는다.
- WebGL 실패·컨텍스트 손실에는 동일 데이터의 2D 투영을 표시한다. 재시도와 수치 조작은
  가능하다. 한·영 본문과 정적 그림은 JavaScript 없이도 내보낸 HTML에 포함된다.

## 원본과 검증

서비스 원고는 `content/learning/physics-math-for-ai/*.ko.md`, `*.en.md`, 단원 메타데이터는
`src/data/interactive-book.ts`에 둔다. 이 디렉터리의 초기 벡터 원고와 scene JSON은 설계·
기준 시나리오이며 서비스 본문의 중복 관리 원본으로 사용하지 않는다.

- `npm run check`: 린트, 콘텐츠, 회귀 테스트, 전체 정적 빌드, 타입·링크·사이트맵 검사.
- `scripts/learning-simulations.test.ts`: 설계 JSON의 17개 기준 사례, 일-에너지 관계,
  수렴·발산·특이 사례, 렌더 어댑터, 저장값 검증, 두 언어 수식 렌더링.
- `npm run check:learning`: 미리보기를 켠 상태에서 실행. 한·영 320/768/1440px 접근성·
  넘침, 입력·수치·저장·언어 유지·문제·학습 표시·WebGL 대체·모션 설정을 검사한다.

- `npm run check:language`: 사이트 전체 영어 UI 및 문서 제목 회귀 검사.

후속 검토에서는 설명의 난이도, 실험과 이론의 배치, 조작 범위, 예측 질문의 흐름을 조정한다.

## 대학원 입문 독자를 위한 내용 보강

첫 세 단원의 한국어·영어 원고를 함께 확장했다. 벡터는 13개, 행렬·그래디언트는 각각
15개 절로 구성한다. 기호를 이미 안다고 가정하지 않고 정의 → 직관 → 중간 계산 →
실험 → AI 예제 → 오해와 연구 점검 순서로 설명한다. 이 절 수는 시범 단원의 현재
편집 구조이며 전체 교재의 분량 제한이 아니다.

- 벡터: 스칼라·성분·기저·N의 뜻, 삼각부등식, 시간별 위치·속도, 일-에너지 검산,
  두 특징 표현의 가중 합과 정규화의 한계.
- 행렬: 행·열과 전치 표기, 기저를 같은 계수로 조립하는 과정, 행별 내적,
  변환 순서, 작은 선형층, 랭크와 정보 손실, 역변환의 오차 증폭.
- 그래디언트: 1차원 예측 오차, 차분에서 편미분으로 가는 과정, 거듭제곱 미분의
  중간 계산, 반복별 손실 표, 성분 배율, 헤시안의 두 번째 항과 초과 이동.

`ConceptWalkthrough`는 벡터 덧셈·전단의 기저·경사하강법을 3~4개의 수동 단계로
보여준다. 고정된 기준 예제이며 자유 실험과 독립적이다. 자동 재생은 하지 않고,
단계 선택은 언어 전환 시 유지한다. 접근 가능한 SVG 대체 설명과 수식 설명을 제공한다.

각 3D 실험에는 ‘먼저 예측 → 예제 열기 → 결과 해석’ 안내를 세 개씩 추가했다.
예제 열기는 현재 모델 값을 명시적으로 교체하며 자유 조작·저장 기능을 계속 사용할 수 있다.
해설은 펼쳐서 읽도록 하고 다른 안내를 선택하면 다시 접는다. 수치 표에는 반올림 표시와
모델 계산을 구분하는 안내를 추가했다.

본문 목차는 Markdown의 실제 h2 ID에서 생성한다. 표의 원래 의미를 보존하면서 키보드
가로 스크롤을 지원한다. 계산 예제 회귀 검사에는 가중 합, 합성 순서, 손실 이력, 차분값과
정확한 이차함수 손실 변화량을 포함한다.

내용 보강 후 전체 회귀 테스트는 68개(교재 관련 24개) 통과했다. 최종 수식·예제 검사,
정적 빌드·타입·HTML 1,237개의 내부 링크·자산·목차 앵커 검사도 통과했다. 브라우저는
한·영 및 다크 모드 28개 화면과 9개 조작 묶음을 확인했다. 새 검사에는 개념도 단계의
언어 전환 유지, 본문 목차 링크, 아홉 안내 예제의 실제 모델 값과 해설 펼치기가 포함된다.
개념도 검토 이미지는 `.runtime/learning/{vectors-and-forces,linear-transforms,gradients}-concept-en.png`에 있다.

## 연쇄법칙·Jacobian·역전파 확장

현재 읽기 경로에 세 미분 단원을 추가하여 총 아홉 단원이다. 각 단원은 한·영 본문,
4단계 개념도, 3개 안내 실험, 2개 확인 문제를 갖춘다. 실험은 주제에 맞는 SVG 계산 그래프를
사용하며 연쇄법칙의 곡선·접선, Jacobian의 실제 변화·예측, 역전파의 매개변수별 검산 표를
제공한다. 경계점·큰 보폭·저장 범위 이탈을 일반 미분 오류와 구분하여 설명한다.
현재 계산 계약·검증과 다음 집필 순서는 [순차 구현 기록](implementation-sequence.md)을 따른다.
