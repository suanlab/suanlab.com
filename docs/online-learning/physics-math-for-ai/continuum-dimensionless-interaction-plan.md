## 공통 표시 규칙

`learning-continuum-dimensionless.ts`의 관측은 `{ value, sign, logMagnitude }`다. 실제0은 sign=0,value=0,logMagnitude=null이다. 비영 표현 불가는 value=null이고 부호·로그가 남는다. 양의0값으로 대체하지 않는다. 정규화의 분모가0인 상태와 표현 범위 밖인 비영 관측도 구분한다. 원래4백여 단원의 데이터와 메뉴는 보존한다.

일반 수치 입력·정밀 입력·예제 버튼의 값은 같은 모델 입력으로 전달한다. 시각화는 기존 파랑·주황·초록과 명암 테마를 사용하며 색 외에 범례·선 모양·표를 제공한다. 그림의 시간 진행은 정상 해를 실제 시간 적분한 것으로 표시하지 않는다. 물질 이동 장식은 정상 장을 읽는 안내이며, 계산한 과도해가 아니라고 명시한다. 물리 좌표 x와 무차원 좌표 ξ를 각각 명시한다.

## Peclet 단원

8개 입력: U∈[−2,2],D∈[0.0001,4],L∈[0.25,4],cL,cR∈[0,4],A∈[0.25,4],조회 ξ∈[0,1],닮음 배율 a. 배율 b는 안내에서 고정·선언하거나 별도 비물리 비교 입력으로 둔다. 닮음 변환 후 입력 범위 밖이면 비교 불가를 표시하고 계수를 자르지 않는다.

개념4단계는 (1)두 시간과 부호 있는 Pe (2)하류 경계층과 양의 경계 가중치 (3)이류·확산·전체 플럭스 (4)닮은 곡선과 다른 실제 수송량이다. 각각 고정 예제와 간단한 질문을 붙인다. 전체 곡선은 균일 ξ 격자와 양쪽 D/|U| 부근을 해상하는 표본을 함께 사용하고 정확한 두 끝·조회점을 포함한다. 가까운 조회점이 일반 숫자 좌표에서 겹치는 경우 별도 표와 로그 관측을 남긴다.

그림 후보는 물리/무차원 농도,좌우 가중치,기울기,개별·전체 플럭스,로그 꼬리,작은 Pe 보정,두 시간,닮음 비교다. 같은 세로축에 kg/(m²s)와 kg/s를 섞지 않는다. 전체 플럭스의 안정 값과 반올림 직접값을 표로 함께 제공한다.

안내3개: 흐름 반전과 경계 교환,같은 Pe에서 길이·시간·유량 비교,큰 Pe와 미세 역방향 플럭스. 퀴즈2개: 물리 Pe와 격자 Pe,일정 농도와 비영 이류 플럭스. 예제에는 손계산 Pe10,U0,음의 U,양끝 동일,영 농도,1e−20/최소 비영 U,Pe80000의 양방향,큰 항 상쇄,영 조회점과정확한 끝점,닮음 변환을 포함한다.

## Damkohler 단원

8개 입력 후보: D,L,k∈[0,128],c0∈[0,4],A,조회 ξ,닮음 배율 a,b. D,L,A는 위와 같은 양의 범위를 쓴다. L은 전체 판 두께가 아니라 표면에서 대칭면까지의 반두께라고 모든 관련 표·그림에 명시한다.

개념4단계는 (1)확산/반응 시간과 Da=φ² (2)유한 판 농도·무유속 면의 비영 농도 (3)실제 저장 질량과 유입=소모 (4)효과도·침투 길이와 닮음이다. 개념 예제는 각각 Da4손계산,k0,다른 실제 면적,큰 φ와 계수2를 사용한다.

그림 후보는 판과 경계조건,농도와정규화 기저,기울기·플럭스,국소 소모,누적 물리 소모 적분,저장·유입·소모 표,효과도와 부족분,침투 길이,로그 꼬리,작은 Da 고갈,닮음 비교다. 농도 적분은 kg,반응 적분은 kg/s로 표시하고 완전한 대칭 판의 두 배와 반쪽 결과를 구분한다. 큰 φ에서는 표면 침투 길이에 맞춘 표본을 보완한다.

안내3개: 밀폐면의 농도와 기울기,반쪽 판 수지와 전체 판 환산,같은 Da와 다른 실제 질량. 퀴즈2개: k0의 미정 측정 효과도와 해석적 연장,확산 제한에서 반응속도4배의 전체 소모. 예제에는 Da4,k0,c00,작은 k,최소 k·조회 ξ,큰 φ밀폐 꼬리,최소 농도와 결합 배율,반응률·저장량 단위 차이,기하 닮음을 포함한다.

## 연결 후 필수 점검

단원2개·개념8개·안내6개·퀴즈4개·입력16개를 실제 등록한 뒤 검사한다. 모델 입력 범위·조작 연결·고정 예제와 실제 표를 대조하고 전체 회귀·형식·내용·정적 출력 검사를 통과한다. 한영·명암·모바일/데스크톱,키보드·정밀 입력·모든 예제,원본 SVG·가로 넘침·영어 표시를 확인한다. 완료 기록은 해당 증거 이후에만 갱신하며,현재275/362개 입문 검증 수를 미리 올리지 않는다.
