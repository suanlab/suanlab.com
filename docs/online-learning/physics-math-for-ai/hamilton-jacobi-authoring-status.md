## 균일한 힘의 완전적분과 정준 이름표

후보 `uniform-force-hamilton-jacobi-family`는 $H=p²/(2m)−Fq$에서 완전적분을 직접 유도한다. 위치 미분으로 운동량, 매개변수 미분으로 초기 상태 이름표를 읽고 실제 Hamilton 방정식과 작용 적분을 확인한다. 매개변수만의 `c alpha²/2` 항을 바꿀 때 같은 초기 상태를 유지하는 보상도 다룬다.

`lambda t q²/2`를 추가한 손상 후보는 정준 사상의 혼합 Hessian과 행렬식이 정칙해도 Hamilton-Jacobi를 만족하지 않는다. 조회 잔차0, 선택 궤적의 물리성, 독립 상태 전체의 PDE를 분리한다. 조회 위치를 옮기면 다른 특성곡선의 이름표가 되는 경우와 원래 선택 궤적의 운동량 잔차를 구분한다. 물리적 힘은 손상 매개변수와 함께 바뀌지 않는다.

## 조화진동자의 생성함수 좌표계와 caustic

후보 `oscillator-hamilton-jacobi-caustic-atlas`는 정확한 위상 흐름에서 끝점 주작용과 혼합 완전적분을 유도한다. 반주기의 끝점 호환·초기 운동량 미정과 사분 주기의 혼합 함수 실패가 실제 흐름의 특이성이 아님을 보여 준다. 실제 작용은 `(qp−q0p0)/2`로 계속 유한하게 계산한다.

초기 운동량 그래프 `p0=sigma xi`의 사영을 별도로 진화시킨다. 두 생성함수가 모두 정칙인 일반 각도에서도 그래프가 caustic에 도달할 수 있다. 초기 가족 소속, 끝점 경로, 선택한 물리적 궤적을 구분한다. 0시간·반주기·한 주기와 극점에서의 미정 값을 작은 epsilon이나0으로 채우지 않는다.

조회 시계는 사분면과 유리수 원 매개화로 정확한 사인·코사인을 만들며 물리 시간 표시는 atan과 pi로 평가한다. 이는 정확한 흐름의 매개화이고 시간 보폭을 입력 코드로 둔 Cayley 적분법이 아니다. 작용·Hessian 곡선은 미정 표본과 분모 부호 전환을 가로질러 연결하지 않는다.
