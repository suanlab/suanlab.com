# 상세평형: 저장 실습·표지·학습 흐름 검증

2026-11-07. 세 가족의 저장 가능한 실습과 장식 표지를 작성하고 기존 개념·결과 화면, 최종 퀴즈를 독립 native worker 화면에 연결해 검증했다. **실제 교재 등록·Next 읽기/worker 자산·전체 회귀는 미완료**다. 등록527단원·1,581안내, 원래288/362주제 입문 검증·74미완료를 유지한다. 전체51영역509주제·연구 심화의 완료로 세지 않는다.

## 입력·저장·시계

`learning-detailed-balance-controls.ts`는 가족별 입력 항목과 정수 초안 적용, 실제 전이 횟수의 증가/되감기를 담당한다. 소수·지수 표기·범위 초과·없는 필드·영 분모·분모보다 큰 분자·영 가중치 합·비양수 목표 가중치를 거부한다. 배열 편집은 사본을 만들며 입력을 동결해 반환한다. 분모 변경 시 기존 분자를 몰래 잘라내거나 비영 underflow를0으로 바꾸지 않는다.

`detailed-balance-lab.tsx`는 안내3개·프리셋·자유 정수 입력·전체 설정 초기화·저장과 계산 수명주기를 연결한다. 유효한 입력만 `suanlab-detailed-balance-${kind}`의 version1 저장 형식에 기록한다. 다른 가족·이전 버전·잘못된 저장 값은 기본 준비로 대체한다. 저장소 사용 불가 시 현재 방문에서 수동 조작을 유지한다. 프리셋 강조는 canonical 입력으로 결정하므로 자유 입력·복원·초기화와 일치한다. 초기화는 잘못된 초안과 오류 표시도 지운다.

순환과 두 상태 모델의 수동/자동 진행은 같은 전이 커널·초기 법칙을 유지하며 N을 하나씩 증가시켜 새 계산을 요청한다. N은0–512의 이산 전이 횟수이며 프레임 간격을 물리적 시간으로 부르지 않는다. Hastings는 초기 분포·시간·표본 경로 조작 없이 고정 커널 준비를 순회한다. 전역 모션 정지, reduced-motion, 화면 밖, 입력 초점 이동에서 자동 진행을 멈추고 수동 조작은 유지한다.

새 입력의 결과를 기다릴 때 이전 결과를 표시하지 않는다. 중지하면 해당 준비의 결과를 숨기며 재시도는 새 worker를 사용한다. 저장 복원·설정 변경·worker 파일 실패도 같은 입력 identity 계약을 따른다. 수치 모델을 main thread로 가져오는 동기 fallback과 정밀도 선택기는 없다.

## 표지와 기존 스타일

`detailed-balance-cover.tsx`는 기존 CSS 색 변수와 SVG 표지 관례를 따른다. 순환의 정상전류1/12, Hastings의 후보 흐름2/7·1/28과 보정 흐름1/28·수락률1/8, 두 상태의 λ=−1/2 교대 오차와 절댓값 포락선을 고정 예로 그린다. 실습 저장 값과 독립적인 장식 그림이며 수치 모델이나 worker를 실행하지 않는다. 고정 예의 수치와 그래프 좌표는 실제 모델과 대조했다.

실제 교재의 `BookArt` dispatch에는 아직 연결하지 않았다. 개념·결과 화면은 [앞 단계 검증](detailed-balance-views-verification.md), 수치 기반은 각 가족의 독립 기준·본문 검증 기록을 따른다.
