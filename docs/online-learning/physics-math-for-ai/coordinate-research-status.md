# 일반화 좌표: 곡률과 고유진동수 연구 확장

2026-11-12. `polar-generalized-velocity-force-metric`, `double-pendulum-generalized-mass-metric` 두 단원의 한영 원고 4편을 보강하고 검증했다. 기존 본문·여섯 연습 문제·해설·실습 입력을 보존한다. 전체 해석역학 심화 검토 완료를 뜻하지 않는다.

## 추가 내용

- 중심이 이동한 조화 퍼텐셜에서 보통 Hessian·공변 Hessian·직교 Hessian의 pullback을 유도한다. 원형 탐침의 곡률과 구속 없는 평형의 안정성 해석을 구분한다.
- 이중진자의 아래쪽 평형에서 질량·강성 행렬의 일반화 고유값 문제를 유도한다. 절대각·상대각의 동일한 물리적 진동수와 다른 행렬 스펙트럼, 질량 내적의 모드 직교성을 계산한다.
- 언어별 증명·비교표·실행 Python·추가 연구 질문을 제공한다. 그림 2종의 한영 SVG 4개를 기존 홈페이지의 색과 형태에 맞췄다.
- 작은 진동의 선형화와 비선형 시간 적분을 구분한다. 기존 실습은 순간 기하를 계산하며, 새로운 퍼텐셜·모드 계산은 보충 Python 예제다.

## 현재 검증

독립 표준 라이브러리 `python3 scripts/learning/verify-coordinate-research.py`에서 극좌표 Hessian 216상태, 정확 유리수 좌표 변환 54쌍, 비선형 진자 6궤적과 6개 보폭 절반 대조가 통과했다. 한영 표시 수식은 각각 6개·7개이며, 대응 Python 셀 4개의 실행 결과가 일치했다.

- 선택 15개 파일의 **351개 검사**, lint·콘텐츠·타입·빌드·출력 검사가 통과했다. 전체 저장소 검사나 전체 CI 성공으로 집계하지 않는다.
- 최종 빌드는 **1,893경로·1,888 HTML**이다. 8개 고정 소스 해시, 그림 4개의 소스/출력/제공 바이트와 두 단원의 출력/제공 HTML 바이트를 대조했다.
- 바뀐 두 단원을 **한영 320·768·1440px 라이트와 한영 1440px 다크, 16상태**에서 검사했다. 안내 6개·퀴즈 4개·개념 선택 8개·저장/완료 2그룹, 수식/표/코드 스크롤·목차·이미지 decode가 통과했다. 페이지 오류·Axe 위반은 0개다. SVG 원본 4개와 대표 한영 모바일 2개 화면도 직접 검토했다.
- 기존 원고 전체 바이트와 이전 검토 항목 645개를 보존했고, 새 원고 4개만 등록해 검토 항목은 649개다. 단원·안내 등록은 **650단원·1,969안내** 그대로다.
