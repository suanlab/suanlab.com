## 물리와 계산의 계약

`src/lib/learning-maxwell.ts`는 클라이언트에서 사용할 수 있는 순수 계산 모델이다. 일정한 양의 ε·μ와 c=1/√(εμ)를 함께 사용한다. 기본 ε는 교육용 반올림 μ와 SI 광속으로 유도하며 이전 정전기 단원의 반올림 상수를 혼합하지 않는다. 임의 계수를 실제 물질의 완전한 구성 법칙이라고 해석하지 않는다.

평면파의 진행 방향과 장 진폭 비율을 연결한다. xz 경로의 법선은−y, yz 경로의 법선은+x다. 닫힌 면과 고정 열린 면, 선속과 변화율, Wb·V·T m를 구분한다. 주파수만 어긋나게 하면 두 발산을 통과해도 진화 식이 실패하며, 한 점의 잔차0도 장 전체의 해를 보장하지 않는다. 영진폭·영파수는 별도의 유효한 퇴화 경우다.

가까운 cos 끝값 차이는 중간 위상과 sinc로 평가하여 비영 폭을 유지한다. 정확한 면적0에서는 평균을 정의하지 않는다. 비영 값의 산술 손실은 사용 불가로 보고한다. 시간 위상 |ωt|≤10⁶ rad는 명시적 지원 범위다. 이 값 밖의 입력을 숨겨서 자르거나 주기로 바꾸지 않는다.

방사형 예제는 E=a(t)r, B=0, ρ=3εa, J=−εa′r를 유계 영역에 지정한 제조해다. 경계 전류 공급이 필요하며 유한 고립 장치·물질·입자 동역학 해가 아니다. 전도·변위 전류의 상쇄와 닫힌 구 전하 수지를 따로 검사한다. 일정 밀도 편차는 연속·진화 관계를 통과해도 초기 Gauss 제약을 위반한다. 편차에서 직접 구한 결함과 반올림된 밀도로 구한 잔차를 분리한다. 작은 구에서는 선속만 표현 가능하고 전하가 사용 불가일 수 있다.

## 실제 검증과 한계

전용26개·전체3,976개 테스트, 타입·lint·콘텐츠1,700 URL 검사가 통과했다. 등록 전 동결한466개 기존 단원·안내,42개 실험 그룹457항목과 상대 순서를 보존했다. 네 원고를 실제 콘텐츠 로더로 렌더링하여 strict KaTeX, 언어별 수식 일치, 유일한 목차 앵커, 접근 가능한 수식 스크롤, 영어의 한글 잔존 없음과 문제 해설을 확인했다.

별도 Python 생성기는 제품 코드를 가져오지 않는다.54개 평면파 조건에서 공간·시간5점 차분과 SciPy 면적분을 대조했다.81개 방사형 조건은 실제3차원 구면 법선에 E·n과 J·n을 합산하고 전하 시간 차분·전류 발산과 비교했다. 얇은 경로3조건은 cos 차감이나 제품 sinc 대신 공간 도함수를 적분했다. 생성 파일의 재현성도 확인했다.

최대 관측 차이는 평면파 면적분 시간 차분1.96×10⁻¹¹ 이하, 구 전하 시간 차분2.08×10⁻¹⁰ 이하, 얇은 경로 상대 차이2.23×10⁻¹⁶ 이하다. 선택한 정규화 조건의 관측값이며 엄밀한 오차 상한이 아니다. 모델 내부의 해석적 상쇄·잔차는 독립 검증과 구분한다.

기존 홈페이지 소스2,932개와 출력4,147개를 보존하고 새 파일을 포함한 소스2,942개를 동결했다. 미등록 원고 단계이므로 새 빌드·화면 점검·공개 배포는 하지 않았다. 첫 검사에서 설명 분량에 둔 임의 단어 수 기준과 JSON 방향 타입을 수정했고, 최종 테스트·타입 검사를 다시 통과했다.
