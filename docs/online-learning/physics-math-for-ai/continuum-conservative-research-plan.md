# 보존 이산화 연구 보강 설계

2026-11-13. 기존 비균일 체적·Godunov/Roe 단원의 한영 전체 원고와 일차 자료를 읽었다. 본문·순서형 여섯 문제·풀이와 실제 기존 궤적·부호 로그·참조·실습 제어를 보존한다.

## 실제 체적과 볼록 엔트로피

영 이류·대칭 비음 확산에서 체적 비를 불변 가중치로 가진 가역 생성자를 유도한다. Poisson uniformization으로 정확한 확률 평균과 모든 볼록 함수의 수축을 설명한다. 농도·셀 질량 확률·상대 엔트로피의 단위를 구분한다.

양의 상태에서의 로그 소산, 영 농도의 미분 특이성, 영 생성자·영 저장량·끊긴 성분을 분리한다. 질량과 이차 노름은 맞아도 음의 농도를 만드는 정확한 Euler 반례를 제시한다. 기존 실습을 정확한 반군 전파자로 바꾸었다고 소개하지 않는다.

## 공간 플럭스와 실제 시간 갱신

Burgers 엔트로피 잠재함수에서 엔트로피 보존 플럭스를 유도하고 물리 플럭스 산술평균과 비교한다. 비음 소산을 더한 구조·면 결손·반이산 예산을 대조한다. 실제 Euler 단계의 양의 보정과 초기 범위 위반을 별도로 보여준다. 기존 Godunov/Roe 유한 구간 솔버를 교체하지 않는다.

## 검증·후속

한영 표시 수식 40개·실행 표 4개·연구 해설 12개·그림 4개를 대조한다. 보충 절 제거로 기존 본문 해시와 풀이 24개를 복원한다. 독립 Taylor/Poisson 전파, 체적 가중 볼록 진단·영/분리 대조, 정확 유리수 면 엔트로피·비균일 Euler 예산을 검사한다. 새 빌드의 한영 16화면·실습·저장/완료·접근성과 최종 모바일 그림을 확인한다.

설계 시점 순차 연구 보강은 20/22단원이었다. 관련 381검사·새 빌드·16화면 검증 후 현재 22/22단원이며 [검증 기록](continuum-conservative-research-status.md)에 근거를 연결했다. 그 이후에도 영역 전체 22단원 연구 종합 대조가 남는다. 그 이전에는 42영역·415주제 대조 / 9영역·94주제 후속을 유지하고 교육과정 완료를 선언하지 않는다.
