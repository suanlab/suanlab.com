# 공간 상관·스펙트럼 계산 모형 계약

2026-11-10. 단원 ID는 `spatial-spectra-decay-and-correlation-length`이다. 주차나 분량 제한 없이 물리적 정규화·손계산·독립 검산·실험을 갖춘 한영 단원을 집필한다. 이 문서는 구현 완료 보고가 아니다.

## 1. 입력과 에너지

입력 필드: `sites`3..16, `boundary` open/periodic/dirichlet, `constraint` none/mean-zero, `massSquared`와 `speedSquared`각[0,16], `spacing`[1/16,16], `temperature`(0,16], `origin`과 `selectedMode`각0..n−1. 실수 계수 입력은12자리 이하 분자·분모의 정수/분수 표기이며 원래 표기를 보존한다. 원천은0이다.

U=(a m²/2)∑φᵢ²+(c²/(2a))∑간선(φᵣ−φₗ)², K=M I+κL, M=a m², κ=c²/a, C=T K⁻¹이다. 이것은 앞 가우스 단원의 m²I+κL에 물리적 격자 정규화를 명시한 것이다. m²는 이미 제곱된 계수이며 다시 제곱하지 않는다. 기준 측도는 위치별 dφ의 곱이다.

열린 사슬은 n−1간선, 주기는 마지막-첫 간선, 외부0고정은 열린 사슬과 두 끝의0고정 간선이다. 위치는 주기 j a, 열린 셀 중심(j+1/2)a, 고정 내부점(j+1)a이다. 물리적 상자 길이는 주기/열린 n a, 고정(n+1)a다.

m²=c²=0은 항상 거부한다. m²=0의 열린/주기는 총합0 제약이 필요하다. 고정 경계의 m²=0,c²>0은 정규화 가능하다. 총합0은 다른 앙상블이며 고정 경계의 단순 표본 평균 빼기와 같다고 가정하지 않는다.

## 2. 정확한 유한 공분산과 증거

총합0에서는 B의 열이 eᵢ−eₙ₋₁인 기저로 G=B(BᵀKB)⁻¹Bᵀ, C=TG를 계산한다. 전체 공간이면 B=I다. 양의 유리수 LDLᵀ 피벗과 대칭성, PC=C, PKC=TP를 검사한다. P는 총합0에서 I−11ᵀ/n, 아니면 I다. exact 입력·K·L·B·P·C·제약 잔차를 반환한다.

이산 미분 연산자는 A=K/a이므로 전체 공간에서 A C=(T/a)I다. 이것이 연속 점 원천의 δ함수를 δᵢⱼ/a로 나타내는 정규화다. 에너지의 노드 원천−Jᵀφ에 대한 응답은 C/T, 밀도 원천−a hᵀφ에 대한 응답은 a C/T이다. 원천0이라는 본 계산에서 두 규약을 혼용하지 않는다.

## 3. Fourier 규약과 경계 모드 혼합

Fₗⱼ=n⁻¹ᐟ² exp(−2πilj/n), C̃=FCF*, K̃=FKF*를 사용한다. 모든 경계에서 전체 복소 C̃,K̃를 계산해 반환한다. 실수 공분산의 변환은 Hermitian이며 대각 성분은 양의 실수다. 주기에서는 정확한 병진 불변성이 성립하고 비대각0이다. 열린/고정에서는 DFT가 고유기저라고 가정하지 않는다. 실제 경계 기저의 동역학은 기존 field-modes 단원과 연결한다.

주기 에너지 고유값은 λₗ=a m²+4c²/a·sin²(πl/n), 공분산 모드 분산은 T/λₗ다. 제약이 있으면0모드를 제외하며 그 값을0으로 둔다. 특수 각도의 유리수 sin²는 대수적으로 인식하고 나머지는 방향성 구간으로 계산한다. 허용 오차로 영모드나 유리수 값을 추측하지 않는다.

mode l의 접힌 정수 파수는 l≤n/2이면 l, 아니면 l−n이다. 짝수 Nyquist는 양의 n/2 규약이다. 물리적 k=2πm/(n a)를 표시하고 alias 짝도 명시한다. 위치축·배치 번호·파수축·시간을 혼동하지 않는다.

trace C=∑diag C̃, Fourier Hermitian 잔차, 선택 원점 행의 역변환과 정확한 C를 대조한다. power=diag C̃와 연속체 비교용 a·power를 함께 구별한다. 후자는 주기에서 T/[m²+4c²/a² sin²(ka/2)]이며 저파수 극한 T/(m²+c²k²)로 간다.

## 4. 무한 사슬과 주기 image 합

m²,c²>0에서 u=M/κ=a²m²/c², r=2/(2+u+√(u(u+4))), A∞=T/√(M(M+4κ))다. r을1−작은값의 차로 계산하지 않는 형태를 사용한다. 무한 공분산은 C∞(d)=A∞ r^|d|이다.

특성식 κr²−(M+2κ)r+κ=0, 원점 jump (M+2κ)A∞−2κA∞r=T가 이를 정한다. 감쇠 길이는 ξ=−a/logr=a/acosh(1+u/2)이고 연속 근사는 ξcont=√(c²/m²)다. 유한 화면의 기울기 맞춤에서 이 공식을 얻었다고 말하지 않는다.

제약 없는 n고리의 Cₙ(d)=A∞(r^d+r^(n−d))/(1−r^n), d=0..n−1이다. massive 총합0이면 T/(nM)을 감산한다. massless 총합0 고리는 Cₙ(d)=(T/κ)[(n²−1)/(12n)−d(n−d)/(2n)]다. image 식은 열린/고정 경계에 적용하지 않는다.

c²=0,m²>0의 제약 없는 무한 기준은 독립 위치로 C∞(d)=T/M·δd0, ξ=0으로 분류한다. 유한 총합0 조건화에서는 C=(T/M)P여서 이웃 결합이 없어도 음의 비대각 공분산이 있다. m²=0,c²>0이면 무한계 정상 장 공분산과 유한한 감쇠 길이를 반환하지 않는다. 유한 고정/총합0 공분산의 존재와 별개다. 로그를0이나 음의 공분산에 적용하지 않는다.

## 5. 거리 행과 국소 비율

주기는 원점에서 순방향 d=0..n−1을 따라 j=(origin+d)%n을 읽는다. image 대칭과 끝의 되감김이 보이도록 거리와 최단 거리를 혼용하지 않는다. 열린/고정에서는 각 j와 실제 부호 있는 변위(j−origin)a를 읽어 경계 비균일성을 보인다.

이웃 값이 둘 다 양수이고 엄격히 감소할 때만 a/log(C₁/C₂)를 국소 비율 진단으로 계산한다. 비양수·같음·증가·경계 비균일을 분류하고 임의 값을 대입하지 않는다. massless 총합0에서도 처음 몇 값의 비율은 양수일 수 있으므로 이 진단을 무한계 ξ라고 표시하지 않는다.

## 6. 고정 길이 정련

주기 symbol만 네 수준 n·2ˡ, a/2ˡ을 계산한다. c²,m²,T, L=n a와 접힌 물리 mode 정수m를 고정한다. 음의 alias는 정련 후 새 배열 인덱스로 다시 매핑한다. 전체 공분산 행렬은 입력의3..16위치에서만 계산하며 정련은 최대128위치의 symbol 비교이지 그 행렬을 계산했다는 뜻이 아니다.

비교값은 λ/a와 a·power다. 고정된 물리적 파수에서 O(a²) 차이를 검사하되 모든 lattice mode에 대한 균일 근사로 소개하지 않는다. 단순한 n증가(고정a)와 고정L의 a감소는 다른 실험이다.
