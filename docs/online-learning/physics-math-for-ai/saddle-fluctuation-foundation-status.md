# 안장점·요동·비가우스 근사: 수학 기반과 집필 범위

2026-11-10. 경로적분 세 번째 처리인 `saddle-fluctuation-and-nongaussian-approximation`의 [일차 자료](saddle-fluctuation-primary-source-audit.md)·[수학 모형 계약](saddle-fluctuation-model-contract.md)·독립 유도식 검산을 준비했다. **26유한 모형,정확분수4701검사와80자리Decimal27검사,총4728검사**가 통과했다. 소수 적분은18행이며 인증 적분 구간이 아니다.

이는 새 학생용 원고나 생산 계산기가 아니다. 정상점 반복 구현·생산 정밀도와 전송 비용·독립 전체 응답 검산·Worker·한영 본문/그림/실습·실제reader가 남는다. [20요건 중4개](saddle-fluctuation-acceptance-matrix.json)는 자료와 수학 기반에 관한 요건만 충족한다. 단원·경로적분 원주제·전체 목표는 미완료다.

## 이전 단계와 차이

Euclidean 커널 단원은 이차 작용을 정확하게 적분했다. 새 단원은 양의 사차 potential을 더하고 **최소점·Gaussian 부피·그 밖의 보정**을 분리한다. 같은 최소 작용도 폭이 다르면 적분값이 다르고, 비가우스 분포의 평균이 최소점과 같을 필요도 없다.

주 모형은 고정 양끝의 `V=mω²x²/2+λx⁴/4`다. 일반 양끝의 유일한 비선형 최소점과 Hessian,잔차의 위치/작용 인증,Gaussian covariance와determinant 구간,삼차/사차 모멘트의 첫 보정을 다룬다. 양끝0인 경우에만 간단한 비음수Taylor 적분비 경계를 제공한다. 여러 최소점과 퇴화는 별도의 한 좌표 사차 우물로 비교하며 전체 이중 우물 양자 경로 계산으로 표시하지 않는다.

## 검산한 내용

- N2,3,4,7,8,16,32와세ω²의21개 영점 정상 모형에서 전체Gaussian 역행렬을 대조했다.3855성분의HR=I와315개씩의6차/8차 모멘트를 별도 Gaussian 모멘트 재귀로 확인했다. 자유 사슬의첫 보정`λτ³(1−N⁻⁴)/(40m²)`도 검사했다.
- 임의 이동점에서는 선형 잔차·이차 Hessian·삼차·사차 항을 모두 유지한 다항식 항등식을12경우 검사했다. 정확한 비영 정상점의N2두 경우와N3/4/6결합 모형을 구성했다. 결합 모형의 끝점 분수는 예정12자리 입력 문법 안에 있다.
- 비영 정상점의잔차로 위치·작용·전체Gaussian 역행렬 오차를 감싸고,양의 정부호 조건을 만족할 때 두 행렬의determinant 사이에 실제 값을 감쌌다. 이는 **알려진 정확 정상점**을 가진 모형에서 인증식을 대조한 것이며,아직 일반 입력의 생산 해법이 아니다.
- N2,a=0,b=37/32에서x*=1/2,H=39/8,c₁=−232/19773을 얻었다. 이때 이동 후 나머지가−3/128인 지점도 있어 비음수 가정을 반박한다. b=13/2에서는x*=2,c₁=19/6174>0이다. 사차 보정만 남기거나 첫 보정이 항상 음수라고 설명하지 않는다.
- 한 좌표우물의하나/둘/퇴화 최소점,극대점의음의곡률,두 최소점앞인자의합,첫 보정과ℏ¹ᐟ⁴폭을 확인했다. 사차 형식 급수의인접계수비가커지는16항 관계도 검사했다.
- 80자리Decimal에서 세 정상점의작은ℏ9행과단일/이중/퇴화 우물9행을1024/2048또는2048/4096분할Simpson 적분으로 비교했다. 관찰한 격자 차이·보정 계수 접근·퇴화 스케일을 기록했다. 유한 절단/수치 적분의 인증 오차나 일반 경로 적분의 수렴 증거로 세지 않는다.

## 재현과 증거

```bash
python3 scripts/learning/verify-saddle-fluctuation-derivations.py
```

Python 표준 라이브러리의Fraction·Decimal·Gaussian 모멘트 재귀와Gauss–Jordan을 사용한다. TypeScript 수치 모듈이나학생용 코드를 실행하지 않는다. `.runtime/learning/saddle-fluctuation-scope/derivations.json`에26모형·계수·인증 대조와18소수 행,`verification.json`에범위·소스 해시·미완료 상태를 기록했다. 일차 자료PDF와실제47쪽 이미지도 로컬 증거에 보존했다.

`4701+27`은 이 수학 검산 스크립트의 검사 수다. 이전 Euclidean 단원의217프로젝트 검사나 전체 저장소 테스트 수에 더해 동일한 검사 범위인 것처럼 보고하지 않는다. 수학적 부등식의 근거는 계약에 명시했으며 형식 증명 도구를 사용한 것은 아니다.
