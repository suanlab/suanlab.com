# 연속체 가정: 자료 검토와 적용 범위

2026-11-06. [연속체 보존식 두 단원](continuum-conservation-authoring-status.md)에 이어 원래 두 번째 입문 주제인 연속체 가정을 준비했다. 이 문서는 자료와 계산 설계의 근거이며 홈페이지 통합 완료의 증거가 아니다.

## 확인한 1차 자료

- Natalia Berloff, Cambridge, [Fluid Dynamics: Averaging in Fluid Dynamics](https://www.damtp.cam.ac.uk/user/tong/concepts/fluid2.pdf), PDF pp.2–4. 미시 길이와 거시 길이의 분리 및 평균장·연속방정식의 연결을 확인했다.
- David Tong, Cambridge, [Kinetic Theory, §1.2](https://www.damtp.cam.ac.uk/user/tong/kintheory/one.pdf), PDF pp.7–8. 입자 간격과 평균 자유 행로를 구분하고 충돌 시간에는 상대 속도가 관련된다는 점을 확인했다. 해당 도입부의 충돌 추정식을 모든 기체에 보편적인 정밀 계수로 사용하지 않는다.

자료의 일반 배경과 이번 교재의 선택된 모형을 구분한다. 사차 compact 커널, 유한 탄도 입자, 선택한 계수·충돌·해상도 부등식은 교재의 실습 구성이다. 실제 물질의 충돌·상태 관계·상관·열적 완화는 별도 증거가 필요하다. 자료가 이 제품 구현을 인증한다는 뜻은 아니다.

## 단위와 가정

입자 커널 실험은 일차원 선밀도 kg/m와 질량 유속 kg/s를 사용한다. 이차 모멘트와 속도 분산 수송의 단위는 N이다. 삼차원 계수 실험은 수밀도 /m³와 정육면체 부피 ell³를 사용한다. 두 실습의 밀도 차원을 섞지 않는다.

입자 운동은 외력·충돌이 없는 일정 속도 탄도 운동이다. 고정한 정규화 커널에서는 질량·운동량의 국소식과 전체 적분이 성립하지만 이것만으로 유체의 국소 평형이나 구성 법칙을 증명하지 않는다. 커널은 C1이며 C2가 아니다. 폭의 시간 변화는 관측 항을 추가한다. 공간적으로 변하는 폭·벽면 재정규화·임의 정밀도·작은 폭의 무제한 극한은 구현 범위 밖이다.

계수 실습은 균일 Poisson 기준과 고정 총개수의 독립 균일 위치에 대한 이항 분포를 구분한다. 상관된 물질에 Poisson 분산을 자동 적용하지 않는다. n과 lambda의 입력은 독립적인 비교 변수이므로 실제 재료에 적용할 때는 물리적 일관성을 확인한다. epsilon·eta·충돌 분리 계수는 사용자가 선언한 기준이다. 그 교집합 통과를 일반적인 연속체 유효성·평형·오차 인증으로 표시하지 않는다.

## 독립 검증 방법

별도 Python 생성기는 제품 모형을 가져오지 않는다. 실제 커널 정의의 공간 구적, 위치·시간·폭 미분을 55자리 산술로 계산한다. 잘라 낸 지지 경계를 적분 분할점으로 사용하며 제품의 닫힌 구간 원시식을 복사하지 않는다. 이항 계수의 평균·분산은 전체 확률을 열거해 구한다. 원본 참조 파일은 덮어쓰지 않고 별도 경로의 재생성 해시를 비교한다.
