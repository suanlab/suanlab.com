# 열·물질 확산의 화면 통합 순서

이후 [홈페이지 통합과 최종 검증](continuum-diffusion-authoring-status.md)을 마쳤다. 아래 수치와 미완료 설명은 기초/설계 작성 당시 기록이다.

2026-11-06. 계산·상세 원고 이후에 진행할 화면 설계다. 아직 새 UI는 구현하지 않았다. 진입은 **도서 → Interactive Book**을 유지한다.

## Fourier 열전도

예정 ID: `fourier-heat-diffusion-mode-budget`. 입력11개는 체적 열용량·열전도도·평균 절대 온도·상대 대비·파수·위상·단면적·시간·질의 x·창 중심·반폭이다. 열유속W/m², 경계 전력W, 현열J, 온도 노름K²m³를 각각 표시한다.

- 온도·섭동·공간 기울기·열유속을 같은 실제 위치에서 대조한다. 전체값이 평균과 같게 반올림되는 것과 섭동 관측 불가를 분리한다.
- 유한 창의 실제 에너지 변화율과 방향 있는 경계 전력을 비교한다. 대칭 항등식으로 보존한 반폭과 반올림된 끝점의 관측을 구분한다. 폭0과 양의 폭의 끝점이 합쳐지는 경우를 다른 상태로 둔다.
- 별도의 한 주기 셀 관측에서 총 현열 보존과 이차 노름 감소를 비교한다. 유한 창 입력 범위 밖의 주기를 임의로 작게 바꾸어 대입하지 않는다.
- 시간 감쇠, 파수에 따른 감쇠율, 안정적 진폭/노름 변화와 반올림 인자를 보여 준다. 지수 단독 언더플로와 결합 배율의 관측 범위를 분리한다.

고정 개념4단계는 온도와 열유속의 위상, 유한 창의120W 수지, 주기 셀의 보존/노름 감소, 작은 비영 감쇠다. 안내3개는 최대 온도와 최대 열유속 구별, 실제 창의 경계 방향, 현열과 노름의 다른 보존 성질을 다룬다. 퀴즈2개는 같은 열확산율의 물성과 열에너지/노름의 단위를 확인한다.

예제에는 손계산·전도도0·균일 온도·시간0·음의 대비·위상 이동·작은 비영 감쇠·언더플로·배율 결합의 회복·폭0·끝점 반올림 대조를 포함한다. 단원 노트에서 엔트로피나 미시적 열전달 모델까지 계산한 것으로 확장하지 않는다.

## Gaussian 물질 확산

예정 ID: `gaussian-fick-diffusion-spreading`. 입력10개는 총질량·단면적·초기 표준편차·초기 평균·이류 속도·확산계수·시간·질의 x·왼쪽/오른쪽 경계다. 경계 순서가 유효하지 않으면 창 관측만 계산 불가로 표시하고, 입력을 몰래 정렬하거나 전체 화면을 예외로 중단하지 않는다.

- 실제 농도·공간 미분·이류/확산/전체 플럭스를 분리한다. 로그 농도는1kg/m³ 기준이며 선형 농도와 다른 축으로 그린다.
- 현재·초기 농도와 평균 이동·분산 증가·봉우리 감소를 비교한다. 전체 질량kg와 유한 창 질량kg, 농도kg/m³를 나누어 표시한다. 관측 그림의 유한 범위를 실제 벽으로 해석하지 않는다.
- 실제 폭의 로그 구적과 유한 창 질량 변화율·방향 있는 경계 플럭스를 비교한다. 두 차수의 로그 적분 차이는 진단이며 엄밀한 상한이 아니다.
- 질량0이면 농도와 플럭스0을 유지하되 질량 정규화 평균·분산은 미정으로 둔다. 선언한 형상 중심과 실제 질량 모멘트를 다른 행으로 표시한다.
- 작은 분산·표준편차·봉우리 변화, 반올림된 같음, 먼 꼬리와 매우 얇은 창을 대조한다. 확률 적분이 언더플로해도 배율을 결합한 실제 질량이 표현 가능한 경우를 포함한다.

고정 개념4단계는 확산만 있는 대칭 퍼짐, 이류와 확산의 분리, 유한 창 수지, CDF 뺄셈이 잃는 꼬리다. 안내3개는 봉우리/폭/총질량, 유한 창의 출입, 작은 퍼짐과 꼬리 관측을 다룬다. 퀴즈2개는 분산 성장과 질량0의 미정 정규화 모멘트를 확인한다.

## 검증 후 완료 처리

원래488단원·안내와43개 실험 그룹479항목의 canonical 내용·상대 순서를 보존한다. 두 단원에 각각 고정 개념4단계·안내3개·퀴즈2개를 연결한다. 실제 최종 정적 출력의 한영·명암·모바일/데스크톱, 전체 예제·정밀 입력·저장·초기화·퀴즈·키보드·접근성·원본 그림과 경계 상태를 검증한 뒤에만 원래 주제 완료 수를 갱신한다.
