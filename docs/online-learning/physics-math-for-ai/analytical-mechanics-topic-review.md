# 해석역학 10개 원주제 연구 대조 진행

2026-11-12. 전체 **51영역·509주제**를 유지한다. 입문 집필 완료와 구분하여 기존 해석역학 **10주제·20단원**을 원래 순서대로 보강·대조한다. 새 연구 확장을 검증한 단원은 11개이며, 나머지 원고와 전체 영역의 최종 대조는 계속 진행한다.

## 원주제별 진행

|---|---|---|
| 일반화 좌표 | `polar-generalized-velocity-force-metric`, `double-pendulum-generalized-mass-metric` | 두 단원의 Hessian·좌표 불변 진동수 확장 검증 |
| 작용·정상 작용 | `free-particle-action-boundary-gauge`, `harmonic-action-stationary-saddle` | 끝점 비용·전체 Morse 지수·켤레 끝점 확장 검증 |
| Lagrange 방정식 | `polar-lagrange-newton-equivalence`, `double-pendulum-lagrange-dynamics` | 비이차 후보·질량 척도·보정 입력 확장 검증 |
| Hamiltonian·정준 변수 | `polar-hamiltonian-legendre-map`, `time-gauge-hamiltonian-energy` | 비선형 Legendre 역변환·시간 게이지의 원 감김 확장 검증 |

## 검증 근거와 한계

- [정준 동역학 세 단원 검증](canonical-research-status.md), [Lagrange 두 단원 검증](lagrange-research-status.md), [작용·정상 작용 두 단원 검증](action-research-status.md), [일반화 좌표 두 단원의 유도·실행·그림 검증](coordinate-research-status.md)과 [전역 작용 두 단원의 검증](analytical-topology-research-status.md)을 따로 기록한다. 기존 본문·연습 문제·안내·실습 입력을 보존한다.
- 현재 보강을 포함한 계산·렌더·원고 보존 선택 검사는 18파일·368개다. 이전 전역 작용 보강의 20단원·160화면 검증과 이번에 바뀐 두 단원의 화면 검증을 구분한다.
- 기존 [입문 감사](analytical-mechanics-domain-audit.md)는 당시의 근거로 남긴다. 이번 변경을 전체 20단원의 연구 깊이 최종 검토나 전체 저장소 CI 성공으로 바꾸어 부르지 않는다.

## 다음 순서

다음은 남은 4차원 symplectic 사상 단원에서 비선형 좌표·Jacobi 조건의 차원 의존성을 검토하고, 이어서 Noether 두 단원을 진행한다. 이미 보강한 그래프·시간 게이지의 내용을 반복 집필하기보다 관련 후속 단원과 연결한다.

원주제 심화의 최종 대조 수는 **39영역·386주제**이며, **12영역·123주제**가 남는다. 단원별 보강 진행을 전체 영역 완료로 집계하지 않는다.
