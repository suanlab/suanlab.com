# 장의 에너지·Poynting 흐름의 자료 대조와 독립 준비

2026-11-05. 유도·전자기파 다음 주제의 준비 기록이다. 이 자료·독립 탐색에 이어 [계산 모델과 상세 한영 원고 검증](poynting-energy-foundation.md)을 마쳤다. 이후 [단원 등록·화면 통합 검증](poynting-energy-authoring-status.md)을 마쳤다. 자료 준비 자체로 완료 수를 올리지는 않는다.

## 확인한 1차 자료

[Feynman Lectures II Chapter 27](https://www.feynmanlectures.caltech.edu/II_27.html)의 §27–2–27–3, 식27.5와27.14–27.15에서 장 에너지의 변화, 바깥 선속, J·E의 부호와 표준 에너지·Poynting 벡터 정의를 확인했다.

Haus·Melcher의 [Electromagnetic Fields and Energy, Chapter 11](https://ocw.mit.edu/courses/res-6-001-electromagnetic-fields-and-energy-spring-2008/0f814aee1c72517df7d7e7e96b7365e1_11.pdf), MIT OCW의 §11.1–11.4도 확인했다. 고정 부피의 적분·국소 수지, 저장·전달·소산, 물질 가정의 차이를 구분하는 근거로 사용한다. 열람일은2026-11-05다.

이번 교육 예제는 일정한 양의 ε·μ에서 u=εE²/2+B²/(2μ), S=E×B/μ, ∂tu+div S+J·E=0을 사용한다. 일반적인 분산·이력·움직이는 물질의 에너지를 이 간단한 식으로 모두 설명하지 않는다. 에너지 밀도 J/m³, 흐름 W/m², 일률 밀도 W/m³와 유한 부피의 W·J를 구분한다.

## 후보와 직접 유도한 예제

첫 예제는 Bz=b(t), E=(b′y/2,−b′x/2,0), J=−ε∂tE다. 직접 벡터곱으로 S=−bb′(x,y,0)/(2μ)를 얻는다. 전기 저장 변화 εb′b″r²/4와 J·E=−εb′b″r²/4가 상쇄하며 자기 저장 변화 bb′/μ는 div S=−bb′/μ와 맞는다.

반지름 R, 높이 h인 고정 원통의 전기 에너지는 επhR⁴b′²/16, 자기 에너지는 πR²hb²/(2μ)다. 바깥 전력은−πR²hbb′/μ, 내부 J·E 적분은−επhR⁴b′b″/8이다. 부호가 음수인 J·E는 이 지정한 원천이 장에 에너지를 공급하는 경우이며 무조건 저항 발열이라고 부르지 않는다. 유계 제조해는 외부 경계와 원천을 필요로 한다.

둘째 예제는 앞 펄스의 E=f+g, cB=f−g를 사용한다. 직접 제곱하면 u=ε(f²+g²), Sz=εc(f²−g²)이며 총 u와 S에서는 두 반대 진행 성분의 교차항이 상쇄한다. |S|≤cu이고 u>0일 때 S/u는 조건부 국소 에너지 흐름의 비율이다. 이 비율을 입자 속도나 정보 속도라고 동일시하지 않으며 u=0에서 정의하지 않는다.

Gaussian 초기 분할 비율 β에서 전체 z축 적분은 εA²σ√π[β²+(1−β)²]다. 이는 가로 단위 면적당 에너지로 전체3차원 유한 에너지가 아니다. 같은 초기 E여도 초기 B가 달라 에너지가 다를 수 있다. 유한 고정 slab는 양 끝의 S 차이와 내부 에너지 시간 변화를 비교한다.

## 실제 독립 탐색

`.runtime/learning/prepare-poynting-energy.py`는 제품 코드를 가져오지 않는다. 원천81조건에서 실제 E·E·B·B와 E×B를 계산하고 공간·시간5점 차분, 원통의 실제 방사형 부피 적분과 방향 있는 옆면 적분을 수행했다. 최대 관측 국소 차이는2.82×10⁻¹² 이하, 원통 수지 차이는2.13×10⁻¹¹ 이하다.

펄스54조건에서는 실제 장으로부터 u·S를 계산하고 국소 차분·유한 slab 적분·전체 z축 SciPy 적분을 비교했다. 최대 관측 slab 수지 차이는2.91×10⁻¹² 이하다. 선택한 정규화 계수·표본의 관측값이며 엄밀한 오차 상한이 아니다. 결과는 `.runtime/learning/poynting-energy-exploration.json`, 실제 종료는 `poynting-energy-preparation-exit.json`이다.

에너지 수지만으로 Maxwell 전체를 검증할 수 없다는 반례도 포함했다. 정적인 E=(0,x,0), B=J=0은 에너지 변화·Poynting 흐름·J·E가 모두0이지만 curl E z=1이므로 Faraday 법칙을 위반한다. 이 음성 대조를 물리적인 완전한 Maxwell 해로 표시하지 않는다.

추가180자리 mpmath 기준과 정규화 구적으로 얇은 slab9조건, 균형 펄스의 작은 비영 선속1조건, 절대 에너지의 언더플로3조건을 준비했다. 직접 원시함수 차감·제곱 차감의 상쇄와 비영 에너지의 표현 한계를 구분한다. 절대 에너지가 사용 불가일 때 모형으로부터 유도한 조건부 흐름 비율을 실제 부동소수점 관측값의 몫이라고 표시하지 않는다. 증거는 `.runtime/learning/poynting-energy-cancellation-preparation.json`, 실제 종료는 `poynting-energy-cancellation-preparation-exit.json`이다.

## 상세 집필과 시각화 순서

첫 단원은 물통의 저장량·경계 유입·배수에 대응하는 비유로 시작하되, 에너지 흐름은 벡터이며 물질의 이동과 같지 않음을 설명한다. 고정 원통의 바깥 법선을 먼저 그린 뒤 국소식의 각 항과 적분식의 단위를 연결한다. 기본 예제에서 전기 저장, 자기 저장, 경계 전력, 원천 일을 따로 계산하고, b″=0과 J를 제거한 음성 대조를 비교한다. 작은 전기 항을 읽을 수 있도록 성분별 축과 과학적 표기를 사용한다.

둘째 단원은 같은 초기 E에서 단방향·양방향 초기 B를 바꾸는 비교로 시작한다. E²와 B²의 간섭항을 펼쳐 쓴 다음 총 에너지에서의 상쇄를 유도한다. 공간별 전기·자기·전체 에너지, 부호 있는 S, 고정 slab의 두 경계와 누적 저장량을 차례대로 보여준다. 전체 축 적분은 가로 단위 면적당 값이라고 축·표·설명에 표시한다. 초기 B를 바꿀 때 초기 에너지도 바뀌므로 단순히 같은 에너지를 재분배한 실험으로 설명하지 않는다.

각 단원은 직관 → 가정·단위 → 수식 유도 → 수치 대입 → 조작 예제 → 실패 반례 → 풀이 문제 순서로 한영 원고를 작성한다. 풀이에는 원천 일의 부호, 고정 부피 수지, 초기 조건과 에너지, 균형 펄스의 흐름, 표현 손실과 정확한0의 구분을 포함한다. 구체적인 입력 범위와 그림 수는 제품 수치 계약을 확정한 뒤 결정한다. 상세 한영 원고는 이후 작성했으며 화면·등록 완료 단원으로는 아직 집계하지 않는다.
