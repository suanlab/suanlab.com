# 사차 적분과 발산 점근급수: 학습 화면 검증

2026-11-10. `quartic-integral-asymptotic-truncation`의 한영 학습 화면을 준비했다. 실제 Interactive Book 등록과 생산 Next.js 자산 검증은 다음 단계다.

## 학습 내용과 시각화

- 한영 원고 각 18절·12표시 수식·8해설 문제에 개념 8개, 안내 실험 6개, 해설 퀴즈 8개와 예제 14개를 연결했다.
- 가우스 모멘트, 발산 급수와 점근 전개, 부호 있는 나머지, 최소 상계 차수와 차수 예산의 차이를 설명한다.
- 적분 핵의 2D 곡선·로그 높이·Three.js 곡면과 부분합·항 크기·나머지 상계·오차 구간을 표시한다. 큰 부분합에는 부호 보존 로그 척도를 제공한다.
- 수치 적분 구간, 점근 나머지 구간과 두 구간의 교집합을 출처별로 구분한다. 수치 정밀도로 구별되지 않는 오차는 정확한 0으로 단정하지 않는다.
- 결합상수 0에서는 3D 결합상수 축을 한 평면으로 접는다. 양수에서 기존 축 대응은 유지한다.
- 분수 입력·차수 선택·저장 복원·재생·취소·오류 복구·WebGL 재시도와 키보드/터치 조작을 제공한다.

## 검증 근거

관련 테스트 117개(학습 화면 신규 8개)를 통과했다. 한영·명암·320/1440px 8조합에서 예제 112회, 개념 64회, 안내 48회, 퀴즈 64회를 확인했다. 저장 오류 5상황과 최대 입력 1흐름, 결합상수 0의 추가 한영 2상태를 포함해 접근성 검사 24회를 통과했다.

최대 입력에서 모바일 터치·재생의 비재계산·취소/오류 후 재시도를 확인했다. 저장/최대 흐름의 Worker 16개와 추가 0축 흐름의 12개가 종료됐다. 기본 화면 검사의 Worker 32개 종료 수치는 **마지막 새로고침 이후만** 집계하며, 앞선 준비 상태에서도 활성 Worker 0을 확인했다. 0축 수정 뒤에는 해당 분기를 별도 검사했으며 양수 축 대응은 단위 검사로 확인했다.

실행 기록은 `.runtime/learning/quartic-asymptotic-teaching/`의 `tests.log`, `teaching-tests.log`, `native-verification.json`, `storage-maximum.json`, `zero-axis.json`에 있다. 타입·lint 결과와 소스/출력 보존 검사는 같은 디렉터리에 기록한다.
