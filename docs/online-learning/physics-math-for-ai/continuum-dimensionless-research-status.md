# 무차원 수 연구 보강 검증 기록

2026-11-13. [설계](continuum-dimensionless-research-plan.md)에 따라 격자 Peclet과 Robin 공급 저항을 기존 두 단원에 추가했다. 한영 원고 4편·그림 4개, 표시 수식 40개·실행 표 4개·연구 해설 12개를 연결했다. 연구 절을 제거하면 기존 본문 4편과 풀이 24개가 원래 해시로 복원된다. 기존 해석적 실습의 제어와 등록 순서는 유지했다.

## 추가한 설명

- **Peclet:** 물리 Pe·부호 있는 셀 p·기존 격자 Pe를 구분한다. 중심 차분의 음의 절점, p = ±2의 영 계수, 상류 차분의 번짐과 Bernoulli 적합 플럭스를 비교한다. 정상 상수 계수의 절점 정확성을 미해상 미분·비정상·변계수의 인증으로 확대하지 않는다.
- **Damkohler:** 유한 외부 공급에서 실제 표면 농도·Biot 수·전체 반응률·효과도를 유도한다. 공급 상한·화학 민감도·같은 반응률의 양의 역문제 쌍·두 무차원수를 보존하는 닮음을 설명한다. 공급·반응이 모두 영인 경우의 비유일 정상 농도를 보존한다.
