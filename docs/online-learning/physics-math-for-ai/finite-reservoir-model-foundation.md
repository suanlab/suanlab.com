# 유한 저장고 모델 검증 현황

2026-11-06. 앙상블 첫 가족 `finite-binary-reservoir-canonical-comparison`의 계산 기반을 작성했다. **본문·시각화·실험·퀴즈 및 홈페이지 등록은 미완료**다. 등록 단원 512개나 원래 주제 완료 수를 추가로 늘리지 않는다.

## 구현

`src/lib/learning-finite-reservoir.ts`는 고정 총여기 수의 균등 이진 껍질에서 부분계의 정확한 주변 분포와, 같은 점유 평균을 갖는 정준 이항 분포를 별도로 반환한다. 계수·정규화·모멘트·전체변동거리는 BigInt로 계산한다. 기존 이진 다중도 행과 범위 밖 양수의 로그 표현을 재사용한다.

정보량은 양의 항으로 계산하며 근접 분포의 KL에서 큰 수를 빼지 않는다. 확률은 먼저 반올림하지 않고, 초월함수가 들어간 정보량의 항만 기존 192유효비트 산술로 근사한다. 정확한 0·유한 정보량·무한대 KL·선형 표시 범위 밖 양수를 구분한다. 전체 4096자리 한도는 계산 자원 제한이며 열역학 극한을 뜻하지 않는다.

## 검증

`npx tsx --test scripts/learning-finite-reservoir.test.ts`의 32개 테스트가 통과했다. Python Fraction/Decimal 독립 기준 26개 중 작은 계 18개는 실제 고정-K 배치도 열거했다. 기준값 재생성은 바이트 단위로 일치했다.

검사는 모든 상태의 계수와 두 확률법칙, 평균·분산·TV·엔트로피·양방향 KL을 비교한다. 같은 평균과 다른 요동, 저장고 증가의 오차 수열, 빈 부분계·빈 저장고·단일 자리·확정 준비, 잘못된 입력을 포함한다. 4096자리의 점질량 준비와 극소 정준 확률도 별도로 확인했다. 린트와 타입 검사를 통과했다.
