# 복합물리 연구 보강 설계

2026-11-13. 기존 열탄성·열전 단원의 한영 원문을 읽고 같은 물리 가정에서 연구 질문을 확장한다. 원래 본문 4편·풀이 24개와 실습 제어를 보존한다.

## 열탄성: 소산과 완전 이완의 차이

세 상태의 특성 삼차식과 Hurwitz 조건을 유도한다. 양의 전도·비영 상호 결합이 모두 필요함을 불변 집합으로 설명한다. 영 전도는 정지 방향과 지속 진동, 영 결합은 역학 진동을 남긴다. 단열 사영을 수렴으로 소개하지 않는다.

작은/큰 전도에서 고유근 점근식과 스펙트럼 이완률을 비교한다. 매우 빠른 열 이완이 역학 감쇠까지 항상 빠르게 만들지는 않는다. 비정규 행렬의 점근 고유률과 유한 시간 좌표 기울기를 구분한다. Y-star는 기존 변형률 기호와 구별한 작은 에너지 좌표 척도다.

## 열전: 다른 부하, 다른 최적화 목적

원래 오른쪽 고온·왼쪽 저온 포트 부호를 유지하고 수동 저항 부하에서 전류를 결정한다. 최대 출력의 저항 일치와 최대 효율의 다른 부하를 유도한다. 실제 고온 열·저온 열과 엔트로피 생성 적분을 대조한다.

개방회로의 전도 열과 영 효율, 단락의 영 유용 출력, 영 온도차에서 정의되지 않는 효율을 분리한다. 고정 저장소·상수 물성·이상적 단일 막대와 반환 기준의 결과이며 실제 제품의 성능으로 확대하지 않는다.

## 검증과 완료 기준

한영 수식 40개·실행 표 4개·연구 해설 12개·그림 4개를 대조한다. 연구 절을 제거하여 원래 본문 해시를 복원한다. 정확 유리수 특성식·열 포트, 별도 Taylor/RK4 시간 적분과 물리 좌표 엔트로피 구적을 확인한다. 실제 새 빌드에서 한영 16화면·실습·저장·접근성과 최종 모바일 그림을 검토한다.

설계 시점 순차 보강은 16/22단원이었다. 관련 143검사·새 빌드·16화면 검증 후 현재 18/22단원이며 [검증 기록](continuum-multiphysics-research-status.md)에 근거를 연결했다. 전체 영역 연구 감사는 별도이며 42영역·415주제 대조 / 9영역·94주제 후속과 교육과정 미완료를 유지한다.
