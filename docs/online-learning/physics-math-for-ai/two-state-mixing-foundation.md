## 정확한 유한 계약

`src/lib/learning-two-state-mixing.ts`는 P=[[1−a,a],[b,1−b]]에서 a=A/D,b=B/D와 별도 초기 확률 u=U/V를 받는다. 분모는1..1,000,000, 분자는0..각 분모의 정수이며 전이 횟수는0..512다. 입력을 변경하지 않고 지정한 필드만 동결하여 반환한다. 비유한 값·비정수·영 분모·확률 범위 밖·잘못된 기록 범위를 거부한다.

BigInt 정수 질량의 행렬 갱신과 별도 아핀 재귀 닫힌식을 계산한다. 각 시점의 확률·부호 편차·총변동·최악 초기 거리·양방향 흐름·순흐름과 초기 분포를 포함한 Cesaro 평균을 제공한다. 모든 관측은 정확한 유리수 점이며 소수와 크기 로그는 표시 투영이다. 비영 표시 범위 밖의 오차를0으로 바꾸지 않는다.

## 경계와 관측 의미

- a=b=0: 모든 분포가 정상이다. 유일 참조·참조 거리·참조 분산을 만들지 않지만, 각 초기 준비의 점별 극한과 평균 극한은 초기 분포다.
- a=b=1: 유일한 균일 정상법칙·상세평형을 갖지만 비정상 초기 분포는 교대한다. 균일 초기화만 점별로 일정하며 최악 초기 혼합은 실패한다. 분포의 Cesaro 평균은 별도 극한을 가진다.
- 한 방향만 양수: 가약적이어도 유일한 흡수 정상법칙과 모든 초기화에서의 수렴이 가능하다. 정상 확률0의 역전이 행은 미제공이다. 귀환이 불가능한 일시적 상태의 주기는null이다.
- 정상 지시변수 분산·한 지연 공분산과 상관을 구별한다. 흡수 법칙의 분산·공분산은0이지만 정규화 상관은 미제공이다. 행렬 고유값을 무조건 관측 상관이라고 부르지 않는다.
- signed gap=1−λ와 absolute gap=1−|λ|를 별도로 제공한다. 교대 끝점은 앞의 gap이2여도 절대 수축이 없다.

1/4 기준은 선택 초기화가 아니라 최악 초기 거리로 판정한다. 정확한 분수로 등호를 포함해 최초 도달을 확인하며, 유한 기록 구간의 미도달·주기적 영구 미도달·유일 참조 부재를 구별한다. 확률 분포를 평균한 값은 경험적 점유 비율의 기댓값이며, 경로 표본의 분산·신뢰구간·유효 표본 수가 아니다.

## 본문과 증거

한영 각각16절·16수식·표3개·해설 문제6개다. 두 방의 직관, 정상 방정식과 고유값, 정확한 재귀, 통신·흡수·교대·항등, 선택 초기 거리와 최악 초기 거리, 두 gap, 평균 시계, 정상 지지집합과 표시 범위 아래의 오차를 설명한다. 일반 개념은 [저자 교재](https://pages.uoregon.edu/dlevin/MARKOV/markovmixing.pdf)와 대조하고 구체적인 유한 계산은 직접 유도했다. [유도 노트](two-state-mixing-derivation-notes.md)에 경계와 식을 정리했다.

새 모델45개·본문6개, 관련 회귀190개가 통과했다. 독립 Python `Fraction` 기준30설정의294선택 시점과 고정 관측, 총4,549개의 정확한 관측을 분자·분모·부호·소수 투영으로 대조했다. 전체4,033시점에서는 정규화·닫힌식·흐름 증가량과, 참조가 있는 경우 총변동 수축을 별도로 검사한다. 직접 기준과 모든 관측을 전수 대조했다고 주장하지 않는다.

기준은2×2 행렬 거듭제곱에서 분포와 최악 초기 거리를 계산하고, 아핀 닫힌식과 Cesaro 기하급수 합을 대조한다. 작은 준비의 경로 열거는214개 도착 확률 비교를 준다. 별도270설정은 분모1..5의 모든 전이 분자 쌍과 초기 확률0,1/2,1을 검사한다. 이는1,000,000까지의 전체 범위를 전수 검사한 것이 아니다.

기준 바이트 재생성·lint·타입 검사와 기존4,216소스·4,280정적 출력 보존을 확인했다. 이번241개 준비/관련 검사와 직전 등록의 전체8,005검사·빌드는 범위가 다르다. 이번에는 전체 테스트·빌드·브라우저 등록 검사를 다시 실행하지 않았다. 근거는 `.runtime/learning/two-state-mixing/verification.json`과 같은 폴더의 검사 기록이다.
