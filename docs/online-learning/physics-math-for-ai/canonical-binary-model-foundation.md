# 정준 이진 에너지 요동 모델 검증 현황

2026-11-06. `canonical-binary-energy-fluctuations`의 계산 모델과 독립 기준값을 작성했다. **상세 한영 원고·대표 그림·개념·실험·퀴즈 및 홈페이지 등록은 미완료**다.

## 계산 내용

`src/lib/learning-canonical-binary.ts`는 이름 있는 이진 자리 n개에 대해 전체 여기 수 분포, 정확한 배치 다중도, 평균·분산, 에너지·에너지 분산, 엔트로피·열용량, log Z와 상대 요동을 반환한다. 내부 `learning-binomial-logit.ts`는 부호 있는 로그 오즈의 공통 계산을 담당한다.

유한한 양의 온도와, 상한이 있는 이 스펙트럼의 음의 온도를 지원한다. T=0 입력은 양의 쪽에서 접근한 평형 극한으로 정의한다. 정확한 ε=0에서는 균등 준비와 잔류 엔트로피를 보존한다. n=0이나 평균 에너지가 0일 때 상대 요동은 정의하지 않는다. 유도·단위·극한은 `canonical-binary-derivation-notes.md`에 기록했다.

## 수치와 검증

유한 온도의 양의 확률을 표시 범위 밖 0으로 바꾸지 않는다. 첫 로그도 범위 밖이면 둘째 로그의 가용성을 별도로 표시한다. 표시 확률이 사라져도 물리적 에너지·분산에는 나타나는 경우를 검사했다. 단위값에 가까운 모멘트의 중첩 로그는 꼬리와 같은 정확도로 인증한 값이 아니며 동일성 증명에 사용하지 않는다.

Python 독립 기준값은 38개다. 직접 분포 합·모멘트와, 거대한 지수의 별도 로그 경계를 사용한다. 작업 정밀도를 늘려 재계산하며 최대 1416자리까지 사용했다. 구현의 꼬리 전환점 4096을 넘어 10000까지 직접 계산한다. 기준 파일 재생성은 바이트 단위로 일치했다.

`learning-canonical-binary.test.ts`의 47개 검사와 기존 수치 모듈을 함께 실행한 **280개 검사 모두 통과**했다. 양·음 온도의 반사 관계, 온도 미분과 요동 응답, 4096자리 분포, 물리 입력의 양 끝 범위, 실제 0·작은 양수·로그 가용성·직렬화를 검사했다. 타입 검사와 변경 파일 린트도 통과했다.

## 남은 순서

정준 요동의 상세 한영 본문·풀이를 작성하고, 입자 교환 가족의 계산과 본문을 준비한다. 세 가족의 교육 UI와 실제 읽기 화면을 연결·검증한 후에만 등록 단원과 원래 주제 완료 수를 갱신한다. 현재는 512단원·1536안내, 입문 검증 283주제·미완료 79주제를 유지한다. 새 홈페이지 빌드·배포는 하지 않았다.

근거는 `.runtime/learning/canonical-binary-model-verification.json`, 재생성 도구는 `scripts/learning/generate-canonical-binary-references.py`, 독립 기준은 `scripts/fixtures/canonical-binary-independent.json`이다. 이번 계산 기반은 전체 앙상블 이론이나 교육과정의 완료를 뜻하지 않는다.
