## 모델과 계산 원칙

`src/lib/learning-wave-equation.ts`는 클라이언트에서 사용할 수 있는 순수 TypeScript 모델이다. Node API나 교재 데이터에 의존하지 않는다.

- `periodicWaveChain`: 선밀도μ·장력τ·길이L을 고정하고 입자 수N을 바꾼다. 실제 m=μa, κ=τ/a를 사용한다. 서로 다른 초기 위치·속도 Fourier 성분을 격자/연속체 고유진동수로 각각 진화시킨다. 영모드는 선형 병진이며 임의로 제거하지 않는다.
- 해상 조건은 정수 모드0≤n<N/2다. Nyquist·중복·해상 불가·성긴 배열을 거부한다. N은8·16·32·64·128, 시간0–64 s다. 물리 가정과 계산 지원 범위는 별개다.
- 사슬의 실제 에너지는 질량 운동에너지와 각 주기 링크 에너지의 합이다. 양쪽 링크 절반을 입자에 배분하고 힘으로 계산한 배분 에너지 미분을 독립 링크 흐름 차와 비교한다.
- `wavePulsePoint`: 초기 변위와 초기속도를 각각 올바른 대칭으로 연장한다. 왼쪽 진행 조건 g=cf′가 양의 반직선에서 성립해도 연장 f의 도함수로 연장 g를 대신하지 않는다. 반사상은 물리 영역 밖의 계산 장치다.
- `wavePulseEnergyBalance`: 공간 에너지 적분과 두 경계의 시간 흐름 적분을 따로 계산한다. 이동하는 유한 지지 경계에서 구간을 나누면 각 에너지/흐름은 최대12차 다항식이다. 8점 Gauss–Legendre는15차까지 실수 산술에서 정확하다. 부동소수점 잔차는 표시한다. 그림용 표본으로 적분하지 않는다.
- 변위 평탄부와 에너지 전면을 구분한다. 전체 에너지 보존과 유한 관측 구간의 에너지 변화도 구분한다. 초기 기울기 지표를 모든 시각의 선형 물리 타당성 보장으로 사용하지 않는다.

## 독립 기준값

`scripts/learning/generate-wave-equation-references.py`는 제품 코드를 불러오지 않는다. 출력은 `scripts/fixtures/wave-equation-independent.json`이다.

사슬24개 계·120개 시점은 순환 강성 행렬의 실제 상태 행렬지수로 계산하고 별도 DOP853 적분과 대조했다. 연속체는 초기 표본의 별도 FFT 전파와 물리 에너지의 주기 사다리꼴/Parseval 합으로 계산해 궤적·기울기·에너지·격자 오차를 대조한다. 국소 파형27개 계·648개 위치/시점은 독립 Polynomial 도함수와 양·음의 위치에 둔 반사상 소스로 만들었다. 변위의 속도 적분은 실제 SciPy quad, 에너지 공간 적분과 흐름 시간 적분은 각각의 지지 경계로 나눈 QUADPACK으로 구했다. 별도108개 구간 수지를 대조한다. SymPy로 일반 양방향 해의 PDE와 국소 에너지 보존 항등식을 확인했다.

전용 테스트는 `scripts/learning-wave-equation.test.ts`다. 실제 계산 대조 외에 동일 재료의 이차 수렴, 영모드·초기속도·운동량, 실제 힘과 가속도, 각 링크의 에너지 수지, 유한 전파, 속도만 준 평탄부, 비영 초기속도의 고정단/자유단 경계, 반사 부호와 오른쪽 흐름, 국소 PDE·보존의 차분 검사, 영시간·영입력·잘못된 자료를 검사한다. 네 원고는 실제 로더의 엄격한 KaTeX와 한영 목차·해설 문제로 검사한다.

## 화면 연결 때 유지할 구분

첫 단원에서는 실제 이산 입자·보간선·연속체 평가점을 구분하고, 같은 재료의 N 변경과 그림 해상도 변경을 별도 의미로 표시한다. 초기 변위에 없는 초기속도 모드와 영모드 병진을 안내 실험에 포함한다. 낮은 모드와 해상 한계 근처 모드의 차이도 보여 준다.

둘째 단원에서는 실제 반직선만 물리 영역으로 표시하고 전체 직선 연장은 구성 설명에 한정한다. 순수 진행파뿐 아니라 독립 속도 입력이 있는 반사, 속도만 준 평탄부, 관측 창에서 빠져나가는 에너지를 확인한다. 양쪽 경계 흐름의 부호와 누적 전달을 표시하며 전체 에너지와 창 에너지를 한 값으로 합치지 않는다.
