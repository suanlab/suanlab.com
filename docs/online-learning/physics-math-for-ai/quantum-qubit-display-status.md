# Quantum circuit·channel: certified display arithmetic

2026-11-09. [네 단원의 학습 준비](quantum-qubit-authoring-status.md)에 이어 시각화에 필요한 정확 수치→좌표 변환과 밀도행렬 관측값을 구현했다. **아직 기존 Worker 응답·학습 화면에 연결하지 않았으며 등록0/4이다.**

## 구현한 계산

- `learning-qubit-display.ts`: 정확한 `a+b√2`를 폭이 최대 `2^-40`인 dyadic 구간으로 변환한다. 양 끝점과 중점은 JavaScript로 정확히 표현되는 수이며, 정확한 부호·격자점 일치 여부를 별도로 보존한다. 두 계수를 각각 Number로 변환해 더하지 않는다.
- 시각화 범위를 벗어나면 좌표를 `null`로 반환한다. 허용 범위는 ±1부터 ±1024까지 2의 거듭제곱으로 정하며, 값을 경계에 강제로 붙이지 않는다. 극소 비영 값의 구간에0이 포함되어도 정확한0이라고 표시하지 않는다. 구간 중점은 표시용 근사값이지 원래 값의 정확 표현이 아니다.
- `learning-qubit-density-display.ts`: 2×2/4×4 행렬의 Hermitian·PSD·단위 trace를 확인하고 유효한 상태에만 정확 순도와 표시 구간을 제공한다. 한 큐비트에는 X/Y/Z Bloch 관측값을 추가한다. 두 큐비트 결합 상태를 하나의 Bloch 벡터로 표현하지 않는다.
- 비물리적 선형 출력·정규화되지 않은 갈래·확률0의 영행렬에는 상태 순도/Bloch를 제공하지 않는다. 자동 정규화도 하지 않는다. 실제 수업에서는 원래 행렬과 실패 조건을 별도로 보여줘야 한다.

각 생산기와 분리된 검증기를 추가했다. 좌표 검증기는 정수 부등식으로 끝점 포함·인접 격자·부호·범위·중점을 확인한다. 밀도행렬 검증기는 기존 독립 Schur PSD와 지표별 수축으로 순도·Pauli 기댓값을 확인한다. 이 함수들은 Worker/CLI 전용이며, 검증기의 입력은 소유권 복사를 마친 값이어야 한다.

## 검증 근거

- Python 정수 제곱근으로 √2의 유리수 구간을 좁히는 독립 참조82개: 경계·범위 밖·음수·`10^-500`·1200단계 Pell 상쇄 포함. 생성기와 제품의 계산 방법이 다르다.
- 기존595독립 보고서의 실수 성분 **126,476개**를 변환하고 별도 검증했다.
- 보고서 속 **4,991개** 2×2/4×4 후보 행렬을 검사했다. 수학적으로 상태 조건을 만족하는3,099개와 나머지1,892개에 대해 판정·순도·Bloch·변조 거부를 확인했다. 연산자 행렬도 포함하는 검사이며, 이 숫자는 실제 화면의 상태 패널 수를 뜻하지 않는다.
- 새93검사와 기존 Worker/컨트롤러/학습 준비678회귀 검사, TypeScript와 변경 파일 lint 통과. 독립 참조의 재생성 해시도 확인했다.

근거: `.runtime/learning/quantum-qubit-display/verification.json`, 검사 로그와 소스/근거 해시. 기존 등록571단원·1713안내, 입문309/362검증·53미완료는 유지한다.
