## 독자가 따라갈 질문

양자 변분 원리는 어느 상태의 에너지를 비교할지 설명했다. 다음에는 여러 입자와 모드에서 상태 공간이 왜 커지는지, 물리적 상호작용은 어떻게 적는지, 통계에 따라 연산자가 왜 달라지는지, 텐서 네트워크가 어떤 구조를 보존하거나 버리는지 배운다. 물리적 Hilbert 공간, 좌표 표현, 근사 집합, 수축 알고리즘과 최적화 알고리즘을 구별한다.

MPS와 DMRG의 관계는 [Schollwöck의 리뷰](https://arxiv.org/abs/1008.3477)를, MPS·PEPS를 연결하는 도식과 차원별 방법의 배경은 [Orús의 입문 리뷰](https://arxiv.org/abs/1306.2164)를 기준 자료로 삼는다. 논문의 흐름을 그대로 옮기지 않고 아래의 손계산·반례·코드 실험으로 설명을 구성한다. Jordan–Wigner의 연산자 부호 convention은 [Google Quantum AI의 공식 설명](https://quantumai.google/openfermion/tutorials/jordan_wigner_and_bravyi_kitaev_transforms)과 대조한다. 외부 라이브러리를 설치하거나 호출하는 실습으로 교체하지 않는다.

| 4. `matrix-product-state-contraction-gauge` | 물리/가상 색인, 열린 MPS, 수축, 환경, gauge 자유도, 정규형의 역할, 표현 비용 | 1…4개 qubit·가상 차원 1…4의 일반 복소 유리수 텐서를 실제 수축해 모든 진폭·노름·국소 관측을 대조. 한 bond의 가역 scale/shear와 역변환을 이웃 텐서에 적용. 매개변수 길이가 바뀌어도 물리 상태가 같은지 확인. |
| 5. `schmidt-cuts-bond-rank-truncation` | cut별 Schmidt rank, bond 차원의 하한, 가중치·얽힘, 최적 저랭크 오차, 절단/재정규화와 fidelity, 축퇴의 비유일성 | 2…4개 qubit의 모든 연속 cut을 비교. 작은 쪽 reduced matrix의 차원은 최대 4지만 어느 쪽을 계산했는지 기록한다. 최적 오차와 특정 절단 상태의 선택을 구별하고, 축퇴를 가르는 임의의 고유벡터를 몰래 반환하지 않는다. |

이론은 일반 입자 수와 임의의 cut을 설명한다. 작은 계산기에서 확인한 사례를 열역학적 극한·임의 차원·모든 Hamiltonian의 증명으로 일반화하지 않는다. 각 수치 범위는 실험의 유효 범위이며 교육과정의 분량 제한이 아니다. DMRG 최적화, 보존 대칭, MPO, 임계/비임계 얽힘, PEPS·MERA, 실제 물질·학습 모델 연결과 수렴·복잡도 주장은 뒤의 연구 심화에서 별도로 유도하고 검증한다.

## 표기와 모델에서 먼저 고정할 것

- `|n₀ n₁ …〉`의 n₀를 최상위 비트로 하고 오른쪽 연산자를 먼저 적용한다. 정수 색인·텐서 색인·기저 순서 변환을 그림과 표로 함께 준다.
- spin 계산은 Pauli 행렬을 쓴다. 물리적 S=ℏσ/2와 계수의 차이를 명시한다. 그래프의 bond는 중복 없는 무방향 변으로 정한다. 두 site의 ring에서 같은 bond를 자동으로 두 번 세지 않는다.
- 모든 자유 상태는 비영이어야 한다. 각각의 텐서가 비영이어도 전체 MPS 수축은 영벡터일 수 있다. 이를 다른 상태로 보정하지 않고 물리 상태의 정의 조건 실패로 처리한다.
- 물리적 오른쪽 reduced matrix는 계수 배열 C에 대해 CᵀC*다. C†C와 고유값이 같다는 사실로 같은 밀도 행렬이라 판단하지 않는다. 복소 위상·국소 Y 관측 반례로 검사한다.
- Schmidt 가중치를 pᵢ로 적고 버린 가중치 ε를 정의한다. 최적 **비정규화** rank 절단의 제곱 오차 ε, 재정규화 상태의 fidelity 제곱 1−ε와 거리 제곱 2(1−√(1−ε))를 같은 양으로 표시하지 않는다.
- 축퇴한 cutoff를 가르면 최적 오차 값은 유일할 수 있어도 최적 projector/상태는 유일하지 않다. rank를 선택할 수 없다고 오차까지 정의 불가로 만들거나, 임의의 고유벡터를 유일한 답으로 그리지 않는다.
- 초기 boson 수치 계약은 작은 cutoff에서 정확 대수적 계수를 유지한다. coherent builder는 별도 매개변수 계약과 tail 인증을 먼저 확정한다. 초기 계획은 0≤μ≤16이며, 이 범위를 유리수 입력에서 정확 검사하고 이론적 coherent 상태의 범위와 혼동하지 않는다.

## 먼저 검산한 기준 사례

`scripts/learning/generate-quantum-many-body-hand-checks.py`는 production 코드 없이 SymPy 행렬로 다음을 검산한다. 결과는 `.runtime/learning/quantum-variational-integration/next-topic-hand-check.json`이다.

1. **4-spin GHZ와 열린 Ising+횡장:** H=−ΣZᵢZᵢ₊₁−(1/2)ΣXᵢ, 원시 상태 |0000〉+|1111〉에서 N=2, E=−3, Var=1, 연결 ZZ 상관=1. 바닥 상태라고 주장하지 않는다. 별도의 반강자성 삼각형은 에너지 −1 여섯 개와 3 두 개를 갖는다.
2. **두 fermion 모드:** 모든 CAR를 검사하고 생성 순서를 뒤집으면 |11〉의 부호가 반대임을 확인한다. parity를 버리면 잘못된 반교환자의 Frobenius 제곱이 4다. 단위 hopping의 스펙트럼은 −1,0,0,1이며 입자 수 연산자와 교환한다.
3. **boson cutoff 3:** [a,a†]=diag(1,1,1,−3), trace=0이다. (|0〉+|3〉)/√2에서 기대값은 −1로, 무한 공간의 CCR 값 1과 다르다. 경계 점유를 숨긴 재정규화로 이 차이를 지우지 않는다.
4. **3-site GHZ MPS와 gauge:** 가상 차원 2의 실제 텐서 곱과 G=[[2,1],[0,1]]를 검사한다. 원시 상태 노름 제곱은 2로 같지만 텐서 매개변수의 제곱 길이는 6에서 19/2로 변한다.
5. **4-site 중간 cut:** 계수 배열 diag(3,2,1,0)의 가중치는 9/14,4/14,1/14,0이다. rank 2의 버린 가중치는 1/14, 재정규화 fidelity 제곱은 13/14다. GHZ의 rank 1 절단은 오차 제곱 1/2를 공유하는 서로 다른 최적 상태를 갖는다.
6. **복소 partial trace의 방향:** C=[[1,i],[0,0]]에서 물리적 오른쪽 밀도 행렬의 Y 기대는 +1이고 C†C를 잘못 쓰면 −1이다. 같은 스펙트럼만 검사하는 테스트로는 이 오류를 발견할 수 없다.

## 구현·집필·통합 관문

각 단원은 가정→기저/색인→유도→계산 표→직관→일반 대학원생용 예제→실패 반례→AI 연결→해설 연습 순으로 상세 한영 원고를 작성한다. 새 기호는 첫 사용에서 정의하고, 도식·변수의 물리 의미와 계산 범위를 같이 설명한다. 설명 없는 식 나열이나 같은 템플릿의 제목 치환으로 대체하지 않는다.

수치 모델마다 독립 고정밀 기준과 정확 항등식, 복소·축퇴·영 수축·경계·차원·역변환·부호·단위 검사를 먼저 마련한다. 그 뒤 snapshot/입력/Worker/취소·교체/결과 인증, 고정 개념 비교·자유 실험·세 안내·예측·해설 퀴즈·저장을 연결한다. Three.js는 site·bond·cut·수축 순서를 설명하며 자동 재생을 실제 물리적 시간으로 표현하지 않는다. 전체 진폭과 수치 근거를 접근 가능한 2D/표에서도 제공한다.

기존 홈페이지 색·명암과 **도서 → Interactive Book** 메뉴를 유지한다. 한영·작은 화면·키보드/터치·모션·실패 복구를 실제 화면에서 검증한 다음 등록한다. 등록 후 실제 reader·정적 빌드·생산 Worker/3D 자산·기존 단원 보존을 다시 확인한다. 다섯 단원의 필수 범위가 갖춰져야 이 원주제의 입문 완료를 검토하며, 전체 교육과정과 연구 깊이의 완료는 별도 관문이다.
