# 정준 그래프·Gauss 제약의 한영 학습 화면

2026-11-10. `graph-gauss-constraints-physical-phase-space`의 한영 학습 화면을 작성하고 실제 브라우저에서 확인했다. [독립 계산·응답 검증과 Worker](graph-gauss-worker-status.md)에 이어 진행했다. **실제 Interactive Book reader 등록과 Next 생산 자산 검증은 아직 남아 있다.**

## 학습 내용과 조작

- 10개 개념 단계·7개 안내 실험·8개 해설 퀴즈와17개 예제를 연결했다. 안내 실험이 모든 예제를 포함하고 정답 위치도 분산했다.
- 전하 조건의 해 존재와 현재 입력의 Gauss허용 여부를 구분한다. 독립 rank·배치 몫 좌표 수·물리 차원을 별도로 표시하며,빈 전하 수준집합은 차원0과 구분한다.
- 원래/고정 링크와 입력/올림 전기장을 바꾸는 Three.js그림과2D대체 그림을 제공한다. 공통 전기 척도에서 부호 있는 흐름과 링크 위상,앵커·계산 루트·숲·선택 경로를 구분한다. 올림값을 게이지 동치나 최소거리 투영으로 부르지 않는다.
- 노드 발산과 목표 전하의 공통 척도 그림,성분별 경계 수지,정준 위상 복소평면과 정확한 경로·전기 분해·Poisson괄호·에너지·순간 미분 표를 제공한다. 앵커의null은 목표 미부과이며 그림은 시간 적분이 아니다.
- 그래프·분수 위상·전기 변수·전하·계수·숲/루트/앵커·명시한 퍼텐셜 경로를 직접 편집하고 저장한다. 잘못된 입력은 적용하지 않고 이전 결과의 귀속을 알린다. 저장 불능에도 실험은 계속된다.
- 키보드·터치 시점,WebGL손실의2D전환/재시도,명암 테마,개념 전환 효과 끄기와 reduced-motion설정을 지원한다. 표시 선택은 계산 Worker를 새로 만들지 않는다.

## 실제 확인

- 새8검사와 기존 기반/응답/controller검사를 합친 **273검사** 통과.17예제와 최대5입력의 편집·저장 왕복,잘못된 형식/경계 조건/경로,공통 척도와 부호,32평행·역방향·자기 루프,안내 범위와 번들 분리를 검사했다.
- 한영×명암×320/1440px의 **8조합**에서17예제의 판정·rank·물리 차원·에너지,10개념·7안내·8퀴즈를 확인했다. 전기 입력·잘못된 숲 거부·새로고침 복원,표시 선택의 Worker비생성,3D키보드·WebGL복구·2D/3D전환을 검사했다. 접근성16회·영어 한글 미노출·페이지 가로 넘침 검사를 통과하고368Worker를 종료했다.
- 저장 오류5종과접근성5회에서20Worker를 종료했다. 모바일 한영2흐름에서분수 전하/전기 입력,H=23/9·역방향 퍼텐셜의14/9,비불변 경로 거부,빈 그래프,모션 토글·테마·터치 시점을 확인하고24Worker를 종료했다.
- 가장 큰12노드32간선·18자리분수·8경로각32단계를320px화면에 저장 복원했다. 물리 차원42,계산 후 입력 수정과표시 전환·3D·가로 넘침 없음·접근성1회를 확인했다. 두 Worker를 생성/종료했고 표시 선택은 재계산하지 않았다. 총 접근성 검사는 **22회**다.
- 최대 입력의 긴 분수 표가 페이지를 약131만픽셀로 늘리는 문제를 발견했다. 긴 표와 수치 카드를 키보드 스크롤 가능한 영역으로 제한해 값을 모두 유지하면서 약2만6천픽셀로 줄였다. 수정 후 전체 화면/저장/모바일 검사를 다시 수행했다. 초기 캡처 안정화 실패와 측정 기록도 보존한다.
- 모바일 그림과경계 선속·음의 전기장/자기 루프의2D/3D그림,최대 입력3D그림을 검토했다. 타입·대상 lint검사를 통과했다.

명령은 `npx tsx --test scripts/learning-graph-gauss-{foundation,workers,controller,teaching}.test.ts scripts/learning-gauge-orbits-foundation.test.ts`와 `npx tsx scripts/check-graph-gauss-{teaching,storage,input,maximum}-native.ts`다. 근거와 로컬 미리보기 정보는 `.runtime/learning/graph-gauss-teaching/`에 보존한다. 이 단계는 esbuild로 구성한 학습 화면이며 Next 생산 자산 검증은 아니다.
