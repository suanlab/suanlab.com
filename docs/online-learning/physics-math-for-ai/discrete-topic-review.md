2026-11-11에 이산수학의 9개 원주제를 한영 원고와 수치 모형에 대조했다. 전체 51영역·509개 원주제의 검토를 이어가는 기록이다. 각 단원의 입문 설명을 확인하고, 세기 단원에 증명·반례·실행 가능한 AI 표현 실험을 보강했다. 영역의 연구 심화는 진행 중이다.

## 추가한 집합 표현 실험

세기 단원에 다섯 절을 추가했다. 시퀀스·집합·중복집합의 대응부터 원핫 합 표현의 단사성을 증명하고, 크기가 바뀌면 평균 집계가 잃는 정보를 표로 보여 준다. 같은 표현을 갖는 정답 묶음에서 제곱오차를 최소화하는 값이 평균이라는 사실도 완전제곱 항등식으로 유도한다.

Python 표준 라이브러리로 3개 범주, 크기 1–4의 34개 중복집합과 120개 시퀀스를 열거했다. 시퀀스의 개수는 다항계수 합으로 독립 확인한다. 각 중복집합을 균등 가중하여 크기를 예측할 때 평균 원핫 표현의 최적 제곱오차는 정확히 `21/34`다. 합 원핫 표현과 평균·크기 쌍은 직접 디코딩하여 오차 0을 달성한다. 두 언어의 코드가 같은 결과를 출력했다.

범주 세 개와 정확한 정수·유리수 연산이 실험의 조건이다. 크기 외의 목표, 다른 임베딩, 다른 가중치, 연속 입력에는 조건을 다시 검토한다. 다음 연구 과제는 특징 차원 제한에 따른 충돌과 학습 오차, 더 큰 입력 크기에서의 외삽을 측정하는 것이다.

## 원전 확인 범위

Zaheer 외, *Deep Sets*, NeurIPS 2017, arXiv v3, 2018-04-14의 §2.2, §3.1, 부록 A.1과 A.2의 가정·증명 도입을 확인했다. 합을 통한 순열 불변 표현에 연결하고, 유한 범주의 원핫 증명과 자체 전수 열거를 교재에 제시했다. 후속 검토에서는 연속 입력 정리의 전체 증명과 원 논문의 학습 실험을 재현한다. [확인한 원문](https://arxiv.org/pdf/1703.06114v3)

## 화면 검증

`npm run check:discrete`에서 한영·320/768/1440px·명암·키보드·안내 실험·문제·진도 저장을 검사한다. 정수 입력 검사는 소수 초안의 오류 표시, 이전 계산 유지, Escape 복원을 확인하도록 현재 입력 규약에 맞췄다. 수화 대기와 실제 가로 넘침 요소의 스크롤도 검증한다. 새 원고를 포함한 정적 빌드가 성공했고 1,888개 HTML의 링크·자산·사이트맵 검사를 통과했다. 실제 학습 화면에서 한영·반응형·접근성 70개 상태와 상호작용 10개 묶음, 안내 예제 27개를 통과했다. 페이지 실행 오류와 WCAG A/AA 위반은 0건이었다. 새 비교표의 네 행, Python 코드의 키보드 스크롤, 정수 초안의 오류 표시와 복원도 확인했다. 실행 근거는 `.runtime/learning/discrete-browser.json`에 있다.
