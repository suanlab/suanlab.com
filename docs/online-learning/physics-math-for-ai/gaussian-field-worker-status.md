# 유한 가우스 장: 독립 응답 검증과 실제 Worker

2026-11-10. `finite-gaussian-field-sources-connected-correlations`에 별도 전체 응답 검증기, 계산/검증 Worker와 React hook을 연결했다. 아직 실제 교재에 미등록이며 학습 화면·reader·생산 Next.js 자산 검증은 후속이다.

## 계산과 다른 검산 경로

생산 모델은 기저를 택한 유리수 LDLᵀ·삼각 풀이를 사용한다. 검증기는 생산 모델이나 그 유리수 코어를 가져오지 않는다. 별도 Rational 클래스에서 발생 벡터 외적으로 정밀도를 만들고, 평균0 제약은 경계 확장 행렬의 Gauss–Jordan 역행렬로 푼다. 제한 공간 행렬식은 확장 행렬식으로, LDL 대각/하삼각 표시는 선행 주 소행렬과 교체 행 소행렬의 비로 재구성한다. 행렬식은 행 교환을 처리하는 Bareiss식이며 모멘트는 명시적 사차 전개 대신 재귀 가우스 항등식을 쓴다.

같은 물리 모형을 별도 알고리즘과 산술로 검산하는 것이며 다른 확률분포로 교차 검증했다는 뜻은 아니다. 이전 독립Python/SymPy46입력의 정확한 참조와 함께 판단한다. 모든 행렬·기저·측도·원천 미분·정규화 로그 비·사차 모멘트·제약 승수와 원시 입력 표기를 대조한다.

산술 입력은 소유한 원래 요청에서만 읽는다. 외부 응답의 분수 문자열은 숫자로 해석하지 않고 기대 문자열과 비교한다.16입력 캐시는 신뢰한 입력에서 재구성한 동결 값만 보관한다. 기본234·제약139·큰 분모 입력786개, 총1159개 실제 leaf를 하나씩 변조해 모두 거부했다. 세 준비 각각의 모든 최상위 응답 영역을 포함한다.

## 전송·소유권·취소

매 실행은 계산 Worker와 독립 검증 Worker를 소유한다. 요청번호·중첩 원천/관측 배열·원시 분수 표기·검산이 일치한 응답만 ready로 공개한다. 입력 변경·비활성화·숨김·해제와 시간 제한에서 이전 작업을 중단한다. 큰 응답 소유권 복사는 여러 task로 나눠 취소 가능하게 한다. 재시도, 전송/Worker/검증 오류와 자원 한도를 처리한다.

메타데이터는 descriptor로만 읽고 새 plain record에 own property로 정의한다. `__proto__`처럼 보이는 필드가 상속 getter를 만들지 못하며 getter·희소 배열·순환·기호·추가 속성·잘못된 원형과 큰 전송 값을 거부한다. controller와 hook은 계산/검증 숫자 엔진을 가져오지 않으며 SSR에서 Worker를 만들지 않는다.

## 확인한 근거와 한계

- 기반61+새 계산/검증54+controller19, 합계134검사를 통과했다. 독립 참조46입력, 세 준비의1159개 변조, 요청/입력 귀속·캐시 소유권·원시 응답의 비산술 처리를 확인했다. 제약·경계·측도·ambient force가 형식만 맞춘 응답으로 바뀌지 않는다.
- 실제 Chromium module Worker에서 참조46+명시적17예제, 총63요청(중복 포함)을 계산/검산했다. 차원 변조63개와 잘못된 요청 귀속63개를 거부했다. 직접 생성한2Worker를 종료했으며 계산 중 타이핑도 반응했다.
- 실제 React hook에서 비활성화·시작/검증 중 숨김·복귀·입력 교체·전송 오류 후 재시도·pending unmount를 확인했다.17생성/17종료·활성0·페이지 오류0이다. 숨김은 visibility event 모의이며 실제 탭을 물리적으로 숨긴 실험은 아니다. 전송 보류로 각 경합 지점을 제어했다.
- 타입·변경 파일 lint·번들 의존성 검사를 통과했다. 독립 검증 번들은 생산 엔진/산술을 포함하지 않고 reader hook에도 숫자 엔진이 없다. 현재 Worker는 별도 esbuild 자산이며 생산 Next.js 자산과 reader는 후속 단계다.

근거는 `.runtime/learning/gaussian-field-worker/`의 `all-tests.log`, `leaf-mutations.json`, `native-workers.json`, `native-hook.json`, 의존성 그래프와 타입/lint 로그다. 기존 계산 모델·입력·한영 원고는 수정하지 않았다.
