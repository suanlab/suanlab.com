## 유한 Curie–Weiss: 분포와 평균을 함께 보기

첫 화면은 N=2,K=0,b=0이다. 다중도 막대, 비정규화 가중치, 정규화 확률을 같은 M 축에 나란히 그린다. 각 막대에는 M과 m=M/N을 모두 표시한다. 현재 선택한 거시상태의 미시 다중도는 정확한 정수 문자열로 보여준다. 축과 표를 통해 그림 없이도 수치를 읽을 수 있게 한다.

고정 개념은 이름 붙은 배치→다중도→장·결합의 가중치→정규화→부호 평균과 절댓값 평균→분산과 감수율 순서다. 표본을 그리지 않고 정확한 분포를 보여주는 경우에는 표본 히스토그램이라고 부르지 않는다. N이나 온도 준비를 바꾸는 화면 전환을 물리 시간 애니메이션으로 설명하지 않는다.

실험은 세 가지다.

1. N=2,K=0,b=0과 실제 K=Math.log(2),b=0을 비교한다. 이상적인 ln2 손계산의 1/3 동률과 실제 입력의 최빈값 판정을 구별한다.
2. N=16,K=2,b=0에서 시작해 N=32,64를 비교한다. 평균0, 양의 절댓값 평균, 두 봉우리를 동시에 확인한다.
3. 같은 계에 b=±0.2를 가해 반사 대칭과 장에 따른 집단 확률 변화를 비교한다. 최소 비영 장은 별도 정밀도 예제로 제공하고 슬라이더가 이를0으로 바꾸지 않게 한다.

퀴즈는 중앙 배치의 큰 다중도, 평균0과 이봉 분포의 양립, 유한계 반응 N Var(m), 유한 양의 온도에서의 해석성을 묻는다. 오답 해설에 해당 관측량과 준비를 명시한다.

## 변분 Curie–Weiss: 모든 근의 역할을 동시에 보기

ψ(m), f(m), 근 표를 연결한다. ψ의 영역은 [−1,1]이고 끝점의 엔트로피를0으로 정의한다. f의 끝점은 발산하므로 표시 영역을 명시한다. 샘플링된 곡선은 그림을 위한 근사이고, 근 마커와 역할은 인증된 계산 결과에서 가져온다. 그림 격자의 영점 탐색으로 모델의 근 목록을 대체하지 않는다.

근 표에는 m, 곡률, 가지의 미분, ψ, ψ−ψ(0), 전역/준안정/극대/임계 역할을 둔다. 반응 열 이름은 **가지의 미분**으로 고정한다. 음의 값을 평형 감수율이라고 표시하지 않는다. 자유에너지 숫자가 같은 두 행에도 전역 선택 및 양의 차이 구간을 따로 보여준다.

고정 개념은 에너지·엔트로피의 경쟁→제약 자유에너지→단조 구간과 모든 근→곡률과 국소 안정→장과 전역 선택→유한 평균 및 극한 순서다. 물리적으로 움직이는 공은 계산의 의미를 바꿀 수 있으므로 기본 설명은 곡선·접선·마커의 변화로 구성한다.

실험은 다음 세 가지다.

1. b=0에서 K=0.5,1,2를 비교한다. 유일 최소→사차 임계 최소→두 전역 최소와 중앙 극대를 구별한다.
2. K=9/8에서 실제 인접 binary64 장 세 값을 직접 선택한다. 근 두 개가 가까워지는 영역을 확대하고 스피노달 비교 결과와 정밀도를 표시한다. '정확한 접점'으로 반올림하지 않는다.
3. K=2,b=0,±0.2 및 최소 비영 장을 비교한다. 전역 선택, 준안정 장벽, 반사, 표시 범위 밖 차이를 확인한다. 유한계 영장 평균과 순수 가지를 별도 비교란에 둔다.

퀴즈는 곡률0에서 필요한 고차항, 스피노달과 공존의 차이, 부호 없는 평균과 대칭 깨짐, 작은 잔차와 근 정확도의 차이를 묻는다. log-cosh 퍼텐셜을 제약 지형으로 바꾸는 오답도 설명한다.

## 육차 Landau: 검증한 모형을 연결할 화면

m∈R인 현상론 모형임을 계속 표시한다. 스핀 평균의 [−1,1] 범위를 그대로 적용하지 않는다. 계수 a,b,c,H와 단위를 명시하고 c>0을 검사한다. m의 그리기 영역은 모든 인증 근과 최소를 포함하도록 정하며 그리기 범위를 수학적 정의역으로 부르지 않는다.

고정 비교 후보는 b>0의 연속 전이, b=0의 삼중임계 준비, b<0,c=1의 세 공존 최소다. 정확한 a=3/16,b=−1,c=1,H=0에서 최소0,±√3/2와 장벽±1/2, 높이1/96을 보여준다. 독립 모델과 원고의 준비 검증을 마쳤고, 이 준비를 기준으로 세부 프리셋과 정답 데이터를 작성한다. 국소 최소를 따라가는 곡선은 준안정 가지이며, 실측 이력이나 핵생성 시간이라고 명명하지 않는다.

## 공통 비동기 계산·접근성·검증

정확한 BigInt 계산은 전용 worker에서 실행한다. 요청마다 세대 번호를 붙이고 입력 변경·단원 이동·unmount·취소 때 worker를 종료한다. 새 요청 이후 도착한 이전 결과는 폐기한다. 로딩·실패·재시도·정밀도 상한 상태를 분리한다. worker 자산 실패를 조용히 main thread 계산으로 대체하지 않는다. 큰 입력을 실행하는 동안 UI 조작과 취소가 가능해야 한다.

기존 홈페이지의 색 변수, 명암 모드, 반응형 간격을 따른다. 모션은 그래프 간 관계를 설명하는 짧은 변화에만 쓰고 감소 모션에서는 정적 상태를 즉시 보여준다. 부호와 안정성은 색 외에 텍스트·선 형태로도 표현한다. 표·수식·근 확대는 키보드로 읽을 수 있게 하고 작은 화면의 가로 넘침을 검사한다.

실제 읽기 검증은 한영·명암·모바일/데스크톱에서 메뉴→목록→목차→단원 이동, 개념 단계·선택지, 실험 프리셋, 퀴즈 해설, 저장 복원, 연속 요청의 이전 결과 차단, worker 누수·실패 복구를 포함한다. 정적 export의 경로·fragment·canonical·sitemap·worker 번들도 검사한다. 세 가족의 등록과 주제 완료 수 변경은 이 증거 뒤에 한다.
