# 온도·열·일 연구 보강 검증 기록

2026-11-13. 기존 `finite-body-thermal-contact-heat-entropy`와 `ideal-gas-two-path-heat-work`의 **한영 원고 4편·공개 그림 4개**에 연구 설명을 추가했다. 원래 본문과 해설 24개를 바이트 단위로 보존했다. 새 표시 수식은 한영 합계 40개, 실행 Python/표는 각각 4개, 연구 해설은 12개다. 새 조작이 아닌 본문 연구 보충이며 기존 실습·프리셋·단원 순서를 유지한다.

## 설명과 적용 범위

- **열접촉의 척도:** 일정 양의 열용량·양의 선형 연결과 보정된 온도/시간을 전제한다. 비영 온도차의 두 기울기에서 식별되는 변화율과 열용량 비를 유도한다. 공통 열용량/연결 배율은 전체 온도를 보존하지만 에너지·엔트로피의 크기를 바꾼다. 계수 2의 로그 변화율 Jacobian은 관측 우도를 지정한 Fisher 행렬과 구별한다.
- **별도 보정 실험:** 같은 연속 상태의 직전·직후 기울기 차와 알려진 경계 열전력으로 절대 척도를 구한다. 초기 등온·끊긴 연결과 실제 센서/입력의 유한 응답은 따로 다룬다. 열입력 후에는 단열 경계가 아니며 두 물체와 양의 온도 열원의 엔트로피를 구분한다. 전기적 일을 열 엔트로피 유입으로 대신하지 않는다.
- **이상기체 경로:** 로그 부피 위치에 두 매끄러운 온도 형상을 더한다. 실제 p dV와 가역 δQ/T를 적분해 총 일·열·끝점 엔트로피에 보이지 않는 이력을 구성한다. 중간 탐침도 실패하지만 1/4 탐침과 총 일은 이 유한 가족의 두 계수를 식별한다. 양의 온도의 충분조건·동일 부피의 계수 상실·경로와 시간 일정의 차이를 설명한다. 임의 미지 경로나 유한 속도 가역 장치의 식별/실현을 인증하지 않는다.

계·부호·가역성 관례는 [자료 대조](thermo-statmech-source-audit.md)에, 실제 수식·코드·질문은 해당 reader에 있다. 일차 자료가 이번 특수 역문제나 시간 법칙까지 제공한다고 표시하지 않는다.

## 독립 계산과 보존
