# 열·물질 확산 두 단원의 계산·상세 원고

이후 [홈페이지 통합과 최종 검증](continuum-diffusion-authoring-status.md)을 마쳤다. 아래 수치와 미완료 설명은 기초/설계 작성 당시 기록이다.

2026-11-06. 연속체의 다섯 번째 입문 주제에 대해 계산 모델과 상세 한영 원고를 작성했다. **홈페이지 화면 통합과 최종 화면 검증은 미완료**다. 등록488개 단원·1,464개 안내, 원래 주제272개 입문 검증·90개 미완료를 유지한다. 전체51영역509주제와 연구 심화의 완료를 뜻하지 않는다.

## 추가한 계산

`src/lib/learning-continuum-diffusion.ts`는 다음 두 상수 계수 가족을 제공한다.

- `heatModeAt`: 양의 절대 온도 위의 cosine 모드, 실제 기울기·시간 미분·Fourier 열유속과 국소 에너지 수지. 열용량·열전도도·열확산율을 구분한다. 안정적인 진폭 변화와 반올림 온도·감쇠 인자도 따로 남긴다.
- `heatModeWindow`/`heatModeCell`: 실제 단면적과 창의 현열J·경계 전력W,273.15K 기준 현열, 전체 주기의 현열 보존과K²m³ 노름 감소. 지정한 반폭의 sinc 적분과 반올림 끝점 수지를 구분한다. 폭0은 별도 정확한 영 적분이다.
- `gaussianDiffusionAt`/`gaussianDiffusionState`: 총질량·실제 관 단면적을 가진 농도, 평균 이류·분산 증가, 공간/시간 미분과 이류·확산·전체 플럭스. 작은 분산·표준편차·봉우리·평균 변화를 반올림 관측과 분리한다. 질량0의 물리장과 미정인 질량 정규화 모멘트를 구분한다.
- `gaussianDiffusionWindow`: 실제 폭의 로그 공간 Gauss–Legendre 구적, 유한 창 질량·시간 변화율과 방향 있는 두 면의 플럭스. 농도와 분율이 표현 범위 밖이어도 로그를 유지하며, 결합 배율에서 회복 가능한 실제 관측은 따로 계산한다. 두 차수의 로그 적분 차이는 진단이며 엄밀한 오차 상한이 아니다.

부호와 로그 크기를 함께 보존해 중간 지수·곱의 언더플로로 전체 관측을0으로 만들지 않는다. 정확한0, 표현 가능한 비영 값과 계산 불가한 비영 값을 분리한다. 물리장과 보존식의 공유 식 잔차는 해석적 가족 진단이라고 명시했다. 일반 변계수·벽·반응·미시적 열전달 솔버를 제공하거나 인증하는 것은 아니다.

## 독립 검증과 발견한 문제

`generate-continuum-diffusion-references.py`는 제품을 import하지 않고 mpmath160자리로 실제 장을 미분·구적한다. 열 사례24개는 유한 창의 저장·전력과 실제 주기 체적의 노름·기울기 소산을 확인한다. 농도 사례24개는 장과 유한 창 수지·무한 영역0/1/2차 질량 모멘트를 계산한다. 꼬리 창6개와 작은 변화3개도 포함한다. 꼬리 참조는 가장 큰 로그 밀도로 배율을 조정해 적분 자체가 너무 작아서 참조의 상대 정확도를 잃는 문제를 피한다.

검증 중 먼 꼬리의 고정 구적 간격이 충분하지 않음을 발견했다. 구간 폭/표준편차뿐 아니라 평균에서 가장 가까운 꼬리 거리도 사용해 구간을 더 나누었다. 꼬리를 자르거나 질량을 재정규화하지 않고 독립 로그 적분과 맞췄다. 열 플럭스 차분 검사는4차 stencil로 절단 오차를 줄여 원래 잔차 허용값을 유지했다.

전용24개와 전체4,440개 검사, 타입·lint·콘텐츠1,723 URL 검사가 통과했다. 실제 장의 유한 차분과 유한 창 저장 변화, 부호·단위, 전도도/확산계수/질량0, 끝점 반올림, 매우 작은 변화와 배율 회복을 포함한다. 참조 재생성 파일은 fixture와 바이트 단위로 일치한다. 생성기는 기존 파일을 덮어쓰지 않는다.

한영 원고는 실제 Markdown/KaTeX 로더로 렌더링했고 목차ID, 접근 가능한 수식·표, 수식 일치, 영어의 한글 부재와 각6개 풀이를 확인했다. 기존488단원·안내와43실험 그룹479항목의 canonical 내용·상대 순서를 보존했다. 기존 소스3,076개와 출력4,194개도 해시가 같다.

새 단원을 아직 등록하지 않았으므로 새로운 화면 검사나 정적 배포 빌드 완료를 주장하지 않는다. 기존 미리보기·Interactive Book 메뉴를 유지했고 commit·push·공개 배포는 하지 않았다. 실제 종료 기록과 `.runtime/learning/continuum-diffusion-foundation-verification.json`을 근거로 한다.
