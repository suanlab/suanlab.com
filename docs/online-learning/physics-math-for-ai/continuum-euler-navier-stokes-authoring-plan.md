## 1. 선형 Euler와 음향 특성

예정 ID: `linearized-euler-acoustic-characteristics`. 선수는 압축 흐름의 보존식, 연속체 척도, 파동과 특성 방법이다.

균일 배경에서 D0=partial_t+U partial_x를 두고 밀도·속도·압력 섭동의 세 선형 방정식을 유도한다. 음향 불변량 u′±p′/(rho0 c)와 접촉 변수 p′−c²rho′를 서로 다른 속도로 수송한다. 배경 유동·음속·위상·섭동 크기를 분리하고 양의 전체 밀도·압력 및 선형화의 작은 진폭 가정을 명시한다.

같은 실제 섭동 장에서 선형 잔차와 비선형 Euler의 이차 크기 잔차를 비교한다. 음향 에너지와 평균 유동의 총에너지는 다른 관측이다. 신호의 실험실 속도, 유체에 대한 상대 속도, 입자 이동을 구분한다. 충격파·큰 진폭의 일반 해·보편적인 선형화 오차 상한을 주장하지 않는다.

## 2. Taylor–Green의 비선형 운동량과 점성 감쇠

예정 ID: `taylor-green-navier-stokes-viscous-decay`. 선수는 응력·변형, 속도 기울기와 운동 에너지다.

실제 이차원 벡터장·유선·압력·와도와 입자 이동을 함께 보여 준다. 공간 압력이 대류를, 점성이 시간 감쇠를 어떻게 맞추는지 각 벡터 항을 분리한다. nu=0의 Euler 특수 경우와 양의 점성의 감쇠를 같은 해 가족에서 비교한다. 압력을 누락한 대조를 같은 속도장에서 남긴다.

물리 길이2pi/k의 주기 셀과 깊이를 명시하고 질량·운동 에너지·소산의 SI 단위를 유지한다. 압력은 일정한 기준값을 더할 수 있는 비압축성 gauge이며 음의 압력 변화량을 음의 절대 열역학 압력으로 해석하지 않는다. 0 진폭·0 점성과 작은 비영 입력의 산술 상태를 구분한다. 이차원 매끄러운 정확 해를 3차원 난류나 일반 솔버의 인증으로 확장하지 않는다.
