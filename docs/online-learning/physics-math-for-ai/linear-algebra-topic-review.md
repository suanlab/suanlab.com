## 보강한 SVD 논증

기존 원고는 Frobenius 최소화에 필요한 투영 논증을 후속 설명으로 남겨 두었다. 임의의 랭크 제한 후보 B의 열공간 투영 P를 사용해 A−B를 서로 직교하는 두 성분으로 분해했다. tr(PAAᵀ)의 가중치는 0과 1 사이이며 합이 rank(P)인 점을 이용해 버린 제곱 특잇값의 합을 하한으로 얻는다. 절단 SVD가 그 하한을 달성함을 확인했다. 랭크 0과 전체 랭크를 포함하는 인덱스 규약을 명시하고, 스펙트럼 하한의 부분공간 논증이 적용되는 범위도 적었다.

다음으로 유한 이차 모멘트 M=E[xxᵀ]에서 출력 제곱오차가 ‖(A−B)M¹ᐟ²‖²_F임을 유도했다. M이 양의 정부호이면 가역 변수 변환으로 AM¹ᐟ²의 절단 SVD를 이용하는 최소화 해를 구할 수 있다. 중심화하지 않은 이차 모멘트와 공분산의 관계, 특이 M의 별도 지지 공간 논증, 비선형·분류 목적의 후속 검토를 명시했다.

## 직접 실행한 기준 예제

A=diag(3,1)과 네 입력 (±0.1,±10)에 같은 확률을 주었다. M=diag(0.01,100)이다.

| 근사 | 행렬 제곱오차 | 기대 출력 제곱오차 |
|---|---|---|
| 일반 SVD의 diag(3,0) | 1 | 100 |
| 입력 가중 SVD의 diag(0,1) | 9 | 0.09 |

두 언어의 NumPy 예제를 실행하여 이 값을 확인했다. 네 입력에서 직접 계산한 예측 오차와 trace 식을 비교하고, 실제 SVD로 가중 근사를 구성해 랭크도 확인한다. 행렬의 잔차 노름과 제곱오차를 구분하고, 기존 단위원 시각화와 새 입력 분포의 차이를 설명했다. M=I를 대조 조건으로 제시했다.

## 연구 연결과 확인 범위

Hu 외, *LoRA: Low-Rank Adaptation of Large Language Models*, arXiv v2, 2021-10-16의 §4.1을 확인했다. 기저 가중치를 고정하고 갱신을 두 인자로 학습하는 매개화를 연결했다. 본 교재에서는 열공간을 이용한 갱신 랭크 상한, 전체 가중치가 완전 랭크일 수 있는 2×2 예제, 인자 원소 수 r(d+n)를 직접 유도했다. [확인한 원문](https://arxiv.org/pdf/2106.09685v2)

이번 네 입력 실험은 교재에서 구성한 선형 과제의 재현이다. 후속 연구에서는 보정 통계의 추정·분할, 목표 갱신과 과제 최적화의 비교, 랭크·예산·추론 비용을 검토하고 원 논문의 언어모형 학습 실험을 재현한다.

## 실행 검증

`learning-foundations.test.ts`와 `learning-matrix-structures.test.ts`의 49개 검사, `learning-algebra.test.ts`의 24개 검사가 통과했다. SVD 재구성·조건수, 직교 잔차·최소제곱·공분산, 작은 정수 행렬의 기저·랭크·PSD, 벡터화의 인자 순서를 포함한다. 11개 단원의 원고 공통 검사도 실제 한영 렌더러에서 모두 통과했다. 이 실행은 해당 이름의 검사 11개를 선택했고 나머지 660개는 선택하지 않았다.

행렬 구조 브라우저 검사에서 수화 대기, 넘치는 해당 요소의 키보드 스크롤, 정수 입력의 소수 초안 오류·기존 계산 보존·Escape 복원을 현재 입력 규약에 맞췄다. 초기화 직후의 입력 초안이 아직 이전 값일 때 비교 기준을 읽던 검사 타이밍도 수정했다. 최종 정적 빌드가 성공했고 1,888개 HTML의 링크·자산·앵커·사이트맵 검사가 통과했다. 기본 선형대수 6개 단원은 한영·320/1440px·명암의 24개 화면 상태와 상호작용 6개 묶음, 안내 예제 18개, 해설 퀴즈 12개를 통과했다. 경계 조건을 보강한 최종 SVD 원고는 4개 화면 상태에서 다시 확인했다. 행렬 구조 5개 단원과 목록은 42개 한영·반응형·접근성 상태와 상호작용 6개 묶음, 안내 예제 15개를 통과했다. 페이지 실행 오류와 WCAG A/AA 위반은 0건이었다.

실행 근거는 `.runtime/learning/linear-review-browser.log`, `.runtime/learning/linear-svd-final-browser.json`, `.runtime/learning/matrix-browser.json`에 보존했다. 저장한 입력과 진도 복원, 언어 전환, 목차 연결, 새 비교표와 코드의 키보드 스크롤도 확인했다.
