## 픽셀 모델의 계약

`pixelApertureSampling`은 SI 입력을 받고 `E0[1+ηcos(2πν(x−vt)+φ)]`를 직사각형 면적·노출 구간으로 적분한다. 간격 p와 폭 a를 분리하며 면적은 a·b다. 평균 변조 전달은 `sinc(νa)sinc(νvT)`이고 정규화 sinc의 부호를 유지한다. 0면적·0노출에는 실제 평균을 null로 두되, 명시한 점·순간 극한은 비교용으로 제공한다. 실제 에너지·광자 평균은0이다.

부호 있는 alias는 `[-νs/2,νs/2)`에 두고 원점 보정 `2πk x0/p`와 이동 중심 시간 위상을 유지한다. 유한 sinc 복원은 유지한 격자점을 통과하지만 무한 표본의 완전 복원으로 부르지 않는다. 반환된 표본이나 호출자가 바꾼 입력 객체가 내부 관측 함수를 변경하지 않는다. 화면 곡선은 원래 최고 주파수당 최소24표본을 유지한다. 이것은 실제 센서 표본 수를 늘린다는 뜻이 아니다.

`calibratedPhotonExposure`는 W/m²·m²·s·m를 사용하며 정확한 SI h와 c로 `EATλ/(hc)`를 계산한다. 이전 광학 단원의 상대 강도를 교정 없이 연결하지 않는다.

## 센서 모델의 계약

`photonCountingSensor`의 광자 평균은 노출 전체에 걸쳐 적분된 값이다. 노출을 바꾸는 물리 실험은 광자 평균도 다시 계산해야 한다. 0노출에 양의 광자 평균을 넣으면 거부한다. 유효 QE는 전체 픽셀 면적 기준의 정의이며 fill factor를 이중 적용하지 않는다.

광전자와 암전자 합 N은 Poisson, 읽기 잡음 R은 독립 Gaussian이다. 연산 순서는 `C=min(N,F)` → `Y=b+K(C+R)` → `D=clip(floor(Y+.5),0,2^B−1)`이다. F는 정수 electrons, K는 DN/electron, b는 DN다. 저장 넘침은 N>F, 아래 ADC clipping은 Y<−.5, 위 clipping은 Y≥M+.5다. 최대 코드 점유와 clipping 확률은 구별한다.

각 Poisson 계수에 조건부 정규 CDF 구간 확률을 곱해 디지털 분포를 직접 합한다. 읽기 잡음0에는 결정론적 규칙을 쓴다. 포화 전 해석적 모멘트, 저장 포화 후 모멘트, 디지털 모멘트를 따로 제공한다. 포화 전 SNR을 디지털 정확 SNR로 부르지 않는다.1/12DN²는 별도 근사값이며 실제 디지털 분산을 대신하지 않는다.

유한 Poisson 구간을 재정규화하지 않고 Chernoff 꼬리 질량 상한·확률 질량 잔차·디지털 일차/이차 모멘트 누락 상한을 반환한다. 이 상한은 부동소수점 오차 전체의 인증이 아니다. 정규 CDF는16점 Gaussian quadrature이며 ±9 밖 꼬리 처리의 절대 누락은 약1.13×10⁻¹⁹ 이하이다. 확률 합의 수치 잔차는 그대로 유지한다. 분포 계산량을 제한하는 지원 범위는 광자 평균0~4096, 비트2~8, 저장 상한1~8192다. 이 범위를 실제 모든 센서의 물리 한계로 해석하지 않는다.

## 독립 계산과 검사

휴대 가능한 생성기는 `scripts/learning/generate-sampling-sensors-references.py`, 기준값은 `scripts/fixtures/sampling-sensors-independent.json`이다. NumPy/SciPy만 사용하며 제품 TypeScript를 가져오지 않는다.48개 픽셀 준비에서 공간·시간 이중 적분432개를 계산했고, Poisson 확률과 정규 CDF로 센서36조건의 코드 확률4,032개·저장/ADC 모멘트를 계산했다. 정규 CDF 독립 관측은77개다.

실제 제품 대조에서 평균 복사조도 최대 차이는 약1.13×10⁻¹⁷W/m², 광자 평균4.10×10⁻¹², 코드 확률1.69×10⁻¹², ADC 평균9.12×10⁻¹¹DN, 분산9.07×10⁻⁹DN², 정규 CDF2.23×10⁻¹⁶이었다. 지정한 조건에서 관측한 차이이며 보편 오차 한계가 아니다. 원래 값은 `.runtime/learning/sampling-sensors-reference-comparison.json`에 있다.

전용 테스트30개는 위 독립 기준 외에 영조건·경계·부호·alias 위상·움직임·정수 반올림·결정론적 양자화·full-well/ADC 분리·누락 입력 거부·실제 원고 렌더링을 확인한다. 최초 개발 검사에는 표시 표본 개수를 두 배로 잘못 기대한 테스트가1개 실패했다. 제품 격자의 주기당24표본 조건은 충족했으므로 구현의 배열 크기를 그대로 복제한 기대값을 없애고 물리적 간격 조건으로 검사했다. 첫 로그는 `sampling-sensors-development-focused.log`에 보존한다.

최종 검사·실제 종료·소스 동결 기록은 `.runtime/learning/sampling-sensors-foundation-verification.json`을 참조한다. 새 원고의 존재만으로 홈페이지 완료 수를 늘리지 않는다.

## 다음 홈페이지 연결

두 종류의 실험·복소 광학 종류의 상대 순서를 보존하며 `wavesKinds` 뒤에 추가한다. 기존 HSL·명암 테마를 사용하고, 영역 적분·실제 표본·유한 복원·연속 원래 장면을 서로 다른 그림으로 표시한다. 센서는 물리 변환 흐름, 전자 분포, 잡음 분산 분해, 저장 포화와 ADC 코드 확률·레일·clipping을 구별한다. 모든 확률과 양의 광량의 원래 축·단위를 유지한다.

각 단원에 개념4단계·안내 실험3개·해설 퀴즈2개와 유의미한 준비 예제를 만든다. 픽셀 폭·간격·노출·원점·위상을 따로 조작한다. 센서의 물리 노출 조작은 고정한 교정 복사조도·면적으로부터 광자 평균을 매번 다시 계산해야 한다. 지원 범위를 넘는 준비를 몰래 clamp하지 않는다. 한영·반응형·접근성·키보드 스크롤·연속 값 저장·원본 그림 직접 검토와 실제 새 빌드 검증 후 입문 주제를 완료 처리한다.
