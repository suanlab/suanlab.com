## 관측과 수치 해석

실제 SI 값을 표에 남기며 작은 비영 값은 그래프의 축척을 명시해 표시한다. 영폭의 관측 평균·실제 제어면과 양의 작은 폭의 좌표 해상도 손실을 구분한다. 산술상 사용할 수 없는 값은 빈 구간이나 미정 값으로 표시하며 정확한 영으로 바꾸지 않는다. 시간별 저장량, 순간 변화율과 유한 시간 변화를 분리한다. 국소식의 두 항은 각각의 미분 관측을 사용한다.

해석 가족의 잔차와 구적 차수 차이는 선택한 계산의 진단이며 독립 인증이나 엄밀한 오차 상한이 아니다. 일반 유동 솔버·충격파·점성·열전도까지 검증했다고 확장하지 않는다. 독립 구적·차분·입자 ODE와 100자리 참조의 범위는 [계산 모델·원고 검증](continuum-conservation-foundation.md)에 기록했다.
