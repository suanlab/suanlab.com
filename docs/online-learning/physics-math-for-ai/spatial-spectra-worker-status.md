## 계산기와 다른 검산 경로

생산 계산기의 축소 LDLᵀ 역산 대신, 간선 발생 행렬의 Gram 행렬과 전체/확장 Gauss–Jordan 역산으로 공분산을 재구성한다. 축소 LDLᵀ 피벗은 Bareiss 주부분행렬식의 비로 대조한다. 실제 입력에서 나온 수만 유한 행렬의 산술 피연산자로 사용한다.

전체 Fourier 행렬은 두 번의 행렬곱 대신 위상 차이를 합친 직접 합으로 재구성한다. 같은 위상의 계수를 먼저 묶어 최대 입력의 비용을 줄였다. 이 변경은 경계별 모드 혼합이나 행렬 원소를 생략하지 않는다. 주기/제약의 해석적 영성분과 실수 대각은 별도로 확인한다.

검산 산술은 별도3072비트 구간 격자·2048비트 π·삼각함수 Taylor 전개를 사용한다. 감쇠 근은 다른 이차근 표현, 길이는 acosh의 로그 표현으로 계산한다. 로그는 정확한 이진 범위 축소와640항 atanh 급수 및 양의 기하 꼬리 상계로 검산한다.3072비트 격자가 모든 초월함수의3072비트 상대 정확도를 뜻하지는 않는다.

정확한 출력은 예상 문자열과 대조한다. 비유리 구간은 길이가 제한된 정규 분수·512비트 이진 끝점만 파싱하고, 독립 구간을 포함하며 크기 기준1e−90보다 좁아야 한다. 단순 겹침은 허용하지 않는다. 전체 응답의 필드·배열 크기·입력 귀속·정밀도·분류·표와 잔차·설명 계약까지 확인한다.

## Worker와 소유권

계산 Worker가 응답하면 해당 Worker를 종료하고, 별도의 검산 Worker에서 수학을 확인한다. 메인 스레드의 두 큰 응답 복사는 짧은 작업으로 나눠 실행하며 취소 토큰을 확인한다. 읽기 전용 결과, 요청 번호와 원래 분수 표기까지 일치하는 입력 귀속을 유지한다.

교체·취소·실패·마감시간·unmount에서 두 Worker를 정리하고 늦은 응답은 버린다. 숨김 visibility 이벤트에서는 취소하고 복귀 시 재개한다. hook과 controller의 브라우저 묶음에는 생산 수치 엔진이나 독립 검산 엔진이 들어가지 않는다. 최대977592bytes 응답과3–16위치·12자리 입력 한도를 유지했다.
