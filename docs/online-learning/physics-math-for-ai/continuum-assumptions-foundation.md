## 입자 평균장의 보존과 한계

`src/lib/learning-continuum-assumptions.ts`는 파일·데이터·AI 의존성이 없는 순수 계산 모듈이다. 커널은 W=15/(16h)(1−q²)², |q|<1이며 전체 적분은1이다. 지지 경계에서 C1이지만 C2는 아니다. 밀도는 삼차원 kg/m³가 아닌 일차원 kg/m다. 일정 속도의 입자는 서로 지나가며 충돌·외력·평형을 생성하지 않는다.

질량 유속을 밀도로 나눈 가중 속도와 이차 모멘트를 구분하고 중심 속도 편차로 분산 수송을 계산한다. 같은 위치의1kg 입자 두 개가±1m/s로 움직이면 h=1m에서 밀도15/8kg/m, 평균 속도0이지만 운동량 유속·분산 수송은15/8N이다. 정지한 단일 입자의 h를1m에서2m로 바꾸면 원점 밀도는 절반이 되지만 전체 질량은 그대로다.

고정 폭의 질량·탄도 운동량 국소식과 유한 창의 상대 유입을 검증했다. 폭이 시간에 따라 바뀌면 질량뿐 아니라 운동량 관측에도 폭 미분 항을 추가한다. 빈 지지 구간의 속도와 영길이 창의 평균은 미정이다. h는0.02–2m, 양의 창 길이는10⁻⁸m 이상인 명시적 교육용 범위를 사용하며 작은 입력을 임의로 확대하지 않는다. 공간적으로 변하는 폭·벽면 재정규화·일반 유체 응력은 미포함이다.

## 가능한 평균 길이와 계수 요동

균일 Poisson 계수 기준에서 기대 개수는 n ell³, 상대 표준편차는1/√(n ell³)다. 허용 요동 epsilon의 계수 하한과 c lambda의 충돌 하한을 eta L의 해상도 상한과 비교한다. 후보 구간이 존재해도 현재 ell이 구간 밖일 수 있다. 경계 등호는 선택한 부등식의 약속이며 점근적 척도 분리·오차 상한·실제 국소 평형의 증거가 아니다.

손계산에서 n=10²⁴/m³, lambda=10⁻⁷m, L=10⁻³m, epsilon=0.01, eta=0.1, c=10이면 후보 구간은10⁻⁶–10⁻⁴m다. ell=10⁻⁵m의 기대 개수는10⁹이다. L만10⁻⁶m로 줄이면 상한이 충돌 하한보다 작아져 후보 구간이 사라진다. n·lambda는 독립 비교 입력이며 실제 물질에 적용하려면 같은 상태의 일관된 값인지 확인해야 한다.

고정 총개수의 균일 독립 위치에는 이항 분산 Np(1−p)를 사용한다. N=1000,p=0.1의 상대 표준편차는√90/100이다. p=0의 미정 비와 p=1의 정확한0을 구분한다. 상관된 물질에 Poisson 분산을 자동 적용하지 않으며 Fano 계수·시간 척도·벽면·열적 완화·구성 관계는 별도의 증거가 필요하다.

## 독립 계산과 실행 결과

제품을 가져오지 않는 Python 생성기로 실제 커널 정의의 공간 구적·위치/시간/폭 미분48조건과 이항 확률 전체 열거95조건을 계산했다.55자리 정확 이진 입력 참조를 별도 경로로 재생성해 canonical 파일과 해시까지 일치함을 확인했다. 기존 참조 덮어쓰기도 실제로 거부되고 파일이 보존되는지 검사했다.
