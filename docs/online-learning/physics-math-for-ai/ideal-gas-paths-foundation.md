# 이상기체 두 경로 기반 구현

최신: [온도·열·일의 홈페이지 입문 통합 검증을 마쳤다](temperature-heat-work-authoring-status.md). 아래는 해당 단계의 기록이며 전체 영역·연구 심화 완료를 뜻하지 않는다.

2026-11-06. `ideal-gas-two-path-heat-work`의 계산 모델과 한영 본문을 작성했다. 앞선 [열접촉 가족](thermal-contact-foundation.md)과 함께 첫 주제의 기반을 검증했다. 실습·그림·교재 등록·홈페이지 통합은 아직 남아 있으며,502단원·1506안내·279입문 검증·83미완료를 유지한다.

## 계·단위·경로

`src/lib/learning-ideal-gas-paths.ts`는 물질량이 일정한 단원자 이상기체, Cᵥ=3R/2, 마찰 없는 준정적 체적 제어, 가역 열 교환을 가정한다. 물질량0.25–2 mol, 두 온도250–350 K, 두 부피0.005–0.04 m³, 진행률0–1을 허용한다. 압력은 nRT/V로 계산하며 단위는Pa다. R은 SI 정의 값의 이진 근사를 사용한다.

A는 고정 부피에서 온도를 바꾼 뒤 고정 온도에서 부피를 바꾼다. B는 순서를 뒤집는다. 각 단계에 진행률 절반을 주고 온도·부피를 선형으로 보간한다. 이는 경로 위치이며 시간·속도·전력이 아니다. 피스톤 동역학이나 유한 온도차의 열전달을 푼 모형이 아니다.

일은 기체가 외부에 하면 양수이고 ΔU=Q−W다. 각 경로의 상태·압력·현재 누적 열/일/내부 에너지/엔트로피를 계산한다. 전체 끝점 비교와 A정방향/B역방향 순환의 일 차이도 직접 계산한다. 가스의 엔트로피 변화와 가역 실현의 총 생성0을 구별한다.

## 수치 상쇄와 판정

현재 온도·부피를 구성할 때 공급된 이진 입력을 합·곱으로 유지하고 마지막에 표시값으로 투영한다. 작은 변화량은 따로 관측한다. 엔트로피는 온도 로그와 부피 로그를 따로 더하지 않고 하나의 양의 유리수 비에 대한 로그로 결합한다. 따라서 정확한 상태 엔트로피0과 그 양쪽 작은 변화를 구별한다.

열의 두 항이 반대 부호이면 범위를 줄인 로그의 양의atanh급수에 정수 내림/올림을 적용해 상하한을 만든다. 남은 꼬리의 상한도 포함한다.128비트에서 시작해 필요하면2048비트까지 좁혀 부호와 상대 폭을 확인한다. 판정 실패는 전체 열 관측의 `null`/`unresolved`로, 크기만 표현 범위 밖인 관측은 값의 `null`과 비영 부호·로그로 구별한다. 모든 지수·로그 계산이 임의 정밀도라는 주장은 하지 않는다.

실제 회귀 사례에서는 n=1,T₀=251,T₁=271,V₀=0.015625,V₁=0.013987598122283916인 A의 반올림 ΔU+W가0이지만 열은3.468780578357212×10⁻¹⁴ J로 양수다. 가정 안의 정확한 입력 모형에서 생기는 차이며 실험 측정 정밀도를 뜻하지 않는다.

## 독립 계산·본문 확인

`scripts/learning/generate-ideal-gas-path-references.py`는 제품과 다른 방법으로 경로를 재구성한다. `fractions.Fraction`으로 이진 입력의 경로 좌표를 보존하고,24일반 사례는160자리로 실제 p dV·Cᵥ dT·가역 열/T 적분을 계산한다.21극한 사례는1000자리로 계산한다. 극소 진행률, 같은 끝점, 단계 경계, 정확한 등엔트로피 끝점과 그 양쪽, 넓은 온도/부피 비, 열 상쇄 근방과 위의 잘못된0을 포함한다. 독립 생성기를 재실행한 출력은 고정 참조와 바이트 단위로 일치한다.

이상기체 모델59검사·본문 렌더링1검사와 기존 열접촉51검사, 총111검사를 통과했다. 타입 검사·새 파일lint도 통과했다. 두 언어의 수식 일치·6개 풀이·앵커·수식 스크롤 접근성·영어의 한글 부재를 확인했다. 아직 새 화면의 브라우저 검증이나 새 페이지 빌드를 수행한 것은 아니다.

원고는 `content/learning/physics-math-for-ai/ideal-gas-two-path-heat-work.{ko,en}.md`다. 끝점 엔트로피가 같아도 단열 경로가 아닌 예, 진행률의 의미와 수치 상쇄 예를 추가했다. 본문·모델·참조·실행 기록은 `.runtime/learning/ideal-gas-paths-foundation-verification.json`에 연결한다.
