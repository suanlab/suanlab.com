# 앙상블·Holevo 정보와 상대 엔트로피의 수치 기반

2026-11-09. 양자정보 순서3·4의 한영 원고4개, 엔트로피 구간 연산과 두 계산기를 추가했다. 앞의 두 단원과 합쳐 **4/9단원의 본문·수치 기반**이 준비되었다. 실제 등록·Worker·학습 화면의 완료를 뜻하지 않는다.

## 본문과 예제

두 단원 모두 언어별10절·해설 문제6개다. 앙상블 본문은 고전-양자 블록 상태의 엔트로피 유도, 측정 확률표, 달성 정보량과 Holevo 상계, 정답 확률 최적화와 정보량 최적화의 차이를 다룬다. 자체 예제의 평균 고유값은4/5·1/5이고, 선택한 Helstrom 측정의 정보량은 약0.531004bit, Holevo 정보는 약0.721928bit다.

상대 엔트로피 본문은 행렬 로그와 원소별 로그를 구별하고, 비직교 순수 상태 사이에서도 지지집합 때문에 무한값이 나오는 예를 설명한다. 비가환 혼합 쌍에서 완전 Z 탈위상 전후 값1.0150374993·0.2780719051과 손실log₂(5/3)를 계산한다. 등호가 전역 역함수를 뜻하지 않는다는 반례와 작은 양의 고유값을 반올림하면 안 되는 이유도 포함한다.

## 수치 계약

- 물리성·사전확률은 기존 정확 유리수 판별기로 검사한다. 내부 스펙트럼의 제곱근은512bit 방향 구간, 로그는256bit 방향 구간으로 계산한다.
- 이진 엔트로피는 구간 안의 최대점1/2까지 검사한다. 음수 로그와 가중치의 곱은 네 끝점으로 감싼다.
- 앙상블은 Z 또는 Helstrom 측정의 정보를 평가한다. accessible information을 최적화했다고 주장하지 않는다. 알려진 비음수/Holevo 범위와 교차한 결과뿐 아니라 **교차 전 원래 정보량과 Holevo 구간**도 반환하고 검사한다.
- 상대 엔트로피의 지지집합 실패는 정확하게 분류한다. 무한값을 유한 수나 JSON Infinity로 바꾸지 않는다. full-rank 참조의 작은 고유값이 현재 정밀도에서 분리되지 않으면 명시적으로 실패한다.
- 탈위상 비교는 두 상태에 같은 채널을 적용한다. Petz 회복·일반 차원 해법·보안·용량 정리를 구현한 것은 아니다.

## 독립 참조와 검사

`generate-quantum-information-entropy-references.py`는130자리 mpmath Hermitian 행렬 고유분해로 앙상블/측정384개, 상대 엔트로피64쌍을 생성한다. 계산기는 이 참조를 가져다 쓰지 않는다. 참조는120자리 십진 중심과 보수적1e-110 대조 여유를 쓰는 고정밀 수치 참조이며, 엄밀한 구간 증명서로 과장하지 않는다. 이전 판별의 대수적 증명서 검증과는 별도 방식이다.

새458검사는 교차 전후 구간을 모두 대조하고, 작은 full-rank 고유값·입력 거부·확정 표지·정답 확률/정보량의 다른 최적화와 한영 strict KaTeX 렌더링을 확인한다. 참조 재생성 바이트, 타입·lint·이전 판별/유한 블록/회로/채널 회귀, 기존 소스·정적 출력 보존은 `.runtime/learning/quantum-information-entropy/verification.json`에 기록한다.
