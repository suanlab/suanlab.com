## 물리와 수치의 계약

일정 SI 계수의 c=1/√(εμ)를 유지한다. 기본 ε는 반올림 교육용 μ와 SI 광속으로 함께 유도하며, 임의 계수를 실제 물질의 완전한 구성 법칙이라고 해석하지 않는다. 평면파 입력 시간은 ns, 내부 시간은 s다. E와 cB만 같은 단위로 비교하며 실제 B는 SI 표에 별도 표시한다.

xz 경로의 법선은−y, yz 경로의 법선은+x다. 고정 열린 면의 순환 법칙과 닫힌 상자의 Gauss 법칙을 구분한다. 자속과 시간 변화율, V·T m·Wb의 단위를 섞지 않는다. 주파수 음성 대조는 발산 두 식과 한 점의 잔차를 통과해도 일반 위상의 진화식을 위반할 수 있다. 영진폭·영파수는 별도의 유효한 퇴화 경우다.

작은 cos 끝값 차이는 중간 위상과 sinc로 계산하여 실제 비영 폭을 유지한다. 직접 끝값 차감은 별도로 비교한다. 정확한 면적0에서는 평균이 미정이며 수치 범위 손실을 물리적0으로 채우지 않는다. ns·pC 입력의 SI 변환이 비영 값을 잃으면 해당 관측은 사용 불가로 표시한다.

방사형 장은 경계 전류가 필요한 유계 제조해다. 입자 수송·물질 응답·유한 고립 장치를 푼 모형이 아니다. 전도와 변위 전류를 구분하며, 변위 전류를 전하 수송으로 이중 계산하지 않는다. 일정 밀도 편차는 보존·진화 관계를 유지해도 초기 Gauss 제약을 위반한다. 편차는 실제 원천 변화이며 게이지가 아니다. 안정 결함과 반올림 밀도로 계산한 잔차를 분리하고, 후자의 작은 요동은 산술 오차임을 명시한다.

별도 Python 계산54평면파·81구 전하·3얇은 경로는 [기초 집필 기록](maxwell-foundation.md)을 따른다. 공유 해석식 잔차·반대 면 상쇄는 독립 검증이나 엄밀한 오차 인증이 아니다. 원점의 장0과 비영 발산, 작은 구의 비영 선속과 사용 불가 전하도 구분한다.
