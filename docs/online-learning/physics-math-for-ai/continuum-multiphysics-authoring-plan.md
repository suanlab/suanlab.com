## 열·탄성의 상호 에너지 교환

예정 ID: `thermoelastic-mode-reciprocal-energy-exchange`.

작은 변형·기준 절대온도 근처의1차원 열탄성체에서 변위와 온도 편차의 주기 단일 모드를 유도한다. 열팽창 응력과 변형률 속도의 역방향 열 항을 동시에 포함한다.3상태 선형 계의 행렬 지수와 실제 공간 적분으로 역학·열 가용 에너지 교환 및 전도 소산을 대조한다. 이차 가용 에너지가 실제 전체 내부 에너지·누적 열량과 같다는 해석은 하지 않는다.

초기 변위·속도·온도 편차를 분리하고 결합0,전도0,음의 온도 편차,작은 진폭·결합,실제0과 로그로 남는 작은 교환을 다룬다. 역결합을 생략한 모델은 다른 모델로 계산하며,외부 열 포트를 추가하지 않고 닫힌 계의 보존으로 포장하지 않는다. 행렬법·시간 적분·상호 교환 항·원래 PDE의 미분을 독립적으로 검사한다.

개념4단계는 열팽창과 역작용,두 에너지 사이의 상쇄,전도 소산,일방향 근사의 누락이다. 안내3개·퀴즈2개와 한영 상세 원고·손계산·풀이6개씩을 제공한다.

## 열·전기 막대의 열과 일 수지

예정 ID: `thermoelectric-bar-seebeck-peltier-joule-balance`.

양의 길이·면적·전기저항률·열전도도와 양의 양끝 절대온도에서 정상 막대를 다룬다. 상수 Seebeck 계수,선언한 전위차와 부호 있는 전류,Π=ST를 함께 사용한다. 온도 포물선·전기장·열 플럭스·단자 전력과 두 끝 열 포트를 계산한다. Joule 소모,가역 교환과 실제 냉각/발전 조건을 구별한다.

열전 개방회로의 영 전류와 비영 열전도,Seebeck0,온도차0,전류 반전,작은 비영 전력·상쇄·기준 전위의 불변성을 포함한다. 단일 막대를 모든 접촉·반환 경로·열저항을 가진 실제 냉각기로 부르지 않는다. 양의 냉각열·양의 입력 전력이 확인되지 않은 비를 COP로 표시하지 않는다.

개념4단계는 단자 조건과 전류,전도·Peltier 열 플럭스,Joule과 국소 수지,전체 전력·경계 열이다. 안내3개·퀴즈2개와 한영 상세 원고·손계산·풀이6개씩을 제공한다.
