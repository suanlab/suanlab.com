## 수치와 그림의 해석

후보는 정확한 증명 검사를 통과한 뒤에만 독립 정련에 사용된다. 관찰 구간은 생산기 한 번의 반올림과 같은 byte라는 조건 대신 별도 인증 구간을 포함해야 한다. 양쪽 구현이 같은 모형 매개변수를 사용함을 원래 입력 표기까지 확인한다. 54개 표본 대조는 모든 연속 입력에 대한 반복 횟수/균일 상대 정확도 정리가 아니다. 예산을 넘거나 인증이 해결되지 않으면 성공 결과를 내지 않는다.

c₁ 구간의 인증과 버린 고차 항의 오차 보증은 다르다. 실제 적분비 경계는 λ=0 또는 인증된 영점 정상 경로에만 제공한다. 양끝0은 충분조건이며 N=2의 반대 끝점도 포함한다. 일반 비영 경로에는 같은 Taylor 경계를 제공하지 않는다. 유효하지만 넓은[0,1] 경계를 숨기지 않는다.

정상점은 일반적으로 실제 평균이 아니며 Gaussian 공분산은 실제 사차 공분산이 아니다. 단면은 다른 좌표를 고정하고, 주변분포는 그 좌표를 적분한다. 두 폭을 같다고 표시하지 않는다. Well은 별도의1좌표 모형이며 전체 적분·고차 오차·양자 이중 우물 경로·터널링을 계산하지 않는다. 소수 곡선·3D 높이·지수/제곱근 그림을 인증된 값으로 부르지 않는다.
