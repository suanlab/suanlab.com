# 유한계·열역학 극한 연구 보강 검증 기록

2026-11-13. 기존 경계 성장·광역성과 가법성, 공간 밀도의 자기 평균화, 두 상 분배함수의 영점·둥글림 **3단원·한영 6원고**에 연구 설명과 그림 6개를 추가했다. 기존 본문과 풀이 36개를 그대로 보존했다. 표시 수식 48개·실행 Python과 표 각 6개·연구 해설 18개를 추가했다.

## 연구 내용과 적용 범위

- **경계 자유 에너지와 확률 거리:** 유한 양의 역온도에서 경계 에너지의 균일 상한을 분배함수와 자유 에너지 상한으로 옮긴다. 무자기장 열린 Ising 사슬을 직접 연결해 자유 에너지 밀도 차가 사라져도 전체 블록의 TV·상호 정보가 남는 예를 계산한다. 경계 상한이 사라지지 않는다는 사실만으로 실제 차가 비영이라고 결론 내리지 않는다.
- **약한 극한과 희귀 모드:** IID/집단 Bernoulli 혼합에서 중심극한 수렴과 이차 모멘트 수렴을 구별한다. 집단 확률이 c/N이면 사라지는 질량이 유한한 분산을 운반한다. 실제 유한 분산으로 표준화한 극한·균등 적분 가능성·알려진 모형의 중앙 확률을 비교한다. 이산 법칙과 Gaussian의 TV 수렴이나 추정 신뢰구간을 주장하지 않는다.
- **축퇴 가중치와 복소 영점:** 새로운 기준 가중치 N^κ가 동일한 압력 극한 아래 전이 중심을 이동시키는 예를 유도한다. 둥글림 폭·중심 이동·복소 영점·반응도의 측도 극한을 대조한다. 기존 두 동일 가중 상태의 실습과 구별하며 다항 축퇴를 원문의 지수 축퇴와 동일시하지 않는다.

이론 출처와 직접 유도의 경계는 [출처 기록](thermo-statmech-source-audit.md), 계산·해시·화면 범위는 [JSON 근거](finite-size-research-evidence.json)에 기록한다.

## 독립 계산과 원문 보존

열린 사슬의 미시 상태를 직접 열거한 36준비에서 분배함수·KL·TV·상호 정보·주변 분포·상관을 확인했다. 비영 자기장 경계 부등식 63개, 유리수 혼합 모멘트 288개, 특성함수 대조 36개, 희귀 꼬리 4개를 검산했다. 양의 실수장 256준비와 복소 영점 544개, 반응도의 수치 적분 4개도 독립 대조했다. 이는 원고의 명시한 유한 모형 검산이며 일반 열역학 극한 정리의 증명이 아니다.

관련 회귀 **209검사**를 통과했다. 다른 29단원·58원고와 앞선 연구 자산 186개를 유지했다. 보존 장부 859항목에 새 검토 6개를 추가해 865항목이다. 등록은 650단원·1,969안내, 원래 범위는 51영역·509주제다.
