# 파동·진동·음향·광학 9원주제 연구 대조 진행

2026-11-13. 전체 **51영역·509주제**를 유지하며 다음 영역의 기존 **9주제·18단원·36한영 원고**를 원래 순서로 대조한다. 입문 집필 완료와 구분한다. 공진·결합 진동·파동 방정식·간섭 회절·분산 군속도·편광·기하 파동 광학·Fourier optics 열여섯 단원의 한영 연구 보강 **16/18단원**을 재검증했다. 나머지 원고와 영역 전체의 연구 대조는 계속 진행한다.

## 보존과 검증 기준

기존 [입문 영역 감사](waves-optics-domain-audit.md)와 [대응표](waves-optics-domain-audit-plan.md)는 당시 검토의 근거로 남긴다. 현재 등록은 650단원·1,969안내다. 기존 원고·여섯 해설 문제·실습 입력·선수 순서를 보존하고, 새 예제의 물리 가정·단위·유도·한영 의미·실행 코드·그림을 검토한다. 개별 보강을 전체 영역 대조 완료로 바꾸어 집계하지 않는다.

## 다음 순서와 전체 범위

첫 두 단원의 원고·계산·최종 16화면 검증을 마쳤다. 선택 4파일·44검사와 빌드·타입·1,888 HTML 정적 검증을 통과했다. 영어 모바일 6안내·4퀴즈·8개념 선택·2저장/완료 그룹을 확인했다. 결합 진동 두 단원도 선택 4파일·51검사와 최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. 각 배치의 화면 검사를 같은 최종 빌드의 전체 영역 검사로 합산하지 않는다. 파동 방정식 두 단원도 선택 49검사·최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. 간섭·회절 두 단원도 선택 47검사·최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. 분산·군속도 두 단원도 선택 53검사·최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. 편광 두 단원도 선택 50검사·최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. 기하·파동 광학 두 단원도 선택 48검사·최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. Fourier optics 두 단원도 선택 54검사·최종 16화면·6안내·4퀴즈·2저장/완료 그룹을 검증했다. 다음은 관측·샘플링·센서다. 다른 2단원에는 이미 상세 본문과 실습이 있으므로 기존 근거를 읽고 부족한 부분을 보강한다. 모든 18단원과 9원주제를 대조한 뒤 영역 집계를 갱신한다.

현재 전체 대조 기록은 **40영역·396주제**, 후속은 **11영역·113주제**다. 입문 **362/362**와 요청 당시 미완료 **48개**는 완료 상태이며, 연구 심화와 공개 배포는 별도 확인한다. [전체 색인](domain-topic-review-index.md)을 따른다.
