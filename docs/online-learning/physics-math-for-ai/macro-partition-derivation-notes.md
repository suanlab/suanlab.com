# 가중 미시분포와 결정론적 거시 관측: 계산 계약

2026-11-06. 둘째 가족 `finite-macro-partition-conditional-entropy`의 도출·독립 참조 준비다. 생산 모델 검증까지 진행했다. 상세 한영 원고 검증도 마쳤고 교육 UI는 아직 없다. 현재 결과는 [본문 기반 보고서](macro-partition-manuscript-foundation.md), 초기 모델 단계는 [모델 보고서](macro-partition-model-foundation.md)에 기록한다.

## 입력과 관측

미시상태 i=0,…,n−1의 가중치 wᵢ≥0, 비교 목표 vᵢ≥0와 사상 g(i)∈{0,…,G−1}를 받는다. 두 가중치 벡터 각각의 합은 양수다. 유한 계산기의 n,G 한도는32를 계획한다. 모든 유한 binary64 입력을 정확한 이진 유리수로 해석하고 합을 먼저 Number로 투영하지 않는다.

pᵢ=wᵢ/W, qᵢ=vᵢ/V, 상태군 Cₘ={i:g(i)=m}, 크기 Ωₘ=|Cₘ|다. 군 확률은 Pₘ=Σᵢ∈Cₘpᵢ, Qₘ=Σᵢ∈Cₘqᵢ다. Pₘ>0일 때만 rᵢ|ₘ=pᵢ/Pₘ를 정의한다. Q의 조건부도 별도로 같은 규칙을 따른다. Ωₘ=0인 빈 군과 Ωₘ>0이지만 Pₘ=0인 군을 구별한다. 둘 다 p의 조건부 분포는 정의되지 않으며 가중 엔트로피 기여만0이다.

## 세 엔트로피를 분리하기

자연로그를 사용하면 H(p)=−Σpᵢlnpᵢ, H(P)=−ΣPₘlnPₘ이며 H(p)=H(P)+ΣPₘH(rₘ)다. 결정론적 관측의 H(P)는 원래 미시 정보량보다 크지 않다.

각 비어 있지 않은 군 안을 균등하게 채운 재구성을 pbarᵢ=P_g(i)/Ω_g(i)로 따로 정의한다. 이는 실제 준비 p의 조건부를 추정한 결과가 아니라 선택한 추가 규칙이다. H(pbar)=H(P)+ΣPₘlnΩₘ이고

`H(pbar)−H(p)=Σ(Pₘ>0) Pₘ D(rₘ || uniform(Cₘ))≥0`.

생산 모델은 가까운 두 엔트로피를 빼서 이 작은 양수를 구하지 않는다. 원래 가중치로 양의 조건부 KL 기여를 계산해야 한다. 별도의 환경·동역학·에너지 가정이 없으므로 이 재구성의 정보 증가를 실제 계의 열역학적 엔트로피 생성이나 비가역 시간 진화로 부르지 않는다.

## 목표 분포와 지지집합

p가 양수인 모든 자리에서 q도 양수이면 `D(p||q)=D(P||Q)+Σ(Pₘ>0)PₘD(rₘ||sₘ)`이다. 관측으로 KL이 증가하지 않으며, 동등 조건은 양의 P를 갖는 모든 군에서 두 조건부가 같은 것이다.

pᵢ>0,qᵢ=0이면 미시 KL은 수학적 무한대다. 같은 군의 다른 자리에서 q가 양수라면 군 KL은 유한하고 내부 KL이 무한대일 수 있다. Pₘ>0,Qₘ=0이면 군 KL부터 무한대이며 목표 조건부 sₘ는 정의되지 않는다. 이때 조건부 합을 임의로 채우거나 무한대끼리 빼지 않는다.

JSON에는 KL의 `status: finite | infinite`를 별도로 둔다. 유한하지만 표시 범위 밖인 양수는 finite, value=null, sign=1, 유한 logMagnitude로 남긴다. 수학적 무한대는 infinite와 value=null을 사용한다. 정의되지 않은 조건부 분포나 해당 분해 항은 null이다. 실제0은 value=0, sign=0이다.

## 손계산과 교육 예제

1. p=(.6,.2,.1,.1), 군은{0,1}/{2,3}. P=(.8,.2), 조건부는(.75,.25)/(.5,.5)다. H(p)=1.088899975, H(P)=.500402424, H(X|M)=.588497552 nat이다. 재구성은(.4,.4,.1,.1), 엔트로피는1.193549604, 증가량은.104649629다.
2. p=(.8,0,.1,.1)도 P=(.8,.2)로 같다. H(p)=.639031860이므로 군 확률만으로 미시 엔트로피를 복원하지 못한다. 같은 균등 재구성까지의 증가량은.554517744다.
3. 상태마다 다른 군이면 H(M)=H(X), 조건부 엔트로피와 재구성 증가량은0이다. 모든 상태를 한 군으로 묶으면 H(M)=0이고 숨은 정보량이 H(X) 전체다.
4. p=(1,0,0), 사상(0,1,1), G=3. 군1은 두 상태를 갖지만 준비 확률0이고 군2는 아예 비었다. 두 군에 임의의 조건부 확률을 표시하지 않는다.
5. p=(1/2,1/2), q=(1,0)를 한 군으로 묶으면 거시 KL은0, 미시·내부 KL은 무한대다. 관측에서 차이가 안 보인다고 원래 분포가 같은 것은 아니다.
6. 같은 p,q에서 각 상태를 별도 군으로 두면 거시 KL도 무한대다. 두 번째 군의 목표 조건부는 정의되지 않는다. 이는 아주 작은 양수 확률의 underflow와 다르다.

## 독립 기준값과 남은 구현

`generate-macro-partition-references.py`는 생산 코드에 의존하지 않고 Fraction으로 정규화한 뒤4096자리 mpmath 직접 로그 합을 사용한다. 일반24개와 극한12개에 대해 엔트로피 연쇄·재구성 차이·유한 KL 분해를 독립 확인한다. 작은 예제, 빈 군, 지지집합 위반, 합의 overflow, 최소 양수 가중치, 한 ULP 차이, 극소 정규화 변화가 포함된다. 초기1800자리 참조는 한 극한 사례의 약10⁻¹⁸⁹⁵ 거시 KL을 분해하지 못해4096자리로 교정했다. 과거 준비 증거는 당시 기록이며 현재 기준값은 수정된 참조다. 근사 항등식 확인의 절대 허용치는10⁻³⁰⁰⁰이다. 참조의 내부 항등식만으로 생산 모델의 정확성을 증명하지 않는다.

현재 구현은 정확한 군 합·조건부 확률·재구성 확률과 투영 전 엔트로피 기여를 반환하고, KL을 근접 분포에서도 안정적으로 계산한다. 독립 참조와 성질 검사의 모델 검증을 마쳤으며, 한영 본문도 검증했다. 다음은 잡음 관측 가족과 시각화다.
