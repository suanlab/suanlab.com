# 정준 그래프·Gauss 제약 단원의 자료와 모형 범위

2026-11-10. `graph-gauss-constraints-physical-phase-space`의 입문 범위를 정한다. 이 문서는 집필·독립 계산을 위한 범위 검토이며 단원 완료나 홈페이지 등록을 뜻하지 않는다.

## 확인한 일차 자료

- [David Tong, Gauge Theory, §2.2.1](https://davidtong.org/pdfs/teaching/gauge-theory/gauge2.pdf), 인쇄40–42쪽,식2.27–2.30: 시간 성분을 고정한 뒤에도 Gauss 방정식을 제약으로 유지한다. 정준 운동량과 전기장의 관계는 정규화와 추가 항에 의존한다. 국소 변환의 생성자와 경계에서 남는 대칭을 구분한다. 본 교재의 유한 Abelian 모형으로 비가환·theta항 결과까지 구현했다고 주장하지 않는다.
- [Kaplan–Stryker, arXiv:1806.08797v2, §I](https://arxiv.org/html/1806.08797): 링크의 원형 좌표와 전기적 공액 변수,Gauss 조건과 물리적 상태 공간을 확인했다. 이 논문은 양자 주기 격자이며 위상적 전기 선속도 별도로 고정한다. 논문의 변수 수를 임의 그래프의 고전 위상공간 차원으로 복사하지 않는다.

두 자료의 관련 절을 직접 읽었다. 아래 유한 그래프의 부호·차원·숲 해법은 교재에서 유도하고 별도 정확 계산으로 검사할 내용이다. 연속체나 양자 결과를 직접 이산화했다고 제시하지 않는다.

## 구현할 모형

유한 방향 그래프의 고전 위상공간을 `T*U(1)^E`로 두고 `Ue=exp(i Ae)`,실수 공액 운동량 `pe`, `{Ae,pf}=δef`를 사용한다. 전기적 변수는 이 정규화의 운동량이며 양자 정수 스펙트럼은 구현하지 않는다. 물질 동역학도 없으며 전하는 고정된 매개변수다.

접속행렬B의 간선 열은 from에서+1,to에서−1이다. 자기 루프는0열이다. 변환은 `A→A+Bᵀα`,앵커에서는α=0이다. 비앵커 행I에서만 `BI p=ρI`를 부과하고 앵커의 전하는 입력하지 않는다. 따라서 전체 중성이 필요한 성분과 경계로 선속을 내보내는 성분을 구분한다.

앵커 호환 숲의 경로 행렬P에 대해 `BI Pᵀ=0`,비숲 간선 열의 단위행렬을 검사한다. `p=p0+Pᵀπ`라는 affine 제약 해,원형 좌표 `exp(iθ)=∏U^P`와 공액π를 설명한다. 제약이 불가능한 전하에서는 물리 위상공간 차원을 표시하지 않는다. 제약을 어긴 입력을 몰래 투영하거나 물리 상태로 부르지 않는다.

에너지는 양의 전기 계수와 명시한 닫힌/앵커 사이 경로의 `κ(1−Re W)`로 정의한다. 열린 경로 항은 외부 앵커 기준을 이용한 선택이며 일반 Maxwell자기 에너지로 동일시하지 않는다. 숲을 바꿔도 같은 경로 항을 유지한다. 정확한 Hamiltonian벡터장과 Gauss미분을 계산하되 시간 적분의 정확도나 연속체 수렴은 주장하지 않는다.
