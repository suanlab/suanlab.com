# 분산·군속도의 홈페이지 연결

2026-11-05. 기존 HSL 색상·명암 테마·독자 화면에 계산 모델 두 개와 상세 한영 원고 네 개를 연결했다. 전체 교육과정과 연구 심화의 완료 여부는 별도로 관리한다.

## 연결한 구성

| 단원 | 계산과 시각화 |
| --- | --- |
| `dispersive-wave-packets-phase-group-velocity` | 실제 실수장·복소장·포락선, 초기/현재 강도, Fourier 진폭·분산 관계·접선, 전체 위상·국소 파수·chirp, 폭·중심·최고값·노름의 시간 변화 |
| `lattice-wave-packet-transport-dispersion` | 실제 질량의 변위·속도, 해석장 강도와 배분 에너지, 링크 전력·국소 수지·잔차, 모드 진폭·에너지·분산, 세 전달 속도·두 원형 중심·집중도 |

기본 SVG28개·표4개, 개념 단계8개·안내 실험6개·해설 퀴즈4개를 한영으로 제공한다. 각 상세 원고의16개 절·여섯 개 해설 문제와 실제 독립 기준값은 [기반 집필 기록](dispersion-foundation.md)에 있다.

Gaussian의10개 예제는 세 속도의 차이, 영분산의 모양 보존, 같은 강도와 반대 chirp, 초기 시각·영진폭·영파수·정지/왼쪽 포락선·위상 반전과 빠른 위상을 비교한다. σ는 진폭 폭이며 강도 표준편차는 W/√2다. 전체 노름을 역학적 에너지로 표시하지 않는다.

격자의11개 예제는 좁은/넓은 대역, 실제 진행 시각, 영에너지, 세 입자만큼의 병진, 주기 중심0과8 m, 같은 재료의64입자, 격자 한계 근처와 큰 기울기를 비교한다. 실제 질량·강성·에너지·전력에 SI 단위를 사용한다. 고정한 최고 진폭 상한과 같은 준비 에너지는 다르다.

## 계산과 표시에서 지킨 조건

Gaussian의 표시 구간은 초기장과 현재 포락선의 ±4폭을 함께 포함한다. 각 곡선을 자기 최대값으로 나누지 않는다. 국소 전체 위상의 기울기는 공간에서 일차식이므로 끝점의 최대값과 초기 반송 파수를 사용해 모든 그림 간격의 위상 변화가0.15 rad 이하가 되도록 표본을 정한다. 실제 Fourier 적분과 그림 표본 수는 별개다. 전체 위상과 반송 기준선도 구분한다.

초기/현재 비교에서 시간에 따라 표시 구간과 적응 표본 수가 달라질 수 있다. 반대 분산 부호를 대조하는 검사는 같은 공간 좌표에서 강도를 비교하며, 배열 길이가 같아야 한다는 잘못된 조건을 요구하지 않는다. 복소장 차이는 허수부 하나가 아니라 실제 복소 차이로 평가한다.

영진폭의 관측 중심·위상과 영 반송 파수의 위상속도는 미정이다. 빈 관측을 가짜0의 궤적으로 그리지 않는다. Gaussian의 무한 꼬리와 움직이는 최고점으로 최초 정보 전면을 판단하지 않는다. 이차 포락선의 정확한 계산과 실제 매질의 인과 전파는 다르다.

격자는 실제 입자만 점으로 표시하며 Nyquist보다 낮은 양의 모드를 사용한다. 링크 전력의 위치는 링크 중점이다. 같은 에너지 배분에서 실제 시간 미분과 유입−유출 전력 및 잔차를 함께 보여 준다. 실제 전력에서 계산한 aΣJ/E와 에너지 가중 군속도, 반송 군속도는 따로 표시한다.

해석장 노름은 m³, 실제 에너지는 J다. 두 원형 중심은 각각의 집중도를 함께 제공하고 주기 경계의 점프나 미정값을 연결하지 않는다. 원형 중심의 시간 미분을 전체 전력 속도로 해석하지 않는다. 큰 기울기의 정확한 조화 격자 계산이 실제 줄의 선형 근사 타당성을 보증하지도 않는다.
