## 구현한 화면

`src/components/learning/finite-size-view.tsx`는 공통 버튼·키보드 접근 표·페이지 표·유리수/구간 인증 펼치기와 세 결과 화면을 제공한다. `finite-size-concept.tsx`는 고정 비교 series에6단계 설명·준비 선택·예측/해설을 연결한다. 입력·단계 키가 바뀌면 이전 화면 상태가 새 준비에 섞이지 않는다. 새 색이나 CSS를 추가하지 않고 기존 `ai-*`와 학습 색상 변수를 사용했다.

경계 화면은 성장 기록과 세 결합 그래프를 선택한다. 두 블록의 모식도와 정확한 면/자리/쌍 수를 나누고, 같은 기록의 제한 내부·교차·전체 에너지, 별도 Kac 정규화의 보정항을 비교한다. 모든 표는 선택 기록과 일치하며 전체 크기 경로 그래프는 별도로 표시한다. 큰 정수 자리 수는 문자열로 유지한다.

공간 혼합 화면은 계 전체의 모드 선택 기호도, 현재 N의 정확한 점유 수 분포, 선택 격자점의 편차·사건 포함과 양의 질량을 제공한다. 공분산 이중 합·분산 등가 수, 정확 꼬리·독립 참조·두 상한, 분산/N배 분산 경로와 극한 원자를 분리한다. 과거 요약의 확률과 현재 전체 분포를 섞지 않는다.

반올림 화면은 두 허용 배치, 고정 N의 장 응답, 압력 보정 구간과 g에서의 폭을 보여준다. 현재 N의 단위원 근을 선택하고 켤레·정확한 회전수·그림용 좌표를 대조한다. 양의 공존점과 홀수 차수의−1 근, 작은 양의 로그와 지수화한 값의 반올림 표시를 구별한다.

## 표시와 접근성

그래프는 이산 크기/점유 수의 시각적 연결이며 시간 궤적이나 연속 확률밀도가 아니다. 크기 축에는 실제 log₂ 크기를 사용한다. 부호 있는 값과 근사 ln 절댓값을 구별하고, 정확0은 로그축 아래 채운 점, 선형 표시 범위 밖 비영값은 빈 원, 미제공은 연결하지 않는 값으로 표시한다. 현재 관측량 표에서 부호·유리수·로그 구간을 확인할 수 있다.

SVG에는 고유 제목/설명과 범례, 표에는 caption·행/열 머리글과 스크롤 영역이 있다. 긴 정수와 구간 끝점은 펼쳐 읽고, 큰 분포·근 목록은32행 단위로 접근한다. 한 자리/확정 준비의 미제공과 정확0은 다른 문구다. 근 좌표는 근사이고 정확한 회전수가 위상 검산이라는 범위를 유지한다.
