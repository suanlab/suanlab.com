# 상관·요동: 세 가족의 실제 학습 화면 연결 계약

2026-11-07. 세 가족의 모델·원고 다음 구현 계약이다. [worker 기반](correlations-worker-foundation.md)은 별도 native 환경에서 검증했다. 개념·시각화·안내·퀴즈의 별도 구현·검증은 [학습 화면 기록](correlations-teaching-components.md)을 따른다. 아래는 원래 계약이며 실제 등록·Next 자산·읽기 검증은 아직 남았다. 현재 소스의 palette·한영·명암·모션 설정을 사용하고 도서 → Interactive Book에 연결한다. Online Book 목록에는 신규 진입 링크를 추가하지 않는다.

## 개념 단계와 그림

각 가족에 고정 준비6단계와 단계별 예측 질문·해설을 둔다. 전체18단계에서 자유 입력 실습과 고정 개념 준비를 분리한다.

| 가족 | 순서대로 설명할6단계 | 결과로부터 그릴 시각화 |
| --- | --- | --- |
| 두 스핀 | 네 상태 → 원시 곱/연결 값 → 음의 교차/양의 분산 → source 방향 → 척도 → Fisher 좌표 | 상태 가중치, 부호 공분산 표, 합·차 관측과 source 방향 |
| 고리 | 결합·주기 경계 → 두 경로 → 홀짝 부호 → 자기 항을 포함한 χ → 무한 사슬 길이 → 홀수 좌절 | 위치와 두 경로, 유한/무한 상관, 균일 반응·길이 비교 |
| AR(1) | 정상 초기 법칙 → 지연 공분산 → 유한 쌍 수 → 양의 혁신 분해 → 유한/점근 → 끝점·등가 수 | 공분산 창, 접두 n별 V, τ/n 참조, SE·분산 등가 수 |

그림은 worker 결과를 사용한다. 모델·고정밀 함수는 주 스레드의 component/config로 가져오지 않는다. 둥근 확률 구름의 기하를 부동소수점으로 그리더라도 고윳값·계수 인증으로 사용하지 않는다. 매우 작은 양의 값을 선으로 구별하지 못할 때 표의 부호·경계를 기준으로 읽도록 설명한다. 고리 강조가 움직이는 것은 경로 설명이며 물리적 시간 전이가 아니다.

AR(1) 최대512×512 전체 셀을 한 화면에 그리지 않는다. 그림의 관측 창과 전체 계산 범위를 표시하고, 전체 지연은 접근 가능한 페이지 나눔으로 읽는다. 끝점의 0은 로그 축에서 별도로 표시한다. 비혼합 끝점에는 τ/n 선을 그리지 않으며 음의 의존성의 진동 곡선을 단조 평활화하지 않는다.

## 안내 실험과 해설 퀴즈

각 가족3개 안내 실험으로 총9개를 준비한다. 각 실험에 예측·조작·관측할 값·해설과 실제 프리셋을 연결한다.

- 두 스핀: 영장 양·음 K의 합/차 분산; 편향 독립의 원시 곱과 연결 값; source 척도 두 배·영 관측량·작은 비영 결합.
- 고리: 삼각형/사각형의 두 경로; 홀수/짝수 반강자성 좌절; 같은 짧은 거리의 크기 증가와 길이/균일 반응 차이.
- AR(1): ρ=0/±1/2의 유한 쌍; 짧은 n에서 τ/n 보정; ±1 끝점과 인접 모수의 홀짝 분산·등가 수.

기본 준비는 128비트로 빠르게 계산되는 보통 입력을 사용한다. 최소 크기 입력과 정밀도 상한은 명시적 프리셋으로 분리한다. 각 가족3문항의 최종 퀴즈에서 좌표·관측량·단위·극한을 잘못 섞는 선택지를 해설한다. 바뀐 자유 입력을 고정 퀴즈의 정답 근거로 사용하지 않는다.

## Worker와 상태 수명

typed input/result 판별자를 가진 세 가족 공통 프로토콜·evaluator·controller·hook을 준비한다. evaluator만 모델을 import한다. 요청 ID·정규화된 입력 key·정밀도·family별 관측 구조를 검증한다. 이는 전송 계약 검증이며 임의 sender의 수학을 증명하는 검증기가 아니다.

새 입력은 이전 worker를 종료하고, 계산 시작·취소·재시도·복구·단원 이동·unmount에서 오래된 결과를 표시하지 않는다. worker 자산 실패 시 주 스레드에서 계산하는 fallback은 두지 않는다. SSR은 Worker를 읽거나 계산하지 않는다. 동기 계산 종료는 worker 자체 종료로 처리하며 메시지만 보내고 실행이 계속되는 상태를 취소 완료로 세지 않는다.

입력 초안의 빈 값·미완성 지수·표시 범위 이하 텍스트를 committed0으로 바꾸지 않는다. reset은 초안까지 지운다. localStorage 복원은 family·유한 값·범위·버전을 확인하며 알려진 구조적0, 수학적 무한대, 표시 범위 밖 비영, 정밀도 미해결을 구별한다. 전역 모션 정지·화면 밖 정지와 수동 조작도 각각 검증한다.

## 실제 등록 게이트

먼저 숫자 ID·원고·모델·전송·취소 검사를 통과시킨 뒤 세 단원·9안내를 등록하고 dispatch·cover·curriculum·검색을 연결한다. 기존524개 단원·안내 값과 상대 순서를 스냅샷으로 보존한다. 한영·명암·모바일/데스크톱 실제 읽기, 고정 준비·프리셋·퀴즈·저장 복원·접근성·근거 표시·최대 크기 페이지 나눔·실패 복구를 검사한다. Next 정적 worker가 실제 분리됐는지, 내부 링크·정적 출력·전체 회귀도 확인한다. 그전에는 원래 주제의 입문 완료 수를 올리지 않는다. 전체51영역·509주제와 연구 깊이는 별도 미완료 범위다.
