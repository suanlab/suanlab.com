2026-11-07. 유한계와 열역학 극한의 세 번째 가족에 자세한 한영 본문을 작성했다. 세 가족 모두 정확 모델·독립 기준·한영 원고가 준비되었으며, 실제 worker·학습 UI·읽기 등록은 아직 미완료다. 등록530단원·1,590안내, 원래289/362입문 검증·73미완료와 전체51영역509주제·연구 심화의 미완료를 유지한다.

## 본문과 예제

파일은 `content/learning/physics-math-for-ai/two-phase-partition-zeros-rounding.{ko,en}.md`다. 각15개 대제목·동일한 표시 수식14개·표3개·모식도2개·해설 문제6개다. 영문2,636단어·한국어 한글4,520자이며 길이보다 구체적인 상태·계산·풀이의 일치를 검증 근거로 삼았다.

완전히 비거나 완전히 점유한 두 배치에서 시작한다. 상태 공간을 먼저 지정해 독립 자리 분배함수와 혼동하지 않도록 하고, 네 자리의 활동도/역수/공존점 장부로 확률·밀도 분산·장 응답·지수화 압력 보정을 비교한다. 이어 고정 N의 응답과 크기 경로의 이동, 압력의 작은 보정과 미분·요동의 극한을 구별한다.

10–90% 반올림 폭은 g 좌표에서 유도한다. 역크기와 역제곱 경로는 유한 활동도와 정확 점유 확률을 직접 계산하고, 같은 공존점으로 접근해도 다른 밀도 극한을 갖는 이유를 설명한다. 복소 평면 그림은 정확 회전수 표와 함께 제공하며 각도를 N배 한 위상으로 다항식 영점을 검산한다. 마지막에는 t=10^−3072에서 양의 로그 보정을 보존하는 유리수 인수 분리와 급수 꼬리 상한을 설명한다.

## 검증한 구별

평균 밀도1/2가 절반만 점유한 허용 배치를 뜻하지 않는다. 복소 활동도에서는 항을 확률로 해석하지 않는다. 홀수 크기의−1 근, 양의 공존점1, 복소 로그의 여러 가지와 가장 가까운 대표값을 나눈다. 정확한 회전수·위상 항등식과 그림용 사인·코사인 좌표도 구별한다.

지수 기울이기가 정의되었기 때문에 성립하는 응답 관계를 임의의 입력 미분으로 일반화하지 않는다. 극소 양의 로그의 인증 구간, 지수화 보정의 정확 유리수와 반올림된 소수 표시는 서로 다른 표현이다. Tong의 독립 배경 인자 포함 예시와 현재 두 상태 준비를 구분하며, 일반 Lee–Yang 정리·AI 학습 전이를 증명했다고 하지 않는다.

## 검사와 보존

`scripts/learning-two-phase-rounding-content.test.ts`의 새8검사가 통과했다. 실제 학습 Markdown 로더에서 양 언어의 고유 목차·동일 수식·키보드 접근 가능한 수식/표/모식도·6개 풀이를 확인했다. KaTeX 오류·미해결 표식과 영어의 한글 누출은 없다. 유한 장부의 모든 값, 영점 표의 모든 회전수·홀짝 표시, 접근 경로 예제·공존점 배율·극소 로그를 정확 모델에 대조했다.

모델·공유 산술·첫 두 원고와 기존 유한 사슬 관련432검사, 합계440개와 typecheck·lint가 통과했다. 이번 단계에서 전체 프로젝트 테스트·정적 빌드·실제 브라우저 접근성 검사를 수행하지 않았다. Markdown 렌더링 속성 검사를 실제 교재의 전체 접근성 검증으로 확대하지 않는다.

이전 소스4,266개와 정적 출력4,287개의 바이트·경로 집합을 보존하고 한영 본문·본문 검사3파일을 추가했다. 증거는 `.runtime/learning/two-phase-rounding-manuscripts/verification.json`과 같은 디렉터리의 로그다. 기존 등록 교재와 계산 모델은 변경하지 않았다.
