# 기하·파동 광학 연구 보강 검증

2026-11-12. 기존 두 단원 한영 네 편에 상거리 불확실성과 개구 경계의 모멘트 정칙성을 보강했다. 기존 본문·여섯 해설 문제·실습 제어를 보존하며 불확실성·개구 제어를 새로 구현했다고 표현하지 않는다. 파동 순차 연구 대조는 **14/18단원**이고 전체 영역 완료가 아니다. 전체 대조 **40영역·396주제**, 후속 **11영역·113주제**를 유지한다.

## 보강 내용

- `paraxial-ray-matrices-thin-lens-imaging`: 물체 거리의 연속 불확실성이 초점 조건을 가로지를 때 실상·허상 가지와 역제곱 상거리 밀도를 유도했다. 정확한 극점 확률이 0이어도 평균·이차 모멘트는 존재하지 않을 수 있다. 절단 이차 모멘트의 성장, 잘못 확장한 국소 오차 막대, 같은 준비에서 유한한 고정 센서 좌표 통계, 극점에서 떨어진 영역의 명시적 전개 나머지 상계를 구분한다. 기존 아홉 광선의 각도 부채꼴 RMS를 다른 모집단 통계로 바꾸지 않는다.
- `gaussian-beam-focusing-ray-wave-limit`: 별도 일차원 Fresnel 모델의 딱딱한 상자와 연속 사다리꼴 개구 계열을 구성했다. 유한 장 노름·점별 유계성·횡파수 이차 모멘트·전체 직선 위치 RMS의 조건을 구분한다. 경계를 날카롭게 할 때 L2 장 거리는 0으로 가지만 영이 아닌 고정 거리의 RMS는 발산하는 계열을 유도했다. 유한 검출기 창과 근축 모델의 물리적 유효성 한계를 명시하며 실제 Maxwell 장의 무한 측정 폭을 주장하지 않는다.

한영 수식은 단원별 8개씩, 실행 Python 셀·수치 표는 언어 간 동일하다. 원고마다 새 연구 질문 세 개를 추가했다. 기존 홈페이지의 파랑·주황·회색으로 제작한 SVG 네 개의 원본과 최종 모바일 화면 네 개를 확인했다.

## 독립 계산과 기존 계산기 대조

선택 4파일 **48검사**, 집중 보강·보존 **12검사**, lint·콘텐츠·빌드·타입·**1,888 HTML** 정적 검증을 통과했다. 전체 등록 **650단원·1,969안내**, URL 1,885개를 유지한다. 기존 물리·통합 검사 파일은 바꾸지 않았고 새 쌍 검사에서 추가 절을 포함한 정확한 17절과 원래 본문 해시를 확인한다.

표준 라이브러리 독립 계산으로 상거리 밀도 108개·꼬리 확률 72개·절단 이차 모멘트 72개·고정 센서 통계 162개·국소 나머지 상계 45개를 대조했다. 개구 모멘트 12개·Fourier 장/미분 각 60개·딱딱한 경계의 유한 절단 12개·스펙트럼 모멘트 및 전파 모멘트 꼬리 상계 각 4개·정련 4개를 확인했다. 발산 결론은 유한 수치 검사가 아니라 원고의 해석적 증명에 의존한다.

기존 광선 계산기에서 물체 거리 분포 54개·스냅샷 918개를 계산했다. 실상·허상·정확한 초점 입력을 포함하며 고정 각도 광선의 센서 통계와 기존 부채꼴 통계를 구분한다. 본문의 센서 예제는 평균 −0.005 mm·표준편차 약 5.7735 µm다. 기존 매끄러운 가우스의 자유 전파 모멘트도 18설정에서 대조했다.

## 화면과 보존 검증

최종 빌드의 변경 두 단원에서 한영 **16화면**(밝은 테마 320/768/1440px·어두운 테마 1440px), 영어 320px의 **6안내·4해설 퀴즈·8개념 선택·2저장/완료 그룹**을 검사했다. 페이지 오류·Axe 위반은 없다. 선택 언어의 원고 그림과 로드 완료를 기다리고 이미지·목차·키보드 가로 스크롤·실습을 확인했다. 이 수를 전체 영역의 최종 화면 검사로 합산하지 않는다.

추가 절을 제거하면 기존 네 본문 바이트가 복원된다. 다른 파동 원고 32편·기존 검토 705항목·이전 여섯 배치 원고/그림 48해시를 재검증했다. 검토 기록은 709항목이다. 고정한 원고/그림 여덟 입력, 원본·내보내기·서빙 SVG 네 쌍과 HTML 두 쌍을 대조했다. 기존 상세 강의·해설·선수 순서·등록 데이터는 보존한다.
