# 두 이진 스핀의 연결 공분산 유도와 계산 계약

## 모델과 source

네 이름 붙은 고전 배치를 한 번씩 세며 지수는 `K*s1*s2+h1*s1+h2*s2`다. 유한 binary64 K,h1,h2∈[−8,8], a1,a2∈[−4,4]를 정확한 입력 실수로 취급한다. 장 미분에서는 K를 고정한다. source t는 `h→h+t*a`, 관측량은 `A=a1*s1+a2*s2`다. 유한 합을 두 번 미분하면 `∂i logZ=E[si]`, `∂j∂i logZ=Cov(si,sj)`를 얻는다. 물리적 에너지 장 Hi에 대한 미분에는 고정 T,J에서 `1/(kBT)`가 붙는다.

## 작은 행렬의 부호를 직접 증명하기

배치 순서를 `--,-+,+-,++`로 고정한다. 확률표의 2×2 행렬식을 전개하면 `C12=4*(p--*p++−p-+*p+-)`다. 정규화 전 곱은 각각 `exp(2K)`, `exp(−2K)`이므로 부호는 정확히 K의 부호다. 유한 장의 값은 분모와 크기에 영향을 주지만 이 부호를 바꾸지 않는다. 이 특정 두 이진 변수에서는 교차 공분산 0이 확률표의 계수 1, 즉 독립과 동치다. 일반 변수나 세 변수의 공동 독립으로 확장하지 않는다.

각 대각은 `4*P(si=−1)*P(si=+1)`이다. 모든 유한 입력에서 두 인수가 양수다. `Var(A)=Σx<y px*py*(Ax−Ay)²`는 기댓값을 전개하면 얻는다. 0이 아닌 a에 대해 네 A 값이 모두 같을 수 없으므로 분산은 엄밀히 양수다.

행렬식의 양의 식은 독립적으로 확인한다. 열벡터 `sqrt(px)*(1,s1x,s2x)`를 모은 3×4 행렬 V를 만들면 `det(VVᵀ)=det(C)`이다. 첫 행·열에 대한 Schur complement를 취하면 된다. Cauchy–Binet 전개에서 서로 다른 세 배치의 `(1,s1,s2)` 행렬식은 절댓값 4다. 따라서 `det(C)=16*Σx<y<z px*py*pz`다. 대각 곱에서 교차 제곱을 빼는 불안정한 계산을 피하면서 양의 정부호성을 유지한다.

## 좌표와 정보기하

`score_h=σ−μ`이므로 Fisher 정보의 두 장 블록은 C다. 고정 선형 좌표 `h=Bθ`에서는 `Iθ=BᵀCB`이고, source a는 열 하나인 경우다. 비선형 좌표에서는 Fisher 정보의 좌표 변환과 log Z의 보통 Hessian을 구별한다. 후자에는 좌표의 이계미분 항이 추가된다. 두 모수를 같은 source로 제한하거나 중복 매개화하면 별도의 식별성 문제가 생긴다.

## 실제 구현의 경계와 독립 참조

최대 지수·차이·계수 조합은 정확한 유리 연산이다. 이동한 지수함수와 로그는 기존 방향성 함수가 계산하며, 유리 구간 연산을 통해 확률·모멘트·행렬식에 전파한다. 같은 정확한 지수의 평균 항은 먼저 묶는다. 일반 평균의 우연한 상쇄는 해소하지 못할 수 있으며 그때는 미해결로 남긴다. K=0 교차항과 영 관측량의 분산은 구조적 0이다.

해소 조건은 비영 구간의 부호 확정과 상대 폭 ≤2⁻⁴⁸이다. 128,256,…,8192비트를 순서대로 시도하며, 정밀도 상한에서 사용 불가를 0으로 바꾸지 않는다. 분석적 교차 부호는 별도로 유지한다. 선형 표시 범위보다 작은 양의 관측량도 부호·경계·근사 로그 크기를 보존한다. 일반 크기 로그와 방향성 log 확률은 서로 다른 계약이다.

Python Decimal 참조는 정규화된 확률에서 **중심화 모멘트 합**을 계산한다. TypeScript의 양의 쌍·삼중 합을 가져오지 않는다. `Decimal.from_float`로 실제 입력을 사용하고 400/900자리와 추가 80자리 결과를 대조한다. 이상적인 `exp(log3/2)=sqrt3` 손계산을 반올림된 로그 입력의 참조로 대신하지 않는다.

후속 구현은 주기 Ising 고리의 거리·경계와 AR(1) 관측 인덱스의 정상성·오차를 별도로 명시해야 한다. 이 모델에는 공간 상관 길이, 샘플러 동역학이나 인과 개입이 없다.
