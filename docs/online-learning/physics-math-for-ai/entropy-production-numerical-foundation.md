# 엔트로피 생성: 수치 모델과 Worker 기반

이후 [실제 교재 통합 검증](entropy-production-integration-status.md)을 마쳤다. 아래의542단원·296검증/66미완료와 미등록 표시는 수치 기반 준비 시점의 기록이며 현재는543단원·297검증/65미완료다.

2026-11-08. 정상·자율 세 상태 점프 과정에서 경로 비가역성, 평균 생성률, 유한 시간 지수 평균을 계산하는 기반을 구현했다. 한영 본문은 [한국어](entropy-production-chapter.ko.md)·[영어](entropy-production-chapter.en.md) 초안을 유지한다. **미등록 준비 단계**이며 실제 교재의 입문 완료 수에 더하지 않는다. 현재 등록542단원·원래296/362입문 검증·66미완료다. 전체51영역509주제와 연구 심화 범위를 유지한다.

## 계산하는 양과 해석

- 여섯 양의 전이율과 정확 유리수 정상분포로 방향별 통행량, 순환 전류, affinity, 변별·전체 생성률을 계산한다. 상세 균형은 정수 곱으로 판정한다. 부동소수점 곱이 같게 반올림되는 거의 평형 사례도 비평형으로 유지한다.
- 열린 경로의 총 생성량은 전이율 로그 비와 정상분포 경계항을 포함한다. 개별 경로는 음수일 수 있지만 평균 생성률은 비음수다. 예시 경로는 방향 비트열과 균등 체류로 구성하며 확률적 표본이라고 부르지 않는다.
- 정방향·역전 경로의 로그 밀도에는 초기 가중치, 점프 전이율, 체류 생존 항을 포함한다. 초 단위 점프 시각의 Lebesgue 측도에 대한 밀도이며, 특정 시각의 경로가 발생할 확률과 구별한다.
- 정상분포의 Shannon 엔트로피는 일정해도 정상 통행과 생성률은 양수일 수 있다. 열 저장고가 지정되지 않았으므로 단위는 nats와 nats/s다. 임의 전이율에서 열·온도를 추론하지 않는다.

## 유한 시간 전파와 계산 가용성

Tilted 행렬은 원래 대각을 유지한다. 일반 tilt에서 확률 생성자가 아니므로 행 합을0으로 만들거나 경로 가중치를 재정규화하지 않는다. 양의 이동 행렬에 대해65항 Taylor 합·명시적 행렬 노름 꼬리 상한·방향성 반올림·반복 제곱을 사용한다. 행렬 크기 조절의 정확한 배율은 로그에 누적한다. 이는 산술 처리이며 경로 법칙을 바꾸지 않는다.

시간0, tilt0/1, 상세 균형에서의 지수 평균1은 정규화 항등식으로 표시한다. 나머지는 전파 계산의 로그 구간을 제공한다. 무점프 경로 하한과 볼록성도 명시적으로 적용한다. 선형 지수 평균은256–2048bit 정밀도를 사용하며 미해결 구간·양의 상한 미가용·binary64 표시 범위 밖을 정확0이나 무한대로 바꾸지 않는다. 균일 전이율의 Poisson 계수·분산 참조는 상태 의존 전이율에 적용하지 않는다.

15개 정수 입력은 전이율·분모의 양수, 크기≤10⁹, 시간0–4s, tilt−1–2, 기록 간격1–64, 점프0–16을 검사한다. 시간0에서는 점프가 없고 사용하지 않는 방향 비트도 없어야 한다. 이 제한은 수치 실험의 입력 범위이며 교재 분량·주차 제한이 아니다.

## 검증 근거

독립 SymPy nullspace 정상분포와220자리 mpmath의 **이동하지 않은3×3 직접 행렬 지수**로73준비·657시간 기록·12,003항목을 대조했다. 구간365항목의 미해결 상태와 선형 평균 상한 미가용24항목도 유효한 상태로 검사했다. 작은 양수의 subnormal 표시2항목과 정확0인 경로34항목을 구분한다. 전 매개변수에 대한 기계 증명이나 경험 데이터 재현이라는 뜻은 아니다.

휴대 가능한 [독립 참조 생성기](../../../scripts/learning/generate-entropy-production-references.py)는 제품 코드를 읽지 않고 입력만 사용한다.73사례를 재생성해 저장된180자리 참조 문자열까지 동일함을 확인했다. 기존 참조는 덮어쓰지 않는다.

```bash
npx tsx --test scripts/learning-entropy-production-*.test.ts
python3 scripts/learning/generate-entropy-production-references.py --output /tmp/entropy-reference-new.json
npm run typecheck
npm run lint
```

수치81검사와 메시지77검사, 합계158검사·타입·lint를 통과했다. 기존 단원을 포함한 전체 회귀8,963검사도 실패0으로 완료했다. 한영 초안의14절·8표시 수식·6해설과 독립 참조 예제도 다시 렌더링해 확인했다. 입력 소유권, 잘못된 정수 원문, 다른 요청·입력의 응답, 누락된 인증, 변형된 경로·시간 행·분류·밀도 구조를 검사한다. 메시지 검증은 구조·정체성 검사이며 송신자의 수학을 독립적으로 증명하지 않는다.

실제 Chromium Blob Worker에서 제품 Worker 진입점을 번들하여73준비·657기록의 구조화 복사를 확인했다. Worker3개 생성·3개 종료, 잘못된 입력 거부, started 이후 중단, 교체 요청 수락, 중단 후 결과 전달0을 확인했다. 메인 화면 타이머는508회 동작했다. **Next.js가 내보낸 Worker 자산이나 학습 UI 수명주기 검증은 아니다.**

초기 테스트의 mutation 타입 지정과 브라우저 테스트의 TSX `__name` 보조 함수 누락은 테스트 도구에서 수정했다. 이전 실패 로그를 보존했으며 수치 허용오차를 늘리지 않았다. 상세 근거는 `.runtime/learning/entropy-production-model/verification.json`과 해당 로그·해시 기록이다. 이전 등록 소스4443파일·출력4318파일은 변경하지 않았다.

## 다음 실제 학습 화면

1. 방향별 통행과 순흐름을 나란히 그려 정상 인구와 비평형 통행을 구별한다.
2. 열린 경로·반대 방향 경로·왕복 경로에서 경계항과 점프 항을 하나씩 비교한다.
3. 한 경로, 평균 생성량, 로그 지수 평균을 별도 축과 단위로 표시한다. 가용하지 않은 값을 연결하지 않는다.
4. 실제 Worker 자산과 중단·교체·재시도·저장 복원, 모션 정지·화면 밖·reduced-motion·입력 초점 정책을 검증한다.
5. 한영 본문·개념 설명·자유 실습·풀이·퀴즈를 Interactive Book에 등록하고 실제 읽기 흐름과 접근성·전체 정적 출력을 검증한다. Online Book에는 교재 진입 링크를 넣지 않는다.

비정상 초기화·구동 프로토콜, 국소 상세 균형·저장고, 숨은 생성·거친 입자화·추정 편향·연구 응용은 후속 범위에 남아 있다. [Seifert 저자 원고](https://arxiv.org/pdf/1205.4176)6.1–6.2절을 가정과 경로 법칙의 출처로 사용하며, 이 세 상태 구현과 수치 참조는 직접 유도·검산한 것이다.
