# 엔트로피·압축의 독립 응답 검증

2026-11-09. 결합 엔트로피·PPT와 유한 IID 블록을 검증하는 두 번째 응답 검증기를 구현했다. 양자정보 응답 검증은 **2/9가족**까지 준비되었으며 실제 Worker·학습 화면·reader 등록은 아직 없다.

## 독립 수학 경로

`validateQuantumEntropyResponse`는 원래 요청을 소유하고 raw input key·version·가족·정확 필드를 확인한다. 생산 상태/블록/엔트로피 모델을 호출하지 않는다.

- 결합 상태는 Bell/고전 상관/독립 혼합의 볼록 결합으로 재구성한다. 네 Bell 고유공간의 작용을 확인하고, 부분추적과 부분전치에서 스펙트럼·국소 상태·negativity를 구한다.
- 로그는 생산기의 atanh 급수 대신 별도 signed `log(1+u)` Taylor 급수다. 범위를 u∈[-1/4,1/2]로 줄이고608bit 고정소수점의 모든 곱/나눗셈을 바깥 방향으로 반올림한다.608항 뒤의 절대 꼬리는 `2^-608/609`로 감싼다. ln2는 ln(3/2)-ln(3/4)로 구성하고 최종 구간은512bit다. 2의 정수 거듭제곱은 정확히 처리한다.
- 네 유리수 고유값의 엔트로피와 대각화 후 엔트로피에서 조건부 정보·상호정보·원래/교차한 탈위상 증가를 확인한다. coherence가 정확히 없으면 증가량0을 구조적으로 확인한다.
- 블록 중복도는 Pascal 덧셈, 고유값은 반복 곱, 순서는 p와1-p의 비교로 만든다. p=1의 영 고유값 동률 순서도 별도 처리한다. 누적 rank 구간에서 보존 개수를 계산하고, 전체 중복도2^n·전체 확률1과 정수 메모리 크기를 확인한다.

유리수 사칙연산과 표시 formatter는 공용 primitive다. 엔트로피 수치 평가에는 생산 로그 evaluator를 쓰지 않는다. 검사 bundle에 생산 상태/블록/엔트로피 모델과 계산 진입점이 없으며, 방출된 코드에는 생산 로그 context도 없음을 확인한다.

## 검증 범위

새303검사는 다음을 포함한다.

- 독립 고정밀 로그43개와 dyadic 정확값/정의역, 기존 독립 결합 상태27개.
- 작은 블록의 모든 rank660건,64복사본의30개 경계·큰 계수 사례와32자리 상태 경계6개.
- 대표 응답72개 수치 좌표 각각의 거짓 구간과 표시값 변조.64복사본 응답은134개 좌표를 검사한다.
- 사전확률·rank·중복도·순서·정수 메모리·PPT 분류·해석 문구·요청/소유권 변조.
- 표시가 같은 거짓 정확 엔트로피, Number 범위 아래의 양의 고유값을0으로 바꾸는 오류, 큰 rank의 마지막 bit를 잃은 가중치, 미해결인 작은 양의 coherence 증가를 정확한0으로 바꾸는 오류.

보고 구간은 독립512bit 증명서를 포함해야 하고, 폭은 `(1+max(abs(endpoint)))*2^-224` 이하이어야 한다. 원시 유리수 필드는 정확한 양 끝점이 필요하다. 수학적으로 옳고 충분히 좁은 대체 구간은 허용한다. 고정밀 십진 로그 참조는 corroboration이며 그 자체를 엄밀한 구간 증명서라고 기록하지 않는다.

관련4,582개 회귀·타입·lint·참조 재생성·기존 소스/정적 출력 보존은 `.runtime/learning/quantum-information-entropy-response/verification.json`에 기록한다. 로그 급수의 일차 정의는 [NIST DLMF4.6.1](https://dlmf.nist.gov/4.6.E1)이며 위 범위 축소·방향 반올림·기하급수 꼬리 상계는 이 구현에서 명시했다.
