# 분배함수 연구 보강 검증 기록

2026-11-13. 유한 스펙트럼 생성함수·결합 자리 인수분해·무한 사다리 정규화의 **3단원·한영 6원고·그림 6개**를 보강했다. 원본문과 풀이 36개를 정확히 보존했다. 표시 수식 60개, 실행 Python과 비교 표 각각 6개, 연구 해설 18개를 추가했다. 새 표집·숨은 스핀 모형을 기존 reader의 조작 가능한 기능으로 소개하지 않는다.

## 새 설명과 가정

- **유한 재가중:** 분배함수 비의 불편 추정과 그 로그의 아래쪽 편향을 구별한다. 상대 분산을 목표→출발 chi-squared 발산으로 유도하고 독립 표본 수·로그 결손의 점근 근사·에너지 기준 이동을 설명한다. 시차 상관이 있는 표본에 독립 분산을 자동 적용하지 않는다.
- **숨은 스핀 합:** 별도로 명시한 열린 세 스핀 사슬의 가운데를 합해 끝점 결합과 공통 로그 가중치를 구한다. 정확한 주변 법칙만으로 원래 에너지 분산을 보존할 수 없음을 전체 분산 분해와 Fisher 정보로 설명한다. 온도 의존 유효 퍼텐셜을 고정 미시 에너지로 취급하지 않는다.
- **무한 가중치 분산:** 정규화·전체 지지·유한 KL이 모두 있어도 중요도 가중치의 이차 모멘트가 무한한 기하 꼬리를 계산한다. 원래 무한 출발 아래의 절단 적분을 새로 정규화한 절단 분포와 구별하고, 유한 평균의 대수의 법칙과 분산 기반 오차 분석을 구분한다. 반 간격 바닥 에너지가 원시 비에 붙이는 인자는 정규화한 가중치에서 소거됨도 명시한다.

정준·Ising 배경과 중요도 재가중의 출처는 [자료 기록](thermo-statmech-source-audit.md), 수식·조건·유한 예제는 실제 reader, 해시와 실행 범위는 [JSON 근거](partition-research-evidence.json)에 연결한다.

## 독립 계산과 원문 보존

일반 유한 스펙트럼·역온도·에너지 이동의 81준비에서 재가중 평균·상대 분산을 대조했다. 정확분수로 독립 표본 묶음의 가능한 횟수를 모두 합친 16법칙에서 불편성·분산·Jensen 방향을 확인했다. 숨은 스핀은 여덟 미시 상태 직접 합산의 15준비에서 끝점 법칙·조건부 평균·분산 분해를 대조했다. 유리수 기하 꼬리 9조합과 표의 네 역온도 사례의 60자리 부분 모멘트 계산도 확인했다. 이 유한 계산만으로 임의 모형·표집기·관측량의 효율을 인증하지 않는다.

관련 **18파일·230검사**가 통과했다. 새 절의 H2·H3·표·표시 수식 기대값만 갱신하고, 별도로 원문 복원 해시와 기존 풀이를 검사했다. 다른 29단원·58원고와 앞선 연구 자산 87개를 유지했다. 보존 장부는 기존 829항목을 보존하고 이번 여섯 검토를 더해 835항목이다. 등록은 650단원·1,969안내, 전체 분모는 51영역·509주제다.
