## Reader와 탐색

감사한 한영 원고10개를 그대로 사용하고 선수학습 링크·본문 목차·이전/다음 단원·세 개념 단계·모식도·예측/해설·실험·세 해설 퀴즈를 연결했다. 개념 그림은 모식도라고 명시하며 현재 입력의 계산 결과와 혼동하지 않는다. 기존 홈페이지 색·명암·모바일/데스크톱 틀을 유지한다. 실험은 단원별 지연 로드하고3D는 요청 시 불러온다.

등록 후 **571단원·1713안내 실험**이다. 기존566단원/1698안내의 내용과 순서,51영역의 범위와 기존 멤버십을 보존했다. 최초 전체 검사에서 새 안내를 레지스트리 앞에 삽입한 순서 회귀를 발견해 **뒤에 추가**하도록 고쳤다. 이전 레지스트리의 바이트를 정확히 재구성해 baseline SHA-256과 일치함을 확인했고,테스트 기준값을 완화하지 않았다.

한영 목록의 표지10개·검색10건·데스크톱/모바일 메뉴4건·sitemap을 확인했다. Reader의 메뉴 활성 표시와 breadcrumb는 Interactive Book을 가리킨다. Online Book 목록에는 이 교재 링크를 넣지 않았고 기존 도서 링크를 유지했다. 기존 reader URL과 저장 키도 유지한다.

## 실제 생산 자산과 수학 검증

Next 정적 빌드가 만든 계산/독립 검증 Worker2개를 실제 HTTP 자산으로 실행했다. 소스 factory의 module 옵션은 이 빌드에서 classic으로 컴파일되므로,브라우저에서 관측한 실행 모드와 URL을 기준으로 검사했다. 두 자산의 HTTP 응답은 출력 파일 바이트/SHA-256과 일치한다.

47기준 준비의 전체 결과와47021개 수치 관측을 Node 계산 결과와 대조했고,독립 생산 검증 Worker에서 여섯 계산 종류의 정확한 입력 귀속을 확인했다. 유효한0관측을 다른 유효한1관측으로 치환한 변조6종도 거부했다. 직접 probe100개 Worker는 모두 종료됐다. 전체 reader 의존성 그래프에서도 다체 계산기와 수학 검증기가 메인 스레드에 포함되지 않음을 확인했다.

생산3D chunk도 실제 reader에서 로드하고 canvas·시점 변경·문맥 손실·재시도를 확인했다. 무한 boson 바닥,임의 축퇴 eigenvector,자동 MPS 압축·전역 다중 cut 최적성 등의 미지원 결론을 추가하지 않는다. 학습 화면의 각 수치/물리 제한은 기존 상세 보고서와 원고를 따른다.

## 화면·언어·저장·반응성

다섯 단원×한영×명암×320/1440px의 **40기본/40접근성 상태**를 통과했다. 기본 영어 화면의 한글·본문 가로 넘침·페이지 오류가 없었다. 각 reader에서 개념 단계/해설,퀴즈·완료의 새로고침 복원,실제3D·문맥 손실·복구를 검증했다. 초기와 새로고침 후의 Worker 생애를 따로 계측하고,클라이언트 메뉴 이동으로 언마운트한 뒤에도 확인해100개 생성/종료를 대조했다.

영어 별도 감사는 기본·개념 해설·활성 편집 필드·JSON 오류·퀴즈 피드백 및 coherent 편집을 포함한 **5경로36상태**에서 본문과 가시적인 title/alt/placeholder/aria-label을 확인했다. 전체 사이트의 모든 숨은 상태까지 새로 감사했다고 확대하지 않는다.

여섯 큰 준비를 실제 reader에서 계산/검증하는 동안 입력 편집은26–52ms였다.20ms heartbeat의 pending 최대 간격은60.7–179.4ms였고,모든 입력에서 stale-ready 결과는0건이었다. 검증 Worker가 활성인 상태의 취소는45ms,이후 재시도·다른 준비로 교체·Worker 종료 수지도 통과했다. 이는 이번 로컬 Chromium 실행의 관측값이며 실제 탭 숨김 자동화까지 검증한 것으로 세지 않는다.
