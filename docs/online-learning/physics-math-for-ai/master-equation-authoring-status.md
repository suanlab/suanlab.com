# Master equation 세 단원: 집필·교재 연결과 검증

2026-11-08. 비평형 첫 원래 주제의 세 단원을 Interactive Book에 연결했다. 입문 주제의 전체 읽기·수명·접근성 검증을 정상 종료했다. 전체 교육과정과 연구 심화의 범위는 유지한다.

## 단원과 과학적 범위

- **연속시간 생성자와 Euler 근사**: 전이율/확률·단위, 정확한 반군, 체류/복귀, 정상 가족, Euler의 보존·양수성·선형 안정성, 부호 값과 반올림 아래 비영 전류를 구별한다.
- **Poisson 시계와 잠재 사건**: 같은 생성자의 다른 시계, 주기적 조건부 사슬의 연속시간 완화, 부분 확률/조건화, 양의 누락 꼬리와 성분별 인증을 다룬다.1에서 반올림 질량을 빼 작은 꼬리를 지우지 않는다.
- **체류시간과 방문·시간 점유**: 방문1:1:1과 시간4:2:1, 정상 초기값, 영 이탈률의 흡수·정상 가족, 초기 유역별 극한, 노출시간과 식별 범위를 다룬다. 흡수 상태의 다음 실제 점프 행은 미제공이다.

한영6본문·표시 수식58개·해설36문제,18개념 단계·예측,48이름 붙은 준비와9안내를 연결했다. 생성자 고리·정확/근사 시간 법칙·Poisson 무게/꼬리·확률 성분 구간·방문/시간 막대를 기존 색과 글꼴로 표시한다. 넓은 구간에 추정 중간값을 만들지 않고, Euler 음수를 자르거나 부분 확률을 몰래 정규화하지 않는다. 초기 무게와 정규화한 초기 법칙도 따로 읽는다.

물리 시간 순회는 앙상블 법칙의 시간 질문을 바꾸며 Euler 단계 수/Poisson 절단과 구별한다. 표본 입자의 경로나 평균 체류의 고정 카운트다운을 만들지 않는다. 열저장고·열·열역학적 엔트로피 생성은 지정하지 않았다. 계산 범위는 인터랙션 제한이며 교육 분량 제한이 아니다.

## 구현과 독립 계산

엄격한 소유 입력·결과 구조·준비 식별을 검사하고 요청별 native worker를 사용한다. 새 준비·취소·단원 이동은 이전 worker를 종료하며 동기 계산으로 대체하지 않는다. 입력은 정수 원문과 결합 조건을 확인하고, 저장 JSON도 소수 손실·비영 underflow를 검사한 뒤 읽는다. 미해결 구간·표시 불가·정확한0·정의되지 않은 값은 구분한다.

사전 독립48준비의 정확 관측량8738개와 초월함수 구간15216개를 대조한 원형을 실제 소스로 옮겼다. 현재48생산 결과는 계약 설명을 제외하고 사전 결과와 일치한다. 전달되는 관측량25174개의 형식도 확인했다. 정지·흡수·주기·부적절한 Euler·극소 꼬리·체류 가중은 손계산 회귀에도 포함했다. 수치 포함 검사와 형식 검사는 각각 방향성 산술의 증명이나 전 입력의 정확성을 대체하지 않는다.

## 현재 검증

현재 전체8483검사·빌드·타입·1774 HTML의 정적 링크·자산·목차·사이트맵·canonical 검사를 통과했다. 원래533단원·1599안내의 값·순서·기존 영역 메타데이터를 보존한 채 총536단원·1608안내가 됐다. 그래프 사전 점검96준비·340SVG와 별도로, 새 실제 한영 모바일6화면의 worker·가독성·접근성을 확인했다.

최종 실제 그림 검사는24/24조합, 전체 읽기의 완결된 조합은24/24이다. 전체 읽기는 모든24조합의48준비·6개념·고정 비교·모든 안내·정확값·기록 페이지·로그·정오답·입력·복원을 대조하고 별도 오류·취소·재시도·모션·단원 이동·저장 불가를 검사한다. 정상 종료까지 확인했다. 메뉴·breadcrumb·검색·카드·사이트맵은 한영·모바일/넓은 화면에서 확인했고 Online Book 목록과의 분리도 유지한다.

터치 검사 직후 관성이 남은 상태로 화면 크기를 바꾼 첫 그림 실행은 실패했다. 실제 위치를 측정해 관성을 확인했고, 측정상 스크롤이 멈춘 뒤 별도 크기 변경을 검사하도록 순서를 분리했다. 사용자의 스크롤을 강제로 되돌리는 응용 코드는 추가하지 않았다. 초기 확률 표 보완 전의6화면 기록과 처음 비평형 목록을 빈 상태로 가정한 역사적 테스트 실패도 원본 로그로 보존했다.

## 남은 순서

이 원래 입문 주제를 검증한 뒤 다음 Fokker–Planck 주제로 이어간다. 다음은 Fokker–Planck, 확률 흐름, 상세평형 위반, 요동 소산, 선형 응답, 엔트로피 생성, 확률열역학, 동기화·임계 동역학, 축약·유효 기술이다. 후속 양자·장/다중척도·상대론·물질/계산·역문제·연구 방법과 모든 연구 심화도 남아 있다. 공용 WavePlot32개 소비자 가독성은 별도 후속 작업이다.
