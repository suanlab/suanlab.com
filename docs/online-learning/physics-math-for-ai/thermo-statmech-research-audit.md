## 같은 최종 출력의 검증

- 관련 **113파일·2,251검사**가 통과했다. 프로젝트 전체 테스트 수를 뜻하지 않는다.
- **32단원·256화면**에 중복·누락이 없다. 한영 320/768/1440px 라이트와 한영 1440px 다크를 검사했다. 영어 모바일에서 **152개념·96펼친 안내·76해설 퀴즈·32저장/완료 그룹**을 실행했다. 페이지 오류·Axe 위반은 0이며 열두 묶음의 실제 종료 코드는 모두 0이다.
- 현재 목차·이미지 decode·영어 한글 누출·루트 넘침, 수식/표/코드의 키보드 스크롤을 확인했다. native SVG 64개의 글자 경계도 통과했다. 그림 주변 모바일 캡처 **64개**를 원본 픽셀 크기의 모음 16개로 직접 검토했다. 캡처는 전체 본문 모든 스크롤 위치의 시각 검토를 뜻하지 않는다.
- 입력 **5,472파일**·출력 **400파일**을 고정했다. HTML 32개·SVG 64개의 실제 제공 바이트가 출력과 같고 SVG는 소스와도 같다. 한국어 SSR·디코딩한 영어 Flight에 현재 원고 64편의 렌더링이 정확히 들어 있다. 기존 연구 자산 **207개**를 유지한다. 원본 그림 시각 검토는 변경 없는 58 SVG와 수정 6개 기록으로 이어진다.
- [그림 수정](thermo-research-svg-repair.md)의 새 빌드 **1,893경로·1,888 HTML**, lint·콘텐츠 **1,885 URL/293논문/51프로젝트**·타입·정적 출력 검사 이후 제품 변경이 없어 그 출력을 사용했다. 종합 검토에서 새 빌드를 또 실행했다고 표시하지 않는다.

첫 종합 실행은 SVG 잘림을 찾아 중단했다. 수정 출력의 실행에서는 2,251검사를 통과한 뒤 장시간 실행기가 종료 코드 143으로 끝났다. 완료된 증거는 유지하고 부분 화면 결과는 제외했다. 묶음별 독립 프로세스로 나머지 화면을 다시 검사해 각 종료 코드 0을 확인했다. 프로세스 중단을 제품 오류 또는 전체 통과로 바꾸어 기록하지 않는다.
