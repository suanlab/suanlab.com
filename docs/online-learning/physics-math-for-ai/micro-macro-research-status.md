## 설명과 직관

- **껍질의 교환:** 두 블록 사이의 무작위 비트 교환으로 닫힌 count 전이를 유도한다. 정상 분포·올바른 평균·수렴을 구별하며 항상 교환하는 두 자리의 주기 반례를 제시한다. 조건부 균일 준비에서 전체 미시 엔트로피는 증가해도 count 엔트로피는 감소할 수 있다.
- **거친 관측의 기억:** 균일 재추출을 섞은 세 상태 순환은 미시적으로 혼합되지만, 두 상태를 한 색으로 합치면 다음 색은 과거 관측에 의존한다. 정상 한 단계 표와 실제 두 단계 예측의 차이, 조건부 정보량을 계산한다.
- **반복 센서:** 같은 단일 오차율이라도 독립 오류와 공유 오류의 결합 우도는 다르다. 충분통계·사후확률·상호정보·MAP 오류를 비교하고 두 번 읽을 때 정보는 증가해도 분류 오류는 그대로인 예를 설명한다.

교환 시도·정보량에 물리 시간이나 측정 열비용을 붙이지 않는다. 한 지연에서의 조건부 정보 0만으로 일반 Markov 성질을 인증하지 않는다. 새 모형과 기존 정적 실습의 가정을 본문에서 구별한다.
