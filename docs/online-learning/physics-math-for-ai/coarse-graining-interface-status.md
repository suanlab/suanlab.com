# Coarse graining: 개념 비교와 자유 실험 화면

2026-11-08. [Worker 검증](coarse-graining-worker-status.md)에 이어 두 가족의 개념·자유 실험·예측 문제·모션·브라우저 저장을 구현했다. **아직 교재 등록과 Next.js 읽기 통합 전**이다. 등록548단원·1644안내, 원래299/362입문 검증·63미완료, 전체51영역509주제와 연구 깊이·공용 그림 후속 범위를 유지한다.

## 무엇을 배우고 조작하는가

| 가족 | 개념 비교 | 자유 실험 |
| --- | --- | --- |
| 이산 Markov 집계 | 같은 거시값·다른 미래, 초기 편차0과 닫힘의 차이, 기억 절단의 실패 | 독립 참조와 같은 준비9개, 전이·lifting·초기 무게·갱신 횟수·기억 깊이 |
| 연속 숨은 변수 소거 | 숨은 초기값, 빠른 시간척도와 유한 시간 오차, 커널0과 자율 관측의 차이 | 준비11개, 유리수 계수·초기값·ε·시간 창·관측 기록 수 |

각 가족에 세 개념 단계와 예측 문제·정답 해설, 같은 비교를 자유 실험으로 옮기는 안내를 넣었다. 고정 비교는 저장된 자유 실험과 독립적으로 계산한다. 수치 엔진을 주 스레드에서 실행하지 않는다.

미시 상태0·1을 합친 A와 상태2의 B를 상자로 보여주며 실제·순수 Markov·초기 항을 유지한 잘린 기억 궤적을 비교한다. 이산 횡축은 정수 갱신 번호이며 물리 시간을 만들지 않는다. 음수 근사는 자르지 않고 확률 여부와 half-L1 차이를 표시한다. 현재 항·초기 숨은 항·전체 기억은 부호 있는 막대로 비교하고, 마지막 기록의 다음 갱신 진단을 새로운 시각으로 그리지 않는다.

연속 그림은 초 단위 시각의 실제 x와 Markov x를 비교한다. 현재 속도의 세 항, 실제 y·준정상 편차·오차·기억식과 숨은 재구성 잔차·시간척도를 함께 읽는다. 작은 초기 강제의 해석적 부호·별도 로그·정밀도 미해결 상태를 구별한다. 정의하지 않은 관측은 대시·곡선의 끊김으로 남기며 구조적0으로 바꾸지 않는다. 수치 표시의 정확 유리수·방향성 구간 근거도 펼쳐 볼 수 있다.

## 조작과 복구

정수 칸은 Enter·blur로 적용하고, 유효하지 않은 입력은 이전 준비를 유지한다. 전체 JSON 편집과 세 초기 무게의 개별 편집을 지원한다. 저장값을 복원한 뒤 쓰며, 손상된 저장값은 기본 준비로 복구한다. 저장 불가 상태에서도 현재 실험을 계속할 수 있다. Worker 오류 시 이전 결과를 숨기고 재시도를 제공한다.

기록 슬라이더와 이전·다음 버튼은 수동으로 사용할 수 있다. 자동 재생은 사이트 모션 정지·시스템 동작 줄이기·화면 밖에서 진행하지 않는다. 가로 그림·표는 영역 안에서 스크롤하며 그래프와 표는 같은 관측값을 사용한다.
