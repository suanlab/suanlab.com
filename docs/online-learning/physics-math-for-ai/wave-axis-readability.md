# 작은 물리량 그래프의 축 가독성 개선

2026-11-05. 파동 방정식 단원의 작은 에너지·흐름·변위 오차가 공통 최소 축 여백0.01 때문에 좁은 높이로 보이는 항목을 개선했다. 물리 계산값·단위·초기조건·안내 실험은 바꾸지 않았다.

## 실제 변경

`waveVerticalDomain`은 물리적0과8% 비례 여백을 유지한다. `WavePlot`의 기본 최소 여백은 기존0.01이며, 파동 방정식 그림만 선택적으로1e−12를 사용한다. 기존 단일 진동자·결합 진동 그림의 기본 범위는 유지된다. 영입력에도 양의 유한 축 범위가 남고, 부호 있는 흐름은 양쪽 부호를 유지한다. 작은 수지 잔차의 실제 수치는 별도 표에서 읽는다.

기본 사슬 예제에서 입자별 에너지 변화는 차트 높이240px 중 약12.73px에서193.83px로 커졌다. 단위를 mJ로 바꾸거나 값에 상수를 곱한 것이 아니라 같은 J 값을 더 적절한 축 범위에서 보여 준다. 실제 SVG의 축 경계·글자 범위도 검사한다.

## 검증

축 전용4개와 당시 전체3,564개 테스트·타입·lint·정적 빌드1,690개·출력1,685개 HTML 검사를 통과했다. 새 두 단원과 기존 네 진동 단원의 한영·테마 회귀를 포함한58개 화면, 펼친 안내24개·상호작용4그룹, 영어532경로·590상태를 검증했다. 원본 SVG100개를 담은 갤러리8개와 대표 해설4개를 직접 보고, 모바일100개 그림의 키보드 가로 이동 및8개 구성의 연속 시각 비율 저장을 확인했다. 빌드 전 동결한2,815개 UI 관련 파일과 빌드 후 추가한 별도 감사 도구 한 파일의 해시는 유지되었다.

근거는 `.runtime/learning/wave-axis-verification.json`, `wave-axis-*.log`·실제 종료 기록, `wave-axis-browser/`의 보고서·이미지·수동 검토 해시다. 실행은 `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run check:export`, `node scripts/check-wave-axis.cjs`, `node scripts/check-language.cjs`다.

이 근거는 현재 등록448개 단원의 화면 변경을 검증한다. 동시에 작성한 미등록 간섭·회절 기반 모델과 원고를 새 홈페이지 단원으로 검증했다는 주장은 하지 않는다. 원래36영역·362주제 중252개 입문 검증·110개 미완료 수, 전체51영역·509주제와 연구 심화 범위는 유지한다. 공개 배포·commit·push는 포함하지 않는다.
