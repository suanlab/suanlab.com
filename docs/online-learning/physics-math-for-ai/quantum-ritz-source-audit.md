# Nonorthogonal Ritz: 수학·입력·정밀도 계약

2026-11-09. [양자 변분 집필 설계](quantum-variational-authoring-plan.md)의 두 번째 수치 가족이다. 유한 시험 공간을 일반 복소 기저로 다루며 연속 문제의 수렴·절단 오차나 연구 심화 완료를 의미하지 않는다.

## 입력과 물리 공간

`learning-ritz-input.ts`는63개 소유 유계 정수 필드를 받는다. 전체 차원 n=1…4, 열 개수1≤k≤n, Hamiltonian의 양의 공통 분모, 일반 복소 n×k 기저 B와 비영 복소 계수 c를 지정한다. 비활성 원소는0이며 각 정수의 절댓값은10⁶ 이하이다. 양의 scale 분모와 비영 scale 분자, 복소 shear는 명시적인 가역 좌표 비교에 쓰인다. k=1에서는 사용하지 않는 shear를0으로 둔다.

Hermitian H는 상삼각 원소와 켤레 하삼각으로 구성한다. S=B†B의 정확 복소 유리수 행렬식으로 열독립성을 확인한다. det S=0인 입력을 거부하며, 매우 작은 양의 고유값을0으로 만들어 열을 버리지 않는다. 추가·누락·symbol·상속·accessor·비유한 수·분수·잘못된 차원/분모·비활성 원소도 거부한다. getter를 읽지 않고 data descriptor를 검사해 복사본을 동결한다.

물리 상태는 ψ=Bc이고 정규화 인자는 N=c†Sc이다. 계수의 Euclidean 길이 c†c와 물리 상태의 길이를 구별한다. 계수의 제곱을 측정 확률이라고 표시하지 않는다.

## 정확한 일반화 문제와 잔차

A=B†HB, C=S⁻¹A와 공간 사영 Pᵥ=BS⁻¹B†를 정확 유리수로 계산한다. S와 A는 Hermitian이고 SC=C†S이지만 C는 일반적으로 Euclidean 내적에서 Hermitian이 아니다. S의 역은 정확 cofactor/행렬식으로 구한다. C의 trace 거듭제곱과 Newton 항등식에서 det(tI−C)=det(tS−A)/det S의 실수 계수를 구성한다.

선택한 상태의 에너지 E, 분산과 전체 잔차 r=(H−E)ψ를 계산한다. rᵥ=Pᵥr와 r⊥=(I−Pᵥ)r는 직교하며 Var(H)=(||rᵥ||²+||r⊥||²)/N이다. 좌표 정류 잔차 Ac−ESc는 B†r와 같다. rᵥ=0은 시험 공간 안의 Ritz 정류 조건이고 전체 r=0과 다르다. 압축 연산자의 이차 모멘트는 ||PᵥHψ||²/N이며 전체 〈H²〉와도 구별한다.

각기 다른 Ritz 값 μⱼ의 좌표 사영 Qⱼ=∏ₗ≠ⱼ(C−μₗI)/(μⱼ−μₗ)에서 물리 사영 Pⱼ=BQⱼS⁻¹B†를 구성한다. 축퇴 고유공간을 개별 기저 벡터로 분해하지 않는다. 전체 잔차 연산자 Rⱼ=(H−μⱼ)Pⱼ와 ||Rⱼ||²_F는 그 공간의 진단이며 특정 Ritz 벡터 하나의 잔차라고 부르지 않는다. B†Rⱼ=0과 물리 사영의 Hermitian 성질·멱등성·trace/중복도·ΣPⱼ=Pᵥ를 구간으로 대조한다.

## 공간 포함·좌표 변경·조건

B의 실제 열 prefix1…k를 각각 계산해 시험 공간 포함에 따른 최소 Ritz 에너지의 감소를 확인한다. 일반적인 두 공간을 포함 관계 없이 비교하는 기능으로 확대하지 않는다. 중복도를 포함해 오름차순으로 정렬한 전체 H의 λⱼ와 Ritz μⱼ에서 λⱼ≤μⱼ≤λⱼ₊ₙ₋ₖ의 두 여유 구간을 반환한다.

좌표 비교는 M의 첫 대각을 비영 실수 scale로 바꾸고 첫 행 두 번째 원소에 복소 shear를 넣는다. B′=BM, c′=M⁻¹c를 정확하게 계산해 ψ·Pᵥ·특성 다항식의 불변성을 검사한다. S′와 A′ 및 계수의 Euclidean 길이는 바뀔 수 있다. 이 비교가 모든 가역 M을 입력받는 기능이라는 주장은 하지 않는다. 자유 기저 B 자체는 일반 복소 입력이다.

Gram 조건수는 S의 최대/최소 고유값의 비이다. B의2-노름 조건수 자체나 물리 상태의 오류로 표시하지 않는다. 가까운 종속은 정확 rank 결손과 구별하고, 좌표 변경이 조건을 바꿀 수 있음을 설명한다.

## 구간 계산과 독립 기준

새 `learning-ritz-interval.ts`는 방향성2048비트 작업 연산과 바깥512비트 출력 반올림을 제공한다. 스펙트럼은 기존 square-free/Sturm 분리를4096비트로 호출한다. 이 정밀도에서 재귀 호출 스택이 넘치는 오류를 발견해 탐색을 명시적인 작업 스택으로 바꿨다. 왼쪽 우선 순서·정확 dyadic 근 처리·Sturm 개수·정밀도 상한은 유지하며 정밀도를 낮추지 않았다. 4096비트·10⁻³⁰⁰ 간격·중복 근의 회귀 검사도 추가했다. 부동소수점 역행렬·고유값·rank 판정·기저/상태 재정규화는 사용하지 않는다. 확률만 증명된[0,1] 범위와 교집합을 취한다. 512비트는 출력 격자이며 모든 허용 입력의 결과 폭이 똑같다는 보장은 아니다.

독립 생성기는 SymPy로 Gram·역·모멘트·특성 다항식·정확 실근 중복도를 구한다. mpmath400자리에서는 S=LL†의 Cholesky를 써 L⁻¹AL⁻†를 Hermitian 고유분해하고 물리 공간으로 되돌린 사영을 대조한다. 생산 코드의 C 다항식 사영과 다른 수치 경로다. 정리되지 않은 복소 상수식을 먼저 정확하게 전개·약분해 불필요한 symbolic 계산 비용을 줄인다.
