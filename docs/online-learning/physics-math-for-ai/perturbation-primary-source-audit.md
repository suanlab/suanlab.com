# 섭동이론: 입문 범위와 일차 자료 검토

2026-11-10. 원래 `field-multiscale` 영역의 `perturbation` 원주제를 검토했다. 작은 항을 더하는 계산만으로 원주제를 완료 처리하지 않는다. 정칙 전개, 발산 점근급수, 특이 극한과 시간에 따른 비균일성을 단계적으로 가르친다. 기존 eigenvalue·Markov response 단원과 연결하되 장이론 입문에 필요한 조건과 실패 사례를 보충한다.

## 확인한 자료와 적용 범위

- [NIST DLMF §2.1](https://dlmf.nist.gov/2.1): 극한, 차수 기호, 점근 전개와 균일성의 정의를 확인했다. 고정 차수에서 매개변수를 줄이는 극한과 고정 매개변수에서 차수를 늘리는 극한을 구분한다.
- [NIST DLMF §2.2](https://dlmf.nist.gov/2.2): 암시적 방정식의 역전개와 Lagrange 공식의 사용 조건을 확인했다. 아래 삼차 평형식의 계수와 수렴 반경은 이 교재에서 별도로 유도하고 독립 계산으로 검산한다.
- [NIST DLMF §2.11](https://dlmf.nist.gov/2.11): 작은 마지막 항만으로 오차를 보장할 수 없음을 확인했다. 잔차와 안정성으로 얻은 증명된 상계, 독립 수치 근사, 경험적 추정에 각각 다른 이름을 붙인다.
- [Oxford, A. C. Fowler의 Perturbation methods](https://people.maths.ox.ac.uk/fowler/courses/perturb.html): 대수 방정식·적분·경계층·장시간 전개를 포괄하는 교육 범위를 확인했다. 공개 강의 개요이며 각 세부 정리의 증명 근거로 사용하지 않는다.

Cambridge의 Cowley 강의 PDF는 검색 결과에는 있지만 직접 열기가 시간 초과됐다. 본문을 읽은 자료로 기록하지 않고, 이 단계의 수학적 근거로 삼지 않았다.

## 집필 순서와 원주제 완료 조건

1. **정칙 섭동과 잔차 기반 오차 보증** — `regular-perturbation-residual-certificates`. 볼록 사차 에너지의 평형식을 사용한다. 무차원화·계수 맞추기·유일한 해·수렴 반경·잔차와 오차·조건 민감도·독립 구간 검산을 다룬다. 첫 집필 대상이다.
2. **발산 점근급수와 절단** — 양의 사차 상호작용을 가진 유한 적분에서 가우스 모멘트 전개, 고정 차수 나머지, 항의 성장과 절단을 다룬다. 이 유한 적분을 연속체 경로적분의 정의나 완성으로 취급하지 않는다.
3. **특이 섭동과 경계층** — 작은 최고차 미분항을 제거하면 경계조건을 잃는 예제를 다룬다. 내부/외부 변수, 정합, 합성 근사와 전체 구간 오차를 검사한다.
4. **세속항과 장시간 균일성** — 약한 비선형 진동에서 고정 시간 전개와 장시간 위상 오차를 비교하고, 주파수 보정·복수 척도 및 적용 시간을 다룬다.

각 단원에 한영 상세 설명·손계산·그림·조작 실험·해설 문제, 독립 모델 검산, 실제 reader와 생산 자산 검증이 필요하다. 네 단원을 원주제와 대조한 후에만 입문 범위 완료를 판정한다. WKB·Stokes·재합성·비섭동 기여·연속체 재규격화의 연구 깊이는 별도로 남는다.

## 첫 계산 모형의 명시적 약속

`k x + λ x³ = h`, `k>0`, `λ≥0`를 다룬다. 입력은 유리수 `k∈[1/1000,16]`, `λ∈[0,16]`, `|h|≤16`, 차수 `0..16`이다. 안정한 단일 변수 모형이며 음의 강성·다중 우물·상전이·장 전체의 동역학을 구현했다고 주장하지 않는다.

계수는 생산 모형의 삼중 합 점화식과 독립 Python의 Lagrange 이항계수 공식으로 대조한다. 잔차 다항식은 독립 SymPy 전개로 확인하고 근은 SymPy의 실근 구간 분리와 유리수 이분법을 대조한다. 작은 잔차를 실제 해 오차로 바꾸는 상수는 `1/k`이며 `k=0`으로의 확장은 허용하지 않는다.

현재 등록 수는 590단원·1796안내, 원래 입문 범위는313/362검증·49미완료다. 첫 단원 준비만으로 이 수치를 늘리지 않는다.
