## 수정할 문제

1. **정수 입력의 소수 손실.** 실제 읽기 화면에서 N에 `3.00000000000000001`을 입력하고 Enter를 누르면 오류 없이3으로 저장된다. 변환 전 문자열에서 정수 여부를 검사해야 한다. 연속 계수의 기존 입력 의미는 유지한다. 정수 옵션을 과학 표기 입력과 공통 문자열 파서에 연결하는 수정을 적용했다. 소수 손실 거부와 정확한 정수 표기의 회귀 검사2개가 통과했다. 재빌드한 브라우저의 재검증은 아직 남아 있다.
2. **모바일 그림 글씨.** 320px에서 전용 확률 그림의 최소 글자 크기는 약12.64px, 자유에너지·도함수 그림은 약9.72px다. 그림 내부 최소 폭과 키보드 스크롤 안내를 보완하고 설명문은 스크롤 밖에 둔다.
3. **본문과 실제 실험의 불일치.** 변분·Landau 원고가 읽기 화면 등록과 worker 통합을 미래 작업으로 설명한다. 현재 구현된 그래프 선택, 근 확대·상세, 상태 행 페이지 이동, 정밀도 상한을 설명하도록 고친다. 유한 분포와 극한을 한 화면에서 비교하는 제안은 현재의 별도 단원 기능과 구별한다. 각 한영 원고에 실제 조작·예측·해석을 잇는 예제를 보탠다.

재현 기록은 `baseline.json`에 있다. 이는320px 기본 준비와 정수 오류 재현에 한정되며 전체 브라우저 행렬의 대체 근거가 아니다.

배경 자료로 [저자 사이트의 통계장론1장](https://davidtong.org/teaching/statistical-field-theory/sfthtml/S1)과 [통계물리5장](https://davidtong.org/teaching/statistical-physics/statmechhtml/S5)을 확인했다. 교재의 유한 완전 연결 모형 및 육차 계수 준비는 별도로 지정한 대상이다. 기존 Cambridge 주소의 요청 시간 초과만으로 링크가 영구적으로 깨졌다고 판정하지 않는다.
