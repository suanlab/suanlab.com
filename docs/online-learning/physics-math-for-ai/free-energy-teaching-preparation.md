# 자유에너지 개념·안내·퀴즈와 비교 순회 준비

2026-11-06. 두 가족에 고정 개념8단계·안내6개·퀴즈4개·장식용 표지2개를 작성하고, 실습의 상태 비교 순회와 연결했다. 아직 실제 교재 단원으로 등록하지 않았다. 기존 등록507단원과1521안내 실험은 그대로다.

## 집필과 연결

`interactive-book.ts`의 기존 내용을 바이트 단위 접두사로 보존하고 끝에 `freeEnergyTeachingDrafts`를 추가했다. 기존 학습 단원·안내 배열은 수정하거나 재분류하지 않았다. 나중에 등록할 두 단원의 전제 단원·제목·공식·문제, 단계별 설명과 고정 입력을 같은 데이터 파일에서 관리한다.

스펙트럼 개념은 에너지–엔트로피 경쟁, 숨은 조건부 불균형, 정확한 퇴화 평형, 범위 밖 양수를 다룬다. 기체 개념은 외부 제약, 압축 쪽의 양의 차이, 기준 이동, 근사 상쇄0을 다룬다. 고정 그림은 실습 설정과 독립적인 실제 모델 계산이다. 안내 버튼은 검증된 예제를 불러오며 예측·조작·해설을 제공한다.

퀴즈는 기존 저장·정답/오답·완료 표시 컴포넌트를 재사용한다. 필요한 입력인 문자열 ID와 질문 목록만 받도록 타입 계약을 조정했으며 실행 로직은 바꾸지 않았다. 새 표지는 기존 색상 변수의 장식용 SVG이고 계산 결과나 정량 그림으로 제시하지 않는다.

## 비교 순회와 모션

33개의 비교 상태를 재생하거나 수동으로 선택한다. 스펙트럼은 현재 T·에너지·복제 수를 유지하며 균등 바닥 조건부 분포의 가중치로 교체한다. 기체는 현재 n,T,P,Vr,Fr를 유지하고 체적만 바꾼다. 표시용 순회이며 실제 시간·완화·수치 적분이 아님을 화면에 설명한다.

자동 순회는 사용자가 시작해야 한다. 모션 감소·사이트 일시정지·화면 밖 이동·문서 비가시 상태·마지막 프레임에서 멈춘다. 예제나 입력을 바꿔도 멈추며 새로고침 후 자동 재개하지 않는다. 수동 단계와 처음으로 돌아가기는 모션을 줄인 상태에서도 사용할 수 있다.

## 검증

전체 `npm test`6698개·타입·대상 lint를 통과했다. 새20검사는 한영 고정 개념16화면, 전제/안내/문제 데이터, 두 가족의33개 순회 입력, 표지와 단계 경계를 다룬다. 기존 계산·본문·실습 검사도 유지했다.

독립 브라우저 화면의 한영·명암·320px/1440px 조합에서 개념 전환64회, 안내 불러오기48회, 퀴즈 선택96회, 예제 전환80회를 확인했다. 전체 화면 접근성80상태에 위반이 없었고, 페이지 수평 넘침·비정상 SVG·런타임 예외도 없었다. 답·완료 표시와 실습 설정의 새로고침 복원16회를 확인했다. 모바일 스크린샷8개 중 영어 어두운 스펙트럼과 한국어 밝은 기체 화면을 직접 검토했다.

양쪽 실습의 자동 전진·사이트 일시정지·수동 단계·모션 감소·화면 밖 정지를 별도 검사로 재확인했다. 백그라운드 정지는 `document.hidden`과 `visibilitychange`를 제어한 모의 검사이며 자연스러운 백그라운드 탭 전환을 검증했다고 주장하지 않는다.

기존 소스3840개와 정적 출력4232개를 그대로 보존했다. 추가로 기존 데이터 파일 전체가 접두사로 유지됨과 퀴즈 변경이 타입 표기뿐임을 해시로 확인했다. 등록 전507개 단원·안내의 순서와 해시를 `pre-free-energy-registry-hashes.json`으로 보관했다.
