# 해석역학: 전역 작용·감김 수 연구 확장

2026-11-12. 해석역학의 기존 `lagrangian-momentum-graphs`, `time-gauge-hamiltonian-energy` 두 단원에 한영 연구 확장을 추가하고 검증했다. 기존 본문·여섯 연습 문제·해설·실습 입력은 보존한다. 전체 20단원·10개 원주제의 심화 검토 완료를 뜻하지 않는다.

## 추가한 내용

- 구멍 난 평면의 비선형 운동량 장: 대칭 Jacobian, Lagrangian 그래프, 국소 작용, 감김 수와 주기 적분을 유도한다. 역제곱 퍼텐셜을 명시해 국소 Hamilton–Jacobi 해와 불변 그래프의 조건도 검산한다.
- 원 위의 일정 게이지 항: 정준 운동량 이동과 symplectic 보존, 전역 생성함수의 부재, 감김 부류별 정상 작용을 구분한다. Cauchy–Schwarz와 완전제곱으로 전역 최소를 증명하고 초기값 문제와 경계값 최적화를 구분한다.
- 한영 원고 4편, 그림 2종의 한영 SVG 4개, 두 개의 동일한 한영 Python 셀, 언어별 추가 연구 질문 6개를 제공한다. 새 비선형 모델을 기존 실습 조작에 구현했다고 표시하지 않는다.

## 검증 상태

독립 표준 라이브러리 검산 `python3 scripts/learning/verify-analytical-topology.py`는 76개 경로 주기, 48개 Hamiltonian 접선 상태, 36개 정확 유리수 원운동 상태를 통과했다. 한영 Python 셀 4개도 모두 실행해 대응 출력이 일치했다.

- 선택 14개 테스트 파일의 **346개 검사**, lint·콘텐츠·타입·정적 빌드·출력 검사를 통과했다. 전체 저장소 테스트나 전체 CI 완료를 뜻하지 않는다.
- 최종 빌드는 1,893경로·1,888 HTML이다. 새 그림 4개의 소스/출력 바이트, 두 단원의 제공 HTML/출력 바이트와 8개 소스 해시를 대조했다.
- 해석역학 기존 **20단원의 한영 320·768·1440px 라이트와 한영 1440px 다크, 160상태**를 검증했다. 60개 안내의 실제 입력·펼친 해설 줄바꿈, 40개 퀴즈, 80개 개념 선택, 20개 저장·완료 흐름이 통과했다. 페이지 오류와 Axe 위반은 0개다. 기존 검사 범위를 유지하며 화면 크기·그림·수식·표·코드 스크롤 검사를 확대했다.
- 새 연구 절은 추가 모바일 2상태·4개 화면 캡처로 직접 검토했다. 제공한 SVG 원본 4개도 직접 검토했다.
- 20단원의 선수 폐포 175개 등록 단원은 누락과 순환이 없다. 기존 원고 전체 바이트와 이전 검토 항목 641개를 보존했고, 새 검토 항목 4개만 추가해 총 645개다.
