## 계산과 독립 대조

`learning-curie-weiss-variational.ts`는 실제 binary64 K∈[0,8],b∈[−4,4]를 정확한 유리수로 읽는다. 방향성 로그와 임계 급수, 단조 가지의 근 격리로 모든 정지근을 찾는다. 전역·준안정 최소, 불안정 극대, 사차 임계 최소, 장벽과 자유에너지 분할을 구별한다. 인접 스피노달 장의 근을 epsilon으로 합치지 않는다. [계산 근거](curie-weiss-variational-derivation-notes.md)에 증명과 정밀도 계약을 정리했다.

독립 생성기는 TypeScript 급수를 가져오지 않고 직접 Decimal 로그와 단조 구간 이분법을 사용했다.21사례를400/1200자리와 추가80자리에서 대조했다.39개 정지근,306개 관측값의 부호·유리 구간, 근의 역할·전역 선택·잔차0포함을 검사했다. 실제 log(3), 임계점 양쪽, 인접 스피노달 장, 최소 비영 장과 반사를 포함한다. 생성기는 정상 종료했고 fixture 비교를 대기하던 검사도 완료되었다. 이 기록은 이중 정밀도 대조이며 별도의 두 번째 전체 fixture 재생성을 주장하지 않는다.

## 원고와 테스트

한영 원고는 각각14절·동일16수식·1표·해설6문제다. 영어3043단어, 한국어5634한글자를 포함한다. 배치 수 경계에서 변분 극한을 유도하고 유한 대칭 평균과 순수 가지, 공존과 스피노달, 제약 퍼텐셜과 log-cosh 함수, 극한 순서·반응의 차이를 설명한다.

모델29검사와 원고7검사, 총36검사를 통과했다. 이후 육차 Landau와 기존 관련 모델을 함께 확인한318검사도 통과했다. strict KaTeX, 접근 가능한 수식·표, 한영 수식 대응과 풀이 수치를 실제 콘텐츠 렌더러에서 검사했다. lint·타입 검사도 통과했다. 근 잔차를 단독으로 해 정확도의 증거로 사용하지 않는다.
