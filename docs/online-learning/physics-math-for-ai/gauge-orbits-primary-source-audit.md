# 게이지 궤도·트리 고정·앵커의 범위와 일차 자료 검토

2026-11-10. 원래 대칭·게이지 요구사항의 게이지 고정, 잔여 자유도, 경계 기준과 비식별성을 보완하는 두 번째 단원이다. `field-theory-authoring-plan.json`의 세 요구사항과 세 단원 구성을 유지한다. 정준 제약·전하·Gauss 법칙은 세 번째 단원이며 이번 모형으로 완료 처리하지 않는다.

## 확인한 일차 자료

1. David Tong, [Gauge Theory 4장 §4.2.1](https://davidtong.org/pdfs/teaching/gauge-theory/gauge4.pdf): 군 값을 갖는 링크와 끝점 변환·Wilson 관측의 틀을 확인했다. 자료의 격자 SU(N) 모형과 여기의 정적 U(1) 그래프를 구분한다.
2. Burbano와 Bauer, [arXiv:2409.13812v2 §III.1·부록 C.3.2](https://arxiv.org/html/2409.13812v2): 신장 트리 고정, 루트 기반 경로 구성과 남는 루트 변환을 확인했다. 해당 부록의 연결·단순 그래프 가정과 SU(2) 설정을 그대로 일반화했다고 주장하지 않는다.

아래 다중그래프·물질·앵커 판정은 별도로 유도했다. 기존 단원의 `Uij: j 기준→i 기준` 약속에 맞추어 모든 식을 검산했다.

## 선언한 모형과 완전성

동일한 유한 방향 다중그래프에서 연결 U,V와 복소 물질 ψ,φ를 독립 입력한다. 자기·평행 간선과 고립 노드를 허용한다. 전체 군은 U(1)^N이며, 앵커 집합 A의 부분군은 ga=1로 선언한다. ψa=0이라는 경계값만으로 앵커를 추론하지 않는다.

- 루트 경로 곱 hi로 트리 링크를 1로 만든다. 비트리 좌표 hiUijhj*는 선택 숲의 완전한 연결 불변량이다. 양쪽 고정값이 같으면 gi=conj(hRi)hLi로 실제 변환을 구성한다.
- 물질은 zi=hiψi로 옮긴다. 성분별 Gram 행렬과 비트리 좌표를 함께 비교하면 전체 군 아래의 상태를 완전히 판정한다. 비영 피벗의 비로 잔여 위상을 구하고 영벡터는 따로 처리한다.
- 앵커 두 개를 합치는 트리 간선을 제외한 최대 부분 숲을 만든다. 각 부분 트리의 앵커를 루트로 두면 모든 고정 위상은 앵커에서 1이다. 남는 좌표는 닫힌 곱 또는 앵커 사이의 열린 곱이다. 앵커 없는 원래 성분 수 C0에 대해 숲 간선 수 N−|A|−C0, 남는 좌표 E−N+|A|+C0를 확인한다.
- 앵커가 있는 성분의 고정 물질은 직접 비교하고, 없는 성분은 Gram으로 비교한다. 실제 변환이 앵커에서 1임을 확인한다.
- 전체 트리를 허용 변환으로 1로 만들 수 있는 조건은 같은 성분의 모든 ha가 같다는 것이다. 루트 정규화 변환 자체의 ha=1 조건과 구분한다.
- 안정자는 연결에서 성분별 U(1), 물질 포함 시 영 물질 성분의 U(1)만 남는다. 앵커 군에서는 앵커 없는 성분만 해당한다. 차원은 운동학적 궤도 차원이며 정준 물리 자유도가 아니다.
