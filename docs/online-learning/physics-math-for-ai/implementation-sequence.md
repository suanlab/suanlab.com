# 순차 구현 기록과 다음 집필 순서

전체 교재는 기존 지식 지도에 따라 계속 확장한다. 이 문서는 실제로 읽고 조작할 수 있는
단원과 아직 집필해야 할 단원을 구분한다. 주차·전체 분량·최종 장 수의 제한을 두지 않는다.

숫자는 현재 권장 경로의 표시 순서다. 기존 단원의 URL과 브라우저 저장 키는 유지한다.
필수 선수는 `src/data/interactive-book.ts`의 `prerequisiteIds`에 기록하고, 각 선수 단원의
위치가 해당 단원보다 앞서는지 검사한다. 읽기 경로와 모든 개념의 필수 선수 관계는 다르다.
예를 들어 그래디언트를 읽기 위해 최소제곱·PCA 전체를 먼저 이수해야 한다고 강제하지 않는다.

각 단원은 상세 한·영 본문, 기호 설명, 손계산, 단계별 개념도, 조작 가능한 실험, 수치 표,
세 개의 안내 실험과 두 확인 문제를 갖춘다. 다음 공개 단원을 추가할 때도 같은 기준을 따른다.

## 선형대수 확장 단원의 계산 계약

- 내적·투영: 기준 u=(3,2,0), v=(2,0,0), 내적 6, 계수 1.5, 투영 (3,0,0), 잔차 (0,2,0).
  v=0이면 방향으로 지정하는 투영 공식과 각도를 정의하지 않는다. u=0, v≠0의 투영은 0이다.
  영 부분공간으로의 투영과 영벡터의 방향을 구분한다.
- 최소제곱: 고정 입력 x=(1,2,3), 응답 y=(1,2,2), 절편 없는 y≈ax. 시작 a=0.5의 손실은
  0.75, 최적 a=11/14, 잔차 (3,6,−5)/14, 제곱합 5/14, 반제곱 손실 5/28이다.
  3D 축은 세 관측의 응답 성분이고 관측 평면의 x/y축과 구분한다.
- 고유값: 실대칭 2×2 행렬만 조작한다. 기준 [[2,1],[1,2]]의 고유값은 3과 1, 분산 비율은
  75%다. 행렬 작용의 단위원 반축 |λ|와 공분산 기준 타원의 반축 √λ를 구분한다.
  파랑 점 32개는 기준 타원의 √2배 고리로 만들며, 분모 n 공분산은 주어진 행렬과 일치한다.
  이 점들은 Gaussian 표본이 아니다. 반복 고유값의 방향 비유일성, 총분산 0의 비율 미정의,
  부정부호 행렬의 공분산 해석 불가를 명시한다.

계산은 `src/lib/learning-linear-algebra.ts`, 상태·그림 어댑터는 `algebra-model.ts`, UI는
`algebra-lab.tsx`에 둔다. 기존 Three.js 엔진·테마·2D 대체 보기·저장 기능을 공유한다.
새 단원의 안내·수치 입력도 기존 단원과 공통 컴포넌트를 사용한다.

## 미분 단원의 계산 계약

- 연쇄법칙: u=2x+1, y=u², x=1에서 u=3, y=9, 전체 미분 12. δ=0.1의 실제 변화
  1.24, 일차 예측 1.2, 정확한 나머지 0.04. 꼭짓점에서도 이차 변화는 남는다.
- Jacobian: F=(xy,x²+y), p=(2,3), J=[[3,2],[4,1]], d=(0.1,−0.2), q=(1,−1).
  Jd=(−0.1,0.2), 실제 변화 (−0.12,0.21), Jᵀq=(−1,1), 두 쌍대 내적은 −0.3이다.
- 역전파: x=(1,2), θ=(0.5,−0.25,0.5,2,0), t=0, ReLU에서 z=h=0.5, 예측 1,
  손실 0.5, 기울기 (2,4,2,0.5,1). 학습률 0.01의 동시 갱신 후 손실 0.279826805.
  학습률 2에서는 손실 2. ReLU 0의 기울기 0은 계산 규약으로 명시하고 경계 차분을 표시한다.

`learning-calculus.ts`는 순수 계산, `calculus-model.ts`는 상태·프리셋,
`calculus-lab.tsx`와 `calculus-graph.tsx`는 수동 단계 SVG·입력·검산 UI를 담당한다.
계산 그래프는 공간 좌표가 아니므로 Three.js 카메라를 사용하지 않는다. 브라우저 저장·테마·
안내 실험·기존 문항을 공유하며 자동 재생 없이도 모든 과정을 확인한다.
업데이트 후보가 매개변수 ±100 또는 50회 제한을 넘으면 후보 수치와 이유를 표시하고 적용하지 않는다.

## 이번에 구현한 기존 집필 대기열

아래 네 묶음을 현재 25–38번의 14개 단원으로 풀어 구현했다. 본문·실험·문항이 없는 경로는
공개 목록에 넣지 않는다. 이 목록은 전체 51개 영역·509개 세부 주제의 완성을 뜻하지 않는다.

1. SVD·저랭크 근사: 고유값과 특잇값의 차이, 재구성과 근사 오차를 다룬다.
2. 확률분포·기댓값·분산: 표본과 분포, 조건부 확률, 평균과 불확실성을 연결한다.
3. 통계적 추정·가능도·Bayes: 목적함수의 통계적 의미와 평가 가정을 검토한다.
4. 정보이론·정규화·확률 최적화에서 동역학·물리·연구 경로로 확장한다.

현재 읽기 경로는 전체 목차를 줄인 대체물이 아니다. [지식 영역 색인](curriculum/catalog.md)과
[선수 지식 지도](curriculum/knowledge-map.json)의 기초·심화·물리·연구 영역을 이어서 집필한다.

## 확장 단원의 계산과 검토 범위

새 14개 단원의 순수 계산은 `src/lib/learning-foundations.ts`, 조작 UI와 2D 그림은
`src/components/learning/foundations-lab.tsx`, 기준 설정·안내·문항은 기존 typed 레지스트리에 둔다.
SVD·이산 확률 막대·분포 밀도·확률 과정·시간 궤적·관측 민감도·대응 실험 그림을 사용한다.
모든 그림은 실제 좌표·축 의미와 반올림 전 계산값을 공유한다.

- 경계: 특이 행렬·식별 불가·확률 0의 무한 비용·정상분포 비유일성을 숫자로 숨기지 않는다.
- 수치: 미분방정식·진동자는 정확해와 수치해를 비교하며 보폭 변경 시 최종 시간도 달라짐을 명시한다.
- 통계: 가능도·밀도·표본·사후예측을 구분한다. 연구 점수는 합성이고 t 구간의 가정을 밝힌다.
- 물리: 질량·강성·위치·시간·에너지 단위와 canonical 평형·축퇴도를 명시한다.

## 논리·집합·증명 기초 확장

미완료 영역의 첫 항목에서 6개 단원을 추가했다. 읽기 경로의 앞에 놓고 기존 의미 기반 URL과
저장 키는 유지한다. 논리 기초 전체를 강제로 이수해야 기존 수치 단원에 진입하도록 만들지는 않는다.

- 함의·대우·역·필요충분: 네 배정을 전수 비교하고 선택한 배정을 표시한다.
- 양화사: 입력별 증인과 공통 증인을 구분한다. 집합 제한 양화의 빈 정의역 규약을 명시한다.
- 집합·함수: 소속 표, 상·역상, 단사 충돌·미사용 공역을 같은 대응에서 계산한다.
