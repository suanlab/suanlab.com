# 중첩·간섭·회절의 홈페이지 연결

2026-11-05. 계산 모델 두 개와 상세 한영 원고 네 개를 기존 홈페이지의 HSL 색상·명암 테마·독자 화면에 연결했다. 전체 교육과정과 연구 심화의 완료 여부는 별도로 관리한다.

## 연결한 단원과 학습 흐름

| 단원 | 계산과 시각화 |
| --- | --- |
| `coherent-superposition-detector-averages` | 복소장 합·실수장·실제 제곱 관측, 위상 집단·노출 평균·가시도·부호 있는 sinc, 별도 실수장 적분 진단 |

기본 SVG23개·표6개, 개념 단계8개·안내 실험6개·해설 퀴즈4개를 한영으로 제공한다. 각 원고에는 가정·단위·직관·유도·수치 예제와 여섯 개 해설 문제가 있다. [기반 집필·독립 기준값](interference-diffraction-foundation.md)과 [자료 대조](interference-diffraction-source-audit.md)를 함께 유지한다.

간섭의10개 예제는 진폭 불균형과 부분 결맞음의 같은 무늬, 음의 노출 sinc에 의한 밝고 어두운 위상의 교환, 실수장 평균과 반송파 평균의 차이, 순간 노출·없는 경로·완전한 어둠을 비교한다. 비정수 진폭을 임의로 반올림하지 않고 저장한다. 실수장 그림은 양의 확률을 가진 첫 실현이며 집단 전체의 유일한 장으로 표시하지 않는다.

회절의12개 예제는 접한 두 슬릿과 두 배 폭 단일 개구를 같은 실제 거리에서 비교하고, 한 슬릿 차단·개구 병진·반대 위상·정현비 영점·먼거리 극한을 확인한다. λ·w·F를 조절할 때 실제 z와 관측 위치 x가 어떻게 바뀌는지 명시한다. nm와 μm의 끝값도 유효 범위에서 정확하게 변환한다.

## 물리량과 수치 계산의 표시 원칙

순간값·집단 평균·유한 노출 평균·실수장 제곱 평균을 구분한다. 없는 경로의 상호 결맞음과 완전한 어둠의 가시도는 미정이다. 작은 노출은 단위 노출 좌표에서 적분하며 노출0의 실제 수치 적분 분할 수는0이다. 위상 스캔은 순수 모델의 공통 계산을 재사용한다.

회절 강도는 원래 값과 공통 거리 배율을 제거한 I/F를 함께 보여 준다. 복소 개구 적분의 실수·허수 그림은 두 장에서 같은 관측면 위상을 제거한 좌표계다. 이를 실제 공간 파면으로 해석하지 않도록 설명하고, 선택점 표와 벡터에는 원래 복소장 위상을 유지한다. 이 방식으로 작은 F의 빠른 관측면 위상에 의한 그림 표본의 aliasing을 피한다.

유한 화면의 적분을 전체 투과 에너지로 표시하지 않는다. 일차원 스칼라 근축 모델의 수치 세분화 일치는 정확한 Maxwell 해나 모든 각도의 타당성을 보장하지 않는다. 세분화 차이·복소장 차이·강도 차이를 분리한다.
