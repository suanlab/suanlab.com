# 앙상블 worker와 안내 설정 검증 현황

2026-11-07. 세 앙상블 모델을 별도 계산 worker와 React 훅에 연결했다. **실험 패널·대표 그림·고정 개념도·퀴즈·등록 및 실제 Next 읽기 페이지 검증은 미완료**다.

## 구현

`learning-ensemble-protocol.ts`는 스칼라 입력·요청 식별자·시작 확인·결과·오류를 정의한다. 모델 import는 타입 전용이다. 유한 저장고의 전체 크기·여기 제약, 정준/입자 교환의 간격 0·양/음 온도·온도 0 관례를 그대로 검증한다. 요청은 허용된 필드만 복제·고정하며 입력 순서나 부수 필드에 의존하지 않는 키를 만든다.

worker 전용 평가기가 실제 모델을 실행한다. 제어기는 새 요청에서 이전 worker를 종료하고 요청·포트·입력 토큰으로 늦은 이벤트를 차단한다. 결과의 종류·범위·제출 매개변수·배열 길이·숫자 표현 형태를 대조한다. 이 검사는 수학적 정확성의 증명이 아니며 수치 검증은 기존 독립 기준값 검사에 맡긴다.

`useEnsembleCalculation`은 렌더링 중 입력이 바뀐 순간에도 이전 결과를 새 입력 아래 노출하지 않는다. 동일한 입력 객체를 매번 새로 만들어도 정규화한 키가 같으면 재계산하지 않는다. 비활성화·중단·재시도·StrictMode 해제에서 수명을 정리하며 동기 계산 fallback은 없다.

## 예제와 안내

`learning-ensembles.ts`에 한영 예제 24개와 안내 9개를 작성했다. 안내에는 예측 질문·조작·해설과 검증한 예제 인덱스가 있다. 평균과 분산의 차이, 같은 밀도의 저장고 확대, KL 방향, 열용량 단위, 총량과 상대 요동, 확률 밖의 에너지·화학 응답, 입자 수 조건부와 온도 0 임계점을 다룬다.

저장 데이터 검증은 같은 가족만 허용하고 잘못된 스칼라·다른 가족을 거부한다. 차트 값 선택은 표시 불가·비유한 값과 실제 0을 구분한다. 이 안내들은 아직 교재의 등록 안내 1536개에 추가되지 않았다.

## 검증

새 수명주기·프로토콜·SSR 검사 18개와 설정 검사 6개를 포함해 **관련 179개 검사 모두 통과**했다. 잘못된 요청·결과, 희소 배열, 비유한 숫자, 이전 입력의 늦은 응답, 재진입·중단·해제·복구를 확인했다. 서버 렌더링은 Worker에 접근하지 않는다. 타입 검사와 변경 파일 린트도 통과했다.

`check-ensemble-worker.mjs`는 격리 webpack 자산으로 실제 브라우저의 React StrictMode와 worker를 실행한다. 세 모델의 함수가 별도 worker 자산에 있고 클라이언트 번들에는 없는지 검사한다. 실제 계산 시작 뒤 클릭·heartbeat가 진행되며, 입력 교체·비활성화·중단·재시도·화면 해제와 재생성, 큰 계산의 전체 완료를 확인했다. worker 자산 로드를 의도적으로 막은 뒤 복구도 검사했다.

최종 구간에서 worker 14개 생성·14개 종료, 잔여 worker 0, 오래된 결과 노출 0, 페이지 예외 0이었다. 이는 격리 검증이며 실제 Next export·교재 경로가 검증됐다는 뜻은 아니다. 기존 홈페이지 미리보기 서버와 정적 출력은 변경하지 않았다.
