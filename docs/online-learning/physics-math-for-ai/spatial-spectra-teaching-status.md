## 추가한 설명과 시각화

위치와 공간 파동, 격자 간격, 경계별 모드 혼합, 네 위치 손계산, 무한 감쇠와 유한 복제, 질량0/제약 반례, 고정 파수 정련과 연구 가정을8개념으로 나누었다. 한영 기준 개념도는 현재 입력과 별개임을 표시한다. 예측→예제 비교→해설과 오답/정답 해설을 연결했다.

현재 입력의 C,K,Fourier 공분산 실수/허수부를 열지도와 선택 가능한 이산 Three.js 막대로 비교한다. 두 첨자가 위치인지 Fourier 모드인지 구분한다. 거리별 유한 공분산과 존재하는 무한/주기 복제 기준, 원래 S와 연속체 비교용 a S, 부호 있는 파수와 정련 표를 제공한다.

모든 그림은 표시 투영이며 분수·구간 표가 근거다.0을 포함하는 구간은 기준면에 그리되 정확한0이라고 부르지 않는다. 그림 범위 밖의 값에서는 그림 전체를 숨기고 정확한 표를 유지한다. 큰 표는 자체 스크롤 영역으로 제한한다. 모드 재생과 행렬/척도 선택은 재계산이나 시간 시뮬레이션을 만들지 않는다.

## 입력·저장·조작

기존 사이트의 HSL 색·공통 실험 CSS와 버튼을 사용한다. 입력은 원래 정수/분수 표기를 보존하고 적용 시 검증한다. 유효하지 않은 초안은 이전 적용 결과와 구별하며, 계산 교체 중에는 이전 결과를 숨긴다. 버전이 있는 브라우저 입력 저장, 초기화, 취소와 재시도를 연결했다.

열지도는 화살표/Home/End로 이동한다.3D는 지연 로드하고 키보드·터치 회전, 시점 초기화, 컨텍스트 손실 후2D 대체·재시도를 지원한다. 동작 줄이기 설정에서는 모드 재생을 끄며 숨김 시 중지한다. 메인 브라우저 묶음에는 생산 계산기나 독립 검산 엔진을 넣지 않았다.
