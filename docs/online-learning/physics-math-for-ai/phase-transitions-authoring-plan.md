## 1. 유한 Curie–Weiss 분포와 대칭

예정 ID: `finite-curie-weiss-magnetization-symmetry`.

고전 스핀 N개, M=Σσᵢ, m=M/N, `E=−JM²/(2N)−hM`을 고정한다. 자기 상호작용을 뺀 관례와의 공통 에너지 차이도 명시한다. `K=J/(kBT)`, `b=h/(kBT)`에서

`P(M) ∝ choose(N,(N+M)/2) exp(KM²/(2N)+bM)`.

미시상태를 모두 열거하는 작은 N 참조와 이항 다중도의 거시 합을 독립 대조한다. `<m>`, `<|m|>`, `<m²>`, `Var(m)`, `χ_b=N Var(m)`, `ln Z`, 자유에너지를 제공한다. b=0이면 유한 N의 정확한 대칭으로 `<m>=0`이다. 이봉 분포·가장 흔한 상태·단일 관측의 부호를 평형 평균이나 유한 양의 온도의 특이점으로 오해하지 않는다. 물리적 장 응답은 `χ_h=βχ_b`이며 단위를 구분한다.

고정 손계산: N=2,b=0이면 `Z=2exp(K)+2`. 이상적 K=ln2에서는 M=−2,0,2의 질량이 각각1/3이고 `<m>=0`, `<m²>=2/3`, `χ_b=4/3`이다. 실제 binary64 K의 고정밀 참조에는 이상적 exp(K)=2를 대입하지 않는다.

그림은 다중도→가중치→정규화 막대와 N·장·결합 비교다. 정적 준비 비교를 스핀의 물리 시간 변화로 부르지 않는다. 유한 표본의 비혼합은 상전이의 증명이 아니다.

## 2. 열역학 변분과 자발 대칭 깨짐

예정 ID: `curie-weiss-variational-stability-limits`.

`s(m)=−[(1+m)/2]ln[(1+m)/2]−[(1−m)/2]ln[(1−m)/2]`, m∈[−1,1]에서

`ψ(m)=−Km²/2−bm−s(m)`, `lim ln Z/N=−min ψ`.

유한 합에서 이 극한으로 가는 에너지·이항 엔트로피의 도출을 설명한다. 정상점은 `atanh(m)−Km−b=0`, 곡률은 `1/(1−m²)−K`다. 모든 고정점·국소 최소·전역 최소·준안정성을 구분한다. K=1,b=0의 평탄한 임계점을 임의 epsilon으로 안정/불안정에 편입하지 않는다. 음·양 장 극한과 N→∞의 순서를 명시한다.

이상적 K=ln3,b=0에서 정상점은0,±1/2이다. ±1/2의 곡률은 `4/3−ln3>0`이며 `ψ(1/2)−ψ(0)=5ln3/8−ln2<0`다. spinodal은 K>1에서 `m²=1−1/K`, `b=atanh(m)−Km`로 검사한다. spinodal과 평형 공존, 고정점 반복의 수렴, 실제 동역학을 혼동하지 않는다.

수치 구현은 근의 구간·잔차·곡률·자유에너지 비교를 함께 제공한다. 표시 정밀도로 합쳐지는 근을 소멸했다고 선언하지 않으며 경계·미해결 상태를 남긴다. 제약 엔트로피 함수와 정상점에서만 값이 대응하는 log-cosh 형태를 그림에서 무단 교체하지 않는다.

## 3. Landau 자유에너지와 불연속 전이

예정 ID: `landau-sixth-order-coexistence-stability`.

`Φ(m)=am²/2+bm⁴/4+cm⁶/6−Hm`, c>0, m∈R인 명시적 현상론 모형을 사용한다. 이 m을 앞 단원의 유계 스핀 평균과 자동으로 동일시하지 않는다. 계수의 에너지 또는 자유에너지 밀도 단위를 고정한다. 온도 응답을 말할 때에는 a(T) 등의 의존성을 별도로 지정한다.

H=0,b<0에서 공존은 `a*=3b²/(16c)`, `m*²=−3b/(4c)`다. 정렬 가지의 접힘 `a=b²/(4c)`와 비정렬 가지의 안정성 경계 a=0을 공존점과 구분한다. b>0의 연속 전이, b=0의 평균장 삼중임계 거동과 적용 한계도 다룬다. 국소 최소를 따라 그린 곡선을 평형 이력 현상이나 핵생성 시간의 계산이라고 주장하지 않는다.

최소값 선택은 선언한 평균장·열역학적 유효이론의 평형이다. 유한 자유도의 양의 온도 적분에서 비해석성을 증명한 것으로 해석하지 않는다.

독립 손계산: b=−1,c=1,a=3/16,H=0이면 `Φ=m²(m²−3/4)²/6≥0`. 전역 최소는0,±√3/2이며 장벽의 정상점은±1/2, 높이는1/96이다. 근을 스캔 격자로 누락하지 않도록 다항식 근 격리와 전역 비교를 검증한다.

## 집필·검증 순서

각 가족을 독립 실제 입력 고정밀 참조→계산 모델→상세 한영 원고·풀이→고정 개념·안내·퀴즈→worker·실제 읽기 검증 순서로 만든다. 기존 색·명암·모션·감소 모션·저장 복원을 유지한다. 계산 범위를 명시하고 표시상0·근 중복·정밀도 상한을 구별한다. 세 예정 ID는 검증 전에 교재 목록에 등록하지 않는다. 이상적 ln2/ln3 손계산과 실제 이진 입력 참조를 분리하며 새 주제 완료 수는 실제 통합 검증 뒤에만 늘린다.
