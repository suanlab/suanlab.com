## 확인한 설명·시각화 문제

- 유한 저장고 입력은 개수 n,b,K만 받는다. ε 없이 SI 에너지나 물리적 온도를 조절한다고 읽히지 않도록 실제 입력과 이론의 관계를 추가한다.
- 정준 본문 첫머리의 표본 수 조작 설명은 실제 도구와 다르다. 도구는 이론 분포를 계산하며 M회 표본 추출이나 난수 시드 입력이 없다. 독립 반복의 표준오차 계산과 구별한다.
- 앙상블 전용 막대그림을 320px 화면에서 측정한 결과 글씨는 실제 13px였다. SVG의 9·10 속성값보다 공통 CSS가 우선하므로 속성만 보고 글씨 크기를 단정하지 않았다. 전용 그림의 최소 폭과 글씨, 키보드 스크롤 안내를 보완한다.
- 자동 비교는 준비 조건의 전환이다. 물리적 완화·열평형 도달·입자 수송의 시간 모형으로 설명하지 않는다.
