# 기하·파동 광학의 홈페이지 연결

2026-11-05. [검증한 계산 모델·한영 상세 원고](ray-wave-optics-foundation.md)를 기존 HSL 색상·독자 화면·명암 테마에 연결했다. 전체 교육과정·연구 심화의 완료와 입문 주제 검증은 구별한다.

## 광선에서 지킨 해석

물체점의 아홉 출발 광선을 같은 횡방향 척도로 그린다. 파랑은 실제 전파, 주황 점선은 허상의 역연장이다. 렌즈·실제 센서·그림 범위 안의 상 표식을 구별하며 종·횡 축 확대가 다름을 명시한다. 범위 밖의 유한한 상을 화면 끝에 그리지 않고 실제 숫자를 표에 유지한다.

정확한 `u=f`에는 유한 상 좌표·배율이 없다. `u=100.1mm,f=100mm`의 큰 유한 상100100mm와 합치지 않는다. 렌즈 없음은 정확한 항등 변환이고 음의 렌즈와도 구별한다. 센서 위치별 폭은 같은 광선 준비를 유지한 계산이다. 균등 각도 표본의 퍼짐을 방사 법칙·회절 PSF·교정된 해상도로 부르지 않는다.

상 거리·배율·민감도 스캔은 정확한 특이 입력을 포함하고 극점에서 선을 나눈다. 표본 양쪽을 한 연속선으로 연결해 유한한 중간 상태를 만들지 않는다. 큰 기울기와 초점 근처 민감도는 각각 모델 근사·역문제 조건수의 다른 진단이다.

## Gaussian에서 지킨 해석

입력의 실제 폭·진폭을 유지한 채 관측면을 이동한다. 파랑 포락선의 양·음 경계와 부호 있는 평행 기하 광선을 구분한다. `w²=(Aw0)²+(Bλ/(πw0))²`를 보여주고 기하 초점과 실제 최소 폭의 위치를 따로 읽는다. 허리의 역연장 좌표는 이후 실제 도착점이 아니다.

관측면의 복소장과 강도는 계산한 실제 값이다. 위상은2π 분기 점프에서 선을 나누고 영진폭에는 실제 위상 곡선을 만들지 않는다. 영장의 q·폭은 기준 모드 기하학이며 실제 비영 빔이 아니다. 허리의 역곡률0을 유한 곡률 반경0으로 바꾸지 않는다.

중심 강도와 이차원 전체 제곱장 적분을 함께 유지한다. 반경 단면의 선적분을 빔 총량으로 부르지 않으며 교정 없는 적분 단위는 상대 제곱장·m²다. 전체 Gouy 진행량과 반송파를 분리한 실제 포락선 위상을 구분한다.

강한 공분산 상관에서는 직접 행렬식의 작은 차가 손실될 수 있다. 원래 모멘트·인자·직접 계산·이론값·상대 잔차·상쇄 비율을 구별한다. 이론적 보존값으로 직접 잔차를 덮지 않는다. 큰 발산각·렌즈 기울기를 근축 정확성의 인증으로 해석하지 않는다.

## 검증 상태와 다음 순서

전용·회귀83개, 전체3,719개 테스트와 TypeScript·lint·콘텐츠1,690개 URL 검사가 통과했다. 기존454개 단원·안내·실험·상대 순서를 정규 데이터 해시로 검사했다. 정적 빌드는1,698개 페이지를 생성했다. 출력1,693개 HTML·링크·자산·정규 URL, 한영·명암·320px/1440px 화면64상태, 펼친 안내24개, 조작·저장·퀴즈4그룹 검사가 통과했다. 영어540경로·598상태에서 미번역 문자열이 없었다. 원본 SVG72개·키보드 가로 이동72개·연속 값 저장8개를 검사하고 갤러리8개·펼친 안내4개를 직접 검토하여12개 이미지 해시를 보존했다. 현재456개 단원·1,368개 안내 실험, 원래 주제256개 입문 검증·106개 미완료다. 파동 영역은9개 중7개 입문 검증이며 연구 심화는 남았다.

초기 화면 검사에서는 이론상0인 센서 폭에 약8.67×10⁻¹⁶mm의 수치 잔차가 표시되는 것을 발견했다. 실제 값을0으로 고치지 않고 검사 도구가 물리적 허용량 안의 잔차를 받아들이도록 수정했다. 첫 실패와 대기하던 원본 그림 검사 종료는 `.runtime/learning/ray-wave-optics-first-browser-roundoff/`에 보존했다. 그 뒤 Gaussian 원고의 표 안 수식 접근성 요소가 스크롤 영역 밖을 기준으로 배치되어320px 화면을402px로 늘리는 문제를 찾았다. 표를 배치 기준으로 지정하자320px로 정상화되었다. 표의 키보드 가로 이동 회귀 검사를 추가했다. 첫 수정 후의 실패와 이전 빌드 검사는 `.runtime/learning/ray-wave-optics-before-table-position-fix/`에 보존했다. 최종 소스를 새로 동결하고 모든 검사·빌드·화면 검증을 다시 실행해 통과했다.

다음 원래 주제는 [Fourier optics의 자료·독립 탐색](fourier-optics-source-audit.md)이다. 아직 다음 주제의 제품 모델·원고·홈페이지 등록은 아니다. [전체 남은 순서](remaining-next-steps.md)를 유지한다. 이번 작업은 공개 배포·commit·push를 포함하지 않는다.

원본 그림 검토에서2m 고정 간격 스캔이 mm 크기의 초점 구조를 놓치는 문제를 확인했다. 관측 범위를 실제 준비에 맞추고 선택한 관측면·새 허리·그 주변 Rayleigh 길이 표본을 반드시 포함하도록 바꿨다. 원래 q 렌즈 상태에 자유 전파를 순차 합성하여 매우 좁은 허리의 역곡률 상쇄도 줄였다. 경계 안팎 표식은 화면 비교에만 부동소수점 여유를 쓰고 원래 상 좌표·물리적 특이점은 바꾸지 않는다. 앞 빌드의 자동 검사 통과와 두 장의 수동 검토는 `.runtime/learning/ray-wave-optics-before-adaptive-scan/`에 남겼으며 최신 검증으로 대신하지 않는다.

입력 배열의 빈 요소도 빠짐없이 검사하도록 반복 검증을 보완하고 두 단원의 빠진 렌즈 모드 거부를 확인했다. 이 변경 직전 검사·빌드는 `.runtime/learning/ray-wave-optics-before-input-shape-audit/`에 보존한다. 최종 기록은 이 변경까지 포함한 소스를 새로 동결한 뒤의 검사와 빌드를 사용한다.

최종 근거는 `.runtime/learning/ray-wave-optics-integrated-verification.json`과 개별 로그·실제 종료 기록, `ray-wave-optics-browser/manual-review.json`의 수동 검토 이미지 해시다. 최종2,869개 소스 해시는 유지되었고 빌드 시점과 모두 같다. 진행표 갱신 뒤 교육과정 생성 결과도 빌드 시점과 같다.

최종 순차 q 전파 모델의 독립 기준값 대조도 다시 실행했다. Gaussian96개 계·복소장288개 관측에서 최대 복소장 차이는약8.52×10⁻¹³, 폭 상대 차이는5.36×10⁻¹⁶이었다. 실제 값은 `.runtime/learning/ray-wave-optics-integrated-reference-comparison.json`에 있으며 보편적 오차 한계가 아니다.
