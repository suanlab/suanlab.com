# 관측·샘플링·센서 연구 보강 검증

2026-11-13. 두 단원 한영 네 편에 이동 격자 식별·조건성과 포화 후 Fisher 정보를 보강했다. 기존 본문·여섯 해설 문제·실습 제어를 보존하며 새 초해상도·추정기를 구현했다고 표현하지 않는다. 파동 순차 연구 보강은 **18/18단원**이다. 모든 단원의 같은 최종 빌드 종합 대조는 후속이므로 전체 기록 **40영역·396주제**, 후속 **11영역·113주제**를 유지한다.

## 보강 내용

- `pixel-aperture-sampling-aliasing`: 비음인 두 주파수 장면·픽셀 적분·두 이동 격자 모델을 구성했다. 실제 실수 픽셀에서 복소 계수를 적합하는 단계, 알려진 두 앨리어스의 계수·특잇값·오차 상계를 유도했다. 반 피치의 개구 뒤 조건수와 개구 전달 영점의 불가역성을 구분한다. 두 프레임으로 임의 스펙트럼을 복원한다거나 물리 광자 예산을 최적화한다고 주장하지 않는다.
- `photon-counting-exposure-sensor-noise`: 양의 Poisson 평균을 고정 상한으로 검열했을 때 점수·Fisher 정보와 조건부 점수 분산에 의한 손실을 유도했다. 상단 구간 N≥F와 엄격한 넘침 N>F를 구분하고 알려진 읽음 잡음·ADC 채널의 추가 정보 축소를 설명한다. 포화 분포 계열의 구조적 식별성과 잡음 없는 유한 모든 레일 관측의 단조 우도를 구분하고, 독립 반복의 정보 합, QE가 0일 때 입사 평균의 비식별성도 분석한다. 이는 표준 준수·실측 카메라 인증이나 모든 추정기의 보편 오차 막대가 아니다.

한영 수식은 단원별 8개씩, 실행 Python 셀·수치 표는 언어 간 동일하다. 원고마다 연구 질문 세 개를 추가했다. 기존 홈페이지의 파랑·주황·회색 SVG 네 개의 원본과 최종 모바일 화면 네 개를 확인했다.

## 계산과 기존 모델 대조

선택 4파일 **55검사**, 집중 보강·보존 **12검사**, lint·콘텐츠·빌드·타입·**1,888 HTML** 정적 검증을 통과했다. 전체 등록 **650단원·1,969안내**, URL 1,885개를 유지한다. 기존 물리·통합 검사는 바꾸지 않았고 새 검사에서 정확한 17절과 원래 본문 해시를 확인한다.

아홉 배치의 중복을 제거한 영역 전체 28파일 **395검사**도 통과했다. 이번 55검사를 포함한 수이며 별도로 합산하지 않는다. 원고 36편과 검사 파일 해시가 실행 중 바뀌지 않음을 확인했다. 이 수치·본문 대조는 아직 18단원 전체의 최종 독자 화면 감사 완료를 뜻하지 않는다.

표준 라이브러리 독립 계산으로 두 격자 36계열·실수 픽셀 복조 72개·연속 픽셀 적분 216개·이동 오차 상계 108개·개구 영점 12개를 대조했다. 포화 정보·꼬리 점수 항등식·꼬리 미분 각 18개, 읽음 채널 축소 18개·조건부 점수 및 코드 미분 각 72개·레일 우도 단조 계열 세 개도 확인했다. Poisson 계수 256 이후 꼬리는 최대 검증 평균 20에서 Chernoff 상계가 1e−180보다 작으며 남긴 확률을 재정규화하지 않는다.

기존 단일 줄무늬 적분 144개로 두 성분·두 격자 36계열을 합성하고 중복 DC를 한 번 뺐다. 개구 영점은 원점 네 개에서 재현했다. 독립 센서 기준 12개와 QE 두 설정으로 우도·미분 24설정/72호출을 비교했다. 저장 분산·상단 레일/넘침·정보 축소와 QE=0인 두 준비의 동일 코드 분포를 확인했다. 실제 복수 성분 장면·새 이동 제어가 UI에 추가되었다는 뜻은 아니다.

## 화면과 보존

최종 빌드에서 변경 두 단원 한영 **16화면**(밝은 테마 320/768/1440px·어두운 테마 1440px), 영어 320px의 **6안내·4해설 퀴즈·8개념 선택·2저장/완료 그룹**을 점검했다. 페이지 오류·Axe 위반은 없다. 선택 언어의 그림·목차·키보드 가로 스크롤·실습 제어를 확인했다. 이 수를 18단원 전체의 같은 최종 빌드 화면 검사로 합산하지 않는다.

추가 절을 제거하면 기존 네 본문 바이트가 복원된다. 다른 파동 원고 32편·기존 검토 713항목·이전 여덟 배치 원고/그림 64해시를 보존했다. 검토 기록은 717항목이다. 고정한 원고/그림 여덟 입력, 원본·내보내기·서빙 SVG 네 쌍과 HTML 두 쌍을 대조했다.
