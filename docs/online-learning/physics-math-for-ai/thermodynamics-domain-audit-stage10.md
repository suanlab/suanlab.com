# 상세평형 세 단원 상세 점검

2026-11-07. 전체 교육과정의 남은 내용을 순서대로 보완하는 작업이다. 앞선 상관·요동 점검은 새 정적 출력의 읽기 24조합·접근성 576상태까지 통과해 열역학 상세 점검이 25/32단원에 도달했다. 이 문서는 다음 세 단원의 진행 근거이며, 전체 교육과정이나 연구 심화의 완료를 뜻하지 않는다.

## 원고와 독립 계산

- `stationary-flux-three-state-cycle`: 한영 본문을 읽고 분포 진화와 무작위 표본 경로, 정상 참조와 현재 준비의 흐름, 정상성과 상세평형을 구별했다. 기본 가중치 2,1,1의 N=3 분포와 정상 순전류를 실제 조작에 연결했다.
- `metropolis-hastings-proposal-balance`: 제안·조건부 수락·최종 이동의 장부, 거부 체류, 비유일 정상 법칙과 점프 시계를 확인했다. 보정 전환·역제안 부재·높은 수락과 낮은 이동의 비교 표를 추가했다.
- `reversible-two-state-periodicity-mixing`: 부호 있는 편차·TV·최악 초기값 TV·Cesaro 평균과 항등·흡수·완전 교대의 구별을 확인했다. 실제 전이 버튼과 기록 표 페이지의 의미를 설명했다.

한영 6개 원고와 예제 36개를 대조했다. Python Fraction의 직접 행렬 진화와 별도 Gaussian elimination으로 유리수 관측량 18,944개·정확한 구간 18,944개, 분류 428개를 확인했다. 근사 로그는 선택한 284개 관측만 대조했으며 모든 로그를 검증했다고 주장하지 않는다. 수학 모델·예제·안내·교재 등록 순서는 바꾸지 않았다.

근거: `.runtime/learning/thermodynamics-domain-audit-stage10/independent-comparison.json`. Levin–Peres 저자 페이지의 두 PDF 주소는 같은 2판 파일을 제공함을 내려받은 해시와 본문에서 확인했다. Hastings 원 논문의 수락 규칙과 별도의 기약성 조건도 확인했다. 기존 인용 주소를 고장 난 링크로 판정하지 않았다.

정수 입력은 이미 원문 문자열을 엄격하게 검사했다. 소수나 지수 표기를 반올림해 저장하는 결함을 재현하지 못했으므로 파서를 변경하지 않았다. 순환·두 상태의 자동 전이는 같은 전이와 초기 준비에서 N을 증가시키며, Hastings의 자동 순회는 서로 다른 고정 커널을 비교한다. 이 구분을 유지했다.
