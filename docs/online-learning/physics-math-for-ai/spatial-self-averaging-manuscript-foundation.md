# 공간 밀도·상관·자기평균화: 한영 본문 검증

2026-11-07. 유한계와 열역학 극한의 두 번째 가족에 자세한 한영 본문을 작성했다. [정확 모델과 독립 참조](spatial-self-averaging-foundation.md)의 결과를 실제 본문의 확률 장부와 풀이에 연결했다. 세 번째 가족의 모델·본문, 세 가족의 worker·학습 화면·교재 등록은 아직 미완료다.

## 본문과 학습 흐름

파일은 `content/learning/physics-math-for-ai/spatial-density-self-averaging-correlations.{ko,en}.md`다. 각각15개 대제목·동일한 표시 수식16개·표3개·모드 선택 모식도1개·해설 문제6개다. 영문2,608단어·한국어 한글4,638자이며, 길이보다 구체적인 준비 정의와 유도·수치 대조를 검증 근거로 사용했다.

픽셀 평균의 공통 교란이라는 직관에서 시작해, 계 전체의 모드 선택과 각 자리의 값 생성을 나눈다. 같은 주변분포가 독립성을 뜻하지 않는 이유, 순서 있는 비대각 공분산 합, 정확한 이항/끝점 혼합 분포를 차례로 유도한다. 네 자리 확률표는 각 성분과 혼합 질량, 등호 포함 사건을 함께 보여준다.

정확한 사건 확률·독립 참조 상한·실제 Chebyshev 상한·혼합 구조 상한을 구별한다. 분산 증가와 특정 꼬리 감소의 반례, c·c/N·c/N² 경로의 유한 값과 극한 계수, 유계 밀도의 확률 수렴, 약한 극한 원자, 분산 등가 자리 수를 다룬다. 선도 분산이 같아도 극소 꼬리가 달라지는512자리 예제를 직접 계산한다.

## 의미를 확인한 부분

모드 선택은 계 전체에서 한 번이다. 자리를 도식상 배열했어도 거리에 따른 상관이나 국소 Gibbs 상호작용을 정의한 것은 아니다. N=1의 쌍 부재, p=0/1의 상관계수 미정의, 양의 임계값에서 확률0, 격자 사건에 속하지만 질량0인 점을 구별했다.

고정 ε 사건의 극한은 정확 혼합식으로 따로 구한다. 경계 원자에 약한 수렴만 적용하지 않는다. 크기별 확률공간의 결합을 지정하지 않아 거의 확실한 수렴은 주장하지 않는다. 분산 등가 수를 데이터의 독립성이나 시간 MCMC 유효 표본 수로 재명명하지 않는다.

극소 비영 확률과 큰 유한 꼬리 비는 정확 유리수이며 Number 표시 불가를0·수학적 무한대로 바꾸지 않는다. p 조작과 고정 기준 법칙의 지수 기울이기는 다르므로 응답 항등식을 조건 없이 붙이지 않는다. AI 환경 교란 비유는 학습 동기이며 데이터 보정·성능 보장은 아니다.
