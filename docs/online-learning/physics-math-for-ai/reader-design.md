# AI를 위한 물리와 수학 첫 구현 설계

작성일: 2026-10-26. 우선 작업은 신규 교재의 학습·화면·장면 설계를 확정하는 것이다.
Colab은 Python Programming 과정만 먼저 제작한다. 다른 Colab 분야는 후속 참고 범위다.
이 문서는 초기 설계 계약이다. 첫 세 단원의 현재 구현과 검토 경로는
[시범 구현 기록](preview-implementation.md)에 별도로 정리한다.

## 교재 구조와 시범 범위

[전체 교육과정](../physics-math-for-ai.md)은 주차·분량·총 장 수의 제한 없이 확장한다.
지식 영역과 단원은 선수 관계로 연결하며, 초기 화면 구현은 다음 세 장면으로 검증한다.
시범 장면 수는 전체 교육과정의 범위를 정하지 않는다. 계획된 영역과 집필·구현된 자료의
준비 상태를 따로 표시한다.

| 장면 | 학습 목표 | 핵심 조작 | 계산·표시 기준 |
| --- | --- | --- | --- |
| 벡터와 힘의 합 | 성분·크기·방향·가속도 구분 | 두 힘, 질량, 시간, 카메라 | 일정한 외력의 해석해; 힘·변위 화살표의 단위 구분 |
| 선형변환 | 기저와 점에 같은 행렬 적용 | 3×3 행렬, 점, 변환 전후 보기 | 열벡터 convention `y = A x`; 부피 배율 `abs(det(A))` |
| 그래디언트 | 미분·갱신·학습률·목적값 연결 | 시작점, 학습률, 단계 이동 | 양의 이차함수, 순수 경사하강법; 물리 운동과 구분 |

읽기 순서는 전체 정독 경로 또는 선택한 연구 경로의 필수 선수 절에서 만든다.
단원은 의미 기반 ID를 사용하고 번호는 해당 경로의 표시 순서로만 쓴다. 시범 파일의
숫자 접두는 기존 원고 식별용이며 전체 장 순서와 무관하다. 미완성 단원은 준비 상태만
표시하고 공개 경로를 생성하지 않는다.

콘텐츠 단위는 도서 → 지식 영역 → 장·단원 → 절 → 장면이다. 장은 목차와 공개 URL의 단위이고,
절에는 설명·수식·예측·실험·해설·도전 과제를 묶는다. 첫 구현은 각 시범 장에 장면 하나를 둔다.

## 학습자 동선

도서 목록 → 교재 소개와 선수 지식 → 장 선택 → 개념 읽기 → 결과 예측 → 실험 조작 →
해설 확인 → 도전 과제 → 완료 표시 → 다음 준비된 장 순으로 연결한다.

예측을 건너뛰어도 해설과 본문을 읽을 수 있다. 정답 여부와 수업 완료를 구분하고,
완료 표시는 개인 학습 진도로 사용한다. 공개 교재의 문제를 비공개 성적 평가로 취급하지 않는다.

## 화면 설계

| 화면 | 구성 | 학습자가 할 수 있는 일 |
| --- | --- | --- |
| 교재 소개 | 학습 목표, 지식 지도, 선수 관계, 학습 경로, 준비 상태 | 시작할 장 선택, 이어 읽기 |
| 장 읽기 | 장 목차, 설명, 수식, 개념 그림, 실험 링크 | 텍스트 확대·선택·검색, 해당 절 이동 |
| 장 실험 | 설명·질문과 Three.js 장면·수치·입력 패널 | 예측, 입력 변경, 단계 진행, 해설 확인 |
| 대체 보기 | 같은 설명·입력·계산표와 정적 그림 | WebGL 없이 같은 수치 예제를 확인 |

데스크톱은 본문 약 40%, 실험 약 60%의 두 열을 시작안으로 삼는다.
모바일은 설명 → 장면 → 수치와 입력 → 해설 순으로 배치한다. 최소 320px에서 조작 패널이
가로로 넘치지 않아야 한다. 긴 수식에는 자체 가로 스크롤을 제공하고 페이지 폭을 늘리지 않는다.

책 표지와 장 전환은 입체적 책 연출을 적용하되, 본문은 실제 HTML로 유지한다.
한 화면에 읽기·조작·모든 설정을 압축하지 않고 고급 설정은 펼쳐 보게 한다.
색·선 모양·기호·라벨을 함께 사용하고, 숫자 입력에는 변수명·단위·허용 범위를 표시한다.

## 장면별 설명과 동작

### 벡터와 힘의 합

[한·영 원고](01-vectors-and-forces.ko.md)와 [장면 명세](01-vectors-and-forces.scene.json)를 사용한다.
힘 변경이나 질량 변경은 시간을 0으로 되돌리고 선택한 초기 상태에서 시작한다.
카메라 회전은 모델 값에 영향을 주지 않는다. 자동 진행과 수동 단계 이동을 분리한다.
합력이 0인 경우에는 초기 속도 0인 예제와 움직이는 예제를 모두 제공한다.

### 선형변환

[장면 명세](02-linear-transforms.scene.json)에 항등·스케일·회전·전단·반사·특이행렬을 둔다.
기저 화살표, 단위 정육면체, 점에 같은 행렬을 적용한다. `A`는 행 배열로 저장하고 점은
열벡터로 계산한다. Three.js 어댑터에서 저장 순서를 명시적으로 변환해 이중 전치를 피한다.

행렬식의 부호와 부피 크기를 구분한다. `det(A) = -1`은 부피가 음수라는 뜻이 아니라
방향 반전을 뜻하며, 부피 배율은 1이다. `det(A) = 0`인 예제는 평면으로 붕괴하고 역행렬이 없다.

### 그래디언트

[장면 명세](04-gradients.scene.json)의 함수는 `L(x,y) = (a x² + b y²)/2`, `a,b > 0`이다.
기울기는 `(a x, b y)`이고 갱신은 `p_next = p - learningRate * gradient(p)`다.
입력 `x,y`는 무차원 매개변수, 함수값도 무차원이다. 물리적 힘·질량·관성은 이 모델에 없다.

3D 장면의 높이는 목적값이고 바닥 두 축은 매개변수다. 화면 좌표는 `(x, heightScale*L, y)`로
매핑한다. 바닥의 음의 그래디언트 화살표와 갱신 좌표를 표시하고, 높이 배율 변경은 계산을
바꾸지 않는다. 시각적 보간과 실제 갱신 단계도 구분한다.

이 양의 이차함수에서 모든 초기값에 대해 수렴하는 학습률 범위는
`0 < learningRate < 2/max(a,b)`다. 경계 값은 일부 성분의 왕복을 만들 수 있으며,
더 큰 값은 해당 성분이 0이 아닌 초기값에서 발산한다. 이 조건을 임의의 비선형 손실 전체에
그대로 적용하지 않는다. 기준 예제에는 수렴·왕복·증가하는 경우와 정지점을 포함한다.

## 상태와 조작 규칙

| 상태 | 저장할 값 | 동작 |
| --- | --- | --- |
| 학습 | 단원·절 ID와 버전, 선택한 경로, 예측 답, 해설·도전 결과 | 장을 나갔다 돌아와도 같은 학습 위치 유지 |
| 모델 | 입력, 프리셋, 시뮬레이션 시간 또는 단계 | 모델 함수가 수치와 그림에 같은 결과 공급 |
| 보기 | 카메라, 확대, 그림 배율 | 모델 정답과 독립적으로 변경 |
| 실행 | 재생 요청, 탭·장면 가시성, 모션 허용 | 자동 진행 가능 여부를 계산 |

자동 진행은 사용자의 재생 요청, 사이트 모션 허용, 탭 표시, 장면 가시성을 모두 만족할 때만
동작한다. 중단 중인 시간은 모델 시간에 더하지 않는다. 모션 감소 상태에서도 숫자 입력과
한 단계 이동을 제공한다. 장 전환 애니메이션도 모션 감소 시 즉시 전환으로 대체한다.

입력 변경은 일시정지 후 해당 장면의 초기화 규칙을 적용한다. 언어 전환은 값·예측·카메라·학습
위치를 보존한다. 초기화는 모델만, 진도 초기화는 별도 동작으로 제공해 역할을 구분한다.

## 구현 계약

- 데이터 레지스트리는 도서·장·장면 ID와 준비 상태, 한·영 원고 경로를 가진다.
- Markdown은 기존 방식을 유지하고 수식 렌더링을 추가한다. 본문 로더는 언어를 명시적으로
  받으며 영문 본문을 한국어 원문 영역으로 표시하지 않는다.
- 모델은 `stateAt(params, time)` 또는 `nextState(params, state)` 형태의 순수 계산으로 둔다.
  GPU·DOM·로케일에 의존하지 않고 수치 기준 시나리오로 검증한다.
- Three.js는 React 클라이언트 어댑터에서 필요할 때 로드한다. 씬·카메라·입력 이벤트와
  렌더러 자원의 생성·정리를 관리하고, 같은 모델 값을 DOM 표·수식에도 전달한다.
- WebGL 실패·손실에는 모델과 본문을 유지하고 정적 그림·수치 표로 전환한다.
- 정적 내보내기 경로는 준비된 장에서 생성한다. 목차·검색·사이트맵이 같은 목록을 사용한다.
- 진도는 선택 경로·단원 버전과 함께 브라우저에 저장한다. 전체 교재의 고정 완료율·주차를
  사용하지 않는다. 이 단계에는 계정·기기 간 동기화를 포함하지 않는다.

## 설계 확인과 구현 착수 조건

1. 확장형 지식 지도와 단원별 선수 절, 선택 경로, 시범 장면의 학습 목표·공개 범위를 확인한다.
2. 세 장면의 기준 계산과 단위, 특이·경계 사례를 검산한다.
3. 이 설계를 기준으로 첫 장의 읽기/실험 화면을 구현한다.
4. 첫 장에서 수치·언어·키보드·320/768/1440px·모션 감소·WebGL 대체 보기를 확인한다.
5. 같은 계약으로 선형변환과 그래디언트 장면을 구현한다.

초기 설계 자료는 교육과정, 첫 장 한·영 원고와 정적 그림, 세 장면 명세다.
현재 첫 세 단원의 별도 서비스 원고와 실행 화면을 구현했다. 확장 설계 전체의
완료를 뜻하지 않으며, 공개 배포 여부와 검증 결과는 시범 구현 기록에서 관리한다.
