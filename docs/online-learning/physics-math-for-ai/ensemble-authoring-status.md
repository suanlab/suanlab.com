# 앙상블 세 단원의 입문 통합 검증

2026-11-07. 유한 저장고와 정준 근사, 정준 에너지 요동과 열용량, 입자 교환과 화학 응답의 세 한영 단원을 **도서 → Interactive Book**의 목차·읽기 화면에 연결했다. 로컬515단원·1545안내다. 원래36영역·362주제 중284개의 입문 범위를 검증했고78개가 남았다. 전체51영역·509주제와 연구 깊이는 미완료다.

## 실제 교육 내용

상세 한영 본문6편은 가정·유도·직관·손계산·반례·해설 연습을 담는다. 세 단원에 고정 개념 단계12개, 안내 실험9개, 준비 예제24개, 해설 퀴즈6개를 연결했다. 기존 사이트의 색·폰트·명암·책/실험 스타일을 따른다.

유한 저장고에서는 배치와 여기 수, 평균과 분산, 저장고 크기별 TV와 방향별 KL을 구별한다. 정준 모형은 한 자리 정규화와 이항 분포, 고정 Hamiltonian의 온도 응답, 계 크기와 반복 표본 수의 차이를 연결한다. 입자 교환은 개수·조건부 배치·화학 응답·grand potential과 온도0의 접근 경로를 설명한다. 음의 온도, 정확한 퇴화, 빈 계, 희귀한 양의 확률과 물리적 모멘트, 큰 입력의 정확한 상쇄도 예제로 제공한다.

실험 설정과 고정 개념 준비는 독립적이다. 큰 분포의 차트는 선택한 레이블을 재정규화하지 않으며 전체 표는32행씩 보여준다. 실제0·범위 밖의 비영·미정·무한대를 구분한다. 모든 새 계산은 별도 worker에서 수행하며 예제 순회를 물리 시간이나 완화 동역학으로 설명하지 않는다.
