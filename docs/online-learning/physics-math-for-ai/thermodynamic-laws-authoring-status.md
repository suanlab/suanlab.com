# 열역학 법칙: 교재 연결과 입문 통합 검증

2026-11-06. **입문 주제의 홈페이지 통합 검증 완료.** 세 단원을 등록하고 실제 정적 경로의 학습 흐름 검증을 마쳤다. 전체 교육과정·열역학 영역 전체·연구 심화의 완료를 뜻하지 않는다.

## 연결한 학습 내용

| 단원 | 핵심 관측 |
| --- | --- |
| `carnot-cycle-engine-refrigerator` | 정·역방향의 p–V·T–S 경로, 구간별 열·일·에너지·엔트로피, 온도 상한과 실제 효율·성능계수 |
| `two-reservoir-cycle-entropy-admissibility` | 두 저장고 포트와 완결 순환 수지, 양의 생성에 따른 일 감소, 반사실적 음의 생성, 일 입력 소산 |
| `gapped-spectrum-low-temperature-entropy` | 축퇴 미시상태와 상태군 확률, 잔류 엔트로피·열용량·평균 에너지, 극한의 순서와 숫자 표현 범위 |

상세 한영 본문 6개와 풀이 36개, 입력 16개·완전한 비교 예제 40개를 연결했다. 각 가족에는 실제 계산을 사용하는 고정 개념 4단계·안내 실습 3개·퀴즈 2개가 있다. 고정 예제는 저장한 실험 입력과 독립적이며, 안내를 로드하면 전체 입력을 바꾼다. 선수 단원·목차·검색·이전/다음·표지와 **도서 → Interactive Book**을 연결했다. Online Book 본문에 교재 카드를 넣지 않는다.

같은 온도·팽창비 1·작은 차이·역방향의 부분 일·영 일 경계·전달 없음·제2법칙 위반 가정·정확한 영 간격·극소 양의 간격과 온도를 포함한다. 실제 0, 미정, 숫자 범위 밖 비영 값을 구별한다. 스펙트럼의 첫 로그와 추가 로그도 가용 상태를 별도로 표시한다. 양의 온도 곡선과 T=0 평형 극한을 잇지 않는다. 상태 비교와 경로 진행률을 실제 냉각 시간·출력으로 해석하지 않는다.

## 검증 근거

생산 모델은 [세 가족 기반 검증](thermodynamic-laws-foundation.md)의 독립 참조와 단위·부호·극한 검사를 유지한다. 기존 504개 단원·안내의 순서와 항목별 해시를 고정 참조와 비교했다. 최종 소스에서 전체 **6,235개 검사**, lint·타입 검사·콘텐츠 검증을 통과했다. 정적 빌드는 1,750페이지를 생성했고, 출력 검사에서 HTML 1,745개의 내부 링크·자원·앵커·사이트맵·canonical을 확인했다.

실제 등록 경로의 한영 개념 24상태·안내 18상태·퀴즈 선택지 36상태·예제 80상태, 입력 변경 32회에서 관측 표 3,208행을 계산 뷰와 비교했다. 축 584개·접근성 9상태·새로고침 6회·정수 입력 제한 6회, 검색 6회·이전/다음 6상태를 확인했다. 개념 단계는 키보드로 선택했고 입력 32개의 포커스와 320px 표의 키보드 가로 스크롤을 확인했다. 개념 그림 12개와 실습 그림 12개를 직접 검토하고 명암·모바일 화면을 저장했다.

실습만 검사하는 것과 별도로, 본문·개념·퀴즈·실습을 포함한 **페이지 전체 72상태**를 검사했다. 한영 데스크톱과 영어 320px에서 밝은·어두운 테마 및 개념 4단계를 모두 확인했으며 접근성 위반과 실행 오류는 없었다. 근거는 `.runtime/learning/thermodynamic-laws-final/reader-a11y-result.json`이다.

실제 경로 재생과 감소 모션·사이트 일시정지·화면 이탈 정지·수동 단계를 확인했다. 이 환경의 headless Chrome은 별도 탭으로 전환해도 문서를 visible로 보고했다. 따라서 숨김 처리 검사는 `document.hidden`과 `visibilitychange`를 통제한 브라우저 검사로 수행했으며, 자연스러운 OS 탭 전환 검사라고 주장하지 않는다.

최종 정적 출력의 영어 UI **592경로·650상태**에서 번역 누락과 기록된 실행·문서 제목 오류가 없었다. 소스·자산 3,842파일과 정적 출력 4,232파일의 해시 및 파일 집합이 검사 전후 일치한다. 블로그·QT 상세는 템플릿별 표본을 사용하고, 명시적으로 표시한 원문·코드·인용은 번역 검사에서 제외한다.

## 함께 수정한 문제

푸터의 XML 사이트맵에 Next.js 페이지 링크를 사용하여 존재하지 않는 `sitemap.xml.txt` 사전 요청이 발생했다. 일반 파일 링크로 고쳤으며 한영 실제 이동 2회와 네트워크·콘솔 검사로 확인했다. 기존 URL과 스타일은 유지한다.

페이지 전체 검사에서는 고정 개념 표와 실습 표의 이름이 같아 `landmark-unique` 위반이 발생했다. 두 영역의 이름을 구분하고 개념·실습을 함께 렌더링하는 회귀 검사를 추가했다. 수정 후 페이지 전체 72상태가 통과했다.

첫 빌드는 `ENOSPC`로 실패했다. 재생성 가능한 `.next/cache/webpack`만 정리해 약 6.2GB를 확보한 뒤 정상 빌드했다. 원본 콘텐츠와 기존 검증 기록은 삭제하지 않았다. 최초 실패 로그와 수정 후 성공 로그를 구별하여 보존한다.
