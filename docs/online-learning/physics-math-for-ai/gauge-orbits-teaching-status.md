# 게이지 궤도·트리·앵커의 한영 학습 화면

2026-11-10. `gauge-orbits-tree-fixing-boundary-anchors`의 한영 학습 화면을 작성하고 실제 브라우저에서 검증했다. [독립 계산·응답 검증과 Worker](gauge-orbits-worker-status.md)에 이어 진행했다. **실제 Interactive Book reader 등록과 Next 생산 자산 검증은 아직 남아 있다.**

## 학습 내용과 조작

- 9개 개념 단계,7개 안내 실험,8개 해설 퀴즈와17개 정확 입력 예제를 연결했다. 안내 실험이 모든 예제를 포함한다.
- 전체/앵커 군 각각의 연결·공동 동치를 네 카드로 구분한다. 연결 변환의 물질 잔차나 전체군 변환의 앵커 잔차가 남을 수 있음을 명시한다.
- 두 상태·전체 트리/앵커 부분 숲·원래/고정 표현을 전환한다. 숲·선택 경로·앵커·계산 루트를 구분하는 Three.js 그림과2D대체 그림,닫힌/열린 경로의 복소평면을 제공한다. 경로의 방향·반복은 정확한 부호 목록에서 확인한다.
- 두 상태에 공통 진폭 척도를 사용해 진폭 차이를 보존한다. 정점·간선의 정확한 정상형,양쪽 경로 곱과 잔차,전체 트리 Gram,앵커 호환성,실제 변환과 안정자/궤도 차원을 표로 확인한다. Gauss제약 이후의 물리 자유도와 구분한다.
- 두 상태와 숲·루트·앵커를 직접 입력하고 저장한다. 잘못된 입력은 적용하지 않고 이전 결과의 귀속을 알린다. 저장 불능에도 실험을 계속할 수 있다.
- 시점은 키보드·터치로 조작하며 WebGL손실 시2D로 전환하고 재시도한다. 개념 전환 효과를 끄거나 시스템의 reduced-motion설정을 따른다. 수치 계산/검증은 Worker에서 수행하고 표시 선택은 재계산을 시작하지 않는다.

## 확인한 근거

- 새8검사와 기존 기반85/응답89/controller18을 합친 **200검사** 통과.17예제와 최대5입력의 편집/저장 왕복,잘못된 조합,공통 척도,앵커/루트/열린 경로,32평행·역방향·자기 루프와 번들 의존성을 검사했다.
- 한영×명암×320/1440px의 **8조합**에서17예제의 네 판정,9개념·7안내·8퀴즈,표시 조작의 Worker비생성,앵커 편집·잘못된 숲 거부·새로고침 복원,키보드 시점·WebGL손실/재시도·2D/3D전환을 확인했다. 접근성16회와 영어의 한글 미노출·페이지 넘침 검사를 통과했다.368Worker를 생성/종료했다.
- 별도 저장 실패5종과접근성5회에서20Worker를 종료했다. 모바일 한영2흐름에서빈 간선/숲·앵커 입력·잘못된 지수 번호 거부·모션 토글·테마 전환·터치 시점을 확인하고20Worker를 종료했다.
- 모바일 그림과 두 앵커/평행·자기 루프 예제의2D/3D그림을 실제 크기로 검토했다. 타입·대상 lint를 통과했다.
- 이전5631개 소스와 정적 출력4473파일은 단계 시작 기준으로 보존했다. 진행 문서6개만 의도적으로 갱신했다. 기존 단원과 완료 수치는 바꾸지 않았다.

실행 명령은 `npx tsx --test scripts/learning-gauge-orbits-{foundation,workers,controller,teaching}.test.ts`, `npx tsx scripts/check-gauge-orbits-{teaching,storage,input}-native.ts`다. 근거는 `.runtime/learning/gauge-orbits-teaching/`이며 별도 로컬 미리보기는 `review-server.json`에 기록한다. 이 단계는 로컬 esbuild 학습 화면 검증이고 실제 Next 생산 자산 검증은 아니다.
