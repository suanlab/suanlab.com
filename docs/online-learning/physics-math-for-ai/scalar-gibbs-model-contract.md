# 유한 사차 스칼라 깁스 장

단원 ID는 `finite-quartic-scalar-gibbs-fields`다. 공간 블록에서 얻은 국소 질서변수에 실수값과 유한 격자 작용을 부여한다. Landau–Ginzburg 자유에너지에서 사차항을 유지해야 하는 조건과 한 최솟값 주변의 Gaussian 전개를 출발점으로 삼았다. [Tong, Statistical Field Theory §1.3과 §2](https://davidtong.org/teaching/statistical-field-theory/sfthtml/S2)

## 모형과 정규화

`A = Σᵢ(a xᵢ⁴ + b xᵢ² − hᵢxᵢ) + (c/2)(x₀−x₁)²`는 무차원 작용 E/T다. 한 사이트에서는 결합항을 생략한다. 기준 측도는 무차원 좌표의 Lebesgue 측도다. 유한 차원 이론을 일반 격자로 설명하고 계산 예제는 한 사이트 또는 연결된 두 사이트를 사용한다.

입력 a∈[1/8,2], b∈[−2,2], hᵢ∈[−1,1], c∈[0,2]는 1/8 간격이다. 반경 R은 2…8 정수, 각 축의 셀 수는 16, 32, 64, 128이다. 이 범위는 실험에서 계산량과 사차 감쇠를 함께 제어한다.

각 사이트에서 d=max(0,−b)+|h|/2, C=d²/(2a)+|h|/2로 두면

```text
a x⁴ + b x² − hx + C
  = (a/2)x⁴ + (a/2)(x²−d/a)² + max(b,0)x²
    + (|h|/2)(x−sign(h))²
```

따라서 이동한 가중치는 좌표별 exp(−a x⁴/2)의 곱으로 위에서 제한된다. 양의 사차항으로 음의 b와 비균일 원천에서도 모든 다항 모멘트가 유한하다. 이동한 적분을 Zs라 하면 log Z=log Zs+ΣC다.

## 계산의 포함 구간

셀마다 다항식 P와 exp(−A−ΣC)를 방향 반올림으로 계산한다. 중점법의 셀 평균 오차는 ΣᵢΔᵢ² sup|∂ᵢᵢ(P exp(−A−ΣC))|/24 이하이다. 각 축에 차례로 중점법을 적용하고 차이의 합을 평가한다. 이 구간과 함수의 셀 값 범위를 교차시킨 뒤 셀 부피를 곱한다.

R 바깥의 한 좌표를 R+u로 쓰면 (R+u)⁴≥R⁴+4R³u다. `(R+u)^p`를 전개해 지수 감쇠에 대해 항별 적분하면 절댓값 모멘트의 상한을 얻는다. 여러 좌표의 상자 바깥은 좌표별 초과 사건의 합집합으로 제한한다. 계산은 상자 안 포함 구간과 상자 밖 기여의 절댓값 상한을 따로 반환한다.

Zs의 양의 하한으로 나누어 평균, 2차·4차 모멘트와 공분산의 구간을 얻는다. 원천이 모두 0이면 전체 반전 대칭으로 홀수 총차수 모멘트가 정확히 0이다. 국소 Hessian은 별도로 표시하며 공분산은 전체 적분에서 구한다.

## 검산과 연결

순수 사차 한 사이트는 Gamma 적분으로 대조했다. 두 사이트는 대칭·비균일 원천에서 독립 Gauss–Legendre 적분과 대조했다. 중점 셀 수를 늘려 상자 안 오차의 감소를 확인했고, 꼬리 상한은 같은 R에서 동일하다.

한영 원고 12절씩과 확인 문제 2개, 안내 실험 2개를 교재에 등록했다. 실험은 두 좌표의 결합을 열지도로, 단일 좌표의 가중치를 곡선으로 보여 준다. 브라우저 Worker가 계산한 구간과 정확한 유리수 끝점을 함께 읽을 수 있다.

실제 정적 페이지를 영어 데스크톱과 한국어 모바일 다크 모드로 열었다. 결합 상태에 따른 그림 변경, 공분산 출력, 계산 취소, 한 격자점 예제 전환과 탐색 링크를 확인했다. 기본 두 점 모형의 32분할 공분산 구간은 반올림하면 [0.406240, 0.652015]이다.

통계장론의 네 입문 단원 가운데 세 단원을 검증했다. 연결 생성함수와 르장드르 유효작용 원고의 Python 실습은 실행을 확인했다. 실험 구현, 교재 등록과 원래 주제의 종합 점검이 남아 있다.
