# Duffing 세속항·장시간 위상: 실제 교재 통합

2026-11-10. `duffing-secular-frequency-long-time`을 Interactive Book의 594번째 단원으로 등록하고 실제 교재와 배포용 Worker를 검증했다. 6개 안내 실험을 더해 총1820안내다. 현재 교재에는 반영했지만 commit/push·공개 배포는 하지 않았다.

## 교재와 개념도

한영20절·15표시수식·8해설 문제와 기존 학습 화면을 연결했다. 표지와8개 개념도는 hardening potential, 진폭 의존 유효 결합, 단순 전개의 성장, Lindstedt 시계, AGM, 장시간 위상, 에너지/위상 구분과 표본화 반례를 다룬다. 그림은 고정된 설명 예제이며 현재 입력의 수치 보증과 명확히 구별한다. 개념·문제는 reader에 한 번만 나타나며 embedded 실험에서는 중복하지 않는다.

단원 목록, 영역 연결, 선수 단원·이전/다음 이동, 학습 완료·문제 답·실험 입력의 새로고침 복원을 확인했다. Online Book 목록에는 새 콘텐츠 링크를 추가하지 않고 기존 도서 → Interactive Book 구성을 유지했다. 내부 reader 경로는 기존 `/book/online/physics-math-for-ai/` 규칙을 따른다.
