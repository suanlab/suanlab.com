# 사차 적분과 발산 점근급수: 독립 검증·실제 Worker

2026-11-10. [한영 원고와 계산 기반](quartic-asymptotic-foundation-status.md)에 독립 응답 검증기,계산/검증Worker,취소 가능한 controller와React hook을 연결했다. **한영 학습 화면·실제 Interactive Book 등록·Next 생산 자산 검증은 아직 남아 있다.**

## 다른 계산으로 전체 응답 확인

생산 계산기는 가우스 모멘트 계수의 비율과 단조 항 비율 탐색을 사용한다. 검증기는 팩토리얼 계수와 정수 이차식의 판별식으로 계수·전역 권장 차수를 다시 구한다. 부분합·첫 누락 항·홀수/짝수 포함 구간·오차 거리·구간 교집합과 차수 예산의 판정을 모두 대조한다.

적분 검증기도 생산 적분기·분수 도구·지수함수 엔진을 가져오지 않는다. 음의 지수함수의 교대 전개,작용의 이항 전개,차수별 대각 다항식 곱과 별도 유리수 연산으로256패널·192비트·32/33차의 방향 보존 보증을 재구성한다. 양쪽 지수 계산은 같은192비트 포함 격자 칸을 선택한다. 기존 지수 구간이 한 칸보다 넓으면 생산 계산기가 정밀도를 올려 확인한다.

순수 적분 구간,점근 구간,교집합의 의미와 꼬리 상계·가우스 정규화 메타데이터도 확인한다. 검증기는 원래의 제한된 입력에서만 산술을 수행하고 응답의 긴 분수 문자열을BigInt피연산자로 읽지 않는다. 검증 결과의 캐시는 최대16개 입력만 보관하며 외부 결과와 공유하지 않는다.

## 계산 수명과 화면 연결

실행마다 계산Worker와독립 검증Worker를 순서대로 생성·종료한다. 큰 응답의 소유권 복사는 작업을 나누고 입력 교체·취소·기한·화면 이탈 시 중단한다. 잘못된 현재 응답은 실패시키고 다른 요청ID의 늦은 메시지는 최신 결과로 게시하지 않는다.

React hook은 비활성화·문서 숨김·새 입력에서 이전 결과를 숨긴다. 복귀·재시도는 새 요청으로 계산한다. 서버 렌더링에서는Worker를 만들지 않으며 수치 엔진을 hook번들에 포함하지 않는다.
