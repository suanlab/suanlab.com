# 보존형 이산화 두 단원 집필 설계

후속 상태: [두 단원의 홈페이지 통합 검증](continuum-conservative-authoring-status.md)을 마쳤다. 아래 내용은 자료·설계·기반 단계의 기록이며 현재 다음 순서는 연속체 전체 영역 종합 점검이다.

2026-11-06. [자료 검토](continuum-conservative-source-audit.md)에 따른 준비다. [비균일 체적 기반](continuum-conservative-volume-foundation.md)과 [Godunov 기반](continuum-conservative-godunov-foundation.md)의 계산·독립 참조·한영 원고를 검증했다. 두 단원의 실습 화면은 미완료이며 입문 검증 수를 올리지 않는다.

## 비균일 체적·공유 플럭스·질량과 노름

예정 ID: `nonuniform-volume-shared-flux-mass-norm`.

주기1차원 비균일 셀의 실제 경계·중심·양의 체적을 선언한다. 일정한 면적·양/음 이류 속도와 비음 확산을 사용한다. 각 면의 수치 플럭스를 한 번만 계산하고 인접 셀에 반대 부호로 적용한다. 셀 평균과 점 표본을 구분하며 초기 주기 프로필의 실제 셀 적분을 제공한다.

질량 Mq의 보존과 부피를 뺀 단순 합의 보존은 다르다. 평균 체적으로 모든 셀을 나누는 음성 대조가 단순 합은 보존하면서 실제 질량을 바꾸는 경우를 보여준다. 공유 면만으로 충분하다고 하지 않고 저장 체적까지 대조한다. 균일 격자에서는 두 갱신이 일치하는 대조를 포함한다.

이산 incidence 행렬·질량 행렬·양의 면 전도도에서 질량·이차 노름의 미분과 실제 Euler 한 단계의 이차 항을 유도한다. 노름을 물리적 에너지라고 부르지 않는다. 양의 계수 조건과 부적절한 시간 간격을 비교하고, dt를 바꾸거나 잘라 안정한 다른 실험으로 몰래 교체하지 않는다. 정지·영 확산·영 시간·작은 변화와 대칭 상쇄를 검증한다. 작은 편차가 큰 평균에 가려지지 않도록 표현을 설계한다.

AI의 셀별 예측과 공유 면 플럭스 예측, 체적 가중 학습 손실, 리메싱·일관성·안정성·식별성을 연결한다. 공유 플럭스 구조가 모든 수치·물리 성질을 보장한다는 주장은 하지 않는다.

## 실제 Godunov 갱신·충격파·entropy

예정 ID: `godunov-burgers-conservative-shock-entropy`.

무점성 Burgers의 실제 비선형 셀 평균 갱신을 구현한다. Godunov 인터페이스 플럭스와 정확한 충격파/희박파 해를 사용하며, 미보정 Roe의 sonic 희박파 반례와 보존형 구조를 함께 비교한다. 필요하면 Rusanov 대조를 추가하되 실제 알고리즘·CFL·경계 조건을 선언한다. 보존형임과 entropy 적합성이 다른 조건임을 설명한다.

좌우 상태의 양·음·동일·영·정지 충격파·sonic 희박파를 포함한다. 정확한 Riemann 해를 참조할 때에는 전체선/유한 구간의 경계 처리를 명시한다. 경계를 지난 파나 상호작용을 무시한 해를 정확한 참조로 표시하지 않는다. 경계 수지·공유 플럭스·독립 질량 적분·실제 충격 위치와 격자 오차를 확인한다.

양의 상태에서 비보존형 advective 갱신이 실제 질량을 잃는 한 단계 항등식을 별도 음성 대조로 사용한다. 충격파의 entropy 결손과, 실제 시간 이산화의 entropy 예산·수치 entropy 플럭스를 구분한다. [자체 유도](continuum-conservative-derivation-notes.md)의 대칭 수치 entropy 플럭스·국소 결손·실제Euler 보정을 연결하고, 실제 단계에서 충분 조건을 검사한다. 정지 충격파의 수치 플럭스와 유일하지 않은 물리적 추적값을 구분한다. 최적CFL 상수나 모든 entropy에 대한 보편성을 주장하지 않는다.
