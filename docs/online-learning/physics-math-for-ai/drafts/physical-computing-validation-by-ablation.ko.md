## 1. 기대 동작과 읽기 규약 정하기

두 포트의 아날로그 가속기가 광장 또는 전압 벡터 $y=Mx$를 출력하도록 설정했다고 가정합니다.

$$
M=\begin{pmatrix}0.75&0.25\\0.25&0.75\end{pmatrix}.
$$

입력 범위, 출력 부호를 읽는 방법, $y$와 같은 단위의 오차 허용치를 정합니다. 결맞은 광학 시스템에서 실수 진폭의 부호를 복원하려면 위상 기준이 필요합니다. 각 입력에 대해 디지털 기준값을 계산합니다. 지연이나 에너지를 비교할 때 전처리, 변환, 동기화도 기록합니다. [Shen 외의 결맞은 나노광 회로 실험](https://arxiv.org/abs/1610.02365)

## 2. 기저 입력으로 교정하기

$e_1=(1,0)^T$와 $e_2=(0,1)^T$의 출력은 $M$의 두 열입니다. 장치가 두 채널에 공통 상수 이득 $g$를 적용하면 기저 교정으로 유효 행렬 $gM$을 얻습니다. 장치가 선형이면 이후 입력의 출력도 예측할 수 있습니다. 설정 행렬과 교정한 행렬을 함께 저장하면 절대 오차와 교정 후 잔차를 모두 구할 수 있습니다.

## 3. 검증용 보강 입력과 상쇄 입력 남기기

읽기 회로가 각 채널의 크기를 $L=0.8$에서 자른다고 가정합니다. $g=1$에서 기저 입력의 출력 크기는 최대 0.75이므로 기저 교정은 $M$을 그대로 얻습니다. 검증용 입력 $e_1+e_2$의 목표 출력은 $(1,1)^T$이고 실측 모형의 출력은 $(0.8,0.8)^T$입니다. $e_1-e_2$의 출력은 $(0.5,-0.5)^T$여서 읽기 범위 안에 듭니다.

중첩 잔차를 계산합니다.

$$
r=\widetilde y(x_1+x_2)-\widetilde y(x_1)-\widetilde y(x_2).
$$

선형 장치라면 측정 오차 범위 안에서 0입니다. 이 예에서 기저의 합을 입력하면 $(-0.2,-0.2)^T$입니다.

## 4. 한 조건씩 바꾸어 원인 검증하기

중첩 입력의 진폭을 절반으로 줄여 반복합니다. 잘림 모형에서는 출력이 읽기 범위 안에 들어오므로 잔차가 사라집니다. 일정한 선형 이득 오차에서도 중첩 잔차는 0이지만 설정 행렬에 대한 오차가 입력 크기에 따라 바뀝니다. 같은 입력을 유지한 채 읽기 범위를 바꾸어 잘림 가설을 더 검증할 수 있습니다. 온도와 실행 시점을 비슷하게 유지하며 반복해 측정 변동을 추정합니다.

## 5. Python으로 교정과 검증 입력 계산하기

```python
import numpy as np

target = np.array([[.75, .25], [.25, .75]])
basis = np.eye(2)

def measure(x, gain=1.0, limit=0.8):
    return np.clip(gain * (target @ x), -limit, limit)

fitted = np.column_stack([measure(x) for x in basis])
assert np.allclose(fitted, target)
for x in (np.array([1, 1]), np.array([1, -1]), np.array([.5, .5])):
    observed = measure(x)
    residual = observed - fitted @ x
    print(x, observed, residual)
assert np.allclose(measure([1, 1]) - fitted @ [1, 1], [-.2, -.2])
assert np.allclose(measure([1, -1]), fitted @ [1, -1])
assert np.allclose(measure([.5, .5]), fitted @ [.5, .5])
```

## 6. 실제 작업의 품질까지 보고하기

실제 입력의 특성과 경계 사례를 반영하는 검증 벡터를 고릅니다. 잔차와 후속 작업의 품질을 교정 주기, 에너지 및 시간 측정 경계와 함께 보고합니다. 연산 수, 측정한 데이터 이동량, 물리 계측값을 같은 실험에 연결합니다. 다른 연구자가 알고리즘, 장치, 읽기 회로가 각각 결과에 준 영향을 확인할 수 있습니다.
