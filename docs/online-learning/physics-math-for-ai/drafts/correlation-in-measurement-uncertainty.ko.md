## 1. 입력 공분산을 함께 전달하기

두 센서가 교정 장치, 환경 또는 기준 시계를 공유하면 오차가 함께 움직일 수 있습니다. 입력 공분산이 $\Sigma$일 때 선형 결합 $z=w^Tx$의 분산은 $w^T\Sigma w$입니다. 대각 성분은 각 입력의 분산이고, 비대각 성분은 두 입력이 함께 변하는 정도입니다. [JCGM 100, 측정 불확실성 표현 지침](https://doi.org/10.59161/JCGM100-2008E)

## 2. 합과 차의 분산 비교하기

표준편차가 $\sigma_1,\sigma_2$이고 상관계수가 $\rho$일 때 $z_\pm=x_1\pm x_2$의 분산은 다음과 같습니다.

$$
\operatorname{Var}(z_\pm)=\sigma_1^2+\sigma_2^2\pm2\rho\sigma_1\sigma_2.
$$

두 표준편차가 1이고 $\rho=0.75$이면 합의 분산은 3.5, 차의 분산은 0.5입니다. 척도가 같고 $\rho=1$이면 평균을 뺀 두 편차가 같아서 차의 분산은 0입니다. 두 입력의 평균은 서로 다를 수 있습니다.

## 3. 수식을 그림과 연결하기

양의 상관을 가진 오차는 대각선 방향으로 길게 퍼집니다. 합 방향으로 투영하면 이 변동이 남고, 차 방향에서는 억제됩니다. 실험의 타원은 공분산 인자로 단위원을 변환한 결과입니다. 결합 가우스 분포라면 마할라노비스 반지름이 일정한 경계이며, 완전 상관에서는 선분으로 줄어듭니다.

## 4. 일차 전파가 부정확한 경우 확인하기

미분 가능한 $f$를 입력 평균에서 선형화하면 $\operatorname{Var}(f(X))\approx\nabla f^T\Sigma\nabla f$입니다. $X\sim\mathcal N(0,\sigma^2)$이고 $f(X)=X^2$이면 평균에서 기울기는 0이지만 실제 분산은 $2\sigma^4$입니다. 접선 근사가 놓친 곡률 때문에 출력이 퍼집니다. 분포 전파, 정확한 모멘트 또는 몬테카를로 계산으로 이 효과를 구할 수 있습니다. [JCGM 101, 몬테카를로 분포 전파](https://doi.org/10.59161/JCGM101-2008)

## 5. 표본을 전달해 검산하기

```python
import numpy as np

rng = np.random.default_rng(2026)
u, v = rng.standard_normal((2, 100_000))
rho = .75
x = u
y = rho*u + np.sqrt(1-rho**2)*v
assert np.isclose(np.var(x+y), 3.5, rtol=.03)
assert np.isclose(np.var(x-y), .5, rtol=.03)
assert np.isclose(np.var(x**2), 2., rtol=.04)
print(np.var(x+y), np.var(x-y), np.var(x**2))
```

## 6. 연구 판단에 맞게 불확실성 전달하기

쌍을 이룬 관측이나 기록된 오차 모형에서 공분산을 추정합니다. 하나의 오차 원인을 공유하는 모든 출력에 같은 입력 표본을 전달합니다. 단위와 비선형 효과의 크기를 확인합니다. 표준편차와 예측구간을 구분하고, 구간을 구할 때 사용한 분포 가정을 밝힙니다.
