# 앙상블 개념·퀴즈와 교재 등록

2026-11-07. 세 앙상블 단원에 개념 단계12개, 기존 검증 안내9개, 해설 퀴즈6개를 연결했다. 교재에는515단원·1545안내가 등록되어 있다. 이 기록은 최종 정적 출력과 실제 읽기 화면의 통과를 대신하지 않는다.

## 교육 화면

유한 저장고는 여섯 전체 배치에서 부분계 배치와 여기 수를 구별하고, 같은 평균의 정확/정준 분포와 저장고 크기별 TV·KL을 비교한다. 정준 모형은 한 자리 정규화와 이항 분포에서 출발하여 고정 Hamiltonian의 온도 응답과 계 크기별 상대 요동을 비교한다. 입자 교환은 입자 수·조건부 배치, 고정 온도의 화학 응답, 온도0의 빈/가득 찬/임계점과 접근 경로를 구별한다.

`learning-ensemble-concepts.ts`의 준비는 실험창 저장 상태와 독립적이다. `use-ensemble-series.ts`가 작은 기준 예제들을 worker에서 순서대로 계산한다. 새 단계에서는 이전 결과를 숨기고, 오류 후 재시도와 이동 시 정리를 지원한다. 여러 온도·편향의 막대는 이산적인 준비 비교이며 보간 곡선이나 시간 진화로 표시하지 않는다.

초기 그림은 자리·개수 확률을, 후속 그림은 각 설명의 응답량을 보여준다. 에너지 척도는 차원이 맞는 `ε/kB=1 K`로 표기한다. 과학적 표기 축 숫자가 잘리는 문제는 실제 화면에서 발견해 수정했고, SVG 안의 텍스트 경계 검사로 재발을 검증한다.

## 보존과 확인

`scripts/fixtures/pre-ensemble-registry-hashes.json`은 기존512개 단원·안내의 내용과 순서를 고정한다. 등록 테스트가 이 해시를 비교한다. 과거 주제의 테스트는 당시 접두 구간을 검증하도록 수정하여 이후의 정상적인 추가를 허용하고, 현재 전체 등록 수는 별도 검사한다.

개념 화면 검사31개, 보존·연결 검사와 전체7205개 검사가 통과했다. 최종 축 여백 변경 이후에도 개념 검사를 다시 실행했고, 실제 사이트의 CSS·폰트로 렌더링한48개 그림 상태에서 잘린 텍스트가 없음을 확인했다. 모델·원고·기존 패널의 검증은 이전 foundation 보고서에 기록되어 있다.

## 남은 검증

최종 정적 빌드와 전체 export 검사, 실제 읽기 화면의 한영·명암·320px/데스크톱 조합, 96개 개념 전환·72개 안내·192개 예제·144개 퀴즈 선택·저장 재로드를 확인한다. 개념 계산 오류 복구·빠른 단계 교체, 무거운 실험 계산 중 언어/테마 조작과 이동 정리도 확인한다. 도서→Interactive Book 메뉴·목차·breadcrumb·검색·sitemap과 Online Book 목록에서의 교재 제외를 유지한다.
