## 4차원 형식 보존과 부피 보존

`four-dimensional-symplectic-maps`는 두 정준 쌍의 전체 형식 `ω=dq1∧dp1+dq2∧dp2`를 검사한다. 역수 배율, 대칭 이차 생성자의 결합 전단, 전체 부피는 유지하지만 형식은 바꿀 수 있는 비교 변환을 다룬다. 원래의2차원 진동자 적분기 실험을 다시 붙인 단원이 아니다.

`MᵀJM=J`와 정준 bracket 보존, 행렬식·Pfaffian의 부피 배율, 선택 탐침의 짝짓기를 별도로 계산한다. 결합 정준 변환에서 투영 기여2 Js와−1 Js가 합1 Js를 보존하는 예를 제공한다. 부피 비교 변환의 a=b 특수 경우는 실제로 심플렉틱이 됨도 판정한다. 영면적 탐침의 통과와 전체 구조, 종속 탐침의 차원과 미정 면적비를 구분한다.

행렬 블록의 kg/s·무차원·s/kg를 구분하고 단위가 다른 계수의 통합 크기를 만들지 않는다. 폐곡선의 `∮p·dq=−ω(u,v)`는 작용 Js이며 경계 매개변수는 물리적 시간이 아니다. 실제 운동이나 에너지 보존을 주장하지 않는다.

## 운동량 그래프와 Lagrangian 조건

`lagrangian-momentum-graphs`는 `p=Aq`, `A=[[a,b+c],[b−c,d]] kg/s`의 그래프를4차원에 매장한다. 전체 매장 차원은2로 유지되고 끌어온 형식은 `A−Aᵀ`다. Lagrangian 조건, 생성 작용의 존재, 대칭 이차 함수의 볼록성, 운동량 대응의 rank를 따로 계산한다.

볼록하지 않은 saddle·오목한 작용, 특이한 A와 영단면도 대칭이면 Lagrangian인 예를 제공한다. 비대칭 장은 원점의 기울기 적합이0이어도 단위 정사각형 작용−2 Js와 형식 결함으로 실패한다. 주변 형식의 비퇴화와 그래프의 영제한,1차원 선의 isotropy와 필요한 절반 차원을 구분한다.

국소 닫힘과 전역 exactness의 차이는 원 위의 일정한 각운동량 일형식으로 설명한다. 이 전역 위상 예제를 사각형 코드가 수치 인증한다고 주장하지 않는다. 일반적 부분다양체 분류·축약·Hamilton-Jacobi 전체는 아직 별도 주제다.
