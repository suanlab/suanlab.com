# 양자정보 이진 판별의 독립 응답 검증

2026-11-09. 이진 상태 판별의 독립 검증기를 구현했다. 양자정보 응답 검증 **1/9가족**이며, 나머지 여덟 가족·실제 Worker·학습 화면·reader는 아직 미완료다.

## 구현

원래 요청과 소유한 응답의 raw input key·version·가족·정확 필드를 확인한다. 생산 모델을 호출하지 않고 Hermitian 특성방정식·고유공간·정확 대수적 구간 포함 관계로 판별 결과를 검사한다. trace distance와 제곱 fidelity도 행렬에서 별도로 도출한다.

프로젝터 응답의64개 수치 좌표(상수 판정은61개), 모든 복소 행렬 위치·확률·스펙트럼 순서, 전략·영 고유값·비유일성·동일/직교 분류를 확인한다. 표시값·log·부호·resolution은 공용 primitive로 구간에서 재생성한다. shared rational/표시 primitive와 독립 모델 검증의 경계는 [응답 계약](quantum-information-response-contract.md)에 명시했다.

## 검증

새511검사로 다음을 확인했다.

- 기존 독립 수학 참조325입력의 정상 응답과32자리의 거의 같은 상태20입력을 수용한다.
- 64개 좌표 각각의 거짓 구간/일관되게 재생성한 표시를 거부하고, 별도로64개 표시값 변조도 거부한다.
- 같은 표시값 아래의10^-100 구간 오류·복소 비대각 전치·잘못된 입력·분류·정밀도·누락/추가 필드·getter/순환·큰 계수를 거부한다.
- 성공 응답은 소유·동결되며 외부 원본 변경의 영향을 받지 않는다. 유효한 좁은 대체 구간과 과도하게 넓은 구간을 구분한다.
- 브라우저 bundle 의존성에 생산 판별기·계산 진입점·fixtures가 없음을 확인한다. 실제 Worker 실행 검증은 아니다.

관련4,279개 입력·원고·수치·회로/채널 회귀와 타입·lint·기존 소스/정적 출력 보존은 `.runtime/learning/quantum-information-discrimination-response/verification.json`에 기록한다.
