## 가역 반응과 실제 종별 수지

예정 ID: `reversible-reaction-advection-diffusion-budget`.

같은 질량 기준의 두 상태 A↔B에 공통 이류 속도U와 확산계수D를 둔다. 종별 원천은 S_A=−kf c_A+kb c_B, S_B=−S_A이고 단위는kg/(m³ s)다. 반응률의 단위는1/s다. 전체 농도는 앞 단원의 유한 질량 Gaussian을 사용한다. 초기 혼합 비율이 공간적으로 일정하면 c_A=f_A(t)c_total, c_B=(1−f_A(t))c_total의 분리형 가족을 구성할 수 있다.

kf+kb>0에서 f_A는 kb/(kf+kb)로 지수 완화한다. 두 반응률이 모두0이면 모든 비율이 정상이므로 선호 평형을0으로 지정하지 않는다. 작은 비영 완화·반올림 혼합비, 매우 빠른 반응과 비영 꼬리의 종별 관측을 분리한다. 실제 창의 종별 저장 변화율·경계 플럭스·반응 원천 적분을 비교하고 합의 질량 보존도 별도로 확인한다. 두 상태의 서로 다른 확산계수·공간 의존 초기 조성·일반 화학양론·열 방출은 이 가족 밖의 후속 확장이다.

## 비선형 Fisher–KPP 전선과 원천항

예정 ID: `fisher-kpp-reaction-diffusion-front`.

c_t+U c_x=D c_xx+r c(1−c/c_sat), D>0,r>0에서 logistic-square 후보 c=c_sat/[1+exp(lambda(x−x0−(U+v)t))]²를 직접 대입한다. lambda=√(r/(6D)), v=5√(Dr/6)로 차원을 복원한다. 유한 창의 저장 변화와 이류·확산 경계 플럭스가 원천 적분과 맞는지 독립 미분·구적으로 검증한다.

프로필 기준점 x0+(U+v)t에서 c는 c_sat/4이며 절반 농도 위치가 아니다. 농도 레벨별 전선 위치와 이동 속도를 구분한다. 이 특수 가족의 속도를 최소 전선 속도나 임의 초기조건의 보편 선택으로 확장하지 않는다. D=0 또는 r=0은 이 프로필 매개화의 정의 범위 밖이며, 같은 실제 장에서 원천만 누락하는 대조를 별도로 사용한다.

성장 원천은 모델에 포함되지 않은 자원과의 전환을 나타내는 열린 기술이다. 닫힌 화학계에서 질량이 무에서 생긴다고 해석하지 않는다. 왼쪽 plateau의 전체 질량은 무한하므로 Gaussian의 유한 총질량 진단을 복사하지 않는다. 큰 양·음 지수의 포화, 안정적 여량 c_sat−c와 선형/로그 꼬리를 구분한다.

## 검증과 화면 연결

두 가족의 실제 미분·유한 창 적분·원천과 경계·종별 합·전선 속도를 제품과 독립적으로 계산한다. 상세 한영 원고에 직관·가정·단위·직접 유도·손계산·대조·연구 연결과 풀이6개씩을 넣는다. 기존 테마의 고정 개념4단계·안내3개·퀴즈2개를 연결하고 최종 반응형·접근성·실제 조작·원본 그림 검증 뒤에만 원래 주제 완료 수를 올린다. 진입은 도서 → Interactive Book을 유지한다.
