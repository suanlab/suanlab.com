# Fourier optics의 계산 모델과 한영 집필 기반

2026-11-05. 기하·파동 광학 다음 원래 주제의 기반 작업이다. `coherent-fourier-pupil-spatial-filtering`, `incoherent-psf-otf-image-formation`에 순수 계산 모델 두 개와 한영 상세 원고 네 개를 작성했다. 아직 단원 등록·실험 UI·새 홈페이지 빌드 검증은 아니다. 등록456개·안내1,368개, 원래 주제256개 입문 검증·106개 미완료를 유지한다.

## 장과 강도의 서로 다른 선형 관측

`src/lib/learning-fourier-optics.ts`는 브라우저에서 사용할 수 있는 일차원 연속 스칼라 근축4F 모델이다. 다른 굴절률·벡터 집속·이차원 원판·센서 픽셀·잡음을 암묵적으로 포함하지 않는다. DFT나 숨은 주기 컨볼루션으로 연속 PSF를 대체하지 않는다.

`coherentFourierImaging`는 명시한 유한 주기 Fourier 준비의 복소 계수를 거른 뒤 장을 더하고 제곱한다. 같은 차수의 준비는 먼저 복소 진폭으로 합쳐 Parseval 평균을 계산한다. `incoherentFourierImaging`는 점원마다 원래 비음수 강도 기여를 계산해 더한다. 점원 가중치와 별도 정현 강도 준비는 단위와 의미가 달라 합쳐 하나의 입력으로 취급하지 않는다.

공간주파수는 cycles/m, Fourier 평면은 `ξ=λ f1 ν`, 실제 영상은 `x′=m x, m=−f2/f1`이다. 일차원 광량 보존 관례에서 실제 장은 `1/sqrt(|m|)`, 강도 밀도는 `1/|m|`로 바뀐다. 실제 좌표의 반전·길이와 원래 적분량을 함께 보존하며 교정 없는 상대 광량을 W로 표시하지 않는다.

## 수동 동공과 원래 광량

고정 기준 반폭, 실제 개구 비율α, 중앙 차폐ε, 진폭 투과율σ와 이차·선형 위상을 사용한다. 동공은 `ε fc≤|ν|<fc`에서 통과하며 정확한 바깥 경계는 제외한다. 경계와 가까운 다른 주파수를 반올림으로 합치지 않는다. 닫힌 개구·완전 중앙 차폐·영진폭을 구분한다.

연속 동공의 적분량 `S=2 fc(1−ε)σ²`는 역길이 단위다. 고정한 기준 동공의 `Sref=2 fref`에 대한 비결맞은 상대 투과율은 `T=α(1−ε)σ²`다. 조건부 단위 적분 PSF와 원래 기준 응답 `T×PSF`를 따로 유지한다. 결맞은 준비의 투과율은 실제 모드의 스펙트럼 가중 비율이며 일반적으로T와 다르다.

`fourierPupilTransfer`, `fourierPupilOTF`, `fourierPointSpread`는 별도 관측을 제공한다. OTF는 이동한 복소 동공의 겹침 적분이다. 이차 위상의 차가 선형이 되는 구조를 사용해 구간별 sinc 적분으로 계산한다. 원래 복소 OTF·기준 전달·조건부 OTF·MTF·위상을 구분한다. 위상 동공의 음·복소 OTF를 양수 크기로 대신하지 않는다.

## 실제 장과 미정값

PSF의 복소 진폭은 선형 위상에서 부호 있는 정확한 구간 sinc로 계산하고, 이차 위상에서는 복합 Gaussian 적분으로 계산한다. 성긴·세분화 적분 차이를 제공하지만 인증된 오차 한계라고 부르지 않는다. 유한한 PSF 표본 창의 합으로 다시 나누어 거짓 단위 정규화를 만들지 않는다.

닫힌 동공에서는 원래 응답은0이지만 조건부 PSF·OTF·MTF·위상은 미정이다. 열린 장치에 영점원을 넣은 경우에는 장치의 기준 전달이 남되 실제 점영상·원천 정규화 투과량을 구별한다. 격자의 정확한 주파수0은 상수 준비다. 이때 실제 상수 평균을 계산하고 공간 대비는 만들지 않는다.

격자는 양의 코사인 제곱 형태로 계산해 어두운 극값의 상쇄를 줄인다. 구성한 수동 동공의 변조 한계에서 반올림 수준 보정이 필요한 경우 보정량을 노출하며 원래 복소 OTF는 바꾸지 않는다. 임의 전달 곡선을 물리적 동공으로 투영한 것이 아니다. 입력 점원 배열은 복제해 외부 변경이 관측 함수에 새어 들어오지 않게 했다.

## 핵심 수치 예제

기준 파장500nm·첫 초점100mm·기준 반폭1mm이면 차단20,000cycles/m다. `E=1+0.5 cos(2πx/L)`, L100µm의 평균은1.125다. 개구 비율0.4에서 DC만 남아 평균1·투과율8/9다. 중앙 차폐0.2에서는 측대역만 남아 평균0.125·투과율1/9이고, 강도 맥놀이는 장의 통과 대역과 다른 관측이다.

선형 위상π/2는 환산 마루를−12.5µm로, 배율−2의 실제 마루를+25µm로 옮긴다. 약한 복소 준비 `1+i0.2cos`에 이차 위상2π를 넣으면 반대 극값0.64·1.44가 나타나되 평균1.02는 유지된다. 정확한 지수 위상 물체와 이 유한 준비는 구별한다.

비결맞은 열린 슬릿의 조건부 중심은40,000m⁻¹, 첫 영점은25µm다. 개구0.5·진폭 투과율0.5에서는T0.125·조건부 중심20,000·원래 기준 중심2,500이다. 원천 가중치1·0.4의 전체 영상 적분은0.175다. 이차 위상6, 주파수15,000cycles/m에서는 OTF약−0.0679647로, 변조0.8의 반대 밝기0.945628·1.054372가 대비 반전을 보여준다.

## 이식 가능한 독립 기준값

`scripts/learning/generate-fourier-optics-references.py`는 NumPy·SciPy를 사용하며 제품 TypeScript를 불러오지 않는다. `scripts/fixtures/fourier-optics-independent.json`에48개 동공(열림16·차단32), 실제 복소 동공 적분816개, 이동 동공 자기상관1,200개를 저장했다. 결맞은48개 준비·장 관측816개·실제 주기 제곱장 적분, 비결맞은48개 준비·점영상432개도 독립 계산했다.

열린 sinc 제곱의 유한 창 적분5개는 별도 sine integral 식과 대조한다. 이 유한 수집량을 무한 공간의 단위 적분으로 바꾸지 않는다. 초기 준비용 DFT 탐색32개와 이번 최종 연속 적분 기준값은 서로 다른 기록이며 같은 검증으로 세지 않는다.

실제 제품 대조의 최대 차이는 동공 복소장약2.97×10⁻¹¹, 원래 OTF1.96×10⁻¹¹, 결맞은 복소장1.05×10⁻¹⁵·평균4.45×10⁻¹⁶, 점영상1.82×10⁻¹¹, 격자 강도2.23×10⁻¹⁶이었다. 동공 적분량으로 척도화한 앞의 두 차이는약9.47×10⁻¹⁶·2.45×10⁻¹⁶이었다. 이는 유한 기준 집합의 관측 차이이며 보편적 오차 한계가 아니다.

## 본문·표시·검증 범위

각 단원의 한영 원고는16개 절과 해설 문제6개를 담는다. 반전·단위·원래 광량·위상·제로 입력·식별성·미분 가능성을 수식과 실제 숫자로 설명한다. 진폭·강도 전달의 차이, 일차원 직사각과 이차원 원판의 차이도 명시한다. 엄격한 KaTeX 경고·오류 검사와 실제 콘텐츠 로더의 한영 목차·렌더링을 검사한다.

초기29개 검사 뒤 표시 준비를 점검하니, 고정 점영상 창에서129개 표본으로 최고 격자 주파수를 그리면 성긴 보간이 생길 수 있었다. 점영상과 격자 프로필을 분리하고 격자 표시에는 최대 네 주기·129개 표본을 사용하도록 바꿨다. 이 선택은 연속 함수의 표시 규칙이며 물리적 픽셀 샘플링 모델이 아니다. 관련 회귀 검사를 추가했다. 앞 기록은 `.runtime/learning/fourier-optics-before-split-profile/`에 보존한다.

최종 전용30개·전체3,749개 테스트와 TypeScript·lint·기존 콘텐츠1,690개 URL 검사가 실제 종료0으로 통과했다. 기존 홈페이지2,869개 파일과 새 기반8개 파일을 합한2,877개 최종 해시는 유지됐고 등록 데이터는 바이트 단위로 같다. 실제 종료·소스 해시·전체 테스트 근거는 `.runtime/learning/fourier-optics-foundation-verification.json`에 정리한다. 초기 개발 기록의 미완성 원고 오류는 최종 통과와 구분해 남겼다. 등록 데이터와 기존 홈페이지 소스는 유지하며, 새 홈페이지 빌드·접근성·브라우저 검증을 주장하지 않는다.
