# 상세평형: worker와 실제 읽기 연결 설계

2026-11-07. [실제 교재 입문 통합 검증](detailed-balance-integration-verification.md)을 마쳤다. 기존527단원·안내의 값과 순서를 보존하며 세 단원·9안내를 추가했다. 전체8,207검사·정적 빌드와 실제 읽기24조합·접근성40상태·Next worker 자산·저장·모션·중지/복구·클라이언트 이동을 확인했다. 로컬530단원·1,590안내, 원래289/362주제 입문 검증·73미완료다. 다음은 유한계와 열역학 극한이며 전체 교육과정·연구 심화는 계속 미완료다. 아래 내용은 이 통합의 설계 계약이다.

## 입력과 계산 분리

세 kind는 `stationary-flux-three-state-cycle`, `metropolis-hastings-proposal-balance`, `reversible-two-state-periodicity-mixing`다. 각각 정수 가중치·양의 목표 가중치·유리수 분자/분모라는 서로 다른 입력 계약을 가진다. version1 request ID·kind·검증된 사본으로 요청을 식별한다. canonical key는 필드 순서를 고정하고 unknown 값을 복사하지 않는다. 복원 데이터·실패·중지·교체에서 이전 준비의 결과를 노출하지 않는다.

수치 모델을 import하는 evaluator는 worker 내부에만 둔다. controller·hook·개념 series는 protocol 타입과 factory만 참조하며 SSR에서 Worker에 접근하거나 계산하지 않는다. 계산 전 started ACK, 완료 후 종료, 실제 계산 시작 뒤 중지·재시도, 교체·언마운트·StrictMode와 worker 파일 실패를 검증한다. 동기 계산 fallback을 넣지 않는다.

세 모델은 정확한 정수/유리수 계산이다. 이전 단원의 적응 정밀도 설정을 복사하지 않는다. 범위 밖 비영 표시와 구조적0, 정상 참조 부재·없는 조건부 수락·0지지집합 역전이 행을 각 의미대로 표시한다.

## 가족별 학습과 시각화

각 가족의 기본 구성은 개념6단계·실험 안내3개·최종 해설 퀴즈3개다. 고정 개념 비교는 저장된 자유 실습 입력과 독립적으로 준비한다. 기존 사이트의 typography·palette·명암·전역 모션 설정을 따른다.

- 정상 순환: 확률 막대, 제안/정상 흐름과 순전류의 구별, 정점 수지, 시간 반전, 현재 준비와 정상 참조, 주기·항등 경계를 다룬다. history의 과거 확률을 선택할 때 마지막 요청 시점의 흐름을 섞지 않는다.
- Hastings: 제안·조건부 수락·수락/거부 사건·최종 전이의 표를 연결한다. 목표 준비와 실제 정상 법칙·그 전류, 우연한 보존, 없는 역제안, 수락과 이동, 상태 변화 점프 기록을 구별한다. 이 모델은 고정 커널 비교이며 표본 경로나 시간 진화를 만들지 않는다.
- 두 상태: 현재·정상·점별 극한·Cesaro 평균을 나누어 그린다. 부호 편차와 비증가 거리, 최악 거리와 선택 초기 거리, 기록 범위·혼합 기준, 교대·흡수·항등·한 단계 reset을 다룬다. 현재 정상확률이0인 행과 상수 지시변수의 상관은 미제공으로 표시한다.

시간 순회가 있는 두 모델은 실제 이산 전이 횟수를 움직인다. 프레임 간격을 물리적 시간으로 부르지 않는다. 현재 요청과 다른 history 시점의 흐름을 보여주려면 해당 시점을 다시 계산하거나 worker에서 일치하는 기록을 제공한다. 모션 정지와 화면 밖에서는 자동 순회를 멈추고 수동 조작을 유지한다.

## 입력·표·경계 조작

유효한 정수와 분모 범위를 검증하고 잘못된 초안은 기존 준비를 유지한다. 비영 텍스트가 Number0으로 underflow한 경우를0입력으로 받아들이지 않는다. 분모를 바꾸어 기존 분자가 범위를 벗어나면 오류로 남기며 몰래 잘라내지 않는다. reset은 초안도 지운다. 프리셋 강조는 현재 canonical 입력에서 결정하여 복원과 자유 입력에 일치시킨다.

긴 history는 페이지로 접근할 수 있게 한다. 확률·편차·TV·로그 표시에서 unavailable 값을0으로 그리지 않는다. 교대 편차의 부호를 평활화하지 않고, 정확한0을 로그 축의 양수로 바꾸지 않는다. 미제공 관측과 정확한0에 별도 설명을 제공한다. 혼합 기준의 미관측 도달을 무한대로 표현하지 않는다.

## 등록과 검증 순서

worker protocol/controller/evaluator/factory/hook과 독립 Node·native 검증을 구현했다. 학습 metadata·고정 개념·예측/최종 문제·안내 데이터는 작성·검증했다. 개념/결과 화면과 새 series hook은 별도 native 화면에서 검증했다. 저장 실습·표지와 최종 학습 흐름도 별도 native 화면에서 검증했다. 실제 교재 등록·Next 읽기/자산·전체 회귀 검증도 마쳤다. 그 뒤 기존527개 단원·안내·영역 metadata의 값과 순서를 해시로 보존하고 세 단원·9안내만 추가한다. 이때 예상 등록은530단원·1,590안내지만 **지금의 완료 수치가 아니다**.

실제 concept/lab/cover dispatch·열역학 membership·검색·SSR·정적 빌드와 worker chunk 분리를 확인한다. 실제 읽기의 한영·명암·모바일/데스크톱, 저장·프리셋 강조·전체 표·선택 경계·접근성·모션·중지/재시도·자산 실패·클라이언트 단원 이동과 전체 회귀를 검증한다. 진입은 도서 → Interactive Book이고 Online Book 본문에 추가하지 않는다. 그 후에만 상세평형을 원래 입문 주제 하나로 올린다. 전체 영역과 연구 깊이의 완료는 별도다.
