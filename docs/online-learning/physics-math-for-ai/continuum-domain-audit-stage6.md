## 본문과 수지의 대조

한영 본문 전체의 가정·단위·유도·손계산·각6개 풀이를 읽고 실제 모델·그림·고정 개념8단계·안내6개와 대조했다. Gaussian 필터의 실제 전달·외력 예산에서 이산 저장량과 공유 면으로, 약한 해·entropy 조건에서 실제 Godunov/Roe 갱신으로 이어지는 선수 흐름을 확인했다.

물통3개의 예제에서 질량1kg와 잘못된 규칙의1.075kg, 노름 변화−0.1725kg²/m³를 확인했다. 농도 합과 물리 질량, 물리 확산과 상류 수치 소산, 시간 연속 손실과 양의 Euler 보정을 구분한다. 격자 좌표는 선언한 부동소수점 기하이며 로그 표현이 기하를 기호 계산으로 바꾸지는 않는다.

Burgers의 보존·면별 entropy·완전 이산 조건은 서로 대체할 수 없다. 미보정Roe의−1→1 면은 D=−2/3이고 반대 압축 면의 양의 결손과 합산에서 상쇄될 수 있다. 수치 경계 장부는 실제 수치 플럭스를 사용하며, 정확한 전체선 참조는 통과 시간을 나눈 별도 경계 적분과 비교한다. 셀 평균 오차와 재구성 프로필 오차, 연속체 entropy 적분과 셀 평균의 제곱합도 구별한다. [Clawpack의 유한체적 설명](https://www.clawpack.org/riemann_book/html/Approximate_solvers.html)과 [Roe 반례](https://www.clawpack.org/riemann_book/html/Burgers_approximate.html)를 대조했고, 선언한 이차 entropy 식은 직접 대수로 확인했다.

## 발견한 표시 문제와 수정

두 초기 상태의 변화·오차 로그가 모두 미정일 때 그래프 가로축도0~0.01로 축소됐다. 세로값을 거르기 전에 공급한 가로 좌표 범위를 보존하도록 수정했다. 기본 격자의 초기 로그 그림은 원점을 포함해 마지막 셀 중심인 약1.80748m와1.875까지 유지한다. 물리 구간 전체의 길이2와 셀 중심 표본의 끝점을 혼동하지 않는다.

정의되지 않는 로그에는 곡선이나 점을 추가하지 않는다. 기존의 생략 개수·단위·부호/로그 표와 불연속 참조의 구간 분리, 색상·명암을 유지한다. 계산 모델과 원고는 이번 단계에서 변경하지 않았다.
