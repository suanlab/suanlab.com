# 유도·전자기파 연구 보강 검증

2026-11-13. 유도·전자기파 두 단원의 한영 네 원고에 회로·질량의 반작용과 전기장 시점 관측의 초기 자기장 식별을 추가했다. 기존 본문·각 여섯 해설 문제·실습 입력은 보존한다. 전자기학 순차 보강은 **10/20단원**이며 영역 전체 종합 대조는 후속이다.

## 설명과 시각화

- `faraday-induction-fixed-moving-loop`: 방향 있는 K=BH의 기전력 −Ku와 레일 힘 KI에서 수동 회로·질량의 결합식을 유도한다. 지정 속도의 외부 전력과 자유 운동을 구분하고 운동·유도 저장·열의 수지를 증명한다. 상수 직렬 인덕턴스 근사에서 무손실·저감쇠·임계·과감쇠 해를 모두 다룬다. 큰 저항이 무한히 빠른 제동을 주지 않는 이유, 무손실 반전, 결합 0의 별도 해도 설명한다. 위치 의존 인덕턴스를 사용할 때 필요한 자기 선속 미분과 여에너지 힘을 함께 유도한다. 외부 자기장 원천·복사·실제 물질의 전체 모형으로 확대하지 않는다.
- `electromagnetic-wave-equation-transverse-initial-data`: 분해 가능한 유한 Fourier 모드의 일차 Maxwell 회전을 관측 행렬로 옮긴다. 정수 π 위상의 영공간, 근접한 비영 위상의 잡음 증폭, 초기·이후 측정의 공분산 전파를 구분한다. 정확한 초기 E와 독립 동분산의 추가 시점이라는 조건 아래 최소제곱·정보량을 유도한다. ridge가 관측 정보를 만들지 않는 이유, 유한 대역 시점 설계의 대역폭 의존 악조건, 평균 B의 비식별성을 설명한다. 초기 공간 alias와 시간 맹점을 구분하며 추가 시점으로 일부 공간 alias를 분리할 수 있다는 범위도 유지한다. 기존 Gaussian 중심 점의 β 모호성은 별도의 실제 제품 대조다.
- 각 원고에 **9표시 수식·1실행 셀/표·3해설 연구 질문**과 한영 그림을 추가했다. 기존 청색·주황·회색으로 위상 궤적·잔류 에너지·운동/유도/열 수지, 다른 B의 같은 전기 관측·잡음 이득·유한 대역 악조건을 비교한다. 보이지 않는 시점은 실행 표에서 `unavailable`로 남기며 sin(π)의 반올림값을 정보로 사용하지 않는다.

추가 회로·역학과 주기 역문제는 보충 계산이다. 기존 지정 경로와 Gaussian 실습에 새 회로·Fourier 해법 제어가 생겼다고 표시하지 않는다.
