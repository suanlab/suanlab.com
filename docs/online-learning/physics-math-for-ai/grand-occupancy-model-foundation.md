# 유한 점유 격자 입자 교환 모델 검증 현황

2026-11-06. `grand-canonical-finite-occupancy-fluctuations`의 계산 모델과 독립 기준값을 작성했다. **상세 한영 본문·교육 UI·홈페이지 등록은 미완료**다.

## 구현

`src/lib/learning-grand-canonical-occupancy.ts`는 입자 수 분포·조건부 배치 확률, 평균 입자와 빈자리, 입자 수/에너지 분산·공분산, 엔트로피, 화학 퍼텐셜 응답, log Ξ와 grand potential을 반환한다. 기존 이항 커널을 재사용하며 ε−μ의 차를 큰 로그로 투영하기 전에 계산한다.

양·음의 유한 온도와 양의 쪽 온도 0 극한을 구별한다. 온도 0의 빈 배치·가득 찬 배치·임계점의 균등 준비를 별도로 다룬다. 임계점의 정의되지 않는 μ 미분, 발산하는 log Ξ 극한, 유한 값의 표시 범위 초과, 실제 0과 작은 양수를 서로 다른 상태로 보존한다. 조건부 사건이 금지된 경우 배치 조건부는 null이다.

## 검증

독립 기준값 36개와 추가 검사를 합한 **44개 검사 모두 통과**했다. 작은 계 23개는 모든 비트 배치를 열거했다. 기준 생성은 최대 1416자리 고정밀 계산과 추가 80자리 재계산으로 확인했으며, 재생성 결과가 바이트 단위로 일치했다.

검사는 μ=0의 정준 대응, 고정 온도의 μ 응답과 grand potential 미분, 공통 에너지/μ 기준 이동, 큰 수의 정확한 상쇄, 온도 0의 지지집합·응답, 4096자리 정규화, 물리 입력 경계와 직렬화를 포함한다. 확률의 선형 표시가 사라져도 응답이 표현되는 사례와 정확한 half-MIN 공분산도 검사했다.

세 앙상블 가족의 모델·기존 본문을 함께 검사한 **134개 검사도 모두 통과**했다. 타입 검사와 변경 파일 린트를 확인했다. 기존 커널과 앞 두 가족의 수치 구현은 수정하지 않았다.
