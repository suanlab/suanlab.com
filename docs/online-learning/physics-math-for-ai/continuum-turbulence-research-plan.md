# 난류·폐쇄 연구 보강 설계

2026-11-13. 기존 두 단원의 한영 전체 원고와 관련 이론을 읽고 같은 제조장·필터 관례에서 확장한다. 원래 본문·순서형 여섯 문제·풀이와 기존 실습 제어를 보존한다.

## Reynolds: 요동 외력 일까지 닫기

기존 실습이 미검증으로 남긴 완전한 요동 외력 일 예산을 보충한다. 실제 속도·외력 두 성분을 적분해 평균·요동·전체 예산을 비교한다. 구배 적분의 분자 손실과 부호 있는 전달을 독립적으로 계산한다. 점성이 영이거나 작은 경우의 음의 요동 외력 일도 음의 소산과 구별한다. 같은 정상 제조 앙상블이며 시간 발전 난류로 확대하지 않는다.

## Gaussian: 두 필터의 응력과 전달

표준편차의 제곱합 규칙, 결합 응력·필터한 미세 응력·Leonard 분산을 유도한다. Germano의 일반화한 두 필터 항등식을 선언한 스칼라 가족으로 특수화한다. 공통 거친 구배에서의 전달 분해와 기존 전달을 필터하는 연산을 구별하고 정확한 유리수 평균 반례를 제공한다. 두 영 폭 끝점·양의 분산·속도 오프셋을 유지한다. 수동 필터 실습에 새 제어를 넣었다고 소개하지 않는다.

## 검증 기준과 후속

한영 표시 수식 40개·실행 표 4개·연구 해설 12개·그림 4개를 대조한다. 보충 절 제거로 원래 본문 해시와 풀이 24개를 복원한다. 실제 여덟 위상·물리 높이 외력 구적, 직접 Gaussian 적분과 정확한 전달 반례를 검사한다. 같은 새 빌드의 한영 16화면·실습·저장/완료·접근성과 모바일 캡처를 확인한다.

설계 시점 순차 보강은 18/22단원이었다. 관련 220검사·새 빌드·16화면 검증 후 현재 20/22단원이며 [검증 기록](continuum-turbulence-research-status.md)에 근거를 연결했다. 영역 전체 연구 감사는 별도이며 전체 42영역·415주제 대조 / 9영역·94주제 후속과 교육과정 미완료를 유지한다.
