## 해석 범위와 수치 상태

전송선은 양의 L/C·무손실·개방·지정 입력 전압의 정현파 경계 문제다. 한 주파수에서 맞춘 Cfit의 비분산 에너지와 실제 공간 저장을 구분하고 응답 미분을 비교한다. 음의 Cfit을 양의 수동 정전 커패시터로 해석하지 않는다. B는 모형 응답 계수이며 영 구동 데이터만으로 식별되지 않는다. 정확한 DC의 정적 저장과 저주파 주기 평균 극한은 다르다.

유한 이진 위상과 명시적인 정확한 사분파장 공진을 분리했다. 정확한 공진의 비영 구동은 비호환, 영 구동은 비유일이며 유일한 장을 임의로 만들지 않는다. 실제 위상과 위치·주파수·에너지의 표현 손실을 따로 표시한다. 주파수 스윕은 별도의 유한 위상 가족이며 극점을 가로질러 선을 잇지 않는다. 작은 비영 보정·자기 저장·에너지 차이를 직접 평가하되 잃은 측정 정보의 복원이나 엄밀한 오차 인증으로 설명하지 않는다.

층상 매질은 양의 무손실 유전율·mu=1·수직 입사·접선 E·진공 포트다. 해당 장파장 산술 평균을 보편적 등방 물성으로 확장하지 않는다. Bloch 주값은 접힌 위상이며 금지대 감쇠는 흡수가 아니다. 유한 적층의 R/T와 반복 셀의 분산을 분리하며 N=0의 진공 경로를 별도로 표시한다. 전력 정규화 산란행렬로 유한 적층과 내부장을 계산한다.

정규화 좌표와 SI 주파수·위치를 구분한다. 흐름은 입사 전력, 저장은 기준 유전율과 입사 전기 진폭 제곱으로 정규화한다. 에너지 곡선은 물성 경계에서 나누고 출력 경계는 오른쪽 진공 측이다. 정확한0주파수에서 주기 평균은 미정이다. 작은 D−1·얇은 층·굴절률 대비 해상도·가장자리 판정 미정·비영 전파의 표현 손실을 표시한다. 수치 가장자리 여유·잔차·점근 선도항은 전역 인증이 아니다.
