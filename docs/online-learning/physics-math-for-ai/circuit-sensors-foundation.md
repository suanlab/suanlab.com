# 회로·센서와 연속장의 계산 모델과 상세 한영 원고

2026-11-05. RC 회로와 평판 장의 근사, 유한 면적 코일의 전압과 관측 가능성을 다루는 두 단원의 계산 모델과 원고를 작성했다. 기초 집필 단계이며 홈페이지 등록·시각화·입력·안내·퀴즈 연결은 다음 순서다. 등록476개 한영 단원·안내1,428개, 원래266개 입문 검증·96개 미완료를 유지한다. 전자기학은8/10개 입문 주제 검증, 전체51영역509주제·연구 심화는 미완료다.

이후 [홈페이지 통합 검증](circuit-sensors-authoring-status.md)을 마쳤다. 아래 미등록·다음 단계 설명과 수치는 해당 기록 당시 기준이다.

## 순수 계산 모델

`src/lib/learning-circuit-sensors.ts`는 파일·데이터·AI 의존성이 없는 모형이다. `rcPlateState`, `coilFieldState`, `finiteAreaCoilState`, `inferFixedCoilRates`를 제공한다. 양의 R·판 크기·간격과 유한 입력을 검사하며, 회전수는0을 포함하는 정수다. 잘못된 길이·희소 좌표·불완전한 측정·고정 코일 추정에 이동 탐침을 넣는 경우를 거부한다.

## 회로 수지와 공간 근사를 분리

시간은 θ=t/(RC)이며 실제 초와 구분한다. 전압 변화는 expm1으로 구하고, 전압 자체가 초기 배경으로 반올림되더라도 변화량을 별도로 유지한다. 공급 전력의 흡수·공급 부호, 비음수 저항 열, 전기 저장 변화와 누적 일·열을 구분한다. 작은 비영 에너지의 표현 손실은0으로 바꾸지 않는다.

평판 사이의 균일 E와 변위 전류에서 B를 복원하면 Ampere가 맞아도 Faraday φ 잔차=(μεr/2d)V″가 남을 수 있다. 축의 한 점에서 잔차0과 가족 전체의 Maxwell 적합성은 다르다. 전기 저장0의 UB/UE는 미정이며, 복원한 판 사이 자기 에너지는 국소 근사 적분이다. 이를 기존 회로 예산에 단순히 더해 전체 장치 에너지를 인증하지 않는다.

a/(cRC)와 d/a는 다른 근사 척도이며 일반 장치의 엄밀한 전역 오차 상한이 아니다. 이상 계단의 초기 순간·유한 전파·긴 도선·가장자리·분포 인덕턴스·방사·전체 경계 조건은 별도 문제다. R=0·C=0을 작은 양수로 대신하지 않는다.

## 코일의 면적·운동·관측량

법선은+z, 순회는 위에서 본 반시계다. 원형 물질 루프의 고정 반지름·법선을 유지한 평행 이동을 사용한다. 실제 장은 Bz=B0+g(x²+y²), 이에 맞는 매끄러운 E와 필요한 분포 J를 포함한다. 수동 탐침이라는 가정이 외부 원천을 없애지는 않는다.

평균 B에는 gR²/2가 있고 고정 코일 emf에는 그 시간 미분이 들어간다. 이동에는 2g o·v가 추가된다. 전기 순환·운동 순환·전체 전압·선속 연결을 분리한다. 관측 Φ/A가 면적0에서 미정인 것과 해석적인 원점 극한을 구분한다. 영반지름·영회전수·작은 양의 면적 손실·좌표보다 작은 반지름·좌표 해상도보다 작은 이동을 별도 상태로 반환한다.

고정 코일 전압으로 추정하는 미지수는 B0′·g′이며 초기 선속 없이 일정한 B0·g를 복원할 수 없다. 평행 이동은 정적인 곡률 g를 관측하게 할 수 있지만 일정 균일 B0는 여전히 비식별이다. 센서 부하·역작용·회전·변형·접점 변경은 현재 가족의 범위 밖이다.

## 구조적 rank와 수치 추정

두 고정 코일의 기하 가중치는 |o|²+R²/2다. 같은 가중치의 행은 서로 다른 위치여도 독립 정보를 늘리지 않는다. 정확한 이진 입력의 제곱 차이를 BigInt로 정렬·합산하고 마지막에 반올림하여 작은 기하 차이와 정확한 상쇄를 구분한다. 구조적 rank가2여도 관측이나 해를 표현할 수 없으면 미정이다.

거의 같은 코일에서는 먼저 정규화한 전압을 차감하는 과정도 정보 손실을 증폭한다. 원시 전압·이득의 곱 차이를 유지하는 계산과 반올림한 정규화 관측 차이를 따로 제공한다.180자리 기준은 주어진 반올림 전압·이득에 대한 해이며 실제 장의 진실을 복원했다는 인증이 아니다. 이미 소실된 관측 정보는 복구하지 못한다.

고정 코일 추정은 열 척도 길이를 명시하고 그 기준의 무한대 노름 조건수를 제공한다. 지정 전압 오차의 조건부 전파와 산술·기하·모형 오차를 구분한다. 관측 부족, 지정 오차 범위의 모순, 산술 사용 불가, 유일한 해를 별도 상태로 반환한다. 비활성 탐침의0행을 정규화된 비영 행으로 만들지 않는다.

## 독립 계산과 검증 상태

독립 생성기 `scripts/learning/generate-circuit-sensors-references.py`는 제품 코드를 가져오지 않는다. SciPy ODE와 순일 구적·필드 차분·자기 에너지의 반지름 구적96조건, 실제 E/B 차분27조건, 면적·E/v×B 선적분·이동 선속 차분24조건을 대조했다. 별도 NumPy 측정 전압 선형계2조건,180자리 정확 입력 기하4조건·작은 RC 변화3조건과 반올림 전압·이득의 추정 해도 포함한다. 선택한 수치 관측이며 엄밀한 전역 오차 상한은 아니다.

전용28개·전체4,177개 테스트와 타입·lint·콘텐츠1,710 URL 검사가 실제 종료 코드0으로 통과했다. 결과는 `.runtime/learning/circuit-sensors-foundation-verification.json`에 기록했다. 네 원고를 실제 콘텐츠 로더로 렌더링하여 strict KaTeX·한영 수식 일치·고유 목차·스크롤 접근성·영어 한글 잔존 없음·풀이를 확인했다. 기초 집필 자체로 홈페이지 완료 수를 올리지는 않는다. 기존476개 단원·안내와42개 실험 그룹467항목은 등록 전 canonical 기준으로 보존한다. 기존 홈페이지 소스·설정2,997개와 출력4,167개를 유지하고, 새 파일을 포함한 기초 소스·설정3,007개를 동결한다. 미등록 원고 단계라 새 빌드·화면 점검·공개 배포는 하지 않았다.
