## 에너지 보존과 엔트로피 증가

`fourier-heat-diffusion-mode-budget`는 같은 유효 열용량 모델에 국소 평형과 ds = C dT/T 상태 관계를 명시적으로 추가한다. 엔트로피 플럭스·생성, 고정 평균에서의 최대 엔트로피와 정확한 주기 로그 적분을 유도한다. 현열은 보존되지만 엔트로피는 증가하며 평형 상대 가용성 함수는 감소한다.

가용성의 단위는 J, 엔트로피는 J/K, 기존 이차 온도 노름은 K²m³다. 노름과 가용성의 작은 대비 근사를 정확한 등식으로 바꾸지 않는다. 실제 기관의 일 추출이나 외부 열저장고를 계산한 것이 아니다. 전도도 영·대비 영·비영 산술 범위 제한을 구분하고 기존 실습의 관측과 제어를 유지했다.

## 상대 정보가 줄어도 중심·질량 오차는 남는다

`gaussian-fick-diffusion-spreading`은 같은 이류·확산을 따르는 두 양의 질량 구름을 각자 정규화한다. 움직이는 기준의 KL 소산을 두 PDE의 부분 적분으로 설명하고 Gaussian 상대 Fisher 정보를 모멘트로 구한다. 같은 표준정규 변수 결합과 공분산 하한으로 최적 제곱 수송 비용을 증명한다.

같은 분산이 넓어지면 KL은 영으로 가도 중심 차이와 제곱 수송 비용은 남는다. 같은 형상·다른 질량의 KL 영은 물리적 질량 일치를 인증하지 않는다. 질량 영에서는 정규화 비교를 미정으로 남긴다. 이 내용을 열역학적 엔트로피나 기존 실습의 둘째 구름 제어로 소개하지 않는다.

## 원고·계산·그림 대조

새 **40표시 수식·4 Python 표·12연구 해설**의 한영 수식·코드·실제 출력이 같다. 연구 절 제거로 원래 4본문을 바이트 단위로 복원하며 **24기존 해설**과 원래 15/17절을 보존한다. 최종 목차는 16/18절이다.

독립 표준 라이브러리 검산은 **20실제 열 주기 적분·12국소 엔트로피 차분·27Gaussian 로그/score 적분**을 확인했다. 정확 유리수 계산은 **81Gaussian 모멘트/소산·108수송 결합 비용·15지속 중심 오차·9질량 비관측 대조**를 확인했다. Gaussian 수치 적분은 명시한 유한 꼬리 구간의 보통 크기 사례이며 모든 꼬리·매개변수의 인증이 아니다. 유한 사례는 본문의 논증을 대신하지 않는다.

홈페이지 색·서체 계열의 한영 SVG 4개를 원본 크기로 직접 검토했다. 양의 온도·보존 평균·엔트로피 증가/결손·국소 생성·중심 차이·별도 질량 대조의 정의와 단위를 확인했다. 그림 구간을 잘라 재정규화하지 않았다.
