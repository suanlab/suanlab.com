## 수학과 현재 화면

유일한 바닥 상태와 같은 들뜬 에너지의 g개 미시 상태, kB=1, 양의 절대온도인 정준 평형 조건을 확인했다. 미시 확률을 직접 열거한120자리 Decimal 참조로 등록 예제3개와 실제 입력 범위의 경계 조합8개, 총11준비를 대조했다. 관측값·곡선값2266개, 온도 격자1100개, 엔트로피 항등식22개가 일치했다. 이것은 현재 UI 범위에서의 반올림 Number 출력 검사이며 방향성 구간 인증이나 무제한 입력의 정확성 증명은 아니다.

공식 MIT 앙상블 자료의 정준 무게·에너지 모멘트·축퇴 수준 예시를 확인했다. 교재는 자기 유한 모형을 따로 지정한다. 에너지 점유와 미시 확률, 이진 점유 엔트로피와 전체 엔트로피, 평형 법칙과 순간 에너지의 구별을 유지한다.

실제 영문320px 화면에서 분배함수 단계의 수치가 점유 확률, 엔트로피 단계의 수치가 자유에너지 F인 것을 확인했다. 수학 값은 맞지만 단계의 설명과 읽기 값이 어긋난다. 그래프 글씨는13px였다. 정수 축퇴도의 소수 원문 손실과 비영 underflow 입력은 공유 NumberField에서 이미 올바르게 거부했다.

- 개념 단계가 분배함수 Z와 엔트로피 S를 표시하도록 해당 단원에 한정한 수치 선택을 바꿨다.
- 해당 단원의 SVG 최소 폭400px·명시적 글씨14단위와 영역 설명을 준비했다.400px에서 실제 글씨16px를 유지하며 기존 색과 곡선 좌표를 유지한다.
- 한영 본문에 실제 조작 비교 표와 해설이 있는 여섯 문제를 준비했다. 정규화·축퇴·유한/무한 온도·일관된 에너지 기준 변경·에너지 요동·온도 곡선의 해석을 다룬다. 원래 표시 수식은 유지했다.
