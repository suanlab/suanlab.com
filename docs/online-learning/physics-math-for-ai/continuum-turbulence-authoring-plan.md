## 평균·공분산과 폐쇄 결손

예정 ID: `reynolds-ensemble-stress-closure-defect`.

유한 균등 위상으로 정의한 발산0속도장을 사용한다. 채널 벽의 속도 조건·실제 평균 프로필·섭동 streamfunction·밀도·점성·공분산과 평균 강제 항을 선언한다. 실제 위상 평균과 독립 적분,공분산의 비음성과 응력·에너지 전달을 검증한다. 단순히 벡터 그림을 흔드는 애니메이션을 난류DNS라고 표시하지 않는다.

같은 평균 속도에서 다른 공분산이 생기는 예와 일정한 비음 eddy viscosity 후보의 결손을 보여준다. 평균 전단0에서−Ruv/U_y가 미정/표현 불가인 경우를 구분하고,전단·응력 모두0을 유일한 점성0으로 채우지 않는다. 후보 응력으로 바꿀 때 원래 강제 항과 실제 운동량·일 수지가 어떻게 달라지는지도 확인한다. 명시한 앙상블에서 강제 항이 바뀌는 사실을 숨기지 않는다.

## Gaussian 필터·잔여 응력·에너지 전달

예정 ID: `gaussian-filtered-burgers-subgrid-transfer`.

두 Fourier 모드와 명시한 강제로 구성한 주기 Burgers 장을 사용한다. Gaussian 표준편차·공간 주기·물리 파수·분자 점성·모드 진폭과 실제 필터 연산을 선언한다. 필터한 비선형 항과 필터장으로 만든 비선형 항의 차이,잔여 응력·국소/전체 에너지 전달·반대 방향의 backscatter와 점성 소산을 구분한다.

주기·일정 폭이라 미분이 교환되는 현재 가족과 벽/공간 가변 폭의 추가 문제를 구분한다. 필터 폭0,영 모드,단일 모드,작은 폭·작은 진폭,큰 감쇠 꼬리,전달 방향 반전과 Galilean 응력 불변성을 검증한다. [자체 유도](continuum-turbulence-derivation-notes.md)에서 얻은 네 비음 항의 정확한 유한 분산 표현을 사용한다. 작은 폭에서 계수와 진폭 조합의 상쇄를 각각 안정화하고, 일반·극한 독립 convolution으로 검증한다. 무한 급수 절단을 사용하지 않는다. 유한 격자 aliasing이나 수치 필터를 물리 필터와 동일시하지 않는다.

## 학생용 설명과 검증 순서

각 한영 원고에는 Reynolds 수·다중 척도·에너지 cascade의 역할과 계산 한계,RANS와LES의 연산 차이·폐쇄의 의미·AI 학습 자료의 식별성 및일반화 조건을 설명한다. 손계산·직관·풀이6개씩,고정 개념4단계·안내3개·퀴즈2개와 실제 입력·그림을 제공한다. 전 범위의 난류 이론·모델 보편성이나 연구 심화 완료를 두 예제의 성공으로 대신하지 않는다.

독립 고정밀 공간/위상 적분·미분·실제 강제/에너지 수지와 작은 값의 부호·로그를 확인한다. 이후 기존 테마의 한영·명암·모바일·키보드·정밀 입력·모든 예제·원본 그림·정적 출력·영어 순회를 검증하고 입문 진행을 갱신한다. 다음은 보존형 이산화와 연속체 영역 전체 점검이다.
