# 유한 Curie–Weiss 계산 계약과 검산

2026-11-07. `learning-curie-weiss.ts`의 구현 근거다. 독자용 설명은 `finite-curie-weiss-magnetization-symmetry.{ko,en}.md`에 둔다. 원고·모델 준비를 실제 읽기 통합과 구분한다.

## 준비와 정확한 계수

입력은 정수 N=1..128, binary64 K∈[0,8], b∈[−4,4]다. K,b는 직접 지정한 무차원 매개변수다. 물리적 J,h,T 입력을 먼저 부동소수점으로 나누고도 원래 물리 입력을 정확히 보존했다고 주장하는 API가 아니다. 양의 온도에서 K=J/(kBT), b=h/(kBT)이며 영인 계수는 온도 변화 중에도 영이다.

M=2k−N, `g_k=choose(N,k)`를 BigInt로 생성한다. `g_0=1`, `g_{k+1}=g_k(N−k)/(k+1)`의 나눗셈은 정수다. M/N과 `KM²/(2N)+bM`도 정확한 유리수로 만든다. M²/(2N)의 먼저 반올림된 Number를 에너지로 사용하지 않는다. 모든 미시상태 수는2^N이며 전송용 다중도는 정수 문자열이다.

K≥0에서 점수는 M의 볼록 이차함수이므로 최대 지수는 `a=N(K/2+|b|)`다. 비용 `a−score(M)≥0`을 정확히 만든 뒤, 각 정밀도 P에서 지수함수를 방향성 구간으로 계산한다. 최대점의 다중도는1이고 비용이0이므로 정규화 합의 하한은 항상 양수다.

## 정수 격자 구간과 양의 분산

`raw_k=g_k*exp(score_k−a)`의 상·하한을2^P 격자 정수로 유지한다. 합 W와 정수 모멘트에도 방향을 보존한다. 부호 있는 평균에서는 음의 계수를 곱할 때 구간 끝을 뒤집는다. b=0의 평균0은 대칭으로 증명한 정확한 분기다.

분산은 `sum_{i<j} raw_i raw_j (M_i−M_j)^2 / (N² W²)`이다. 가까운 두 모멘트의 차를 쓰지 않으며, 순서가 있는 M의 간격2를 이용해 O(N)에 계산한다. j번째 지점에서 이전 원소의 질량 합 A, 거리 일차 합 D, 거리 제곱 합 E를 추적한다. 이전 원소를 A에 추가한 뒤

`E_new=E_old+4 D_old+4 A_new`, `D_new=D_old+2 A_new`.

각 j에서 `raw_j*E_new`를 누적한다. O(N)은 구간 연산 수이며 BigInt 연산 비용은 정밀도와 정수 길이에 의존한다. 모든 항이 비음수여서 양의 구간 곱을 직접 사용할 수 있다. 분자와 W²의2^(2P) 척도는 상쇄된다. 테스트에서는 별도의 이중 쌍 합과 독립 Python 중심 분산을 대조한다.

## 로그 확률과 엔트로피

`ln Z=a+ln W`에서 W는 격자 척도를 제거한 합이다. 희귀 꼬리를 표시상0으로 바꾸지 않는다. raw 하한이 양수이면 `ln p=−ln(W/raw)`로 구해 지배 확률이1로 투영되는 문제와 분리한다. W/raw≥1이라는 증명된 경계만 적용한다. raw 하한이0이면 `ln g−cost−ln W`의 구간을 사용한다.

거시 엔트로피는 `−sum p ln p`, 조건부 미시 정보는 `sum p ln g`, 미시 엔트로피는 둘의 합이다. 이 합은 큰 에너지와 log Z를 빼는 것보다 저온·편향 준비에서 안정적이다. 독립 참조는 미시 로그 확률 `score−ln Z`에서 엔트로피를 직접 계산한다.

자기 항을 포함한 무차원 평균 에너지는 `−K E[M²]/(2N)−b E[M]`이며 쌍 관례는 K/2를 더한다. 표기상 E[M²]는 확률 기대값이다. log Z_pair는 log Z−K/2다. 한 스핀의 M²=1, |m|=1은 정규화 합에서 서로 의존적인 구간을 나누는 대신 정확한 상수로 처리한다.

## 정밀도 상한에서 보존할 부호

유한 K,b에서는 모든 거시상태의 확률이 양수이고 상태 수가2개 이상이어서 각 로그 확률은 음수다. Var(m), 평균 |m|, 평균 m²와 두 전체 엔트로피도 양수다. N>1이면 조건부 다중도 엔트로피 역시 양수다.

`d<E[M]>/db=Var(M)>0`이고 영장 평균이0이므로 평균 M의 부호는 b의 부호다. K=0에서는 `E[M²]=N+N(N−1)tanh² b≥N`이다. 고정 b에서 `dE[M²]/dK=Var(M²)/(2N)≥0`이며 N>1이면 엄밀한 증가다. 따라서 쌍 에너지는 b≠0 또는 N>1,K>0에서 음수이고, b=0인 N=1 또는 K=0에서0이다.

구간이 아직0을 포함하더라도 위에서 증명한 부호는 유지한다. 부호를 안다는 사실이 크기를 해결했다는 뜻은 아니다. `unresolved-at-precision-ceiling`과 범위 밖 비영의 null 표시, 구조적0을 구분한다. 일반 관측값의 로그 크기 표시는 근사이며 관측량의 인증은 방향성 유리 구간을 따른다.

## 최빈값은 반올림 확률로 판정하지 않는다

각 `ln g+score` 구간의 상한이 전체 하한 최댓값보다 작은 상태를 제외한다. 같은 g를 공유하는 상태는 공통 ln g를 정확히 소거하고 점수를 비교해 엄밀히 지배되는 상태를 제외한다. 남은 후보가 같은 g와 같은 정확한 점수를 공유하면 최빈값 집합을 인증한다. 그 밖에 구간으로 비교를 끝내지 못하면 미해결 후보를 반환한다.

이 처리는 최소 비영 b가 주는 대칭 분할도 지우지 않는다. N=2에서 실제 binary64 log(2) 입력과 그 다음 수의 최빈값은 각각0과±2다. 지정한 정확한 실수 log 2의 세 동률 상태를 실제 이진 입력의 정답으로 대입하지 않는다. 유한 argmax의 변화는 log Z의 비해석성을 뜻하지 않는다.

## 독립 검증 경계

Python 생성기는 actual float를 `Decimal.from_float`로 읽고, 이동하지 않은 양의 지수 합과 중심 분산을 직접 계산한다. 19사례를400/900자리와 추가80자리에서 대조하고 N≤7의11사례는 총344개의 이름 붙은 배치를 직접 열거한다. 모델의 구간 함수와 O(N) 쌍 합을 복사하지 않는다. fixture 재생성은 바이트를 비교한다.

이 단계에는 worker·고정 개념 화면·실제 읽기 경로 등록이 없다. 특히 최대 지원·최소 비영 장 계산은 수 초가 걸릴 수 있으므로 실제 학습 화면에서는 전용 worker와 취소·이전 결과 차단이 필요하다. 변분 극한과 육차 Landau 가족을 같은 모형의 검증으로 대신하지 않는다.
