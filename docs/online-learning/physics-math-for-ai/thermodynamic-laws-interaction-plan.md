# 열역학 법칙: 세 가족의 상호작용 연결

2026-11-06. [세 가족 기반 검증](thermodynamic-laws-foundation.md) 이후 구현할 계획이다. 아직 실습·그림·교재 등록을 완료한 단계가 아니다. 범위와 분량은 주차로 제한하지 않는다.

## 카르노 순환

물질량·두 저장고 온도·초기 부피·팽창비·방향·진행률을 연결한다. 방향은 정/역의 유효한 선택만 허용하고, 저장고 순서가 바뀐 입력은 수정 안내를 제공한다. 자동으로 온도나 역할을 교환하지 않는다.

실제 p–V와T–S 경로, 네 꼭짓점, 현재 누적 열·일·내부 에너지, 계와 저장고의 엔트로피 수지를 그린다. 순환 전체의 기관/냉동기 분류와 부분 순환의 일 부호를 구별한다. 방향을 반대로 했다고 누적 일을 임의로 음수로 강제하지 않는다.

가역 기관·역방향 냉동기, 네 구간, 같은 온도, 팽창비1, 작은 온도차/팽창비/진행률, 역방향의 영 일 교차와 그 양쪽, 이진 온도 차이의 정확한 복귀를 예제로 포함한다. 실제0/0과 수학적 W/Qh=0, 실제 운전 성능, 온도로 정한 상한을 분리한다. 재생은 경로 위치를 바꾸며 물리적 시간·출력이 아니다. 모션 감소/비활성 화면에서는 멈추고 수동 단계를 유지한다.

## 두 저장고 포트

두 온도·고온 입력·상대 생성 계수를 연결한다. 실제 열·일 포트의 부호와 크기, 에너지/엔트로피 수지, 생성에 따른 일 감소와 카르노 상한을 비교한다. 내부 피스톤 궤적은 그리지 않는다.

양의 일·일 입력·영 일·전달 없음·반사실적 음의 생성을 명확히 표시한다. 음의 생성은 실제 가능한 기관 애니메이션으로 표현하지 않는다. 일을 받는다는 이유만으로 냉동기로 부르지 않는다. ‘형식적인 일/열 비’와 실제 기관 효율도 구분한다.

가역 포트·양의 생성·음의 생성·방출0·영 입력·같은 온도·경계 양쪽·극소 생성과 표현 불가 음의 생성을 대조한다. 반올림된 두 열/엔트로피를 빼서 실제 일/생성을0으로 바꾸지 않는다. 이 모형에는 실제 시간이나 생성률이 없다.

## 저온 유한 스펙트럼

독립 복제 수·두 상태군의 축퇴도·간격의 온도 환산값·온도를 연결한다. 정수 수는 유효한 정수만 적용한다. 같은 에너지의 상태 수를 반복 곱해 확률을 중복 계산하지 않는다. 간격0에서는 위 상태군도 바닥이므로 ‘들뜸’으로 오인하지 않는 표시를 사용한다.

한 복제의 스펙트럼과 상태군 확률, S(T)·C(T)·U(T), 잔류 엔트로피와 들뜸 보정, 두 극한의 순서를 보여준다. 상태 수는 정확한 정수 문자열/로그로 표시하고 복제당 관측과 전체량을 분리한다. 양의 온도 곡선과 T=0 평형 극한은 별도로 다루며, 정의되지 않는 로그 온도나 불연속인 극한 경로를 선으로 이어 붙이지 않는다. 작은 간격의 전이 범위를 해상도 밖에서 임의로 선형 보간해 실제 물리 해처럼 보이지 않게 한다.

확률·SI 값·정규화 값·첫/추가 로그의 표현 범위를 각각 읽을 수 있게 한다. 실제0과 범위 밖 비영 값을 구별하고, 표시 확률1이 순수 바닥 상태라는 오해를 막는다. 온도를 바꾼 평형 비교를 실제 냉각 동역학이나 절대영도 도달 애니메이션으로 부르지 않는다.
