# 반응수송 두 단원의 홈페이지 통합

2026-11-06. **최종 표시 범위 개선 후 계산·원고·화면 통합 검증을 마쳤다.** 등록492단원·1,476안내, 원래274개 주제 입문 검증·88개 미검증이다. 연속체는6/11개 입문 주제를 검증했으며 영역 전체 감사·전체 교육과정·연구 심화는 미완료다.

## 연결한 내용

가역 반응과 Fisher–KPP의 두 상세 한영 원고를 Interactive Book의 선수·이전/다음·교육과정 지도·수식 목차와 연결했다. 진입은 **도서 → Interactive Book**이다. Online Book에 교재 진입 카드를 넣지 않았다.

가역 반응은13입력·16예제·10그래프로 종별 농도와 합, 양방향 전환량과 순원천, 유한 창 수지, 작은 조성 변화, 완화·전 직선 질량·플럭스·국소 수지·원천 누락·로그 농도를 보여준다. 표시 구간은 구름 폭과 실제 질의·관측 창을 포함하도록 잡으며 전체 질량을 재정규화하지 않는다.

성장 전선은11입력·18예제·11그래프로 농도 수준과 이동, 원천 누락, 안정 여량의 로그와 반올림 뺄셈, 실제 기울기·곡률·국소 수지·플럭스·창 수지·로그 농도·로그 원천을 보여준다. K/4 기준과 절반 위치, 상대/실험실 속도, 발산하는 전체 질량과 유한 창을 구분한다.

각 단원의 개념4단계는 실제 고정 예제에 연결하고 안내3개와 퀴즈2개를 제공한다. 한영 설명·테마 변수·키보드 스크롤·정밀 입력·진행 저장을 사용한다. 잘못된 창 순서에서는 입력과 국소 장을 보존하고 창 수지를 제공하지 않는다. 정확한 영·미정 평형·표현 범위 밖의 비영 관측은 서로 다른 상태다.

## 계산과 검사

[계산 모델과 원고](continuum-reaction-transport-foundation.md)의 독립 고정밀62사례를 실습 어댑터에서도 비교했다. 통합16검사는 등록·정의역·34예제·실제 도함수와 원천 적분·평형/영반응·언더플로·질량0·정지 전선·표시 범위와 꼬리 보존을 다룬다. 전체4,499개 검사를 통과했다.

화면 검증은 최종 빌드 출력을 고정한 뒤 수행했다. 수치 모델의 허용오차와 수식 표의4유효자리·요약의소수3자리 반올림을 구분한다. 첫 브라우저 하네스에서 이전 단원의2개 개념 그래프를 기대하던 부분은 새 설계의 단계별 실제1개 그래프와 고유 marker를 확인하도록 수정했다. 원본 그림 검토에서 기본 구름이 좁게 보이는 문제를 발견해 물리장을 유지한 채 표시 구간을 개선했고, 이후 최종 빌드와 화면 검사를 다시 수행했다. 초기 빌드 화면의 통과 기록을 개선된 출력의 증거로 사용하지 않았다.

- 최종 전체4,499검사, 타입·lint·콘텐츠1,727 URL 검사를 통과했다. 정적1,735페이지 생성과 export1,730 HTML의 링크·자산·fragment·canonical 검사를 통과했다.
- 한영·명암·320/1440px의16개 화면,64개 고정 개념 단계,48개 확장 안내,68개 한영 예제와4개 전체 상호작용 묶음을 검증했다. 접근성 위반·가로 넘침·잘린 SVG 라벨·실행 오류가 없었다. 퀴즈 오답/정답, 진행 저장·복원과 초기화를 실제 조작했다.
- 경계19사례와24입력 각각의 실제 표시값 연결을 확인하고 기존 연속체10단원을 다시 열었다. 좁은 화면의 원본42개 SVG와 키보드 스크롤을 검증했고, 한영·명암4개 그림 모음 전체42패널과 안내1개·대표 수치 표4개를 직접 검토했다.
