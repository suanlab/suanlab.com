## 새로 작성한 내용

주기 경계와 N개 결합의 관례, 선택 edge의 홀짝 계수, 두 연결 경로의 상관, 전달행렬 trace 유도, 삼각형·사각형 손계산을 다룬다. 균일 장 반응과 총량·평균 분산, 무한 사슬의 포락선 길이, 홀수 반강자성 좌절, 교대 source와 균일 source의 차이, 극한의 순서도 설명한다. 한영 각각 14절·표 1개·수식 11개·실행 예제와 해설 문제 6개다. 영어 약 2,893단어, 한글 음절 5,515개다.

## 수치·본문 검증

- `src/lib/learning-periodic-ising-ring.ts`: 실제 binary64 K의 방향성 지수·로그 경계, 양의 기하급수 식과 별도 지수의 정확한 거듭제곱을 사용한다. 작은 비영 상관을 0으로 자르지 않는다.
- 독립 Decimal 참조 20사례·2,580관측. 18사례는 전달행렬 trace, 11사례는 총 672배치 직접 열거로 교차 확인했다. 극단적으로 작은 결합의 긴 고리 두 사례는 닫힌 식 참조이며 trace 검산으로 세지 않는다.
- 원고의 양 언어 수식·코드 일치, 실제 Markdown 수식·표·코드 접근성 렌더링, 작은 배치의 손계산·source 유한차분·바닥 배치 수를 검사했다.
- 새 모델 **28개**, 새 본문 **7개** 통과. 이전 공분산 가족과 상전이 등록 회귀를 합친 **77개 통과**.
