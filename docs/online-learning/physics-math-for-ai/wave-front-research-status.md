# 파동 방정식 연구 보강: 격자 꼬리·수동 경계 기억

2026-11-12. 두 단원의 한영 원고 네 편에 무한 격자의 정확 지지·꼬리 상계와 스프링/감쇠 경계의 인과 응답·에너지 수지를 보강·검증했다. 기존 주기 사슬·고정단/자유단 실습을 보존한다. [파동 영역 순차 검토](waves-optics-topic-review.md)는 **6/18단원**이며 영역 전체 완료는 아니다.

## 추가한 논증·직관·예제

- 사슬 단원은 별도의 무한 격자와 한 위치 초기 변위를 사용한다. Fourier 기호·Bessel 급수에서 해를 얻고, 교대 급수의 양의 하계로 고정된 양의 시각에 얼마든지 먼 비영 계수가 있음을 증명한다. 유한 최대 군속도와 엄격한 compact 지지, 작은 변위 꼬리와 에너지 꼬리를 구분한다.
- 같은 초기 자극의 에너지·기울기가 간격 정련에서 발산함을 계산한다. 작은 기울기를 유지하도록 진폭을 간격에 비례시키면 자명한 영 장으로 수렴한다. 원래의 고정된 매끄러운 초기 장과 다른 문제이므로 연속체 유한 의존 정리의 반례로 사용하지 않는다. 검출 임계값과 수학적 영점도 분리한다.
- 경계 단원은 질량 없는 스프링·점성 감쇠 끝점의 힘 부호, 조화 반사·흡수율, 특성에서 얻은 인과적 일차 ODE를 유도한다. 줄과 경계 스프링의 에너지, 열, 입사·반사 전력을 따로 계산한다. compact 입사 펄스 뒤의 시간 꼬리는 국소 저장 에너지의 방출이며 PDE의 유한 전파를 위반하지 않는다.
- 한영 그림 네 개·비교표·실행 Python·각 세 해설 연구 질문을 제공한다. 무한 사슬의 한 위치 데이터와 Robin/감쇠 경계는 보충 모델이며 기존 실습의 새로운 제어 기능으로 표시하지 않는다. 기존 두 모델의 가정·초기값·계산 범위를 유지한다.

## 계산과 보존 검증

`python3 scripts/learning/verify-wave-front-research.py --json`은 표준 라이브러리만 사용하며 제품 코드·등록 데이터를 가져오지 않는다. 초기 Green 계수 25위치, 정확분수 교대 구간 47개·Fourier 계수 52개·격자 꼬리 16상계·재료/에너지 척도 18사례를 확인했다. 유한 정밀도 Fourier 비교로 매우 작은 계수의 비영성을 증명했다고 하지 않고 정확분수 구간·본문 논증과 구분한다. 별도 주기 ODE 600/1,200보 정련 6사례·72좌표도 영상 합과 대조했다.

수동 주파수 응답 192상태에서 반사·흡수·전력 부호를 확인했다. 경계 ODE 1,200/2,400보 정련과 별도 인과 합성곱을 비교한 36사례, 초기 입사 에너지의 정확 다항 적분과 과도 수지 36사례, 꼬리 방출/열 적분 36사례를 대조했다. 같은 사례의 여러 검사를 더해 새로운 궤적 수로 집계하지 않는다. 수치 비교와 본문의 전역 지지·수동성·꼬리 증명을 구분한다.

한영 표시 수식은 단원별 7개·8개로 같고 Python 네 셀의 출력이 본문 표와 일치했다. 기존 주기 실습의 동일 Fourier 기호 6설정, 기존 고정단/자유단의 영 저장 반사 12조회를 연결했다. 선택 **4파일·49테스트**, 원고/보존 집중 **12테스트**가 통과했다.

연구 절만 제거하면 원래 본문 네 편은 기준 `6e8627b`와 바이트가 같고 원래 해설 24개를 포함한다. 다른 파동 원고 32편·이전 검토 항목 689개를 보존했다. 네 검토 해시를 추가해 693개다. 앞선 공진·결합 진동 보강의 원고/그림 16개도 증거 해시와 일치한다. 등록은 650단원·1,969안내 그대로다.
