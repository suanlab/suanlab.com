# 온도·열·일: 두 가족 상호작용 연결

최신: [온도·열·일의 홈페이지 입문 통합 검증을 마쳤다](temperature-heat-work-authoring-status.md). 아래는 해당 단계의 기록이며 전체 영역·연구 심화 완료를 뜻하지 않는다.

2026-11-06. [열접촉](thermal-contact-foundation.md)과 [이상기체 경로](ideal-gas-paths-foundation.md)의 모델·원고 기반 검증 이후 구현할 작업이다. 이 문서만으로 실습·그림·교재 등록을 완료 처리하지 않는다. 주차·분량 제한은 없다.

## 열접촉 실습

입력은 C₁,C₂,T₁₀,T₂₀,K,조회 시간t,구간 시작a,끝b의8개다. 초기 벡터는 `[2,3,330,270,0.4,3,0,3]`. 모델과 같은 단위·범위를 쓰고, a>b는 안내와 함께 잘못된 구간으로 처리한다. 자동 교환으로 사용자의 입력 뜻을 바꾸지 않는다.

계산값으로 두 온도·평형 온도·순간 전달률·누적 전달 에너지·전체 엔트로피·구간 수지를 그린다. 열용량이 큰 쪽의 온도 변화가 작다는 것을 두 물체 그림과 실제 수치로 연결한다. 흐름 화살표는 실제 전달률 부호를 따른다. 표시용 입자를 ‘열 입자’로 설명하지 않는다. 별도 로그 크기 표에서 실제0·작은 비영·표현 범위 밖·연결 없음의 차이를 설명한다.

예제에는 기본 비대칭 용량, 용량 교환, 같은 온도, 연결0, 두 배 연결, 열용량/연결 동시 스케일, 열 흐름 역전, 시간0, 큰 감쇠, 매우 약한 연결, 가까운 온도, 짧은/영 구간과 역순 구간을 포함한다. 세 안내는 ‘가중 평형’, ‘속도와 최종 전달량’, ‘보존과 엔트로피’를 예측→조작→관측→설명으로 구성한다.

## 이상기체 두 경로 실습

입력은 n,T₀,T₁,V₀,V₁,진행률s의6개다. 초기 벡터는 `[1,300,330,0.01,0.02,0.75]`. A/B를 동시에 비교하며 압력을 독립 입력으로 두지 않는다. 모형의 진행률이 물리적 시간이 아님을 그림 곁에 표시한다.

p–V 두 경로에 초기·중간·최종 상태와 현재 위치를 보인다. 누적 W,Q,ΔU,ΔS를 경로별로 그리고, 기체 압력·부피·온도를 같은 상태값으로 갱신한다. 고정 체적에서 압력이 바뀌어도 일이0인 이유를 설명한다. 실제 경로 면적과 일을 연결하며 서로 다른 진행률 상태를 같은 물리 시간으로 비교하지 않는다.

예제에는 가열·팽창, 냉각·압축, 가열·압축, 냉각·팽창, 같은 온도, 같은 부피, 같은 끝점, 경로 역전, 양 끝/중간 진행률, 정확한 등엔트로피 끝점, 그 양쪽, 거의 상쇄되는 열, 반올림 합의 잘못된0과 극소 진행률을 포함한다. 세 안내는 ‘상태량과 경로량’, ‘가역성의 저장고 조건’, ‘같은 엔트로피와 단열의 차이’다.

## 고정 개념·퀴즈·연결

각 가족에4개의 고정 개념 그림,3개의 실제 예제 안내,2개의 이해 확인 문제를 연결한다. 개념 그림은 현재 실습 입력과 독립된 명시적 사례를 사용하고 올바른 계산 그림을 그린다. 각 안내의 로드 버튼은 전체 입력 벡터를 정확히 적용한다. 퀴즈는 예측·이유를 묻고 오답/정답 해설을 제공한다.

선수는 기존 `thermodynamics`, `exponentials-logarithms`, `integration-fundamental-theorem`, `system-boundary-mass-balances` 등 실제 등록 ID를 확인해 필요한 것만 연결한다. 열접촉 다음 이상기체로 읽기를 이어주며 콘텐츠의 실제 순서와 이전/다음·목차·검색을 함께 갱신한다. 진입은 도서 → Interactive Book이고 Online Book 본문에 새 교재 카드를 추가하지 않는다.

## 검증과 완료 판정

입력14개·전체 예제의 실제 모델 관측과 읽기값을 대조한다. 한영·명암·320px/데스크톱에서 기본 상태·개념·펼친 안내·모든 예제·퀴즈·저장·초기화·키보드·접근성·줄바꿈·원본 그림을 확인한다. 없는 관측을0으로 채우거나 불연속/미정 구간을 잇지 않는다. 모든 곡선의 실제 가로축 범위를 보존한다.
