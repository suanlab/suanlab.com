# 단원 집필과 연구 검증 기준

이 교재는 AI를 설명하는 데 필요한 수학·물리를 정의부터 연구까지 누락 없이 연결하는
확장형 참고·학습 체계다. 집필 분량은 필요한 설명·증명·실험에 따라 정하며 학기나 주차에 맞춰
압축하지 않는다. [지식 색인](catalog.md)의 각 항목을 여러 장·절로 계속 확장할 수 있다.

## 학습 깊이

| 깊이 | 포함할 내용 | 확인할 능력 |
| --- | --- | --- |
| 직관 | 문제·현상·비유·그림·작은 예제 | 무엇을 설명하려는 개념인지 자신의 말로 설명 |
| 계산 | 기호·단위·차원·정의역·수치 예제 | 손계산과 실행 결과를 일치시키고 입력 변화 예측 |
| 정식화 | 정의·명제·정리·가정·증명·반례 | 적용 조건과 논리적 결론, 실패 사례를 제시 |
| AI 동작 | 모델 내부의 연산·목적·학습·추론·평가 | 수학 객체와 실제 모델 상태를 대응시켜 유도 |
| 연구 | 원 논문·재현·변형·가설·검증·새 질문 | 새 방법의 근거와 유효 범위를 검증 가능한 형태로 제시 |

각 깊이는 별도의 충분한 분량으로 작성한다. 쉬운 그림만 남기거나 정리 이름만 나열하지 않는다.
모든 개념을 억지로 3D로 만들지 않고 개념에 맞는 표현을 사용한다.

## 단원에 들어갈 필수 항목

- 의미 기반 단원 ID, 해당 지식 영역, 한·영 제목, 버전과 준비 상태.
- 필수 선수 **절**, 보충 설명, 병행할 수 있는 단원, 후속 연구 연결.
- 학습 목표와 실행·설명·유도·검산으로 확인할 성취 기준.
- 표기·정의·기호·단위·shape·좌표·정의역과 수학·물리 가정.
- 핵심 유도와 정리·증명, 가능한 경우 반례·경계·극한 사례.
- 작은 기준 예제, 수치 허용 오차, 그림·표·장면과의 대응.
- AI 동작 중 어디에 쓰이는지, 무엇을 설명하지 못하는지.
- 선택한 원 논문의 주장·버전·문제 설정·증거·한계.
- 연습·해설, 재현 과제, 가정 변경 과제, 연구 질문과 검증 계획.

## 가정·증명·계산의 구분

연속성과 미분 가능성, 적분·미분·극한·기댓값 교환, 정규화·경계·존재·유일성 조건을
필요한 곳에서 명시한다. 수치 예제가 맞는다는 사실과 정리가 증명되었다는 사실을 구분한다.
정리가 성립하는 가정과 실제 모델·데이터가 만족하는 조건도 별도로 확인한다.

고차원이나 무한차원 상태의 그림은 투영·절단·근사임을 표시한다. 3D 그림에 보이지 않는
자유도와 시뮬레이션 오차를 설명한다. 양자 확률진폭을 고전 확률이나 실제 물체의 좌표로
표현하는 경우에는 대응의 한계를 명시한다.

## 수학과 물리 연결의 수준

| 연결 수준 | 설명 방식 | 확인 사항 |
| --- | --- | --- |
| 동일한 수학 구조 | 함수·연산·변수의 대응을 정의 | 두 문제의 가정과 정의역이 대응하는가 |
| 물리 모델 | 법칙·관측·단위·계의 경계를 명시 | 보존·차원·경계·실험과 일치하는가 |
| 교육적 비유 | 이해를 위한 유사점으로 표시 | 비유가 적용되지 않는 반례를 설명했는가 |
| 연구 가설 | 아직 검증 중인 주장으로 표시 | 구분 가능한 예측과 검증 실험이 있는가 |

예를 들어 gradient descent와 관성이 있는 Newton 운동, Shannon entropy와 열역학 entropy,
학습 손실과 물리적 에너지, 일반적 분포 경로와 열 확산을 조건 없이 같은 현상으로 설명하지 않는다.
식의 대응·단위·시간·잡음·경계와 증거를 확인한 뒤 연결한다.

## 연구 실습의 진행

1. **문제 정식화:** 대상·관측·입출력·변수·가정·성공 기준을 명확히 쓴다.
2. **문헌 재구성:** 기존 정의·정리·알고리즘·증거를 원문 버전과 함께 정리한다.
3. **작은 재현:** 직접 검산 가능한 예제로 식·미분·표본·시뮬레이션을 재현한다.
4. **재현 범위 확인:** 원문의 실험 설정·데이터·환경·평가와 차이를 기록한다.
5. **새 질문:** 가정 변경, 새로운 제약·구조·표현·학습·추론 또는 모순되는 현상을 정의한다.
6. **새 방법과 근거:** 유도·증명·반례 또는 실험으로 주장을 검토한다.
7. **평가:** 강한 기준선, ablation, negative control, 민감도·비용·불확실성을 비교한다.
8. **연구 기록:** 긍정·부정적 결과, 실패 조건, 코드·데이터·환경·주장 범위를 남긴다.

새로움을 주장하기 전에 관련 연구와 문제·조건·결론의 차이를 확인한다. 기존 결과를 읽고
변수 이름만 바꾼 것을 새 연구로 표시하지 않는다. 실험적 경향은 실험의 범위와 함께 쓰고,
경험적 scaling을 보편적 물리 법칙이나 일반적인 수학 정리로 바꾸어 말하지 않는다.

## 연구 결과물의 형식

연구 노트는 질문, 선행 근거, 가정, 제안, 유도, 검증, 해석, 한계, 후속 질문으로 구성한다.
대규모 실험만 연구 성과로 인정하지 않고 정확한 정리·반례·수치해법·모델의 실패 분석도 다룬다.
단, 학습 과제를 완료했다는 상태와 새로운 기여를 입증했다는 상태는 별도로 관리한다.

## 문헌과 새 연구의 반영

[근거 자료](sources.md)를 시작점으로 사용하고 단원별로 직접 읽은 원문을 추가한다.
논문 제목·저자·공개/출판 정보·확인 버전·검증 날짜와 어떤 정의·주장·실험을 참고했는지 기록한다.
초록만 확인한 경우 범위와 주제 연결만 기록하고, 증명·수치·재현을 검토한 것으로 표시하지 않는다.

새 연구가 추가되면 필요한 새 개념과 선수 절을 지식 지도에 추가한다. 이견·수정·반례가 있으면
기존 단원의 버전과 주장 범위를 갱신하고 재학습이 필요한 부분을 표시한다. 연구의 발전 때문에
전체 교재를 특정 시점에 영구 완성된 것으로 선언하지 않는다.

## 학습 경로와 진도

주차·학기·전체 장 수는 진도 모델에 포함하지 않는다. 의미 기반 단원 ID와 버전, 선택한 경로,
성취 항목을 저장한다. 전체 정독 경로는 모든 등록 영역을 탐색하고 확장 단원도 이어 공부한다.
목적별 경로는 관련 단원과 필요한 선수 절의 집합으로 구성한다.

계속 커지는 전체 색인으로 고정된 완수율을 계산하지 않는다. 선택한 경로의 특정 버전에서
어떤 설명·유도·검산·재현을 완료했는지 보여 준다. 학습자에게 접근 가능한 전문 영역을
제한하지 않고 목적별로 진입점을 제공한다.

## 공개 전 확인

1. 해당 단원의 범위·선수 관계와 정의·가정·증명·반례·단위 검토.
2. 수식·미분·확률·기준 수치와 코드·시각화의 일치 검토.
3. 물리 모델에서는 보존·경계·무차원화·관측·수렴을 확인.
4. 연구 연결에서는 논문 버전·재현 범위·새 주장·증거의 일치 검토.
5. 한·영 본문·문항·해설, 키보드·모바일·모션 감소·정적 대체 보기 확인.
6. 미집필·집필·검토·실행 검증·공개 상태와 자료의 실제 준비 상태 확인.
