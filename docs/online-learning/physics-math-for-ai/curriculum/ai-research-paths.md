# AI 동작 원리와 연구 목적별 학습 경로

이 문서는 수학·물리에서 AI로 가는 순방향 학습과, 모델·논문에서 필요한 개념을 되짚는
역방향 학습을 함께 제공한다. 기간·학기·분량 제한을 두지 않는다. 아래 경로는 시작점이며
새 구조나 연구 문제를 다룰 때 필요한 선수 단원을 추가한다.

## AI의 개념에서 동작까지

모델을 공부할 때 공통으로 데이터·표현·함수·목적·최적화·추론·평가·계산 비용을 확인한다.
학습 목표를 식으로 쓰고 작은 예제의 실제 연산을 따라간 뒤, 새로운 가정과 연구 문제로 확장한다.

| 모델·동작 | 필요한 수학 | 물리와의 관련 범위 | 단원에서 확인할 결과 |

| diffusion·score·flow matching | 확률과정·SDE/ODE·score·연속방정식·수송 | 확산·비평형과 연결되는 수학 및 가정 | 전방·역방향·샘플링·수치 오차와 목적을 비교 |

| 강화학습·의사결정 | MDP/POMDP·Bellman·확률·제어·게임·추정 | 로봇에서는 역학·관측·접촉 추가 | 정책·가치·탐색·off-policy·안정성을 분리 |

| 로봇·3D·world model | 기하·확률 추정·상태·제어·최적화 | 강체·접촉·센서·광학·역학 | 좌표·관측·행동·예측의 폐루프 검증 |
| reasoning·symbolic·program synthesis | 논리·형식언어·조합 최적화·복잡도 | 해당 과학 문제에서 물리 제약 추가 | 생성된 주장·프로그램을 실제 검증과 구분 |
| 모델 압축·효율·하드웨어 | 저랭크·양자화 오차·알고리즘·통신 복잡도 | 소자·열·회로·실측 에너지 | 파라미터 수·연산량·지연·메모리·에너지를 따로 평가 |
| 해석·정렬·신뢰성 | 인과·통계·정보·게임·제약·강건성 | 물리 시스템 적용 시 안전 제약 추가 | 목표·관측·개입·선호·보장의 조건을 구분 |

표는 집필 범위와 성취 목표다. 특정 이론이 모든 모델을 완전히 설명한다는 주장이나
한 연구 논문의 결과를 다른 데이터·모델에 그대로 적용한다는 뜻이 아니다.

## 전체 정독 경로

전체 범위를 공부하려면 [지식 지도](knowledge-map.json)의 영역을 다음 큰 흐름으로 연결한다.
각 흐름은 많은 장·절로 확장하며 완료 기한을 두지 않는다.

1. 수·함수·논리·증명·이산 구조를 익히며 벡터와 작은 확률 예제를 병행한다.
2. 선형대수·해석·미적분에서 행렬·텐서·복소·함수 공간·기하·군으로 확장한다.
3. 확률·측도·통계·Bayes·정보·고차원 현상·그래프 모델·부호를 연결한다.
4. 최적화·수치계산·미분방정식·확률과정·제어·학습 이론·인과·게임을 연결한다.
5. 물리 모델링과 역학에서 해석역학·파동·전자기·연속체·열·통계·비평형으로 확장한다.
6. 양자·다체·장이론·다중스케일·상대론·물질·물리 계산의 연구별 선수 단원을 학습한다.
7. AI 동작 분석과 역문제·연구 방법으로 돌아가 이론·재현·새 가설·새 모델을 검증한다.

연구 방법과 작은 모델 분석은 첫 영역부터 병행한다. 모든 물리·수학을 끝낼 때까지
AI 모델을 보지 못하게 만들지 않는다. 전체 정독과 목적별 왕복 학습을 모두 지원한다.

## 목적별 경로

### AI 개념과 신경망의 동작

수·함수 → 벡터·행렬 → 미분·chain rule → 확률·우도·정보 → 수치계산·AD → 최적화 →
회귀·MLP·정규화·일반화. 결과물은 한 모델의 입력부터 gradient·갱신까지 직접 유도한 원고와 검산이다.

### Transformer와 언어·다중모달 모델 연구

선형대수·tensor → matrix calculus·AD → 조건부 확률·정보·추정 → 최적화·학습 이론 →
시퀀스·상태·위치·대칭 → 복잡도·메모리·저랭크·양자화 → 모델 동작과 추론 연구.
결과물은 작은 attention 계산의 재현, 연산·목적의 변화 가설, 공정한 평가·반례다.
출발 논문은 [Attention Is All You Need](https://arxiv.org/abs/1706.03762)다.

### 생성·diffusion·flow 연구

확률·변수변환 → Bayes·변분·정보 → ODE·SDE·score → 연속방정식·수송·수치해석 →
확산·비평형·sampling → 조건부 생성·역문제. 생성 경로·학습 목적·수치해법을 각각 비교한다.
[Score SDE](https://arxiv.org/abs/2011.13456)와
[Flow Matching](https://arxiv.org/abs/2210.02747)을 별도의 정식화로 읽고 조건·목적을 대조한다.

### AI의 학습·표현·일반화 이론

증명·해석 → 선형대수·함수 공간·커널 → 확률·통계·고차원 → 볼록·확률·비볼록 최적화 →
학습 이론·정보·인과. 결과물은 가정이 명확한 정리·증명·반례와 그 범위를 확인하는 실험이다.
필요에 따라 무작위 행렬·통계물리·변분·기하로 확장한다.

### 에너지·대칭·기하를 사용하는 새 모델

벡터·미분 → 기하·군·함수 공간 → 역학·작용·보존 → 통계역학·분배함수 →
equivariance·energy model·구조 보존. 결과물은 변환 법칙·보존량·목적과 모델의 일치 검증이다.
[Geometric Deep Learning](https://arxiv.org/abs/2104.13478)을 대칭·모델 연결의 연구 독해 자료로 사용한다.

### 로봇·제어·강화학습·에이전트 연구

상태·확률·추정 → ODE·역학·관측 → 제어·최적제어·계획 → RL·게임·인과 →
폐루프 검증·분포 이동·상호작용 연구. 에이전트의 검색·도구 선택·기억·보상을 각각 정식화한다.
고정 도구 호출 데모를 자율성·추론·성능의 증거로 대체하지 않는다.

### Scientific AI·역문제·새 물리 모델 발견

물리 모델·단위 → 해당 방정식·함수 공간 → 수치 시뮬레이션·AD → 관측·통계·식별 →
역문제·실험 설계 → 물리 제약·operator·미분 가능한 모델.
[Physics Informed Deep Learning](https://arxiv.org/abs/1711.10561),
[Fourier Neural Operator](https://arxiv.org/abs/2010.08895),
[Neural ODE](https://arxiv.org/abs/1806.07366)를 다른 문제·가정·해법으로 비교한다.

### 양자·재료·물리 계산 연구

복소·선형대수·확률·함수 공간 → 양자·측정·얽힘 → 다체·통계·tensor network →
재료·소자·제어·물리 계산. 고전 모델과 양자 모델의 데이터·접근 가정·비용을 같은 조건에서 비교한다.
물리적 하한을 실제 AI 시스템의 연산당 에너지로 바로 치환하지 않는다.

## 과학 분야별 추가 학습

특정 연구의 대상 법칙과 관측 과정은 독립적인 장으로 계속 확장한다.

| 연구 대상 | 연결할 추가 물리·수학 | 연구 검증의 초점 |
| --- | --- | --- |
| 분자·화학·단백질 | 양자화학, 분자역학·동역학, 통계역학, 대칭 | 상태·힘·에너지·대칭, 데이터 생성 조건 |
| 재료·고체·소자 | 결정·band·phonon·구성 관계·다중스케일 | 물성·구조·스케일·경계·측정의 일치 |
| 유체·날씨·기후 | 유체·수송·회전계·열·복사·확률·동화 | 보존·해상도·긴 시간 안정성·불확실성 |
| 영상·음향·의료 센서 | 파동·광학·전자기·역문제·검출 통계 | 관측 모형·노이즈·재구성 오차·범위 |
| 천체·중력·우주 | 상대론·중력·통계 추론·관측 기하 | 물리 불변량·관측 선택·모델 식별 |
| 플라스마·핵·고에너지 | 운동론·전자기·양자·장·검출기 모형 | 유효 범위·보존·이벤트·추론의 불확실성 |
| 생체·복잡계 | 확률과정·반응확산·네트워크·비평형 | 식별·모형 불일치·반사실·시간 스케일 |

## 새로운 연구로 넘어가는 과제

- 모델의 특정 가정을 바꾸고 기존 증명·유도·평가에서 무엇이 유지되는지 확인한다.
- 대칭·보존·차원·확률 구조를 만족하도록 새로운 표현·목적·갱신·샘플러를 제안한다.
- 두 설명이 같은 관측을 만드는 반례를 만들고, 구분할 추가 실험을 설계한다.
- 이론적 예측을 수치해·작은 학습 실험·공정한 기준선으로 비교한다.
- 실패·부정적 결과와 유효 범위를 기록하고 재현 자료와 함께 연구 원고로 정리한다.

이 과제는 이미 새로운 연구 성과를 얻었다는 뜻이 아니다. 가설을 연구 결과로 바꾸기 위해
[증명·실험·근거 기준](authoring-and-research.md)을 충족하는 학습 과제다.
