# 유한계 그림 가독성과 열역학 초기 점검

2026-11-07. 유한계 세 단원의 개념/실습 SVG 글씨가 좁은 읽기 열에 맞춰 작아지던 문제를 수정했다. 열접촉·이상기체의 한영 본문4개도 읽고 가정·단위·부호와 대표 계산을 대조했다. 교재533단원·1,599안내,원래290/362주제 입문 검증·72미완료는 그대로다. 전체 교육과정과 연구 깊이는 미완료다.

## 그림과 실제 화면

`finite-size-view.tsx`의 네 그림 유형에 `DiagramViewport`를 적용했다. SVG 내부 폭을 최소560px로 유지하여12단위 축 글씨가 축소되지 않게 한다. 그림 영역은 이름·설명·초점 표시가 있는 region이며 터치와 기본 방향키로 이동한다. 설명문과 범례는 스크롤 영역 밖에 남는다. 색·모션·그림 좌표·계산값·선택 상태를 바꾸지 않았다. 넓은 화면에서는 가용 폭에 따라 늘어나 전체 그림이 보인다.

`scripts/check-finite-size-diagram-readability.ts`는 실제 정적 교재에서 한영×명암×320/1440px×세 단원24경우를 검사했다. 112개 렌더링된 그림의 글씨를 `computed font-size × rendered SVG width / viewBox width`로 측정했고 최소12.00CSSpx였다. 모바일12경우에서 방향키로 양 끝까지 이동하고 터치 스와이프를 확인했다. 넓은12경우는 그림이 들어오므로 스크롤을 강요하지 않는다. 24경우의 설명문 위치·문서 넘침·영어 한글 누출과 페이지 접근성24상태도 통과했다. 페이지 오류는0개다. 자동 접근성 검사만으로 모든 상태를 보증하지는 않는다. 이 개선의 범위는 유한계 전용 그림이며 다른 단원 전체의 그림 글씨를 개선했다고 주장하지 않는다.

초기 검사에서는 넓은 화면에도 이동을 기대해 대기 시간이 만료됐다. 실제 폭570px에 그림이 들어오는 것을 확인하고, 좁은 화면의 이동과 넓은 화면의 전체 표시를 따로 검사했다. 최종 기록이 위 수치의 근거이며 초기 부분 실행을 합산하지 않았다.

## 두 단원 본문과 독립 계산

열접촉의 두 본문에서 계 전체의 단열·일/질량 이동 없음, 일정 양의 열용량,절대온도와 연결 계수의 단위를 대조했다. 에너지 변화는 ±Q,합친 엔트로피 생성은 비음수이며 연결이 끊어진 경우와 열평형을 구별한다. 그림 설명을 실제 온도·에너지·엔트로피·전달률·생성률·온도차 곡선과 선택 점에 맞췄다. 구현하지 않은 온도 막대·흐름 화살표를 설명하는 문장을 제거했다.

이상기체의 두 본문은 닫힌 단원자 이상기체,기체가 한 일을 양수로 두는 ΔU=Q−W,준정적 체적 제어와 가역 열 교환의 다른 조건을 검토했다. 실제 p–V 경로와 진행률 축에 맞게 영어의 ‘예정’ 표현을 수정했다. 한국어 해당 문단은 이미 현재 구현을 설명하여 변경하지 않았다.

`.runtime/learning/thermodynamics-domain-audit-stage1/`의 모델 호출과 독립 Python Decimal100자리 재계산에서 열접촉7사례·이상기체6사례·116값을 대조했다. 열접촉은 온도 역전,허용 범위 안 열용량1/1.5와2/3 비교,연결 계수 배율,연결 없음,같은 초기 온도,3→8초 구간을 포함한다. 평형 온도·끝 온도·구간 열/내부 에너지·엔트로피와 순간 전달률을 확인했다. 기체는 정방향/역방향,정확히 같은 엔트로피 끝점,거의 상쇄되는 양의 열,같은 부피/온도를 포함하여 양 경로의 ΔU·W·Q·ΔS·압력을 비교했다. 기존 수치 코드를 참조 계산으로 가져오지 않고 선언한 상태식과100자리 지수/로그로 계산했다. 이13사례는 모든 입력의 정확성을 증명하지 않는다.

실제 한영 본문4페이지에서 예정 표현이 사라지고 학습 그림이 렌더링되는 것도 확인했다. 행렬의 본문·가정·선택한 독립 계산 검토는2/32단원이다. 두 단원의 전체 프리셋/제어/교수 흐름·선수 연결과 다른30단원의 종합 검토는 계속 남는다.

## 검사·보존·후속 작업

관련22개 시각화/실습/등록 검사와2개 본문 검사,실제 루트 빌드,빌드 후 타입 검사,정적 HTML1,771개의 링크·자산·fragment·canonical·사이트맵 검증이 통과했다. 직전 [통합 검증](finite-size-integration-verification.md)의 전체8,396테스트 기록은 보존하며 이번에 전체 테스트를 다시 실행한 것으로 표시하지 않는다.

이전4,296소스 중4,292개를 바이트 보존했다. 그림 컴포넌트1개·본문3개를 변경하고 브라우저 검사1개를 추가하여 현재4,297소스다. 계산 worker의 파일명과 SHA256도 직전 통합과 같다. `.runtime/learning/finite-size-readable-diagrams`의 `verification.json`,검사 로그,`browser-verification.json`,`worker-preservation.json`,모바일 PNG와 소스/출력 해시가 근거다. commit·push·공개 배포는 수행하지 않았고 사용자4175미리보기는 유지한다.

다음은 [열역학 종합 점검](thermodynamics-domain-audit-plan.md)의 첫 두 단원 제어/교수 흐름과 나머지 법칙·자유에너지·통계역학 단원을 순서대로 대조하는 작업이다. [점검 행렬](thermodynamics-domain-audit-matrix.json)에서 완료한 확인 항목만 갱신하고 영역 전체 완료를 유보한다. 이후 비평형 등 남은 영역과 연구 심화로 진행한다.
