# 양자 변분 원리: 실제 교재 통합

2026-11-09. 원주제 `variational principle`의 두 단원과 한영 원고 네 개를 등록했다. 총 **566개 한영 단원·1,698개 안내 실험**, 원래 입문 원주제 **308/362개 검증·54개 미완료**다. 이는 이 주제의 입문 검증이며 전체 51영역·509주제, 영역 감사와 연구 깊이의 완료는 아니다.

## 연결한 내용

- `finite-state-rayleigh-energy-variance`: 상태의 에너지·분산·잔차, 방향 미분, 축퇴 바닥 공간과 gap 조건, 영분산 들뜬 상태와 영벡터 경로 반례.
- `nonorthogonal-ritz-subspace-certificates`: 겹치는 기저의 Gram metric, 실제 포함 공간의 최소 에너지, 좌표 변경, Ritz 정류와 전체 고유상태의 차이, 내부/바깥 잔차.
- 각 언어·단원마다 14개 절·표시 수식 12개·해설 연습 6개. 고정 개념 비교, 예측 문제, 16개 자유 실험 예제, 안내 실험 3개와 해설 퀴즈 3개를 제공한다.
- 개별 정수/전체 JSON 입력, 원자적 차원 변경, 저장 복원, Worker 취소·교체·오류 후 재시도. 같은 유효 입력으로 초기화할 때도 잘못된 편집 초안을 지운다.
- 실수 3차원 사례의 Three.js 공간 그림과 두 직교 투영, 일반 복소 사례의 전체 성분 그림·행렬·정확/구간 인증. 가역 좌표 변경과 카메라 조작을 물리 상태 변화로 표현하지 않는다.

진입은 **도서 → Interactive Book**이며 목차·검색·선수 단원·이전/다음·breadcrumb를 연결했다. Online Book 목록은 기존 도서 모음으로 유지한다. 기존 564개 단원·안내 내용과 51영역의 내용·상대 순서는 등록 직전 SHA-256 기준으로 보존했다.

첫 정적 빌드 뒤 최종 스크린샷 검토에서 모바일 3D 축 라벨이 잘리는 문제를 발견했다. 화면 aspect와 전체 축/라벨의 경계를 이용해 카메라 거리를 보정하고 깊이 범위도 맞췄다. 물리 상태·에너지·잔차 계산은 바꾸지 않았다. 관련 39개 검사에 portrait frustum 조건을 추가하고, 정적 재빌드 및 실제 3D/reader 검사를 다시 통과했다. 최종 모바일 스크린샷에서 축 이름이 모두 들어오는 것도 확인했다.

이전 전역 검사와 마지막 카메라 보정의 범위를 구별하기 위해 재빌드 전후 HTML의 script/style 외 구조·내용과 Worker 바이트를 비교했다. 1,804페이지의 구조·내용과 Worker SHA-256이 같았고, 새 factory의 classic 모드도 확인했다. 동일 Worker 바이트의 97개 수치 검산이나 전체 회귀를 다시 수행했다고 중복 기록하지 않으며, 영향받은 공간·실제 reader·생산 자산의 후속 검증을 별도로 남겼다.

근거: `.runtime/learning/quantum-variational-integration/verification.json`, 각 검사 로그·JSON·스크린샷, `export-hashes.json`, `source-and-evidence-hashes.json`. 원고의 수학적 가정·정밀도·독립 기준은 앞의 원고/수치 모델/Worker 기록을 유지한다. 읽기 그래프 2,441개 모듈에서 Rayleigh·Ritz·공용 근 분리 엔진이 제외됨을 확인했다.
