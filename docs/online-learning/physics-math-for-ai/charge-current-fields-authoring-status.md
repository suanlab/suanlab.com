## 수치·시각화의 의미

점전하 장은 삼차원 Coulomb 커널의 평면 단면이다. 원천별 벡터 합은 공통 선형 표시 배율을 쓰고, 공간 화살표는 별도로 길이를 압축한다. 실제 물리량은 원래 단위로 표에 남긴다. 같은 부호의 장 상쇄와 반대 부호의 전위 상쇄, 시험 전하0과 원천 충돌을 구분한다.

단면 곡선은0.05 m 표본을 사용한다. y=0에서는 원천 주변±0.0125 m를 **그림에서만** 제외하며 원천을 가로질러 선분을 잇지 않는다. 관측점 계산은 원래 거리 법칙을 유지한다. 매우 큰/작은 유한 세로값은 명시한 표시 배율로 그리며 원래 값은 표에 유지한다. SI 변환이나 원천 위치 구성이 숫자 범위를 벗어나면 입력을0이나 충돌로 바꾸지 않고 관측을 미정으로 표시한다.

전하 수송은 고정 폭·단면적의 지정 Gaussian이다. 밀도와 전류 밀도, 흐름 단면적과 독립 패치 면적, 순간 순유입과 시간 적분을 분리한다. 제어 구간의 바깥 법선은 고정되어 있으며 독립 패치의 법선 회전과 혼동하지 않는다. 작은 양의 질량·underflow·원래 적분 잔차를 유지한다. 국소 미분 일치는 해석 항등식이며 구적 차이는 오차 인증이 아니다. 두 누적 계산의 범례도 실제 표시에 맞게 ‘점’으로 표시한다. 자기 일관된 Maxwell 해를 계산했다고 주장하지 않는다.

## 실제 검증 근거

- 전용46개·전체3,859개 테스트, 타입 검사·lint·콘텐츠 검사(1,696 URL), 정적 빌드(1,704 페이지)와 출력 검사(1,699 HTML)가 실제 종료 코드0으로 통과했다.
- 같은 소스2,908개·출력4,139개 파일의 해시를 고정했다. 교육과정 메타데이터 갱신 뒤에도 소스와 출력이 같은지 대조한다.
- 한영 × 320/1,440px × 명암의 모든8조합에서16개 기본 화면을 검사했다. 개념64단계 클릭, 안내48개 펼침, 예제50회 적용과 단원/언어별4개 전체 조작 그룹을 확인했다. 입력 정밀 저장·새로고침·오답/정답·완료 저장·초기화를 포함한다.
- 큰 유한 값, SI 변환·원천 위치 underflow, 작은 구간 질량 등12개 추가 한영 상태를 검사했다. 축·경로의 유한성, 레이블 범위, 화면 넘침, WCAG axe와 언어를 확인했다.
- 기본 화면에서 그림60건·표20건의 모바일 키보드 스크롤을 확인했다. 별도 원본 캡처의 그림60건과 중복 합산하지 않는다.
- 영어 전체546경로·604상태에서 잔존 한글이 없었다. 기존 원문 게시글의 명시된 원어 표시는 검사 정책에 따른다.
- 원본 SVG 갤러리8개·그림60개와 대표 안내 화면4개를 실제로 열어 한영·명암의 가독성과 과학적 의미를 검토했다. 최종 원본 갤러리는 직접 검토한 캡처와 바이트 동일함을 확인했고, 바뀐 안내4개와 수정 범례 화면은 다시 열어 확인했다. 자동 검사나 이미지 해시만으로 직접 검토를 대신하지 않았다.

근거는 `.runtime/learning/charge-current-fields-integrated-verification.json`과 `charge-current-fields-homepage/`의 브라우저·원본·언어·수동 검토·해시 보고서에 연결한다. 위 수치 검증은 [기반 집필 기록](charge-current-fields-foundation.md)의 독립 NumPy/SciPy 기준도 포함한다.
