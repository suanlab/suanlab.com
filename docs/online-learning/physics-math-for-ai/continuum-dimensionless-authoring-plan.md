## Peclet 수·경계층·닮음 변환

예정 ID: `advection-diffusion-peclet-boundary-layer`.

상수 U,양의 D,L을 가진0≤x≤L의 정지 식 U c_x=D c_xx와 양 끝 농도 cL,cR을 직접 푼다.ξ=x/L,Pe=UL/D에서 c=cL+(cR−cL)expm1(Pe ξ)/expm1(Pe)를 얻고 U=0에는 선형 한계를 별도로 제공한다. 농도 대비0에서도 물리 농도·플럭스는 계산되지만 대비로 정규화한 형상은 미정이다. 부호 있는 Pe와 크기로 비교하는 이류/확산 시간 비를 구분한다.

큰 양/음 Pe에서는 원천 지수를 직접 계산하지 않고 유동 하류의 경계층과 안정적인 두 경계 가중치를 계산한다. 경계·기울기·곡률·상수 전체 플럭스를 독립 미분으로 검증하고 농도 양끝의 작은 차이·U=0·지수 넘침·꼬리 로그를 확인한다. 같은 Pe와 경계 정규화 형상이라도 길이·시간·물리 플럭스가 같지는 않음을 닮음 변환으로 보여준다. 물리 Pe와 수치 격자 Pe_h=|U|h/(2D)는 서로 다른 관측이다.

## Damkohler 수·반응 침투·유한 판 수지

예정 ID: `reaction-diffusion-damkohler-penetration`.

반두께 L의 평판에서 D c_xx−k c=0,c(0)=c0,c_x(L)=0의 해를 직접 유도한다. D,L은 양수,k≥0,c0≥0,실제 단면적A를 사용한다. Da=kL²/D,φ=√Da에서 c/c0=cosh(φ(1−ξ))/coshφ이며,k=0의 균일장과 c0=0의 영 물리장·미정 정규화 형상을 구분한다.

실제 입구 확산 유입 A j(0)이 전체 소모 A∫k c dx와 같은지 독립 구적으로 검사한다. 효과도 tanhφ/φ와 침투 길이√(D/k)를 구분하고,k=0에는 침투 길이의 유한값을 만들지 않는다. 큰 Da의 cosh 넘침·닫힌 끝의 비영 꼬리·작은 Da의 비영 농도 감소를 안정적으로 계산한다. 표면 농도를 Dirichlet로 지정한 모델이므로 외부 물질전달 저항·열 방출을 함께 해결했다고 해석하지 않는다.

## 원고·시각화·독립 검증

두 원고에 무차원화와 단위 변환의 차이,특성척도 선택,Re·Ma·Fr·Pr·Sc·Pe·Da·Wi의 적용 항과 가정,실제0속도에서의 잘못된 이류 시간 사용을 상세하게 설명한다. 다룬 특수 가족·관측 창·기준 농도·경계조건을 선언하고 일반대학원생을 위한 직관·유도·손계산·풀이6개씩을 작성한다.

각 실습은 고정 개념4단계·안내3개·퀴즈2개, 물리 좌표/무차원 좌표의 대응,같은 수를 보존하는 계수 변환과 실제 플럭스 수지를 제공한다. 독립 고정밀 미분·실제 적분·작은/큰 매개변수·닮음 변환을 검사하고 기존 테마의 한영·명암·접근성·정밀 입력·그림 검증 뒤에만 주제 입문 검증 수를 올린다. 진입은 도서 → Interactive Book을 유지한다.
