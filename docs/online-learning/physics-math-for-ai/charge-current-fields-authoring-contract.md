# 전하·전류·장: 다음 두 단원의 집필 명세

이 문서는 첫 두 단원의 집필 명세다. [확인한 자료와 독립 탐색](charge-current-fields-source-audit.md)을 바탕으로 [순수 계산 모델·상세 한영 원고](charge-current-fields-foundation.md)를 작성·검증했다. 이후 [홈페이지 등록·그림·조작·안내·퀴즈 검증](charge-current-fields-authoring-status.md)도 마쳤다. 아래는 구현을 이끈 집필 명세와 보존 기준이다.

## 1. 전하 중첩과 시험 전하

후보 ID: `charge-superposition-test-field`.

**학습 질문:** 같은 위치의 장은 시험 전하를 바꾸어도 같은데, 힘은 왜 달라질까? 양·음 원천의 효과를 숫자로 더하는 것과 벡터로 더하는 것은 어떻게 다를까?

원고는 전하의 부호와 단위 → 원천과 관측점 → 단일 점전하의 방향·거리 법칙 → 벡터 중첩 → 시험 전하의 힘 → 상쇄와 특이점 순으로 구성한다. 두 동일 부호 전하의 중점, 반대 부호 쌍의 중점, 멀리 떨어진 관측점을 계산 예제로 사용한다. 시험 전하가 원천 배치를 교란하지 않는 근사를 설명한다.

평면 배치에도 **3차원 Coulomb 커널**을 사용한다. 각 원천에서 관측점까지의 변위 벡터를 만든 뒤 `q r / |r|³`를 합한다. 그림의 화살표 길이 압축은 표시에서만 적용하며 관측 표에는 원래 성분·크기·단위를 유지한다. 비영 점전하의 위치에서는 장이 정의되지 않으므로 작은 거리로 대체하지 않는다. 장선은 입자 궤적이 아니며, 스칼라 퍼텐셜과 벡터 장도 구분한다.

**조작과 관측:** 원천 부호·크기·배치, 관측점, 시험 전하를 조작한다. 개별 기여와 합 벡터, 거리별 크기, 장과 힘의 성분 표를 연결한다. 시험 전하 0에서도 장은 유지되고 힘은 0인 예제를 포함한다. 특이점·상쇄·영원천·범위 초과를 의미에 따라 구분한다.

**독립 검증:** 이미 준비한 40조건의 퍼텐셜 5점 미분 외에 해석 가능한 대칭, 부호 반전, 회전·이동 공변성, 거리 스케일, 정확한 원천 충돌을 검증한다. 제품 함수로 기대값을 만들지 않는다.

## 2. 연속 방정식과 면을 통과하는 전류

후보 ID: `charge-continuity-surface-current`.

**학습 질문:** 오른쪽으로 움직이는 음전하의 전류는 어느 방향일까? 오른쪽 경계로 전하가 나가는 동안 구간 안의 총전하는 어떻게 변할까?

원고는 부호 있는 밀도 → 운반 속도와 `J=ρv` → 법선이 있는 면의 흐름 → 두 경계의 순유입 → 고정 구간 총전하 → 국소 보존 순으로 구성한다. 양전하·음전하, 좌·우 이동과 정지 예제를 나란히 비교한다. 입자 이동 방향과 관습적인 전류 방향의 차이를 설명한다.

고정 단면적의 1차원 Gaussian 전하 분포가 일정 속도로 이동하는 준비를 사용한다. 총전하는 CDF 차이와 원래 총전하의 곱이며, 시간 변화율은 `면적 × [J(왼쪽)−J(오른쪽)]`이다. 원천항 없는 수송의 예제이며 자기 일관된 Maxwell 해라는 주장은 하지 않는다.

**조작과 관측:** 총전하·폭·속도·시간·두 경계·단면적을 조작한다. 밀도와 전류 분포, 구간 총전하의 시간 곡선, 경계별 전류와 순유입, 적분/국소 잔차를 연결한다. 법선 반전은 같은 물리적 흐름의 보고 부호를 바꾼다. 면적 변화 시 고정 총전하를 유지하는 정규화도 설명한다.

**독립 검증:** 준비한 28조건의 구적·시간 미분에 정지·영전하·좁은 구간·큰 이동·부호 반전·단면적 스케일 사례를 보완한다. CDF 꼬리의 상쇄와 적분 잔차를 다루고 수치 일치 자체를 일반적인 엄밀 보증으로 부르지 않는다.

## 홈페이지 연결 순서

두 순수 계산 모델과 독립 기준 → 상세 한영 원고 → 기존 테마의 그림·표·연속 조작 → 단원별 개념 4단계·안내 실험 3개·풀이 퀴즈 → 실제 한영·명암·모바일/데스크톱 검사 순으로 진행한다. 등록 전에 기존 460개 단원의 보존 기준을 고정한다. 계산이나 설계만 있는 상태를 집필·화면 검증 완료로 세지 않는다.

기존 등록 원본과의 일치를 확인한 뒤 `.runtime/learning/pre-electromagnetism-registry-hashes.json`에 460개 단원·안내 데이터와 41개 실험 그룹의 451개 항목을 고정했다. 다음 구현에서 이 보존 기준을 `scripts/fixtures/`에 그대로 옮겨 사용한다. 새 단원을 등록한 뒤 기대 해시를 다시 만드는 방식으로 기존 내용 변경을 숨기지 않는다.

계산은 새 `src/lib/learning-charge-current-fields.ts`와 별도 실험 어댑터에 둔다. 전자기학 단원을 기존 파동 18개를 정의하는 `wavesKinds`에 덧붙이지 않는다. 별도 전자기학 분류를 만들고 `foundations-lab.tsx`, `concept-walkthrough.tsx`, 단원·안내 등록과 교육과정 coverage를 명시적으로 연결한다. 기존 파동 분류와 등록 460개 단원의 내용은 보존한다. 실제 구현 파일명과 분류 연결은 집필 단계에서 확정한다.
