# 비평형 첫 주제: master equation 사전 집필

2026-11-08 현재 연결 상태: [세 단원 교재 연결과 검증](master-equation-authoring-status.md)으로 이어졌다. 도서 → Interactive Book에 등록했고 전체 읽기 검증을 마쳤다. 아래는 이전 사전 집필 기록이다.

2026-11-07. 기존 열역학의 남은 검증·수정안 적용 순서를 유지하면서 다음 영역의 첫 단원을 준비했다. 현재 도서 등록·홈페이지 반영·주제 완료를 뜻하지 않는다. 비평형 원래10주제와 후속 영역·연구 심화의 전체 범위는 유지한다.

## 준비한 첫 단원

`two-state-continuous-time-generator-euler`의 한영 본문과 계산 원형을 작성했다. 전이율·확률·생성자·물리적 시간의 단위부터 정확한 연속시간 법칙, 대기시간과 복귀, 순간 흐름과 구간 수지, Euler의 보존·양수성·선형 안정성, 영 전이율·흡수·정상 가족과 식별 한계까지 다룬다. 두 언어에 해설 문제6개씩과 조작 설계 표를 넣었다. Levin–Peres2판20.1절의 생성자·Poisson 시계를 확인하고 이 유한 모형을 직접 유도했다.

계산 원형은 정확 유리수 생성자·Euler 값과256bit 방향성 지수 구간을 사용한다. 전이율0..5/s, 물리적 구간0..10s, Euler1..128단계는 대화형 계산 범위이며 이론이나 교육 분량의 제한이 아니다. 물리적 시간과 수치 해상도를 분리한다. 열저장고·열·일·엔트로피 생성은 이 모형에서 지정하지 않는다.

## 독립 근거

예정 준비16개·시간 기록360개를 직접 유리수 Euler 행렬 곱과 별도260자리 행렬 지수로 대조했다. 정확 관측량·점 구간2461개, 초월함수 구간2604개, 행렬 지수 비교784개와 분류192개가 일치했다. 근사 로그 표시의 전체 대조나 방향성 산술의 수학적 증명을 대신하는 기록은 아니다.

질량은 보존하지만 음수인 Euler 행렬, 수축하지만 확률 커널은 아닌 단계, 유효한 주기2 근사, 한 번에 잘못 평형화하는 근사, 정상 초기값이 잘못된 커널을 가리는 사례를 포함했다. 영 시간·영 전이율·흡수·아주 작은 양의 변화·반올림된 정상 점유 안의 비영 전류도 구별했다. 첫 참조 실행에서는 영 시간의 정확한 유리수 점을 고정밀 소수 뺄셈으로 비교해 잔차가 생겼다. 참조에서 해당 점을 정확한 분수로 처리했고 최종 대조가 통과했다. 수치 모델 오류로 기록하지 않는다.

실제 Markdown 로더에서 한영 본문 각각 목차14개·표시 수식11개·표2개·해설6개가 렌더링됐다. 잘못된 준비16개를 거부하고 원본 입력을 소유·동결하며16개 결과를 JSON/structured clone으로 전달할 수 있는 것도 확인했다.

## 이어갈 작업

첫 주제의 다음 두 가족인 Poisson uniformization과 상태별 체류율도 이제 [한영 본문·독립 계산 원형](nonequilibrium-uniformization-holding-preparation.md)을 준비했다. 잠재 사건과 실제 상태 변화, 시간 점유와 점프 횟수 점유를 구별한다. 세 가족 모두 대화형 교재 등록·검증은 남아 있다. 그다음 Fokker–Planck·확률 흐름·상세평형 위반·요동 소산·선형 응답·엔트로피 생성·확률열역학·동기화와 임계 동역학·축약과 유효 기술의 원래 주제로 이어간다.

현재 원형과 본문은 `.runtime/learning/nonequilibrium-master-equation-preparation/prepared/`에 있다. 엄격한 전달 규약·취소 가능한 worker·개념/안내/문제·교재 등록·실제 브라우저 검증은 남아 있다. 연결 전에 초안 표시와 예정 조작을 실제 구현에 맞추고, 기존 홈페이지의 색·글꼴·명암·모션 설정과 도서 → Interactive Book 진입을 유지해야 한다. Python은 내부 독립 계산에만 사용했으며 별도의 물리 Colab 과정을 추가하지 않았다.

근거는 같은 runtime 폴더의 `preliminary-review.json`, `independent-comparison.json`, `prepared-validation.json`이다. 전체 교육과정은 미완료이며 commit·push·공개 배포는 수행하지 않았다.
