## 원래 범위와 진행 단위

원래11개 주제의 각2단원을 순서대로 대조한다. 보존식, 연속체 가정, 응력·변형, Euler·Navier–Stokes, 확산, 반응수송, 구성방정식, 무차원 수, 다중물리, 난류·폐쇄, 보존형 이산화를 빠뜨리지 않는다.

1. 앞4단원의 한영 본문·단위·저장/경계 수지·연속체 가정을 읽고 실제 계산과 대조한다.
2. 응력·변형과 유동4단원에서 관측 방향·구성 가정·선형화·실제 외력·점성·초기 자료를 확인한다.
3. 확산·반응수송4단원에서 셀/유한 창 적분, 이동·원천·종별 수지와 작은 꼬리를 확인한다.
4. 구성식·무차원 수4단원에서 첫 주기와 정상 주기, 변형/응력 관례, 실제 시간·닮음·영비의 정의를 확인한다.
5. 다중물리·난류4단원에서 상호작용, 외력 일, 분산/필터 관례와 국소/전역 예산을 확인한다.

## 계산과 화면 근거

기존 개별 주제 보고서는 출발 근거로 보존한다. 현재 모델·독립 고정밀/유리수/공간·경계 적분과 직접 대조하고, 자체 잔차만으로 참조의 독립성을 주장하지 않는다. 입력별 의미, 실제 갱신/제조해의 구분, 가정 밖 조합의 상태와 나쁜 상쇄를 확인한다. 발견한 문제를 수정하면 영향을 받은 검사와 화면을 다시 검증한다.

전체22단원을 한영·명암·320px/데스크톱의8조합에서 순회한다. 총176기본 상태,704개념 단계,528안내 조합을 확인할 수 있는 범위를 준비하되, 실제 실행 기록과 종료 상태를 따로 남긴다. 예제401개와 입력234개의 연결은 모델 관측에 근거해 검증한다. 원본SVG의 단위·범례·불연속·정의 불가 구간·표시 스케일을 읽고 키보드·접근성·가로 넘침을 확인한다.

정적 출력의 모든 내부 링크·자산·조각·canonical과 전체 영어 표시 순회도 최종 소스에 대해 확인한다. 진입은 도서 → Interactive Book이며 기존 Online Book 분류를 유지한다.

## 완료 판정
