# 구속 연구 보강: 반력·변분·움직이는 경계

2026-11-12. Routh·Dirac 두 단원의 한영 원고 네 편을 보강·검증했다. 기존 본문·여섯 해설 문제·실습 입력을 보존한다. 전체 해석역학 연구 검토의 완료를 뜻하지 않는다.

## 추가 내용

- Routh 보충에서는 표준 비홀로노믹 입자의 단위를 복원하고 Lagrange–d'Alembert 반력을 유도한다. 에너지 보존과 개별 순환 운동량 보존의 차이, Frobenius 비적분성, 정확한 해·경로 의존 높이를 설명한다. Vakonomic 승수와 반력 승수의 단위·방정식·구간의 양립 불가능성을 구분한다.
- Dirac 보충에서는 움직이는 원의 위치·운동량 제약과 명시적 시간 미분을 유도한다. 순간 Casimir 조건만으로는 빠지는 affine 보정, 정확한 Newton 반력·일률·각도 복원과 고정 원 극한/붕괴 경계를 다룬다.
- 한영 SVG 네 개·비교표·실행 Python·각 세 연구 질문을 추가한다. 새 3차원 경로와 반지름 일정은 보충 예제이며 기존 기본 실습의 조작 기능으로 표시하지 않는다.

## 계산·원고 검증

`python3 scripts/learning/verify-constraint-research.py`는 **정확분수 반력 405상태·vakonomic 순간 비교 1,215개·허용 폐경로 48개**, 해석적 입자 해의 유한차분 **405상태**를 확인했다. 움직이는 원은 **정확분수 972상태·복원 경로 420상태·붕괴 거부 12개**를 대조했다. 일반 Rddot가 있는 순간 상태와 일정 반지름 속도 경로의 검증 범위를 구분한다. 순간 비교를 vakonomic 궤적 전체를 풀었다는 뜻으로 사용하지 않는다.

한영 표시 수식은 단원당 8개로 일치하고 Python 셀 네 개의 출력이 본문 표와 일치했다. 선택 **21파일·380검사**, 원고/보존 집중 **12검사**가 통과했다. 전체 저장소 테스트나 전체 CI 성공으로 집계하지 않는다.

원래 네 원고 바이트와 이전 검토 항목 669개를 보존했다. 새 네 편만 정확한 해시로 검토 항목에 추가하여 673개다. 등록은 650단원·1,969안내 그대로다.
