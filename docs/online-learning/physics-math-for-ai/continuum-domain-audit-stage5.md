## 설명과 물리 가정

한영 원고의 모든 절·유도·손계산·각6개 풀이를 읽고 모델·안내·선수 흐름과 대조했다. 내부 기억과 반응·확산 시간에서 상호 결합으로, 점성 유동에서 평균 연산과 공간 필터로 이어지는 연결을 확인했다. 고정 개념16단계·안내12개의 예측·실행·설명도 실제 관측과 맞췄다.

열탄성의 이차 가용 에너지는 전체 내부 에너지·누적 열량과 다르다. 전도가 없어도 두 부분의 교환은 남고, 일방향 모델에는 같은 닫힌 상호 수지를 그대로 적용하지 않는다. [Kelly의 열탄성 자료](https://pkel015.connect.amazon.auckland.ac.nz/SolidMechanicsBooks/Part_IV/Chapter_2_Applications/PDF/02_Thermomech_Applications_02_Thermoelasticity.pdf)의 일정 변형/응력 열용량과 역결합을 확인하고 선언한 일차원 모드로 특수화했다. 열전은 [COMSOL의 구성식 설명](https://doc.comsol.com/6.3/doc/com.comsol.help.heat/heat_ug_theory.07.083.html)과 부호·가역/불가역 기여를 대조했다.

Reynolds 예제의 외력은 구성원별로 다르며 수직 성분도 포함한다. 같은 평균에서 공분산이 달라지는 예제를 같은 완전한 강제 문제의 비유일성 증명으로 확대하지 않는다. Gaussian은 표준편차를 폭으로 사용하며 투영이 아니다. [UW 필터 자료](https://courses.washington.edu/mengr544/handouts/hd-les.pdf)의 폭Δ와는 ℓ=Δ/√12로 연결한다. 두 난류 예제는 제조한 강제 문제이며 DNS·보편적 폐쇄·관성 영역을 검증한 것이 아니다.

## 발견한 계산 오류와 수정

열전에서 거의 상쇄되는 저항·Seebeck 전압을 로그로 더하면 부호가 뒤집히는 사례를 재현했다. r=L=1,S=0.01,TR−TL=10,j=−0.1인 실제 이진 입력에서 기존 전압은 약+4.44e−17V, 전력은 음수로 표시되어 발전으로 분류됐다. 정확한 입력의 전압은−3.469446951953614e−18V이고 전기 입력은+3.4694469519536144e−19W다.

상수 물성 막대의 유리수 식은 입력을 보존한 정확한 곱·합·비로 계산하고 관측을 마지막에 투영하도록 수정했다. 전위·전기장·국소 일·열 플럭스 미분·전체/부분 전력과 경계 열에도 같은 방법을 적용한다. 내부 정밀 표현은 공개 결과에 노출하지 않는다. 정확히 상쇄되는 이진 대조, 영 전류, 작은 양의 냉각 비를 구별한다. 로그는 근사값이며 다른 초월함수 모델 전체의 정확 반올림을 보증하지 않는다.

한영 본문에 이 사례와 정확한 영 대조를 추가했다. 본문 절이14개에서15개로 늘어 구조 검사도 갱신했다. 첫 빌드의 직접 구성한 점성 구간에 빠진 범위 정보와 첫 본문 검사의 이전 절 수 기대값을 수정한 뒤 최종 검사를 다시 통과했다. 실패 기록도 보존한다.

열탄성·난류 그림에서도 세로 로그값을 거르기 전에 가로 범위를 보존한다. 영 초기 상태·영 진폭의 빈 그림은 시간0~4s, 폭0~4m, 작은 입력의−24~0 범위를 유지한다. 정의되지 않는 로그에 가짜 영 곡선을 그리지 않는다. 점성의 특이점은 기존 구간 분리를 유지한다.
