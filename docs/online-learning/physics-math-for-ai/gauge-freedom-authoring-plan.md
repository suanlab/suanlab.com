# Gauge freedom 두 단원의 집필 설계

2026-11-05. [자료·독립 탐색](gauge-freedom-source-audit.md)에 이은 후속 설계다. 계획 당시 아래 항목은 구현·등록·검증 전이었다. 이후 [계산 모델·상세 한영 원고 검증](gauge-freedom-foundation.md)을 마쳤으며 이후 [홈페이지 통합 검증](gauge-freedom-authoring-status.md)까지 마쳤다. 매질·경계 통합 검증 동안 제품 소스와 정적 출력을 유지하며 다음 계산·원고 작업의 기준을 정리했다.

## 학습 순서

첫 단원 `time-dependent-gauge-field-invariance`는 전위가 관측량을 만드는 표현이라는 직관에서 시작한다. 정적인 ∇χ뿐 아니라 시간 의존 변환에서 왜 V도 바꾸어야 하는지 유도한다. 다항식 전위·좌표·단위를 지정하고, 원래/변환된 A·V, −∇V와 −∂tA의 상쇄, E/B, 닫힌 경로 적분을 비교한다. A만·V만 바꾸는 반례, Lorenz 조건을 유지하는/유지하지 않는 유효한 게이지 변환을 구분한다. 손계산과 풀이 문제에서 물리적 동일성과 표현 조건을 따로 판정한다.

두 번째 단원 `lorenz-gauge-source-initial-compatibility`는 G와 분리된 전위 파동식을 연결한다. 종방향 조화 전위의 파동식이 지정한 ρ/J와 E/B에서 역산한 ρ/J를 비교한다. 원천 연속성, 초기 G와 ∂tG, 경계 조건의 역할을 차례로 설명한다. 공명·비공명·순수 게이지·초기 제약 누락을 대조하고, AI/PINN이 파동식 잔차만 줄이는 경우 무엇을 빠뜨리는지 풀이한다.

## SI 단위와 정규화

구현 후보는 길이 L, 전위 U, 파속 c=1/√(εμ)를 먼저 지정하고 ξ=x/L, τ=ct/L로 정규화한다. 물리적 A=(U/c)a, V=Uv, χ=(UL/c)χ̃로 두면 변환은 a′=a+∇ξχ̃, v′=v−∂τχ̃다. 계산용 계수1과 실제 SI 값·단위를 함께 설명한다.

E=(U/L)(−∇ξv−∂τa), B=(U/(cL))∇ξ×a이며 G=(U/(cL))(∇ξ·a+∂τv)다. 무차원 원천은 ρ의 척도 εU/L²와 J의 척도 εcU/L²로 환산한다. 정규화 시간과 초·ns를 같은 숫자로 취급하지 않는다. 양의 L, 유한 입력, 영전위·영진폭, 곱/몫 표현 손실의 상태를 별도로 설계한다. 정규화는 원천·경계·초기 조건을 자동으로 만족시키지 않는다.

## 잔차의 의미

분리된 파동식이 성립하면 Gauss 잔차는 −∂tG, Ampere 잔차는 ∇G다. 따라서 파동식 잔차가 작다는 사실을 Maxwell 전체 적합성으로 표시하지 않는다. Lorenz G=0은 충분한 표현 조건이지만, 일정한 비영 G처럼 실제 장의 잔차가 사라지는 경우까지 물리적으로 불가능하다고 단정하지 않는다. G=0의 보존에는 초기 G·∂tG와 적절한 경계 제약을 확인한다.

독립 검증은 전위에서 계산한 차분·curl·폐경로 구적, 실제 장에서 계산한 원천, 선택한180자리 정확 입력 기준을 분리한다. 같은 해석식의 두 표기 일치는 독립 인증이 아니다. 작은 공명 차이 k²−ω²/c²의 안정 계산과 이미 같아진 입력을 구분한다.
