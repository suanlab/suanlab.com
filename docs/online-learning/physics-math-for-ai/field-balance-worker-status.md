## 독립 수학 검산

검산기는 두 제품 계산기를 가져오지 않는다. 별도 유리수 산술과 전방 자동미분으로 운동·퍼텐셜·배분 에너지를 구성하고, 에너지 기울기에서 가속도를 구한다. 점별 변화율은 연쇄법칙, 내부 흐름은 힘의 일과 변 에너지 변화율로 구한다. 정준량의 소스·경계 유입·모든 접두 부분 구간과 공간 생성자 변화율까지 각각 대조한다.

SymPy 독립 참조130입력과 준비 예제12개를 검사했다. 한 결과의 수치·부호·인덱스·대칭/해석 표시100개를 각각 변조하면 거부한다. 전체 에너지를 유지하는 반대 방향 국소 오류, 잘못된 경계/입력/요청 번호도 거부한다.32점·18자리 입력의 세 극단 사례는 독립 Fraction 에너지와 대조했다. 에너지 배분α는 시간에 대해 고정된 가정이며, 시간 의존α에는 추가 항이 필요함을 한영 원고에 명시했다.

## 전송·수명주기

계산과 독립 검산을 별도 Worker에서 수행한다. 입력·요청 번호 귀속, 소유한 응답 복사, 자원 한도,30초 deadline, 이전 콜백 차단, 교체·취소·재시도·해제를 확인했다. main thread와 hook에는 계산기나 검산기를 포함하지 않는다. 관련343검사·타입·lint를 통과했다.

실제 module Worker145입력(독립 기호 참조130·예제12·극단 에너지3)의 전체 결과 해시가 일치한다. 에너지 변조145건·요청 귀속 오류145건을 거부했다. 실제 React hook에서 비활성화, 계산/검산 중 visibilitychange, 재개, 입력 교체, 재시도, unmount를 확인했다. 만든14Worker가 모두 종료되고 활성 Worker는0이다. visibilitychange는 제어된 이벤트 시뮬레이션이며 실제 OS 배경 탭 검증을 주장하지 않는다.
