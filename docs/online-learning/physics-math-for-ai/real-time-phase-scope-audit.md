## 현재 근거와 역사적 근거

각 단계의 false/pending 표시는 그 날짜의 진행 기록이다. 오늘의 완료 판정은 최신 구현과 연결된 근거를 사용한다. 이전 그림/학습 화면의 hash와 달라진 부분은 controlled 표시/저장·embedded 연결의 후속 검증으로 대체되었고, 이번에는 네 reader 전체의312개념·256문제·200안내를 다시 확인했다. 표의 첫 열 보정도해당8화면에서 따로 검사한다.

수치 재사용은 파일 이름만 같다는 추정에 의존하지 않는다. 현재 계산/검산Worker 의존 그래프를 구성해 보존된 생산 후보와 비교했다. Brownian19·Euclidean19·안장점21·실시간37파일이 모두 byte 동일하고각 후보의 생산 자산도 당시hash와 일치한다. 원래 생산63·71·54·38요청을 이번의새226회 실행으로 보고하지 않는다. 이번 Python 유도식 실행과새16모형 교차 검산도기존 검사 수에 섞지 않는다.

고정 폭·국소화 족·위치만의 초점·harmonic delta·canonical fold의 서로 다른 대상을 그대로 유지했다. 잘못된 pivot을 작은 양수로 치환하거나,정확 초점에서inverse를 만들거나,underflow를0으로 바꿔 검사를 통과시키지 않았다.
