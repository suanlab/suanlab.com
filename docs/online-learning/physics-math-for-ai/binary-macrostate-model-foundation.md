# 이진 미시상태·거시 껍질 계산 기반

2026-11-06. 미시·거시 상태 주제의 첫 가족 `binary-shell-multiplicity-block-counts`에 계산 모델을 추가했다. 모델만 검증한 단계다. 상세 한영 본문·실습 UI·교육 구성·등록은 미완료이며, 나머지 두 관측 가족도 남아 있다.

## 모형과 서로 다른 준비

N개 자리는 서로 구별되고 비상호작용이며 각 자리의 상태는0 또는1이다. 전체 미시상태는2ᴺ개이고 거시값 K는1의 개수다. 양의 에너지 간격 ε를 주면 E=εK이며 바닥 에너지는0이다. 기본 ε=kB·300 K는 에너지 척도일 뿐, 이 계산에 온도 저장고가 지정된 것은 아니다.

`binaryMacrostateModel(N,K,Na,epsilon)`은 N≤4096의 정수 입력을 받는다. K와 블록 크기 Na는0–N이다. ε는 임의의 유한 양의 binary64 J 값이다. 한도는 계산 자원의 제한이며, 일반 조합론이나 열역학 극한의 정의를 제한하지 않는다.

전체 미시상태를 균등하게 준비하면 한 이진열의 확률은2⁻ᴺ, 껍질의 확률은 C(N,K)/2ᴺ이다. K가 고정된 껍질 안에서 균등하게 준비하면 한 이진열의 조건부 확률은1/C(N,K)다. 계수 자체로 균등 준비나 실제 혼합 동역학을 증명하지 않는다. 코드의 두 measure 필드는 이 구별을 명시한다.

N=4,K=2의 다중도는6이다. 전체 준비의 특정 이진열 확률1/16, 껍질 확률6/16, 고정 껍질 내부의 특정 이진열 확률1/6은 서로 다르다. 선택 껍질의 Boltzmann 엔트로피는 kB ln6이고, 전체 준비의 정보 엔트로피는4ln2다.

## 정확한 개수와 조건부 블록

이항 계수 행은 정수 recurrence C(N,k+1)=C(N,k)(N−k)/(k+1)로 계산한다. 전체 합이2ᴺ인지 정확한 정수로 검사한다. 큰 개수를 먼저 Number로 바꾸거나 factorial 근사로 대체하지 않는다. 개수는 문자열과 관측값·로그를 함께 제공한다.

두 번째 블록은 Nb=N−Na다. 고정 K에서 블록 A의 여기 수 a에 대한 다중도는 C(Na,a)C(Nb,K−a), 조건부 확률의 분모는 C(N,K)다. 가능한 정수 지지집합만 반환하고 Vandermonde 합을 정확히 검사한다. 조건부 평균·분산은 이 분포의 일차·이차 정수 모멘트에서 구한다. 분산의 차이를 부동소수점으로 빼거나 음수라서0으로 자르지 않는다.

N=4,K=2,Na=2에서는 블록 여기 수0,1,2의 개수가1,4,1이다. 평균은1, 분산은1/3이다. 모드와 동률은 정수 다중도 비교로 결정한다. 가장 흔한 거시값을 실제 시간의 도착 상태라고 부르지 않는다.

## 엔트로피와 표현 범위

전체 준비에서 H(X)=Nln2, H(K)=−ΣP(K)lnP(K), E[H(X|K)]=ΣP(K)lnC(N,K)를 계산한다. 수학적 연쇄법칙과, 근사 로그를 포함한 수치 합의 일치는 구별한다. 선택 껍질의 SB=kB lnC(N,K)는 J/K이며 정보량은 nat이다. kB의 숫자는 SI 값의 binary64 근삿값이다.

가중 개수와 로그의 곱을 원래 분자에서 합산한 뒤 한 번 투영한다. N=1080,K=0에서는 껍질 확률2⁻¹⁰⁸⁰의 선형 표시가 없지만 −P lnP의 작은 양수 기여는 표현된다. 이 껍질의 다중도는1이므로 SB=0이며, 껍질 내부 확률은1이다. 이 서로 다른0·양수·조건부 확률을 혼동하지 않는다.

N=4096 중앙 껍질의 개수나 매우 큰 ε의 에너지가 Number 범위를 넘으면 value=null과 양의 부호·로그를 유지한다. 확률 underflow도 실제0으로 바꾸지 않는다. 내부 이항 행은 BigInt지만 모델의 반환값은 JSON 직렬화 가능하다. 로그와 엔트로피는 근사이며 보편적인 초월함수 정확 반올림을 주장하지 않는다.

## 독립 검증

참조 생성기는 생산 recurrence 대신 factorial 몫을 사용한다. N≤12의 참조는 이진열을 전수 열거하여 다시 확인한다. 조건부 모멘트는 별도의 유한 모집단 닫힌식으로 비교하며, 엔트로피는 mpmath160자리 직접 합이다. 일반24개·극한12개, 총36개 참조를 생성하고 독립 재생성의 바이트 일치를 확인했다.

45개 검사는 참조 비교, N≤10 선택 껍질의 독립 비트열 블록 열거, 엔트로피 연쇄법칙, underflow 기여 복원, 모드 동률·반전·블록 교환, 에너지 척도 변경, N=0/단일 자리/빈 블록/전체 블록, 범위 밖 개수·에너지·확률 및 입력 거부를 포함한다. 타입 검사와 대상 lint도 통과했다.

기존 빌드의 소스/검사/자산3888개와 정적 출력4236개가 그대로임을 확인한다. 이 모델은 아직 등록·소비하지 않으므로 기존509단원·1527안내 실험과 입문 검증282주제·미완료80주제 수를 변경하지 않는다.
