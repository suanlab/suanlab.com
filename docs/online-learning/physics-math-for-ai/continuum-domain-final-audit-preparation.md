# 연속체 영역 최종 검증 준비

실행 결과: [최종 입문 종합 점검 완료](continuum-domain-final-audit.md). 아래는 실행 전에 고정한 요구사항이다.

2026-11-06. 행별 점검과 영역 전체의 완료 판정을 분리한다. 마지막 두 단원의 점검 이후에도 아래 검증을 최종 소스와 같은 정적 출력에 대해 수행해야 한다. 이 문서는 실행 완료의 증거가 아니다.

## 최종 범위 고정

점검 행렬의 실제22단원·한영44원고·입력234개·예제401개를 등록 데이터와 대조한다. 원고 해시, 각 행의 가정·단위·독립 예산·입력/그림·선수 흐름 근거를 확인한다. 이전 단계의 통과 기록은 해당 소스 당시 근거이며 최종 출력 전체의 새 검증과 구별한다.

## 학습 흐름과 화면

최종 출력의22단원을 한영·명암·320px/데스크톱8조합으로 순회한다.176기본 상태·704개념 단계·528펼친 안내에서 실제 도착 경로, 올바른 개념 그림, 안내 예제와 입력, 목차 앵커·선수·이전/다음 연결, 키보드·접근성·줄바꿈을 확인한다. 기존 단계의 입력234개·예제401개 근거가 현재 파일과 일치하는지도 대조한다.

시작 경로는 도서 → Interactive Book이다. Online Book 본문의 기존 도서 분류, 교재의 기존 URL·북마크와 Interactive Book 메뉴 활성 표시를 유지한다. 한영 본문과 용어·물리 관례의 연결은 원고를 직접 읽은 행별 기록을 바탕으로 확인한다. 파일 존재나 수식 개수만으로 학습 내용을 검증했다고 판정하지 않는다.

## 전체 출력과 영어 표시

최종 빌드·타입·관련/전체 검사와 정적 출력의 모든 내부 링크·자산·조각·canonical·sitemap을 확인한다. 영어 표시는 `scripts/check-language.cjs`의 실제 경로 선택과 상태 전개 범위를 읽고 실행한다. 블로그·QT의 모든 원문을 번역 검증한 것으로 확대하지 않는다. 실행 결과의 실제 경로/상태 수와 종료 코드를 보존하고 예전 전체 순회 수치를 재사용하지 않는다.

소스·출력 해시를 검증 전후 대조하고, 변경이 생기면 영향을 받은 검사를 최종 소스로 다시 실행한다. 사용자 미리보기와 브라우저는 유지한다. 공개 배포·commit·push는 별도 요청에 따라 진행한다.

## 완료 판정과 이후 순서

행렬의22개 행과 전체 검증에 누락·실패·정의가 불분명한 항목이 없을 때만 연속체 입문 영역 종합 점검을 완료로 바꾼다. 연구 심화와 전체51영역509주제의 완료를 뜻하지 않는다. 이후 열역학·평형 통계역학부터 `remaining-next-steps.md`의 남은 영역을 순서대로 진행한다.
