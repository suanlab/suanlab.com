# 엔트로피·자유에너지 실습 UI 준비

2026-11-06. 두 가족의 입력·예제 전환·브라우저 저장·관측 표와 그림을 독립 컴포넌트로 만들었다. 아직 실제 교재 단원으로 등록하지 않았다. 다음 단계는 개념·안내·퀴즈·표지 및 실제 경로 연결과 전체 통합 검증이다.

## 구현한 화면

`learning-free-energy.ts`가 화면용 매개변수·검증·예제를 정의하고 `free-energy-lab.tsx`가 계산을 시각화한다. 기존 교재의 HSL 색상 변수·카드·버튼·표·WavePlot·NumberField·저장 훅을 재사용했다. 기존 공용 컴포넌트나 스타일 파일은 변경하지 않았다.

유한 스펙트럼 화면은 동일 에너지의 바닥 미시상태 두 개와 들뜬 미시상태 하나를 명시한다. 세 가중치를 각각 수정하여 내부 불균형을 유지할 수 있다. 온도를 바꿔도 에너지 간격은 함께 바뀌지 않는다. 확률 막대, 균등한 바닥 조건부 분포의 U/F/Feq 비교 곡선, 직접 계산한 양의 차이, 고정 에너지의 온도별 정준 확률을 보여준다. 현재 시도 분포의 점은 내부 불균형 때문에 비교 곡선 위에 놓이지 않을 수 있다.

기체 화면은 고정 n,T,P에서 F·Ggas·Φ·G*와 양의 가용 에너지를 체적에 대해 비교한다. 표에는 조건부 끝점의 열·일·엔트로피 수지를 포함한다. Fr가 현재 n,T,Vr의 입력이라는 점과 실행 사이의 절대 온도 비교 한계를 설명한다.

총13개 입력과10개 완전한 예제를 제공한다. 작은 에너지는 명시한 축 배율로 표시하고, 범위 밖 점이나 미해결 절대 에너지 상쇄를 선으로 연결하지 않는다. 정확한 압력 평형·근사 상쇄0·비영 값의 underflow·계산 미해결을 별도로 표시한다. 극저온 확률과 KL에는 추가 로그 관측을 제공한다. 현재 확률의 선형 좌표가 없으면 점을0에 놓지 않는다.

## 검증과 한계

새24개 검사와 기존419개를 함께 실행하여443개가 통과했다. 실제 계산값과 표의 연결, 모든 예제의 한영 SVG, 입력 정수·정규화 조건, 극소 총량 복원, 미해결 상쇄와 정확한 기체 평형을 검사했다. 타입 검사와 새 소스·검사 파일의 lint도 통과했다.

실제 브라우저에서는 독립 번들과 기존 정적 출력 CSS를 이용한 로컬 검사 화면을 사용했다. 한영·명암·320px/1440px에서10개 예제의 총80상태를 검사하여 접근성 위반·수평 페이지 넘침·비정상 SVG·런타임 예외가 없었다. 키보드 값 변경16회, 저장 후 새로고침 복원16회, 소수 복제 수 거부8회를 확인했다. 모바일 스크린샷8개를 남겼고 영어 어두운 스펙트럼과 한국어 밝은 기체 화면을 직접 검토했다.

이 결과는 독립 컴포넌트의 검증이다. 실제 교재 경로·메뉴·검색·표지·고정 개념·안내·퀴즈·전체 페이지 접근성이나 사이트 빌드를 검증한 것은 아니다. 자동 모션은 아직 추가하지 않았으며 그래프를 완화 시간이나 피스톤 궤적으로 해석하지 않도록 설명한다. 기존 홈페이지 색·스타일을 유지한다.

임시 검사 서버와 검사 소유 브라우저는 종료한다. 기존 사용자 브라우저와4175 미리보기는 유지한다. 근거는 `.runtime/learning/free-energy-ui-verification.json`이다. 등록507단원·1521안내 실험·검증281주제·미완료81주제 수는 그대로다.
