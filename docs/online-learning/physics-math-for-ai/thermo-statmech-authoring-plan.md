# 열역학·평형 통계역학 집필 준비

최신: [온도·열·일의 홈페이지 입문 통합 검증을 마쳤다](temperature-heat-work-authoring-status.md). 아래는 해당 단계의 기록이며 전체 영역·연구 심화 완료를 뜻하지 않는다.

최신 상태: [열접촉](thermal-contact-foundation.md)과 [이상기체 두 경로](ideal-gas-paths-foundation.md)의 계산·한영 본문 기반 검증 완료. 아래 초기 준비 기록 이후 진행했으며, 그림·실습·등록·주제 통합 검증은 아직 남아 있다.

2026-11-06. 남은 영역 작업의 다음 대상은 `thermo-statmech`다. 연속체 최종 검증 중에 원래11주제의 범위와 첫 계산 가족을 준비한다. **계산·화면을 제품에 구현하거나 입문 검증 수를 올린 단계가 아니다.** 기존502단원·1506안내와279검증·83미완료를 유지한다. 주차·분량 제한을 두지 않으며 연구 심화는 별도로 계속한다.

## 기존 단원과 출발점

기존 `thermodynamics`는 열저장고와 평형인 축퇴 두 수준계의 canonical 확률·에너지·자유에너지·엔트로피를 다룬다. 그대로 보존하고 선수로 연결한다. 여기에 물리적 온도·열·일, 실제 저장과 수송, 앙상블 가정, 공간 상관과 유한계의 범위를 순서대로 더한다. 계산을 정의하기 전에 계·경계·제어변수·단위와 부호 관례를 먼저 설명한다.

## 첫 주제의 두 계산 가족

### 유한한 두 물체의 열접촉

예정 ID: `finite-body-thermal-contact-heat-entropy`. 각각 내부 평형인 두 고정 체적 물체가 일정 열용량 C₁,C₂와 열전도 연결 K를 가진다. 양의 절대온도, 외부 단열, 물질 이동·기계 일이 없는 조건을 선언한다. 온도차는 지수적으로 줄지만 총 내부 에너지는 보존되고 합친 엔트로피는 증가한다.

온도 곡선과 두 방향의 열 전달, 실제 에너지J와 엔트로피J/K, 순간 전력W를 분리한다. 열을 물체에 저장된 별도 물질처럼 그리지 않는다. 영 연결·같은 초기 온도·용량 교환·시간0·큰 시간·작은 전달의 대조를 포함한다. 실제 공간 확산을 푼 모형이 아닌 집중계 근사임을 밝힌다.

### 같은 끝점을 잇는 이상기체의 두 경로

예정 ID: `ideal-gas-two-path-heat-work`. 일정 물질량의 단원자 이상기체를 (T₀,V₀)에서 (T₁,V₁)로 옮긴다. A는 V₀에서 온도를 바꾼 뒤 T₁에서 부피를 바꾸고, B는 T₀에서 부피를 바꾼 뒤 V₁에서 온도를 바꾼다. 압력은 nRT/V로 종속 계산한다.

두 실제 경로의 p–V 곡선·누적 일·열과 같은 내부 에너지/엔트로피 변화를 비교한다. 일은 기체가 외부에 한 일이 양수이며 ΔU=Q−W다. 가역 열 교환을 비교하려면 연속적인 온도의 저장고와 마찰 없는 기계 제어를 명시한다. 단순히 느리다는 이유만으로 가역이라고 부르지 않는다. 진행률은 경로 위치이며 물리적 시간이나 열전달률이 아니다.

## 원고·상호작용·검증

한영 원고에 직관·가정·단위·직접 유도·손계산·반례·풀이6개와 AI 검증 연결을 제공한다. 먼저 계산과 독립 참조를 검증한 뒤 기존 색·타이포그래피·Interactive Book의 고정 개념·조작·안내·퀴즈에 연결한다. 두 물체의 열 흐름과 p–V 경로는 실제 계산값으로 그리며 표시용 애니메이션을 별도 물리 해처럼 사용하지 않는다.

독립 ODE/적분·경로 적분·에너지/엔트로피 수지를 제품과 다른 방식으로 계산한다. 작은 전달·정확한0·미정·표현 불가를 구분하고, 한영·명암·모바일·키보드·접근성·예제·입력·정적 출력까지 확인한 가족만 등록·검증 수를 갱신한다. 진입은 도서 → Interactive Book이며 Online Book 본문에는 새 교재 카드를 추가하지 않는다.
