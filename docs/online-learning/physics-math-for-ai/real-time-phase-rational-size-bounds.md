# 실시간 사슬: 입력 크기와 큰 위상의 보수적 상계

2026-11-10. [수학 계약](real-time-phase-model-contract.md)의12자리 유리수·N2…32에 대한 유도다. 이는 **이차 사슬의 실시간 정상 작용**에 대한 보수적 bound이며 Airy·복소 전파·전체 wire의 비용 증명으로 확대하지 않는다.

## 물리 계수와 continuant

분자/분모는 10¹²보다 작고 따라서2⁴⁰보다 작다. 양의 입력은2⁻⁴⁰보다 크며16이하다. δ=τ/N은2⁻⁴⁵보다 크고8이하이므로 `2⁻⁴³<s=m/δ<2⁴⁹`다. `|v|=|ω²δ²|≤1024`이며 v의 기약 분모 Q는 `Q<2¹³⁰`으로 감쌀 수 있다.

`t=2−v`, `θ₀=1,θ₁=t,θ_k=tθ_(k−1)−θ_(k−2)`에서 `|t|≤1026`이다. 귀납하면 `|θ_k|≤1027^k<2^(11k)`다. θ_k는 v의 정수 계수 다항식이므로 분모는 Qᵏ을 나눈다. 따라서 d=N−1≤31에서

- `θ_d≠0`이면 `|θ_d|≥Q^(−d)>2⁻⁴⁰³⁰`.
- `|θ_d|<2³⁴¹`이며 θ_d 기약 분자의 크기는2⁴³⁷¹보다 작다.

이 separation bound는 실제 초점 근처의 수치 크기보다 매우 보수적이다. 그래도 반올림 tolerance로 특이성을 판정할 필요 없이 정확한 정수 0을 사용할 수 있음을 보여준다.

## 역행렬·정상 경로·작용의 크기

Green 식에서 두 numerator continuant의 차수 합은 d−1−|i−j|≤30이다. 따라서

`|(H⁻¹)_ij| < 2^(330+43+4030)=2⁴⁴⁰³`.

forcing은 내부 좌표가 하나인 경우에도 두 끝점의 합을 포함하므로 `|f_i|≤32s<2⁵⁴`다. d<32를 이용하면 `|q_i*|<2⁴⁴⁶²`다. 양끝 상수의 운동 부분은2⁵⁷보다 작고 potential 부분은2¹⁸이하이므로 `|c|<2⁵⁸`다.

`S*=c−fᵀH⁻¹f/2`에 d²<2¹⁰을 적용하면 충분히 보수적으로 `|S*|<2⁴⁵²⁸`을 얻는다. ℏ>2⁻⁴⁰이므로 `|S*/ℏ|<2⁴⁵⁶⁸`이다. 이는 기존±2⁶⁴ phase cap보다 크다. 새 phase primitive는 입력 크기에 적응하는 π 정밀도를 사용한다. 정확한 초점에서는 이 상계를 가짜 inverse에 적용하지 않는다.

이것은 **값의 크기** bound다. 유리수 분자/분모의 비트 수, 복소 연산의 중간 크기, 시간 복잡도나 wire 문자열 수와 같은 뜻이 아니다. 해당 항목은 별도 exact factorization과 실제 최대/경계 입력 검사로 확인하며 전체 생산 계약이 완료될 때까지 미확정으로 둔다.
