## 확인 수준

공개 출판사·저자·기관의 서지·초록·발췌를 확인했다. 이 확인만으로 원 논문의 모든 정리, 전체 수치 실험, 최신 개정판을 검토했다고 판정하지 않는다. 본문에 제시한 합성 계산은 원 논문 결과와 구별하며 각 Python 예제를 실행했다. TypeScript 모형은 명시한 식·독립 열거·유한차분·수치 적분 중 해당 방법으로 검산한다.

## 심화 검토에 남은 일

- 원문 전체를 읽고 사용한 정리의 정확한 가정·절·쪽과 확인 버전을 기록한다.
- 선택한 원전의 실험 하나를 데이터·환경·평가 조건까지 맞추어 재현한다.
- 합성 예제와 원전의 차이를 기록하고 실제 자료에서 검증할 후속 가설을 정한다.
- 논문별 재현 결과를 한영 단원에 연결하고 성공·실패 조건을 함께 공개한다.

이 문서는 출처 확인과 자체 합성 검산의 범위를 기록한다. 전체 51영역의 연구 심화 완료 여부는 각 원주제와 실제 재현 근거를 대조해 별도로 판정한다.
