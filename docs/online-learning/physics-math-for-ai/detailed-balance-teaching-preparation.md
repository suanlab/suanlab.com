# 상세평형: 개념과 실험 준비 데이터

2026-11-07. 세 가족의 한영 학습 데이터를 작성하고 실제 계산 모델과 대조했다. **학습 화면·실습 조작부·표지·교재 등록은 아직 미완료**다. 등록527단원·1,581안내, 원래288/362주제 입문 검증·74미완료는 유지한다. 전체51영역509주제와 연구 심화도 계속 남아 있다.

## 이번에 작성한 내용

`src/lib/learning-detailed-balance.ts`에 제목, 비교 예제36개, 안내9개와 정수 초안 parser를 추가했다. 세 상태 순환12개, Hastings10개, 두 상태 혼합14개다. 모든 예제는 유효성 검사와 동결된 입력 사본을 사용한다. 전체 입력 범위와 분모·분자 관계는 protocol이 검사하며 parser만으로 준비 전체를 승인하지 않는다. parser는 정수 문자열만 허용하고 소수·지수 표기·음수·비영 underflow·범위 초과를 거부한다.

`src/lib/learning-detailed-balance-concepts.ts`는 가족별 고정6단계, 세 선택지 예측6문제, 최종 해설 퀴즈3문제를 제공한다. 개념 비교 입력은 저장된 자유 실습과 독립적이며 각 요청에 새 사본을 제공한다. 예측·최종 퀴즈 ID와 실험 예제 ID가 겹치지 않도록 이름을 구분했다. 최종 퀴즈의 객체도 개념 문제와 분리했다.

- 순환: 행벡터 관례와 첫 전이 → 정점 수지/쌍별 수지 → 시간 반전 → 귀환 주기 → 비유일 정상 참조 → 상한과 작은 정확한 편차.
- Hastings: 제안/실제 전이 → 역제안 비율 → 우연한 목표 보존 → 없는 제안/수락0 → 점프 법칙 → 고정 커널 비교와 숫자 표시.
- 두 상태: affine 전이 → 교대 오차/TV → 가역적 주기 반례 → 항등/흡수 지지집합 → Cesaro 평균 → 최악 초기값 혼합 기준.

`use-detailed-balance-series.ts`는 고정 예제를 worker에서 차례로 요청하는 hook이다. 입력 key가 바뀌면 이전 결과를 가리고, 교체·언마운트 시 controller를 폐기한다. SSR에서 Worker 접근0과 main 번들의 수치 모델 제외를 검사했다. **이 새 series hook의 native 교체·취소·복구는 아직 검증하지 않았다.** 앞 단계의 개별 계산 hook 검증과 구별한다.

## 검증 범위와 근거

신규 검사9개와 관련 모델·본문·worker 회귀171개, typecheck와 lint가 통과했다. `scripts/learning-detailed-balance-teaching.test.ts`가36예제를 실제 evaluator로 실행하고 전송 구조를 검사한다. 설명의 핵심 수치와 경계를 별도로 대조한다. 정상전류1/12, 우연히 보존되는 목표의 전류1/24, 수락률1/8, 점프 법칙3:6:5, 주기1/3, 흡수의 미제공 상관·역전이 행, Cesaro N+1개 평균, 포함1/4기준, 기록 내 미도달과 영구 미도달, 표시 범위 아래의 정확한 비영값이 포함된다. 한영 텍스트·문제 ID·모든 예제의 안내 접근도 검사한다.

증거는 `.runtime/learning/detailed-balance-teaching/verification.json`, `tests.log`, `regressions.log`, `typecheck.log`, `lint.log`에 있다. 직전4,231개 소스 파일과 정적 산출물4,280개는 바이트와 경로 집합을 유지했다. 이번에는 새 소스4개를 추가했으며 전체 테스트·정적 빌드는 실행하지 않았다. 실제 페이지 렌더링이나 접근성·번역 완성을 이 데이터 검사만으로 주장하지 않는다.
