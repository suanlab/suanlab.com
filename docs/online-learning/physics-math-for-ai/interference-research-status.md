# 간섭·회절 연구 보강: 요동 모멘트·개구 오차 상계

2026-11-12. 두 단원의 한영 원고 네 편에 반복 노출의 분산·결합 모멘트 조건과 Fresnel/Fraunhofer의 절대 상계·기준 위상 반례를 보강·검증했다. 기존 본문·각 여섯 해설 문제·실습 입력을 보존한다. [파동 영역 순차 검토](waves-optics-topic-review.md)는 **8/18단원**이며 영역 전체 완료로 집계하지 않는다.

## 추가한 논증과 예제

- 검출기 단원은 한 노출 동안 고정한 무작위 위상에서 노출 평균 강도의 분산을 유도한다. 첫 모멘트 M이 같은 두 모집단이 평균 무늬 전체를 공유하면서 이차 모멘트 N과 분산 스캔은 다름을 계산한다. 모멘트 행렬의 양의성과 결합 원판 조건을 증명하고, 개별 단위 상계만 만족하는 잘못된 모멘트가 음의 분산을 예측하는 반례를 준다.
- 반복 평균에는 독립성을 명시하고 정상 상관의 공분산 항을 유도한다. 고정 위상을 재사용하는 반복과 긴 노출을 구분한다. 이는 정규화한 고전적 강도의 분산이며 광자 계수·샷 잡음이나 노출 중 빠르게 변하는 위상의 일반 모델이 아니다.
- 회절 단원은 절대 진폭 모멘트로 정확한 두 근축 적분의 균일 복소·강도 오차를 상계한다. 별도로 사전에 정한 기하 위상 보정의 상계를 유도한다. 기존 Fraunhofer 결과를 수정하거나 계산된 정확한 출력에 위상을 적합하지 않는다.
- 개구 간격도 함께 바꾸는 보충 계열에서 고립 강도는 가까워져도 축소 복소 장 차이는 4로 남고 같은 기준 장을 더한 강도는 0과 16으로 달라짐을 증명한다. 고정 개구 정련·기하적 퍼짐·근축의 물리적 유효성·수치 구적 오차를 분리한다. 한영 그림 네 개·비교표·실행 Python·각 세 해설 연구 질문을 제공한다.

## 독립 계산과 보존

`python3 scripts/learning/verify-interference-research.py --json`은 표준 라이브러리만 사용하며 제품 코드·등록 데이터를 가져오지 않는다. 위상 모집단 36개에서 분산 576상태·모멘트 양의 이차형식 108검사를 확인하고 불가능한 모멘트 쌍 네 개를 구분했다. 독립 반복 평균의 직접 열거 18사례와 완전 상관 반복 18사례를 대조했다. 같은 모집단의 여러 검사를 새로운 광원 수로 합산하지 않는다.

개구 절대 상계 108사례·중심 모멘트 6사례를 별도 복합 Simpson 정련으로 확인했다. 보충 기하 계열 네 개는 75자리 Decimal·정확분수 개구 모멘트·120항 지수 급수로 적분해 별도 구적과 대조했다. 유한 수치 비교와 본문의 양의성·부등식·극한 증명은 구분한다. 이론 상계가 기존 수치 정련 진단을 인증된 구적 상한으로 바꾸지는 않는다.

한영 표시 수식은 단원별 8개·8개로 같고 Python 네 셀의 출력이 본문 표와 일치했다. 기존 검출기의 16설정과 그 안의 32단일 위상 평가, 기존 개구의 27설정도 연결했다. 선택 **4파일·47테스트**, 원고/보존 집중 **12테스트**가 통과했다. 기존 목차 검사는 원래 16절을 그대로 확인하고 새 연구 절 하나를 추가한 17절과 고유 앵커를 엄격히 검사하도록 갱신했다.

연구 절만 제거하면 본문 네 편은 기준 `db8fd72`와 바이트가 같고 원래 해설 24개를 포함한다. 다른 파동 원고 32편·이전 검토 항목 693개를 보존했으며 새 해시 네 개를 더해 697개다. 앞선 공진·결합 진동·파동 방정식의 원고/그림 24개도 기존 증거 해시와 일치한다. 등록은 650단원·1,969안내 그대로다.
