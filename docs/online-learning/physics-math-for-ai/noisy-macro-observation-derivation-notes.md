# 잡음 거시 관측: 계산·집필 계약

2026-11-06. 셋째 가족 `finite-noisy-macro-observation-channel`의 도출과 교육 예제를 지정한다. 생산 모델과 독립 참조를 검증했다. 한영 원고도 검증했으며 UI는 아직 작성 전이다. 현재 결과는 [본문 기반 보고서](noisy-macro-observation-manuscript-foundation.md), 초기 계산 단계는 [계산 기반 보고서](noisy-macro-observation-model-foundation.md)에 기록한다. 결정론적 관측 가족의 검증을 잡음 채널까지 확장한 것으로 간주하지 않는다.

## 상태와 관측 장치를 따로 지정한다

입력 미시상태 X의 준비 가중치는 wᵢ≥0이며 합 W>0이다. 관측 장치는 각 입력 i마다 비음수 행 가중치 aᵢⱼ를 지정하고 모든 행의 합 Aᵢ>0을 요구한다. 준비 확률은 pᵢ=wᵢ/W, 조건부 관측 채널은 Kⱼ|ᵢ=aᵢⱼ/Aᵢ다. 준비와 채널 행은 따로 정규화한다.

관측되지 않는 입력 pᵢ=0에도 완전한 채널 행을 지정한다. 그 행을 바꾸어도 실제 결합 분포와 정보량은 변하지 않아야 한다. 모든 가중치가0인 행을 임의로 균등하게 고치지 않는다. 입력·출력 이름은 구별 가능한 유한 레이블이다. 계산 자원 한도는 각각16개이며 성능을 확인했다. 최대 범위의 혼합 입력은 여전히 무거워 UI 통합 시 별도 작업 스레드가 필요하다. 이는 일반 채널이나 교육과정의 범위를 제한하는 조건이 아니다.

## 결합·주변·사후 분포

결합 법칙은 Jᵢⱼ=pᵢKⱼ|ᵢ, 출력은 Rⱼ=ΣᵢJᵢⱼ다. Rⱼ>0일 때 사후 법칙 Bᵢ|ⱼ=Jᵢⱼ/Rⱼ를 반환한다. 출력 확률0인 열의 사후는null이며 그 출력의 가중 조건부 엔트로피 기여만0이다. 실제0인 입력/전이/출력과, 양수지만 선형 표시 범위 밖인 확률을 구별한다.

행마다 분모가 달라질 수 있으므로 준비와 각 채널 행을 Number 확률로 먼저 바꾼 뒤 곱하지 않는다. 정확한 이진 유리수 입력에서 결합 분자·분모를 유지하고 확률의 모든 합·곱을 끝낸 뒤 투영한다. 근사 로그가 들어간 정보량 항은192개 유효 이진 자리와 제한 없는 지수로 반올림해 합산한다. 항별 상대 반올림 오차는2⁻¹⁹² 이하며 양수는0으로 되지 않는다. 로그 근사 오차는 별도로 남는다. JSON에는 원시 BigInt를 노출하지 않는다.

## 정보 항등식

자연로그와 nat을 사용한다. H(X),H(Y),H(X,Y),H(Y|X)=ΣpᵢH(Kᵢ),H(X|Y)=ΣRⱼH(Bⱼ)를 서로 다른 양으로 반환한다. 결합 엔트로피는 H(X)+H(Y|X)=H(Y)+H(X|Y)다. 따라서

`H(X)=H(Y)+H(X|Y)−H(Y|X)`.

결정론적 관측은 모든 양의 준비 질량 행에서 한 출력만 갖는 특수한 경우로 H(Y|X)=0이다. 일반 잡음 관측에는 이 조건이 없으므로 H(Y)>H(X)도 가능하다. 늘어난 출력 레이블의 불확실성이 원래 계의 물리적 엔트로피 생성이라는 뜻은 아니다.

상호정보량은 `I(X;Y)=D(J || p⊗R)`이며0≤I≤min(H(X),H(Y))다. 내부 계산에서는 가까운 엔트로피를 빼서 작거나0인 값을 만들지 않고 양의 Bregman KL 합을 사용한다. J가 양수인 곳에서는 p와R도 양수이므로 유한상태 채널의 이 MI는 수학적으로 무한대가 되지 않는다. 표시 범위 밖의 유한 양수와 실제 독립인 경우의 정확한0을 구별한다.

## 여섯 교육 예제와 기대 해석

1. **일대일 관측.** p=(3/4,1/4),채널은 단위행렬이다. 사후는 각 출력에서 한 입력에 집중하고 두 조건부 엔트로피는0이다. H(X)=H(Y)=I≈.562335145 nat이다. 모든 정보를 보존한다.
2. **이전 군 관측으로 환원.** p=(.6,.2,.1,.1),앞 두 행은 출력0,뒤 두 행은 출력1로 보낸다. H(Y)≈.500402424,H(X|Y)≈.588497552,H(Y|X)=0이다. 결정론적 가족의 실제 모델과 독립 참조 양쪽을 비교한다.
3. **원래 상태와 독립인 잡음.** 모든 행을(1/2,1/2)로 둔다. p=(1,0)이면 H(X)=0이지만 H(Y)=H(Y|X)=ln2이다. MI와 H(X|Y)는0이다. p=(3/4,1/4)로 바꿔도 MI는0이고 모든 양수 출력의 사후는 원래 p다. 출력이 다양하다는 사실이 상태를 잘 구별한다는 뜻은 아니다.
4. **이진 대칭 오류.** p=(1/2,1/2),행 가중치는(9,1)/(1,9)다. 두 출력은 각각1/2,사후는(.9,.1)/(.1,.9)다. H(X)=H(Y)=ln2,H(Y|X)=H(X|Y)=h(.1)≈.325082973,I≈.368064207 nat이다. 오류율1/2에서는 독립,오류율1에서는 결정론적 반전으로 정보가 다시 보존된다. 오류 빈도와 상호정보량을 전체0–1구간에서 무조건 반비례한다고 설명하지 않는다.
5. **지워짐이 표시되는 관측.** 출력0·1·?에 대해 행 가중치(3,0,1)/(0,3,1),균등 입력을 둔다. 출력은(3/8,3/8,1/4)다. ?의 사후만 원래 균등 입력이며 나머지는 한 상태를 식별한다. H(Y)=h(1/4)+(3/4)ln2,H(Y|X)=h(1/4),H(X|Y)=(1/4)ln2,I=(3/4)ln2다. 잡음의 여부를 출력이 알려준다는 구조가 대칭 오류와 다르다.
6. **빈 출력과 미사용 입력 행.** 사용하지 않는 출력 열을 추가해도 분포와 정보량의 양수 부분은 그대로다. 빈 출력의 사후는null이다. 확률0인 입력 행을 바꿔도 정보량은 변하지 않는다. 한편 아주 작지만 양수인 준비나 전이는 제거하지 않으며 로그 증거를 보존한다.

각 예제를 설명하는 상세 한영 본문과 해설6개씩을 작성한다. 개념 그림은 행→결합 질량→출력 열→선택 출력의 사후 순서로 추적하고, 입력 분포·장치 조건부·사후를 서로 다른 이름으로 표시한다.

## 검증 계획

독립 Python Fraction 정규화와 고정밀 직접 로그 합으로 결합·주변·사후와 각 엔트로피·MI를 생성한다. 극한 참조의 정밀도는 고정4096자리라고 가정하지 말고, 원래 가중치 비의 곱과 거의 독립인 결합의 상쇄 크기를 분석해 결정한다. 더 높은 정밀도의 재계산과 바이트 재생성, 명시적인 독립·가역·결정론적 예제의 닫힌식도 확인한다.

검사는 행/전체/사후 정규화, 두 결합 엔트로피 항등식, MI 경계, 결정론적 가족으로의 환원, 독립 채널의 정확한0, 레이블 순서·행별 가중치 스케일 불변성, 미사용 입력 행의 불변성, 입력 거부, 직렬화와 극소 표시 범위를 포함한다. 양의 극소 MI를0으로 자르거나, 근사 엔트로피 차이의 음수를 임의로 보정해서 검사를 통과하지 않는다.

## 물리 해석과 통합

채널은 측정 결과의 확률 법칙이다. 장치의 에너지 준위·환경·상호작용·리셋 절차를 주지 않았으므로 측정 열이나 소산 비용을 결정하지 않는다. 양자 coherence·측정 역작용의 일반 모형도 아니다. 이를 다루는 후속 물리 단원에는 별도 가정과 상태 표현이 필요하다.

이 세 번째 가족의 모델·원고 검증 뒤 세 가족의 그림·조작·개념4단계·안내3개·퀴즈2개씩을 구현한다. 기존 홈페이지 색상·한영·명암과 모션 설정을 따른다. Book→Interactive Book에서 실제 목차·읽기 화면까지 검증하고 Online Book 목록에는 진입 링크를 넣지 않는다. 홈페이지 검증 전에는 등록509단원·1527안내 및 입문 검증282주제·미완료80주제를 바꾸지 않는다.
