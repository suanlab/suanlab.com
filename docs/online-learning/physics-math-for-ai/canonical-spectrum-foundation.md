# 고정 스펙트럼의 정준 분포 계산 기반

2026-11-06. `canonicalFiniteSpectrum(energies, temperature)`를 추가했다. 에너지 스펙트럼을 고정한 채 저장고 온도를 바꾸는 계산이다. 시도 분포의 U/S/F, 평형 자유에너지의 절대 기준, Helmholtz–KL 차이의 전체 연결은 아직 미완료다. 기존 첫 가족 본문은 유지하며, 이 단계를 전체 가족이나 주제 완료로 세지 않는다.

## 입력과 표현

미시상태1–32개의 유한 binary64 에너지(J)와 임의의 유한 양의 binary64 온도(K)를 받는다. 음의 에너지와 반복 에너지를 허용한다. 축퇴도는 미시상태를 나열하여 한 번만 센다. T=0·무한 입력·빈 목록·희소 배열은 거부한다. kB에는 SI 값의 binary64 근삿값1.380649e−23을 사용한다.

Emin을 빼서 aᵢ=(Eᵢ−Emin)/(kBT)를 구성한다. 에너지 차이가 MAX_VALUE를 넘거나 kBT가 MIN_VALUE 아래여도 곱과 차이는 정수 계수와 이진 지수로 보존한다. 각 aᵢ의 정확한 유리수 표현을 문자열 계수로 반환하므로 JSON 직렬화가 가능하다. ‘정확함’은 공급한 binary64 입력의 대수적 연산에 대한 말이며, 원래 물리량이나 초월함수의 정확도를 복구한다는 뜻이 아니다.

분포는 πᵢ=exp(−aᵢ)/Σexp(−aⱼ)이다. 바닥 상태 수 g와 들뜬 상태 가중치 합을 구분한다. 들뜬 상태의 합은 다시 가장 작은 양의 에너지 차이를 기준으로 중심화한다. 커다란 두 반올림 로그를 빼는 대신 원래 에너지 차이의 차이를 사용한다. 중심화한 로그 분배함수는 L=ln(g)+log1p(tail/g)이다.

## 숫자 범위와 해석

각 미시상태에 에너지 차이·배율을 적용한 차이·로그 확률·확률을 반환한다. 유한 양의 온도에서는 모든 확률의 부호가 양수다. 표시 범위 밖의 비영 값은 null로 표시하고 부호를 유지한다. 확률의 로그가 범위 밖이면 별도의 로그 확률 관측에 그 크기의 로그를 남긴다.

유일한 바닥 상태가 화면에서 확률1로 반올림되어도, 들뜬 상태가 있다면 그 로그 확률의 부호는 음수다. 극소 tail에서 L 자체가 underflow해도 부호는 양수이고 ln L을 보존한다. ln L까지 표시할 수 없는 극단에서는 null을 유지한다. 단일 미시상태만 있을 때의 로그 확률0은 구조적0이다.

초월함수 값은 근사 관측이다. g=1이고 log(tail)<−36이면 L≈tail 및 ln L≈ln(tail)을 사용한다. L과 tail의 상대 차이는 tail/2 이하이므로 이 분기의 오차는 약1.2×10⁻¹⁶ 이하이며, 이 근거는 Math.exp·로그·합산의 평가 오차를 없애지 않는다. 극소수의 로그를 반올림된 선형 값에서 다시 계산하지 않는다. 모든 입력에 대한 초월함수의 정확한 반올림을 보장하지 않는다.

## 독립 검증

Python 생성기는 Fraction으로 입력·중심화 차이·열에너지를 정확히 계산한다. mpmath160/1000자리 미시상태 합으로 일반24개·극한20개를 만든다. 모든 원시 유리수 좌표를 생산 결과와 교차 곱으로 정확히 비교한다. 확률·로그 확률·로그 분배함수도 비교한다.

최소 a가10⁶보다 큰 참조 사례에서는 명시적인 점근식을 쓴다. 가장 작은 들뜬 a를 기준으로 합산하고, 바닥 로그 분배함수의 지수적으로 작은 보정은 부호와 로그 크기로 유지한다. 이때 생략된 고차 보정은 상수 배수의 exp(−10⁶) 이하로, 저장한 관측의 정밀도보다 작다. 이 참조의 적용 범위와 방법을 fixture에 명시했다.

추가 검사는 고정 스펙트럼의 온도 변화, 정확히 표현 가능한 기준 이동, 순열, 에너지 차이 overflow, 열에너지 underflow, 양의 들뜬 확률, 축퇴 및 단일 상태, 입력 검증과 JSON 직렬화를 다룬다. 새50검사와 기존114검사를 함께 통과했다. 참조 재생성은 바이트 단위로 일치했다. 근거는 `.runtime/learning/canonical-spectrum-verification.json`이다.
