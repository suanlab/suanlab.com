## 학습 내용과 시각화

10개념 단계는 유한 경로 벡터·잔차 인증·H/Q/C_G 구별·Gaussian 부피·삼차/사차 보정·조건부 실제 경계·작은ℏ와 정련·여러 최소점·퇴화·AI의 Laplace 근사를 연결한다. 각 단계에는 설명·식·별도 기준 그림이 있다. 한영 기준 그림20개에서 모든 SVG 글자의 경계를 확인했다. compact 표지용 component도 준비했다.

현재 입력의 실험 화면은 다음을 제공한다.

- 정상 경로와 국소 Gaussian 표준편차 띠, 자유 직선 기준·고정끝·선택 시각. 일반 정상 경로를 실제 평균으로, Gaussian 띠를 실제 사차 신뢰구간이나 표본 경로로 표시하지 않는다.
- 전체 Hessian·역곡률·Gaussian 공분산의 열지도와 Three.js 막대, 선형/부호 있는 로그 척도·물리 첨자 선택·방향키 탐색·정확한 구간 표. H는 내부 행렬, R/C_G는 끝점0을 포함하는 행렬임을 설명한다.
- 선택 좌표의 사차 작용 단면과 국소 이차 단면. 다른 좌표는 정상점에 고정하므로 주변분포와 다르다. 단면 폭√(ℏ/Hᵢᵢ)와 주변 Gaussian 폭√(ℏRᵢᵢ)를 구별한다.
- 삼차 제곱·사차·전체c₁·ℏc₁·Gaussian 모멘트와 실제 적분비 경계의 조건. 고정N의ℏ곡선은 상대 비에서1을 뺀 값으로 그려 작은 차이의 소실을 줄인다. 이 소수 곡선은 인증 구간이나 실제 적분비의 수치 적분이 아니다.
- 별도 단일 좌표 우물의 모든 정상점·중앙 극대점 제외·두 최소점 앞 인자 합·퇴화·ℏ¹ᐟ⁴척도. potential과 비정규화 상대 가중치, 선택 최소점의 국소 Gaussian을 비교한다. 전체 우물 적분·양자 이중 우물 경로·터널링은 계산했다고 표시하지 않는다.

단면/우물의 표시 척도는 Gaussian 폭과 사차 특성 폭 중 작은 값이다. 작은 곡률에서 큰 Gaussian 폭 때문에 실제 사차 모양을 놓치지 않는다. 매우 가까운 두 최소점이 전역 그림의 표본 해상도보다 작으면 이를 명시하고 인증된 두 위치를 안내한다.

색은 기존 `--learning-*` 토큰, 서체·버튼·표·명암은 기존 교재 CSS를 따른다. 그림은 소수 근사와 인증 구간을 구별한다. 원시 분수는 필요할 때 펼쳐 볼 수 있고 전체 행렬/증명은 열었을 때만 DOM에 추가한다. 표시 시각 재생은 행렬/3D scene을 다시 만들지 않는다.

## 저장·입력·수명

두 모형의 직접 입력은 생산 입력 한도와 원래 분수 표기를 보존한다. 모형 버튼은 첫 예제를 적용하고 안내 선택만으로는 입력을 바꾸지 않는다. 잘못된 draft를 적용하면 오류를 표시하고 마지막 적용 결과를 유지한다. N변경 시 probe도 범위 안이어야 한다.

입력·행렬/척도/물리 첨자·우물 선택·개념 단계·안내 해설·8문제 답을 `suanlab-saddle-fluctuation-v1`에 저장한다. 첫 읽기 전에는 계산/쓰기를 시작하지 않는다. 저장값의 version·정확한 필드·차원·범위·mode를 검사하고, 잘못된 값은 첫 예제로 복원한다. 읽기/쓰기가 거부되어도 현재 실험을 계속한다. 상태 검사는 getter나 객체의 문자열 변환을 실행하지 않는다.

계산과 독립 검산은 기존 별도 Worker에서 수행한다. 새 입력은 이전 결과를 숨기며 취소/교체/재시도·숨김·unmount를 처리한다. 표시 시각·행렬·3D 시점·안내/퀴즈 선택은 새 계산을 만들지 않는다. 재생은 사용자가 시작하며, 움직임 줄이기 설정과 숨김에서 중지한다. Three.js는 보기 선택/화면 진입 시 준비하고 사용자 조작 때만 그린다. WebGL 손실 시 정확한 표/열지도로 돌아가고 다시 시도할 수 있다.
