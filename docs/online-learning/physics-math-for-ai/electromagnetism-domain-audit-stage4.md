# 전자기학 영역 종합 점검 4차: 유도·에너지와 전체 본문 대조

2026-11-05. [3차 점검](electromagnetism-domain-audit-stage3.md)에 이어 유도·전자기파와 에너지/Poynting의4단원 계산·실습·화면을 검토했다. 매질·경계, 게이지, 회로·센서, 유효 모델의 나머지8단원 한영 원고16개도 전체 읽었다. 전자기학 본문은 누적20/20단원·40원고·해설120쌍을 대조했지만, 남은 계산 가족과 최종 전체 화면 검증은 미완료다.

등록480개 한영 단원·안내1,440개, 원래 입문268주제 검증·94주제 미완료를 유지한다. 전체51영역509주제와 연구 심화는 미완료다. 이번 작업은 로컬 홈페이지 출력에 반영했으며 공개 배포는 하지 않았다.

## 발견해 수정한 설명

Lorenz 종방향 조화 전위의 한국어 본문에서 k=0과 ω=0의 의미가 뒤바뀌어 있었다. 위상 kζ−ωτ에서 k=0은 공간 의존성이 없는 경우이고, ω=0은 시간 의존성이 없는 경우다. 한영 원고 모두 이 대응을 명시하고, 두 값이 모두0이면 전위가 공간과 시간에 일정하다고 설명했다.

실제 계산 모델에서 공간 좌표와 시간을 각각 바꾸어 세 극한을 확인하고, 실제 콘텐츠 로더와 새 정적 출력에서 수정 문장을 검사했다. 수정 전 원고2개와 소스·출력 해시, 먼저 수행한 화면 결과는 별도로 보존했다. 수정 전 화면 검사를 수정 후의 최종 근거로 세지 않았다.

## 계산과 학습 내용 검토

유도·에너지의 순수 모델, SI 변환·실습 제어, 그림, 고정 개념 예제16개, 안내12개와 퀴즈8개를 대조했다. 움직이는 경로의 E와 u×B 기여, 실제 모서리 순서와 방향 반전, 순간값과 시간 적분, 초기 E/B와 일차 Maxwell 호환성, 실제 장과 호환 기준을 구분했다. Poynting에서는 전기/자기 저장·경계 흐름·물질 일률, 국소 밀도와 부피 적분, 유한 창과 전체 축의 면적당 값을 각각 확인했다.

독립 생성기는 기준을 덮어쓰지 않고 별도 출력에 재실행해 기존 자료와 일치함을 확인했다. 유도 기준은 이동 경로81조건, 횡파54조건, 영자기장 반례9조건, 작은 Gaussian 차이4조건과 자속 변화2조건이다. 에너지 기준은 원천81조건·펄스54조건, 얇은 구간9조건과 균형 흐름·절대 에너지 표현 손실·SI 작은 원천 결함의 고정밀 계산을 포함한다. 선택한 수치 관측이며 엄밀한 전역 오차 상한이 아니다.

[MIT Faraday Chapter10](https://ocw.mit.edu/courses/8-02-physics-ii-electricity-and-magnetism-spring-2007/ce1720fd4b21def8c2189ff4779f27f7_cha10faraday_law.pdf), [Feynman II Chapter20](https://www.feynmanlectures.caltech.edu/II_20.html), [Chapter27](https://www.feynmanlectures.caltech.edu/II_27.html)의 배경 관계도 대조했다.

추가 본문에서는 자유/분극 전하와 E/D, 반사 H 부호와 임피던스, 원천 요청과 필요한 표면 시트, 장의 동등성과 게이지 조건, 전위 파동식과 초기 제약을 구분했다. 회로 보존을 근사 공간장의 인증으로 확대하지 않으며, 코일 전압·유한 면적 평균·식별성과 안정성도 나눠 설명한다. 전송선의 단자 적합과 내부 저장, 정확한 DC와 저주파 평균, 주기 매질의 금지대와 흡수, Bloch 주값과 누적 위상의 구분도 확인했다. 이8단원의 본문 대조가 해당 계산·화면 검증을 대신하지는 않는다.
