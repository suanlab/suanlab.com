# 미시상태에서 국소 질서변수로: 유한 모형 계약

2026-11-11. `microscopic-blocks-and-local-order-parameters`의 수학 계약이다. 수학 기반·한영 원고·독립 계산 Worker·시각화·실제 reader/생산 자산을 검증하여 **603번째 입문 단원으로 등록했다**. 통계장론 원주제 전체는 진행 중이다.

## 근거와 기존 단원과의 차이

[Tong §1.1.1·§1.3](https://davidtong.org/teaching/statistical-field-theory/sfthtml/S1)는 고정 자화의 합을 공간 블록으로 확장하고 연속 장·gradient 전개를 도입한다. 해당 페이지의 §1.3에 표시된 자화 간격과 달리, ±1 스핀 v개의 평균 간격은 직접 계산하면 **2/v**다. 유한 계산은 이 이산 집합을 유지한다.

[Kadanoff 1966, pp.264–265, 식 (4)–(7)](https://doi.org/10.1103/PhysicsPhysiqueFizika.2.263)를 원문 PDF에서 확인했다. 큰 셀·상관 길이의 분리, 셀을 이진 변수로 대체하는 가정, 이웃 셀 상호작용만 유지하는 가정이 있다. 아래 작은 유한 모형은 그 임계 스케일링 주장을 수치 검증하는 실험이 아니다.

기존 `binary-shell-multiplicity-block-counts`는 균일 미시 측도와 고정 전체 개수, `finite-macro-partition-conditional-entropy`는 주어진 확률과 분할을 다룬다. 새 내용은 공간 결합에서 **제한 합을 계산**하고, 숨긴 경계 자유도가 거친 변수 사이 조건부 의존성을 남기는지 검사하는 것이다. 아래 반례와 수식은 이 교재의 독립 유도다.

## 공간과 입력

1/2차원 직사각 격자, 각 축 2 이상, N≤16 스핀, 같은 직사각 블록 B≤4개다. `blockShape`는 각 축 길이를 나누어야 한다. 블록 부피 v=N/B, 가능한 프로필 수 (v+1)^B≤625다. 사이트와 블록은 첫 축이 빠른 순서로 번호를 붙인다.

open은 내부 양의 방향 edge만, periodic은 각 사이트의 양의 방향 edge를 모두 유지한다. 주기 길이2의 평행 edge는 두 개다. 블록 내부 그래프에는 그 블록이 주기 축 전체를 차지할 때 wrap도 포함한다. 고정 외부 스핀은 이번 계산에 없다.

스핀 σ_i=±1, 전체 edge 수 E, 불일치 edge 수 d, 블록 위쪽 스핀 수 k_b, M_b=2k_b−v, m_b=M_b/v다. 에너지는 `Hmicro=−JΣedge σ_iσ_j−Σ_b H_b M_b`이며 자기장은 블록 내부에서 일정하다. `k_B=1`, T>0.

입력은 양의 유리수 `x=exp(−2J/T)`, `y_b=exp(2H_b/T)`다. 각각 분자·분모 1…999999의 십진 정수 문자열을 허용한다. x<1 강자성, x=1 무결합, x>1 반강자성이다. x=0이나 무한 활동도는 지원하지 않는다. 물리 J,H 자체가 유리수라는 뜻은 아니다. x,y 고정 상태로 T를 바꾸는 조작을 고정 Hamiltonian 열 미분으로 해석하지 않는다.

`selectedUpCounts`는 모든 블록의 0…v 정수다. `witnessPair`는 B=1일 때 빈 배열, 그 외 서로 다른 오름차순 두 블록이다. 이는 다른 모든 블록을 선택 프로필에 고정한 조건부 검사다. 전체 자화를 추가 고정하지 않는다.

## 제한 합과 절대 정규화

`Q_k(x)=Σ_d n(k,d)x^d`, `w_k=Q_k(x)Π_b y_b^k_b`, `Zrel=Σ_k w_k`.

미시 측도는 각 스핀 배치를 한 번 세는 counting measure다. 정확한 물리 partition function은

`Zabs=x^(−E/2)Π_b y_b^(−v/2) Zrel`.

반정수 거듭제곱을 유리수로 표시하지 않는다. 대신 `Zabs²=x^(−E)Π y_b^(−v) Zrel²`와 log Z의 정확한 유리수 피연산자를 반환한다. 자유에너지 `F_k/T=−ln w_k+(E/2)ln x+Σ_b(v/2)ln y_b`는 profile counting measure 기준이다. 연속 dm 측도나 그 Jacobian을 몰래 도입하지 않는다.

`P(k)=w_k/Zrel`, `P(σ|k)=x^d/Q_k`. 퇴화도 Ω_k=Σ_d n(k,d)=Π_b binom(v,k_b)는 x=1일 때 제한 합과 같다. 결합이 있으면 같은 프로필의 미시상태도 균일하지 않다.

`S(σ|k)=ln Q_k−〈d〉_k ln x`, `S(σ)=ln Zrel−〈d〉ln x−Σ_b〈k_b〉ln y_b`, `S(σ)=S(k)+Σ_kP(k)S(σ|k)`다. 로그를 정확한 유리수 출력으로 주장하지 않는다. 전체 자화 분포는 프로필을 합쳐서 별도로 만든다.

## 국소 근사의 정확 비교와 조건부 의존성

선택 프로필의 블록 유도 그래프에서 `Q_b(k_b;x)`를 정확 계산한다. 블록 사이 edge의 균일 평균곱 대체는

`dbar=(1/2)Σcross(1−m_bm_c)`, `wref=Π_bQ_b Π_by_b^k_b x^dbar`다.

dbar=a/b를 기약분수로 놓으면 `Rpower=[Q_k/ΠQ_b]^b/x^a`, `ln(w_k/wref)=ln Rpower/b`다. 반환값은 정확한 양의 유리수와 정수 b다. 정규화한 확률의 KL로 표시하지 않으며 잔차의 부호를 일반적으로 제한하지 않는다. 실제 경계 스핀의 조건부 평균을 블록 평균으로 대체하는 단계가 별도 근사이기 때문이다.

평균곱의 에너지는 항등적으로 `−JΣ c_bc m_bm_c=(J/2)Σc_bc(m_b−m_c)²−(J/2)Σ_bdegree_b m_b²`다. 열린 경계에서는 degree_b가 일정하지 않다. 이 항등식이 실제 제한 자유에너지의 gradient 절단을 증명하지 않는다.

두 블록 a,c를 ±v로 고정한 네 corner weight로 `OR=w++w--/(w+-w-+)`를 계산한다. a,c가 거친 그래프에서 비이웃이고 다른 모든 블록 고정 상태에서 OR≠1이면 그 그래프의 양의 이웃 pair-factorization은 불가능하다. 이웃 쌍의 OR≠1에는 이 결론을 내리지 않는다. 하나의 OR=1도 모든 프로필·쌍의 독립성을 증명하지 않는다. 장거리·다체항을 허용한 모형 전체를 부정하지 않는다.

## 필수 수치 예와 독립성

- N4 open, 블록2+2, x=1/2,y=1, k=(1,1): Q=3/4,Zrel=27/4,P=1/9, 조건부 d 평균7/3·분산2/9. 조건부 미시 확률은 1/6 두 개와 1/3 두 개다. `Rpower=9/8,b=2`.
- 같은 전체 자화0 안에서 프로필 (+2,−2),(0,0),(−2,+2)의 조건부 확률은 2/7,3/7,2/7이다. 전체 자화0의 확률은7/27이다.
- N6 open, 블록2+2+2, 가운데 M=0, x=1/2,y=1: 끝 블록 OR=16/25. 이를 periodic 세 블록의 이웃 OR와 혼동하지 않는다.
- N4 open 한 블록, k=3: 조건부 위치별 평균은 (1/3,2/3,2/3,1/3), 블록 평균1/2다. 무자기장 전체 앙상블 평균0과도 다르다.
- N6 open k=(2,1,0): 중앙 미시 평균은 (+3/5,−3/5)지만 중앙 블록 평균0이다.

생산 기반은 Gray-code 단일 스핀 flip으로 incident edge와 개수를 갱신한다. 독립 Python은 짧은 축의 행별 상태를 연결하는 정수 다항식 transfer로 모든 n(k,d)를 만든다. 별도 직접 열거로 선택 프로필의 미시 평균도 대조한다. 1/2차원·전치·주기 길이2·한 블록 wrap·홀수 블록·16스핀·활동도 경계를 포함한다.
