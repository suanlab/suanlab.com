# Euclidean 양자 커널: 유한 모형과 유도식 검산

2026-11-10. 예정 단원 `euclidean-quantum-kernels-and-time-slicing`의 유한 모형을 설계했다. **정확분수1,054검사·93모형**을 통과했다. 아직 원고·생산 계산기·독립 응답 검산·Worker·교재 화면은 없으며598등록 단원·1844안내·1196원고에 포함하지 않는다. 경로적분 원주제도 미완료다.

## 물리 규약과 입력 범위

Hamiltonian은 H=−ℏ²∂²/(2m)+mω²x²/2, kernel은 ⟨b|exp(−τH/ℏ)|a⟩다. m,ℏ,τ는 양수,ω²는0이상이며 각각16이하,|a|,|b|≤16의 유리수를 계획한다. 분자·분모12자리,구간N=2…32와 내부N−1자유도를 유지한다. 입력은 ω가 아닌 ω²이므로 정확한 유리수 모형을 구성할 수 있다. 생산 wire 최대 크기는 이후 별도 검증하며 아직 통과했다고 주장하지 않는다.

δ=τ/N, s=m/(ℏδ),v=ω²δ²라 두고 사다리꼴 potential을 쓴다.

```text
A_N = s/2 Σ(x_k−x_(k−1))²
    + s v/2 [a²/2 + Σinterior x_k² + b²/2]
Q = s(L+vI), f = s(a e_1+b e_(N−1))
c = s(a²+b²)/2 + s v(a²+b²)/4
```

N=2에서는 두 끝 forcing을 같은 내부 노드에 더한다. 공간 고정끝의 마지막 간선을 빠뜨리거나 양끝 potential의 절반 가중치를 내부 가중치로 바꾸지 않는다.

## 정확하게 대조한 식

D₀=1,D₁=2+v,D_k=(2+v)D_(k−1)−D_(k−2)이며 det Q=s^(N−1)D_(N−1)다. i≤j에서 C_ij=D_(i−1)D_(N−1−j)/(sD_(N−1)), μ_i=[aD_(N−1−i)+bD_(i−1)]/D_(N−1)다. 대칭성으로 나머지 C를 채운다.

커널은 √(P/π)exp[−g(a²+b²)+hab]로 표현한다.

```text
P = s/(2D_(N−1))
g = s/2 [1+v/2−D_(N−2)/D_(N−1)]
h = s/D_(N−1)
A_min = c−fᵀQ⁻¹f/2 = g(a²+b²)−hab
```

독립 발생 행렬→Gauss–Jordan 역행렬/행렬식→완전제곱/경로 직접 작용을 위 점화식과 대조했다. 유리수 P는 prefactor의 제곱에서 공통π⁻¹를 제거한 값이다. π·제곱근·지수의 인증 구간을 계산했다는 뜻이 아니다.

ω²>0에서 Z_N²=P/(2g−h)다. 이를 공통 끝점까지 적분하는 주기 사슬의 발생 행렬식으로 독립 검산했다. N=2 주기 사슬은 평행한 두 간선을 더한다. ω²=0에서는2g−h=0이고 무한 직선의 trace가 발산한다. 자유 커널·작용·끝점 적분1을 별도로 검산했다. ω²>0의 끝점 적분은 √(P/g)exp[−a²(g−h²/(4g))]로1이 아니다.

## 시간 분할 비교

θ=2asinh(ωδ/2)라 놓으면 D_(N−1)=sinh(Nθ)/sinhθ다. 연속 기준해는 Mehler 커널이며 유한 격자는 ω_eff=θ/δ,m_eff=m sinhθ/θ의 다른 조화진동자 커널과 일치한다. 원래 m,ω를 바꿔 그린 결과를 원래 물리계의 정확한 유한 해라고 혼동하지 않도록 설명한다.

오른쪽 끝점 potential의 커널은 대칭 커널에 exp[−δ(V(b)−V(a))/(2ℏ)]를 곱한 것이다. 양끝 potential이 같으면 이 차이는 사라져 대각 예제만으로 첫 차수 오차를 확인할 수 없다. 계획한 비대각 예제 m=ℏ=τ=ω²=1,a=1/3,b=4/3에서 N=4…256의 로그 커널 오차를80자리 Decimal로 비교했다. N을 두 배로 할 때 대칭 오차는 약4배,오른쪽 분할 오차는 약2배 감소했다. 이는 이 예제의 수치 관찰이며 인증된 범용 오차 한도가 아니다.
