## 학습 목표와 출처

정상성은 각 상태의 확률 수지이고, 상세평형은 각 상태 쌍의 왕복 흐름 조건이다. 상세평형으로 정상성을 보일 수 있지만, 초기 분포의 수렴은 기약성·주기성 등 추가 조건을 확인해야 한다. 정의와 일반 정리는 저자 공개 교재 [Levin–Peres, 1.5–1.6절·3.2절·4.3절](https://pages.uoregon.edu/dlevin/MARKOV/markovmixing.pdf)을 기준으로 대조한다. 비대칭 제안의 수락 규칙은 같은 교재3.2.2절과 [Hastings (1970)의 공개 PDF](https://hedibert.org/wp-content/uploads/2013/12/1970Hastings.pdf)2.2절의 구성·검사 비율·기약성 확인 조건을 대조한다. 원 논문 전체와 모든 일반화를 검토했다고 주장하지 않는다.

다음 식과 유한 예제는 이 프로젝트의 모형 선택·직접 유도다. 행벡터 관례 `μ(t+1)=μ(t)P`를 고정하고, 화살표 방향과 행·열을 모든 그림·표에서 일치시킨다.

## 1. 정상 흐름과 세 상태 순환

단원 ID: `stationary-flux-three-state-cycle`.

세 상태0,1,2에서 앞으로 p, 뒤로 q, 제자리에 r로 움직인다. 음이 아닌 정수 가중치의 합으로 p+q+r=1을 정확히 만들며 영합은 거부한다. 균일 π=(1/3,1/3,1/3)는 정상이다. 흐름 `Fij=πiPij`, 순흐름 `Jij=Fij−Fji`를 계산하면 각 정점의 발산은0이지만 순환은 `(p−q)/3`일 수 있다.

- 직관: 각 통의 수위가 일정해도 통 사이에 물은 순환할 수 있다.
- 손계산: p=1/2,q=1/4,r=1/4의 각 정방향 순흐름은1/12다. 정상성과 상세평형은 여기서 다르다.
- 그림: 상태 확률 막대, 양방향 흐름·순흐름을 구별한 삼각형, 상태별 유입/유출 표와 `πP−π`.
- 경계: p=q, 한 방향만 존재하는 주기3 순환, 제자리만 있는 항등 전이. 항등 전이에서 균일분포를 하나 제시해도 유일성은 주장하지 않는다.
- 6단계: 전이 행렬 → 한 단계 확률 수지 → 정상 흐름 → 쌍별 순흐름 → 반례 → 초기 분포와 정상성의 구별.

확률 화살표를 실제 분포 진화와 구별한다. 고정 정상 흐름의 장식 이동을 무작위 표본이나 물리적 시간으로 설명하지 않는다. 물리적 열·엔트로피 생산은 국소 상세평형과 저장고 모형을 도입한 뒤에 다룬다.

## 2. 제안 분포와 Hastings 보정

단원 ID: `metropolis-hastings-proposal-balance`.

세 상태에 양의 정수 목표 가중치 wi를 주고 `πi=wi/Σw`로 둔다. 제안 Q는 앞 가족의 비대칭 순환도 허용한다. i≠j에서 수락 후 흐름을 먼저

`πiPij=min(πiQij,πjQji)`

로 구성하고, `Pij`와 거부를 포함한 대각을 계산한다. Qij>0인 제안에서만 `αij=min(1,πjQji/(πiQij))`를 정의한다. 제안 자체가 없으면 수락률은 미제공이며, 역제안만 없으면 수락률은0이다.0/0을 계산하거나 임의의 작은 수로 바꾸지 않는다.

- 직관: 목적지 선호도뿐 아니라 그곳에서 돌아오게 제안할 가능성도 보정한다.
- 기준 반례: 목표(1,2,4), 제안 가중치(앞2,뒤1,제자리1). 비율 `min(1,πj/πi)`만 쓰는 비교 전이는 `πP−π=(0,−1/28,1/28)`을 만든다. 보정 전이는 정확히0이다.
- 그림: 제안·수락 후 전이·거부 대각의 세 표, 양방향 목표 흐름, 보정 유무의 정상성 잔차.
- 경계: 대칭 제안, 균일 목표, 한 방향 제안, 항등 제안. 한 방향 제안에 올바른 보정을 적용하면 전부 거부할 수 있다. 목표 보존과 탐색 성공을 구별한다.
- 6단계: 목표와 제안 → 단순 수락 반례 → 왕복 흐름 최소 → 대각과 거부 → 지지집합 → 보존·기약성·효율의 구별.

실습의 목표 가중치는 모두 양수다. 목표0의 상태와 일반 연속 밀도·기준 측도·Radon–Nikodym 조건은 후속 일반화에서 별도 유도한다. 유한 표의 결과를 연속 공간이나 LLM 샘플러의 정당성으로 확장하지 않는다.

둘째 가족에는 모든 머무름을 삭제한 점프 체인의 관측 시계도 추가했다. 실제 정상분포에 이동 확률을 곱한 법칙을 원래 목표와 비교하며, 없는 이동 사건과 유일하지 않은 정상해를 임의의 분포로 바꾸지 않는다. 정확한 유한 검증을 연구 일반화의 완료와 구별한다.

## 3. 가역 두 상태 체인의 주기성과 수렴

단원 ID: `reversible-two-state-periodicity-mixing`.

`P=[[1−a,a],[b,1−b]]`, 0≤a,b≤1을 정확한 유리수로 지정한다. a+b>0일 때 `π1=a/(a+b)`이고 `π0a=π1b`다. 초기 상태1 확률 u에 대해

`μ1(t)=π1+(u−π1)(1−a−b)^t`,

`TV(μ(t),π)=|u−π1|·|1−a−b|^t`

를 행렬 반복과 독립적으로 비교한다. t는 이산 전이 횟수다. 연속 시간의 발생률이나 관측 개수로 바꾸어 해석하지 않는다.

- 직관: 왕복 흐름이 맞아도 매번 두 방을 교대로 방문하면 초기 분포가 남는다.
- 예제: a=b=1은 상세평형·유일 정상분포를 갖지만 초기 점질량은 진동한다. a=b=1/2는 한 단계 뒤 정상분포다. 작은 전이와 거의 교대하는 전이를 비교한다.
- 경계: a=b=0은 정상분포의 가족이며 선택한 하나의 정상분포·고유 정상값을 만들어내지 않는다. 한쪽 전이만0인 경우는 흡수 상태와 유일 정상분포가 공존할 수 있어 기약성의 충분조건과 필요조건을 구별한다.
- 그림: 현재 분포와 정상분포 막대, 부호 있는 편차, TV 대 전이 횟수, 행렬·닫힌식의 정확한 비교 표.
- 6단계: 왕복 조건 → 정상해 → 닫힌 재귀 → 교대 반례 → 흡수·항등 경계 → 수렴 조건과 속도.

셋째 가족에는 점별 극한과 Cesaro 평균, signed/absolute gap, 정상 지지집합에서만의 반전, 분산0과 정규화 상관 미제공, 최악 초기 거리 기준도 추가했다. 유한 기록 구간에서의 미도달과 주기적 영구 미도달을 구별한다.

TV가0인 점을 로그 축의 작은 양수로 대체하지 않는다. 음의 편차를 지우거나 진동을 단조 곡선으로 평활화하지 않는다. 이 분포 수렴 실습에서 경험적 MCMC 오차나 모든 관측량의 유효 표본 수를 인증하지 않는다.

## 현재 증거와 구현 순서

`python3 scripts/learning/verify-detailed-balance-hand-checks.py`는 Python `Fraction`으로 순환8설정, Hastings25설정, 두 상태24준비의33시점씩 **792비교**를 검사한다. 흐름 수지·상세평형·단순 수락의 반례·유한 분포의 닫힌식을 확인했다. 근거는 `.runtime/learning/detailed-balance-preparation/hand-checks.json`이다. 이 검사는 이상적 유리수 예제이며 미래 TypeScript 구현의 정확성 증거가 아니다.
