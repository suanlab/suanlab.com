# 가중 미시·거시 관측의 계산·한영 본문 기반

2026-11-06. `finite-macro-partition-conditional-entropy`에 검증한 모델과 상세 한영 본문을 갖췄다. 이진 껍질 가족에 이어 두 번째 원고 기반을 검증한 단계다. 잡음 관측 가족과 실제 교육 UI·홈페이지 통합은 남아 있으며 원래 미시·거시 상태 주제는 진행 중이다.

## 본문과 직관

각 언어는15개 절,동일한 display 수식16개,표2개,해설이 있는 연습6개로 구성된다. 영어는2643단어,한국어는 한글5122자다. 파일은 `content/learning/physics-math-for-ai/finite-macro-partition-conditional-entropy.{en,ko}.md`다.

네 상태의6:2:1:1 질량이8:2의 두 관측값으로 모이는 표를 통해 조건부 정규화와 숨은 정보를 추적한다. 같은 관측 확률을 갖는 다른 준비3개를 비교하고, 원래 준비·관측 법칙·군 내부 균등 재구성의 엔트로피를 따로 설명한다. 관측을 세분할 때 드러나는 정보와 실제 준비가 바뀌는 것을 구분한다.

KL을 보존해도 원래 상태를 식별하지 못하는 예제로 비교 보존과 상태 복원을 구분한다. 확률0인 비어 있지 않은 군·빈 선언 군·미정 조건부·지지집합 위반의 무한 KL·수치 표시 범위 밖의 유한 양수를 따로 다룬다. 작은 정보량을 엔트로피 표시값끼리 빼거나0으로 자르지 않는 이유를 극소 거시 KL 예제로 설명한다.

## 검증

실제 `getLearningContent` 로더로 양 언어를 렌더링했다.16개 수식의 일치,KaTeX 오류 부재,고유한 목차와 실제 앵커,키보드로 접근 가능한 수식 영역과 표,두 표,6개 풀이,영어의 한글 부재와 미치환 토큰 부재를 확인했다. 표에는 로더가 tabindex와 접근성 안내를 붙이므로 속성이 없는 `<table>` 문자열만 검사하지 않는다.

내용 검사4개는 실제 모델로 조건부 확률·엔트로피 연쇄·재구성 증가량,동일한 관측의 다른 준비,KL 보존과 상태 식별의 차이,관측 세분화의 정보 이동,0·미정·무한대 예제를 재확인한다. 기존 모델 검사46개와 함께50개가 통과했다. 타입 검사와 대상 lint도 통과했다.

원래 모델 증거의 전체 해시는 집필 진행 기록을 바꾸기 전에 일치함을 확인했다. 모델·검사·4096자리 생성기·독립 참조 자체는 수정하지 않았다. 진행 JSON과 계산 계약 문서는 현재 단계를 반영하므로 이전 증거의 해당 문서 해시는 당시 스냅샷이다. 기존 통합 소스·자산·검사3888개와 정적 출력4236개도 그대로다. 새 미등록 파일이 추가된 것이며 전체 파일 집합의 크기가3888개라는 뜻은 아니다.
