2026-11-13. 기존 두 단원의 한영 전체 원고·기존 해석적 실습을 읽고 보존한다. 기존 특성 전파·유한 창 수지·Taylor–Green 감쇠·실제 셀·RK4·작은 변화 관측은 이미 있는 내용이다. 연구 추가는 별도 경계 문제와 해 사이 오차에 한정한다.

## 아음속 유입 경계와 전체 상태 노름

`linearized-euler-acoustic-characteristics`: 0 < U < c인 고정 구간에서 왼쪽 두 특성·오른쪽 한 특성의 유입을 센다. 접촉 변수 h를 속도 단위로 바꾸고 양의 임의 가중치로 전체 선형 상태 노름을 만든다. 이를 비선형 총에너지나 열역학적 내부 에너지로 주장하지 않는다.

특성 속도의 제곱근으로 음향 노름 유속을 정규화하고 두 끝에서 수축 반사 규칙을 적용한다. 원래 진폭 계수 1이 주입 영을 보장하지 않는 대조, 압력·속도 관측으로 놓치는 접촉 전용 대조를 추가한다. 음속·정지 특성에서는 조건 개수를 다시 센다. 실제 강체벽·장치 수동성·기존 실습의 반사 경계 제어로 확대하지 않는다.

## 기준 감쇠와 오차 성장

`taylor-green-navier-stokes-viscous-decay`: 같은 매개변수의 매끄러운 무외력 주기 해 두 개를 비교한다. 차이 방정식의 대류·압력을 적분하고 배경 대칭 변형률의 부호 없는 교환을 남긴다. 공간 평균 영과 기본 셀의 Poincare 상수로 시간 의존 상한을 구한다. 상한 증가와 실제 오차 증가는 구분한다.

별도 두 모드 발산 영 초기 오차의 Fourier 적분으로 양의 초기 수지를 직접 구성한다. 이후 궤적을 푼 것으로 주장하지 않는다. 진폭 가족 내부의 정확 감쇠 및 Galilean 이동한 해의 보존되는 평균 오차를 비교한다. 평균 영 충분조건을 임계 Reynolds 수나 일반 삼차원 정칙성으로 확대하지 않는다.
