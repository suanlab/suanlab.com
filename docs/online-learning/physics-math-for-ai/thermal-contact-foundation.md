# 유한 열용량 두 물체의 열접촉 기반 구현

최신: [온도·열·일의 홈페이지 입문 통합 검증을 마쳤다](temperature-heat-work-authoring-status.md). 아래는 해당 단계의 기록이며 전체 영역·연구 심화 완료를 뜻하지 않는다.

2026-11-06. 열역학·평형 통계역학 첫 주제의 첫 계산 가족 `finite-body-thermal-contact-heat-entropy`를 구현하고 한영 본문을 작성했다. 아직 교재 등록·실습·그림·개념·안내·퀴즈·홈페이지 통합은 하지 않았다. 기존502단원·1506안내와279입문 검증·83미완료를 유지한다. 이상기체 두 경로는 여전히 초안이다.

## 계산 대상과 물리적 범위

`src/lib/learning-thermal-contact.ts`는 외부 단열·고정 체적·일정 열용량·균일한 내부 온도·선형 열연결을 가정한다. 각 열용량0.5–4 J/K, 초기 절대온도250–350 K, 연결0–2 W/K, 시간0–8 s를 허용한다. 기계적 일·물질 이동·상전이·공간 온도 분포는 포함하지 않는다.

두 상태의 에너지 수지와 온도차 감쇠를 계산한다. `thermalContactState`는 온도·평형 온도·전달률·누적 열·내부 에너지 변화·개별 및 전체 엔트로피 변화·생성률·시간 상수를 제공한다. `thermalContactWindow`는 전진 시간 구간의 전달량과 엔트로피 변화를 직접 계산한다. 양의 전달 방향은 물체1→2다. 단위는 온도K·전달량J·전력W·엔트로피J/K·생성률W/K다.

## 작은 양과 수치 계산

전체 엔트로피 변화는 두 로그의 나쁜 상쇄를 피하기 위해 양의 생성 적분을 사용한다. 유도에서 전달 비율로 바꾼 적분에16점 Gauss–Legendre를 적용한다. 개별 엔트로피는 `log1p`의 비율, 누적 전달은 `expm1`의 비율을 사용한다. 작은 구간에서는 누적값끼리 빼지 않는다.

공급된 이진 입력의 곱·합·유리식을 기존 `learning-binary-products`로 계산한 뒤 관측값으로 투영한다. 지수·로그·수치 적분은 보통 부동소수점 근사다. 임의 정밀도나 모든 가능한 입력의 정확한 마지막 비트를 보장하지 않는다. 관측은 값·부호·로그 크기를 제공하며, 표현 범위 밖의 비영 값은 `null`과 비영 부호로 유지한다. BigInt는 공개 결과로 내보내지 않는다.

K=0은 연결 없음이며 시간 상수 자체가 없다. 매우 작은 양의K에서 시간 상수를 표현할 수 없는 상황과 구별한다. 두 온도의 표시값이 같아져도 모형의 작은 온도차와 흐름을 별도로 유지한다. 내부 에너지의 절대 기준을 임의로 정하지 않고 변화량을 보고한다.

## 독립 근거와 검사

`scripts/learning/generate-thermal-contact-references.py`는 제품을 호출하지 않는다. 실제 온도 변수의2×2 행렬 지수와 상태 엔트로피의 로그로24일반 사례(120자리)·12극한 사례(1000자리)를 계산한다. 일반3사례는 물리적 시간의 열 흐름·생성률 적분도 대조한다. 같은 생성기를 다른 경로에 다시 실행한 결과가 고정 참조와 바이트 단위로 일치한다. 개별 시각과 구간, 영 연결·동일 온도·영 시간·몸체 교환·아주 약한 연결·극소 시간·큰 감쇠·가까운 끝점이 포함된다.

제품 검사는 참조 관측의 값·부호·로그, 에너지 보존·라벨 교환·열용량/연결 스케일·구간 가산성·단조성·표현 범위·입력 거부를 확인했다. 모델50검사와 한영 원고 렌더링1검사, 총51검사를 통과했다. 타입 검사와 새 파일의 lint도 통과했다. 원고의6개 풀이·수식·앵커·스크롤 접근성과 영어의 한글 부재를 확인했다. 이것은 새 그림의 브라우저 검증을 대신하지 않는다.

원고는 `content/learning/physics-math-for-ai/finite-body-thermal-contact-heat-entropy.{ko,en}.md`다. 직관·가정·단위·유도·손계산·구간 변화·작은 양·풀이·AI 검증 연결을 담았다. 근거 기록은 `.runtime/learning/thermal-contact-foundation-verification.json`에 연결한다.
