# 온도·열·일: 두 단원 홈페이지 통합 검증

2026-11-06. 원래 열역학·평형 통계역학의 첫 주제 ‘온도·열·일’을 두 단원으로 작성하고 입문 통합 검증을 마쳤다. 전체 열역학11주제·영역 종합 점검·연구 심화는 미완료다. 다음은 [열역학 법칙](thermodynamic-laws-authoring-plan.md)이다.

## 추가한 내용과 연결

- `finite-body-thermal-contact-heat-entropy`: 두 유한 물체의 온도, 전달률, 에너지·엔트로피와 직접 시간 구간 수지.
- `ideal-gas-two-path-heat-work`: 같은 끝점의 두 실제 p–V 경로, 현재 누적 열·일·내부 에너지·엔트로피, 역경로·같은 엔트로피·작은 열의 대조.

한영 본문4개에 직관·가정·SI 단위·유도·손계산·풀이6개씩과 AI 모형 검증 연결을 담았다. 입력14개·예제30개·고정 개념8단계·안내6개·이해 확인4문제를 연결했다. 실제 모델 값을 사용하는11개 실습 그래프와 값·부호·해당 단위의 로그 크기 표를 제공한다. 역순 시간 구간은 임의로 교환하지 않고 미정 수지와 수정 안내를 표시한다.

도서 → Interactive Book에서 교재로 진입한다. 기존 교재 URL은 유지하고 Online Book 본문에는 진입 카드를 추가하지 않았다. 기존502단원의 순서·메타데이터·안내는 해시로 보존을 확인했다. 로컬은504단원·1512안내가 됐다.

## 계산과 그림의 범위

물리 가정·독립 참조는 [열접촉 기반](thermal-contact-foundation.md)과 [이상기체 기반](ideal-gas-paths-foundation.md)에 있다.36열접촉·45기체 참조와 각 독립 생성기 재실행 근거를 이어받았다. 모델·원고 파일은 해당 기반 검증 이후 바뀌지 않았다.

실습은 외부 단열 집중계 또는 가역 이상기체 경로를 계산한다. 실제 공간 확산·피스톤 동역학·기체 분자 운동을 푼 것은 아니다. 기체의 진행률은 물리적 시간이 아니다. 자동 재생은 조회 시간/경로 위치를 바꾸며 모션 감소·화면 비활성화에서 멈추고 수동 단계는 유지한다.

원본 그림 판독에서 새 영어 안내의 띄어쓰기와 온도·압력·생성률 축의 음수 여백을 개선했다. 공유 그래프에 선택적 세로 범위를 추가했고 다른 그림은 기존 자동 범위를 유지한다. 최종 온도 축은240–360 K, 압력·생성률은 비음 범위를 사용한다. 범위 밖 관측을0으로 채우거나 미정 구간을 연결하지 않는다. 작은 개념 값도 그림 아래 실제 수치로 확인한다.
