# 공진·감쇠 연구 보강 검증

2026-11-12. 파동 영역 첫 두 단원의 한영 원고 네 편에 약한 감쇠/장시간 결합 극한과 흡수의 전체 주파수 적분을 추가·검증했다. 기존 원고·해설 문제·실습 입력을 보존한다. 이번 순차 연구 검토는 **2/18단원**이며 영역 전체 대조나 공개 배포 완료로 집계하지 않는다.

## 원고·직관·그림

- `sinusoidal-forcing-transient-response`: 양의 부족감쇠·정확 공진·영 초기값에서 위치와 속도를 유도한다. 유한 시간의 무감쇠 극한, 고정 감쇠의 안정화, `tau=beta t`를 고정하는 결합 극한을 구분한다. 감쇠 의존 정규화 에너지의 두 반복 극한이 1과 0으로 다른 이유와 전이 곡선 `(1-exp(-tau))²`를 증명한다. 빠른 위상 자체의 수렴을 가정하지 않는다.
- `oscillator-frequency-response-power-resonance`: `exp(+iΩt)`의 허수부 부호와 양의 평균 전력을 연결한다. 역수 치환으로 흡수 가중치 전체 적분 `pi/(2m)`을 증명한다. 약한 감쇠의 점별 극한/약한 극한, 유한 대역의 포착 비율, 생략한 높은 주파수 꼬리를 구분한다. 적분은 같은 힘 진폭의 별도 정상상태 실험이며 주파수를 시간에 따라 훑을 때의 누적 열이 아니다.
- 한영 비교 그림 네 개·각 비교표 하나·Python 셀 하나·해설 연구 질문 세 개를 추가한다. 첫 예제의 100초 조회와 두 번째의 무한 대역은 보충 계산이며 기존 실습 범위 확장이나 새 제어 기능으로 표시하지 않는다. 실제 센서에 이상적 점성 단일 모드 가정을 무한 주파수까지 적용하지 않는다.

## 독립 계산과 보존

`python3 scripts/learning/verify-resonance-research.py --json`은 표준 라이브러리만 사용하며 제품 모듈을 가져오지 않는다. 초기값·방정식 미분 144상태·RK4 600/1,200보 정련 36사례·결합 극한 54상태·장시간 상계 144상태·유한 시간 작은 감쇠 6사례를 대조했다. 전체 적분 45사례는 별도의 `Omega=omega0 tan(z)` 구적을 사용하고, 꼬리 상계 135사례·양의 전력 225상태·유한 구간 적분 정련 8사례를 확인했다. 이 유한 수치 검사와 본문의 극한·적분 증명을 구분한다.

한영 새 표시 수식은 단원별 7개·8개로 같고 Python 네 셀의 출력이 본문 표와 일치했다. 실제 계산 함수의 유한 시간 상태 12개와 평균 전력 25개도 보충식과 일치했다. 기존 본문 네 편은 연구 절만 제거하면 기준 `5628a24`와 바이트가 같고 원래 해설 24개를 포함한다. 다른 파동 원고 32편과 이전 검토 항목 681개도 보존했다. 네 검토 항목을 더해 685개이며 등록은 650단원·1,969안내 그대로다.

선택 **4파일·44테스트**가 통과했다. 기존 검사의 본문 전체 `Answer` 표지 수는 새 연구 답변까지 합산해 두 실패를 냈다. 원래 여섯 번호 문제와 해설은 해당 연습 절에서 엄격하게 확인하고 새 연구 질문 세 개는 별도로 검사하도록 고쳤다. 원본문 전체 해시는 그대로 검증한다. 실패 기록은 최종 통과 근거와 구분해 남긴다.
