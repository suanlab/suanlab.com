# 연속체 종합 점검 2단계 준비

이후 [응력·변형의 수정과 검증](continuum-domain-audit-stage2.md)을 진행했다. 아래는 점검 시작 당시의 재현·준비 기록이다.

2026-11-06. 다음 대상은 `cauchy-traction-stress-balance`, `finite-deformation-small-strain-rotation`, `linearized-euler-acoustic-characteristics`, `taylor-green-navier-stokes-viscous-decay`의4단원·한영8원고·입력50개·예제72개다. 준비와 문제 재현만 진행했으며 이4단원의 영역 종합 점검은 완료되지 않았다.

응력·변형2단원의 한영4원고와 계산 모델은 직접 읽었다. 실제/기준 면적, 압력 유속과 traction의 부호, 전단 접선의 관례, 평면 응력과 삼차원 정수압의 차이, Green/소변형률과 유한 회전, 삼각 인자와 극분해를 구분하는 설명은 유지한다. 유동2단원의 한영4원고·계산·화면은 아직 재점검하지 않았다.

## 먼저 재현한 산술 문제

`affineDeformationState`는 Green 변형률 성분을 일반 수 또는 null로 투영한 후 방향별 이차형식을 구한다. 이 때문에 한 성분이 표현 범위 밖이면 최종 방향 관측은 표현 가능해도 미정으로 전파될 수 있다.

주 신장 둘을1, 회전과 평행 이동을0, 전단 g를 최소 양수의4배, 관측 방향을π/4로 정했다. E22=g²/2는 비영이지만 일반 표시 범위 밖이다. 반면 방향별 Green 변형률 g*n_x*n_y+g²*n_y²/2는 최소 양수의2배로 반올림된다. 현재 제품은 이를 null로 반환한다. 입력 법선 성분을 정확한 이진 유리수로 해석한 독립 Python Fraction 계산과 현재 실행을 `.runtime/learning/continuum-domain-stage2/preliminary-diagnostic.json`에 기록했다. 이 비교는 초기 위치·삼각함수 평가에서 이미 잃은 정보를 복원한다는 주장이 아니다.

또한 대각 응력 diag(최소 양수,0)에서 평균과 반차를 먼저 나누면 둘 다 표현 범위 밖이 되어, 원래 표현 가능한 두 주응력과 주방향까지 미정이 된다. 대각 행렬 자체의 독립 참조는 주응력(최소 양수,0)·주방향0이다. 재현은 같은 폴더의 `principal-stress-diagnostic.json`에 보존했다.

## 이어서 할 작업

1. 성분을 표시하기 전의 완전한 이차형식에서 방향 관측을 계산하고, 방향별 공학 변형률까지 작은 비영 값이 전달되는지 독립 참조와 대조한다. 표시 불가인 E22 자체를0으로 바꾸지 않는다.
2. 한영8원고를 직접 읽고 현재 면적·법선·외력·회전 객관성, 선형 음향의 유효 범위, Taylor–Green의 실제 외력·점성·입자 초기값을 확인한다.
3. 힘·모멘트 면적분과 변형된 선분, 음향 특성·에너지 및 점성 소산의 독립 검사 범위를 점검한다. 공유 해석식의 잔차를 독립 인증으로 부르지 않는다.
4. 수정 후 입력·예제·실제 화면과 선수 흐름을 검증한 뒤에만 점검 행렬의 다음4행을 갱신한다.
