# 장의 에너지·Poynting 흐름의 계산 모델과 상세 한영 원고

2026-11-05 기초 집필 단계의 기록이다. 이후 [홈페이지 통합 검증](poynting-energy-authoring-status.md)을 마쳤으며 아래 미등록 수치는 당시 기준이다.

고정 원통의 원천 일·경계 수지와 양방향 펄스의 에너지·흐름을 집필했다. 계산 모델과 원고 검증 단계이며 화면·조작·안내·퀴즈·등록은 다음 순서다. 등록470개 한영 단원·안내1,410개, 원래263개 입문 검증·99개 미완료를 유지한다. 전자기학은5/10개 입문 주제 검증이며 전체51영역509주제·연구 심화는 미완료다.

## 계산 모형과 수치 계약

순수 모형은 `src/lib/learning-poynting-energy.ts`다. 앞 유도·Gaussian 모형과 일정한 양의 SI 계수를 사용한다. 일반적인 분산·이력·비선형·움직이는 물질의 에너지를 설명하는 모형이 아니다. 국소 밀도 J/m³, 흐름 W/m², 원천 일률 밀도 W/m³, 원통 에너지 J와 일률 W, slab의 면적당 J/m²를 구분한다.

유도 모형은 전기 저장 변화와 J·E, 자기 저장 변화와 Poynting 발산을 따로 계산한다. 필요한 전류를 제거한 대조에서는 실제 전도 전류·총 전류·Ampere 잔차도 바뀐다. 큰 자기 변화율이 작은 전기 결함을 숨기는 SI 예제를 보통 합산·안정 묶음 합산·180자리 기준으로 비교한다. 원통 법선은 바깥쪽이며 위·아래 선속은0이다. 빈 영역의 정확한0과 비영 중간 곱의 표현 손실을 구분한다.

펄스는 실제 E/B로 전기·자기 저장을 계산한다. 안정적인 cB를 사용한 흐름과 직접 제곱 차감의 기준 흐름을 분리한다. 실제 B=0 대조에서는 실제 흐름0을 유지하며 호환 기준 B를 대신 사용하지 않는다. 호환 모형과 B=0 모형의 전체 축 에너지 식도 별도다. 같은 초기 E와 다른 초기 B는 다른 에너지 예산일 수 있다.

에너지0의 비율은 미정이다. 절대 에너지를 표현할 수 없어도 해석적 호환 모형의 비율은 별도로 알려질 수 있으나 관측 수치의 몫이라고 표시하지 않는다. Gaussian의 잃어버린 꼬리를 물리적0으로 채우지 않는다. 전체 축 에너지는 가로 단위 면적당 값이며 전체3차원 에너지는 유한하지 않다.

고정 slab에서는 실제 폭을 유지한 단위 좌표의8점 Gauss 복합 구적을 사용하고 소구간 폭을σ/2 이하로 나눈다. 경계의 제곱 Gaussian 차이는 expm1으로 별도 계산한다. 실제 적분·경계식의 잔차나 공유 도함수는 독립 인증이 아니며 엄밀한 구적 오차 상한도 주장하지 않는다. 정적 E=(0,x,0), B=J=0 반례는 에너지 수지가 맞아도 Faraday가 실패함을 보여준다.

## 실제 검증

전용24개·전체4,050개 테스트와 타입·lint·콘텐츠1,704 URL 검사가 실제 종료 코드0으로 통과했다. 기존470개 단원·안내,42개 실험 그룹461항목 및 상대 순서를 등록 전 canonical 기준으로 보존했다. 실제 콘텐츠 로더로 네 원고의 strict KaTeX, 한영 수식 일치, 고유 목차 앵커·접근 가능한 수식 스크롤·영어 한글 잔존 없음·풀이를 확인했다.

독립 Python 생성기는 제품 코드를 가져오지 않는다. 원천81조건의 실제 E·E/B·B와 E×B, 공간·시간5점 차분, 반지름 부피 구적과 방향 있는 원통 옆면 구적을 비교한다. 펄스54조건의 실제 장 에너지·흐름·국소 차분·slab·전체 축 SciPy 구적을 검사한다.180자리 mpmath로 얇은 slab9조건의 저장·경계 차이, 작은 균형 흐름, 절대 에너지 언더플로3조건과 SI 크기 차이를 비교했다. 기준 생성은 저장 파일과 바이트 단위로 재현됐다.

관측한 국소 원천 차이는2.82×10⁻¹² 이하, 원통 수지 차이는2.13×10⁻¹¹ 이하, 펄스 slab 수지 차이는2.91×10⁻¹² 이하다. 선택한 표본의 결과이며 모든 입력에 대한 엄밀한 상한이 아니다. 이전 홈페이지 소스2,958개와 정적 출력4,155개는 유지했다. 새 원고가 미등록이므로 이번에는 빌드·실제 화면·공개 배포를 수행하지 않았다.
