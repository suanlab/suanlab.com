## 선형 Euler 음향 특성

`linearized-euler-acoustic-characteristics`의 입력은 배경 밀도·음속·유속·비열비, 파수·위상, 오른쪽/왼쪽/접촉 진폭, 현재 시간·관측 위치다. 차원이 다른 입력에는 SI 단위를 붙인다. 음속과 물질 유속을 같은 관측으로 합치지 않는다.

1. 같은 위치축의 밀도·속도·압력 섭동 곡선과 실제 전체값 표를 제공한다. 각 축의 단위를 구분한다.
2. 세 특성 변수와 U+c/U−c/U의 시공간 선을 표시한다. 파봉 궤적을 입자 궤적으로 표시하지 않는다.
3. 고정 구간의 실제 시간 변화 적분과 방향 있는 경계 플럭스를 비교한다. 단위 단면적당 값을 kg으로 바꾸지 않는다.
4. 음향 에너지와 Uq+p′u′ 플럭스를 표시하며 기체의 전체 에너지와 구분한다.
5. 같은 장의 선형·비선형 잔차, 진폭 절반 대조, 안정적 접촉 변수와 반올림 뺄셈을 제공한다. 이차 수렴은 질량·압력 잔차에서 정확하고 원시변수 속도 잔차에서는 작은 진폭 극한임을 설명한다.

고정 개념4단계는 단일 오른쪽 음향, 접촉 모드, U=c의 정지한 왼쪽 특성, 비선형 잔차다. 안내3개는 특성 속도 비교, 압력 없는 밀도 수송, 진폭 세분화로 구성한다. 퀴즈2개는 신호/물질 속도 구별과 선형/비선형 해 구별을 확인한다. 음향 에너지가 언더플로한 비영 파동도 별도 예제로 둔다.

## Taylor–Green 비선형 점성 감쇠

`taylor-green-navier-stokes-viscous-decay`의 입력은 밀도·초기 진폭·파수·동점성계수·압력 기준·깊이·시간, 관측 x/y와 입자 시작점이다. 초기 진폭을 배경 평균 유속으로 표시하지 않는다.

1. 실제 길이2pi/k의 주기 셀에 같은 공간 축척으로 속도 방향·압력·와도를 그린다. 벽 경계로 읽히지 않게 표시한다.
2. 대류, 압력 가속도, 시간 미분과 점성 가속도의 성분을 실제m/s²로 비교한다. 정규화 도식에는 방향 전용 표시를 붙인다.
3. 질량, 운동 에너지J, 소산W와 에너지 변화율을 실제 체적에서 비교한다. 임의 작은 창에는 주기 셀 수지를 그대로 적용하지 않는다.
4. 현재 유선과 시간 의존 RK4 입자 경로를 구분한다. 입자 끝점, 시간 간격 세분화, 좌표 반올림 횟수와 계산 불가 상태를 남긴다.
5. 점성 영, 압력 기준 변경, 같은 장에서 압력 항 누락, expm1 안정적 변화와 반올림 인자 대조를 제공한다.

고정 개념4단계는 대류/압력, 시간/점성, 점성 영 Euler 극한, 작은 비영 감쇠다. 안내3개는 네 가속도 항, 속도/에너지 감쇠율, 입자 시간 진행으로 구성한다. 퀴즈2개는 압력 gauge와 소산의 단위·정의를 확인한다.

## 통합과 완료 판정

새로운 독립 lab 모듈과 figure를 연결하고 기존 실습의 canonical 순서·내용을 보존한다. 각 단원은 기존처럼 고정 개념4단계, 안내3개, 퀴즈2개를 제공한다. 한영·명암·모바일/데스크톱 기본 화면, 모든 예제, 정밀 입력·저장·초기화·퀴즈, 접근성·키보드·원본 그림·경계 상태를 실제 최종 출력에서 검증한다. 이 검증 전에는 등록 단원 수와 원래 주제 검증 수를 올리지 않는다.
