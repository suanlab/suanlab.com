# 유한계와 열역학 극한 사전 검토

2026-11-07. 상세평형의 현재 출력 검증 중 진행한 읽기·독립 계산·수정안 준비다. 응용 소스는 바꾸지 않았으며 열역학 완전 점검 수를 올리지 않는다.

## 본문과 독립 계산

세 가족의 한영 본문6개를 모두 읽고 실제 UI 예제44개를 대조했다.

- 경계·광역성·가법성:12예제의 모든 성장 기록에서 관측량2023개·정확한 구간2023개와 정수 개수860개, 해석적 극한168항목을 독립 계산했다. 작은 기하20개는 좌표와 순서 없는 쌍을 직접 열거했다.
- 공간 밀도·자기평균화:16예제의 관측량7887개·정확한 구간7887개, 분포1269행·사건 포함1269건을 대조했다. 작은 계11개는 이름 붙은 이진 배치를 직접 열거했다. 모든 크기 기록·극한 원자·미제공 상관/등가 수·희귀 사건의 큰 유한 비율을 구별했다.
- 두 배치·분배함수 영점:16예제·95크기 기록의 정확한 관측량8362개와 초월함수 구간606개를 별도260자리 참조로 대조했다. 작은 압력 보정은180/260자리 결과의 안정성도 확인했다. 정확 위상3175개와 근사 좌표6350개를 따로 검사했다. 고정밀 수치 포함 검사는 방향성 산술의 증명을 대체하지 않는다.

합계는44예제·정확한 유리수 관측량18272개·정확한 구간18272개와 초월함수 구간606개다. 근사 로그 대조는 선택한 관측에 한정한다. 수치 모델은 변경하지 않았다.

Campa·Dauxois·Ruffo 원문의 광역성/가법성 절에서 자기 항 관례를 확인했다. 원문의 자기 항 포함 관례와 교재의 자기 쌍 제외 관례가 다르므로 유한 에너지 수치를 그대로 옮기지 않는다. Tong의 인공 분배함수 예시는 독립 배경 인자를 포함하며 교재는 이를 명시적으로 제외한다. 본문의 Cambridge 주소에서는 웹 요청 시간 초과만 확인했으며, 저자 사이트에서 내용을 대조했다.

## 실제 기준 화면과 수정안

현재 영문320px 세 화면에서 정수 원문 검사가 소수 손실을 거부하고 이전 준비를 유지함을 확인했다. 기존 내부 폭560px 가독성 보완은 축 글씨12px, 모식도 설명15px, 모드 그림16px를 유지한다. 이전 보고서도 최소12px로 정확하게 기록했으며16px를 보장했다고 해석하지 않는다.

세 단원 모두 두 번역 끝에 아직 교재·worker·학습 화면이 등록되지 않았다는 과거 문구가 남아 있었다. 수정안에서 이 문구를 현재 구현에 맞추고, 실제 버튼·선택·관측량을 연결하는 비교 표를 추가했다. 공간 크기 단계의 마지막 최대값 제한과 기록 선택·요청 크기의 차이를 명시했다.

전용 SVG 글씨를16px 이상으로 하고 긴 지수 표기 축 눈금의 왼쪽 여백을 늘리는 수정안도 준비했다. 현재 사이트 글꼴/CSS를 이용한 별도 사전 점검에서88개 한영 SSR 렌더링·208개 SVG의 최소 글씨16px와 viewBox 안의 배치를 확인했다. 한영 원고6개는 실제 Markdown 로더로 렌더링해 수식·목차·표와 해설을 확인했다. 이 결과는 초안 점검이며 실제 배포 출력의 접근성·상호작용 검증이 아니다.
