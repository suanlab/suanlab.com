# 유한 시도 분포의 U·S·F 계산 기반

2026-11-06. `finiteTrialThermodynamics(energies, temperature, trialWeights, copies)`를 추가했다. 고정 스펙트럼의 정준 분포와 함께 시도 분포의 평균 에너지·정보 엔트로피·물리 엔트로피·TS·Helmholtz 함수를 반환한다. Feq와 안정적인 양의 차이 F−Feq는 다음 구현 범위다. 전체 가족과 주제는 미완료이며 아직 등록하지 않았다.

## 입력·단위·정규화

미시상태1–32개, 유한 에너지(J), 유한 양의 온도(K)를 사용한다. trialWeights는 음이 아닌 유한 가중치이고 적어도 하나가 양수여야 한다. pᵢ=wᵢ/W, W=Σwᵢ의 정규화는 정확한 이진 유리수로 유지한다. 가중치 합이나 개별 wᵢEᵢ가 숫자 범위를 넘어도 표시 전에 계산을 이어간다.

U=ΣpᵢEᵢ, H=−Σpᵢlnpᵢ, S=kBH, F=U−kBTH이다. U·F·TS는 J, S는 J/K, H는 nat이다. 공급된 binary64 입력에 대한 U와 정규화는 정확한 대수적 연산이며, 로그를 포함한 값은 근사다. kB도 SI 값의 binary64 근삿값을 사용한다.

copies는 음이 아닌 유한 정수다. 독립·동일 분포 복제본과 가법 에너지의 총량을 계산한다. 총량의 인자를 원래 분자에 곱한 뒤 한 번 투영하므로 복제당 underflow한 값이 총량에서는 다시 표현 가능할 수 있다. 반대로 총량도 범위 밖이면 부호와 로그 크기를 보존한다. 상관된 복제본에는 결합분포가 필요하다.

## 극소 확률과 엔트로피

p가1에 가까우면 w ln(W/w)를 직접 계산하지 않는다. t=(W−w)/w에 대해 w ln(1+t)=(W−w)log1p(t)/t를 사용한다. t 자체가 underflow해도 W−w를 정확히 보존하고 이 비율의 극한1을 사용한다. |t|≤1/8을 정확한 유리수 비교로 선택한다.

작은 p의 로그는 반올림된 subnormal 확률에서 다시 구하지 않는다. 원래 비율의 로그를 사용하여 각 엔트로피 기여를 공통 분모 W 위에 합산한다. 확률0의 기여는0이며, 유일하게 점유한 미시상태의 H도 구조적으로0이다. 작은 양의 기여를 임계값으로 삭제하지 않는다.

## 자유에너지의 0 판정

F의 분자는 ΣwᵢEᵢ−kBT·엔트로피분자다. 이미 반올림한 U와 TS를 빼지 않는다. 그래도 로그의 근사 오차는 남는다. `zeroStatus`는 `structural-zero`, `unresolved-transcendental-cancellation`, `not-zero-approximation`을 구분한다. 비영 근삿값도 심한 상쇄에서는 참값의 부호를 보증하지 않는다.

실제 검증 사례에서 두 에너지를 근사 ln2와 정확한 이진 곱의 상위·하위 성분으로 구성하면 생산 F는0이 된다. 독립1000자리 참조는 약−8.19658×10⁻³⁸ J를 준다. 이0은 미해결 상쇄로 표시한다. 반면 확률이 한 에너지0 상태에만 있거나 총 복제 수가0이면 구조적0이다. 향후 UI도 이 상태를 구분해야 한다.

기준을 C만큼 옮기면 복제당 U와 F는 C, 총량은 copies·C만큼 이동한다. H·S와 정준 확률은 유지된다. 이 검증은 입력 이동 자체가 정확히 표현 가능한 사례로 수행했다. 입력 생성에서 잃은 유효 자릿수를 복구했다고 주장하지 않는다.

## 독립 검증과 범위

Fraction의 정확한 정규화·에너지 모멘트와 mpmath의 직접 엔트로피 합으로 일반24개160자리·극한21개1000자리 참조를 만들었다. 극한에는 분자 곱 overflow, 복제당 underflow와 총량 복원, MAX/MIN 혼합, 정확한 에너지 상쇄, 근사 로그의 거짓0 사례가 포함된다. 생성 파일은 독립 재생성과 바이트 단위로 일치했다.

새52검사와 기존 정준 분포·KL·기체·본문 검사를 함께 실행하여216개를 통과했다. 타입 검사와 새 파일의 lint도 통과했다. 한영 본문의 현재 구현 설명을 갱신하고 수식·목차·풀이 렌더링을 재검사했다. 근거는 `.runtime/learning/trial-thermodynamics-verification.json`에 기록했다.

정준 분포는 앞 단계의 고정 Hamiltonian 모듈을 그대로 사용한다. 그러나 표시된 정준 확률을 유한 가중치 KL 함수에 넣어 정확한 항등식이라고 주장하지 않는다. 평형 함수와 양의 차이는 원래 스펙트럼 및 로그 정규화에 직접 연결해야 한다. 그림·입력·개념·안내·퀴즈와 홈페이지 통합도 남아 있다. 연결은 도서 → Interactive Book을 사용한다. 등록507단원·검증281주제·미완료81주제는 그대로다.
