## 학습 경로와 두 계산 가족

기존 functional variation·Euler–Lagrange 단원에서 배운 정류 조건을 복소 상태의 에너지 함수로 연결한다. 정류점은 최솟값과 다르고, 작은 잔차는 바닥 상태라는 증명이 아니라는 두 구별을 먼저 설명한다.

1. `finite-state-rayleigh-energy-variance`: 1…4차원의 일반 복소 Hermitian Hamiltonian과 비영 시험 상태를 받는다. 정규화 에너지, 에너지 분산, 잔차, 전체 고유값과 중복도, 바닥 고유공간의 중첩을 비교한다. 정확 유리수 계산과 인증된 스펙트럼 구간을 분리하고, 단순히 표본화한 곡선의 최소를 전역 최소라고 부르지 않는다.
2. `nonorthogonal-ritz-subspace-certificates`: 같은 유한 Hamiltonian과 전열계수 시험 기저 B를 받아 A=B†HB, S=B†B의 일반화 Ritz 문제를 푼다. 비직교 좌표의 계수 크기와 물리 상태의 확률을 구별한다. rank 결손은 입력 오류로 설명하고, 가까운 선형 종속은 별도의 조건 문제로 표시한다. 중첩 시험 공간의 에너지 개선과 좌표 변경 불변성을 검증한다.

## 본문에서 직접 유도할 내용

- 스펙트럼 가중평균에서 E≥E₀를 증명한다. 등호는 바닥 고유공간 전체에 대한 조건이며 축퇴 때 특정 벡터 하나로 제한하지 않는다.
- 정규화 복소 방향 변화에서 δE=2 Re〈δψ,(H−E)ψ〉를 유도한다. 위상·크기 방향과 물리적인 접선 방향을 구별한다.
- 정규화 상태의 ||(H−E)ψ||²=Var(H)를 증명하고, 잔차가 작아도 들뜬 고유상태일 수 있는 반례를 제시한다.
- 알려진 양의 gap이 있을 때만 바닥 고유공간의 누출에 대한 에너지 기반 상한을 쓴다. 바닥 에너지 추정치·정확값·gap 하한을 혼용하지 않는다.
- B의 열독립성에서 S의 양의 정부호성과 Ac=ESc를 유도한다. Galerkin 직교 조건 B†r=0과 전체 잔차 r=0을 구별한다.
- 시험 공간 포함에 따른 최소 Ritz 에너지의 단조성과 min–max 들뜬 상태 상한을 설명한다. 비포함 공간·근사 직교 제약에는 같은 단조성을 주장하지 않는다.
- Hamiltonian의 자기수반성·하한·정의역과 경계 조건을 다룬다. 유한 행렬 계산을 연속 Hamiltonian에 대한 무조건적인 오차 인증으로 확대하지 않는다.
- Gaussian 조화 진동자 시험 함수의 정규화·운동/위치 에너지·길이 차원·정확 최소를 손으로 계산한다. VQE·신경망 파동함수에는 ansatz 편향·표본 오차·최적화 실패를 각각 연결한다.

## 실험과 검증 계약

두 가족 각각 한영 상세 원고, 풀이가 있는 문제, 개념3단계·예측·안내·퀴즈와 의미 있는 자유 입력을 준비한다. 첫 실험은 바닥/들뜬 상태의 동일한 영분산을 비교한다. 다음은 Hamiltonian을 고정하고 시험 공간을 넓힌다. 세 번째는 같은 공간의 비직교 좌표만 바꿔 물리 결과의 불변성을 확인한다. 에너지 곡선·스펙트럼·잔차/누출·시험 공간 그림은 기존 홈페이지 색과 모션 정책을 따른다.

수치 구현 전에 유계 입력·소유 필드·차원·복소 켤레·rank·중복 고유값·null·정밀도 계약을 확정한다. 독립 유리수/고정밀 기준은 복소 위상, 이동/스케일, 축퇴, 잘못된 gap 추론, 영이 아닌 미소 잔차, 비직교 기저 변경, 거의 종속·정확 종속, 중첩/비중첩 공간을 포함한다. Worker 취소·이전 응답 차단·저장 복원 후 실제 한영·명암·모바일·접근성과 정적 출력을 검증한다. 진입은 **도서 → Interactive Book**으로 유지한다.
