## 공간 크기 탐색과 표지

한 단계는 같은 준비의 공간 배율 또는 자리 수를 두 배로 늘린다. 마지막 단계에서 선언한 최대 크기에 멈추고, 끝에서 자동 순회를 시작하면 크기1로 돌아간다. 이 동작은 입력 오류의 자동 절단과 다르며 화면에 설명한다. 시간 진화·물리적 프레임 간격·무작위 경로를 주장하지 않는다.

자동 진행은 현재 계산이 끝난 뒤에만 다음 크기를 요청한다. 사이트 모션 중지·화면 밖·축소 모션·입력/결과 조작 포커스에서는 순회를 멈추고 수동 조작을 유지한다. 계산 오류도 자동 진행을 멈춘다.

`finite-size-cover.tsx`의 고정 장식 예제는12자리 접합 격자의 세 에너지,4자리 공간 혼합 확률 장부,4차 단위원 근과 공존점 보정이다. 저장된 실습과 독립적이며 장식 SVG는 aria-hidden이다. 기존 색상 변수·typography·`ai-*` 스타일을 재사용했다.
