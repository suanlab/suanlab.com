# Quantum circuit·channel: Worker display observations

2026-11-09. [정확 표시 산술](quantum-qubit-display-status.md)을 실제 계산·독립 검증 Worker와 컨트롤러 응답에 연결했다. **수치 학습 UI·Three.js·실제 reader 연결은 아직 남아 있으며 등록0/4이다.**

## 실제 응답에 포함한 값

성공 응답은 기존 정확 `result`와 필수 `observations`를 함께 전달한다. `coordinates`는 보고서의 구조를 유지하면서 복소 스칼라를 실수/허수 좌표 구간·정확 부호·격자점 일치 정보로 바꾼다. ±1 범위 밖 성분의 좌표는 `null`이다. 원래 정확 값은 유지하며, 근사 좌표를 물리 조건 판정에 사용하지 않는다.

`states`는 행렬 크기가 아닌 명시적인 역할로 구성한다. 각 항목은 정확 행렬·행렬 성분의 표시 구간·유효한 밀도행렬에 한정한 순도와 단일 큐비트 Bloch를 포함한다.

- 채널: 입력·출력·Bell 출력·참조 주변 상태. 전치의 단독 출력과 비물리적 Bell 출력을 구별한다.
- 환경: 입력·결합·계·환경·참조 출력/주변 상태. 결합 상태에 단일 Bloch 벡터를 붙이지 않는다.
- Instrument: 기록을 잊은 보정 전 상태, 결과1에 조건부 X를 적용한 보정 후 상태, 전/후 조건부 갈래와 고전–양자 상태. 확률0 갈래는 전/후 모두 `null`이다. 묶인 결과의 혼합 조건부 상태도 유지한다.
- Deferred: 결맞는/탈위상 결합 상태와 각각의 계·기록 주변 상태, 기록–계 표현과 고전 보정 결과. 기록의 Y 성분이1에서0으로 바뀌는 것을 따로 관찰할 수 있다.

회로는 기존 단계별 정확 순도·축약 Bloch·확률·Pauli/연결 상관에 표시 구간을 대응시킨다. 아직 입력 좌표를 애니메이션 장면에 적용하는 UI는 없다.

## 독립 검증과 전달

검증 Worker는 먼저 기존 정확 보고서를 검증한 뒤 모든 좌표의 구간·부호·범위와 역할별 상태를 확인한다. 새 상태의 X 보정은 지표 치환으로, 고전–양자 상태는 블록 배치로, 탈위상 주변 상태는 직접 지표 합으로 계산해 제품의 행렬 곱/partial trace 구현과 구별했다. 생산 관측값·순도·Bloch·행렬 좌표는 별도 검증기를 통과해야 한다.

기존 컨트롤러가 검증 receipt의 응답만 소유권 복사하여 전달한다. 계산 Worker의 원시 성공 응답은 공개하지 않는다. 응답의 노드/깊이/문자 예산과 기본30초 제한은 늘리지 않았다. main-thread 컨트롤러 번들에는 산술·표시 계산기가 없고, 검증 번들에는 제품 관측값 생산기가 없음을 의존성 해시로 확인했다.
