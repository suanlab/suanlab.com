## 계산과 시각 표현

각 가족에16개의 한영 예제를 작성했다. 순수 가족은 복소 곱/Bell 위상, 최대 얽힘 qutrit/ququart, 비균등·반복·가까운 Schmidt 가중치, 직사각형/1차원 부분계, 혼합 여공간 조건부와 확률0을 포함한다. 혼합 가족은 같은 marginal의 세 광원, Werner의 두 문턱, 선택 설정과 최적값의 차이, 얽힌 정확 CHSH 경계와 유효 perturbation, 복소 일반·분리 혼합과 작은 비영 고유값을 포함한다.

진폭 그림은 정규화된 실수/허수 성분을 공통 길이 눈금에 그린다. 기저 확률은 Worker가 계산한 크기 제곱이며 모양으로 얽힘을 판정하지 않는다. Schmidt 막대는 서로 다른 가중치와 중복도를 묶고, 일반 기저벡터를 구했다고 표시하지 않는다. 부분전치 ±항·영 중복도와 근의 중복도를 구분한다.

혼합 화면의 A/B Three.js Bloch 공은 축약 상태만 그린다. 입자의 위치나 얽힘 자체가 아니며 벡터를 길이1로 보정하지 않는다. WebGL 실패 시 같은 좌표의2D 투영을 제공하고 재시도한다. Pauli 상관·부분전치·선택 S·최적 Smax·정확 shifted-K 인증을 따로 보여준다. PPT 충분성은2×2에만 적용하고 최적 측정축이나 분리 분해를 구성했다고 표시하지 않는다.

계산된 Q의 machine projection이 null/비유한/미해결이면 해당 좌표를 그리지 않고 —로 표시한다. 확률0의 조건부 상태는 null이며 대체 상태를 만들지 않는다. 모든 정확/구간 근거는20개씩 펼쳐 읽을 수 있고, 근거 페이지 이동으로 Worker 계산을 다시 시작하지 않는다.

## 조작·모션·저장

고정 개념3단계는 저장된 자유 실험과 독립적인 입력들을 Worker로 차례대로 계산한다. 각 단계에 예측·비교 행동·해설을 두고, 가족마다3개 안내 실험과3개 퀴즈를 제공한다. 자유 실험은50/32개의 모든 정수 필드와 전체 JSON을 편집할 수 있다. 잘못된 정수·차원·PSD 입력은 이전 준비를 보존하며 오류를 설명한다.

새 차원 버튼은 선택한1…4차원 쌍에 |0⟩⊗|0⟩를 새로 만든다. 기존 상태를 조용히 자르지 않는다. Werner 생성은 p=k/100의 새 singlet/I4 혼합으로 전체 상태를 바꾸고 네 설정을 유지한다고 명시한다. 일반 상태의 숨은 p를 추정하는 슬라이더로 표시하지 않는다.

재생은 이미 계산한 Schmidt 행 또는 공동 설정 쌍의 읽기 포커스만 이동한다. 물리 시간·상태 보간·연속 측정이 아니다. Site motion pause·reduced motion·offscreen·visibilitychange에서 중지하며, 감소 설정에서도 수동 선택은 가능하다. 저장은 복원 후에 쓰고 다른 가족·잘못된 version/정수 입력을 거부한다. 저장소 차단 시 현재 방문에서만 유지한다.
