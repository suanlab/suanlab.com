# 미시·거시 상태 세 가족의 읽기 화면 통합 계약

2026-11-06. 세 모델과 상세 한영 본문의 기반을 실제 교육 UI로 연결하는 다음 작업이다. 이 문서는 구현·등록 완료의 증거가 아니다. 단원 수와 원래 주제 완료 수는 실제 경로 검증 후 갱신한다.

## 화면과 표시 원칙

기존 홈페이지의 CSS 색 변수·명암·폰트와 학습 실험 패널을 따른다. 원래 준비·관측·재구성 또는 사후를 같은 색 막대의 이름만 바꿔 보여주지 않는다. 각 도표에 대상 공간·분모·단위와 실제 입력 조건을 쓴다. 숫자0,정의되지 않은 조건부,표시 범위 밖 양수,수학적 무한대를 각각 설명한다.

비교 프레임의 재생은 서로 다른 준비/제약/장치의 비교다. 동역학을 정의하지 않았으므로 물리 시간·입자 이동·단조 엔트로피 증가로 설명하지 않는다. 기존 전역 모션 일시정지·감소된 모션·화면 밖 정지·수동 이동을 따른다. 모델의 최종 결과만 그림·요약·표에 동시에 반영한다.

## 가족 1: 이진 껍질과 블록

입력은 N,K,블록 A의 자리 수,양의 에너지 간격이다. N이나 블록을 바꿀 때 범위를 벗어난 K/블록 값은 명시된 제어 규칙으로 함께 조정하고 저장 데이터도 검증한다. 에너지 간격은 계수·준비 확률을 바꾸지 않는 별도 척도다.

작은N의 이름 붙은 비트열,전체 껍질의 계수/확률 막대,선택 껍질 안의 블록 여기 수를 연결한다. 큰N은 전체 비트열을 전수 렌더링하지 않고 정확한 계수 문자열·요약·표를 사용한다. 극소 확률은 로그 증거를 함께 제공한다.

개념4단계는 배치→계수→두 준비의 세 확률→블록 조건부다. 안내3개는 N=4,K=2의1/16·6/16·1/6 비교,블록1·4·1 및 분산1/3,희귀 K=0의 확률과 엔트로피 구분이다. 퀴즈2개는 높은 거시 막대가 특정 미시상태를 더 자주 만드는지,상호작용 없이 조건부 의존이 생길 수 있는지 묻는다.

## 가족 2: 가중 분할과 균등 재구성

기본 네 상태의 준비 가중치와 목표 가중치,분할(쌍/개별/한 군/세분화)을 조작한다. 모든 가중치가0인 입력은 분포가 아니므로 설명과 함께 거부한다. 지지집합0을 작은 양수로 대체하지 않는다. 선언된 빈 군과 질량0인 군을 구별한다.

네 상태→군 질량→실제 조건부와 균등 재구성의 차이를 보여준다. H(X),H(M),H(X|M),H(pbar),증가량을 각각 표시하고 미시·거시·숨은 KL은 다른 비교 패널에 둔다. 분해가 미정이면 무한대끼리 빼지 않는다.

개념4단계는 가중 준비→조건부 정규화→연쇄법칙→별도의 재구성이다. 안내3개는6:2:1:1과8:0:1:1의 같은 관측,같은 군 조건부를 가진 두 준비의 KL 보존,숨겨지거나 드러나는 지지집합 불일치다. 퀴즈2개는 같은 histogram의 미시분포 식별 가능성,KL 보존과 상태 식별의 차이를 묻는다.

## 가족 3: 잡음 채널과 사후

기본 모드는 가역 관측·대칭 오류·독립 잡음·표시되는 지워짐·결정론적 군 관측이다. 기본 손계산의 준비·행은 정수 가중치로 표현한다. 오류/지워짐 제어는0과1의 경계를 포함하며 대칭 오류율1의 가역 반전을 누락하지 않는다. 일반 유한 행 입력도 모델 계약에 맞게 검증한다.

채널 표와 결합 표를 구분하고,선택 입력의 행과 선택 출력의 사후 열을 연결한다. H(Y|X)는 장치 잡음,H(X|Y)는 남은 입력 불확실성으로 표시한다. 출력 엔트로피와 상호정보량을 다른 값으로 제시한다.

개념4단계는 준비/장치→결합→출력→사후/MI다. 안내3개는 대칭.1 오류의 결합 표,사전3:1에서 반대 방향 조건부 구별,지워짐1/4의 식별/미정 관측 비교다. 퀴즈2개는 독립 램프의 높은 엔트로피가 정보를 뜻하는지,언제나 뒤집는 센서가 정보를 잃는지 묻는다.

## 계산 작업 스레드

16×16 극한 입력은 현재 약8초의 진단 사례가 있으므로 브라우저 메인 스레드에서 직접 계산하지 않는다. 세 모델의 순수 입력/결과와 요청 식별자를 직렬화 가능한 프로토콜로 정의하고 작업 스레드에서 평가한다. 정적 export에서 worker 자산 경로가 실제로 로드되는지 확인한다.

조작 중 새 요청은 이전 결과를 덮어쓰지 못해야 한다. 긴 계산을 중단하거나 새 요청을 우선할 수 있는 수명 주기를 정하고,입력 변경을 적절히 모아 불필요한 작업을 줄인다. 해제된 화면의 worker와 이벤트를 정리한다. 저장·재생·재설정·다른 단원 이동에도 이전 요청의 결과가 새 상태로 들어오지 않아야 한다.

계산 중에는 마지막 결과를 새 입력의 결과인 것처럼 표시하지 않는다. 진행 상태와 최신 결과의 조건을 구분한다. worker 사용 실패는 친절한 재시도/읽기 안내를 제공하며,무거운 계산을 조용히 동기 실행하는 fallback을 만들지 않는다. 요청·오류의 검증과 UI 반응성 검사는 별도로 수행한다.

## 통합 완료 기준

세 단원마다4개 개념·3개 안내·2개 질문,각각의 대표 그림과 조작을 실제 읽기 화면에 연결한다. 기존509단원·1527안내의 내용과 순서를 보존한 상태에서 등록한다. Book→Interactive Book의 메뉴·목차·breadcrumb·검색·sitemap을 확인하고 Online Book 목록에는 새 진입 링크를 넣지 않는다.

전체 검사·콘텐츠 검증·빌드·정적 출력 뒤 실제 페이지에서 한영·명암·모바일/데스크톱·저장/재로드·모션·키보드·접근성·도표 범위를 검증한다. 특히 긴 계산 중 클릭·언어/메뉴 전환과 새 요청이 응답하고,이전 결과가 늦게 도착해 새 상태를 덮지 않는지 확인한다. 이때만 미시·거시 상태의 원래 주제 완료 수를 올린다. 연속 측도·상호작용·양자 통계·열역학 극한과 전체 연구 깊이의 후속 범위는 별도로 계속한다.
