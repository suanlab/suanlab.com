## 보존 운동량을 고정하는 Routh 축약

`routh-cyclic-momentum-reduction`은 방사·순환 각도 Lagrangian에 속도 선형 결합 beta를 포함한다. 정준 각운동량 ell과 기계적 각운동량, 부분 Legendre 변환 `R=L−ell omega`, L에 바로 대입한 잘못된 방사 힘을 비교한다. gyroscopic 계수의 단위와 시간 진화가 아닌 반지름 프로파일의 의미를 명시한다.

같은 한 점에서 올바른 두 힘이 일치해도 힘의 기울기와 에너지 변화율은 다른 사례, 정준 운동량0에서 회전하는 사례, 특별히 고정 속도 모델과 일치하는 극한, 원점의 비가역 각도 Legendre 사상을 다룬다. 외부 모터가 각속도를 고정하는 별도 문제의 토크·일률·Jacobi 보존량을 구분한다. 원래 방정식·재구성·에너지·모터 일 균형은 정확 유리수다.

정규 영역의 위상 차원4→운동량 수준3→대칭 몫2를 구분한다. 반지름0의 조회 상태·차원은 미정이며 양의 첫 그림 표본이나 작은 분모로 대신하지 않는다. 기존 중심력 유효 퍼텐셜의 이름만 바꾼 단원이 아니다.

## Dirac bracket과 실제 축약 위상 차원

`circle-dirac-constraint-geometry`는 위치·접선 운동량의 제2종 구속 쌍을 독립 상태에서 미분한다. `D=J−JGᵀC⁻¹GJ`로 행렬을 직접 만들고 구속 소거·두 투영자·계수·Hamiltonian 벡터장·국소 각도와 운동량 bracket을 계산한다.

원래 정준 자유 벡터장이 순간 접선 조건을 만족해도 이차 구속을 벗어나는 사례, 두 구속의 변화율0이 잘못된 초기 구속값을0으로 수정하지는 않는 사례, 에너지와 각운동량 보존의 차이, 주값 각도 절단과 원점 역행렬 특이성의 차이를 다룬다. 물리적인 영구속면에서만 반력·반력 일률·축약 에너지를 보고한다. 면 밖에서는 정규 잎 차원2와 물리적 상태의 부적합을 별도로 표시한다.

행렬의 q-q·q-p·p-p 블록, 구속 행렬·역행렬·기울기·위상 투영자의 서로 다른 단위를 노출한다. 하나의 Euclidean 노름으로 다른 단위를 합산하지 않는다. 작은 epsilon이나 목표 반지름으로 실제 특이한 역행렬을 대체하지 않는다. 수치 삼각함수 기준 원·주값 각도는 구조 판정과 분리한다.

## 독립 검증과 원문 확인

- 생성기 `scripts/learning/generate-constraints-reduction-references.py`는 제품 코드를 가져오지 않는다. 독립 속도 역변환·부분 미분으로 Routh220사례, 일반 상태 구속 역행렬·Dirac 구성으로240사례를 만든다.
- 실제 구속값을 대입하기 전에 기호적으로 네 좌표 Jacobi 삼중항 전체, Casimir 소거, 투영자·에너지·토크 항등식을 검사한다. 숫자 몇 개의 일치를 일반 증명으로 취급하지 않는다.
- 원고는 언어별 각15개 절, 직접 계산한 예제와 각6개 해설 문제를 포함한다. 엄격 KaTeX·한영 목차·영어 혼입·정확한 수치 예제와 특이 경계를 검사한다.
- Routh 읽을거리는 Langerock·Cantrijn·Vankerschaver의 정리1, Tong의 직접 대입 부호 주의다. Dirac 구성은 Dolan의 정의(12)를 따르며 성분 부호·정규화는 정의에서 직접 유도해 Kleinert·Shabanov 식(5)–(9)와 교차 확인했다. 원문 내부 표기를 그대로 복사하지 않고 안쪽 힘·Casimir·Jacobi로 검산했다.
