# 관측량 보정·무교란·반복성 자료 대조

2026-11-13. [기존 관측·연산자 자료 대조](quantum-observables-source-audit.md)의 C²/C³ 규약을 유지한다. 아래 원문을 열어 유한 사영 측정의 가정을 대조했다.

- [Preskill §2.1, 식 2.4–2.9](https://www.preskill.caltech.edu/ph219/chap2_15.pdf): 서로 다른 고유값에 연결된 사영, 확률, 조건부 사영과 반복 측정. ε=0에서는 스펙트럼 사영을 I로 합친다. 영점에서도 계산 기저를 구별하면 별도 세분화 도구다.
- [Busch·Singh, Lüders theorem for unsharp quantum measurements](https://arxiv.org/pdf/1304.0054): 도입부 식 1.1–1.2의 coarse Lüders 갱신과 모든 상태에서의 기대값 무교란/가환성. 이번 원고는 유한 sharp 사영 경우만 블록 행렬로 직접 증명한다. 논문의 추가 unsharp 결과를 임의 도구에 적용하지 않는다.

평균·표준편차·정렬 고유값의 연산자 노름 보정 경계는 Cauchy–Schwarz·역삼각부등식·유한 최소–최대 원리로 직접 유도한다. 작은 간격의 이상적 스펙트럼 도구 불연속은 특정 모델의 반례이며 실제 검출기의 불연속이나 일반 행렬 함수의 operator Lipschitz 성질을 주장하지 않는다.

C³의 아홉 준비는 Hermitian 교란 행렬의 대각·실수부·허수부를 복원한다. 정확한 모집단 값에 대한 유한 대조이며 유한 시행 신뢰구간이나 미지 상태의 단일 복사본 tomography가 아니다. 내부 위상 회전 도구는 분기 행렬의 완전성과 올바른 고유공간 출력을 직접 확인한다. 반복성·순수성·특정 상태 보존을 구별한다.

기존 reader의 coarse/fine·순서·준비 조작은 보존한다. 연속적인 내부 unitary나 실제 분해능 검출기를 새로 구현했다고 표시하지 않는다. 원문 문장·그림을 복제하지 않고, 독립 행렬 곱·고유값·정확 유리수 검산으로 예제를 확인한다.
