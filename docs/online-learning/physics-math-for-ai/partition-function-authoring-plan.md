# 분배함수 주제의 다음 작성 계약

현재 갱신: [실제 교재 입문 통합 검증](partition-function-authoring-status.md)을 마쳤다. 아래는 해당 준비·모델·분리 화면 단계의 계약과 당시 검증 기록이다.

2026-11-07. 앙상블의 실제 읽기 화면 검증과 별개로 준비한 다음 주제 설계다. 첫 가족의 [모델·한영 원고 검증](partition-cumulant-foundation.md)과 두 번째 가족의 [결합 이진계 모델·한영 원고 검증](coupled-partition-foundation.md)을 마쳤다. 세 번째 가족의 [무한 사다리 모델·한영 원고 검증](energy-ladder-foundation.md)도 마쳤다. 세 가족의 [실험·worker·고정 그림](partition-function-teaching-components.md)은 별도 브라우저에서 검증했다. 상세 단계 설명·퀴즈·교재 등록과 실제 읽기 검증은 아직 남아 있으며 원래 주제 완료 수에 포함하지 않는다. 주차나 총 분량의 상한을 두지 않는다.

분배함수를 정규화 상수로 정의한 뒤 독립 부분계의 곱셈과 에너지 평균·분산의 생성 관계를 연결한다. 출발 참고는 [David Tong의 Statistical Physics, §§1.3.1–1.3.2](https://davidtong.org/pdfs/teaching/statistical-physics/statphys1.pdf#page=24)다. 아래의 세 실험 가족과 경계 사례는 이 교재를 위한 구현 계획이다.

## 1. 유한 준위의 정규화와 cumulant 생성

예정 ID: `finite-spectrum-partition-cumulant-generators`.

- 유한한 명시적 미시상태에서 `Z=Σexp(−βE)`와 `ln Z`를 구별한다. 미시상태를 반복해 적은 퇴화와 별도 다중도를 이중 계수하지 않는다.
- 고정 Hamiltonian에서 `−∂β ln Z=U`, `∂β² ln Z=Var(E)`, 고차 cumulant의 부호와 단위를 유도한다. 온도 의존 에너지 준위를 미분하면서 같은 식을 무조건 적용하지 않는다.
- 기준점 이동 `E→E+c`는 p·분산·S·C를 보존하지만 U와 F를 c만큼 이동시킨다. 입력 전에 소실된 작은 간격을 큰 오프셋에서 복구한다고 표현하지 않는다. 오프셋과 간격을 별도 입력으로 유지하는 방식을 검토한다.
- 기준 예제는 준위 `(0,ε,2ε)`, `ε/(kBT)=ln2`: 이상적 가중치 `(1,1/2,1/4)`, `Z=7/4`, `p=(4,2,1)/7`, `E[K]=4/7`, `Var(K)=26/49`다. 실제 binary64 입력과 이상적 대수값의 작은 차이는 독립 고정밀 기준으로 확인한다.
- 간격0의 세 배치, 음의 온도의 유한 유계 스펙트럼, 확률의 선형 범위 밖에서도 남는 물리적 모멘트, 숫자로 표현되지 않는 Z와 표현 가능한 ln Z를 포함한다.

## 2. 곱 분해의 조건과 상호작용

예정 ID: `coupled-binary-sites-partition-factorization`.

두 이름 붙은 이진 스핀 `σ1,σ2∈{−1,+1}`과 `E=−Jσ1σ2−h(σ1+σ2)`를 네 배치로 직접 열거한다. `J=0`인 전체 곱 상태공간에서 Z의 곱과 p의 독립성을 확인하고, 상호작용 J 또는 상태공간 제약을 각각 바꾼다.

- `J/(kBT)=ln2,h=0`의 이상적 값은 `Z=5`, 정렬 배치 각각2/5, 반정렬 배치 각각1/10, 상관3/5다. 평균 스핀0이 독립성을 의미하지 않는다.
- `J=0`이어도 `σ1+σ2=0`만 허용하면 두 배치만 남아 `Z=2`다. 곱 분해에는 에너지 가법성 외에 곱 상태공간도 필요함을 설명한다.
- 두 결합 변수에 대한 `ln Z`의 Hessian과 feature covariance를 연결한다. 분배함수의 곱 분해 오차와 상호정보량을 같은 수치라고 주장하지 않는다.
- 구조적 영 공분산, 양의 상관·음의 상관, 편향된 주변분포, 실제 금지 배치와 극히 드문 양의 배치를 구별한다. signed covariance를 임의의 epsilon으로0 처리하지 않는다.

## 3. 무한 에너지 사다리와 절단의 정규화

예정 ID: `infinite-energy-ladder-normalization-cutoff`.

상태 `n=0,1,…`와 주어진 준위 `E_n=ε(n+1/2)`를 가정한다. 이 단원에서 양자화 자체를 유도했다고 주장하지 않는다. `ε>0,T>0`의 등비급수에서 무한 Z와 절단 `0≤n≤L`의 Z·평균·분산을 각각 구한다.

- `q=exp(−ε/(kBT))`, 무한 `Z=exp(−x/2)/(1−exp(−x))`, 절단 밖의 정규화 질량 `q^(L+1)`을 유도한다. 유한 목록의 합이1이라는 이유로 무한 계의 오차가0이라고 하지 않는다.
- ε=0 또는 음의 온도에서 유한 절단은 정규화되더라도 동일한 무한 사다리는 정규화되지 않는 경계를 설명한다. 비정규화 상태를 임의의 확률분포로 대체하지 않는다.
- `q`가 표시상1로 반올림되어도 `1−q=0`으로 계산하지 않는다. `expm1`·작은 x 전개와 정확한 입력 비를 검토한다. 표시 범위 밖의 평균 점유와 표현 가능한 에너지·열용량을 분리한다.
- 높은 온도와 절단 제거의 순서가 관측량에 미치는 차이를 비교한다. 상태 수 절단의 제거를 입자 수·부피의 열역학 극한과 동일시하지 않는다.

## 작성·검증 순서

각 가족은 이론·가정·직관·손계산·반례·AI의 log-normalizer 연결·해설 연습을 갖춘 한영 원고를 작성한다. 분배함수로부터 정적 분포를 얻는 것과 표본추출 또는 혼합 속도를 구하는 것은 구별한다. 정규화 불가·미정·수학적 발산·유한 양수의 표시 범위 초과는 서로 다른 상태로 제공한다.

1. 기존 finite-spectrum·binary product·interval 모듈을 먼저 검토하고 재사용 가능한 수학 계약을 정한다. 데이터→페이지 의존 방향과 무거운 계산의 worker 격리를 유지한다.
2. 작은 상태의 독립 열거, 실제 이진 입력에 대한 고정밀 기준, 구조적 불변량·단위·정규화·응답 관계를 확인한다. 유한 차분은 여러 간격의 관찰 오차를 기록하며 독립적인 증명으로 사용하지 않는다.
3. 상세 한영 원고 → 실제 시각화와 안내 → 설명에 대응하는 고정 개념도 → 해설 퀴즈 순서로 작성한다. 존재하는 섹션 수나 카탈로그 링크만으로 완료로 세지 않는다.
4. 기존515개 단원과1545개 안내의 내용·순서를 먼저 보존하고 등록한다. 한영·명암·모바일·접근성·수치 상태·오류 복구와 실제 정적 읽기 화면을 확인한 뒤에만 원래 주제의 입문 검증 수를 갱신한다.

뒤의 Boltzmann·Gibbs 분포, 상전이·질서변수, 상관·요동, 상세평형, 유한계·열역학 극한 및 다른 영역·연구 깊이는 계속 별도 작업으로 남긴다.
