# 조화진동·감쇠·공진 집필 및 홈페이지 연결

2026-11-05. 두 단원을 홈페이지의 기존 테마와 독자 화면에 연결했다. 최종 빌드의 한영 화면·접근성·조작·전체 영어 검사를 통과했다. 조화진동·감쇠·공진 입문 주제의 통합 검증을 마쳤다. 전체 교육과정과 연구 심화의 완료를 뜻하지 않는다.

## 실제 연결된 구성

| 단원 | 계산과 그림 |
| --- | --- |
| 정현파 외력과 초기값 과도 응답 | 위치·힘·속도, 실제 위상 궤적, 에너지, 순간 입력·열, 특수해와 초기 기억의 분해, 독립 에너지 수지 표 |
| 주파수 응답·위상·전력 공진 | 이득·위상·전력 곡선, 특성 주파수 표, 선택한 한 주기의 위치·속도·힘·전력·저장 에너지, 전달함수·주기 에너지 표 |

총 15개 SVG 그림과 세 개 표를 한·영으로 제공한다. 두 단원의 개념 단계 여덟 개·안내 실험 여섯 개·해설 퀴즈 네 개를 연결했다. 실제 초기값과 주기 특수해, 주파수 실험군을 구분한다. 원고의 유도·직관·예제·해설 문제는 [기반 집필 기록](waves-oscillations-foundation.md)을 따른다.

`src/lib/learning-waves.ts`는 정수 조작값을 물리 단위로 변환하고 `learning-waves-oscillations.ts`의 모델에 연결한다. 데이터는 기존 단일 배열에 유지하며, 앞서 배운 감쇠 진동·선형 ODE를 선수 단원으로 사용한다. 442개 기존 단원·안내·설정·상대 순서의 보존을 정규 데이터 해시로 검사한다. 현재 등록은 444개 단원·1,332개 안내 실험이다.

## 확인하고 수정한 경계 조건

- 에너지 적분은 그림용 257개 표본에서 분리한다. 빠른 감쇠를 별도의 적응형 적분으로 계산하고 완료 여부·오차 추정치를 표시한다.
- 부동소수점 제곱이 원래 강성비로 정확히 돌아오지 않는 경우에도 정준 제곱근 값으로 지정한 고유주파수 표식은 무감쇠 공진으로 처리한다. 이웃 주파수를 임의로 공진점에 붙이지 않는다.
- 영입력에는 측정 위상이 없고 DC에는 유한 주기·측정 주기 위상이 없다. 내재적 전달 위상의 극한과 구분한다.
- **힘이 0이면 전달함수가 특이해도 영 특수해를 선택할 수 있다.** 이때 실제 초기 자유 운동은 남는다. ‘유계 주기해 없음’이라는 잘못된 분해 안내를 피하도록 모델·검사를 보완했다.
- 영입력의 영 특수해는 선택한 시계의 한 주기로 표시할 수 있다. 모든 주파수에서 입력 전력이0이므로 실제 반전력 주파수는 미정으로 두며, 내재적 품질계수와 구분한다. 측정 위상이 없는 경우에도 주파수 축은0–8 rad/s로 유지한다.
- 모바일 과감쇠 예제에서 공통 CSS가 SVG 글자 크기 속성을 덮어써 축 숫자가 잘리는 문제를 발견했다. 해당 숫자의 인라인 글자 크기로 수정하고 재빌드했다. 이전 실패 및 수정 전 통과 기록은 보존한다.

## 검증 근거

전용 32개·전체 3,480개 테스트, TypeScript와 lint가 통과했다. 독립 기준값 58개 초기값 문제·522개 시점·24개 실수 전력 적분과 대조한다. 최종 정적 빌드1,686개 생성·1,681개 HTML 출력·1,678개 URL 검사, 한영320px 라이트/1440px 다크·접근성·직전 두 단원 회귀를 포함한54개 화면 상태, 펼친 안내 해설24개와 조작·저장·정오답·완료 표시4개 그룹을 통과했다. 영어528경로·586상태에서 미번역·런타임 오류가 없었다. 원본 크기 SVG60개와 한영 펼친 해설을 검토하고 모바일 SVG60개의 키보드 가로 이동을 확인했다. 검증 중 소스2,787개 해시는 변하지 않았다. 근거는 `.runtime/learning/waves-integrated-verification.json`, 개별 실행 로그·실제 종료 기록·`waves-browser/` 그림과 보고서에 있다.

실행 명령은 `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run check:export`, `npm run validate:content`, `node scripts/check-waves.cjs`, `node scripts/check-language.cjs`다. 긴 브라우저 검사는 개별 프로세스와 종료 기록으로 확인하며, 실행 중 빌드 출력을 교체하지 않는다.
