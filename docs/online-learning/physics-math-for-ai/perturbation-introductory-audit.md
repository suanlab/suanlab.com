# 섭동이론 네 단원: 입문 범위 종합 검토

2026-11-10. 원래 `field-multiscale` 영역의 `perturbation` 입문 범위를 충족한다고 판정했다. 정칙 전개, 발산 점근급수, 특이 경계층, 세속항·장시간 전개라는 처음 선언한 네 처리와 현재 원고·실험·생산 검증을 대조했다. 이는 섭동이론의 모든 연구 깊이나 전체 교육과정의 완료 판정이 아니다.

## 무엇을 읽고 확인했는가

[최초 범위](perturbation-primary-source-audit.md)와 각 단원의 일차 자료 감사·기반·Worker·교수 화면·실제 교재 기록을 읽었다. 한영 원고의 유도, 수치 예, 실패 조건과 해설 문제를 검토했다.18개 요구의 절 번호와 구체적인 판정 이유는 [검토 행렬](perturbation-introductory-audit-matrix.json)에 남겼다. 행렬의 체크나 파일 존재만으로 완료를 결정하지 않았다.

| 처리 | 원고 | 검토한 논증과 한계 |
|---|---|---|
| 정칙 전개 | `regular-perturbation-residual-certificates`,17절 | 양의 기울기가 유일한 근·잔차 안정성·에너지 보증을 연결한다. 계수 재귀와 Lagrange 계수, 반경4/27 및 k=0 제외를 확인했다. 수렴과 고정 차수 점근성을 혼동하지 않는다. |
| 발산 적분 | `quartic-integral-asymptotic-truncation`,18절 | 유한한 가우스 적분과 발산하는 결합 급수를 구분한다. 부호 있는 유한 나머지를 먼저 증명한 뒤 평균내고, 첫 누락항 보증과 예산 내/전체 절단 선택을 구분한다. 독립 구적과 교집합의 정보 의존성도 공개한다. |
| 경계층 | `singular-perturbation-boundary-layer-matching`,18절 | 차수 감소로 잃는 경계조건, 부호·반사·δ의 지배 균형과 정합을 확인했다. 정확 차이로 균일 값 오차를 증명하고 미분·경계 결함·점별 오차와 구분한다. a=0과 호환 자료는 별도다. |

네 모형은 각자 명시된 유한 문제를 다룬다. 볼록 평형의 잔차 오차 정리를 경계 문제나 장시간 운동에 옮길 수 없고, 사차 유한 적분을 연속체 경로적분의 존재 증명으로 사용할 수 없다. 이것이 단원별 성공 사례만 모으지 않고 원주제로 대조한 핵심이다.

## 보완한 학습 내용

마지막 단원의 기존20절 안에 한영 비교표와 네 해설 사례를 추가했다. 작은 매개변수의 정의, 고정하는 자료와 극한, 관측량/노름, 실제 가능한 보증과 실패 유형을 나란히 설명한다. 이전 세 단원으로 가는 복습 링크도 실제 경로로 연결했다.

손계산의 기준은 평형 p=0.93의 잔차0.0104357, 사차 적분 S₂=0.9578125와 누락항 상한0.0270703125, 내부 잔차0인 u=1의 경계 오차1, Duffing의 H=10⁶에서1차 위상 누적 약8.16382라디안이다. 직접 모델 검사에서 정확한 분수와 포함 구간을 대조했다. 서로 다른 단위의 오차 크기로 방법을 순위 매기지 않도록 설명했다.
