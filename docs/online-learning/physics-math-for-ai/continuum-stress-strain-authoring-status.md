## 관측과 해석

법선·traction 방향 도식은 각각 정규화하며 길이를 실제 힘으로 읽지 않게 표시한다. 실제 Pa·N·N·m·N/m³는 다른 패널과 표에 남긴다. 직사각형과 변형 격자의 공간 축은 같은 길이 축척을 사용한다. traction 성분 궤적의 자동 축척은 숫자 축으로 읽도록 설명한다.

평면 내 등방 압축과 평면 밖0인 plane-stress의 범위를 구분한다. 중복 주응력의 비유일한 축, 영면적의 별도 traction 질의, 무너진/미지원 양의 기하, 산술 미정 관측을0으로 바꾸지 않는다. 모멘트는 직사각형 중심 기준이며 체적력 누락 대조는 같은 실제 응력장을 사용한다.

변형 지도에서 전단이 있으면 b는 실제 y신장이나 주신장이 아니고 R은 일반적인 극분해 회전이 아니다. 정확한 회전과 I+omega J는 다른 지도다. 안정적인 가족 계산과 반올림한 F·다각형·길이 관측을 분리한다. 작은 회전의 로그 그림은 원래 값 표와 함께 제공하며 반올림0의 로그를 미정으로 남긴다. 공유 진단을 일반 물리 인증·오차 상한으로 확장하지 않는다.
