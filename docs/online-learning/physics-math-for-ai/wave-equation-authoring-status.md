# 파동 방정식의 홈페이지 연결

2026-11-05. 계산 모델 두 개와 한영 상세 원고 네 개를 기존 홈페이지 테마의 독자 화면에 연결했다. 최종 빌드의 한영·모바일·다크 모드·접근성·시각화·조작 검증을 마쳤다. 파동 방정식 입문 주제의 통합 검증이며 전체 교육과정·연구 심화의 완료는 아니다.

## 실제 연결한 구성

| 단원 | 계산과 시각화 |
| --- | --- |
| `coupled-chain-continuum-wave-limit` | 독립 초기 변위·속도, 실제 입자와 연속체 변위·속도, 힘·스펙트럼·격자 오차·RMS, 각 모델의 에너지, 입자별 배분 에너지·링크 흐름·실제 에너지 미분 |
| `wave-initial-data-reflection-energy-flux` | 초기 장·실제 변위·속도·기울기·방향별 변위와 에너지, 공간 흐름, 관측 구간/전체 에너지, 경계 전력·독립 시간 적분·잔차, 초기 의존 구간 |

기본 SVG25개·표5개, 개념 단계8개·안내 실험6개·해설 퀴즈4개를 한영으로 제공한다. 등록448개 단원·1,344개 안내 실험이다. 원고의 유도·직관·예제와 각 여섯 개 해설 문제, 독립 기준값은 [기반 집필 기록](wave-equation-foundation.md)에 있다.

`learning-wave-equation-lab.ts`는 조작값을 SI 단위로 바꾸고 이미 검증한 순수 모델에 연결한다. 사슬 길이는8 m로 고정하고 재료·격자·여러 초기 성분을 조절한다. 파형의 중심은2 m, 반폭은0.5–1.5 m로 두어 모든 경계 선택에 초기 호환성을 유지한다. 기본 파형은 고정단 반사이며 연속적인 시각 비율2/3으로 실제 t=4 s를 선택한다. 관측 구간은[0,4] m다.

## 계산과 표시에서 지킨 조건

- 같은 재료에서 격자를 세분화하면 질량은 줄고 강성은 증가한다. 실제 입자 점·연속체 곡선·표시 해상도를 구분한다.
- 초기 변위에 없는 별도 속도 모드와 영모드 평균 병진을 제공한다. 격자와 연속체의 초기 변형 에너지가 다른 것을 숨기지 않는다.
- 시간 그림은 물리 진동수 또는 이동 폭을 기준으로 충분히 표본화한다. 공간 에너지와 시간 경계 흐름의 적분은 그림 표본에서 분리한다.
- 반직선에서 초기 변위와 속도를 각각 같은 대칭으로 연장한다. 그림 창의 끝을 추가 반사 경계로 만들지 않는다. 반사상 에너지를 실제 총량에 더하지 않는다.
- 의존 삼각형은 에너지 궤적이 아니다. 선택 시각0에는 실제 초기점으로 축소한다. 속도 원시함수의 성분별 상수는 실제 변위 합에서 사라진다.
- 속도만 준 평탄부의 변위와 에너지 전면, 전체 보존과 관측 구간의 감소를 별도로 보여 준다. 초기 기울기 지표는 모든 시각의 물리적 선형성 보장이 아니다.

## 현재 확인한 근거

모델·콘텐츠·기존 연결 회귀를 포함한 전용52개, 전체3,560개 테스트와 TypeScript·lint·콘텐츠1,682개 URL 검사가 통과했다. 기존446개 단원·안내·설정·상대 순서의 보존을 정규 데이터 해시로 검사했다. 정적 빌드는1,690개 페이지를 생성했고 출력 검사가 통과했다. 개별 실행 로그·실제 종료 기록은 `.runtime/learning/wave-equation-integrated-*`에 있다. 출력1,685개 HTML·링크·자산·정규 URL, 브라우저50상태·펼친 안내24개·조작/저장/정오답/완료4그룹, 영어532경로·590상태 검사가 통과했다. 원본 SVG100개를 담은 갤러리8개와 대표 펼친 해설4개를 직접 확인했다. 모바일320px에서100개 그림의 키보드 가로 이동과8개 구성의 연속 시각 비율 저장도 확인했다. 실제 화면·접근성·글자 영역 검사 뒤에 해설 촬영에만 고정 헤더를 숨겼다.

첫 화면 검사에서는 공통 요약값의 소수 셋째 자리 반올림을 상세 표의 네 자리 유효숫자와 혼동한 검사 가정을 발견했다. 요약값0.091과 상세 표0.09143을 각각 검사하도록 도구를 고친 뒤 최종 통과했다. 실패 기록은 보존했다. 마지막 기존 단원 회귀에서는 준비 대기 식이 아직 없는 요소의 disabled를 읽은 검사 오류가 있었다. 요소 존재를 확인하도록 고친 뒤 이미 통과한49개 상태·24개 안내·4개 조작 그룹의 근거를 보존하고 남은 한 상태를 재검사했다. 보고서의 resumeEvidence에 연결했다. 앱·빌드 출력은 바꾸지 않았다. 빌드 시점2,813개 소스 중2,812개는 같고 검사 도구 한 파일만 바뀌었다. 이후 최종 검증 동안2,813개 해시는 유지되었다. 진행표 갱신 후 교육과정 생성 결과도 빌드 시점과 같다.

최종 근거는 `.runtime/learning/wave-equation-integrated-verification.json`, 개별 로그·실제 종료 기록·`wave-equation-browser/`의 이미지와 수동 검토 해시다. 실행 명령은 `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run check:export`, `npm run validate:content`, `node scripts/check-wave-equation.cjs`, `node scripts/check-language.cjs`다.

## 후속 표시 개선 완료

작은 에너지·흐름이 공통 최소 축 여백0.01 때문에 좁게 보이던 항목을 선택적 최소 여백으로 개선했다. 물리값과 단위는 유지했으며 기존 진동 그림의 기본 여백도 유지했다. 기본 사슬 에너지 변화가 약12.73px에서193.83px로 커졌다. 새 빌드·한영58상태·원본 SVG100개 재검증은 [축 가독성 개선 기록](wave-axis-readability.md)에 있다. 이전 통합 검증 수치와 후속 표시 개선의 근거를 구분한다.
