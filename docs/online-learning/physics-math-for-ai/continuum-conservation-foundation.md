# 연속체 보존식의 계산 모델과 상세 한영 원고

이후 [홈페이지 통합과 최종 검증](continuum-conservation-authoring-status.md)을 마쳤다. 아래 수치와 다음 단계는 기초 작성 당시의 기록이다.

2026-11-05. 전자기학 입문 종합 점검에 이어 연속체 첫 주제의 두 계산 모델과 한영 원고4개를 작성·검증했다. 홈페이지의 새 단원 등록과 시각화 연결은 다음 단계다. 등록480개 한영 단원·1,440개 안내 실험, 원래268개 입문 검증·94개 미완료 주제를 유지한다. 남은 집필 영역은9개이며 전체51영역509주제와 연구 심화는 미완료다.

## 이동 관측과 질량 수송

`src/lib/learning-continuum-conservation.ts`는 파일·데이터·AI 의존성이 없는 순수 계산 모듈이다. 밀도는 ρ0[1+α cos(k(x−vt))]이며 기준 밀도와 대비·파수·유체 속도·단면적을 따로 입력한다. k=0이면 실제 균일 밀도는ρ0(1+α)다. 무한 축의 전체 질량이나 자동 주기 경계를 가정하지 않고 유한 관측 창을 사용한다.

창의 속도w와 유체 속도v를 구분해 상대 유속ρ(v−w)를 계산한다. 왼쪽 바깥 법선은−x, 오른쪽은+x다. 물질 창의 순유입0과 실험실 유속의 비영 값을 구분하며, 잘못된 실험실 유속을 사용한 대조도 같은 실제 장에서 제공한다. 안정적인 sinc 적분과 배경 소거, 사인 곱의 유한 시간 변화를 사용한다. 반올림한 경계 차이와 끝점 질량 차이도 별도로 남긴다.

## 압축 흐름의 세 예산

두 번째 모형은 일정 단면적·비점성·단열·무체적력의 매끄러운 해 가족이다. s=1+at, ρ=ρ0/s, u=(v0+ax)/s, p=p0s^−γ를 사용한다. a·시간·양의 밀도·γ의 범위를 검사하여 s≥0.5를 유지한다. γ는 교육용 열량 관계의 계수이며 특정 실제 기체의 측정 물성을 가정하지 않는다. 일반 Euler 초기·경계값 솔버나 충격파 모형은 아니다.

물질 입자는 x=sX+v0t로 움직이며 속도는 일정하다. 저장 벡터U=(ρ,ρu,E)와 유속F=(ρu,ρu²+p,(E+p)u), 움직이는 경계의 F−wU를 계산한다. 물질 구간에서 질량·운동량·운동 에너지는 일정하지만 압력 일로 내부·총에너지는 변할 수 있다. 압력 일을 제거한 에너지 유속과 실제 저장 변화를 비교하되, 그 대조에 맞추려고 장이나 원천을 바꾸지 않는다.

손계산 예제는 γ=2, a=0.5/s인 초기[−1,1]m 물질 구간이다. 질량2kg와 운동 에너지1/12J는 유지되며,0→1초에 총에너지가25/12J에서17/12J로 줄어−2/3J의 압력 일을 확인한다. 질량 예제는 저장2kg·초기 순유입1kg/s와0→0.5초의 변화√2/πkg를 구분한다.

## 영입력·산술·검증의 해석

정확한 영시간·영대비·영파수·영변형률과 작은 비영 입력을 구분한다. 영폭에서는 질량0을 평균 밀도0으로 정규화하거나 정상적인 두 제어면을 만들지 않는다. 양의 폭이 좌표 해상도 아래이면 그 상태를 기록한다. 표현할 수 없는 작은 비영 곱은 명시적인 미정 값으로 남긴다. log1p·expm1과 안정적인 차이식을 이용해 반올림한 저장량 뒤의 표현 가능한 가족 변화를 유지한다.

일부 중간 산술이 사용 불가이면 최종 양도 보수적으로 미정일 수 있다. 임의 정밀도 산술이나 모든 작은 입력의 완전한 회복을 주장하지 않는다. 해석 잔차와16/32차 Gauss–Legendre 구적의 차이는 선택한 가족·계산의 진단이며 엄밀한 오차 상한이 아니다. 국소 보존식만으로 초기·경계 정보나 관측하지 않은 장을 유일하게 식별하지 않는다.

## 독립 계산과 실행 결과

제품을 가져오지 않는 `scripts/learning/generate-continuum-conservation-references.py`로 독립 참조를 만들었다. 실제 밀도의 공간 구적·질량 변화·시간 유입72조건, 실제 Euler 장의 공간 구적·세 예산144조건, 그 안의 독립 국소 차분48조건, 별도 입자 ODE48조건을 비교한다.100자리 정확 이진 입력 기준은 작은 물질 에너지 변화3조건과 작은 파수 질량 변화1조건을 포함한다. 별도 경로로 재실행한 참조가 canonical 파일과 해시까지 일치했다. 생성기는 기존 참조 파일을 덮어쓰지 않는다.

전용32개·전체4,289개 테스트, 타입·lint·콘텐츠1,714 URL 검사가 실제 종료 코드0으로 통과했다. 새 입력·순수 모형·독립 관측·단위·영입력·좌표 변환·시간 반전·손계산·한영 렌더링을 검사했다. 기존480개 단원·안내,42개 실험 그룹471항목과 상대 순서는 canonical 해시로 보존했다. 이전 소스3,023개·출력4,175개가 그대로이고 새10개 파일을 포함한 기초 소스3,033개를 기록했다.

근거는 `.runtime/learning/continuum-conservation-foundation/`과 `continuum-conservation-foundation-verification.json`, 각 검사 실행의 실제 종료 기록이다. 새 원고·모델이 아직 홈페이지에 연결되지 않았으므로 새 빌드·새 화면 검증·공개 배포를 했다고 표시하지 않는다.
