# 비평형·확률열역학·복잡계 입문 종합 점검

2026-11-08. 원래10주제와 실제17단원의 대응을 확인하고, 전체9752검사와 함께 모든17단원의 한영34읽기·접근성34조합을 재검사했다. 두 coarse-graining 읽기는 별도로16조합·키보드/터치·오류 복구를 통과했다. 등록550단원·1650안내, 원래300/362입문 검증·62미완료다. 아래 대응표는 연구 깊이 전체의 완료를 뜻하지 않는다.

## 원래 주제와 실제 학습 범위

| 원래 주제 | 단원 | 확인할 구별과 가정 |
| --- | --- | --- |
| master equation | 두 상태 생성자·Euler, uniformization, holding/jump/occupation | 전이율과 확률, 잠재 사건과 실제 점프, 방문 빈도와 체류 시간 |
| Fokker–Planck | OU 밀도·Euler 모멘트, 셀 질량·경계 | 초기 법칙·확률 흐름·공유 면 flux·경계 질량과 안정성 |
| 확률 흐름 | 정상 Gaussian 순환 | 정상 밀도와 영 전류의 차이, 순환의 방향·보존 |
| detailed balance와 그 위반 | 연속 순환의 경로 반전 | 정상 점유와 상세 균형, 점프·대기·경로 비의 방향 |
| fluctuation-dissipation | 열적 OU 변동·응답 | 열적 초기화·섭동·관측량·시간 약속과 평형 가정 |
| linear response | Markov 섭동·응답 | 생성자 규약·정적 해·커널·유한 섭동과 선형 예측의 차이 |
| entropy production | 정상 점프 경로 엔트로피 생성 | 교통량·순전류·시간 반전·엔트로피 생성, 물리적 열과의 추가 가정 |
| stochastic thermodynamics | 구동 두 상태 열·일, 저장소별 열 흐름 | 에너지 준위·국소 상세 균형·열/일 부호와 저장소 라벨 |
| synchronization·critical dynamics | Hopf 진폭, 두 위상 잠김·미끄러짐, 유한 Kuramoto | 진폭·위상·안정성, 완료 회전과 표시 분기, 유한 배열과 무한 극한 |
| coarse graining·유효 기술 | Markov 집계·정확 기억, 연속 숨은 변수·Markov 근사 | 모든 초기 법칙의 닫힘, 숨은 초기 강제, 기억 절단·준정상 가정과 오차 |

이산 확률 모형마다 행/열 규약과 시간 단위를 본문에서 확인한다. Markov 집계의 갱신 번호에 물리 시계를 추가하지 않는다. 확률적인 사영과 결정론적 숨은 초기 항을 임의의 열적 잡음으로 합치지 않는다. 확률 공간을 벗어난 기억 근사의 half-L1 차이, 미해결 구간, 구조적0도 구분한다.

## 증거를 읽는 방법

각 주제는 한영 이론·풀이, 독립 수치 검산, 실제 개념·자유 실험과 안내·퀴즈를 갖는다. 원래10개 제목과 교재 목록의17개 ID를 대조하고, 각 읽기의 본문 목차·영어·실험 계산 완료·문항·접근성을 재검사한다. 파일 존재나 단원 개수만으로 내용의 완성을 판단하지 않는다.

기존548개 단원·안내의 의미와 상대 순서는 등록 전 해시와 비교한다. 전체 회귀 검사는 이전 수치 모형을 포함하며, 새 두 모형은 별도 독립 참조·구간·부호·경계 사례로 검산했다. 실제 coarse-graining 읽기는 한영·명암·데스크톱/모바일·키보드·터치·메뉴·저장 복원·Worker 오류 복구를 검사한다. 종합 재검사는 모든17단원의 한영 기본 읽기와 접근성을 확인하는 추가 범위이며 모든 입력의 수학적 증명이나 모든 UI 상태의 전수 검사는 아니다.

## 계속 남는 연구 범위

- 일반 상태공간·무한 차원 생성자, 경계 정칙성과 강한/약한 해.
- 비정상·비선형 응답, 비평형 변동 관계와 시간 반전의 물리적 선택.
- 확률적 초기화와 조건부 기대 사영, 일반 Mori–Zwanzig와 오차 제어.
- 공간 coarse graining·재규격화 흐름·유효 결합·보편성과 연구 응용.
- 열역학 극한·장시간 극한·연속 극한의 순서, 더 일반적인 잡음·결합·네트워크.
