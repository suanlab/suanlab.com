# 유한 가우스 장: 한영 학습 화면 검증

2026-11-10. `finite-gaussian-field-sources-connected-correlations`의 독립 학습 화면을 구현했다. 아직 실제 Interactive Book reader에 등록하지 않았으며 생산 Next.js 자산 검증은 다음 단계다.

## 학습 내용과 그림

한영 8개념·6안내·8해설 퀴즈·17예제를 연결했다. 연결 공분산 C, 원래 이점함수, 원천 응답 G, 정밀도 K의 열지도와 이산 Three.js 막대를 비교한다. 위치 쌍은 행렬 첨자이며 두 물리 공간 축이나 시간으로 해석하지 않는다. 평균·선택 열·Wick 세 기여는 별도 막대 그림이고 각 그림은 독립 재척도한다. 정확한 분수와 영점은 표로 확인한다.

연결량은 검증된 C를 직접 읽으며 부동소수점 원래 모멘트에서 평균 곱을 빼지 않는다. 그림 표시 범위를 벗어난 값은 0으로 그리지 않고 정확한 표로 전환한다. 이 방어 경로는 합성된 큰 값으로 검사했고 46개 실제 참조 입력에서는 표시 가능했다. 원천이 만든 평균과 단위 원천에 대한 응답, 중심 사차 모멘트와 누적량을 구분한다. 제약력·투영 잔차·유도 측도도 확인할 수 있다.

## 입력과 상호작용

3–8개 위치, 세 경계, 평균0 제약, 유리수 계수·원천 벡터·네 관측 첨자를 바꿀 수 있다. 위치 수를 바꿀 때 벡터 길이와 관측 첨자도 맞춰야 하며 잘못된 입력은 이전 결과를 보존한다. 버전과 크기를 검증해 저장·복원한다. 행렬/척도/성분 변경과 재생은 Worker를 재실행하지 않는다.

3D는 명시적으로 열며 터치·키보드·시점 초기화와 컨텍스트 손실 후 재시도를 제공한다. 감소 모션에서는 재생을 끈다. 표는 가로 스크롤이 가능하고 행렬은 화살표 키로 선택한다.
