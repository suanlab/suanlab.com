# 이진 미시·거시 상태의 계산·한영 본문 기반

2026-11-06. `binary-shell-multiplicity-block-counts`의 독립 계산 모델에 상세 한영 본문을 결합했다. 첫 가족의 계산·원고 기반 검증이며, 미시·거시 상태 전체 주제나 홈페이지 통합의 완료가 아니다.

## 학습 내용

각 언어는15개 절과 해설이 있는 연습6개로 구성된다. 영어 원고는2568단어, 한국어 원고는 한글4667자이며,15개 display 수식은 두 언어에서 동일하다. 원고는 `content/learning/physics-math-for-ai/binary-shell-multiplicity-block-counts.{en,ko}.md`에 있다.

네 자리의 여섯 배치를 직접 열거하고 특정 미시상태·거시 껍질·선택 껍질 내부의 세 확률을 대조한다. 균등 준비의 선택, Boltzmann/Gibbs 엔트로피와 정보량의 단위, 관측과 숨은 정보의 연쇄법칙을 설명한다. 고정 총 여기 수로 생기는 블록 의존성을 상호작용과 구별하며 조건부 평균·분산을 유도한다.

전형적인 비율 구간의 집중과 정확한 중앙값 하나의 확률을 분리한다. N=1080의 양수 확률 underflow와 실제0인 껍질 엔트로피를 대조한다. 연속 측도·분해능·입자 구별·잡음 관측에 필요한 추가 가정과, 개수만으로 시간 진화나 ergodicity를 결정할 수 없음을 명시한다.

## 검증과 한계

기존 독립 참조36개와 모델 성질을 검사하는45개 테스트에 원고·예제 검사3개를 더해48개가 통과했다. 실제 `getLearningContent`로 두 원고를 렌더링하여 KaTeX 오류 부재, 한영 수식 일치, 고유한 목차와 실제 앵커, 키보드 접근 가능한 수식 영역, 언어별6개 풀이를 확인했다. 영어에 한글이 없고 미치환 템플릿 토큰도 없다.

예제 검사는 네 자리의 세 확률, 두 블록의1·4·1 및1·16·36·16·1 개수와 유한 모집단 분산, 홀수N의 정확한 최빈 동률, 엔트로피 연쇄법칙과 희귀 껍질의 양수 기여를 모델로 재확인한다. 타입 검사와 대상 lint도 통과했다. 개수·정규화·조건부 모멘트는 정확한 정수/유리 연산이며 로그·엔트로피의 초월함수 값은 근사다.

첫 모델 증거의6개 파일과 기존 통합 소스·자산·검사3888개, 정적 출력4236개의 해시를 재확인했다. 새 미등록 원고와 검사가 추가되었으므로 전체 파일 집합이3888개라는 뜻은 아니다. 이번에는 홈페이지를 다시 빌드하거나 새 UI를 검증하지 않았다.

## 남은 순서

가중 결정론적 관측과 잡음 관측의 모델·독립 참조·한영 본문을 먼저 완성한다. 이후 세 가족의 그림·조작·개념 단계·안내 실험·퀴즈를 연결하고 실제 읽기 경로를 검증한다. 기존509단원·1527안내 실험 및 입문 검증282주제·미완료80주제는 변경하지 않는다.

초기 모델 보고서와 증거는 그 당시의 기록으로 보존한다. 현재 근거는 `.runtime/learning/binary-macrostates-manuscript-verification.json`이며, 전체 순서는 [미시·거시 상태 집필 설계](micro-macro-authoring-plan.md)에 따른다.
