# 앙상블: 제약·접촉 조건에서 확률법칙으로

2026-11-06. 미시·거시 상태 다음 주제의 집필 설계다. 아래 세 가족은 입문 경로이며, 전체 앙상블 이론의 범위를 대신하지 않는다. 첫 가족의 계산 모델·독립 기준값·상세 한영 본문을 작성·검증했다. 둘째 가족의 정준 요동 계산과 상세 한영 본문도 검증했다. 2026-11-07에 셋째 가족의 입자 교환 한영 본문까지 검증했다. 세 가족의 모델과 본문이 준비됐으며 `ensemble-integration-plan.md`에 따라 교육 UI를 구현한다. worker와 한영 안내의 격리 검증도 마쳤으며 실제 패널을 이어서 구현한다. 홈페이지에는 아직 등록하지 않았다. 주차와 분량 제한을 두지 않는다.

## 학습 목표와 연결

앙상블을 서로 다른 계의 이름으로 외우기 전에, 같은 미시상태 공간에서도 준비 조건이 달라지면 확률법칙이 달라짐을 설명한다. 독자는 고정된 양, 교환 가능한 양, 외부 제어값, 확률변수, 가정을 각 예제에서 직접 적는다. 단일 계의 시간 궤적과 독립적으로 준비한 복제들의 분포는 구별한다. 평형 분포의 식만으로 ergodicity나 실제 평형 도달 시간을 증명하지 않는다.

선수 단원은 이진 껍질·블록 조건부, 가중 분할, 유한 스펙트럼 자유에너지다. 이후 분배함수·Boltzmann/Gibbs 분포·상관과 요동·열역학 극한에서 일반화한다. 분배함수는 여기서 확률을 정규화하는 데 필요한 만큼 도입하고, 후속 주제의 미분 생성·상전이 분석을 생략된 완료 항목으로 처리하지 않는다.

## 가족 1: 유한 저장고와 정준 근사의 오차

예정 ID: `finite-binary-reservoir-canonical-comparison`.

같은 양의 에너지 간격 ε를 갖는 구별 가능한 비상호작용 이진 자리 n개와 저장고 b개를 둔다. 전체 여기 수 K를 고정한 균등 껍질에서 부분계의 여기 수 A는 다음 법칙을 갖는다.

$$
P(A=a)=\frac{\binom n a\binom b{K-a}}{\binom{n+b}K}.
$$

범위 밖 이항 계수는 0이다. 허용되는 a의 범위를 먼저 정하고, 부분계의 특정 이진 배치 확률과 A의 확률을 따로 표시한다. ρ=K/(n+b)일 때 비교 정준 법칙은 Binomial(n,ρ)다. 평균 nρ는 같아도 분산은 전체 자리 수가 2 이상일 때 정준 분산의 b/(n+b−1)배다. 전체 자리 수 1과 확정 준비의 분산 0은 별도로 처리한다.

손계산 예제 n=2,b=2,K=2에서는 A의 확률이 (1,4,1)/6이며, 같은 평균의 정준 비교는 (1,2,1)/4다. 전체변동거리 1/6과 분산 1/3 대 1/2을 확인한다. 평균이 같다는 사실은 분포의 동등성을 뜻하지 않는다.

그림은 전체 껍질→부분계와 저장고의 허용 조합→두 분포→오차와 요동의 네 단계다. 저장고 크기를 바꿀 때 K를 어떤 규칙으로 바꾸는지 표시한다. 고정 n, b 증가, K/(n+b)→ρ라는 조건 아래의 수렴과 n도 함께 커지는 극한을 혼동하지 않는다. 저장고 엔트로피의 선형 근사와 이차 곡률 보정을 본문에서 유도한다. 유한 차분으로 얻은 기울기와 연속 미분 온도를 같은 숫자라고 단정하지 않는다.

## 가족 2: 고정 입자 수에서 에너지 요동

예정 ID: `canonical-binary-energy-fluctuations`.

n개의 구별 가능한 이진 자리에 정준 준비를 지정한다. t=βε, β=1/(kBT), T>0이며 단일 자리 여기 확률 r=1/(1+exp(t))다. K의 이항 분포와 개별 배치의 확률을 동시에 보여준다. Z=(1+exp(−t))ⁿ, U=nεr, Var(E)=nε²r(1−r), C=nkB t²r(1−r)를 직접 연결한다.

같은 평균에 가까운 껍질 하나를 선택해도 에너지 분산 0인 미시정준 준비와 정준 준비는 다르다. n=1에서도 정준 분포는 정의되지만, 작은 계의 단일 관측값을 곧바로 온도라고 부르지 않는다. 정확한 분포를 기준으로 하고, 선택적으로 독립 표본의 경험 histogram과 표준오차를 겹친다. 표본 수·seed를 공개하며 표본 프레임을 물리 시간으로 부르지 않는다. 절대 요동 증가와 상대 요동 감소를 다른 축에서 확인한다.

큰 |t|에서는 지수 overflow를 피하고, 양수지만 표시 범위 밖인 확률과 실제 0을 구분한다. T→0⁺ 및 β→0⁺의 극한을 유한 입력과 구별한다. 음의 온도는 위로 유계인 스펙트럼과 인구역전 조건을 별도 절에서 다루며, 보통의 무한 운동에너지 기체에 일반화하지 않는다.

## 가족 3: 입자 교환과 유한 배제 격자

예정 ID: `grand-canonical-finite-occupancy-fluctuations`.

M개의 이름 붙은 자리마다 점유 0/1, 점유 에너지 ε, 총입자 수 N을 둔다. 같은 자리에 둘 이상 들어가지 못하는 고전적 격자 모형임을 명시한다. α=βμ, t=βε에서 r=logistic(α−t), Ξ=(1+exp(α−t))ᴹ, N~Binomial(M,r)다. μ와 ε는 같은 에너지 단위이며, μ=0이 빈 계를 뜻하지 않는다.

N이 고정된 조건부 준비는 그 N의 모든 점유 배치에 균등하다. 조건부 확률과 전체 grand-canonical 확률, N의 다중도를 세 층으로 구분한다. 평균 M r, 분산 M r(1−r), Cov(U,N)=εVar(N), 고정 β에서 ∂⟨N⟩/∂μ=βVar(N)를 확인한다. α를 조절하는 미분과 μ를 조절하는 미분의 단위 차이를 보여준다.

M=2, α=t에서는 N 확률 (1,2,1)/4이며 N=1 조건부의 두 배치는 각각 1/2다. 입자 수 고정 준비와 평균만 같은 준비를 비교한다. 이 결과를 연속 이상기체의 부피 인자·Gibbs 보정·Bose/Fermi 통계로 바로 대체하지 않는다. 후속 절에서 입자 구별 가능성, 상태 계수, 실제 저장고와 측정 장치를 연결한다.

## 구현과 검증 계약

모델마다 독립 조합/고정밀 기준값, 대칭·정규화·경계·요동 항등식·허용되지 않는 입력을 검증한다. 유한 저장고의 정확한 법칙과 근사 법칙은 서로 다른 데이터로 보존한다. TV·KL을 함께 보여줄 때 지지집합 불일치와 무한대 방향을 명시한다. 큰 계수와 극소 확률의 기존 표현 규칙을 따른다.

각 가족에 상세 한영 본문, 풀이가 있는 연습 6개, 개념 4단계, 안내 실험 3개, 설명형 퀴즈 2개를 작성한다. 기존 사이트 색상과 Interactive Book 진입 경로를 유지한다. 본문·모델·UI·전체 검사·실제 정적 페이지 검증 후에만 원래 주제 완료 수를 올린다. 연속 측도, 상호작용, 장거리 계, 앙상블 비동등성, 큰편차와 열역학 극한은 전체 범위의 후속 작업으로 남긴다.
