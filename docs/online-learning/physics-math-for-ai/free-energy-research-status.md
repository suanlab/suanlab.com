# 자유 에너지 연구 보강 검증 기록

2026-11-13. 유한 스펙트럼 Helmholtz–KL과 이상기체 부피 가용성의 **두 단원·한영 4원고·공개 그림 4개**를 보강했다. 기존 원본문과 해설 24개를 바이트 단위로 보존했다. 새 표시 수식은 한영 합계 40개, 실행 Python/표는 각각 4개, 연구 해설은 12개다. 기존 실습·프리셋·비교 순회·등록 순서를 유지한다.

## 추가한 설명과 경계

- **준위 변경·완화:** 원래 세 상태 실습과 구별되는 두 상태 준비를 명시한다. 순간 변경의 평균 일과 새 목표에 저장한 비평형 차를 이후 열적 완화의 생성 엔트로피와 구별한다. 양의 시간 척도를 가진 상세평형 전이율을 추가해 KL 감소·열·에너지·초과 일 분해를 유도한다. 목표 변경의 KL 점프를 고정 목표 단조성 위반으로 부르거나 기존 순회에 물리 시계를 붙이지 않는다.
- **관성 피스톤:** 질량·면적·점성 및 같은 온도조절기로 돌아가는 소산 열을 추가한다. 부피 관성의 단위와 무차원 시간·감쇠를 유도하고 퍼텐셜이 증가하는 지나침에서도 운동 에너지와의 합은 감소함을 보인다. 기계 저장량을 포함한 열·엔트로피 수지를 쓰며 기존 퍼텐셜만의 끝점 식의 조건을 설명한다. 결정론 거시 모형은 미시 정준 요동·유한 열전달 실현성이나 임의 RK4 간격의 양성을 인증하지 않는다.

물리 관례·직접 유도 범위는 [자료 대조](thermo-statmech-source-audit.md), 수식·직관·질문은 실제 reader, 실행·해시는 [JSON 근거](free-energy-research-evidence.json)에 연결했다.

## 독립 계산과 보존

주방정식의 확률 흐름 RK4와 독립 엔트로피 생성률 적분으로 준위 변경·완화 54수지를 대조하고 같은 간격 준비 3개를 확인했다. 피스톤은 50자리 Decimal의 24차 역수 급수 ODE 전개로 6궤적을 독립 계산했다. 점성 손실의 급수 적분·순열·엔트로피 18수지, RK4 두 간격의 36비교와 양의 부피·지나침을 확인했다. 유한 사례는 일반 오차 인증이나 장치 검증을 대신하지 않는다.

관련 **12파일·197검사**가 통과했다. 새 절을 반영해 기체 목차 검사의 H2 기대값을 15에서 16으로 갱신했고, 별도로 정확한 원문 복원을 확인했다. 첨자가 Markdown 강조로 바뀌지 않도록 새 본문의 수식 표기를 정리했다. 다른 30단원·60원고와 앞선 연구 자산 36개를 유지했다. 기존 보존 기록 813항목을 그대로 두고 이번 네 원고만 추가해 817항목이다. 등록은 650단원·1,969안내, 전체 분모는 51영역·509주제다.
