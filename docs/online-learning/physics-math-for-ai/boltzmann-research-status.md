# Boltzmann·Gibbs 연구 보강 검증 기록

2026-11-13. 기준 측도·Boltzmann 식별, 유한 Gibbs 조건부 갱신, Gaussian Gibbs 정규화의 **3단원·한영 6원고·그림 6개**를 보강했다. 기존 원문과 풀이 36개를 정확히 보존하고 표시 수식 60개, 실행 Python과 표 각각 6개, 연구 해설 18개를 추가했다. 새로운 관측·갱신 모형과 기존 reader의 정적 조작을 구별한다.

## 새로운 설명과 적용 조건

- **두 온도 식별:** 같은 에너지·기준 가중치를 유지하고 서로 다른 역온도를 교정하면 로그 오즈의 절편과 기울기를 구별할 수 있음을 유도한다. 독립 관측 우도·Fisher 행렬식·세 번째 설정의 모형 점검을 연결한다. 정확한 모집단 역산과 유한 표본 추정, 양의 랭크와 좋은 조건을 구분하며 공통 에너지·기준 척도 모호성은 남긴다.
- **상태 의존 자리 선택:** 올바른 조건부 재추출이라도 선택 정책이 출발 상태에 따라 바뀌면 편향될 수 있는 두 비트 반례를 계산한다. 구성별 선택 비 Metropolis 보정과 거절 자기 고리를 포함해 목표 흐름을 복원한다. 첫 비트 평균의 점화식을 전체 혼합률이나 물리 시간으로 확대하지 않는다.
- **Gaussian 표집 정확도:** 정규화 가능한 목표와 Euler 사슬의 안정 조건·정상 공분산 편향을 분리한다. 고유 모드 분산 점화식, 정확한 Lyapunov 식, Gaussian KL, 안정 경계의 선형 분산 증가를 유도한다. 목표를 보존하는 정확한 선형 전이는 이차식에 한정하며 알고리즘 단계를 물리 초로 부르지 않는다.

자료는 [출처 기록](thermo-statmech-source-audit.md), 실제 수식·예제는 reader, 해시와 재현 범위는 [JSON 근거](boltzmann-research-evidence.json)에 연결했다.

## 독립 계산과 보존

전체 이진 관측 법칙을 열거한 90준비에서 점수 평균·Fisher 행렬·역산·남은 기준 모호성을 확인했다. 유리수 선택 kernel 24개에서 보정 흐름과 정상성을 확인했고 비보정 편향 반례 15개를 얻었다. 균일 목표의 첫 비트 점화식도 전체 네 상태 분포와 대조했다. Gaussian 공분산은 직접 유리수 선형계로 20개 Lyapunov 문제를 풀어 검산했다. 안정 경계 분산 21단계와 정확한 선형 전이의 12모드 공분산 보존도 확인했다. 유한 계산은 임의 표집기·비선형 에너지·추정량의 정확도 인증이 아니다.
