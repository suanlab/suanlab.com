## 독립 계산 경로

새 참조 모듈은 유리수 사칙연산만 공유하며 `Q(sqrt(2),i)`의 곱·켤레·유리화 나눗셈을 구성한다. 생산 scalar·회로·채널/밀도행렬·프로토콜 모델을 import하지 않는다. 입력 벡터가0이면 거부하고, 정규화하지 않은 입력의 크기를 정확하게 보존한다.

CNOT 후보의 출력은 직접 `[a,0,0,b]`로 만들고 외적으로 결합 밀도행렬을 구성한다. 주변 상태는 입력 대각 확률, 목표 복제는 입력 밀도행렬의 tensor 좌표로 대조한다. 한 복사본의 제곱 fidelity는 두 입력 확률의 제곱합이다. 두 입력의 겹침은 별도 진폭 내적의 절댓값 제곱을 두 norm으로 나눈 값이다. 복제 후보의 실패, 두 ray의 필요조건, 보편적 복제 불가 정리를 구분한다.

BB84 참조는 projector trace 대신 같은 기저의 결정론적 전이와 다른 기저의1/2 전이로80가지 확률을 구성한다. 선별 확률·전체/기저별 오류율을 합산하고, 공개 기저와 Eve의 공격 여부/기저/결과에만 조건화한 Alice bit의 사후분포로 정보량과 추측 성공률을 구한다. Bob의 비공개 bit를 Eve 관측에 포함하지 않는다. IID 표본의 무오류 확률은 반복 곱으로 확인한다. 정보량 계산은 이 이상적 공격의 flagged posterior에 한정되며 일반 보안 증명·비밀키율이 아니다.

응답 소유권·원래 요청·정확 분류와168개 복소 수 계수,91개 유리수 관측값/metadata를 검사한다. 복소 계수와 표시 endpoint는 기존 canonical wire 규약을 유지한다.

## 최대 입력의 응답 제한 수정

32자리 분수와256표본을 함께 사용하면 정상 확률의 분자/분모가8천 자를 넘을 수 있다. 기존 공용 복사기의8192자·관측 endpoint의4096자리/지수8192 제한으로 정상 응답이 거부되는 문제를 재현했다.

공용 함수의 기본값은 유지하고 명시적으로 제한된 선택 인자를 추가했다. BB84만 문자열16384자, endpoint 계수10000자리와 이진 지수32768을 사용한다. 입력 분모 `d<10^32`에서 `(4d)^256`의 계수 자릿수와2의 지수에 맞춘 유한 상계다. 기본 한계·상한 초과·음수/비정수 예산 거부와 큰 홀수/2의 거듭제곱 분모를 검사한다.
