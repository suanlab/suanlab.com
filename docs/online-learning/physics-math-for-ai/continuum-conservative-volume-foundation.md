## 독립 계산과 회귀 검사

생성기는 제품 코드를 가져오지 않는다. incidence·질량 행렬을 고정밀로 조립하고 `(I+dt R)^steps`를 직접 계산한다. 연속체 참조는 해석적 셀 적분이다. 제품은 부호·로그를 사용하는 초기 편차와 누적 변화 점화식으로 계산하므로 서로 다른 경로를 비교한다.

일반24사례는160자리, 작은 변화12사례와 임의ring6사례는1600자리로 계산했다. 참조42사례를 다시 생성해 fixture와 바이트 일치를 확인했다. 일반 곱셈으로 `유속×면적` 또는 `확산계수×면적`을 먼저 계산하면 사라질 수 있는 값을 부호·로그 곱으로 보존하도록 수정했다. 최소 양의 부동소수점 시간 간격의 ring 참조도1600자리로 올려 끝점 차감으로 작은 노름 변화가 사라지지 않게 했다.

최종 관련54검사가 통과했다. 독립 셀·면·예산 비교, 세 셀 유리수 값, 안정한 격자 세분화의 오차 감소, 실제 다음Euler단계의 노름 예산, 모든 입력의 비유한·누락 거부, 큰 입력의 유한/null 표현, 정지·영 시간·작은 곱·불안정 사례와 한영 렌더링을 포함한다. 전체 회귀4,792검사도 통과했다. 전체 회귀 이후 추가한 극단 입력 검사1개는 최종54개 실행에 포함된다. lint·typecheck·콘텐츠 검사도 통과했고 기존 등록URL은1,735개다.

## 해석과 남은 작업

질량은kg, 이차 노름은kg²/m³이며 J가 아니다. 큰 시간 간격도 입력 그대로 실행하며, 보존 장부가 닫혀 있어도 음의 농도와 노름 증폭을 드러낸다. 공유 면의 정확한 대수적 질량 장부와 셀 직접 합산 진단을 구별한다. 격자는 일반 부동소수점이고, 큰 양·음 상태의 상쇄가 나쁘면 셀 합산 오차를 절댓값 질량 규모로 평가한다.

기존 빌드 입력3,161파일과 출력4,218파일의 해시가 그대로임을 확인했다. 새 기반은 아직 등록하지 않아 현재 홈페이지500단원·1,500안내, 원래 주제278검증·84미완료는 유지한다. 새 빌드나 화면 검증을 수행했다는 뜻은 아니다.

후속 `godunov-burgers-conservative-shock-entropy`의 실제 비선형 갱신·경계 수지·국소 entropy·독립 참조·한영 본문은 [별도 기반 기록](continuum-conservative-godunov-foundation.md)에 정리했다. 다음은 두 단원을 **도서 → Interactive Book**에 연결하고 화면·정적 출력·영어 순회를 검증한다. 연속체 전체 영역 점검과 나머지 영역·연구 심화도 남아 있다.
