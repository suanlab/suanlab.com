## 학습 내용

같은 정상분포·배경 생성자에서도 손잡이가 전이율을 바꾸는 방식에 따라 응답이 달라질 수 있음을 세 방 모형으로 설명한다. 동일한 전이율 비율 미분에 대칭적 통행 계수 η를 달리한다. 비평형 예제에서는 초기 점유 응답이−1/76,45/76,91/76/s로 바뀐다.

[한국어 본문](linear-response-chapter.ko.md)과 [영어 본문](linear-response-chapter.en.md)은 각각14절·표시 수식11개·비교표2개·해설6문제다. 직관→단위·행/열 약속→섭동 미분→인과 커널→켤레 관측량→정적·주파수 응답 순서로 전개한다. 확률과 그 미분, 유한 입력과 접선, 초기 응답 속도와 계단 변화, 정적 극한과 비영 주파수를 구별한다. 평형의 지수 커널과 복소 감수성은 해설에서 직접 계산한다.

## 정확 수치 원형

`src/lib/learning-finite-state-linear-response.ts`는 양의 여섯 유리 전이율, 유리 η와 비음수 각주파수를 받는다. 생성자·정상법칙·미분 생성자·부호 있는 원천·켤레 관측량·세 상태 점유의 초기 커널·정상 미분·정규화 Poisson 해·복소 감수성을 정확 유리수로 출력한다.

비영 주파수는 실수6차 연립계로 풀고, 영 주파수는 정규화된 정적 문제로 분리한다. 특이한 Q의 역행렬을 사용하지 않는다. 작은 비영 pivot을 허용오차로 버리지 않으며 근삿값 대신 정확 끝점도 함께 반환한다. 복소수0에서 위상은 정의되지 않음을 표시한다. 진폭 제곱은 정확하지만 제곱근·위상각은 아직 계산하지 않는다.

정적·주파수 원형은 별도 파일로 유지한다. 여기에 `src/lib/learning-finite-state-response-experiment.ts`의 **시간 곡선·유한 진폭 진화**를 추가했다. [시간 영역의 수학적 계약](linear-response-temporal-foundation.md)을 따른다. worker·UI·읽기 등록은 아직 없으며 다음 구현 대상으로 유지한다. 임의의 전이율 비율을 열이나 온도로 해석하지 않는다.

시간 커널 s exp(Qt), 계단 감수성 π′(I−exp(Qt)), 같은 원래 정상분포에서 시작하는 실제 유한 입력 확률 π exp(Q(h)t)를 구한다. 양수 uniformization·방향성256bit 산술·명시적 Poisson 꼬리·확률 행렬의 scaling/squaring으로 감싼다. 부분합을 정규화하지 않으며, 부호 있는 접선을 [0,1]로 잘라내지 않는다. 기록 수를 바꿔도 같은 시각의 계산은 같다.

정확 sQᵏo=0(k=0,1,2)을 Cayley–Hamilton 관계로 연결해 항등적인0을 판정한다. 단순한 상쇄나 고정 정밀도보다 작은 양의 커널은 미해결 상태로 남긴다. 지수 전이율의 양의 역수 상한을 만들 수 없는 경우 실제 확률은 가용하지 않다고 표시하며0·Infinity를 대입하지 않는다. 영 시간·영 입력은 정확 항등식으로 처리한다. 선형 응답이0이어도 유한 입력의 비선형 효과는 계산한다.
