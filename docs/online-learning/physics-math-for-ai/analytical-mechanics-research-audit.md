## 원고·번역·선수 관계의 보존

각 원고에서 연구 확장 절 하나만 제거하면 Git 기준 `d486291`의 원고 40편과 바이트가 같다. 원래 해설 문제 **240개**를 보존했다. 자유입자 작용·조화 작용 단원은 번호 항목 안에 해설을 쓰는 형식이므로, 다른 단원의 굵은 해설 표지 유무로 오판하지 않고 여섯 원문 항목을 각각 대조했다.

원래 한영 수식 5쌍의 표기 일치와 15쌍의 의미·구두점·묶음 차이에 대한 [입문 감사의 판단](analytical-mechanics-domain-audit.md)은 원문 보존과 함께 유지한다. 이번 연구 확장 20쌍은 표시 수식 **272개**, Python **40셀**의 코드와 실제 출력이 언어 사이에 일치했다. 수식을 자동 삭제·정규화해 과거 차이를 숨기지 않았다.

현재 등록은 650단원·1,969안내 그대로다. 영역 선수는 `classical-mechanics`, `variational-geometry`이며 단원 선수 폐포 175개의 존재·순환 없음과 직접 선수의 등록 순서를 확인했다. 이전 검토 항목 677개는 그대로이며 네 편을 더해 681개다. 앞선 36원고·36그림은 아홉 상세 증거의 해시와 다시 일치했다.
