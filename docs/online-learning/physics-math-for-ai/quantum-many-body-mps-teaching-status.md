# MPS contraction·gauge 학습 화면 준비

2026-11-09. `matrix-product-state-contraction-gauge`의 상세 원고와 계산·독립 검증 Worker를 학습 화면에 연결했다. 다체계 학습 화면 준비는 **4/5**,등록은 **0/5**다. 최종 검증 근거는 `.runtime/learning/many-body-mps-teaching/verification.json`이다. 실제 reader 등록·생산 자산·공개 배포는 별도 관문이다.

## 교육 내용과 실습

감사한 한영16절·14수식·4표·8해설 연습 원고를 바이트 변경 없이 콘텐츠 경로에 복사했다. 세 개념·세 안내 실험·세 해설 퀴즈와 다음8기준 입력을 제공한다.

1. GHZ3의 실수 scale/shear: 전체 벡터 norm²=2,좌표 제곱 노름6→19/2.
2. GHZ3의 복소 gauge: 정확한 역행렬과 전체 벡터 보존.
3. 복소 상쇄:1+i·i=0,비영 tensor들이 전체 영벡터를 만드는 예.
4. 실수 경로의 상쇄.
5. 오른쪽 Y+ 곱 상태:복소 위상과〈Y〉=1.
6. 중복 bond4 곱 상태:모든 cut rank1,활성 복소 성분48대 dense 진폭8.
7. 한 위치의 복소 벡터:내부 cut/gauge가 없는 경우.
8. 네 위치 GHZ의 비균일 bond2/3/2:모든 cut의 실제 rank2.

위치별 tensor 수축 단계를 선택하면 검증된 prefix 복소 행렬과 같은 cut의 E/R 환경·노름 닫힘을 함께 본다. 원래/gauged 좌표 전환은 계산을 다시 실행하지 않으며 전체 최종 prefix는 동일하다. 중간 가상 성분을 확률로 표시하지 않는다. 복소 환경의 닫힘은 이 convention의Σ_ab E_ab R_ab이며,임의로 trace(ER)로 대체하지 않는다.

2D/Three.js 그래프는 tensor·물리 leg·가상 bond 차원·선택 gauge 위치를 설명한다. 파랑은 수축한 위치,주황은 gauge bond이며 배치·재생은 물리 공간이나 시간 진화가 아니다. 작은 화면의 그래프는 키보드로 가로 스크롤할 수 있다. 모션 제한·화면 밖에서 설명 재생을 멈추고 WebGL 실패 시2D와 수치 표를 유지한다. 렌더러는 이벤트가 있을 때만 그리며 닫기·결과 교체·언마운트 때 자원을 정리한다.

## 상태·표현·보장 범위

원시/정규화 전체 복소 상태,좌표 노름,가역 G/G⁻¹,환경 covariance,모든 cut의 계수 rank와 bond 상한,국소 Gram/isometry 잔차,국소 밀도·Bloch·모든 pair XYZ 상관을 제공한다. 전체 수축이0이면 원시 대수와 환경은 남기고 정규화 물리 관측은 미제공이다. 진공이나 균등 확률을 대신 넣지 않는다.

269정수 입력·활성 tensor/gauge 편집·원자적 JSON·입력 종류별 버전 저장을 사용한다. 구조적으로 유효한 전체 영벡터도 허용한다. 자동 SVD/QR 정규화,Schmidt spectrum/절단,DMRG·물리 시간 진화·바닥·열역학적 극한·항상 압축된다는 보장은 제공하지 않는다. GHZ/혼합 및 three-body XXX는 본문의 해석적 비교이며 현재 입력의 혼합 모형 기능이 아니다.
