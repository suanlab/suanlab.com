## 점탄성의 기억과 에너지 분배

`kelvin-voigt-maxwell-memory-dissipation`은 E·점도·작은 변형률 진폭·각주파수·초기 탄성 변형률·관측 시간·적분 시작/끝의8개 입력을 연결한다. 모델 정의역은 E∈[0.25,4]Pa,η∈[0.0625,4]Pa s,진폭과 초기 탄성 변형률±0.005,ω∈[0,4]rad/s,시간∈[0,16]s다. 음의 진폭은 방향을 바꾸지만 소산은 비음이다. 시작≤끝인 시간 구간과 정확한 영 기간을 구분한다.

변형률과 속도는 서로 다른 단위의 별도 그래프로 보여준다. Kelvin–Voigt/Maxwell 응력, 실제/정상 주기/과도 응력, 내부 탄성·점성 변형률, 저장 에너지·입력 전력·소산과 실제 시간창 수지를 연결한다. 응력–변형률 경로에는 시작점·끝점을 표시해 닫히지 않은 첫 경로를 loop라고 부르지 않는다. 정상 저장·손실 탄성률, 주기 일과 실제 첫 주기 일·저장 변화·소산을 함께 비교한다.

고정 개념4단계는 병렬·직렬 차이, 초기 기억, 첫 주기와 정상 주기, 상쇄에 숨은3차 변화다. 안내3개는 같은 하중에서 초기 상태 변경, 주파수와 위상·손실 비교, 실제 시간창 에너지 수지다. 퀴즈2개는 음의 순간 전력과 비음 소산의 양립, 첫 주기와 정상 주기 공식의 차이를 묻는다.

기본 손계산 E=2,η=1,진폭0.002,ω=1과 정상 초기 탄성 변형률0.0008을 제공한다. 초기 탄성 변형률0.001의 작은3차 변화,ω=0의 사전 저장 에너지 완화,빠른 비영 기억 언더플로,주기가 시간 범위 밖인 작은 양의 주파수,주기가 산술 범위 밖인 최소 주파수,정확한 영 진폭과 작은 비영 진폭을 검증한다. 이상적인 변형률 계단을 유한 곡선으로 위장하지 않는다. 같은 장에서 완화·소산을 누락한 대조와 초기 상태를 바꾼 실험은 다른 비교다.

## 초탄성의 기하·응력·일

`neo-hookean-uniaxial-constitutive-objectivity`는 전단계수·로그 신장비·강체 회전각·현재 관측 법선각·기준 면적·기준 길이·경로 시작/끝 로그 신장비의8개 입력을 연결한다.μ∈[0.25,4]Pa,로그 신장비±ln4,각도±π,기준 면적·길이∈[0.25,4]를 사용한다. 두 횡방향 신장과 체적 보존을 표시해 평면 그림을2차원 비압축 모델로 오해하지 않게 한다.

현재/기준 모양, Cauchy/nominal 응력과 각각의 올바른 면적·힘, 전체 변형 에너지와 기준 체적당 밀도를 보여준다. 회전된 축과 실제 관측 법선,traction의 법선·접선 성분, 안정 응력 행렬과 직접 반올림 행렬을 구분한다. 경로 일은 nominal 응력과 신장 증가량을 사용하고 잘못된 Cauchy 공액 대조를 별도로 표시한다. 에너지와 에너지 변화, 저장과 소산을 혼용하지 않는다.

고정 개념4단계는 신장2의 손계산, 같은 힘을 주는 두 응력·면적, 시편과 법선의 동시 회전, 작은 신장의 안정 에너지다. 안내3개는 면적을 함께 바꾸는 힘 비교, 관측 법선을 함께/따로 회전하기, 왕복 경로의 일과 작은 로그 신장이다. 퀴즈는 압력을 결정하는 자유 측면 조건과 일축 양의 접선의 한계를 묻는다.

필수 상태는 정확한 무변형·순수 회전,압축/인장,고정 실험실 법선과 대응 물질 면의 차이,반올림 신장1과 양의 안정 에너지,에너지 밀도 언더플로와 체적 배율에서 회복되는 전체 에너지,매우 작은 대칭 경로의 상쇄다. 잘못된 면적의 힘과 잘못된 응력–변형 공액은 계산 오류를 드러내는 대조로 표시한다. 양의 일축 접선을 모든 다축 안정성·좌굴의 인증으로 확대하지 않는다.

## 통합 완료 조건

두 단원에 개념4단계·안내3개·퀴즈2개와 실제 원고·선수·이전/다음·교육과정 지도·수식 목차를 연결한다. 기존492단원·1,476안내와43실험 그룹483항목의 canonical 내용·순서를 보존한다. 수식과 그림의 단위를 명확히 하고 관측 불가한 비영 값·정확한 영·수학적으로 미정인 주기를 구분한다.

전체 테스트·타입·lint·콘텐츠·정적 export 뒤 출력을 고정한다. 한영·명암·좁은/넓은 화면에서 접근성·실제 모든 입력·예제·안내·퀴즈·저장·초기화·원본 SVG와 표를 확인한다. 초기 과도·작은 변화·대조 실험을 별도 경계 사례로 검증한 뒤에만 입문 주제 완료 수를 갱신한다. 영역 전체 감사와 연구 심화는 별도로 남긴다.
