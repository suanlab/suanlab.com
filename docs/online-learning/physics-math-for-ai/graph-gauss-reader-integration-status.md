## 연결한 학습 내용

한영18절 원고,10개념·7안내 실험·8해설 퀴즈·17예제를 연결했다. 원형 링크와 전기 운동량,접속행렬,두 제약 판정,경계 수지,rank와 차원,정준 경로,특수해/올림값,숲 좌표와Hamiltonian,순간 흐름·연구 검사에 대한 설명용 그림10개와 표지를 기존 색상·SVG체계로 작성했다. 설명 그림과 현재 실험의 결과는 구분한다.

reader는 기존 퀴즈/완료 상태 저장을 사용하고 실험의 중복 개념·퀴즈는 숨긴다. 선수 단원은 궤도·트리·앵커와Poisson정준 흐름이다. 이전/다음 읽기 순서·교육과정 지도·단원 카드·한영 검색을 연결했다. 진입은 **도서 → Interactive Book**이며 Online Book에는 교재 카드를 추가하지 않았다.
