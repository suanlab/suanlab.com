# 열역학·평형 통계역학 입문 종합 점검 계획

2026-11-07. 원래11개 주제의 집필 다음 단계는 개별 통과 기록을 묶는 작업과 영역 전체의 내용·연결·실행을 다시 대조하는 작업이다. 유한계 세 단원의 실제 교재 통합 검증을 마쳤고 아래 영역 점검으로 이어간다. 이 계획과 파일 목록만으로 영역 완료를 표시하지 않는다. 연구 심화는 별도로 남는다.

## 점검 대상과 순서

원래11주제에 작성한31단원·한영62본문을 모두 읽고, 기존 입문 `thermodynamics` 단원과의 연결도 확인한다.

## 각 단원에 필요한 근거

- 한국어와 영어 본문을 모두 읽고 가정·단위·부호·예제·풀이를 대조한다. 이미 구현된 그림을 계속 ‘예정’이라고 부르는 문장 등 화면과 본문의 불일치도 수정한다.
- 독립 참조 생성기와 모델 입력을 확인한다. 일반적인 예제뿐 아니라 영점, 경계, 지지집합, 극한, 취소·언더플로 사례를 식으로 재계산한다. 기존 검사의 단순 재실행을 내용 검토로 세지 않는다.
- 개념 단계·예측·안내·최종 문제의 정답과 해설이 같은 준비를 설명하는지 확인한다. 시각화의 축·정규화·선택·진행률이 실제 계산 결과와 일치해야 한다.
- 단원 간 선수 관계와 잘못 일반화하기 쉬운 연결을 검토한다. 수학적 유한 모형을 물리적 열역학이나 일반 샘플러 정리로 확대하지 않는다.
- 실제 교재에서 한영·명암·좁은/넓은 화면, 자유 입력·저장·복원·오류, 모션·키보드·접근성을 확인한다. 계산 worker를 사용하는 경우 취소·실패·단원 이동과 종료도 확인한다.

## 완료 조건

점검 행렬에 단원별 실제 파일 해시, 읽은 두 본문, 독립 계산, 교수 자료, 선수 연결과 화면 근거를 남긴다. 발견한 결함을 수정하고 관련 검사·전체 회귀·빌드·정적 링크 검증을 마친다. 마지막으로31단원과 기존 입문 단원의 연결을 빠짐없이 대조한 뒤에만 **입문 영역 종합 점검 완료**를 기록한다. 이후 비평형·확률열역학·복잡계의 원래10주제로 이어가며, 전체51영역·509주제와 연구 깊이의 완료는 별도로 검증한다.

## 1차 보완과 남은 점검

[가독성·초기 내용 점검](finite-size-readability-verification.md)에서 유한계 세 단원의 그림을 최소560px의 내부 폭으로 표시하고 키보드·터치 이동, 설명문 위치와 실제 최소 글씨 크기를 검증했다. 한영·명암·320/1440px의24화면에서 확인했으며 모바일12경우는 이동하고 넓은12경우는 그림 전체가 들어온다.

온도·열·일의 두 단원은 한영 본문4개를 읽고 가정·단위·부호를 대조했다. 구현된 그림을 ‘예정’으로 부르던3파일을 실제 화면에 맞췄다. 열접촉7사례와 이상기체6사례의 상태·구간 수지를 독립100자리 계산으로 대조한116비교도 통과했다. 한영 실제 본문4화면의 수정 반영을 확인했다.

행렬의 본문·가정·선택한 독립 계산 검토는 **2/32단원**이다. 이 두 단원의 전체 입력·프리셋·교수 흐름·선수 연결과 다른30단원의 검토가 남아 있다. 이번 변경으로 영역 전체 완료나 새로운 입문 주제 추가를 표시하지 않는다.

## 2차 점검 결과와 다음 수정

[첫5단원 점검](thermodynamics-domain-audit-stage2.md)에서 열접촉·이상기체의 실습 흐름을 확인하고 카르노·저장고 수지·저온 스펙트럼의 한영 본문·계산·교수 자료까지 대조했다. 행렬의 확인 항목을5/32단원으로 갱신했으며 나머지27단원과 연구 깊이는 미완료다.

`1e-999` 입력을 실제0으로 저장하던 문제를 확인하여 다섯 실습에 검증 필드를 적용했다. 같은 기존 공통 필드를 사용하는 다른10개 파일은 아직 남아 있다. 진행 JSON의 `sharedNumberFieldValidationFollowup`과 실제 사용처 목록을 따라 이 문제를 확장 수정한 뒤 영역 점검을 계속한다. 전체 입력 계층을 수정했다고 표시하지 않는다.


## 공통 입력 후속 점검 완료 · 2026-11-07

[공통 입력 수정 검증](shared-number-input-verification.md)에서 나머지10사용처의 비영 underflow·정수·오류 초안·초기화를 검증했다. 이 작업은 열역학32단원의 영역 종합 점검을 대신하지 않는다. 완전 점검은5단원이고 나머지27단원은 계속 진행한다. 다음 두 단원은 Helmholtz–KL 및 이상기체 가용 함수다. 한영 본문 검토에서 발견한 오래된 구현 미완료 문구를 수정하고, 독립 계산·교수 자료·실제 조작 화면을 대조한다.
