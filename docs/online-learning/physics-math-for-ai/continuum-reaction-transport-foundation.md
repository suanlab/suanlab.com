## 계산 모델

`src/lib/learning-continuum-reaction-transport.ts`는 두 개의 정확한 매끄러운 가족을 제공한다.

- 가역 반응: 같은 질량 기준 A↔B가 공통 Gaussian 이류·확산 운반장을 공유한다. 공간적으로 일정한 초기 조성에서 시간 의존 분율을 직접 유도했다. 종별 실제 시간/공간 미분·플럭스·원천, 양방향 전환량, 전 직선 질량과 유한 창 저장·경계·원천 수지를 제공한다. 종별 원천 합0과 관측 창의 경계 수송을 구분한다.
- Fisher–KPP: 양의 D,r에서 logistic 제곱 특수 이동해를 차원 복원했다. 실제 미분·이류와 확산 플럭스·성장 원천, 상대/실험실 속도·농도 수준 위치, 유한 창 질량과 성장 적분을 계산한다. 프로필 기준점은 K/4이고 절반 위치가 아니다. 특수 속도를 임의 초기조건의 보편 속도로 해석하지 않는다.

가역 반응률이 모두0이면 모든 조성이 정상이며 평형은 유일하지 않다. 평형에서도 양방향 전환량은 양수일 수 있다. 질량0에서는 선언된 조성과 미정인 질량 정규화 관측을 구분한다. 두 비율·작은 변화·부호와 로그를 별도로 보존하며 강제 재정규화를 하지 않는다.

성장 모델은 자원 변수를 포함하지 않는 열린 기술이다. 왼쪽 양의 plateau 때문에 전 직선 질량은 발산한다. 창 질량을 전체 질량으로 표시하지 않는다. D=0/r=0은 이 정확한 프로필 밖이며, 같은 실제 장에서 원천을 누락하는 대조와 구분한다. 포화 농도·안정 여량·성장 원천과 반올림 뺄셈, 선형 언더플로·유한 로그를 별도로 남긴다.

## 독립 검증

`scripts/learning/generate-continuum-reaction-transport-references.py`는 제품 모듈을 import하지 않고 mpmath160자리로 실제 장을 미분·적분한다. 가역 반응24사례는 두 종의 농도·미분·플럭스·원천과 물리 창 수지를, 전선24사례는 실제 도함수·비선형 성장·창 저장과 경계를 검증한다. 작은 완화·빠른 과도·정확한 정상·작은 평형의7사례와 전선 양쪽 꼬리7사례도 포함한다. 극단 꼬리 참조는 안정적인 유리식으로 여량·성장의 로그를 계산한다. 160자리 직접 뺄셈이 모든 포화 차이를 구분한다고 주장하지 않는다.

순수 모델22개와 원고·기존 데이터 보존3개 검사를 추가했다. 실제 장의 유한 차분, 같은 장의 원천 누락 대조, 질량0, 양방향 평형 전환, 부호·단위, 작은 변화와 배율 회복을 포함한다. 빠른 완화의 분율 검사는 로그 변환의 반올림을 고려해 독립 참조 허용오차로 비교한다. 비영 과도가 수학적으로 정확한 평형에 도달했다고 가정하지 않는다. 생성기는 기존 참조 파일을 덮어쓰지 않는다.

전체4,481개 검사와 타입·lint·콘텐츠1,725 URL 검사를 통과했다. 독립 참조62사례를 재생성한 파일은 fixture와 바이트 단위로 일치한다. 기존490단원·안내와43실험 그룹481항목의 canonical 내용·상대 순서를 보존했다. 기존 소스3,089개와 export4,198개는 해시가 같고 새 소스10개의 해시도 기록했다.

검사·재생성·보존 결과와 실제 종료 기록은 `.runtime/learning/continuum-reaction-transport-foundation-verification.json`에 있다. 새 단원은 아직 등록하지 않았으므로 정적 배포 빌드나 새 화면 검증을 완료했다고 주장하지 않는다. 기존 Interactive Book 메뉴와 미리보기를 유지하며 commit·push·공개 배포는 수행하지 않았다.
