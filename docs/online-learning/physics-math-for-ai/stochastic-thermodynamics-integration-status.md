- [두 저장고의 열 흐름과 숨겨진 생성](http://localhost:4175/book/online/physics-math-for-ai/reservoir-resolved-two-state-heat-flow/): 두 온도·채널 전이율·정상 전류·열·교환 엔트로피, 상태만의 가역성과 조건부 KL, 예시 채널열과 경계항·밀도를 구별한다.

## 물리·표현 계약

첫 가족의 W,Q는 계로 들어오면 양수다. 준위 변화는 확률을 바꾸지 않으며 고정 준위 이완에서 열을 교환한다. 과정 단계 축을 물리 시간 궤적으로 표시하지 않는다. 네 일 원자는 같은 일 값이라도 상태쌍별로 유지하고, 여덟 끝점 원자는 모든 중간 점프 수를 적분한 법칙이다. 도달 불가능한 원자의 열·엔트로피는 미제공이다. 정준 초기화가 없으면 같은 Jarzynski 등식을 적용하지 않으며 자유 에너지의 초기·최종 KL을 분리한다.

두 번째 가족의 평균은 항상 π에서 시작한다. 예시 시작 상태·점프 수·채널 코드는 한 결정론적 예시만 바꾸며 평균이나 일반 경로 표본을 정의하지 않는다. A/B 이름과 온도 순서를 구별하고, 저장고 교환 엔트로피 각각이 음수여도 총 생성률이 비음수임을 설명한다. 상태만 보면 생성률0이지만 표지된 열 흐름은 남을 수 있다. 조건부 채널열 확률과 초 단위 점프 시각의 밀도, 해석적 IFT와 유한 예시 합을 혼동하지 않는다.

두 가족 모두 무차원 열과 SI joule을 나누며 온도 재척도 시 에너지도 함께 바뀐다. 표시 범위 밖의 양수는0으로 대체하지 않는다. 그림에서는 미제공 숫자의 점·연결선을 생략하고 구간·부호·로그 근거를 표에서 제공한다. 그림 좌표와 반올림 숫자는 수치 인증 자체가 아니다.
