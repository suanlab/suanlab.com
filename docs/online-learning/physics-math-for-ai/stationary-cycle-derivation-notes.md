# 세 상태 순환의 유도와 수치 경계

2026-11-07. 첫 가족의 정확한 유한 모형에 관한 노트다. 본문은 `content/learning/physics-math-for-ai/stationary-flux-three-state-cycle.{ko,en}.md`에 있다. 상세평형 전체·연구 심화나 실제 홈페이지 연결의 완료 증거는 아니다.

## 행렬, 정상해와 유일성

행벡터 μ의 오른쪽에 P를 곱한다. 첫 행은(r,p,q), 다음 행은(q,r,p), 마지막은(p,q,r)다. 열의 합도1이라 π=(1/3,1/3,1/3)가 정상이다. p+q>0에서 정상 방정식은 `(p+q)xj=p*x(j−1)+q*x(j+1)`이다. 최댓값을 택하면 양의 가중치를 가진 이웃도 같은 최댓값이고, 가능한 한 방향이 고리 전체를 돌므로 정규화된 정상해는 유일하다. p=q=0은 나눗셈 없이 항등 전이로 분기하며 모든 분포가 정상이다.

`Fij=πiPij`, `Jij=Fij−Fji`이면 J01=J12=J20=(p−q)/3이다. 모든 정점의 발산은0이다. 상세평형은 각 Jij=0이므로 이 모형에서 정확히 p=q와 동치다. 현재 분포에서는 Fij(t)=μi(t)Pij이며 발산은 μi(t)−μi(t+1)이다. 이 둘을 같은 준비로 표현하지 않는다.

## 귀환과 시간 반전

p+q>0이면 모든 상태가 서로 통신한다. r>0이면 귀환1, r=0이고 양방향 이동이면 귀환2·3, 한 방향만 있으면 귀환3의 배수다. 따라서 주기는 각각1,1,3이다. 항등 전이는 한 상태짜리 닫힌 통신류3개이며 각각 주기1이다. 균일 정상 준비에서의 역전이는 P의 전치다. 조건부 시계/반시계 순회 확률 p³,q³는 정상 초기화에서 똑같이1/3을 곱하므로 그 비대칭이 유지된다.

## 총변동의 행 거리 상계

세 순환 행의 쌍별 거리는 `(|p−q|+|q−r|+|r−p|)/2=max(p,q,r)−min(p,q,r)`이다. 이를 δ로 둔다. d=μ−π의 양·음 부분의 질량은 모두 M=TV(d)다. M>0이면 d=M(a−b), a,b는 분포이고 `dP=M Σij ai*bj*(Pi·−Pj·)`다. 삼각부등식으로 TV(dP)≤Mδ를 얻는다. M=0은 직접 성립한다. t=0에서 계수의0제곱을1로 두고 반복한다.

상계와 등식은 다르다. (f,b,s)=(7,2,5), μ0=(1,0,0)에서 μ1=(5/14,7/14,2/14), TV1=4/21이고 δTV0=5/21이다. 반면 (2,1,1)은 균일 기여와 한 방향 순열의 합으로 표현되어 이 특정 준비에서1/4의 정확한 감소가 가능하다. 이 예의 등식을 일반적인 혼합률로 승격하지 않는다.

## 표시가 정상처럼 보여도 정확히는 아닌 준비

f=s=L,b=L−1,D=3L−1로 놓으면 `P=(L*11ᵀ−R−)/D`다. 합이0인 d에는 균일 항이 사라져 `dP=−dR−/D`다. 따라서 d(t)=(-1/D)^t*d(0)*R−^t이고, 점질량 초기화의 TV는2/(3D^t)다. L=1,000,000,t=64에서 세 확률이 같은 반올림 값으로 보이고 TV의 선형 표시가 불가능해도 정확한 분수는 비영이다.

모델은 공통 분모의 정수 질량으로 전이시켜 부동소수점의1/3끼리 빼지 않는다. 공약수 약분은 정확한 값을 바꾸지 않는다. 0 검사는 정수 분자를 사용한다. 표시용 Number는 nearest/ties-to-even 투영이고 범위 밖 비영은null로 둔다. 근사 로그는 인증된 초월함수 구간이 아니며, 정확한 유리수 경계와 혼동하지 않는다.

## 독립 대조의 구성

Python 기준은 Fraction 전이 행렬을 목적지별로 누적하고 각 단계에서 행렬 곱을 한다. TypeScript는 정수 질량과 공통 분모를 전이시킨다. 두 구현의 단순 반올림 일치 대신 약분된 분수 자체를 대조한다. 기준의 RREF·그래프 도달성·귀환 길이 gcd는 런타임의 명시적 모형 분기를 복사하지 않는다. 작은 준비의 전체 상태 경로 열거로 기준의 도착 확률도 대조한다.

직접 기준 대조는24설정·262선택 시점 및 고정 관측3,872개다. 전체3,135시점에는 분포 합·비음성·TV 단조성과 상계를 별도로 검사한다. 유한 경로 열거는237개의 도착 확률을 비교한다. 큰 정수 극단·정확한0·주기·항등·균일 초기화·공통 척도·비영 표시 범위 밖을 포함하지만, 허용 입력 전체에 대한 전수 검증은 아니다.
