# 순수 합성계: 수치 관례와 독립 검산 계약

2026-11-08. `bipartite-pure-schmidt-partial-trace`의 계산 정의다. 상세 본문·교수 화면·Worker·reader는 별도 후속 단계이며 이 계약으로 원래 tensor product·entanglement 주제를 완료 처리하지 않는다.

## 좌표·정규화·축약 상태

부분계 차원 a,b는 각각1…4다. 4×4 raw 복소 계수 슬롯과 두4성분 raw 국소 probe, 두 차원을50개 소유 정수로 받는다. 정수 크기는10⁶ 이하이며 차원 밖 좌표는0, 상태와 probe는 비영이다. 계수 행렬 C의 행은 A, 열은 B이고 평탄 인덱스는 i*b+j다. N=Σ|Cij|², ψij=Cij/√N이며 전체 밀도는 CC의 원소별 곱이 아니라 평탄 벡터 zz†/N이다.

부분추적을 인덱스로 직접 계산해 ρA=CC†/N, ρB=CᵀC*/N을 대조한다. C†C/N은 ρB의 전치다. 예를 들어 C의 첫 행이(1,i)이면 ρB01=−i/2, Gram의01=+i/2다. 이 부호는 관례 차이로 무시하지 않는다.

Rank(C)는 정확 복소 Gaussian 소거, 축약 상태 rank는 전체 principal minor의 양성으로 따로 계산한다. 특성 다항식은 principal minor 합으로 만들고 차원별 영 인자를 뺀 비영 다항식이 일치하는지 확인한다. 모든2×2 minor가0인 rank1에는 정확한 곱 인수를 제공한다. 비영 pivot으로 u=C[:,j],v=C[i,:]/Cij를 정하면 uvᵀ=C이고 두 raw 노름 곱은 N이다. Rank>1에는 비영 minor 증거를 남긴다.

## 일반 스펙트럼과 정밀도

스펙트럼을 qubit의 이차식으로 제한하지 않는다. 최고4차 유리수 다항식의 gcd/미분으로 square-free 인자를 만들고 각 인자의 정확 중복도를 계산한다. 정수 계수 Sturm 수열의 부호 변화로 실근 수를 세며 dyadic 중점을 나눈다. 부호 평가에는 Number나 고유값 tolerance를 사용하지 않는다.

기본 분리 폭은2⁻¹⁰²⁴다. 선형 인자나 정확 dyadic 근은 유리수 점으로 보존한다. 나머지는 근을 하나 포함한 유리수 구간이다. 유리수인 근도 알고리즘이 정확 점으로 찾지 못하면 구간으로 보고할 수 있다. exactRationalRootKnown은 정확 유리수 점으로 확인했는지의 표시이며 false가 무리수임을 뜻하지 않는다. 다항식의 실근/차수·분리 정밀도 조건이 맞지 않으면 오류를 반환하며 가상의 근을 만들지 않는다. 일반 고유벡터나 Schmidt 기저는 계산하지 않는다.

내부 스펙트럼 구간을768bit 작업 계정에 옮기고512bit 바깥쪽 구간으로 보고한다. 양의 Schmidt 가중치만 로그를 계산하며, 영 중복도는 따로 명시한다. Entropy는 중복도까지 합산하고 순수 국소 rank1의0을 정확히 보존한다. 정수 raw 계수의 유한 범위와 정확 rank 증거를 사용하며 작은 양수·gap을 합치거나 노름을 보정하지 않는다.

부분전치의 순수 상태 스펙트럼은 λi와 각 i<j의±√(λiλj), 나머지 영 중복도 a*b−r²다. 같은 값이 반복된 항을 유일한 고유공간으로 표시하지 않는다. Negativity는 양의 pair 크기의 합으로 계산해 큰 두 값을 빼는 상쇄를 피한다. 일반 혼합 상태의 PPT 분리 판정은 이 가족에 적용하지 않는다.

## 국소 측정·변환·고전적 비교

각 probe로 rank1 projector와 그 여공간 사건을 만든다. 두 사건의 공동 확률과 축약 상태의 주변 확률을 대조한다. 상대계 사건의 조건부 축약 밀도는 양의 확률에서만 정규화하며0일 때 null이다. 여공간 rank가2 이상이면 조건부 상태가 혼합일 수 있다. 상대계의 비선택 측정 뒤 자기 축약 상태가 유지되는 무신호성 계정을 정확히 확인한다.

H=I−2P인 국소 Householder 반사를 적용한다. 전체 텐서 작용과 C′=HA C HBᵀ, 축약 상태의 unitary conjugation·특성 다항식·순도를 비교한다. 이것은 명시한 국소 변환 예제이며 모든 unitary를 입력하는 기능이 아니다.

같은 기준 기저 확률로 대각화한 비교 상태를 별도로 제공한다. 이는 곱 기저 projector의 확률 혼합이므로 분리 가능하다. Bell 상태와 그 대각 혼합은 같은 국소 I/2와 기준 기저 통계를 가질 수 있으나 전체 밀도·순도가 다르다. 기준 기저 상관만을 얽힘 증거로 부르지 않는다.

## 독립 참조와 실패 수정

참조 생성기는 생산 TypeScript를 import하지 않는다. SymPy의 tensor product·직접 부분추적·rank·특성 다항식·principal minor·조건부 행렬·전체 국소 작용을 사용한다. Mpmath250dps 일반 복소 Hermitian 고유값 계산으로 축약 스펙트럼을 얻고, 전체 최대16×16 부분전치 고유값에서도 negativity를 대조한다. 보고 참조는210자리이며 구간 폭 max(1,|참조|)×10⁻¹²⁵를 요구한다.

SymPy 계산 전에 복소 유리수 행렬을 정확히 전개한다. 실제 노름 식이19연산인 상태를 정확 정수38로 정리하는 병목을 확인하고 구형 생성기를 종료한 뒤 수정 소스로 다시 생성했다. 영 고유값이 다른 단순근과 같은 square-free 인자에 들어갈 수 있으므로, 독립 중복도 검사에서는 정확 rank로 정한 영 인자를 먼저 제거한다. 사례 삭제나 정밀도 완화로 실패를 해결하지 않는다.

관례 배경은 [Preskill Chapter2](https://www.preskill.caltech.edu/ph219/chap2_15.pdf)의 합성계·부분추적·Schmidt 설명이다. 위 유계 입력·정확 rank/다항식·Sturm 계산·독립 참조와 손계산 구성은 이 교재에서 설계했다. 최종 검증 수와 재생성·보존 근거는 별도 단계 보고서에 기록한다.
