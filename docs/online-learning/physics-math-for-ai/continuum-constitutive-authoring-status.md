## 연결한 실습

점탄성의 기억·소산과 비압축 초탄성의 응력·면적·객관성 원고를 기존 테마의 실습에 연결했다. 선수·이전/다음·교육과정 지도·수식 목차와 새 커버 그림을 제공한다. 진입은 **도서 → Interactive Book**이며 Online Book에 교재 진입 카드를 추가하지 않았다.

- 점탄성:8입력·20예제·15그래프. 병렬/직렬 응력,초기 기억·과도·정상 주기,첫 주기와 정상 주기의 일,작은3차 변화,변형률과 속도,내부 변형,저장 에너지·전력·소산·시간창 수지,응력 경로와 주파수 응답을 제공한다.
- 초탄성:8입력·18예제·기하1개와 그래프9개. 실제 기준/현재 모양,두 응력·면적의 힘,관측 법선과 traction,작은 신장 에너지,비선형 응력·접선·압력,공액 일·반환 경로와 잘못된 면적/공액 대조를 제공한다.3차원 변형의 평면 투영이며 세 번째 방향을 생략한2차원 비압축 모델로 설명하지 않는다.

각 단원에 실제 고정 예제4단계·안내3개·퀴즈2개를 연결했다. 응력 경로의 가로축은 비영 진폭에서 변형률/|진폭|으로 정규화해 작은 변형을 읽기 쉽게 했으며 그림 면적을 실제 일로 바꾸는 진폭 배율을 명시했다. 영 진폭에서는 실제 영 변형률을 사용한다. 변형률의 로그 크기와 부호를 복원해 작은 선형 변형률 관측이 사라져도 정규화 좌표에서 회복 가능한 값을 보존한다.

## 계산과 회귀 검사

[기초 모델과 상세 원고](continuum-constitutive-foundation.md)의64개 독립 참조를 유지했다. 주파수 스캔에는 주기 전체 적분을 반복하지 않는 `viscoelasticModuli`를 추가하고 기존 주기 계산과 같은 계수 계산을 공유한다. 초기·주기·전력·기억·행렬·힘·일의 기존 독립 검사를 보존했다.

새 통합16검사는 등록·정의역·38예제·실제 convolution과 물리 시간 적분·전체 행렬 참조·계수 전용 계산·샘플링과 끝점·관측 부재·작은3차 변화·비영 꼬리·체적 배율 회복을 다룬다. 관측 법선의 두 끝점은 연산 순서의 반올림을 피하도록 정확한±π를 포함한다.

전체4,543검사,타입·lint·콘텐츠1,729 URL을 통과했다. 정적1,737페이지 생성과 export1,732 HTML의 링크·자산·fragment·canonical 검사를 통과했다. 실습 그림의 가로축 개선을 위해 최초 빌드를 의도적으로 종료하고 최종 소스에서 다시 빌드했다. 종료된 초기 빌드를 최종 성공 증거로 사용하지 않는다.
