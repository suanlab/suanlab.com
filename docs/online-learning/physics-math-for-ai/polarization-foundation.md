## 순수 계산 모델과 관례

`src/lib/learning-polarization.ts`는 교재 데이터·Node API·외부 패키지에 의존하지 않는다. 전파는+z, 오른손 기저는(x,y,z), 시간 인자는 exp(−iωt)다. 실제 장은 복소 Jones 벡터에 시간 인자를 곱한 실수부다. 정규화 강도는 복소 횡방향 성분의 제곱합이며, SI 복사조도에는 별도 매질 교정과 실수장 주기 평균 계수가 필요하다.

- `jonesPolarizationExperiment`는 실제 입력·중간·출력 벡터, 시간 위상129점의 실수 궤적, 타원 축·방향·타원율, 분석기 스캔·투과율을 반환한다. 전체 위상과 상대 위상, 단위 상태 표현과 원래 투과량을 구분한다.
- 회전 지연판은 평균·차 위상과 두 배 축각으로 구성해 영지연의 항등과45도 반파장판의 정확한 교환을 유지한다. 정확히 입력한 π/2 배수의 삼각함수만 정준값을 사용한다. 이웃 각도를 어두운 설정으로 뭉개지 않는다.
- 단축은 비슷한 고유값을 빼는 대신 교차 성분과 장축을 사용해 계산한다. 영장·없는 성분의 상대 위상·원형 상태의 주축 방향을 미정으로 둔다. 거의 퇴화한 방향에는 명시한 상대 반올림 허용오차를 적용한다.
- `stokesPolarizationExperiment`는1–16개의 비음수 가중치를 정규화한다. 결맞음 행렬은 실현 외적을 평균하며 평균 Jones 벡터를 제곱하지 않는다. 부분 편광 전체에 유일한 실제 타원이 있다고 가정하지 않는다.
- 등방 탈편광은 양의 Pauli 혼합으로 구성하고 결정적 소자보다 먼저 적용한다. 강도 손실과 편광도 변화를 분리한다. 무편광을 걸러 편광도가 높아지더라도 전체 투과량이 감소한 사실을 유지한다.
- Stokes 부호는 (Tr C,Cxx−Cyy,2Re Cxy,−2Im Cxy)다. (1,i)/√2의 S3가 양수다. Mueller 기저는(I,Z,X,Y)이며 실제 Jones 변환과 제곱 관측 변환을 따로 반환한다.
- 여섯 분석기 관측은 실제 실현마다 비음수 제곱 크기를 구해 평균한다. 전개된 큰 항의 뺄셈으로 가짜 음의 검출 강도를 만들지 않는다. 복원한 Stokes는 원래 관측 결과로 보존한다.
- `coherencyFromStokes`는 원뿔 밖의 원자료를 거절하며 안쪽으로 투영하지 않는다. `polarizationCoherencyState`는 총 강도·Hermitian 구성·양성을 검사한다. 정규화 편광도만 부동소수점 허용오차64ε 안에서 보정하고 원래 결맞음 행렬은 바꾸지 않는다. 영강도의 편광도·정규화 상태·투과율은 미정이다.

## 독립 기준값과 실제 비교

`scripts/learning/generate-polarization-references.py`는 제품을 불러오지 않고 `scripts/fixtures/polarization-independent.json`을 생성한다.48개 Jones 계는 실제 주축 벡터의 기하학적 투영으로 계산한다. 시간 위상816개 표본에서 입력·중간·출력의 실제 실수 벡터를 구하고, NumPy SVD로 타원 축을, QUADPACK의 실제 한 주기 적분으로 강도 계수를 확인한다.

48개 집단의 여섯 분석기288개 관측값도 실제 실수장 적분으로 대조한다. Mueller 열은 제품의 Pauli 대각합 공식을 다시 쓴 것이 아니라 여섯 물리적 입력 상태의 출력 차이로 복원한다. 편광도는 별도 Hermitian 고유값으로 구하며 SymPy로 Malus 항등식의 잔차0을 확인한다.

실제 제품과의 최대 절대 차이는 Jones 성분·타원 축 약4.45×10⁻¹⁶, 실제 주기 평균 강도1.12×10⁻¹⁵, 시간 벡터 성분8.33×10⁻¹⁶, 결맞음 성분8.89×10⁻¹⁶, 분석기 강도1.78×10⁻¹⁵, Mueller 성분·편광도4.45×10⁻¹⁶였다. 결과는 `.runtime/learning/polarization-reference-comparison.json`에 있다. 선택한 유한 사례의 관측 차이이며 보편적 오차 상한은 아니다.

원고의 타원 수치 예제와3:1 혼합의 회전도 별도 검사했다. 수평·수직3:1은 S=(1,1/2,0,0),45도 사분파장판 뒤에는(1,0,0,−1/2)다. 네 선형 분석기는 각각1/2, 두 원형 분석기는1/4와3/4를 관측한다.

## 상태 유효성과 장치 물리성의 차이

전치 사상은 Stokes 원뿔을 보존하지만 고정한 Jones 집단 모델에서는 비음수 Jones 혼합으로 구성할 수 없다. 독립적으로 만든 비정규화 Choi 행렬의 고유값은(−1,1,1,1)이다. 이는 단순한 출력 제약만으로 AI가 예측한 장치의 물리성을 인증할 수 없다는 연구 대조 예다. 더 넓은 능동·위상 켤레 소자 클래스의 가능성을 부정하는 주장이 아니다.

[NIST 설명과 실제 읽은 범위](polarization-source-audit.md)를 유지한다. 문서가 링크한 원 논문 전체를 읽거나 NIST 라이브러리를 설치·실행한 것으로 기록하지 않는다.

전용27개·전체3,668개 테스트, TypeScript·lint·기존 등록 콘텐츠1,686개 URL 검사가 실제 종료0으로 통과했다. 네 원고를 포함한2,850개 소스 해시가 최종 검사 동안 유지됐으며 기존 홈페이지의2,842개 소스도 바뀌지 않았다. 등록 데이터는 `pre-polarization-data.ts`와 바이트 단위로 같다.
