## 물리·수치 의미를 보존한 표시

Hopf 그림은 실제 반경을 쓰며 매 기록을 단위원으로 맞추지 않는다. 정확한 원점의 위상은 비워 둔다. 반경 회복과 접선 회전을 나누어 평형 원을 주기 궤도라고 부르지 않는다. 임계의 진폭 반감시간과 제곱 진폭 반감시간도 구분한다.

두 위상은 같은 단위원 그림과 함께 감지 않은 상대 위상·순간/유한 창/장시간 평균 주파수를 제공한다. 표시 분기 번호와 완료 회전 수를 따로 표시한다. 안정·불안정·임계 고정 위상과 선형 성장률을 비교할 수 있다. R₁=1인 순간의 정렬을 주파수 잠김이라고 자동 판정하지 않는다.

유한 집단에서는 개별 위상·고유 주파수·실제 속도·창 평균을 함께 표로 확인한다. 반대 집단의 R₁=0,R₂=1과 사분점의 R₁=R₂=0,R₄=1을 구별한다. 정확 대칭 항등식과 일반 부동소수점 관측을 구별하고0의 평균 방향은 정의하지 않는다.

RK4의 n,2n,4n 비교와 d₂/15는 엄밀한 오차 경계가 아니다. 해석적 균형 해와 수정하지 않은 RK4의 차이도 남겨 계산 오차를 물리적 잡음으로 해석하지 않도록 한다. 기록 밀도와 적분 격자는 별개다. 별도 Lorentzian 비교는 폭·분포·무한 집단·다양체 조건을 밝히고 유한 배열의 임계값을 측정했다고 표시하지 않는다.
