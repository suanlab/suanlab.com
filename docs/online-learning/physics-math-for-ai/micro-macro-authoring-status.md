## 검증과 발견한 문제

개념 예제와 실험 표가 같은 접근성 이름을 쓰는 문제를 실제 읽기 페이지에서 찾았다. 개념 표에 `고정 개념 예제 / Fixed concept example` 문맥을 붙이고, 두 화면을 함께 렌더링하는 중복 이름 회귀 검사를 추가했다.

전체 테스트의 최종 결과는 6986개 통과·실패 0개다. 여기에는 다음 앙상블 가족의 계산 기반 테스트 32개도 포함된다. 린트·타입 검사·콘텐츠 검증·빌드·정적 출력 검사도 확인했다. 정적 출력은 HTML 1750개와 내부 링크·자산·fragment·sitemap·canonical을 검사했다.

실제 읽기 화면의 무거운 계산에서 중단·재시도, 언어·테마 변경, 클라이언트 화면 이동, 저장 입력 복원·계산 완료와 새 예제 전환을 검증했다. 생성된 worker 11개가 모두 종료됐다. 모션 자동 비교·전역 일시정지·수동 한 단계·모션 감소·실제 화면 밖 정지를 확인했다. 메뉴·breadcrumb·검색은 새 단원과 모바일/데스크톱에서 확인했다. 두 실제 읽기 화면의 모바일 한글 밝은 테마와 데스크톱 영어 어두운 테마 스크린샷도 검토했다.

화면 행렬의 최종 결과는 `.runtime/learning/micro-macro-integration/reader-result.json`, 모션·계산은 `reader-interactions-result.json`, 연결은 `navigation-result.json`에서 확인한다. 결과 파일이 없는 검증은 완료로 간주하지 않는다. 전체 테스트 실행 래퍼는 143을 반환했지만 최종 테스트 runner 요약은 6986개 전부 통과·취소 0개까지 기록되어 있으며, 종료 요약을 별도 검사했다.

## 남은 순서

한영·명암·320px/1440px의 24개 실제 읽기 화면 조합에서 개념 전환 96회, 안내 72회, 예제 160회, 퀴즈 선택 144회, 저장 재로드 24회를 확인했다. 전체 main 영역의 접근성 280상태에서 위반이 없었고, 영어 한글 혼입·페이지 가로 넘침·비유한 SVG 좌표·페이지 오류도 없었다. 실제 Next worker 자산 URL의 HTTP 200 응답도 확인했다. 다음은 앙상블의 유한 저장고 본문, 정준 에너지 요동, 입자 교환이다. 첫 계산 기반은 `finite-reservoir-model-foundation.md`에 기록했다. 이후 분배함수, Boltzmann/Gibbs 분포, 상전이·질서변수, 상관·요동, 상세평형, 유한계·열역학 극한 및 다른 영역을 계속한다. 연속 측도·상호작용·양자 통계·연구 수준의 확장도 미완료다. 공개 배포는 이번 작업에 포함하지 않았다.
