## 물리와 수치의 계약

`src/lib/learning-induction-waves.ts`는 데이터·파일·AI 모듈을 가져오지 않는 순수 계산 모델이다. 기존 Maxwell 모형의 일정 SI 계수와 일관된 광속을 사용한다.

유도 모형은 Bz=b₀+b₁t+b₂t²/2, E=(b′y/2,−b′x/2,0)와 J=−ε∂tE를 유계 영역에 지정한다. 필요한 경계와 원천을 공급하는 제조해이며 유한 고립 솔레노이드·물질·도선 동역학을 푼 해가 아니다. 양의 xy 경로 법선은+z다. 폭 L=L₀+ut, 높이 H에서 전기 순환−b′LH와 운동 기여−buH를 따로 계산하며 합을 움직이는 자속의 음의 시간 변화율과 비교한다.

L₀∈[1,2] m, u∈[−0.25,0.25] m/s, t∈[−2,2] s는 전체 지원 구간의 양의 폭을 보장한다. 경로 붕괴를 면적0의 간단한 경우로 임의 처리하지 않는다. 높이0에서는 적분0이지만 면적당 평균은 미정이다. 폭 증가분의 산술 손실이 생기면 좌표를 만들어 넣지 않고 폭·꼭짓점을 사용 불가로 보고한다. 다른 계산 가능한 관측은 따로 유지한다.

자속의 삼차 다항식에서는 상수 항을 먼저 소거하여 작은 구간 변화를 유지하고, 직접 끝값 차감과 비교한다. 일정한 물리적 B는 움직이는 경로의 기전력에 기여하므로 전위의 게이지 상수처럼 버리지 않는다. 자기력이 개별 전하에 하는 순간 일률0과 외부 장치의 기계적 에너지 공급을 구분한다.

펄스는 E=f(z−ct)+g(z+ct), B=[f(z−ct)−g(z+ct)]/c이며 두 Gaussian이 같은 초기 E를 나눈다. 초기 B와 ∂tE는 진행 비율에 맞게 달라진다. 두 성분의 파동 식과 두 발산을 모두 통과해도 임의 B=0을 붙인 이동 E는 일반적으로 일차 Maxwell 관계를 위반한다. 한 점의 도함수0과 전체 가족의 적합성도 분리한다.

가까운 Gaussian 차이는 지수 차이와 expm1로 계산하여 작은 비영 B를 유지한다. Gaussian 꼬리의 수치 손실과 영진폭·정확한 대칭 영점을 구별한다. σ≥0.1 m, |z|≤4 m, |t|≤4 s와 |ct|≤8 m는 명시적 지원 범위다. 기본 SI 계수에서는 ns 규모가 필요하며 입력을 몰래 자르거나 감지 않는다. 가로로 무한한 평면 장이며 유한3차원 안테나 복사장·날카로운 파면이 아니다.

비영 중간 곱의 표현 손실은 사용 불가로 표시하는 보수적 계약이다. 다른 계산 순서가 어떤 값을 회복할 가능성까지 부정하지 않는다. 해석적 도함수·상쇄·잔차는 독립 검증이나 엄밀한 오차 인증이 아니다. 장의 에너지·Poynting 흐름과 매질·경계는 다음 원래 주제로 남긴다.

## 실제 검증과 한계

전용24개·전체4,013개 테스트와 타입·lint·콘텐츠1,702 URL 검사가 통과했다. 기존468개 단원·안내,42개 실험 그룹459항목과 상대 순서를 등록 전 동결 canonical 기준으로 보존했다. 네 원고를 실제 콘텐츠 로더로 렌더링하여 strict KaTeX, 언어별 수식 일치, 목차 앵커의 유일성, 접근 가능한 수식·표 스크롤, 영어 한글 잔존 없음과 문제 해설을 확인했다.

별도 Python 생성기는 제품 코드를 가져오지 않는다. 이동 경로81조건의 실제 E·dℓ와 (u×B)·dℓ를 네 모서리에서 SciPy 적분하고 시간 적분·자속 시간5점 차분과 대조했다. 펄스54조건은 장·공간/시간5점 차분·파동 이계 미분·실제 E 선적분과 선속 변화율을 검사했다. B=0 음성 대조9조건과160자리 mpmath의 작은 Gaussian 차이4조건·작은 자속 변화2조건도 비교했다. 생성 파일은 재실행하여 바이트 재현성을 확인했다.

최대 관측 차이는 이동 자속 시간 차분1.36×10⁻¹² 이하, 펄스 일계 차분1.97×10⁻¹² 이하, 이계 차분1.42×10⁻⁹ 이하다. 작은 차이6조건은 저장한 고정밀 기준과 상대 차이0을 보였다. 선택한 표본의 관측이며 모든 입력에 대한 엄밀한 오차 상한은 아니다.

기존 홈페이지 소스2,945개·출력4,151개를 보존하고 새 파일을 포함한 소스2,955개를 동결했다. 미등록 원고 단계이므로 새 빌드·화면 점검·공개 배포는 하지 않았다.
