# 입자 교환 한영 본문 검증 현황

2026-11-07. `grand-canonical-finite-occupancy-fluctuations`의 상세 한영 본문과 풀이를 작성했다. **교육 UI·홈페이지 등록과 실제 읽기 페이지 검증은 미완료**다. 전체 앙상블 주제와 교육과정의 완료를 뜻하지 않는다.

## 내용

언어별 15개 절·같은 수식 16개·표 2개·풀이 6개를 구성했다. 영문은 2748단어, 한글은 한글 문자 5122개다. 고정 자리 수와 변하는 입자 수에서 출발해 다음을 연결했다.

- 입자 수 분포와 선택한 수 내부의 조건부 배치
- 입자·빈자리 평균, 에너지/입자 수 분산과 공분산의 단위
- α 고정·μ 고정의 미분과 화학 응답, 열린 계의 온도 기울기
- Grand potential과 공통 에너지/화학 기준 변환
- 양의 쪽 온도 0의 빈/가득 찬/임계점 준비와 서로 다른 공동 극한 경로
- 유계 음의 온도, 발산하는 log Ξ와 유한 Ω, 표시되지 않는 확률에서 복원되는 응답

화학 응답을 입자 흐름이나 등온 압축률로 바로 해석하지 않는다. 고정 입자 수 선택과 독립 gate의 차이를 AI의 표집 문제에 연결하되 물리적 보정 없이 에너지나 소산을 부여하지 않는다.

## 검증

`learning-grand-occupancy.test.ts`와 `learning-grand-occupancy-content.test.ts`의 **50개 검사 모두 통과**했다. 실제 콘텐츠 로더로 엄격한 KaTeX 렌더링, 한영 수식 일치, 목차 앵커, 수식·표의 키보드 스크롤 표시를 확인했다.

손계산의 분포·모멘트·응답·퍼텐셜을 대조했다. β 미분의 고정 좌표가 다르면 결과가 달라지는 사례, 고정 μ에서 음수가 되는 에너지 온도 기울기, 공통 기준 이동, 조건부 배치와 엔트로피 분해, 경로에 따라 다른 저온 임계점의 극한을 계산으로 확인했다. 확률의 표시 범위 밖에서도 표현되는 응답과 온도 0에서의 실제 지지집합도 구별했다.

세 앙상블 가족의 모델·본문을 함께 검사한 **140개 검사도 모두 통과**했다. 타입 검사·변경 검사 파일 린트·콘텐츠 검증을 통과했다. 기존 모델·기준값과 이전 소스·자산·검사 3942개, 정적 출력 4243개를 보존했다. 이 숫자는 새 파일을 포함한 현재 전체 파일 수를 뜻하지 않는다.
