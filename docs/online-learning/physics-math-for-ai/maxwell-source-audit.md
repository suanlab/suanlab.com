# Maxwell 방정식의 자료 대조와 독립 준비

2026-11-05 자료 준비 당시의 기록이다. 이후 [계산 모델·상세 한영 원고](maxwell-foundation.md)를 작성·검증했다. 이후 [홈페이지 등록·시각화·상호작용 통합 검증](maxwell-authoring-status.md)을 마쳤다. 아래 준비 계산 자체로 주제 완료 수를 늘리지는 않는다.

## 확인한 1차 자료

[MIT 8.02T Chapter 13, Maxwell's Equations and Electromagnetic Waves](https://ocw.mit.edu/courses/8-02t-electricity-and-magnetism-spring-2005/13e4e0069a9ffca5ae3f909083695c2b_chapte13em_waves.pdf)의 §13.1–13.4를 확인했다. §13.1은 전도 전류만 사용한 Ampere 법칙의 면 선택 문제와 변위 전류를 설명한다. §13.3은 네 적분·미분 법칙을 모으고 §13.4는 원천 없는 평면파를 다룬다.

교재는 SI와 방향을 지정한 고정 면·경로를 사용한다. 닫힌 면의 Gauss 법칙과 열린 면 경계의 Faraday/Ampere–Maxwell 법칙을 구분한다. 전도 전류와 ε∂tE는 모두 전류 밀도 단위를 가지지만 후자를 실제 전하 운반자의 이동과 동일시하지 않는다. 매질의 D·H·분극·자화·구성 법칙은 별도 심화이며 여기서는 일정한 계수의 진공형 수학 모형을 명시한다.

## 후보 두 단원과 가정

| 후보 ID | 중심 질문 |
| --- | --- |
| `maxwell-plane-wave-local-integral-laws` | 네 국소 법칙과 방향 있는 적분 법칙이 같은 장을 어떻게 검사하는가? 원천 없는 정현 평면파의 공간·시간 미분, 서로 다른 방향의 직사각형 경로, 닫힌 면 선속과 일관된 파동 계수를 비교한다. |
| `maxwell-charge-displacement-continuity` | 전하 보존과 변위 전류가 어떻게 연결되는가? 유계 영역에 지정한 방사형 시간 의존 E·ρ·J를 사용해 전도/변위 전류의 상쇄, 닫힌 면 전하 수지와 초기 Gauss 제약을 구분한다. |

첫 후보의 자체 검증 예제는 +z 진행, E_x=E₀ cos(kz−ωt), B_y=E₀/c cos(kz−ωt), c=1/√(εμ), ω=ck다. xz 경로를 +x→+z 순서로 돌면 법선−y이며 Faraday 선적분을 검사한다. yz 경로를 +y→+z로 돌면 법선+x이며 Ampere–Maxwell 적분을 검사한다. 예전 정적 단원의 반올림 k·μ와 별도의 정확한 광속을 임의로 섞지 않는다. 평면파는 기본 법칙의 확인 예제이며 유한 안테나·파동 묶음·유도·복사·에너지 흐름의 후속 주제를 완료한 것이 아니다.

둘째 후보는 유계 영역에서 E=a(t)r, B=0, ρ=3εa(t), J=−εa′(t)r를 지정한다. a(t)=a₀+a₁t인 계산에서는 J+ε∂tE=0이며 전하 보존이 성립한다. 전하가 쌓일 때 경계로 전도 전류가 유입되는 조건을 명시한다. 무한 공간의 고립된 유한 전하 장치나 물질 구성 법칙을 푼 해로 주장하지 않는다.

진화 식과 연속 방정식을 만족해도 초기 Gauss 오차가 자동으로0이 되지는 않는다는 반례도 준비한다. ρ에 일정한 편차를 더하면 시간 보존 관계는 유지되어도 Gauss 제약은 어긋날 수 있다. 이 반례를 물리적으로 완전한 Maxwell 해라고 부르지 않는다.

## 실제 독립 탐색

`.runtime/learning/prepare-maxwell.py`는 제품 코드를 가져오지 않는다. 일정한 양의 ε·μ로 c를 계산한 평면파54조건에서 SciPy 면적분의 시간5점 미분과 경로 선적분을 대조했다. 별도의 공간·시간5점 미분도 확인했으며 최대 관측 차이는4.46×10⁻¹¹이다.

유계 방사형 전하 모형81조건에서는 실제 삼차원 벡터의 구면 선속·전도 전류를 같은 면적의 방향 표본으로 합했다. 전하의 시간 미분, J+ε∂tE와 연속 방정식을 별도 차분했으며 최대 관측 차이는4.82×10⁻¹⁰이다. 정규화된 교육 계수·선택한 표본에서 관측한 차이이며 엄밀한 오차 상한이 아니다.

결과는 `.runtime/learning/maxwell-exploration.json`, 실제 종료는 `maxwell-preparation-exit.json`이다. 이후 제품 모델에서는 영진폭·영파수·방향·닫힌 면/퇴화 경로·단위·수치 범위·초기 제약과 음성 대조를 추가한다. 상세 한영 원고와 실제 화면 검증은 별도 단계다.
