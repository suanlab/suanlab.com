# 중첩·간섭·회절: 계산 모델과 한영 원고

2026-11-05. 계산 모델 두 개와 상세 한영 원고 네 개를 작성한 기반 단계의 기록이다. 이후 홈페이지 연결과 화면 검증을 마쳤으며 현재450개 단원·1,350개 안내 실험, 원래 범위253개 입문 검증·109개 미완료다. 최신 근거는 [홈페이지 연결 기록](interference-diffraction-authoring-status.md)에 있다. 아래 기반 단계의27개 전용 검사와 미등록 시점 수치는 당시 이력이다. 전체51영역·509주제와 연구 심화 범위를 유지한다.

## 순수 계산 모델

`src/lib/learning-interference-diffraction.ts`는 Node API·교재 데이터·외부 패키지에 의존하지 않는다. 정규화 강도는 무차원 제곱장 관측량이며 실제 줄의 에너지나 매질 미지정 W/m²가 아니다.

- `coherentSuperpositionDetector`: 비음수 위상 가중치를 정규화하고 실현별 관측량을 평균한다. 장을 먼저 평균해 제곱하지 않는다. 위상 모멘트와 실제 유한 노출 상호 결맞음의 켤레 관례를 명시한다.
- 순간값·노출 평균·실수장 제곱을 구분한다. 음의 sinc는 무늬 위상을 뒤집는다. 한 경로가 없으면 상호 결맞음은 미정, 가시도는0이며 모두 어두우면 가시도도 미정이다.
- 어두운 무늬는 큰 항의 뺄셈 대신 비음수 식으로 계산한다. 거의 평탄한 집단에서도 실제 평가한 두 극값의 큰 값/작은 값을 택해 가짜 음의 대비를 피한다.
- 실제 실수장 제곱은 비음수 적분으로 구하고 닫힌 식·세분화와 비교한다. 작은 노출을 큰 중심 시각에서 뺄 때 구간이 사라지는 문제를 발견해 단위 노출 좌표에서 적분하도록 수정했다. t0=16, T=1e−18에서 약0.06111365인 값을 가짜0으로 만들지 않는다.
- `finiteApertureDiffraction`: 각 직사각 구간에서 수치 Fresnel 장과 해석적 먼거리 장을 구한다. 전체 폭w, η=xw/(λz), F=w²/(λz)를 사용한다. 두 장에서 관측면 위상을 유지하고 공통 종방향 위상만 생략한다.
- 각 무늬의 최고점을 따로1로 맞추지 않는다. 원래 강도와 공통 거리 스케일을 제거한 I/F, 기대 투과 노름을 분리한다. 기대 개구 노름을 무한 스크린의 독립 측정량으로 표시하지 않는다.
- 개구 이차 위상·횡방향 기하 비율·거리 전개의 다음 위상 항을 별도 진단한다. 근축 모델의 수치 적분 정확성과 실제 전체 파동 근사의 타당성을 혼동하지 않는다. 세분화 차이는 보증된 오차 상한이 아니다.

## 독립 기준값

`scripts/learning/generate-interference-diffraction-references.py`는 제품 코드를 불러오지 않는다. `scripts/fixtures/interference-diffraction-independent.json`에48개 간섭 사례와36개 개구 계·468개 위치를 저장한다.

간섭은 실제 복소 크기·실수 제곱의 QUADPACK 적분으로 구하고, 서로 다른 세 위상에서 독립 평균한 결과로 가시도를 복원한다. 회절은 분리하지 않은 실제 복소 Fresnel 커널의 적분과 SciPy의 별도 Fresnel 특수함수로 대조한다. 두 방법의 최대 차이는 약1.56e−14다. 먼거리 장도 개구의 복소 적분으로 검사한다. SymPy로 결맞음과 진폭 불균형의 동일 곡선을 확인했다. 극히 작은 노출에는 별도의70자리 mpmath 기준값을 추가했다.

전용 테스트는 `scripts/learning-interference-diffraction.test.ts`다. 단순한 구현 복제 대신 관측 순서·미정 값·노출 극한·음의 sinc·비식별·접한 슬릿의 넓은 개구 극한·차단과 병진·광축 상쇄·먼거리 열과 실제 엄격한 KaTeX 렌더링을 검사한다.

## 실제 통과한 검사

전용27개·전체3,591개 테스트, TypeScript·lint·기존 등록 콘텐츠1,682개 URL 검사가 통과했다. 네 원고는 실제 콘텐츠 로더에서 엄격한 KaTeX와 한영16개 목차·각 여섯 개 해설 문제로 검사했다. 최종 기준값 생성과 각 검사 프로세스의 실제 종료0을 확인했다. 작은 노출 구간의 수정 전0과70자리 기준값, 단위 구간 수정의 회귀 검사도 포함한다.

최종 근거는 `.runtime/learning/interference-diffraction-foundation-verification.json`, `interference-diffraction-*.log`, `interference-diffraction-foundation-source-hashes.json`이다. 현재 UI 감사 대상2,816개 파일은 변경되지 않았고 미등록 기반 파일8개를 포함한2,824개 해시가 최종 검사 동안 유지되었다. 등록 데이터는 `pre-interference-diffraction-data.ts`와 바이트 단위로 같다.

동시에 기존 파동 그래프의 작은 물리량 축을 개선하고 [새 빌드와 화면 검증](wave-axis-readability.md)을 마쳤다. 그 화면 근거는 등록448개 단원의 실제 변경을 검증하며, 미등록 간섭·회절 원고의 새 홈페이지 연결을 검증한 것으로 세지 않는다.

## 기반 단계에서 정한 홈페이지 연결 계획

아래 계획은 이후 모두 연결·검증했다. 최신 화면·진행 수치는 [홈페이지 연결 기록](interference-diffraction-authoring-status.md)을 따른다.

1. 정규화 장·실수장·검출 평균·위상 집단을 각각 보여 준다. 부분 결맞음 앙상블에 유일한 실제 장이 있다고 그리지 않는다.
2. 노출·경로 진폭·위상 집단을 독립 조절하고 같은 간섭 곡선의 다른 원인을 안내 실험으로 비교한다. 실수 제곱과 해석 신호 강도 사이의1/2 가정도 설명한다.
3. 유한 폭·중심 간격·각 슬릿 위상·복소 기여와 실제 전파 분포를 연결한다. 공유 위상 기준, 원래 강도·거리 축척·투과량을 보존한다.
4. 기존 테마의 개념 단계·안내 실험·해설 퀴즈를 연결하고 기존448개 단원·설정·상대 순서를 보존한다. 실제 화면·영어·반응형·다크 모드·접근성·조작·수치 검증 후에만 등록·입문 검증 수를 늘린다.

뒤의 분산·군속도·편광·Fourier optics 전체는 별도 원래 주제로 남긴다. [전체 남은 순서](remaining-next-steps.md)를 유지한다. 이번 작업은 공개 배포·commit·push를 포함하지 않는다.
