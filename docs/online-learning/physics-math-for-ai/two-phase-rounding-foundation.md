# 두 상의 유한 반올림·복소 영점 계산 기반

2026-11-07. 유한계와 열역학 극한의 세 번째 가족 `two-phase-partition-zeros-rounding`의 모델과 독립 기준을 검증했다. [유도·손계산·로그 구간 증명](two-phase-rounding-derivation-notes.md)을 작성했다. 첫 두 가족의 정확 모델과 한영 원고는 보존한다. 세 번째 한영 본문, 세 가족의 worker·학습 화면·등록은 아직 미완료다.

## 구현과 계약

- 모델: `src/lib/learning-two-phase-rounding.ts`.
- 독립 생성기: `scripts/learning/generate-two-phase-rounding-oracle.py`.
- 기준: `scripts/fixtures/two-phase-rounding-oracle.json`.
- 검사: `scripts/learning-two-phase-rounding.test.ts`.

N=1..512, 양의 활동도 정수 무게1..10^6, 접근 가중치0≤C/D≤1과 양의 분모≤10^6, 방향±1, 고정·역크기·역제곱 경로의 정확히7개 입력을 받는다. 접근 경로에서는 활동도 무게, 고정 경로에서는 접근 방향·가중치를 사용하지 않음을 출력 계약에 명시한다.

허용 배치는 모두0과 모두1의 두 개뿐이다. Z=1+z^N은 독립 자리의(1+z)^N이나 실제 Ising·Curie–Weiss 상태 합이 아니다. 확률·밀도/총수 모멘트·고정 N의 장 응답·지수화한 압력 보정은 유리수로 정확히 보존한다. 압력과 로그장,10–90%의 g 폭, 접근 극한은 유효한 방향성 구간으로 계산한다.

극소 ln(1+t)는 정확한 q=t/(2+t)와 유계 급수 H를 분리해 계산한다. 표시상1+t=1이어도 양의 로그 보정 하한이 남는다. 기존 초월함수 구간 도구는 수정하지 않고 재사용했다. 복소 근은 정확한 회전수·켤레·다항식 위상 항등식을 제공하며 cos/sin 좌표와 거리는 그림용 근사로 표시한다.

## 확인한 학습 구별

유한 압력은 양의 실수 활동도에서 매끄럽고 극한 가지와의 오차는 ln2/N 이하이다. 하지만 공존점의 밀도 분산은1/4로 남고 응답은 N/4로 자란다. 역크기 접근의 밀도 극한은 logistic(±c), 역제곱 접근은1/2다. 홀수 크기의−1 근은 양의 공존점과 다르다. 일반 Lee–Yang 정리를 임의의 모형에 적용하지 않는다. [Tong의 인공 분배함수 예시](https://www.damtp.cam.ac.uk/user/tong/statphys/statmechhtml/S5.html)에서 독립 배경 인자를 뺀 별도 두 상태 준비라는 범위를 유지한다.
