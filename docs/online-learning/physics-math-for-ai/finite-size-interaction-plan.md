# 유한계 세 가족: 개념·실습·읽기 연결 설계

2026-11-07. 세 모델·한영 본문·worker·개념·저장 실습·표지·퀴즈를 실제 교재에 연결하고 [입문 통합 검증](finite-size-integration-verification.md)을 마쳤다. 등록533단원·1,599안내, 원래290/362입문 검증·72미완료다. 다음은 [열역학 영역 종합 점검](thermodynamics-domain-audit-plan.md)이며 전체 교육과정과 연구 깊이는 미완료다. 아래는 구현에 적용한 설계와 검증 계약이다.

## 데이터와 계산 경계

`learning-finite-size.ts`는 제목·프리셋·실험 안내와 정수 초안 파싱을, `learning-finite-size-concepts.ts`는 직관·고정 비교·예측/최종 문제를 제공한다. 자유 실습 저장 입력은 고정 개념 준비를 바꾸지 않는다. 고정 비교는 `useFiniteSizeSeries`가 유효한 입력의 사본을 만들고 순서대로 worker에서 계산한다. 모든 비교가 끝나기 전에는 부분 결과를 노출하지 않으며 단계 전환·오류·해제 때 이전 응답을 숨긴다.

모델/evaluator는 worker 전용으로 유지한다. 주 스레드에는 메시지 구조 검사·입력 동일성·표시 투영과 그리기만 둔다. 실제 Next worker URL·빌드 산출물·읽기 진입·자산 오류 검증은 별도 필요하다. 현재 독립 esbuild 페이지 검증을 그 완료 근거로 사용하지 않는다.

## 경계·광역성·가법성

열린 두 블록의 자리·외부 면·접합 면을 범례로 나눈다. 실제 개수는 정확 문자열로 제공하고 조밀 그래프는 모든 선을 그리는 대신 내부/교차 쌍 수를 표시한다. 동일 기하의 최근접·정규화 전 완전·전체 Kac 에너지를 비교한다. 제한 내부+교차=전체, 별도 정규화+보정+교차=전체라는 서로 다른 장부를 나란히 둔다.

확대 경로의 N과 접합/자리 비, 선택 에너지/자리와 최악 에너지/자리를 구별한다. 두께 고정이 큰 N에서도 경계를 남기는 예제, 평행 블록의 작은 별도 정규화 차이, 불균형 블록의 부호 변경, 두 자리·영 결합·큰 정수의 작은 보정을 탐색 가능하게 한다. 기하 배율을 시간으로 표기하지 않는다.

## 공간 밀도·상관·자기평균화

계 전체의 한 번의 모드 선택에서 독립 생성과 공통 복사를 분기해 보여준다. 임의로 뽑은 픽셀 장면을 정확한 분포인 것처럼 표시하지 않는다. 확률 막대는 worker가 반환한 K 분포이고, ε 사건에 포함된 격자점과 양의 질량을 나눈다. 부호 있는 편차·대각/비대각 공분산 합·분산 등가 수는 별도 표로 제공한다.

세 크기 경로의 분산과 N배 분산을 함께 비교한다. 정확 꼬리·독립 참조·Chebyshev·혼합 상한을 각각 표기하고, 독립 참조를 혼합의 보장으로 묶지 않는다. 분산 증가/꼬리 감소 예제, 임계값 등호, 빈 사건, 한 자리/확정 준비의 미제공, 선도 분산이 같아도 달라지는 극소 꼬리를 직접 선택하게 한다.

## 유한 반올림·복소 영점

두 허용 상태의 무게·확률부터 보여주고 중간 점유가 금지되었음을 명시한다. 압력 보정·밀도 분산·장 응답·g에서의10–90% 폭을 나누어 표시한다. 고정 활동도와 두 접근 경로에서 사용하는 조절 입력만 활성화하고, 크기 경로 변화와 고정 N의 g 미분을 구별한다.

단위원 영점 그림에는 실수/허수 축·양의 공존점·선택 근·켤레 근을 표시한다. 근 좌표와 거리는 그림용 근사, 회전수와 z^N=−1은 정확 검산으로 설명한다. 홀수의−1 근을 공존점1과 섞지 않는다. 로그 보정에는 인증 구간·로그 크기·표시 불가 사유를 제공하고 지수화 보정의 표시값1로 로그를0으로 바꾸지 않는다.

## 공통 UI·접근성·저장

기존 교재의 색상 변수·typography·명암·모션 설정과 `ai-*` 스타일을 따른다. 공간 크기를 순회할 경우 반드시 크기 탐색으로 부르고, 모션 중지·화면 밖·reduced motion에서는 자동 순회를 멈춘다. 수동 조작과 표는 항상 사용 가능해야 한다.

숫자 입력의 초안은 음이 아닌 정수 파서로 검사하고 spin/side는 명시적 선택을 사용한다. 분모 변경으로 제약이 깨져도 몰래 자르지 않고 오류를 설명한다. 잘못된 초안은 확정 입력으로 적용하지 않는다. reset은 초안도 지우고 프리셋 강조는 canonical 입력으로 결정한다. 저장은 버전·가족·정확 입력을 검증하고 복원 실패가 고정 개념을 바꾸지 않게 한다.

작은 비영 값·정확0·미제공·그림용 근사·로그 구간을 다르게 설명한다. 긴 분포/기록 표는 페이지·스크롤·키보드 접근을 제공하고 값이 없다고 막대를0으로 그리지 않는다. 화면 판독기에는 도표의 요약·범례·대체 표와 상태/오류 안내를 제공한다.
