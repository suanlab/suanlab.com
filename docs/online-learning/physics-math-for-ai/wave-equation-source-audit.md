## 기존 내용과 새 질문

기존 `diffusion-wave-advection-modes`는 주기 구간의 단일 Fourier 모드로 세 PDE의 차이와 초기속도를 비교한다. 새 내용은 실제 입자 사슬의 물리량을 고정한 연속체 극한, 여러 초기 성분의 장 진화, 국소 파형의 두 방향 전파와 경계 반사·에너지 흐름을 다룬다. 기존 단일 모드를 이름만 바꾸어 새 주제의 완료로 세지 않는다.

## 직접 유도한 물리량과 검증 기준

장력 τ(N), 선밀도 μ(kg/m), 입자 간격 a(m)를 사용한다. 가로 위치는 평형 좌표이고 u는 작은 가로 기울기를 가진 횡변위(m)다. 입자 질량 m=μa, 이웃 결합 강성 κ=τ/a로 두면

`m uddot_j = κ(u_(j+1)−2u_j+u_(j−1))`, `c²=κa²/m=τ/μ`다.

격자를 세분화하면서 μ와 τ, 물리 길이·초기 파형을 고정한다. m과 κ를 그대로 고정하고 a만 줄이면 같은 매질의 극한이 아니다. 공간 파수 ξ(1/m)로 쓰면 이산 `ω_a²=4c² sin²(ξa/2)/a²`, 연속체 `ω²=c²ξ²`다. 조건은 무차원 `|ξa|≪1`이며 a의 절댓값만 작다고 충분하지 않다. κ와 공간 파수를 같은 기호로 섞지 않는다.

기본 검증은 실제 순환 강성 행렬·행렬지수와 독립 Fourier 스펙트럼, 초기 위치·속도, 물리 에너지, 고정한 파형의 격자 세분화다. 단일 모드에 한정하지 않고 독립된 초기 변위·속도 성분을 갖도록 한다. 그린 점이 실제 이산 질량인지 연속 장의 표본인지, 그림 표본과 계산 격자를 명시한다.

## 국소 파형과 에너지 수지

전체 직선에서 초기 변위 f와 속도 g를 주면

`u(x,t)=[f(x−ct)+f(x+ct)]/2 + integral_(x−ct)^(x+ct) g(s) ds/(2c)`다.

그림에서 초기 변위만 반씩 나누고 속도 적분을 생략하지 않는다. 유한 지지의 매끄러운 다항식 bump를 사용하면 실제 영역 밖의 값과 의존 원뿔을 명확히 검사할 수 있다. 제안 예시는 `b(z)=(1−z²)^3` for |z|<1, 바깥0이다. 초기속도만 준 경우 국소 변위가 남는 평탄부와 이동하는 에너지 전면을 구분한다.

물리 에너지 밀도 `e=(μ u_t²+τ u_x²)/2`의 단위는 J/m, 흐름 `J=−τ u_t u_x`는 W다. 직접 미분해 `e_t+J_x=0`, 구간 에너지 변화는 왼쪽 유입−오른쪽 유출의 시간 적분임을 확인한다. 끝점 에너지 차로 흐름 적분을 정의해 잔차를 강제로0으로 만들지 않는다. 순수 오른쪽 파형에서는 J=ce, 왼쪽은 J=−ce다. 전체 에너지가 보존되어도 유한 관측 구간의 에너지는 변할 수 있다.

반직선 고정단은 u(0,t)=0의 홀수 연장, 자유단은 u_x(0,t)=0의 짝수 연장을 사용한다. **초기 변위 f와 속도 g를 각각 같은 공간 대칭으로 연장**한다. g=c f′인 왼쪽 입사파도 전체 연장 f의 미분으로 g를 대신하면 대칭이 바뀔 수 있다. 초기 bump를 경계에서 떨어뜨려 호환성을 확보한 뒤 반사 부호와 경계 흐름0을 검증한다. 교재의 차원 없는 에너지를 실제 μ·τ 에너지와 혼동하지 않는다.
