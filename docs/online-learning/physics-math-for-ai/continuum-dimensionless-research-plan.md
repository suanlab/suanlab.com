# 무차원 수 연구 보강: 격자 Peclet과 Robin 공급

2026-11-13 설계. 기존 두 단원의 한영 전체 원고와 일차 자료를 읽었다. 부호 있는 Pe·시간·닮음, 정확 지수/쌍곡 함수 해, 반두께·효과도·영 반응·산술 가용성 및 기존 실습을 보존한다.

## Peclet: 같은 물리 상태와 다른 이산 결과

`advection-diffusion-peclet-boundary-layer`: 전체 Pe, 부호 있는 셀 p = Uh/D, 기존 격자 Pe = |p|/2를 구분한다. 중심 차분의 이웃 가중치와 점화식을 유도하고 p = ±2는 분모 절단 없이 원래 식에서 푼다. Pe = 10의 성긴 격자에서 음의 농도를 그대로 비교한다.

상류 차분은 양성이어도 번질 수 있음을 설명한다. 상수 계수 셀의 정확 Bernoulli 플럭스와 공유 면 수지로 정상 절점값을 복원한다. 비균일 격자에서도 이 제한된 절점 정확성은 미해상 경계층 미분·비정상 시간 적분·변계수의 일반 인증이 아니다. 기존 해석적 실습에 수치 솔버 제어를 넣은 것으로 소개하지 않는다.

## Damkohler: 공급 경계도 무차원화하기

`reaction-diffusion-damkohler-penetration`: 밀폐 안쪽 면을 유지하고 바깥 저장소와 실제 표면 사이의 유한 질량 전달계수 hm을 추가한다. 내부 어드미턴스와 Robin 공급을 맞춰 표면 비·전체 반응률·효과도를 유도한다. 질량 전달 Biot 수와 Da가 모두 필요하다.

유한 공급의 빠른 반응 상한, 화학/공급 민감도, 같은 전체 반응률의 무한한 양의 계수 쌍을 비교한다. 공급·반응이 모두 영이면 정상 농도가 유일하지 않음을 보존한다. 유일한 정상 가지의 닮음에는 hm의 배율도 필요하다. 기존 지정 표면 실습은 그대로 둔다.
