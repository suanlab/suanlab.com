# Duffing 세속항·장시간 위상: 한영 원고와 계산 기반

2026-11-10. `duffing-secular-frequency-long-time`의 일차 자료/범위 검토, 한영 원고와 계산 기반을 준비했다. 실제 reader에는 미등록이며 전체 응답의 독립 검증·Worker·한영 교수 화면·생산 자산 검증은 후속이다.

## 내용과 모형

언어별20절·15표시수식·8해설 문제·위상 차이 비교 표와17예제다. x″+x+λx³=0, x(0)=A≥0, x′(0)=0에서 유효 결합g=λA², 공진과 세속항,1·2차 Lindstedt 전개, 복수 척도의 가해 조건, 잔차/에너지/위치·속도/기본 위상 오차를 구분한다. 강한 결합에서 음수가 되는2차 주파수를 물리적 해의 부재로 해석하지 않는다.

기준해는 직접 시간 적분 대신 AGM과nome Fourier 급수로 포함한 비선형 타원함수 주기해다. AGM18반복·Fourier64항의 위치/속도 꼬리 상계,512비트 제곱근/nome와768비트 삼각함수 작업 격자,192비트 출력 격자를 사용한다. 꼬리 상계 식의 포함 구간은 실제 절단 오차의 하한이라는 뜻이 아니다. 반올림 구간과 꼬리를 함께 전파하며 정확한 에너지의 진폭/속도 범위도 적용한다.

정규화한 잔차 다항식과 물리 잔차의 상계를 따로 반환한다. 잔차 상계는 궤적 오차 보증으로 부르지 않는다. 펼친 기본 위상 차이는 atan2나 위치 오차와 구분한다. A=0에는 주기를 만들지 않고 λ=0은 조화 진동, H=0은 초기조건 항등식으로 처리한다.

전체65표본과 관측점 주위 국소65표본을 제공한다. 전체 기록이 주기당8점 기준에 못 미치면 표시하며, 국소 창 선택도 표본화 규약이지 ODE 오차 정리가 아니다.
