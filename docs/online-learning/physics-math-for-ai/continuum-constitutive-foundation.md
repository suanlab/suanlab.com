이후 [홈페이지 통합과 최종 검증](continuum-constitutive-authoring-status.md)을 마쳤다. 아래 수치·미완료 설명은 문서 작성 당시 기록이다.

2026-11-06. 연속체의 일곱 번째 입문 주제에 대한 계산 모델과 상세 한영 원고를 작성했다. **홈페이지 실습 화면 통합·최종 브라우저 검증은 남았다.** 등록492단원·1,476안내, 원래274개 입문 주제 검증·88개 미검증을 유지한다. 전체51영역509주제와 연구 심화의 완료를 뜻하지 않는다.

## 추가한 계산

`src/lib/learning-continuum-constitutive.ts`는 다음 두 교육용 가족을 제공한다.

- `viscoelasticAt`: 같은 매끄러운 일축 사인 변형에서 Kelvin–Voigt 병렬과 Maxwell 직렬 응답, 실제 응력 미분·초기 내부 기억·정상 주기와 과도 응력·내부 변형률을 계산한다. 저장 에너지·실제 변화율·소산·입력 전력을 구분하고 같은 장의 완화·소산 누락 대조를 제공한다.
- `viscoelasticWindow`: 물리 시간 구간에서 실제 일과 소산을 각각 적분하고 안정적인 끝점 에너지 변화와 비교한다. 작은 시간의 물리 좌표는 정규화 좌표와 부호 있는 로그로 계산하며, 정확한 영 기간은 별도의 영 적분이다.
- `viscoelasticCycle`: 저장·손실 탄성률, 정상 주기 일과 별도의 실제 첫 주기 수지를 제공한다. 주파수0의 주기 부재, 양의 주기가 교육용 시간 범위 밖인 경우와 산술 범위 밖인 경우를 나눈다. 초기 과도가 있는 경로를 닫힌 정상 loop라고 부르지 않는다.
- `neoHookeanAt`: 비압축·자유 측면 일축 변형의 전체3차원 F와 B, 경계조건으로 결정한 압력, Cauchy/제1 Piola 응력과 traction, 실제 기준/현재 면적의 같은 힘, 기준 체적당/시편 전체 에너지를 계산한다. 강체 회전의 공변성과 관측 법선의 역할을 구분한다.
- `neoHookeanWork`: 실제 신장 경로의 공액 기계 일을 적분하고 독립적으로 계산한 안정 에너지 변화와 비교한다. 잘못된 Cauchy 응력–신장 공액 대조도 남긴다. 양의 일축 접선을 다축·전역 안정성의 인증으로 확대하지 않는다.

E·점도·전단계수는 양수다. 작은 변형 점탄성 모델과 큰 변형 초탄성 모델의 정의역을 혼합하지 않는다. 초탄성 에너지·응력·체적 보존과 직접 반올림 계산을 별도 관측으로 유지한다. 비영 언더플로에는 로그 크기와 필요한 부호를 보존하며 강제로0을 채우거나 결과를 재정규화하지 않는다. 공유한 해석식의 잔차는 진단이며 독립 정확도 인증이나 엄밀한 구적 오차 한계가 아니다.

## 독립 검증과 발견한 문제

`scripts/learning/generate-continuum-constitutive-references.py`는 제품을 import하지 않는다.160자리 계산의 점탄성24사례는 복소 지수 convolution 원시함수, 실제 미분·물리 시간 적분을 사용하며 각 사례의 한 점을 직접 convolution 구적으로도 대조한다. 초탄성24사례는 전체 행렬·압력·역전치·traction과 에너지 미분, 신장 좌표의 실제 일 적분을 사용한다. 두 모델의 작은 변화는 각각8사례를1,200자리로 계산해 총64참조를 제공한다. 생성기는 기존 파일을 덮어쓰지 않고 재생성 결과는 fixture와 바이트 단위로 일치한다.

검증 중 초기 응력을 조율한 Maxwell 실험에서1차·2차 변화가 상쇄되고3차 변화만 남는 사례를 확인했다. 초기 변화율과 cosine의1에서의 이탈을 분리한 적분 표현으로 작은 비영 변화·미분·에너지 변화를 보존했다. 초탄성의 최소 양의 로그 신장에서는 적분 내부 좌표를 먼저 선형 반올림하는 문제를 발견해 부호 있는 로그와 작은 인자 표현을 유지했다. 작은 대칭 신장 경로의 양·음 기여도 짝지어 적분하되 일을 끝점 에너지에서 정의하는 방식으로 바꾸지 않았다.

순수 모델23개와 기존492단원·안내/43실험 그룹483항목 보존·원고 렌더링3개 검사를 추가했다. 유한 차분, 초기 기억·음의 전력과 비음 소산, 첫 주기와 정상 주기, 영 주파수와 시간 범위, 회전·힘·면적·공액성, 작은3차 변화·언더플로·회복 배율과 대칭 경로를 포함한다. 전체4,525개 검사와 타입·lint·콘텐츠1,727 URL 검사를 통과했다.

기존 소스3,103개와 export4,202개는 해시를 보존했고 새 소스10개를 별도로 고정했다. 새 두 단원은 아직 등록하지 않았으므로 새로운 정적 배포 빌드·실습 화면·브라우저 검증 완료를 주장하지 않는다. 실제 종료 기록은 `.runtime/learning/continuum-constitutive-foundation-verification.json`에 있다. 기존 Interactive Book 메뉴·미리보기를 유지했고 commit·push·공개 배포는 수행하지 않았다.
