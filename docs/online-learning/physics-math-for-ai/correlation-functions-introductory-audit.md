## 보완한 설명과 교차 검산

세 단원에서 h가 서로 다른 원천을 뜻하는 문제를 발견해 공간 단원 마지막 절에 비교표를 넣었다. 물리 에너지·적분 측도·온도 변화 때 고정하는 양을 먼저 명시한다. 격자 간격1/2일 때 M=1,κ=2로 변환하는 예, 밀도 원천의 a C/T 응답, 같은 공분산의 다른 사차 연결량, 조건화3/10과 표본 중심화11/36, 양의 국소 비율이 있는 질량0 반례를 연결했다. 앞 두 단원의 이미 구현된 후속 내용을 미래 작업으로 표현하던 문장도 고쳤다.

새 종합 검사7개는24개 공통 유한 모형의 K,C,P와 밀도 원천 응답을 정확분수로 비교한다. 다른 검사들은 가우스/이진계의 사차 반례, 투영 잔차, 온도 경로, 원래 사차의 잘못된 차감, 질량0·무결합 제약, 음의 파수 인덱스7→15→31→63을 대조한다. 현재 한영 원고6개에 대한 strict 수식 검사는 통과했다.

## 실제 화면과 기존 생산 검증의 구분

이번에 실제 로컬 홈페이지의 세 reader를 한영×명암×320/1440px의24조합에서 새로 검사했다. 개념192회·정오답 해설192회·안내 해설144회·접근성24회, Worker48생성/48종료를 확인했다. 영어 본문에 한글이 없고 문서 가로 넘침이 없다. 새 비교표도 한영×명암×두 폭의8상태에서 표시·키보드 초점·접근성과 단원 간 링크를 확인했다. 빌드와1835HTML 검사를 통과하고, 기존4535파일 백업·63계산/검산 자산을 보존하며 최종 출력을 로컬 홈페이지에 반영했다. 최초 검사에서 표의 부모를 region으로 가정한 검증 코드가 실패해 실제 렌더러의 표 자체 tabindex/이름을 검사하도록 고친 뒤 네 실행 모두 종료0으로 재확인했다.

기존 생산 자산 검증은 가우스63·비가우스53·공간51요청과 각 변조/귀속 거부 기록을 재사용한다. 이를 이번의 새167회 실행으로 계산하지 않는다. 계산/검산 의존 파일은 각각19·19·25개이며 당시 소스 해시와 현재 파일이 모두 같음을 확인했다. 입력 한도를 줄이거나 생산 계산기를 바꾸지 않았다.
