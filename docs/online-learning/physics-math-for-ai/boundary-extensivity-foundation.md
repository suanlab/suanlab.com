## 새 모델과 수치 계약

`src/lib/learning-boundary-extensivity.ts`의 `finiteBoundaryExtensivityModel`은 두 열린 직육면체 격자의 고정 스핀 배치를 계산한다. 차원1..3, 양의 정수 길이·폭·공간 확대 계수, 양의 정수 분모와 비음수 정수 분자로 표현한 공통 결합을 사용한다. 정수 상한은1,000,000이다. 1차원 폭은1이며 균일 확대만 허용한다. 고정 두께 경로는2·3차원에서 가로 폭만 늘린다.

최근접 결합, 자기 쌍을 제외한 정규화 전 완전 그래프, 전체 N으로 J/N을 적용한 완전 그래프를 나란히 계산한다. 제한된 내부 에너지·교차 에너지·전체·자리당 값·최악 절댓값과 재구성 잔차를 제공한다. 잘라낸 블록을 각각 다시 정규화한 비교에는 별도의 정규화 변경 보정항을 제공한다.

모든 유한 관측과 유한 해석적 경로 극한은 정확한 BigInt 유리수다. 기존 정확 유리수 직렬화 helper를 재사용하며, 그 파일 이름이 이 실험에 Markov 시간이나 확률 준비를 도입하지는 않는다. 큰 기하 개수는 정확한 십진 정수 문자열로 반환한다. 기본 크기와 확대의 조합에서 N=2×10^36도 보존한다. 반올림 Number와 근사 로그는 표시일 뿐이며, 해석적 발산은 부호 있는 별도 태그로 반환한다. 실제 유한 에너지가 부동소수점 infinity가 된 것과 혼동하지 않는다.

기록은1부터 요청 확대까지의2의 거듭제곱과 마지막 요청값을 포함한다. 마지막 기록이 `current`이며 모든 중간 기록도 같은 성장 경로의 실제 기하에서 계산한다. 이는 공간 크기 순회이고 시간·표본 수·화면 프레임의 물리적 주기가 아니다.

## 직접 유도한 구분

[유도와 손계산](boundary-extensivity-derivation-notes.md)은 접합/자리=1/(a+b), 외부 면/자리=2/(a+b)+2(d−1)/w를 얻는다. 균일 확대는 둘 다0으로 보내지만 고정 두께는 그렇지 않다. 후자의 에너지 밀도 극한이 반드시 없다는 주장은 하지 않는다.

Kac 교차항/자리의 절댓값은 JNA NB/N²로 남는다. 에너지의 최악 크기는 선형이어도 이 절단 항은 사라지지 않는다. 반대로 균형 잡힌 반대 블록은 정규화 전 H/N=J/2를 유지하지만 전체 Hamiltonian의 최악 크기는 N²이다. 선택한 배치의 취소로 전체 계의 광역성을 판단하지 않는다. 별도 정규화한 평행 블록의 차이−J/2 역시 원래 교차항이 작다는 증명이 아니다.

물리적 정의의 배경은 [Campa–Dauxois–Ruffo II.A](https://arxiv.org/pdf/0907.0323)다. 본 모델은 자기 쌍을 제외하므로 리뷰의 자기 항 포함 표기와 유한 상수항을 섞지 않는다. 열린 격자 면·변 개수와 보정식은 지정한 모형에서 직접 유도했다. 이 유한 에너지 검사만으로 자유에너지 존재·ensemble equivalence·온도·Gibbs 평균·상전이·일반 장거리계 정리를 증명했다고 하지 않는다.

## 검증 근거

`scripts/learning/generate-boundary-extensivity-oracle.py`는 TypeScript를 import하지 않는다. Python `Fraction`으로27사례의1,188개 정확한 관측을 생성한다. 전체 직사각형의 결합 개수와 전체 스핀 제곱 항등식을 사용하여 런타임의 내부/교차 분해를 독립적으로 대조한다. 작은18사례는 실제 격자 꼭짓점과 모든 쌍을 열거해 최근접·내부·접합 연결선과 에너지를 직접 센다.

`scripts/learning-boundary-extensivity.test.ts`의36검사가 통과했다. 독립 기준 외에도 두 자리·단위 폭·영 결합·분수 결합, 공간 확대와 고정 두께의 극한 차이, Kac 보정항, 모든 기록의 유한 크기 보정 항등식, 블록 교환·전체 스핀 반전·결합 비율 재표현, Number 안전 정수 범위 밖 개수, 잘못된 기하/성장 경로를 확인했다.2·4·8자리의276개 전체 스핀 배치를 따로 열거하여 최악 에너지 경계가 실제로 달성됨도 확인했다. 이는 큰 계의 모든 배치를 열거했다는 뜻이 아니다.

공유 산술 helper와 기존 세 유한 사슬 모델의 회귀218개까지 합계254개가 통과했다. typecheck·lint도 통과했다. Python 기준의 재생성은 바이트가 일치한다. 이번 단계에서 전체 프로젝트 테스트·정적 빌드는 실행하지 않았으며, 직전 실제 교재 통합의 전체8,207검사와 구별한다.

증거는 `.runtime/learning/finite-size-boundary/verification.json`, `tests.log`, `related-tests.log`, `typecheck.log`, `lint.log`, `oracle-reproduction-verification.json`에 있다. 이전4,248개 소스와 정적 산출물4,287개의 바이트·경로 집합을 보존했다. 새 소스4개를 추가했으며 아직 홈페이지에 새 항목을 등록하지 않았다.
