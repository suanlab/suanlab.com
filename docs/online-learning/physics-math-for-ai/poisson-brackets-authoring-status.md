# Poisson bracket 집필 현황

2026-11-04. 두 계산 모델·한영 원고·그림·실습·퀴즈를 로컬 홈페이지에 연결하고 검증했다. 전체 **432개 한·영 단원·1,296개 안내 실험**이다. 공개 배포는 수행하지 않았다.

## 관측량의 변화와 정준 배율

`poisson-observable-canonical-flow`는 작용 단위의 네 관측량과 βtH를 사용하여 `dA/dt={A,H}+∂tA`를 검사한다. 자유 운동의 `qp−2tH`는 비영 bracket을 명시적 시간 미분이 상쇄한다. 한 시점의 변화율0·전역 보존·선택 궤적의 일정함을 구분한다. `Q=aq,P=p/a`는 bracket을 유지하고, 둘 다 곱한 좌표는 유도된 a²J가 필요함을 보여 준다. 변화율·작용·위상 좌표·Jacobi 예제를 단위별8개 그림으로 제공한다.

## 3차원 각운동량의 대수와 보존

`angular-momentum-poisson-algebra`는 전체 여섯 변수의 기울기에서 각운동량 대수를 계산하고 H와의 bracket을 실제 토크·시간 미분과 대조한다. 등방 계의 보존되지만 비가환인 성분, 초기L=0과 비영 토크, 평면 궤적의 순간 토크0과 이후 변화를 비교한다. 전역 대칭과 선택한 영좌표 궤적의 보존도 별도 판정한다.

공간 투영3개,각운동량·토크·bracket 행렬·에너지·잔차·각도별 회전 생성자의 위치/운동량 변화를12개 그림으로 나눈다. 회전 변화는 실제 속도·힘과 다르다. 평면 제한을 미분 전에 대입하는 함정을 설명하며 일반적인 구속 축약·Dirac bracket 이론을 완료했다고 주장하지 않는다.

두 단원은 검증한 직교 해석 흐름을 재사용하며 새 ODE 적분기가 아니다. 단위가 다른 잔차를 합치지 않고 최대 잔차는201출력 시점의 표본값으로 표시한다. 개념8단계·안내6개·퀴즈4개와 언어별 해설 문제12개를 제공한다. 기존 색상·SVG 틀을 유지하고 정지한 위상 상태도 조회 점으로 표시한다.
