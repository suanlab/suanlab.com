## 좌표와 보편 성질

전단 S=[[1,1],[0,1]]에서 x′=S⁻¹x, α′=αS와 새 계량 SᵀS를 직접 계산했다. x=(2,1),α=(3,4)의 불변 수축은 10이다. 이전 쌍대 성분을 재사용하면 7, 새 gradient와 계량 없이 좌표 내적을 하면 3이라는 비교표와 정확 분수 Python 검산을 추가했다.

다중선형사상에는 유한 차원 텐서곱의 보편 성질을 기저에서 존재·유일성으로 증명했다. 연결 차원 합과 곱 특징 차원은 공식이 다르지만 두 2차원 입력에서는 모두 4라는 예외를 명시하여 기존의 항상 다르다는 답을 수정했다. 네 기저상과 2×4 선형화 행렬도 제시했다. 고차 대칭화는 같은 실수 벡터공간의 슬롯이라는 조건을 명시했다. e001의 Sym·Alt와 남는 성분 표로 두 완전 대칭만으로 복원되지 않음을 보였다.

## CP와 TT의 최적 근사 비교

실수 CP 예제 W=e100+e010+e001과 T_ε=((e0+εe1)⊗3−e0⊗3)/ε를 사용한다. T_ε의 랭크는 2이고 제곱 오차는 3ε²+ε⁴이다. W의 두 단면 곱이 비영 멱영 행렬이므로 두 항 CP의 대각화 조건과 모순되어 W의 CP 랭크가 정확히 3임을 증명했다. S₀의 determinant는 border rank 1도 배제한다. 이로써 랭크 2 최적 근사의 부재와 발산하는 개별 항을 설명한다.

모든 모드에 비정규화 Hadamard 행렬을 적용한 뒤 ε=2⁻⁵⁶에서 binary64 인자들이 모두 1로 반올림되어 직접 차분이 영 배열로 사라지는 현상을 재현했다. 정확한 분수로는 여전히 비영 극한 성분을 얻는다. 이는 기존 두 꼭짓점 실습을 바꾼 결과가 아니라 별도의 소거 예제다.

TT에는 비영 배열의 펼침 랭크가 bond 하한이고 순차 정확 랭크 분해로 동시에 달성됨을 증명했다. 양의 랭크 상한에서 소행렬식의 닫힘과 유계 최소화 수열로 최적 근사가 존재하는 이유도 보였다. 게이지가 있는 코어 매개변수의 안정성이나 optimizer 수렴까지 보장하는 주장은 아니다.

X_ijkl=δ_ikδ_jl의 두 축 순서를 비교했다. (i,j,k,l)의 최소 내부 랭크는 (2,4,2), 저장량은 40이고, (i,k,j,l)은 (2,1,2),16이다. 정확한 유리수 소거로 여섯 펼침을 검사하고 별도 네 코어 수축으로 16개 성분을 모두 확인했다.

## 확인한 일차 자료와 범위

- [de Silva·Lim, arXiv v2, 2008-04-01](https://arxiv.org/abs/math/0607647v2): 명제 4.6과 §4.3의 랭크 3 극한 구성·발산 계수를 확인했다. 단면 곱 증명과 binary64 계산을 교재에서 전개했다. 원전의 전체 분류·양의 부피 결과까지 재현하지 않았다.
- [Oseledets, Tensor-Train Decomposition, 2011](https://doi.org/10.1137/090752286)의 [공개된 출판 PDF](https://users.math.msu.edu/users/iwenmark/Teaching/CMSE890/TENSOR_oseledets2011.pdf): 정리 2.1과 따름정리 2.4, 인쇄 2298–2300쪽의 표현·최적 근사를 확인했다. 네 이진 축의 순서 비교와 정확 검산은 직접 구성했다. TT-SVD의 일반 절단 오차와 실험 전체는 후속 범위다.
- [Kolda·Bader 저자 공개 PDF](https://www.kolda.net/publication/TensorReview.pdf)는 정상 접근되는 46쪽 출판본임을 확인했다. 기존 보충 자료 링크를 유지했다.

## 실행 검증

텐서 계산·입력·예제 검사 21개와 원고 보존 검사 7개, 총 28개가 통과했다. 10개 등록 단원을 선택한 한영 원고 공통 검사도 통과했으며 다른 661개 검사는 이 선택 실행에 포함하지 않았다. 수식·MathML·목차와 영어의 한글 혼입을 확인했다. 새 여섯 Python 예제의 실행과 한영 표시 수식의 일치를 확인했다. 실행 근거는 `.runtime/learning/tensor-research-python.json`이다.

기존 실습과 새 보편 성질의 선형화 행렬은 16개 입력 쌍에서 일치했다. 별도로 여섯 순열을 열거해 대칭화·교대화의 여덟 성분과 잔차 제곱 2/3을 확인했다. 근거는 `.runtime/learning/tensor-symmetry-authoring.json`이다. [NumPy 2.5 공식 broadcasting 설명](https://numpy.org/doc/stable/user/basics.broadcasting.html)에서 뒤쪽 축과 크기 1의 정렬 규칙도 확인했다. 여기의 실습이 NumPy 실행이라는 뜻은 아니다.

`npm run check:tensors`는 78개 한영·320/768/1440px·영어 다크 모드·주제 검색 상태와 상호작용 12개 묶음, 안내 예제 30개를 통과했다. 새 다섯 표·수식·세 코드의 표시, 넘치는 그림·코드의 키보드 스크롤, 정수 초안의 오류·이전 계산 보존·Escape 복원, 문제 풀이·입력·완료 저장을 확인했다. 페이지 실행 오류와 WCAG A/AA 위반은 0건이었다. 실행 근거는 `.runtime/learning/tensor-browser.json`이다.

TypeScript 검사와 정적 빌드가 성공했고, 1,888개 HTML의 내부 링크·자산·앵커·사이트맵·canonical 검사를 통과했다. 이번 열 개 한영 원고의 검토 해시를 추가하여 현재 42개 검토 원고의 정확한 전이만 허용한다. 역사적 fixture와 다른 파일의 바이트 보존 검사는 그대로 유지하며 추가 변조를 거부한다. 공개 반영은 GitHub Pages 배포 결과로 별도 확인한다.
