# 정준 이진 에너지 요동: 유도와 수치 계약

2026-11-06. 예정 단원은 `canonical-binary-energy-fluctuations`다. 유한 저장고 단원 다음의 계산 기반이며, 상세 한영 본문과 풀이 검증은 `canonical-binary-manuscript-foundation.md`에 기록했다. 교육 UI와 홈페이지 등록은 아직 미완료다.

## 같은 계, 다른 준비

n개의 이름 있는 비상호작용 자리에서 각 에너지는 0 또는 ε≥0 J다. ε와 n을 고정하고 정준 준비를 지정한다. 총여기 수 K 자체를 고정하지 않는다. β=1/(kBT), t=βε, r=1/(1+exp(t))로 놓으면

$$
p(x)=r^{K(x)}(1-r)^{n-K(x)},\qquad
P(K=k)=\binom nk r^k(1-r)^{n-k},\qquad
Z=(1+e^{-t})^n.
$$

첫 식은 이름 있는 배치, 둘째 식은 여기 수 읽기의 확률이다. 특정 k에 조건을 걸면 C(n,k)개 배치가 균등하지만, 정준 준비 전체가 그 껍질 하나에만 존재하는 것은 아니다. 상태 개수는 정확히 2ⁿ이며, 원래 준비의 확률과 관측 다중도를 별도로 보존한다.

## 모멘트와 응답

독립성으로 E[K]=nr, Var(K)=nr(1−r)다. 같은 독립 준비에서 다음 식들을 직접 얻는다.

$$
U=n\varepsilon r,\qquad
\operatorname{Var}(E)=n\varepsilon^2r(1-r),\qquad
C=\frac{dU}{dT}=nk_Bt^2r(1-r).
$$

따라서 Var(E)=kBT²C다. U의 단위는 J, 분산은 J², C와 엔트로피는 J/K다. S/kB=n[ln(1+exp(−t))+tr]이며, S는 배치 공간의 정준 엔트로피다. 여기 수만의 엔트로피 H(K)와 구별해야 한다.

n>0과 ε>0에서 상대 에너지 요동은 sqrt(Var(E))/U=exp(t/2)/sqrt(n)이다. n이 커질 때 절대 분산은 커져도 상대 표준편차는 줄어든다. 낮은 양의 온도에서 기대 여기 수가 매우 작으면 유한 n의 상대 요동은 클 수 있으므로, n이 크다는 사실만으로 모든 관측의 상대 오차가 작다고 단정하지 않는다.

이 관계는 독립 평형 준비의 통계다. 시간 상관함수·전이율·완화 시간은 지정하지 않는다. 표본을 추가하는 화면 프레임도 실제 물리 시간을 뜻하지 않는다. [Tong의 1.3.1–1.3.3절](https://davidtong.org/pdfs/teaching/statistical-physics/statphys1.pdf)은 정준 분배함수와 에너지 요동·응답 관계의 참고 원전이다.

## 손계산과 앙상블 비교

t=ln 2, n=2에서는 r=1/3, P(K)=(4,4,1)/9다. 평균은 2/3, 분산은 4/9이며, U=2ε/3, Var(E)=4ε²/9, C/kB=4(ln 2)²/9다. 이전 유한 저장고 n=2,b=4,K_total=2는 같은 평균을 갖지만 분산은 16/45다.

t=1에서는 한 자리 r≈0.26894142137, S/kB≈0.58220310889, C/kB≈0.19661193324다. 독립 복제 수를 늘리면 U·S·C·에너지 분산은 n에 비례한다. 한 자리 확률은 바뀌지 않는다.

## 음의 온도와 끝점

이 스펙트럼의 에너지는 위로 유계다. 유한 T<0도 정규화 가능한 준비이며, r>1/2인 인구역전을 뜻한다. T의 부호를 바꾸면 r은 1−r로 바뀌고, U(T)+U(−T)=nε다. S·C·에너지 분산은 같은 절댓값의 두 온도에서 같다. 이를 무한한 운동에너지 스펙트럼의 일반 기체에 적용하지 않는다. 음의 온도 해석의 원전은 [Tong의 두 준위계, 1.2.3절](https://davidtong.org/pdfs/teaching/statistical-physics/statphys1.pdf)이다.

계산기의 T=0 입력은 **양의 쪽에서 접근한 평형 극한**으로 정의한다. ε>0이면 모두 바닥 배치이며 여기 확률·분산·엔트로피·열용량은 실제 0이다. T→0⁻에서는 모두 위 준위인 다른 극한이므로 이 입력과 혼동하지 않는다. ε=0이면 모든 이름 있는 배치가 같은 에너지이고 정준 준비는 균등하다. 이때 에너지·에너지 분산·열용량은 0이지만 S=nkB ln 2다.

| 조건 | 평균 여기 수 | 여기 수 분산 | 에너지 분산 | 상대 에너지 요동 |
| --- | --- | --- | --- | --- |
| n=0 | 0 | 0 | 0 | 정의하지 않음 |
| ε=0 | n/2 | n/4 | 0 | 정의하지 않음 |
| ε>0, T→0⁺ | 0 | 0 | 0 | 정의하지 않음 |
| ε>0, 유한 T≠0 | nr | nr(1−r) | nε²r(1−r) | exp(t/2)/sqrt(n) |

T→±∞에서는 r→1/2, U→nε/2, Var(E)→nε²/4, S→nkB ln 2, C→0이다. 이 수학적 극한은 유한한 큰 T나 ε=0인 다른 Hamiltonian과 구별한다.

## 계산 범위와 안정성

`canonicalBinaryModel`은 n=0..4096, 유한한 ε≥0, 유한한 양·음의 T와 위의 T=0 극한을 지원한다. ε/(kB|T|)는 입력의 정확한 이진 곱·비로 계산한다. 먼저 ε나 kBT를 범위 밖 0·무한대로 바꾸지 않는다. 상태 계수는 BigInt 문자열이다.

내부 `binomialLogit`은 부호 있는 로그 오즈를 받아 드문 준위와 흔한 준위를 나눈다. 보통 범위에서는 중간 지수의 곱을 유지해 작은 확률이 에너지·분산에 다시 나타날 수 있게 한다. |t|>4096에서는 명시한 지수 꼬리 근사를 사용하며, 생략한 정규화 보정은 exp(−4096)보다 작다. 독립 기준값은 10000까지 직접 계산하므로 구현의 전환점을 같은 분기로 복사하지 않는다.

유한 T≠0에서 모든 배치는 양의 확률을 갖는다. 선형 값이 표시되지 않더라도 부호와 첫째 로그, 필요한 경우 둘째 로그의 가용성을 유지한다. 1로 반올림된 큰 확률도 실제 점질량과 구분한다. 단위값에 매우 가까운 모멘트의 중첩 로그는 반올림 오차를 증폭하므로 정확한 단위값 이탈의 증명으로 사용하지 않는다. 꼬리 진단과 통계적 동일성의 증명은 다르다.

## 독립 검증과 다음 단계
