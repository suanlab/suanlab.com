# 양자정보 용량 단원과 결합 엔트로피 기반 보완

2026-11-09. 마지막 계획 단원의 한영 본문2개와 탈위상 채널 정보 계산기를 작성했다. 기존 엔트로피 장도 고정 부분계를 갖는 두 매개변수 결합 상태 계산기로 보완했다. 양자정보 **9/9단원의 본문·수치 기반**이 준비되었지만, Worker·학습 화면·reader 등록과 원주제 완료는 아직 남아 있다.

## 이번 작성

채널 용량 본문은 언어별12절·해설 문제6개다. C/CE/Q의 자원·단위를 구분하고 Stinespring 환경·선택 입력의 coherent information·degrading map·Pauli 평균과 용량 정리의 역할을 설명한다. 알려진 Z인 p=1, 완전 탈위상 p=1/2, 작은 양의 용량, 유한 블록과 점근 비율의 차이를 다룬다.

계산기는 물리적인 유리수 Bloch 입력에 대해 출력/환경 밀도행렬·정규화 Choi·엔트로피·선택 입력 정보와 **가족 정리로 계산한 용량**을 분리한다. 출력/Choi는 정확 유리수이며 환경 coherence·스펙트럼은512bit 방향 제곱근, 엔트로피는256bit 방향 로그다. 순수 입력과 완전 탈위상의 정확한 coherent-information 영값은 원래 계산 구간과 함께 반환한다. 일반 채널 용량 최적화나 유한 블록 코드 구현은 아니다.

결합 엔트로피 모형은 `rho(c,t)=c*rho_corr(t)+(1-c)*I4/4`다. 부분계는 항상 I2/2이며 Bell 쌍·고전 상관·독립 혼합을 연속적으로 비교한다. 정확한 스펙트럼·PPT·negativity와 엔트로피·조건부 정보·탈위상 증가를 제공한다. 기존 한영 본문에는 이 가족과 **조건부 엔트로피가 양수지만 얽힌 상태**의 수치 예제를 추가했다. 임의4차원 고유분해기나 모든 혼합 상태의 엔트로피/얽힘 도구를 제공한 것으로 과장하지 않는다.

## 검증과 한계

- 독립130자리 mpmath Stinespring 확장·부분추적·Choi 고유분해80개를 대조했다. 생성기 자체에서도 등거리성·각 부분계 trace1을 검사한다. 용량의 최적성은 수치 참조가 아니라 명시된 가족 정리에 의존한다.
- 독립 SymPy4x4 고유분해·부분전치27개로 결합 상태를 대조했다. PPT 경계 양쪽의10^-30 수준 차이도 정확히 분류한다.
- 고정밀 십진 참조의 대조 여유는1e-110이며 엄밀한 초월함수 참조 구간 증명이라고 주장하지 않는다. 제품이 보존한 원래 수치 구간도 검사한다.
