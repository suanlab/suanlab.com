# 분배함수 실험·worker·고정 개념 화면 검증

현재 갱신: [실제 교재 입문 통합 검증](partition-function-authoring-status.md)을 마쳤다. 아래는 해당 준비·모델·분리 화면 단계의 계약과 당시 검증 기록이다.

2026-11-07. 분배함수 세 가족의 한영 원고와 계산 모델에 이어 실제 실험 컴포넌트·worker·고정 그림을 구현했다. 이 기록은 별도 브라우저 검증 페이지의 결과다. 아직 교재 레지스트리·실제 Next 읽기 페이지에 연결하지 않았고, 상세 단계 설명과 해설 퀴즈의 데이터 연결도 남아 있다. 공개515단원·1545안내, 원래284주제 입문 검증·78주제 미완료 수는 유지한다.

## 구현한 구성

- `learning-partition-protocol.ts`: 세 모형의 입력·결과 계약, 상태공간·상태 수·유한 수 검증, 배열까지 복사·동결한 입력 snapshot, 순서에 독립적인 요청 key와 수치 상태/유리 구간 형식 검사.
- 전용 evaluator·module worker·factory·controller·React hook: 계산을 worker에서 실행하고 새 요청이 오면 이전 worker를 종료한다. 완료·실패·취소·unmount도 종료한다. 현재 설정과 다른 결과는 render 단계부터 숨긴다. SSR과 실패 시 메인 스레드 계산으로 대체하지 않는다.
- `learning-partition.ts`: 한영27예제와 예측→조작→해석의9안내. 계산 모듈의 런타임 import 없이 설정만 제공한다.
- `partition-lab.tsx`: 유한 준위 추가/삭제와 공통 기준, 결합·외부장·지원 선택, 사다리 간격·온도·절단 설정, JSON 검증·저장·초기화·수동 단계·정지/재시도·모션 설정을 반영하는 예제 순회.
- `partition-view.tsx`: 상대 에너지 준위, 원래 확률 막대, 결합확률 격자, source Hessian·물리적 응답, 유한/무한 열역학·절단 오차,32행 표. 작은 양수의 최소2px 표식은 실제 수치와 구분한다.
- 고정 개념 입력12세트와 별도 series hook·`partition-concept.tsx`, 장식용 표지3개. 저장된 실험 입력을 사용하지 않으며 여러 준비를 순차 worker로 계산한다. 실패/교체 중 이전 단계나 일부 결과를 새 단계처럼 보여주지 않는다.

## 과학적 의미와 발견한 오류

정확한0·미정·정밀도 미해결·비영 표시 범위 초과·수학적 무한대를 구별한다. 미해결에서 확인한 부호는 남긴다. 로그 꼬리 근사도 구간 인증과 다른 상태다. 확률 그림과 샘플 표를 재정규화하지 않고, 선택한 레이블 간격을 물리적 상태 간격으로 해석하지 않는다.

결합 모형은 Δ와 상호정보량, source 공분산과 온도0의 물리적 미분을 나누어 표시한다. 금지 상태는 격자에서 따로 표시한다. 무한 사다리가 정규화되지 않으면 무한 확률 그림과 오차 수치를 만들지 않는다. q가1로 반올림되어도 양의 입력 비와 무한 분포 존재 조건은 유지한다.

응답 검사 과정에서 사다리의 음의 온도 x가 음수 분모로 표현되어 잘못된 미해결/부호 상태를 만드는 것을 발견했다. 분모를 양수로 유지하고 부호를 분자로 옮겼으며, x≈−0.7과 양의 계산용 감소 비·1보다 큰 물리적 q를 함께 확인하는 회귀 검사를 보강했다. 기존 열역학 값과 독립 참조 검사는 계속 통과했다.

브라우저에서는 어두운 테마의 상태공간 select 대비를 수정했다. 모바일 실제 화면에서 숫자가 여러 줄로 분리되는 현상도 확인하여 숫자 안의 임의 줄바꿈을 제거했다. 표는 키보드로 가로 탐색한다. 기존 사이트의 색 변수·표·버튼·명암 테마를 그대로 사용한다.

## 검증 근거

1. 기존 모델·원고109검사와 worker·패널·고정 그림 검사를 합쳐173개가 통과했다. 마지막 표 스타일 수정 후 프런트64검사를 다시 통과했다. 전역 타입 검사와 변경 TypeScript lint도 통과했다.
2. 실험27예제×2언어×2테마×320/1440폭=216조합을 실제 worker와 브라우저에서 조작했다. 모든 조합의 패널 접근성 위반·문서 가로 넘침·비정상 SVG·영어 한글·페이지 오류는0이다. 생성216·종료216·잔존0 worker를 확인했다.
3. 고정 그림12세트의 같은8조건=96조합을 실제 순차 worker로 계산했다. main 접근성 위반·넘침·SVG 비정상·도형 글자 잘림·영어 한글·페이지 오류는0이다. worker 로드 차단 후 빈 실패 화면과 재시도를 확인했다. 생성203·종료203·잔존0이다.
4. 별도 React StrictMode/실제 worker 검사에서 무거운4096절단 계산 중 클릭과 heartbeat, 새 요청 대체·비활성화·취소·재시도·unmount·완료·worker 로드 차단/복구를 확인했다. 이전 결과 노출0,worker14개 생성/종료 일치,잔존0이다. 관찰한 최대 heartbeat 간격은약43.4ms다. 일반적인 장치의 성능 상한이라는 뜻은 아니다.
5. webpack의 클라이언트에는 세 계산기 함수가 없고, 별도 worker asset 하나에서 실행된다. 이는 아직 실행하지 않은 Next production export의 worker 분리 검증을 대신하지 않는다.
6. 기존 소스3988개와 정적 출력4250개는 직전 앙상블 통합 스냅샷과 해시가 일치한다.4175 미리보기는 유지했다. 검증용 서버·브라우저는 종료했다. 커밋·push·배포는 하지 않았다.

수치 근거와 한영 원고는 [유한 스펙트럼](partition-cumulant-foundation.md), [결합 이진계](coupled-partition-foundation.md), [무한 사다리](energy-ladder-foundation.md)를 참고한다. 기계 판독 기록은 `.runtime/learning/partition-teaching-components-verification.json`이다.
