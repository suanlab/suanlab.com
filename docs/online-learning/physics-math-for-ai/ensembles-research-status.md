# Ensemble 연구 보강 검증 기록

2026-11-13. 유한 저장고·정준 에너지 요동·대정준 점유 요동의 **3단원·한영 6원고·그림 6개**를 보강했다. 원본문과 풀이 36개를 정확히 보존하고 표시 수식 60개, 실행 Python과 표 각각 6개, 연구 해설 18개를 추가했다. 기존 정적 계산기·예제 순회에 새 동역학이나 비균일 에너지 입력이 있다고 소개하지 않는다.

## 새 설명과 적용 조건

- **유한 저장고 식별:** 같은 한 자리 주변 법칙 뒤의 다른 결합 법칙을 비교한다. 두 자리 공분산에서 정확한 모집단 크기를 복원하고 TV·KL의 다른 감소율을 설명한다. 역산의 나쁜 조건과 끝점·유한 표본·다른 준비 기작의 한계를 구별한다.
- **주기 열 응답:** 상세평형 전이율과 초 단위 시간 척도를 새로 명시한다. 열용량이 같아도 완화율에 따라 진폭·지연이 다름을 유도한다. 고정 간격에서 열·Gibbs 엔트로피·생성률을 연결하며 선형 응답과 유한 진폭의 비선형 적분을 구별한다. 열원 제어 장치 전체의 비용은 계산하지 않는다.
- **대정준 응답 랭크:** 동일 에너지의 E=εN이 만드는 중복 관측을 설명한다. 알려진 서로 다른 두 에너지의 독립 자리로 비교계를 정하고 공분산 행렬식·logit 복원·Fisher 좌표 변환을 유도한다. 양의 행렬식과 정확한 표본 추정, 교정된 에너지와 미지 공통 기준을 구별한다.

앙상블 정규화·평형 응답의 자료는 [Tong 1.2–1.4절](https://davidtong.org/pdfs/teaching/statistical-physics/statphys1.pdf)을 대조했다. 역산·전이율·구동·랭크 예제는 본문에서 명시한 모형으로 직접 유도했다. [선행 준비](ensembles-research-preparation.md)는 당시 계산 기반이며, 현재 검증 근거는 [JSON 기록](ensembles-research-evidence.json)을 따른다.

## 검산과 보존

독립 표지 상태 열거로 저장고 쌍 법칙 66개를 대조했다. 비선형 주방정식 RK4의 세 주파수·두 작은 진폭 6사례에서 응답 계수·양의 평균 생성률·진폭 감소 오차를 확인했다. 네 미시 상태 직접 합산으로 공분산·점수·Fisher 변환 27개 준비를 대조했다. 유한 사례의 수치 대조는 임의 진폭·주파수·적분 간격에 대한 오차 인증이 아니다.

관련 **17파일·294검사**가 통과했다. 목차·수식·표 개수의 기대값은 추가한 절만 반영하고, 원문 복원 해시는 따로 검사했다. 다른 29단원·58원고와 앞선 연구 자산 68개를 유지했다. 기존 보존 장부 823항목을 보존하고 새 원고 검토 6개를 더해 829항목이다. 등록은 650단원·1,969안내, 전체 분모는 51영역·509주제다.
