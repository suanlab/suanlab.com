# 분산·군속도: 자료 대조와 독립 계산

2026-11-05. 자료와 독립 탐색을 준비한 단계의 기록이다. 이후 [순수 모델 두 개·한영 상세 원고 네 개·이식 가능한 독립 검증](dispersion-foundation.md)을 작성하고 [홈페이지 연결·실제 화면 검증](dispersion-authoring-status.md)도 마쳤다. 현재452개 단원·254개 입문 검증의 최신 근거는 연결 기록에 있다. 아래 탐색 수치는 이식 가능한 최종 기준값과 구분한다.

## 실제 대조한 일차 자료

- [MIT 8.03SC 강의13 노트](https://www.ocw.mit.edu/courses/8-03sc-physics-iii-vibrations-and-waves-fall-2016/432d23acf0bce355921a8b9a4eefb0b6_MIT8_03SCF16_Lec13.pdf): 본문1–5쪽의 이상적인 줄과 굽힘 강성이 있는 줄의 분산 관계, 두 성분의 맥놀이, 군속도 도입을 읽었다. 두 정현파의 합은 합·차 각의 항등식으로 직접 재유도한다. 실수 진동수들의 비가 임의일 때 정확한 공통 재귀 주기가 항상 존재한다고 가정하지 않는다.
- [Harvard Matthew Schwartz 강의11](https://schwartz.scholars.harvard.edu/sites/g/files/omnuum7046/files/schwartz/files/lecture11-wavepackets.pdf): Gaussian 묶음과 Fourier 표현의 앞부분,5–7쪽의 분산 관계 Taylor 전개와 이동·퍼짐을 대조했다. 복소장의 부호·시간 위상·정규화는 아래 독립 적분으로 검산한다. 일차 전개로 유지되는 모양과 이차 항에 의한 퍼짐의 가정을 분리한다.

Cambridge 자료의 서버 오류와 NPTEL 자료의 시간 초과는 읽기 완료로 기록하지 않는다. 검색 결과만 본 추가 자료도 검증 근거에 포함하지 않는다.

## 두 단원의 구상

후보 식별자는 `dispersive-wave-packets-phase-group-velocity`와 `lattice-wave-packet-transport-dispersion`다. 앞 단원은 위상·포락선·폭·chirp를, 뒤 단원은 실제 질량·용수철 사슬의 분산과 에너지 흐름을 비교한다. 앞서 만든 간섭 평균이나 초기 장의 비분산 전파를 새 이름으로 재사용해 완료 처리하지 않는다.

연속 모델은 ω(k)=ω₀+v_g(k−k₀)+β(k−k₀)²/2와 초기장 A exp[−x²/(2σ²)]exp(ik₀x)를 사용한다. D=σ²+iβt이면 정확한 장은 Aσ/√D · exp[−(x−v_gt)²/(2D)]exp[i(k₀x−ω₀t)]다. 강도의 적분은 A²σ√π, 분산은 σ²[1+(βt/σ²)²]/2다. 그림의 진폭 폭과 강도의 표준편차를 구분한다. k₀=0의 위상속도는 미정으로 표시한다.

이는 선택한 이차 분산 모델의 정확한 해다. 일반 매질의 Taylor 근사라면 대역폭·고차 미분·전파 시간의 오차 조건을 별도로 설명한다. Gaussian은 처음부터 무한 지지를 가지므로 봉우리의 이동으로 최초 신호의 전면 속도를 측정했다고 주장할 수 없다. 군속도·에너지 속도·정보 전달 속도의 보편적 동일성도 가정하지 않는다.

주기 사슬은 양의 해상 가능한 모드에서 ω=2c/a·sin(ka/2), v_g=c cos(ka/2)를 쓴다. 실제 변위와 속도에서 구한 전체 에너지 E 및 링크 흐름 J에 대해 aΣJ/E를 계산하고, 모드 에너지 E_n=mNω_n²|A_n|²/2로 가중한 군속도와 대조한다. 넓은 대역에서는 반송 모드의 군속도 하나로 전체 흐름을 대신할 수 없다. 주기 영역의 중심은 원형 모멘트가0에 가까우면 미정이며, 경계 통과를 불연속 선형 중심 이동으로 해석하지 않는다.

## 실행한 독립 탐색

`.runtime/learning/explore-dispersion.py`는 제품 코드를 불러오지 않는다. Gaussian18개 설정·54개 복소장 관측점을 초기 Fourier 진폭의 직접 사분 적분으로 대조했고 최대 차이는 약1.08×10⁻¹²였다. 실공간 적분으로 보존 노름과 강도 분산도 확인했다.

주기 사슬36개 설정은 실제 운동방정식 행렬의 지수함수와 Fourier 모드 합을 독립 비교했다. 최대 상태 차이는 약8.93×10⁻¹⁵, 에너지 차이는2.67×10⁻¹⁵, 에너지 전달 속도 항등식 차이는8.89×10⁻¹⁶, 국소 에너지 수지 잔차는5.56×10⁻¹⁶였다. 결과는 `.runtime/learning/dispersion-exploration.json`에 있다. 선택한 유한 사례의 수치 확인이며 보편적 오차 상한이나 제품·화면 검증은 아니다.

이후 순수 모델의 입력 범위와 단위, 영진폭·영분산·좁은 대역·격자 경계·중심 미정의 동작을 확정하고 이식 가능한 독립 기준값·전용28개 검사와 상세 한영 원고를 작성했다. 기존 테마의 실제 시각화·조작 화면과 통합 검증까지 마쳤으며 다음 원래 주제는 편광이다.
