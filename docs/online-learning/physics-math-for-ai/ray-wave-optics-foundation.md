## 광선과 센서 관측

`src/lib/learning-ray-wave-optics.ts`의 `paraxialRayExperiment`는 높이·각도 순서의 좌표, 같은 배경 굴절률, 이상적 얇은 렌즈를 사용한다. 직접 좌표 갱신한 아홉 광선과 `P(s)L(f)P(u)` 행렬을 제공한다. 센서 위치·좌표 평균·표본 퍼짐과 계산한 상면을 구별한다. 표본 각도 분포를 실제 방사 법칙이나 점확산함수로 부르지 않는다.

실상·허상·정확한 무한대 상·렌즈 없음을 구분한다. 허상 교점은 역연장 좌표이고 실제 출력은 앞으로 전파한다. `u=f`에서는 유한 상 좌표·높이·배율·상면 행렬·유한 거리 민감도가 `null`이다. 인접한 부동소수점 입력은 큰 유한 상으로 보존하며 임의의 거리 상한·근처값 반올림으로 특이점에 합치지 않는다. 양·음 초점 거리, 비가환 요소 순서, 센서 번짐, 거리 민감도·출력 기울기를 검사한다.

## 유한 Gaussian과 기하 초점의 차이

`gaussianBeamExperiment`는 횡방향2차원의 축대칭 장, `exp(+ikz−iωt)`, `q0=−i zR`, 양의 Fresnel 이차 위상을 사용한다. 입력 허리·렌즈 전후·관측면의 폭·곡률, 복소 진폭·Gouy 진행량, 실제 반경별 장·강도, 종방향 포락선과 기하/회절 기여를 반환한다. q만으로 복소 진폭 계수를 대신하지 않는다.

얇은 렌즈에서 폭·축 중심 위상은 연속이고 역곡률은 `−1/f`만큼 바뀐다. 렌즈 위에 놓인 허리의 최소 폭 위치는 `f zR²/(zR²+f²)`다. 넓고 거의 평행한 빔의 한계에서만 기하 초점 `f`에 가까워진다. 파장500nm·초점20mm에서 입력 반경40µm는 최소 폭35.7391µm·위치4.03400mm, 입력120µm는25.9006µm·19.0683mm다. 기하 초점의 반경과 실제 최소 반경을 따로 설명한다.

곡률 반경이 무한한 허리에서는 유한 곡률값을 `null`로 제공하고 역곡률0을 유지한다. 영진폭에는 실제 위상·조건부 내부 비율이 없으며, 남은 폭은 기준 모드의 기하학이다. 음의 허리 좌표는 출력 Gaussian의 역연장이며 음의 실제 관측 거리로 전파하지 않는다. 적분량은 상대 제곱장·m² 단위로 보존하며 교정 없는 W 단위 전력으로 표시하지 않는다.

## 독립 기준값

`scripts/learning/generate-ray-wave-optics-references.py`는 제품을 불러오지 않고 NumPy·SciPy·SymPy로 `scripts/fixtures/ray-wave-optics-independent.json`을 생성한다. 광선288개 설정·2,592개 순차 표본은 직접 렌즈 좌표·각도를 갱신한다. Gaussian96개 설정의 복소장288개 관측은 실제 일차원 Fresnel 적분 두 개의 곱으로 계산했다. 면적 제곱장 적분은 별도 반경 적분, 새 허리는 폭 제곱의 독립 다항식 맞춤으로 대조한다. 위상 정상 조건은 SymPy에서 정확히0이다.

실행한 제품 대조의 최대 관측 오차는 광선 위치약1.05×10⁻¹⁷m·각도5.56×10⁻¹⁷rad, 복소장8.52×10⁻¹³, 폭 상대4.34×10⁻¹⁶, 적분량 상대7.23×10⁻¹⁶이었다. 이는 이 유한한 기준 집합의 실제 차이이며 모든 입력·근사의 보편적 오차 한계는 아니다. 원본 적분 범위와 허용 오차는 생성기에 남겼다.

## 상쇄·근축 유효성의 한계

입력 범위 끝값80개 조합도 실행했다. q 폭 분해·적분 보존의 최대 상대 차이는 각각약4.29×10⁻¹⁶·8.23×10⁻¹⁶이었다. 그러나 강한 위치·각도 상관에서 원래 공분산의 행렬식을 큰 두 항의 차로 구하면 작은 불변량을 잃을 수 있다. 이 탐색에서 직접 행렬식의 상대 잔차가약2.76×10⁴까지 커졌다. 이 현상을 이론적 보존의 수치 검증 통과로 세지 않는다.

모델은 원래 공분산과 인자 `M diag(w0/2,λ/(2πw0))`, 직접 행렬식·이론값·상대 잔차·상쇄 비율을 구분해 반환한다. 원래 모멘트를 임의로 투영·수정하지 않는다. 새 전용 테스트는 극단적인 상쇄가 드러나는지 실제로 확인한다. q의 허수부는 행렬식 항등식으로 안정적으로 계산한다. 발산각·렌즈에서의 기울기도 별도 진단이며, 큰 입력 조합을 Maxwell의 정확한 해로 인증하지 않는다.

## 원고와 검증 범위

두 단원의 한영 원고는 각각16개 절, 여섯 개 해설 문제를 담는다. 광선의 상 조건을 유도하고 부호·단위·허상·센서 번짐·조건수를 수치 예제로 설명한다. Gaussian은 이차원 정규화·복소 계수·q 부호·최소 허리·위상·폭 분해·모멘트·연구 벤치마크를 연결한다. 실제 콘텐츠 로더와 엄격한 KaTeX 검사에서 두 언어의 목차·수식 렌더링도 확인한다.

전용26개·전체3,707개 테스트, TypeScript·lint·기존 콘텐츠1,688개 URL 검사가 실제 종료0으로 통과했다. 기존 홈페이지의2,856개 파일과 새 기반8개 파일을 합한2,864개 최종 해시는 유지됐고 등록 데이터는 바이트 단위로 같다. 새 빌드·브라우저 검증은 주장하지 않는다. 실제 종료 근거는 `.runtime/learning/ray-wave-optics-foundation-verification.json`에 정리한다. 초기 개발 기록의 미완성 원고·복소 영성분 비교 허용량 문제와, KaTeX 플러그인의 지원하지 않는 타입 옵션은 최종 검증과 구별해 보존한다. 이 옵션은 제거하고 실제 KaTeX 경고와 오류가 없는지도 검사한다.
