## 준비 공분산 화면

분산 곱·Schrödinger/Robertson 하한·두 slack과 정확한 포화/가환 여부를 읽는다. 복소 Gram과 실수 공분산을 전환하고, V의 양의 제곱근으로 단위원을 옮긴 타원과 방향별 이차형식을 본다. 작은 양의 축은0으로 만들지 않으며 영 공분산은 한 점으로 표시한다. 타원은 비가환 공동 확률 등고선이 아니다. 방향별 표시는 반올림 기하이고 실제 u,v 조합은 Worker에서 다시 계산한다.

복소 사영의 길이·잔차와 계수, 실수 선형 결합·준비 내부/평균 사이 분산, 상태·관측량·가중 복소 변동 열을 제공한다. Var(A)=0이면 계수는 null/비유일이고 잔차 Var(B)는 유지한다. 차원에 맞는 입력 칸과 전체75개 정수의 JSON 편집을 제공한다.

## 측정 후 상태와 장치 비교 화면

Qubit 예제16개와22개 정수 입력으로 측정 강도·측정/후속 방향·Bloch 상태·결과별 quaternion 피드백을 바꾼다. 강도 슬라이더는 새 유리수 준비를 적용한다. 같은 효과의 양의 제곱근·피드백·재준비 instrument를 비교하고 입력/비선택/조건부 상태를 선택한다.

Bloch ball은 실제 계산한 길이를 유지하며 Three.js 카메라·2D 투영·WebGL 복구를 제공한다. 확률0의 조건부 상태는 null이며 다른 상태로 대신 그리지 않는다. Raw/보정 pointer의 분산·내재 잡음·bias·RMS 오차, RMS 교란·상태 거리·후속 분포 변화를 구별한다. κ=0의 보정은 null이다. 단순 곱·보정된 세 항·C와 구간 판정을 비교하며, 순차 공동 법칙·sharp-A 반복 누수·Choi/Kraus도 확인한다.

## 학습 흐름·저장·모션

각 단원은 고정 개념3단계·예측3개·안내 실험3개·퀴즈3개다. 고정 비교는 저장된 자유 실험과 독립적으로 계산한다. 준비·퀴즈 답·학습 표시는 가족/단원별로 저장한다. 잘못된 숫자·JSON은 현재 준비를 바꾸지 않고, 다른 가족의 저장 자료는 복원하지 않는다. 저장이 막혀도 현재 방문에서 학습을 계속할 수 있다.
