## 물리와 수치의 구분

원통은 고정된 영역이며 법선은 바깥쪽이다. 전기 저장 변화와 J·E, 자기 저장 변화와 발산·경계 전력을 별도 축에서 비교하여 SI 크기 차이로 작은 결함이 가려지지 않게 했다. 실제 μT 입력을 SI로 변환하며 밀도·흐름·일률·적분 에너지의 단위를 구분한다. 전류 누락 대조에서는 실제 총 전류와 Maxwell 적합성도 바뀐다. 에너지 전용 정적 반례는 에너지 수지가 맞아도 Faraday가 실패함을 보여준다.

펄스의 실제 E/B와 호환 기준을 분리한다. 같은 초기 E라도 초기 B가 달라 에너지 예산이 다를 수 있다. 실제 B=0 대조의 자기 에너지·흐름은0이고 전체 축 전기 에너지 식도 별도로 사용한다. 전체 축 값은 가로 단위 면적당이며 유한3차원 총 에너지가 아니다.

영에너지의 S/u는 미정이다. 절대 에너지가 표현되지 않을 때 해석적 모형 비율을 관측 몫으로 표시하지 않는다. 작은 비영 흐름·꼬리의 표현 손실·대칭 영점을 구분한다. 고정 구간은 중심±반폭으로 정한다. 양의 반폭이 끝점 표현에서 사라지면 구간 관측만 사용 불가이며 국소 관측은 유지한다. 정확히 빈 구간의 적분0과 구분한다. 구적과 해석 잔차는 독립 인증이나 엄밀한 오차 상한이 아니다.

## 실제 검증

전자기학 관련241개·전체4,064개 테스트와 타입·lint·콘텐츠1,706 URL·빌드1,714페이지·출력1,709 HTML 검사가 실제 종료 코드0으로 통과했다. 기존470개 단원·안내,42개 실험 그룹461항목 및 상대 순서를 등록 전 canonical 기준으로 보존했다. 이전 유도 가족이 전체의 마지막이어야 한다는 테스트는 가족 내부의 상대 순서를 검사하도록 바꾸었다.

2단원×2언어×2폭(320/1440)×2명암의16기본 상태와16특수 입력, 안내 펼침48개·예제58개·전체 조작4그룹을 확인했다. 정밀 입력·저장·퀴즈 오답과 정답·완료 저장·초기화·선수 링크·이전/다음 이동·목차·개념 단계·접근성·키보드·넘침·라벨 잘림·영어 한글 잔존·페이지 오류를 검사했다.

모바일 원본 SVG92개의 키보드 이동을 확인하고, 한영·명암 갤러리8개(92그림), 펼친 안내4개, 영어 개념8단계를 직접 검토했다. 영어 UI 전체556경로·614상태가 통과했다. 소스·설정2,971개와 출력4,159개를 동결하고 최종 원장·교육과정 동기화 뒤에도 일치함을 확인했다.

첫 원본 검토에서 원통의 S 화살표를 축 아래로 옮긴 표현이 실제 반지름 방향과 혼동될 수 있음을 발견했다. S는 세로 반지름 축, 법선은 가로 축에 배치하도록 수정했다. 소스가 바뀌므로 진행 중인 이전 화면·영어 작업을 종료하고 모든 검사·빌드·화면을 다시 수행했다. 처음 출력·부분 결과·종료 기록은 `.runtime/learning/poynting-energy-initial-arrow-layout/`에 보관하며 최종 증거로 사용하지 않는다.
