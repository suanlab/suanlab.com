# 양자정보 아홉 가족의 입력·계산 연결

2026-11-09. 아홉 단원의 입력 소유권 모듈, 수학 계산 진입점,44개 한영 교수 예제와 실제 Worker용 초안 corpus를 작성했다. 본문18개·수치 기반9단원에 이어 **입력 계약9/9**를 준비했다. 독립 응답 검증·Worker·화면·등록은 미완료다.

## 구현과 검증

- reader용 입력 모듈은 exact field·descriptor·배열 밀도·문자열 분수·정수/rank 예산을 검사하고 깊이 동결한다. 모델과 BigInt를 번들에 포함하지 않는다. 형식 검사와 수학적 물리성 검증을 구분했다.
- Worker/CLI 진입점은 입력을 다시 소유하고, 아홉 수학 가족과 주요화의 두 모드를 연결한다. 원래 입력을 응답에 포함하지만 수학적 응답 검증기는 아직 아니다.
- 기존 독립 참조가 새 wire 경로에서도 맞는지 판별·결합 엔트로피·앙상블·상대 엔트로피·BB84·텔레포테이션·오류 정정·주요화·용량을 대조한다. 초밀집 부호화의8개 순서/메시지와11개 KL 오류 가족도 별도로 대조한다.
- 원본 변이·getter/toJSON·prototype/symbol·배열 구멍·중복 디코딩 JSON 키·손실 숫자 표기·모든1–64복사본의 rank 경계·0 norm/비물리 상태·Schmidt 합 실패를 검사한다. rank의 최하위 bit가 수학 계산까지 보존되는 사례와 실제/참조 순서도 확인한다.
- 44개 한영 예제를 모두 계산하고, 아홉 가족/두 자원 모드·예제 ID·freeze·영어 표시를 확인한다. 브라우저 번들 의존성 검사는 입력 모듈1개, 교수 예제 모듈은 입력/예제2개뿐임을 확인한다.

새1,282검사와 이전 원고/수치/회로/채널을 합친3,768회귀, 타입·lint·corpus 재생성·기존 소스/출력 보존은 `.runtime/learning/quantum-information-input/verification.json`에 기록한다. 테스트의 독립 참조 대조는 오프라인 검증이며, 아직 실제 브라우저 Worker의 응답 신뢰 경계를 구현한 것은 아니다.
