# Colab 수업 설계 양식

이 양식은 [Colab 교육과정](../colab-curriculum.md)의 수업 하나를 설계하는 집필용 문서다.
내용을 채운 뒤 실제 `.ipynb`의 Markdown·코드 셀로 작성한다. 양식 자체는 실행 노트북이 아니다.

## 수업 정보

- 수업 ID, 강의 slug, 제목 `ko`/`en`, 기본/심화 구분
- 선수 지식, 학습 목표 2~3개, 예상 학습 시간
- 원고·노트북·개념도·해설의 관리 위치와 작성·검토 상태
- 원본 강의·영상·데이터 출처, 확인한 실행 환경과 날짜

## 1 문제와 실행 전 예측

짧은 상황을 제시한다. 입력을 바꾸면 어떤 결과가 나올지 먼저 선택하거나 적게 한다.
정답뿐 아니라 흔히 생기는 오해와 그 이유를 해설에 기록한다.

## 2 개념 그림과 이론

용어, 기호, 축, 단위, 모델 가정을 설명한다. 개념도에는 입력과 출력, 중간 상태를 표시한다.
수식의 각 기호와 코드 변수의 대응표를 제공한다.

## 3 환경과 데이터 셀

Python·패키지 확인, 필요한 설치, import, seed, 작은 데이터 준비 순으로 작성한다.
기본 예제는 개인 Drive와 유료 API 없이 실행한다. 데이터 크기·사용 조건·수집일을 기록한다.

## 4 최소 계산 코드

핵심 계산을 라이브러리 호출 전에 작은 배열이나 함수로 보인다.
입력 shape, 중간 값, 출력과 기준 정답을 함께 확인한다.

## 5 시각화와 매개변수 실험

첫 실행에서 예상 그림을 얻고, 의미 있는 매개변수 2~3개를 바꾸게 한다.
표에는 바꾼 값, 관찰 결과, 예측과의 차이, 이유를 기록한다.
위젯과 동일한 값을 일반 변수 셀로도 바꿀 수 있게 만든다.

## 6 표준 구현과 비교

직접 계산과 라이브러리의 입력·전처리·기본값을 맞춰 비교한다.
수치 허용 오차, 확률적 변동, 다른 동작이 생기는 조건을 설명한다.

## 7 연습문제와 해설

1. 개념 설명: 그림이나 수식으로 결과를 설명한다.
2. 코드 완성: 핵심 연산 또는 조건을 채운다.
3. 전이 과제: 다른 입력·데이터·경계 조건에 적용한다.

문항 ID와 정답 기준은 두 언어에서 같다. 공개 해설과 자가 점검은 학습 보조 자료로 제공하고,
실제 비공개 시험이나 성적 판정 기능은 별도 수업 운영 범위로 구분한다.

## 8 수업별 검증 기록

- [ ] 정의·그림·수식·코드가 같은 개념을 설명한다.
- [ ] 새 Colab CPU 런타임에서 Run all을 완료했다.
- [ ] 환경과 데이터 준비, 실행 시간, 검증 날짜를 기록했다.
- [ ] 작은 예제의 수치와 그림을 해설에 대조했다.
- [ ] 매개변수 실험과 경계 조건을 확인했다.
- [ ] 한국어·영어 코드, 문항 ID, 정답이 일치한다.
- [ ] 출력·개인 실행 기록을 정리하고 원본·실행 링크를 확인했다.
