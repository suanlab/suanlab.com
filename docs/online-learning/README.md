# Colab 강의와 AI를 위한 물리와 수학 제작 계획

작성일: 2026-10-26. 신규 교재 설계를 먼저 구체화하고, Colab은 Python Programming만
우선 제작한다. 신규 교재 **AI를 위한 물리와 수학**은 Three.js로 직접 조작하는
온라인 교재로 제작한다. 이 디렉터리는 제작 계획과 집필 초안을 담는다. 구현 단원의 현재 상태와
검토 방법은 [시범 구현 기록](physics-math-for-ai/preview-implementation.md)을 참조한다.
로컬 검토와 공개 서비스 배포를 구분한다.

## 두 교육 과정의 역할

| 구분 | 기존 강의와 도서 | 신규 AI를 위한 물리와 수학 |
| --- | --- | --- |
| 주된 경험 | 설명과 개념 그림을 읽고 Colab 코드를 실행 | 질문을 예측하고 3D 장면을 조작해 관계를 발견 |
| 핵심 산출물 | 이론 원고, 개념도, 실행 가능한 노트북, 연습문제 | 장별 원고, 수식, 시뮬레이션, 해설, 확인 과제 |
| 코드의 역할 | 학습자가 수정하고 실행하는 주 학습 도구 | 수학·물리 모델의 검증 및 선택 심화 자료 |
| 화면 | 강의 소개에서 원고·Colab·영상으로 연결 | 설명과 실험을 나란히 배치하고 모바일에서는 세로 배치 |

신규 교재는 기초 학습자부터 AI의 동작을 분석하고 새 연구를 수행하려는 연구자까지
대상으로 한다. 주차·학기·전체 장 수·분량 제한 없이 필요한 수학·물리를 계속 확장한다.
전체 정독과 연구 목적별 경로를 제공하고 각 단원의 선수 절·보충·심화를 연결한다.

## 현재 저장소에서 확인한 출발점

- [강의 목록](../../src/data/lectures/index.ts)에 11개 강의 분야가 있다.
  Python은 별도 강의 slug가 아니라 [YouTube Python](../../src/data/youtube/index.ts)의
  `pp`와 컴퓨터프로그래밍 `cpp`에 연결되어 있다.
- [과거 강의·특강 자료](../../src/data/courses/index.ts)와 영상 목록에 Colab·Drive·GitHub
  링크가 있다. 개별 노트북의 실행 상태와 공유 권한은 제작 착수 때 확인한다.
- [현재 온라인 도서](../../content/books/) 8권은 소개·목차 중심이다.
  [도서 로더](../../src/lib/books.ts)는 Markdown을 HTML로 바꾸며 현재 수식 전용 처리와
  코드 구문 강조를 포함하지 않는다. 신규 교재에는 장 단위 원고와 수식 렌더링이 필요하다.
- 정적 내보내기 Next.js, 한국어·영어 UI, 사이트 모션 정지 설정과
  [화면 가시성 감지](../../src/components/motion/use-scene-activity.ts)를 활용할 수 있다.
  Three.js는 공간·기하 단원의 실험에 도입했으며, 화면에 들어올 때 지연 로드한다.

## 공통 제작 원칙

1. 학습 목표, 개념도, 수식, 코드, 해설, 평가 문항이 같은 개념을 설명하게 만든다.
2. 한·영 원고와 UI를 함께 준비한다. 코드 식별자·수치·수식·정답은 언어와 무관하게 같다.
3. 기존 강의·영상 URL과 출처를 유지하면서 새 자료를 연결한다. 원본마다 관리 위치를 정해
   서로 다른 노트북 복사본을 동시에 수정하지 않는다.
4. 노트북과 3D 장면에 모델 가정, 단위, 데이터 출처, 유효 범위, 예상 결과를 명시한다.
5. 기본 수업은 작은 데이터와 CPU로 완주하게 설계한다. GPU·대규모 모델은 선택 심화다.
6. 진도·북마크는 초기에는 해당 브라우저에 저장한다. 기기 간 동기화는 별도의 계정·저장소
   설계가 필요한 후속 범위다.
7. Colab 자료의 기본 공개 상태는 `.ipynb` 실행 확인, 신규 교재는 본문·실험·대체 설명의
   확인으로 판정한다. 작성된 파일 수를 학습 과정 완성도로 표시하지 않는다.

## 이산수학 확장 (2026-10-28)

세기·조합, 이항계수·포함배제, 점화식·생성함수, 그래프·트리·DAG, 경로·연결성,

`npm run check:discrete`로 브라우저 검사를 실행한다. 다음 미집필 주제는 선형대수의
기저·차원·랭크·영공간 등이며, 51개 영역 전체의 완성을 뜻하지 않는다.


## 선형 구조 보완 (2026-10-28)
