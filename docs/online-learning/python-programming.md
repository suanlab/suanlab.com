# Python Programming Colab 과정

현재 Colab 제작 대상은 Python Programming 하나다. 신규 「AI를 위한 물리와 수학」 교재
설계를 우선 진행하면서, 이 과정의 01 수업을 시범 제작해 나머지 수업의 집필·실행 기준을 정한다.
다른 강의의 Colab 제작은 후속 참고 범위에 둔다.

## 대상과 학습 방식

프로그래밍을 처음 배우는 학습자가 Colab에서 코드를 실행하고 결과를 설명하는 과정이다.
각 수업은 **예측 → 개념 그림 → 최소 코드 → 입력 변경 → 시각화 → 자가 점검 → 해설**로 구성한다.
기본 환경은 Python CPU 런타임이며 GPU, 개인 Drive, 유료 API를 요구하지 않는다.

## 시범 수업 01

- 학습 목표: 셀을 순서대로 실행하고, 표현식·변수·출력을 구분하며 입력 변경의 영향을 설명한다.
- 예제: 일정한 속력 `speed_mps`와 시간 `time_s`에서 `distance_m = speed_mps * time_s` 계산.
- 개념 그림: 두 입력이 계산으로 연결되어 결과를 만드는 흐름과 현재 변수 값 표시.
- 실험: 속력과 시간을 바꾸고 출력·거리-시간 그래프가 함께 바뀌는지 확인.
- 자가 점검: 3 m/s로 4초 이동한 거리 계산. 초기 답 0은 미완성 상태이며 `TRY_AGAIN`이 정상이다.
- 해설: 12 m의 근거와 계산 코드를 제공하고 단위·일정한 속력이라는 가정을 설명.

그림을 만드는 보조 코드는 제공하고 학습자는 입력·표현식·출력을 먼저 다룬다.
코드 식별자와 그림의 변수명·단위는 두 언어에서 공유한다. 설명·질문·해설을 번역한다.

## 실행·공개 기준

1. 구조 검사와 한·영 코드 셀 일치 확인.
2. 비어 있는 로컬 Jupyter 커널에서 모든 셀 실행, 수치 결과·PNG 그림·미완성 과제 피드백 확인.
3. 예제의 다른 입력, 올바른 답·잘못된 답·경계 값의 자가 점검 동작 확인.
4. 실제 새 Colab CPU 런타임에서 같은 절차를 확인하고 별도 검증 날짜 기록.
5. 이후 홈페이지에서 원고·노트북·영상 링크를 연결한다.

로컬 Jupyter 통과를 실제 Colab 실행 통과로 표시하지 않는다. 시범 검증 명령과 환경은
[노트북 안내](../../notebooks/python-programming/README.md)에 기록한다.
