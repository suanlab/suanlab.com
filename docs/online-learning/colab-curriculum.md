# Colab 제작 기준과 후속 교육과정 참고

현재 제작 대상은 [Python Programming](python-programming.md) 하나다. 아래 다른 강의와 도서의
연결표는 후속 참고 목록이며 착수 일정에 포함하지 않는다. 기존 강의 주제를 개념 그림, 짧은 이론, 실행 코드, 매개변수 실험, 해설이 연결된
수업으로 구성한다. 학습자는 웹에서 설명과 예상 결과를 살펴보고 Colab 사본에서
코드를 수정·실행한다. 이 문서의 수업과 파일 경로는 제작 계획이다.

## 한 수업의 기본 흐름

1. **문제와 예측:** 실제로 풀 문제, 학습 목표 2~3개, 실행 전 예상 질문.
2. **이론과 개념도:** 용어·가정·수식을 설명하고 데이터나 상태가 바뀌는 그림 제공.
3. **최소 실행 예제:** 핵심 계산을 작은 코드로 직접 구현하고 중간 결과 출력.
4. **시각화와 실험:** 입력·매개변수를 바꾸고 변화의 이유를 기록.
5. **라이브러리 비교:** 직접 구현과 표준 라이브러리의 결과·차이를 확인.
6. **연습과 해설:** 코드 완성, 잘못된 해석 찾기, 새 입력 적용, 정답 근거 확인.

[수업 설계 양식](templates/colab-lesson.md)을 모든 노트북의 집필 기준으로 사용한다.

## 후속 참고 강의 목록

slug는 현재 강의 목록의 식별자다. Python 공통 모듈은 신규 보조 과정이며 `cpp`와 구분한다.

| 현재 분야 | 첫 수업과 개념 그림 | Colab에서 실행할 실험 | 환경과 확인 기준 |
| --- | --- | --- | --- |
| Python 공통 입문 (`pp` 영상) | 변수·배열·함수, 배열의 축과 shape | NumPy 배열 생성·브로드캐스팅, Matplotlib 그래프 | CPU, shape·dtype·계산 결과를 직접 설명 |
| 인공지능 `ai` | 탐색 트리, frontier와 방문 집합 | BFS·DFS·A*의 확장 순서·경로 비교 | CPU, BFS의 최소 간선 수 보장은 동일 비용 조건임을 구분 |
| 머신러닝 `ml` | 데이터 분할, 회귀선·잔차·손실 | 선형회귀 직접 구현과 라이브러리 비교, 과적합 실험 | CPU, 학습 데이터에만 전처리 적합, 검증·시험 데이터 구분 |
| 딥러닝 `dl` | 텐서·계산 그래프·역전파 | 작은 MLP, 자동 미분, 수치 미분과 비교 | 기본 CPU, GPU 심화, gradient 수치 오차 범위 명시 |
| 자연어처리 `nlp` | 토큰→벡터→유사도·검색 과정 | 한국어·영어 토큰화, TF-IDF와 코사인 유사도 | CPU, 토큰·어휘·벡터 크기를 추적, 모델 다운로드는 심화 |
| 컴퓨터비전 `cv` | RGB 채널, 커널·패딩·특징맵 | 합성 이미지에 필터·합성곱 적용, 경계 조건 비교 | CPU, 출력 크기와 수치 결과를 작은 예제로 검산 |
| 오디오신호처리 `asp` | 파형·주파수·스펙트로그램 | 사인파 합성, FFT·STFT, 샘플링 변화 | CPU, Hz·샘플레이트·나이퀴스트 조건을 함께 표시 |
| 빅데이터분석 `bd` | 수집→정제→집계→시각화 | 합성 CSV, pandas 집계·결측 처리, 데이터 규모 비교 | CPU 소규모 기준, 분산 처리 비교는 별도 환경 선택 심화 |
| 데이터베이스 `db` | 관계·키·JOIN·실행 계획 | sqlite3로 스키마·질의·인덱스 실험 | CPU, SQLite 동작 범위를 설명하고 다중 사용자 DB 심화와 구분 |
| 웹프로그래밍 `web` | 요청·응답, DOM, 클라이언트·서버 역할 | 작은 HTML/JSON 처리, 요청·응답 자료 분석 | Colab은 개념·데이터 실험, 브라우저 UI와 배포는 별도 프로젝트 |
| 컴퓨터프로그래밍 `cpp` | 메모리·배열·포인터·함수 호출 | Python 비교, 컴파일러 확인 후 작은 C/C++ 코드 실행 | 컴파일러·표준 버전 기록, 로컬 실행 경로 제공, 정의되지 않은 동작을 정답으로 쓰지 않음 |
| 클라우드컴퓨팅 `cloud` | 자원·큐·분산·장애 구조 | 자원 계측, 스케줄링·재시도·확장 정책 모의실험 | CPU, 실제 Docker/Kubernetes·클라우드 배포는 로컬/별도 계정 실습 |

Colab의 자원과 세션은 가변적이고 GPU가 보장되지 않는다. 따라서 기본 수업을 CPU에서
검증한다. 웹·클라우드의 상시 서비스 운영과 노트북 실행은 서로 다른 실습으로 설계한다.
환경 범위는 [Colab 공식 FAQ](https://research.google.com/colaboratory/faq.html)를 따른다.

## 후속 참고 도서 연결

기존 8권의 소개·목차를 아래 수업군과 연결해 본문·개념도·Colab을 함께 확장한다.
도서마다 중복 코드를 복사하지 않고 공통 수업 ID로 같은 검증된 실습을 참조한다.

| 현재 도서 slug | 연결할 수업군 | 우선 실습 |
| --- | --- | --- |
| `python-programming-basics` | Python 공통 입문, `cpp` | 배열·함수·실행 상태 추적 |
| `data-science-python` | `bd`, `db` | 데이터 정제·집계·시각화·SQL |
| `machine-learning-fundamentals` | `ml` | 회귀·평가·데이터 분할 |
| `deep-learning-pytorch` | `dl` | 텐서·자동 미분·작은 신경망 |
| `natural-language-processing` | `nlp` | 토큰·벡터·텍스트 검색 |
| `computer-vision` | `cv` | 이미지 채널·필터·합성곱 |
| `audio-speech-processing` | `asp` | 파형·스펙트럼·시간 주파수 분석 |
| `agentic-ai` | `ai`·`nlp` 선택 심화, 기존 Agent/RAG 특강 자료 | 검색·도구 호출·상태 전이·평가 |

Agent/RAG 수업은 후속 검토 대상으로 둔다. 작은 문서 검색과 로컬 도구를 만들고,
고정된 모델 응답으로 제어 흐름을 재현한다. 실제 모델 호출은 선택 심화로 구분하고
사용 모델·비용·데이터 전송 범위를 실행 전에 설명한다. 고정 응답 실험을 실제 LLM의
추론 성능 평가로 표시하지 않는다.

## 노트북 구성과 관리

Python 과정은 `notebooks/python-programming/`에서 먼저 작성한다. 다른 분야의 경로는
후속 제작 시 도입할 제안이며 아직 공개 링크가 아니다.

```text
notebooks/python-programming/<nn>-<topic>.<locale>.ipynb
notebooks/lectures/<slug>/<nn>-<topic>.ko.ipynb
notebooks/lectures/<slug>/<nn>-<topic>.en.ipynb
notebooks/lectures/<slug>/solutions/<nn>-<topic>.<locale>.ipynb
public/assets/learning/lectures/<slug>/<topic>/
```

- 한 수업 ID는 `ml-linear-regression`처럼 분야와 개념으로 정한다. URL·노트북 파일·그림에
  같은 ID를 사용하고 번역은 `.ko`/`.en`으로 구분한다.
- 한·영 노트북의 코드와 계산 결과를 일치시킨다. 설명·문항·그림 라벨을 번역하고
  코드 식별자와 데이터 열 이름은 동일하게 둔다. 코드 셀 일치 여부를 공개 전에 확인한다.
- 새 노트북은 이 저장소의 `master`에서 관리하는 안을 기본으로 한다. 실제 파일이 공개된
  뒤 `https://colab.research.google.com/github/suanlab/suanlab.com/blob/master/<notebook-path>`
  형식의 실행 링크를 연결한다. 외부 원본을 선택한 수업은 그 저장소·분기를 명시한다.
- 라이브 노트북은 실행 출력과 개인 실행 기록을 정리해서 저장한다. 웹용 예상 결과 그림은
  같은 코드에서 생성한 별도 자산으로 관리한다. 학습자가 코드를 실행하면 그림을 재생성한다.
- 개념 그림은 SVG 또는 재현 가능한 Python 그림을 우선한다. 축, 단위, 범례, 대체 설명을
  포함하고 색 이외에도 선 모양·기호로 구분한다.
- 기본 데이터는 작은 합성 데이터나 사용 조건이 확인된 공개 데이터다. Drive 마운트,
  개인 파일, 유료 API 없이 첫 실행이 끝나게 한다.
- 설치 셀, 확인된 Python/패키지 버전, 난수 seed, 데이터 생성 방법을 기록한다.
  seed만으로 모든 GPU 연산의 동일성을 보장한다고 설명하지 않는다.
- 위젯이 동작하지 않아도 매개변수 셀을 수정해 다시 실행하면 같은 실험을 할 수 있게 한다.

## 공개 전 검증

각 수업에 아래 결과를 함께 기록한다. 통과하지 않은 항목을 완료로 표시하지 않는다.

| 영역 | 통과 조건 |
| --- | --- |
| 이론 | 정의·수식·차원·가정이 예제와 일치하고 개념도에 설명 가능한 의미가 있음 |
| 실행 | 새 Colab CPU 런타임에서 Run all, 숨은 실행 순서나 개인 파일 없이 완료 |
| 환경 | 설치·데이터 셀 포함, 검증 날짜·환경·실행 시간 기록, GPU 심화와 구분 |
| 결과 | 작은 고정 예제의 수치 검산과 그림의 예상 변화가 해설과 일치 |
| 평가 | 코드 완성·설명·응용 과제에 각각 채점 근거와 해설이 있음 |
| 언어 | 한·영 설명과 그림 라벨이 준비되고 코드·정답·수치가 같음 |
| 연결 | 강의·영상·Colab·GitHub 원본·다운로드 링크가 실제 준비된 자료로 연결 |

홈페이지에서는 이론 읽기, Colab 실행, 영상, 파일 다운로드를 수업별로 연결한다.
준비 상태와 기본/심화 구분을 표시하고, 실행 검증 날짜는 Colab 자료에만 붙인다.
원고와 노트북을 준비한 후 강의 데이터를 확장하고 기존 링크·발표 모드와 함께 검증한다.
